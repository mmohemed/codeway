1. الفئات المجردة (Abstract Classes)

الفئة المجردة هي فئة "غير مكتملة". نستخدمها عندما نريد تعريف مفهوم عام (مثل: "حيوان") لا نريد إنشاء كائنات منه مباشرة، بل نريد استخدامه كقاعدة للأصناف الأخرى (مثل: "كلب"، "قطة").

المميزات الأساسية:

  • يمكن أن تحتوي على دوال مكتملة (بها كود) ودوال مجردة (بدون كود).
  • يمكن أن تحتوي على حقول (Fields) ومتغيرات.
  • تسمح بتعريف "المشيدات" (Constructors).
Abstract Example
public abstract class Shape
{
    // خاصية عادية
    public string Color { get; set; }

    // دالة مجردة: يجب على الأبناء تنفيذها
    public abstract double CalculateArea();

    // دالة عادية: ترثها جميع الأشكال
    public void DisplayColor() => Console.WriteLine($"الشكل لونه: {Color}");
}

public class Square : Shape
{
    public double Side { get; set; }
    public override double CalculateArea() => Side * Side;
}

2. الواجهات (Interfaces)

الواجهة هي "عقد" (Contract). هي لا تخبر الكلاس من أنت (كما تفعل الوراثة)، بل تخبره ماذا تستطيع أن تفعل. تسمح الـ #C للكلاس بتنفيذ أكثر من واجهة في نفس الوقت.

قاعدة ذهبية: ابدأ بالواجهة إذا كنت تريد تعريف سلوك مشترك بين كلاسات غير مترابطة (مثل: ميزة "الطباعة" التي قد يحتاجها كلاس "فاتورة" وكلاس "تقرير").
Interface Example
public interface IPayable
{
    // في الواجهات، كل الدوال مجردة تلقائياً
    void ProcessPayment(decimal amount);
}

public class OnlineStore : IPayable
{
    public void ProcessPayment(decimal amount)
    {
        Console.WriteLine($"جاري معالجة دفع مبلغ {amount} عبر الإنترنت...");
    }
}

3. متى نستخدم كل منهما؟ (المقارنة الحاسمة)

الميزة الفئة المجردة (Abstract) الواجهة (Interface)
الوراثة المتعددة غير مدعومة (يرث من أب واحد). مدعومة (يمكن تنفيذ عدة واجهات).
الحقول (Variables) يمكن أن تحتوي على متغيرات. لا تحتوي على متغيرات (فقط خصائص).
التنفيذ (Logic) يمكن كتابة كود داخل بعض الدوال. (سابقاً) لا يمكن، (حالياً) تسمح بدوال افتراضية.
الغرض لتعريف "نوع" أساسي مشترك. لتعريف "قدرات" أو سلوكيات مشتركة.

مثال يجمع الاثنين معاً:

تخيل نظام طيران؛ الطائرة هي "مركبة" (Abstract Class) وفي نفس الوقت هي "قابلة للطيران" (Interface).

public interface IFlyable { void Fly(); }

public abstract class Vehicle { public string EngineType { get; set; } }

public class Airplane : Vehicle, IFlyable
{
    public void Fly() => Console.WriteLine("الطائرة تقلع الآن...");
}
