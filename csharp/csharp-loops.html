LOOPS IN C# | الحلقات التكرارية

♾️ إتقان الحلقات التكرارية

for, while, do-while, foreach — أدوات التحكم في التكرار. شرح متكامل، أمثلة حقيقية، وتصميم فخم يعكس قوة C#.

أنواع الحلقات الأساسية

for الأكثر شيوعاً

تستخدم عندما يكون عدد التكرارات معلومًا. تتكون من تهيئة، شرط، ومُغير.

// طباعة الأرقام من 1 إلى 5
for (int i = 1; i <= 5; i++)
{
    Console.Write(i + " ");
}
// الناتج: 1 2 3 4 5
// تكرار تنازلي
for (int j = 10; j > 0; j-=2)
    Console.WriteLine(j);

while

ينفذ طالما الشرط صحيح. يُستخدم عندما لا نعرف عدد التكرارات مسبقاً.

int counter = 0;
while (counter < 5)
{
    Console.WriteLine($"تكرار {counter}");
    counter++;
}
احذر من الحلقات اللانهائية: تأكد من تحديث الشرط.

do-while

ينفذ مرة واحدة على الأقل، ثم يتحقق الشرط.

int number = 0;
do {
    Console.WriteLine("ينفذ حتماً");
    number++;
} while (number < 3);

foreach

مثالي للتكرار على المجموعات (arrays, lists).

string[] names = {"أحمد", "سارة", "يوسف"};
foreach (string name in names)
{
    Console.WriteLine($"مرحباً {name}");
}

تطبيقات متقدمة & خوارزميات

حساب المضروب (Factorial)

int n = 5, fact = 1;
for (int i = 1; i <= n; i++)
    fact *= i;
Console.WriteLine($"5! = {fact}"); // 120

البحث عن قيمة في مصفوفة

int[] nums = { 8, 23, 77, 42 };
int target = 77;
bool found = false;
foreach (int num in nums)
    if (num == target) { found = true; break; }
Console.WriteLine(found ? "تم العثور" : "غير موجود");

while مع إدخال المستخدم

string input = "";
while (input != "quit")
{
    Console.Write("أدخل كلمة (quit للخروج): ");
    input = Console.ReadLine();
    Console.WriteLine($"أدخلت: {input}");
}
نصائح ذهبية: استخدم break للخروج المبكر، continue لتخطي التكرار الحالي. الحلقات المتداخلة مفيدة للمصفوفات ثنائية الأبعاد.

// النتائج ستظهر هنا ...
⚡ هذا المحاكي يعرض مخرجات الحلقة بناءً على منطق C#، لتوضيح سلوك التكرار.

التحكم في تدفق الحلقات: break و continue

break

يخرج من الحلقة بشكل فوري.

for (int i = 0; i < 10; i++)
{
    if (i == 5) break;
    Console.Write(i + " "); // 0 1 2 3 4
}

continue

يتخطى التكرار الحالي وينتقل للتالي.

for (int i = 1; i <= 6; i++)
{
    if (i % 2 == 0) continue;
    Console.Write(i + " "); // 1 3 5
}

إتقان الحلقات: أداء وأخطاء شائعة

  • ✨ تجنب الحلقات اللانهائية: تأكد من تحديث متغير الشرط داخل while.
  • 🚀 foreach أسرع وأكثر أماناً للمصفوفات والقوائم، لكن لا يمكن تعديل المجموعة أثناء التكرار.
  • 🎯 for vs foreach: foreach أكثر readable، بينما for يعطيك تحكم كامل بالمؤشر.
  • 📌 الحلقات المتداخلة: انتبه للأداء عند التعشيق العميق (O(n²).
