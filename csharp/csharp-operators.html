العوامل المنطقية والرياضية

دليل شامل ومتكامل لفهم كافة عوامل العمليات الحسابية والمقارنة والمنطقية في لغة C# مع أمثلة حية وتطبيقات عملية

العوامل الرياضية

+الجمعint sum = 5 + 3; // 8
-الطرحint diff = 10 - 4; // 6
*الضربint product = 7 * 6; // 42
/القسمة (عدد صحيح / فاصلة عائمة)double div = 15 / 2.0; // 7.5
%باقي القسمة (Modulus)int rem = 17 % 5; // 2
++الزيادة بمقدار 1 (Increment)int x = 5; x++; // x = 6
--النقصان بمقدار 1 (Decrement)int y = 8; y--; // y = 7
نصيحة: عند قسمة عددين صحيحين، النتيجة تكون عدداً صحيحاً (يتم تجاهل الكسر). استخدم double أو float للحصول على نتائج دقيقة.

العوامل المنطقية & المقارنة

==يساويif (a == b)
!=لا يساويif (x != y)
>أكبر منif (age > 18)
<أصغر منif (temp < 0)
>=أكبر أو يساويif (score >= 60)
<=أصغر أو يساويif (value <= 100)
&&AND (و) منطقي(a > 0 && b > 0)
||OR (أو) منطقي(isWeekend || isHoliday)
!NOT (نفي) منطقيif (!isFinished)
مهم: العوامل المنطقية تُستخدم في الشروط (if, while) لتكوين تعابير معقدة، وتقيم إلى true/false.

أمثلة عملية متكاملة

📐 عمليات حسابية مركبة

// حساب متوسط درجات مع باقي القسمة
int math = 95, science = 88, programming = 92;
int total = math + science + programming;
double average = total / 3.0;
int remainder = total % 3;

Console.WriteLine($"المجموع: {total}");
Console.WriteLine($"المعدل: {average:F2}");
Console.WriteLine($"الباقي: {remainder}");

⚡ منطق AND / OR متقدم

// التحقق من أهلية القيادة (العمر + رخصة)
int age = 20;
bool hasLicense = true;
bool isEligible = (age >= 18) && hasLicense;

// موظف في عطلة نهاية الأسبوع أو إجازة
bool isWeekend = true;
bool isVacation = false;
bool canRest = isWeekend || isVacation;

Console.WriteLine($"Eligible to drive: {isEligible}");
Console.WriteLine($"Can rest: {canRest}");
يمكن دمج العوامل الحسابية مع المنطقية في جمل شرطية قوية، مثل: if ((score > 80) && (attendance >= 75))

أولويات العمليات (Operator Precedence)

عند كتابة تعبيرات معقدة، يتم ترتيب تنفيذ العمليات حسب الأولوية. إليك الترتيب من الأعلى (الأولوية القصوى) إلى الأدنى:

() الأقواس
++ -- (Postfix)
+ - ! (أحادي)
* / % (ضرب/قسمة)
+ - (جمع/طرح)
< > <= >= (مقارنة)
== != (مساواة)
&& (AND منطقي)
|| (OR منطقي)
= (الإسناد) 
// مثال: أولوية الضرب قبل الجمع
int result = 5 + 3 * 2;   // النتيجة 11 وليس 16
int withParentheses = (5 + 3) * 2; // النتيجة 16

bool cond = 10 > 5 && 3 < 8; // true لأن && بعد المقارنات

العوامل المركبة (Compound Assignment)

+=a += 5 ← a = a + 5
-=b -= 3 ← b = b - 3
*=c *= 2 ← c = c * 2
/=d /= 4 ← d = d / 4
%=e %= 3 ← e = e % 3
هذه العوامل تختصر الكتابة وتحسن الأداء، خاصة في الحلقات والتكرارات.

أسئلة شائعة ونقاط متقدمة

❓ الفرق بين = و == ؟
= عامل إسناد (تعيين قيمة)، بينما == للمقارنة (true/false). خطأ شائع استخدام = داخل if.
❓ ماذا يحدث عند قسمة عددين صحيحين على / ؟
يتم تقريب النتيجة إلى أقرب عدد صحيح (إلغاء الكسر). استخدم 2.0 أو تحويل صريح للقسمة الحقيقية.
❓ ما الفرق بين & و && في C#؟
&& يقوم بـ short-circuit (إذا كان المعامل الأول false لا ينفذ الثاني). & يُنفذ كلا المعاملين (bitwise أو منطقي بدون اختصار). يُفضل && في الشروط.
❓ كيف تؤثر الأولوية على المنطق؟
&& له أسبقية أعلى من ||، لذلك a || b && c تعني a || (b && c). استخدم الأقواس لتوضيح النية.
