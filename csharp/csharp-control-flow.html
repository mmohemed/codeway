الجمل الشرطية في C#

تحكم في مسار برنامجك باستخدام if، else if، else، و switch. تعلم كيف تتخذ القرارات بناءً على الشروط المنطقية.

if / else switch statement Ternary Operator

if, else if, else

تستخدم if لتنفيذ كود معين إذا تحقق شرط ما. يمكن ربطها بـ else if لعدة شروط، وelse للحالة الافتراضية.

int score = 85;

if (score >= 90)
{
    Console.WriteLine("ممتاز!");
}
else if (score >= 70)
{
    Console.WriteLine("جيد جداً");
}
else if (score >= 50)
{
    Console.WriteLine("مقبول");
}
else
{
    Console.WriteLine("راسب، حاول مرة أخرى");
}
ملاحظة: يتم فحص الشروط من الأعلى إلى الأسفل، وعند أول شرط صحيح يتم تنفيذ الكود الخاص به ثم الخروج من الجملة الشرطية.

switch case

مناسب عند وجود عدة قيم ثابتة لمتغير واحد. switch ينفذ الكود المرتبط بالحالة المطابقة.

char grade = 'B';

switch (grade)
{
    case 'A':
        Console.WriteLine("ممتاز 🔥");
        break;
    case 'B':
        Console.WriteLine("جيد جداً 👍");
        break;
    case 'C':
        Console.WriteLine("جيد ✅");
        break;
    default:
        Console.WriteLine("درجة غير معروفة");
        break;
}
في C# يجب إنهاء كل case بكلمة break أو return أو القفز goto (نادر) لتجنب "fall-through".

متى تستخدم if ومتى تستخدم switch؟

العامل الشرطي (Ternary Operator)

طريقة مختصرة لكتابة if-else بسيطة: شرط ? القيمة_إذا_صحيح : القيمة_إذا_خطأ

int temperature = 28;
string weatherStatus = (temperature > 25) ? "حار ☀️" : "معتدل 🌤️";
Console.WriteLine(weatherStatus);  // الناتج: حار ☀️

// يمكن تداخل العامل الثلاثي لكن بحذر
int number = 5;
string result = (number > 0) ? "موجب" : (number < 0) ? "سالب" : "صفر";

العوامل المنطقية المركبة

دمج الشروط باستخدام && (AND) , || (OR) , ! (NOT)

int age = 20;
bool hasPermission = true;

if (age >= 18 && hasPermission)
{
    Console.WriteLine("مسموح بالدخول");
}

string day = "Friday";
if (day == "Saturday" || day == "Friday")
{
    Console.WriteLine("عطلة نهاية الأسبوع 🎉");
}

bool isLoggedIn = false;
if (!isLoggedIn)
{
    Console.WriteLine("الرجاء تسجيل الدخول");
}

جرب بنفسك: محاكاة حية لجمل شرطية

هذا البرنامج يطلب (محاكاة) درجة الطالب ثم يطبع التقدير باستخدام if-else if. اضغط على "تشغيل المحاكاة" لترى النتيجة بناءً على درجة محددة مسبقاً (يمكنك تغيير القيمة في الكود أدناه).

int studentScore = 76; // غيّر هذه القيمة لتجربة نتائج مختلفة

if (studentScore >= 90)
    Console.WriteLine("تقدير: A (ممتاز)");
else if (studentScore >= 80)
    Console.WriteLine("تقدير: B (جيد جداً)");
else if (studentScore >= 70)
    Console.WriteLine("تقدير: C (جيد)");
else if (studentScore >= 60)
    Console.WriteLine("تقدير: D (مقبول)");
else
    Console.WriteLine("تقدير: F (راسب)");
// انقر على الزر لمشاهدة نتيجة الجمل الشرطية

تلميح: يمكنك تخيل تغيير قيمة studentScore إلى 95 أو 45 لترى اختلاف المخرجات.

أفضل الممارسات

  • استخدم الأقواس {} حتى مع جملة واحدة لتوضيح النطاق.
  • تجنب تداخل (Nesting) عميق لـ if - استخدم return مبكراً أو switch.
  • ضع الحالات الأكثر احتمالاً في البداية لتحسين الأداء.
  • في switch، استخدم default للتعامل مع القيم غير المتوقعة.

أخطاء شائعة تجنبها

  • استخدام = بدلاً من == في الشرط (التخصيص بدل المقارنة).
  • نسيان break في switch يؤدي إلى خطأ ترجمة (C# يمنع fall-through).
  • وضع فاصلة منقوطة بعد if مباشرة: if(score>50); ينهي الشرط فوراً.
  • عدم استخدام الأقواس مع شروط معقدة يسبب أخطاء منطقية.
