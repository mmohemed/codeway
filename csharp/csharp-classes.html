🏛️ الكلاسات (Classes) و الكائنات (Objects)

أساس البرمجة الكائنية التوجه (OOP) — شرح متكامل للكلاسات، الحقول، الخصائص، المنشئات، والكائنات مع أمثلة تفاعلية وتصميم فخم.

ما هو الكلاس؟ وما هو الكائن؟

الكلاس (Class) هو قالب أو مخطط لإنشاء كائنات، يحدد الخصائص (fields/properties) والسلوكيات (methods). الكائن (Object) هو实例 (instance) حقيقي من الكلاس له حالته الخاصة.

// تعريف كلاس بسيط
public class Car
{
    // fields (حقول)
    public string Model;
    public int Year;
    
    // constructor (منشئ)
    public Car(string model, int year)
    {
        Model = model;
        Year = year;
    }
    
    // method
    public void DisplayInfo()
    {
        Console.WriteLine($"{Model} - {Year}");
    }
}

// إنشاء كائن (object) من الكلاس
Car myCar = new Car("Tesla", 2024);
myCar.DisplayInfo();  // Tesla - 2024
تشبيه: الكلاس مثل قالب الكعكة، والكائن هو الكعكة الفعلية المصنوعة من القالب.

مكونات الكلاس المتكاملة

الحقول (Fields)

متغيرات داخل الكلاس تحمل البيانات.

private string name;
public int age;

الخصائص (Properties)

تغلف الحقول وتوفر تحكم (get/set).

public string Name { get; set; }
public int Age { get; private set; }

المنشئات (Constructors)

تُستدعى عند إنشاء كائن، لتهيئة الحالة الأولية.

public Person(string name)
{
    Name = name;
}

مستويات الوصول (Access Modifiers)

المُعدِّلالوصف
publicمتاح من أي مكان.
privateمتاح فقط داخل نفس الكلاس.
protectedمتاح داخل الكلاس والكلاسات المشتقة.
internalمتاح داخل نفس التجميع (assembly).
public class BankAccount
{
    private decimal balance;   // لا يمكن الوصول من الخارج
    public decimal Balance { get { return balance; } }
    
    public void Deposit(decimal amount)
    {
        if (amount > 0) balance += amount;
    }
}

this و static vs instance members

🔹 الكلمة المفتاحية this

تشير إلى الكائن الحالي، تستخدم لتمييز الحقول عن المعاملات.

public class Employee
{
    public string Name;
    public Employee(string Name)
    {
        this.Name = Name;
    }
}

⚡ static vs instance

الأعضاء الثابتة تنتمي للكلاس نفسه وليس لكائن محدد.

public class Utils
{
    public static double Pi = 3.14159;
    public static int Add(int a, int b) => a + b;
}
// الاستدعاء: Utils.Add(2,3);

الوراثة (Inheritance) و تعدد الأشكال (Polymorphism)

الكلاس يمكن أن يرث من كلاس آخر، ويعيد تعريف الدوال باستخدام virtual و override.

public class Animal
{
    public virtual void Speak() => Console.WriteLine("صوت حيوان");
}
public class Dog : Animal
{
    public override void Speak() => Console.WriteLine("نباح: هو هو");
}
// الاستخدام:
Animal pet = new Dog();
pet.Speak();  // نباح: هو هو
🧬 الوراثة تعزز إعادة الاستخدام، وتعدد الأشكال يجعل الكود أكثر مرونة.

منشئات متقدمة: Constructor Chaining & Static Constructor

public class Product
{
    public string Name;
    public double Price;
    
    public Product(string name) : this(name, 0) { }
    
    public Product(string name, double price)
    {
        Name = name;
        Price = price;
    }
    
    static Product() // static constructor - ينفذ مرة واحدة
    {
        Console.WriteLine("تهيئة الكلاس");
    }
}

أفضل الممارسات في تصميم الكلاسات

  • ✅ Encapsulation (التغليف): اجعل الحقول private ووفّر properties للوصول الآمن.
  • 📐 مبدأ المسؤولية الواحدة: كل كلاس يجب أن يكون لديه سبب واحد فقط للتغيير.
  • 🧩 استخدام المُهيئات (Constructors) لضمان أن الكائنات تُنشأ بحالة صالحة.
  • 🚀 تجنب الكلاسات الضخمة: قسّم الكلاسات الكبيرة إلى كلاسات أصغر ومتخصصة.
  • 📖 التوثيق: استخدم XML comments لتوثيق الكلاس والأعضاء.
