المفوضيات والأحداث

Delegates, Events & Event-Driven Programming

المفوضيات (Delegates) هي العمود الفقري لكل شيء متقدم في C#: الأحداث، الـ Lambdas، LINQ، والـ async/await. تعلم كيف تعامل الدوال كبيانات، وتبني أنظمة أحداث احترافية تفاعلية.

ما هي المفوضيات؟ WHAT ARE DELEGATES?

المفوضية (Delegate) هي نوع (Type) يمثّل مرجعاً إلى دالة. بمعنى آخر: هي "متغير" يمكنه أن يحمل دالة بدلاً من قيمة رقمية. هذا يفتح الباب أمام تمرير الدوال كمعاملات، وتخزينها في متغيرات، واستدعائها لاحقاً — وهو جوهر البرمجة الوظيفية (Functional Programming).

تخيل أنك تريد بناء دالة Sort يمكنها ترتيب أي قائمة بأي معيار. بدلاً من كتابة دالة ترتيب لكل نوع (أرقام، أسماء، تواريخ)، تمرّر المعيار نفسه كدالة. المفوضية هي ما يسمح بذلك.

تشبيه بسيط: المفوضية مثل "ورقة عنوان" تحمل اسم دالة. يمكنك تمرير هذه الورقة لأي شخص (دالة أخرى)، وسيستطيع هو استدعاء الدالة المذكورة فيها دون معرفة محتواها.

تعريف مفوضية واستخدامها

C# — تعريف واستخدام Delegate 
// 1. تعريف نوع المفوضية (توقيع الدالة)
public delegate int MathOperation(int a, int b);

public class Calculator
{
    public static int Add(int a, int b) => a + b;
    public static int Multiply(int a, int b) => a * b;

    public static void Demo()
    {
        // 2. إنشاء متغير من نوع المفوضية وإسناد دالة إليه
        MathOperation op = Calculator.Add;

        // 3. استدعاؤه كأنه دالة عادية
        int result = op(5, 3);
        Console.WriteLine(result); // 8

        // 4. تغيير الدالة التي يشير إليها
        op = Calculator.Multiply;
        Console.WriteLine(op(5, 3)); // 15
    }
}

لاحظ أن المفوضية عرّفت توقيع الدالة (نوع المعاملات ونوع الإرجاع)، ثم أي دالة تطابق هذا التوقيع يمكن إسنادها للمتغير. هذا هو ما يسمى بـ Type Safety — المترجم يضمن أنك لا تسند دالة بتوقيع مختلف.

Multicast Delegates: المفوضية يمكنها أن تشير إلى أكثر من دالة في الوقت نفسه باستخدام += و-=. عند الاستدعاء تُنفَّذ كل الدوال بالترتيب. هذا هو الأساس الذي تُبنى عليه الأحداث لاحقاً.

C# — Multicast Delegate 
public delegate void Notifier(string message);

public static void Main()
{
    Notifier notify = null;

    notify += msg => Console.WriteLine($"📧 Email: {msg}");
    notify += msg => Console.WriteLine($"📱 SMS: {msg}");
    notify += msg => Console.WriteLine($"🔔 Push: {msg}");

    notify("مرحباً!");
    // الناتج:
    // 📧 Email: مرحباً!
    // 📱 SMS: مرحباً!
    // 🔔 Push: مرحباً!
}

المفوضيات الجاهزة في .NET BUILT-IN DELEGATES

لا تحتاج لتعريف مفوضية جديدة في كل مرة. .NET وفّرت ثلاثة أنواع جاهزة تغطي 99% من الحالات، وهي التي ستستخدمها فعلياً في مشاريعك:

Action<T>

دالة لا تُرجع شيئاً (void) وقد تأخذ حتى 16 معاملاً. الأكثر استخداماً.

Action<string> log = msg => ...

Func<T, TResult>

دالة تُرجع قيمة. المعامل الأخير دائماً هو نوع الإرجاع.

Func<int,int> sq = x => x*x

Predicate<T>

دالة تُرجع bool. مكافئة لـ Func<T,bool> لكن دلالتها أوضح.

Predicate<int> isEven = n => n % 2 == 0

النوع التوقيع مثال
Action void (args...) Action<string> print = Console.WriteLine;
Func<TResult> TResult () Func<DateTime> now = () => DateTime.Now;
Func<T, TResult> TResult (T) Func<int,int> sq = x => x * x;
Predicate<T> bool (T) Predicate<int> pos = n => n > 0;

قاعدة ذهبية: استخدم Action إذا كانت الدالة لا تُرجع شيئاً، Func إذا كانت تُرجع قيمة، Predicate إذا كانت تُرجع bool فقط للتصفية. لا تُعرّف مفوضية مخصصة إلا إذا كان الاسم يعطي دلالة مهمة (مثل EventHandler<T>).

الأحداث — Events EVENT-DRIVEN PROGRAMMING

الحدث (Event) هو غلاف حول مفوضية يُتيح نمط الناشر/المشترك (Publisher/Subscriber). الفكرة: كائن "ناشر" يعلن أنه سيُطلق حدثاً عند حدوث شيء (مثل: زر تم النقر عليه، ملف تم تحميله)، وكائنات أخرى "مشتركة" تسجّل اهتمامها بهذا الحدث وتنفّذ كوداً عند إطلاقه.

الفرق الجوهري بين حدث ومفوضية عادية هو التغليف (Encapsulation): الحدث لا يسمح للمشتركين من خارج الكائن باستدعاءه مباشرة، ولا بإعادة تعيين قائمة المشتركين. هذا يمنع كوداً خبيثاً أو خاطئاً من "إطلاق" الحدث من الخارج.

المفهوم المفوضية (Delegate) الحدث (Event)
الوصول من الخارج يمكن استدعاؤها مباشرة لا — يمكن فقط الاشتراك/الانسحاب
إعادة التعيين يمكن بـ = لا يمكن (فقط += و-=)
الاستخدام تمرير دوال كمعاملات نمط الناشر/المشترك
الغلاف — مفوضية + تغليف + قيد

بناء حدث كامل من الصفر

C# — Publisher / Subscriber 
using System;

// 1. تعريف EventArgs مخصص يحمل بيانات الحدث
public class OrderEventArgs : EventArgs
{
    public string OrderId { get; set; }
    public decimal Total   { get; set; }
}

// 2. الناشر: يعلن الحدث ويُطلقه متى شاء
public class OrderService
{
    // تعريف الحدث باستخدام EventHandler<T> الجاهزة
    public event EventHandler<OrderEventArgs>? OrderPlaced;

    public void PlaceOrder(string id, decimal total)
    {
        // ... حفظ الطلب في قاعدة البيانات ...

        // إطلاق الحدث (فقط من داخل الناشر)
        OnOrderPlaced(new OrderEventArgs { OrderId = id, Total = total });
    }

    protected virtual void OnOrderPlaced(OrderEventArgs e)
    {
        // النسخة الآمنة للخيوط: انسخ المرجع قبل الاستدعاء
        var handler = OrderPlaced;
        handler?.Invoke(this, e);
    }
}

// 3. المشترك: يسجّل اهتمامه بالحدث وينفّذ كوداً
public class EmailNotifier
{
    public void Subscribe(OrderService service)
    {
        service.OrderPlaced += OnOrderPlaced;
    }

    private void OnOrderPlaced(object? sender, OrderEventArgs e)
    {
        Console.WriteLine($"📧 إرسال إيميل للطلب {e.OrderId} بمبلغ {e.Total}");
    }
}

// 4. الاستخدام
var service = new OrderService();
var notifier = new EmailNotifier();
notifier.Subscribe(service);

service.PlaceOrder("ORD-001", 2500m);
// 📧 إرسال إيميل للطلب ORD-001 بمبلغ 2500

تسريب الذاكرة (Memory Leak): إذا اشترك كائن في حدث كائن آخر أطول عمراً ولم ينسحب (-=)، فسيبقى الأول حياً للأبد لأن الحدث يحتفظ بمرجع إليه. دائماً انسحب من الأحداث في Dispose.

الناشر — OrderService

المشتركون — Subscribers
EmailNotifier service.OrderPlaced += OnEmail;
SmsNotifier service.OrderPlaced += OnSms;
Logger service.OrderPlaced += OnLog;

حالات عملية من الواقع REAL-WORLD USE CASES

المفوضيات والأحداث ليست نظرية — إليك أين تقابلها يومياً في كود C# الاحترافي:

1. تمرير معيار ترتيب مخصص

C# — Sort with Comparison<T> 
var products = new List<Product> { ... };

// الترتيب حسب السعر تنازلياً — المفوضية هي "قاعدة الترتيب"
products.Sort((a, b) => b.Price.CompareTo(a.Price));

// أو باستخدام Comparison<T> صريحة
Comparison<Product> byName = (a, b) => a.Name.CompareTo(b.Name);
products.Sort(byName);

2. تمرير فلتر مخصص لدالة عامة

C# — Generic Filter with Predicate 
public static List<T> Filter<T>(List<T> source, Predicate<T> condition)
{
    var result = new List<T>();
    foreach (var item in source)
        if (condition(item))
            result.Add(item);
    return result;
}

// استخدام:
var adults = Filter(people, p => p.Age >= 18);
var active = Filter(users, u => u.IsActive);

3. Callbacks — إعلام عند الانتهاء

C# — Callback with Action 
public void DownloadFile(string url, Action<bool> onComplete)
{
    // ... تحميل الملف ...
    bool success = true;
    onComplete(success);  // إعلام المتصل بالنتيجة
}

// استخدام:
DownloadFile("https://...", ok =>
{
    Console.WriteLine(ok ? "✅ تم التحميل" : "❌ فشل");
});

ارتباط بالدروس السابقة: كل ما استخدمته في LINQ (Where(x => ...)) ليس سوى Func<T, bool> — أي مفوضية! وTask.Run(() => ...) في درس تعدد المسارات يأخذ Action. المفوضيات في كل مكان.

أفضل الممارسات الاحترافية BEST PRACTICES

للاستخدام الصحيح للمفوضيات والأحداث، اتبع هذه القواعد المستخلصة من مكتبة .NET نفسها:

  • استخدم EventHandler<T> للأحداث بدلاً من تعريف مفوضية مخصصة — فهي المعيار في .NET.
  • توقيع الحدث دائماً: (object? sender, TEventArgs e) — هذا ما يتوقعه الجميع.
  • استخدم ?.Invoke() عند إطلاق الحدث — يمنع NullReferenceException إن لم يكن هناك مشتركون.
  • انسحب دائماً (-=) في Dispose إذا اشترك كائن في حدث كائن آخر أطول عمراً — لتجنب تسريب الذاكرة.
  • ارفع الأحداث عبر دالة protected virtual OnXxx — يسمح للفئات المشتقة بتخصيص السلوك (نمط .NET القياسي).
  • لا تلتقط استثناءات المشتركين في الناشر — خطأ في مشترك واحد يجب ألا يُسقط الآخرين، لكن الفصل مسؤولية نظام أعلى.

الخلاصة والاختبار السريع SUMMARY & QUIZ

ما تعلمته في هذا الدرس

  • المفوضية هي مرجع إلى دالة — تتيح تمرير الدوال كبيانات.
  • الأنواع الجاهزة: Action، Func، Predicate تغطي أغلب الاستخدامات.
  • الحدث = مفوضية + تغليف، يسمح بنمط الناشر/المشترك دون كشف الدوال للخارج.
  • خطر تسريب الذاكرة من الاشتراك في الأحداث دون انسحاب، وكيف تتجنبه.
  • ارتباط المفوضيات بـ LINQ وTask.Run — الأساس نفسه.
