المجاميع في لغة #C (Collections)

تعلم كيفية اختيار هيكل البيانات الصحيح لتطبيقك

1. ما هي المجاميع ولماذا هي أفضل من المصفوفات؟

المصفوفات (Arrays) محدودة الحجم؛ بمجرد إنشائها لا يمكنك تغيير سعتها. بينما المجاميع (Collections) توفر مرونة هائلة؛ فهي تنمو وتتقلص تلقائياً وتوفر عمليات جاهزة للبحث والفرز.

نصيحة تقنية: في تطبيقات #C الحديثة، نفضل دائماً استخدام System.Collections.Generic لأنها توفر أداءً أفضل (Type Safety) وتمنع أخطاء الـ Run-time.

2. القائمة الديناميكية (List<T>)

هي الأكثر استخداماً. تشبه المصفوفة ولكنها مرنة جداً في الإضافة والحذف.

using System.Collections.Generic;

List<string> names = new List<string>();
names.Add("Ahmed");
names.Add("Sara");
names.Remove("Ahmed"); // الحذف سهل جداً

foreach (var name in names) {
    Console.WriteLine(name);
}

3. القاموس (Dictionary<TKey, TValue>)

يستخدم لتخزين البيانات على شكل (مفتاح وقيمة). فكر فيه كفهرس كتاب؛ تبحث عن المصطلح لتجد التعريف بسرعة فائقة.

Dictionary<int, string> users = new Dictionary<int, string>();
users.Add(101, "محمد");
users.Add(102, "خالد");

// الوصول المباشر عبر المفتاح (سريع جداً)
Console.WriteLine(users[101]);

4. الطوابير والمكدسات (Queue & Stack)

تستخدم هذه المجاميع عندما يكون ترتيب المعالجة مهماً جداً:

Queue (FIFO)

الأول دخولاً هو الأول خروجاً (مثل طابور البنك).

Stack (LIFO)

الأخير دخولاً هو الأول خروجاً (مثل رصة الأطباق).

5. كيف تختار النوع المناسب؟

النوع متى تستخدمه؟ الميزة الأساسية
List<T> عندما تريد قائمة بسيطة مرتبة. الوصول السريع عبر الـ Index.
Dictionary<K,V> عندما تحتاج للبحث السريع عن بيانات عبر معرف (ID). سرعة خرافية في البحث.
HashSet<T> عندما لا تريد تكرار القيم في القائمة. يمنع التكرار تلقائياً.
Queue<T> في أنظمة المهام والرسائل (Messaging). يحافظ على الترتيب الزمني.
