File I/O, Streams & Serialization in C#

نظرة عامة على File I/O FILE I/O OVERVIEW

في C#، التعامل مع الملفات يتم عبر فضاء الأسماء System.IO. هذا الفضاء يوفر أدوات متعددة المستويات: من دوال بسيطة لقراءة ملف كامل بسطر واحد، إلى تدفقات (Streams) دقيقة للتحكم الكامل في البايتات.

الاختيار الصحيح يعتمد على حجم البيانات: الملفات الصغيرة (بضعة كيلوبايتات) يمكن قراءتها كاملة، بينما الملفات الكبيرة (مئات الميجابايتات) يجب معالجتها عبر تدفقات لتجنّب نفاد الذاكرة.

File

دوال ثابتة (Static) بسيطة لعمليات على الملف ككل: قراءة، كتابة، حذف، نسخ، نقل.

Streams

تدفقات ثنائية للتحكم في البايتات أو المحارف سطراً بسطر — للملفات الكبيرة.

Async I/O

دوال ReadAllTextAsync وWriteAllTextAsync — لا تحجب الخيط.

Serialization

تحويل الكائنات إلى JSON/XML والعكس عبر System.Text.Json.

قاعدة اختيار: إذا كان الملف أقل من 10 ميجابايت → File.ReadAllText. أكبر من ذلك → StreamReader سطراً بسطر. أكبر من 100 ميجابايت → FileStream مع buffering.

فئة File — العمليات السريعة THE File CLASS

فئة File توفر دوالاً ثابتة لإنجاز العمليات الشائعة بسطر واحد. هذه الدوال مريحة للملفات الصغيرة والمتوسطة، لكنها تُغلِق الملف تلقائياً بعد كل عملية — وهذا قد يكون غير مناسب للكتابة المتكررة.

الدالة الوصف النسخة الـ Async
File.ReadAllText(path) قراءة الملف كامل كنص ReadAllTextAsync
File.ReadAllLines(path) قراءة الملف كمصفوفة أسطر ReadAllLinesAsync
File.ReadAllBytes(path) قراءة الملف كمصفوفة بايتات ReadAllBytesAsync
File.WriteAllText(path, text) كتابة نص (يستبدل المحتوى) WriteAllTextAsync
File.AppendAllText(path, text) إضافة نص في النهاية AppendAllTextAsync
File.Exists(path) هل الملف موجود؟ —
File.Delete(path) حذف الملف —
File.Copy(src, dst) نسخ الملف —
File.Move(src, dst) نقل/إعادة تسمية —
C# — قراءة وكتابة سريعة 
using System.IO;

string path = "notes.txt";

// كتابة (تستبدل المحتوى)
File.WriteAllText(path, "السطر الأول\nالسطر الثاني\n");

// إضافة نص في النهاية
File.AppendAllText(path, "السطر الثالث\n");

// قراءة كامل الملف
string content = File.ReadAllText(path);
Console.WriteLine(content);

// قراءة سطراً بسطر
foreach (string line in File.ReadAllLines(path))
    Console.WriteLine($"→ {line}");

// نسخة async (لا تحجب الخيط)
await File.WriteAllTextAsync(path, "نص جديد");
string asyncContent = await File.ReadAllTextAsync(path);

تحقّق دائماً من وجود الملف: استدعاء ReadAllText على ملف غير موجود يرمي FileNotFoundException. استخدم File.Exists(path) قبل القراءة أو غلّف الاستدعاء بـ try/catch.

التدفقات — Streams STREAMS & STREAMREADER / WRITER

التدفق (Stream) هو تجريد لقناة بيانات متتابعة. بدلاً من تحميل الملف كاملاً في الذاكرة، تقرأه قطعة تلو الأخرى. هذا ضروري للملفات الكبيرة والعمليات الشبكية.

FileStream

التدفق الأساسي للبايتات. يُستخدم للصور، الصوت، وأي ملف ثنائي.

StreamReader

يغلف FileStream لقراءة النصوص (يدعم الترميز UTF-8).

StreamWriter

يغلف FileStream لكتابة النصوص سطراً بسطر.

MemoryStream

تدفق في الذاكرة — مفيد لمعالجة البيانات قبل حفظها.

C# — StreamReader / StreamWriter 
using System.IO;

string path = "log.txt";

// كتابة سطراً بسطر — using يضمن إغلاق الملف
using (var writer = new StreamWriter(path, append: true))
{
    writer.WriteLine($"[{DateTime.Now:HH:mm:ss}] بدء التطبيق");
    writer.WriteLine($"[{DateTime.Now:HH:mm:ss}] اتصال ناجح");
}

// قراءة سطراً بسطر بدون تحميل الملف كاملاً
using (var reader = new StreamReader(path))
{
    string? line;
    while ((line = reader.ReadLine()) != null)
        Console.WriteLine(line);
}

// النسخة async — أفضل للأداء
await using (var reader = new StreamReader(path))
{
    string? line;
    while ((line = await reader.ReadLineAsync()) != null)
        Console.WriteLine(line);
}

using هي صديقتك: أي كائن Stream يُنفّذ IDisposable. استخدم using (أو await using) لضمان تحرير الملف حتى لو حدث استثناء. إهمال ذلك يُسبب قفل الملف ومنع الكتابة عليه لاحقاً.

الملفات الثنائية — FileStream

C# — Binary Files 
// نسخ ملف صورة (ثنائي) قطعة تلو الأخرى
using var input  = new FileStream("source.jpg", FileMode.Open, FileAccess.Read);
using var output = new FileStream("copy.jpg",   FileMode.Create, FileAccess.Write);

byte[] buffer = new byte[81920]; // 80 KB — حجم موصى به
int read;
while ((read = await input.ReadAsync(buffer)) > 0)
    await output.WriteAsync(buffer.AsMemory(0, read));

التسلسل — Serialization JSON SERIALIZATION

عندما تريد حفظ كائنات (وليس نصوصاً فقط) في ملف، تحتاج إلى تسلسل (Serialization): تحويل الكائن إلى صيغة نصية مثل JSON أو XML. والعكس يسمى إلغاء التسلسل (Deserialization).

في .NET الحديث، System.Text.Json هو الخيار الافتراضي — أسرع وأكثر أماناً من Newtonsoft.Json القديم.

المكتبة الاستخدام الأداء
System.Text.Json الافتراضي في .NET 5+ أسرع، مبني في الإطار
Newtonsoft.Json مرونة أعلى، خصائص قديمة أبطأ قليلاً
XmlSerializer XML للتطبيقات القديمة أبطأ، لكنه مطلوب في بعض الأنظمة
C# — JSON Serialize & Deserialize 
using System.Text.Json;
using System.Text.Json.Serialization;

public class User
{
    public int Id { get; set; }
    public string Name { get; set; } = "";
    public string Email { get; set; } = "";
}

var user = new User { Id = 1, Name = "أحمد", Email = "a@x.com" };

// الخيارات: تنسيق مقروء
var options = new JsonSerializerOptions { WriteIndented = true };

// كائن → JSON → ملف
string json = JsonSerializer.Serialize(user, options);
await File.WriteAllTextAsync("user.json", json);

// ملف → JSON → كائن
string loaded = await File.ReadAllTextAsync("user.json");
User? restored = JsonSerializer.Deserialize<User>(loaded);

Console.WriteLine(restored?.Name); // أحمد

// حفظ قائمة كاملة من الكائنات
var users = new List<User> { user };
await File.WriteAllTextAsync("users.json",
    JsonSerializer.Serialize(users, options));

الأمان أولاً: لا تفتح ملفات JSON من مصادر غير موثوقة باستخدام JsonSerializer.Deserialize بلا حدود — قد تؤدي إلى استنزاف الذاكرة أو هجمات. تحقّق دائماً من حجم الملف والمصدر.

التعامل مع المسارات — Path

C# — Path Class 
// بناء مسار بشكل صحيح عبر الأنظمة
string baseDir = Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments);
string fullPath = Path.Combine(baseDir, "CodeWay", "data", "user.json");

// استخراج أجزاء المسار
Console.WriteLine(Path.GetFileName(fullPath));         // user.json
Console.WriteLine(Path.GetDirectoryName(fullPath));    // ...\CodeWay\data
Console.WriteLine(Path.GetExtension(fullPath));        // .json
Console.WriteLine(Path.GetFileNameWithoutExtension(fullPath)); // user

// إنشاء مجلد إن لم يكن موجوداً
Directory.CreateDirectory(Path.GetDirectoryName(fullPath)!);

لا تربط المسارات يدوياً بـ "\\": استخدم Path.Combine دائماً — فهي تتكيف مع فاصل المسار في النظام (Windows \، Linux/macOS /).

أفضل الممارسات الاحترافية BEST PRACTICES

للتعامل الآمن والفعّال مع الملفات، اتبع هذه القواعد:

  • استخدم using أو await using دائماً مع Streams — يضمن تحرير الملف حتى عند حدوث استثناء.
  • فضّل الدوال async في التطبيقات الحديثة — ReadAllTextAsync وWriteAllTextAsync لا تحجب الخيط الرئيسي.
  • غلّف عمليات الملفات في try/catch واعالج IOException، UnauthorizedAccessException، DirectoryNotFoundException.
  • استخدم Path.Combine لا الربط اليدوي — لضمان التوافق عبر الأنظمة وتجنب أخطاء الفواصل.
  • تحقّق من وجود الملف والمجلد قبل العمليات — File.Exists وDirectory.Exists أو Directory.CreateDirectory.
  • لا تفتح ملفات ضخمة في الذاكرة — استخدم StreamReader للملفات أكبر من 10 ميجابايت، FileStream للأكبر من 100 ميجابايت.
  • حدّد الترميز صراحةً (Encoding.UTF8) عند العمل مع نصوص عربية لتجنب مشاكل الأحرف.

الخلاصة والاختبار السريع SUMMARY & QUIZ

ما تعلمته في هذا الدرس

  • فئة File للعمليات السريعة على الملفات الصغيرة (قراءة، كتابة، نسخ، حذف).
  • التدفقات (StreamReader / StreamWriter) للملفات الكبيرة والمعالجة سطراً بسطر.
  • استخدام using لضمان تحرير الملفات، والنسخ الـ async لتجنب حجب الخيط.
  • تسلسل الكائنات إلى JSON والعكس باستخدام System.Text.Json.
  • بناء المسارات بشكل صحيح باستخدام Path.Combine وDirectory.CreateDirectory.
