أول برنامج في C#

رحلة البداية الصحيحة مع لغة C# و .NET. تعلم كيفية كتابة برنامج "Hello World" خطوة بخطوة، وفهم كل جزء من الكود بطريقة مبسطة.

برنامج Hello World

أول برنامج تقليدي في أي لغة برمجة. سيقوم البرنامج بطباعة جملة "Hello, World!" على وحدة التحكم. يمثل هذا الأساس لفهم تركيب البرنامج (Syntax) وكيفية تنفيذه.

using System;

namespace MyFirstProgram
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("مرحباً بالعالم!");
            Console.WriteLine("Hello, World!");
        }
    }
}
ملاحظة: يمكنك تشغيل هذا الكود في أي بيئة تدعم C# مثل Visual Studio أو Visual Studio Code أو عبر منصة .NET Fiddle.

تحليل الكود

using System;استيراد مساحة الأسماء System التي تحتوي على الفئات الأساسية مثل Console.
namespaceتنظيم الكود في حاوية منطقية لتجنب تعارض الأسماء.
class Programكل شيء في C# داخل class. Program هو اسم الفئة الرئيسية.
static void Mainنقطة دخول البرنامج. يتم تنفيذ الأوامر الموجودة داخله أولاً.
Console.WriteLine()دالة لطباعة النص مع سطر جديد في نافذة الطرفية.
لماذا static و void؟ static تعني أنه يمكن استدعاء الدالة دون إنشاء كائن، و void تعني أنها لا تُرجع قيمة. Main يجب أن تكون static لأن نظام التشغيل يستدعيها مباشرة.

دليل خطوة بخطوة: إنشاء وتشغيل أول مشروع C#

  • 1
    تثبيت بيئة .NET SDK — قم بتحميل SDK من موقع Microsoft الرسمي (يتضمن مترجم C# وأدوات سطر الأوامر).
  • 2
    إنشاء مشروع جديد — افتح الطرفية (Terminal) واكتب الأمر: dotnet new console -n FirstCSharpApp
  • 3
    الانتقال إلى المجلد — cd FirstCSharpApp سترى ملف Program.cs يحتوي على كود افتراضي.
  • 4
    كتابة الكود — استبدل المحتوى بكود "Hello World" الذي تعلمناه أعلاه باستخدام أي محرر نصوص.
  • 5
    تشغيل البرنامج — نفّذ الأمر dotnet run وستظهر رسالتك الترحيبية على الشاشة مباشرة! 🚀
  تعمل أوامر dotnet على جميع أنظمة التشغيل Windows, macOS, Linux.

مفاهيم يجب معرفتها

  مترجم C# : يقوم بتحويل الكود إلى لغة وسيطة (IL) ثم ينفذها CLR.

  Console.WriteLine vs Console.Write : الأولى تضيف سطراً جديداً، الثانية تطبع بدون سطر.

  علامة ; (الفاصلة المنقوطة) : تنتهي كل جملة في C# بفاصلة منقوطة.

  الأقواس {} : تحدد نطاق الكود (code blocks) مثل الفئات والدوال.

تذكر: C# حساسة لحالة الأحرف (Case-Sensitive) — Console لا تساوي console.
