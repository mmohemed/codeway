FUNCTIONS | METHODS IN C#

⚡ الدوال (Methods) البرمجة الكينونية

إعادة استخدام الكود، التنظيم، والتجريد — شرح متكامل لكل شيء عن الدوال في C# مع أمثلة تفاعلية وتصميم فاخر.

ما هي الدوال؟

الدالة (Method) هي كتلة من الكود تؤدي مهمة محددة، يمكن استدعاؤها عدة مرات. تساعد في تقليل التكرار وتنظيم البرنامج. تتكون من: المُعدِّل (modifier)، نوع الإرجاع، الاسم، المعاملات، والجسم.

// تركيب الدالة الأساسي
[public/private/static] type_return اسم_الدالة(parameters)
{
    // body
    return value; // إذا لم يكن void
}

// مثال بسيط
public int Add(int a, int b)
{
    return a + b;
}

أنواع الدوال حسب الإرجاع والمعاملات

Void (بدون إرجاع)

تنفذ عملية ولا ترجع قيمة.

public void PrintMessage(string msg)
{
    Console.WriteLine(msg);
}

مع إرجاع قيمة

ترجع قيمة من نوع محدد (int, string, bool...).

public int GetSquare(int x)
{
    return x * x;
}

معاملات اختيارية (Optional)

قيم افتراضية للمعاملات.

public void Greet(string name, string prefix = "مرحباً")
{
    Console.WriteLine($"{prefix} {name}");
}

params (معاملات متغيرة)

استقبال عدد غير محدد من الوسائط.

public int Sum(params int[] numbers)
{
    return numbers.Sum();
}

تمرير المعاملات: ref و out و in

📌 ref (تمرير بالمرجع)

يعدل المتغير الأصلي.

void Double(ref int x) { x *= 2; }
int num = 5; Double(ref num); // num = 10

📌 out (إرجاع قيم متعددة)

يُستخدم لإخراج قيم من الدالة.

bool TryDivide(int a, int b, out int result)
{
    if(b==0) { result=0; return false; }
    result = a/b; return true;
}

📌 in (تمرير للقراءة فقط)

يمنع تعديل القيمة داخل الدالة.

void Show(in int value) 
{ Console.WriteLine(value); }

static vs non-static (Instance Methods)

النوعالوصفالاستدعاء
static method تابعة للكلاس نفسه، لا تحتاج إلى إنشاء كائن. ClassName.MethodName()
instance method تحتاج إلى كائن من الكلاس للاستدعاء. var obj = new Class(); obj.Method(); 
public class Calculator
{
    public static int AddStatic(int a, int b) => a + b;
    public int Multiply(int a, int b) => a * b;
}
// الاستخدام:
int sum = Calculator.AddStatic(3,5);
Calculator calc = new Calculator();
int product = calc.Multiply(3,5);

Method Overloading (التحميل الزائد)

يمكن أن تحمل الدوال نفس الاسم لكن بمعاملات مختلفة (عدد أو نوع).

public int Sum(int a, int b) => a + b;
public double Sum(double a, double b) => a + b;
public int Sum(int a, int b, int c) => a + b + c;

// الاستدعاء يتطابق تلقائياً مع أنسب دالة
فائدة: يوفر مرونة كبيرة ويحسن قراءة الكود.

الدوال الاستدعائية (Recursion)

دالة تستدعي نفسها لحل مشكلة بتقسيمها إلى أجزاء أصغر. مثال: حساب المضروب.

public int Factorial(int n)
{
    if (n <= 1) return 1;
    return n * Factorial(n - 1);
}
// Factorial(5) = 120
⚠️ انتبه: يجب وجود شرط إيقاف لمنع الحلقات اللانهائية.

🔥 مختبر الدوال التفاعلي

قم بتجربة استدعاء دوال مبنية مسبقاً، أو شاهد سلوك الدوال بأنواعها المختلفة:

// ستظهر نتيجة استدعاء الدالة هنا ...

المحاكي يوضح سلوك الدوال بناءً على منطق C# الحقيقي.

إرشادات ذهبية لكتابة دوال احترافية

  • ✨ مبدأ المسؤولية الواحدة (SRP): كل دالة تؤدي مهمة واحدة فقط.
  • 📝 التسمية الواضحة: استخدم أسماءاً تعبر عن الوظيفة مثل CalculateTotal, GetUserById.
  • ⚡ تجنب الآثار الجانبية: الدوال يجب أن لا تعدل متغيرات عامة إلا عند الضرورة.
  • 🔁 إعادة الاستخدام: إذا كررت كوداً أكثر من مرة -> حوّله إلى دالة.
  • 📦 استخدام (expression-bodied members) للدوال البسيطة: public int Square(int x) => x * x;
