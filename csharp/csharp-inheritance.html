الوراثة وتصميم الأنظمة الكبيرة

لا تتعلق الوراثة بمجرد نسخ الكود، بل هي فن بناء علاقات "Is-A" التي تسمح بنمو النظام وتطوره دون الحاجة لهدم الأكواد القديمة.

1. فلسفة الوراثة والذاكرة

عندما تقوم بوراثة كلاس في #C، فإن الذاكرة تقوم بإنشاء كائن يحتوي على جميع حقول الأب متبوعة بحقول الابن. هذا يعني أن كائن الابن هو فعلياً كائن "أب مُعزز".

لماذا نستخدمها؟ تخيل نظام بنكي. لدينا كلاس Account يحتوي على (الرقم، الرصيد). ثم لدينا SavingsAccount و CheckingAccount. كلاهما حسابات، لكن لكل منهما سلوك مختلف في سحب الأموال. الوراثة تضمن أن كل أنواع الحسابات ستملك "رصيداً" دون تكرار كتابة الكود.

2. تسلسل استدعاء المشيدات

قاعدة ذهبية: يتم تنفيذ مشيد الأب دائماً قبل مشيد الابن. إذا لم تحدد المشيد يدوياً، ستحاول #C استدعاء المشيد الافتراضي للأب.

Inheritance_Constructors.cs
class BaseEmployee
{
    public BaseEmployee(string name)
    {
        Console.WriteLine("1. تنفيذ مشيد الأب: " + name);
    }
}

class Manager : BaseEmployee
{
    // استخدام base لتمرير البيانات للأب
    public Manager(string name) : base(name)
    {
        Console.WriteLine("2. تنفيذ مشيد الابن (Manager)");
    }
}

3. التحكم في الوصول: Protected

المُعدل (Modifier) إمكانية الوصول
public متاح للجميع في أي مكان.
private داخل الكلاس نفسه فقط (الابن لا يراه).
protected داخل الكلاس نفسه وفي جميع الكلاسات التي ترث منه.

4. تعدد الأشكال (Polymorphism)

هذا هو الجزء الأقوى. يمكنك معاملة الابن على أنه أب. مثال: قائمة من الموظفين تحتوي على مديرين، مبرمجين، ومحاسبين. يمكنك استدعاء CalculateSalary() للجميع دون معرفة نوعهم الدقيق.

Override_Example.cs
public class Device
{
    // Virtual تعني: اسمح للأبناء بتغيير طريقتي
    public virtual void TurnOn() => Console.WriteLine("جاري تشغيل الجهاز...");
}

public class Laptop : Device
{
    // Override تعني: سأقوم بالتنفيذ بطريقتي الخاصة
    public override void TurnOn() 
    {
        Console.WriteLine("تظهر شاشة الترحيب ويندوز...");
    }
}

5. الفئات المجردة (Abstract Classes)

الفئة المجردة هي "خطة" لا يمكنك إنشاء كائن منها. هي وجدت فقط لتكون أباً لفئات أخرى.

public abstract class Payment
{
    public abstract void Process(); // دالة بدون محتوى
}

public class VisaCard : Payment
{
    public override void Process() => Console.WriteLine("الدفع عبر فيزا");
}
