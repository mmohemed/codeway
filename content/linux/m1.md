## لماذا Linux؟

**Linux** نظام تشغيل مفتوح المصدر يشغّل معظم خوادم الإنترنت، وكل السحابة تقريباً، والحاويات (Docker)، وأجهزة Android، والموجهات والأجهزة المدمجة. ومختص الأمن أو مهندس السحابة يقضي يومه في طرفية Linux، لذلك إتقانها مهارة أساسية لا غنى عنها.

> **عن الطرفية في هذه الدورة:** الأوامر تعمل في **طرفية محاكاة** داخل المتصفح تمثّل خادم Ubuntu 24.04، فيه المستخدمة `sara` (عضو في مجموعة `sudo`) وخادم ثانٍ اسمه `web01` في الشبكة. المخرجات مكتوبة لتطابق الأدوات الحقيقية، لكنها نموذج تعليمي وليست نظاماً حقيقياً. للتجربة الحقيقية: ثبّت Ubuntu في VirtualBox، أو استخدم WSL على Windows، أو خادماً سحابياً صغيراً.

## النواة والتوزيعات

**Linux** نفسه هو **النواة (Kernel)**: الجزء الذي يدير المعالج والذاكرة والأجهزة. و **التوزيعة** نواة Linux مع أدوات ومدير حزم وإعدادات جاهزة:

| العائلة | أمثلة | مدير الحزم | الاستخدام الشائع |
|---|---|---|---|
| Debian | **Ubuntu** و Debian و Kali | `apt` | الخوادم والسحابة والأمن (Kali) |
| Red Hat | RHEL و Rocky و Fedora | `dnf` | الشركات الكبيرة |
| Alpine | Alpine | `apk` | حاويات Docker صغيرة جداً |
| Arch | Arch و Manjaro | `pacman` | المستخدمون المتقدمون |

ولكل إصدار من Ubuntu اسم ورقم: `24.04` يعني أبريل 2024، و **LTS** (Long Term Support) يعني دعماً بتحديثات أمنية لسنوات، وهو ما تختاره للخوادم دائماً.

## أول أوامر: من أنا وأين أنا؟

```terminal
$ whoami
sara
$ hostname
ubuntu
$ pwd
/home/sara
$ cat /etc/os-release
PRETTY_NAME="Ubuntu 24.04.1 LTS"
NAME="Ubuntu"
VERSION_ID="24.04"
VERSION="24.04.1 LTS (Noble Numbat)"
VERSION_CODENAME=noble
ID=ubuntu
ID_LIKE=debian
HOME_URL="https://www.ubuntu.com/"
$ uname -r
6.8.0-45-generic
$ uptime
 10:00:06 up 1:00,  1 user,  load average: 0.08, 0.03, 0.01
```

- `whoami`: المستخدم الحالي، و `hostname`: اسم الجهاز.
- `pwd` (Print Working Directory): المجلد الحالي.
- `/etc/os-release` ملف يصف التوزيعة وإصدارها، و `uname -r` إصدار النواة.

## شكل الأمر

```text
الأمر   الخيارات   الوسائط
ls      -l -a      /home
```

الخيارات تبدأ بـ `-` ويمكن دمجها: `ls -l -a` مثل `ls -la`. وكل أمر يرجع **رمز خروج**: `0` نجاح، وغيره فشل، ويُقرأ بـ `$?`:

```terminal
$ ls /nothing
ERR: ls: cannot access '/nothing': No such file or directory
$ echo $?
2
$ ls / > /dev/null && echo "worked"
worked
$ ls /nothing 2> /dev/null || echo "failed quietly"
failed quietly
```

- `&&`: نفّذ التالي فقط إذا نجح السابق، و `||`: فقط إذا فشل.
- `> /dev/null` يرمي المخرجات، و `2>` يحوّل رسائل **الخطأ** وحدها.

## شجرة واحدة تبدأ من /

لا توجد أقراص C و D في Linux: كل شيء شجرة واحدة جذرها **`/`**، والأقراص تُركَّب (Mount) كمجلدات داخلها.

| المجلد | ما فيه |
|---|---|
| `/home` | مجلدات المستخدمين (`/home/sara`) |
| `/root` | مجلد المدير root |
| `/etc` | **ملفات الإعدادات** للنظام والبرامج |
| `/var` | بيانات متغيرة: **السجلات** في `/var/log`، ومواقع الويب في `/var/www` |
| `/usr` | البرامج والمكتبات (`/usr/bin`) |
| `/tmp` | ملفات مؤقتة يكتب فيها الجميع |
| `/bin` و `/sbin` | الأوامر الأساسية (اختصارات لـ `/usr/bin`) |
| `/dev` و `/proc` | الأجهزة والعمليات كملفات |

ومن الناحية الأمنية: `/etc` و `/var/log` أول ما يفحصه المحقق، و `/tmp` مكان يحبه المهاجمون لأن الجميع يكتب فيه.

## التنقل

```terminal
$ cd /etc
$ pwd
/etc
$ ls ssh
sshd_config
$ cd ..
$ pwd
/
$ cd ~
$ pwd
/home/sara
$ cd /var/log && ls
auth.log  nginx  syslog
```

| المسار | معناه |
|---|---|
| `/etc/ssh` | **مطلق**: يبدأ من الجذر |
| `ssh` | **نسبي**: من المجلد الحالي |
| `.` و `..` | المجلد الحالي، والمجلد الأب |
| `~` | مجلد المستخدم الرئيسي |

## ls وتفاصيل الملفات

```terminal
$ ls -la
total 20
drwxr-xr-x 3 root   root 4096 Nov  8 09:00 .
drwxr-xr-x 7 root   root 4096 Nov  8 09:00 ..
-rw-r----- 1 syslog adm  1371 Nov  8 09:00 auth.log
drwxr-xr-x 2 root   root 4096 Nov  8 09:00 nginx
-rw-r----- 1 syslog adm   661 Nov  8 09:00 syslog
$ ls -l /etc/passwd /etc/shadow
-rw-r--r-- 1 root root 404 Nov  8 09:00 /etc/passwd
-rw-r----- 1 root shadow 308 Nov  8 09:00 /etc/shadow
```

قراءة السطر: `-rw-r--r-- 1 root root 535 Nov 8 09:00 /etc/passwd`

1. النوع والصلاحيات: `-` ملف عادي، و `d` مجلد، و `l` رابط (التفاصيل في درس الصلاحيات).
2. عدد الروابط، ثم **المالك** ثم **المجموعة**.
3. الحجم بالبايت، ووقت آخر تعديل، والاسم.

- `-a` يُظهر الملفات **المخفية** (التي تبدأ بنقطة مثل `.bashrc`).
- لاحظ أن `/etc/shadow` (فيه بصمات كلمات المرور) لا يقرؤه إلا root ومجموعة shadow.

## البحث عن الملفات: find

```terminal
$ find /etc -name "*.conf" 2> /dev/null
$ find /home -type d
/home
/home/sara
$ find /usr/bin -name "pass*"
/usr/bin/passwd
```

`find` يبحث بالاسم (`-name`) أو النوع (`-type f` ملف و `-type d` مجلد) أو المالك (`-user`) أو الصلاحيات (`-perm`)، وسنستخدمه في التدقيق الأمني.

## إنشاء الملفات وقراءتها

```terminal
$ echo "first line" > notes.txt
$ echo "second line" >> notes.txt
$ cat notes.txt
first line
second line
$ cat > todo.txt <<EOF
> backup database
> update packages
> review logs
> EOF
$ wc -l todo.txt
3 todo.txt
$ head -n 1 todo.txt
backup database
$ tail -n 2 todo.txt
update packages
review logs
```

- `cat` يعرض الملف كاملاً، و `head` و `tail` البداية والنهاية (`tail` مفيد جداً للسجلات).
- `cat > file <<EOF ... EOF` يكتب عدة أسطر في ملف (Here Document).
- `wc -l` يعدّ الأسطر.

## النسخ والنقل والحذف

```terminal
$ mkdir backup
$ cp notes.txt backup/
$ mv todo.txt tasks.txt
$ ls
backup  notes.txt  tasks.txt
$ rm notes.txt
$ rm backup
ERR: rm: cannot remove 'backup': Is a directory
$ rm -r backup
$ ls
tasks.txt
```

> ⚠️ لا سلة محذوفات في الطرفية: `rm` يحذف نهائياً. و `rm -rf` بصلاحيات المدير على مسار خاطئ قد يدمر النظام كله، فاقرأ الأمر مرتين قبل تنفيذه.

## الأنابيب |: قوة الطرفية

الأنبوب `|` يمرر **مخرجات** أمر إلى **مدخلات** الأمر التالي، فتبني من أدوات صغيرة أداة تحليل كاملة. مثلاً: من حاول الدخول بكلمة مرور خاطئة إلى هذا الخادم؟

```terminal
$ grep "Failed password" /var/log/auth.log | head -n 3
2026-11-08T09:12:00.000123+00:00 ubuntu sshd[2312]: Failed password for invalid user admin from 203.0.113.50 port 50120 ssh2
2026-11-08T09:12:03.000123+00:00 ubuntu sshd[2313]: Failed password for root from 203.0.113.50 port 50121 ssh2
2026-11-08T09:12:06.000123+00:00 ubuntu sshd[2314]: Failed password for invalid user test from 203.0.113.50 port 50122 ssh2
$ grep -c "Failed password" /var/log/auth.log
7
$ grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn
      5 203.0.113.50
      2 198.51.100.23
```

| الأداة | وظيفتها |
|---|---|
| `grep نص` | الأسطر التي فيها النص (`-c` العدد، و `-i` بلا حالة أحرف، و `-v` العكس) |
| `awk '{print $1}'` | حقل معين من كل سطر (`$NF` آخر حقل) |
| `cut -d: -f1` | حقل بفاصل محدد |
| `sort` | ترتيب (`-n` رقمي، و `-r` عكسي) |
| `uniq -c` | عدّ الأسطر المتكررة المتتالية (لذلك نرتب قبله) |

هذا السطر الأخير مهارة حقيقية يستخدمها محللو الأمن يومياً: عنوان واحد حاول 5 مرات خلال ثوانٍ، أي هجوم تخمين كلمات مرور (Brute Force).

```terminal
$ cut -d: -f1 /etc/passwd | head -n 3
$ grep "/bin/bash" /etc/passwd | cut -d: -f1
root
sara
```

السطر الأخير يعرض المستخدمين الذين يملكون طرفية دخول: مراجعة أمنية بسيطة.
