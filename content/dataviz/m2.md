## Seaborn: رسوم إحصائية من الجداول مباشرة

**Seaborn** مبنية على Matplotlib، لكنها تفهم جداول Pandas: تعطيها الجدول وأسماء الأعمدة، فتجمّع وتحسب الإحصاءات وتلوّن تلقائياً. والعرف أن تُستورد باسم `sns`:

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]

sns.barplot(data=orders, x="city", y="total", estimator="sum", errorbar=None, color="#2c7be5")
plt.title("Revenue by city")
plt.show()
```

## الأعمدة مع فترات الثقة

افتراضياً `barplot` يرسم **المتوسط** مع **فترة ثقة 95%** (الخط الأسود فوق كل عمود):

## التوزيعات

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

orders = pd.read_csv("orders.csv")
products = pd.read_csv("products.csv")
df = orders.merge(products[["product", "category"]], on="product")
df["total"] = df["qty"] * df["unit_price"]

fig, axes = plt.subplots(1, 2, figsize=(10, 3.5))
sns.histplot(data=df, x="qty", discrete=True, ax=axes[0])
axes[0].set_title("Quantity per order")
sns.boxplot(data=df, x="category", y="total", hue="category", ax=axes[1])
axes[1].set_yscale("log")
axes[1].set_title("Order value by category (log scale)")
fig.tight_layout()
plt.show()
```

```output
[[img:img/lessons/dataviz/4747d5e40e-1.png]]
```

**المخطط الصندوقي (Box plot)** يلخص التوزيع: الخط في المنتصف الوسيط، والصندوق من Q1 إلى Q3، والشعيرات تمتد حتى 1.5 × IQR، والنقاط خارجها قيم شاذة. والمقياس اللوغاريتمي (`set_yscale("log")`) مناسب عندما تختلف القيم بأضعاف كبيرة.

| الدالة | الرسم |
|---|---|
| `histplot` | مدرج تكراري (مع `kde=True` لمنحنى ناعم) |
| `kdeplot` | منحنى كثافة ناعم |
| `boxplot` | صندوقي |
| `violinplot` | كمان: صندوقي + شكل التوزيع |
| `countplot` | عدد الصفوف لكل فئة |

## العلاقات و hue

`hue` يضيف بُعداً ثالثاً باللون:

```python
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
n = 120
students = pd.DataFrame({
    "hours": rng.uniform(0, 10, n).round(1),
    "track": rng.choice(["Data", "Web"], n),
})
students["score"] = (45 + 4.5 * students["hours"] + np.where(students["track"] == "Data", 5, 0)
                     + rng.normal(0, 6, n)).clip(0, 100).round()

sns.scatterplot(data=students, x="hours", y="score", hue="track", alpha=0.8)
plt.title("Study hours vs exam score")
plt.show()

sns.lmplot(data=students, x="hours", y="score", hue="track", height=3.5, aspect=1.6)
plt.show()
```

## الخريطة الحرارية: Heatmap

حين تكون البيانات **جدولاً** (صفوف × أعمدة)، الخريطة الحرارية تحوّل كل خلية إلى لون، فتظهر الأنماط فوراً. أشهر استخداماتها:

### 1. مصفوفة الارتباط

```python
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

rng = np.random.default_rng(2)
n = 200
df = pd.DataFrame({"ads": rng.uniform(5, 40, n)})
df["visits"] = df["ads"] * 80 + rng.normal(0, 300, n)
df["sales"] = df["visits"] * 0.04 + rng.normal(0, 15, n)
df["returns"] = df["sales"] * 0.05 + rng.normal(0, 3, n)
df["temperature"] = rng.uniform(20, 45, n)

corr = df.corr()
sns.heatmap(corr, annot=True, fmt=".2f", cmap="RdBu_r", vmin=-1, vmax=1, square=True)
plt.title("Correlation matrix")
plt.show()
```

```output
[[img:img/lessons/dataviz/cc31605b74-1.png]]
```

- `annot=True` يكتب القيمة في كل خلية، و `fmt=".2f"` صيغتها.
- `cmap="RdBu_r"`: **ألوان متباعدة** (أحمر موجب، أزرق سالب)، مع `vmin=-1, vmax=1` ليكون الصفر أبيض.
- لاحظ أن الحرارة لا ترتبط بأي شيء، بينما سلسلة الإعلانات ← الزيارات ← المبيعات واضحة.

### إخفاء النصف المكرر

المصفوفة متماثلة، فنصفها تكرار:

```python
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

rng = np.random.default_rng(2)
df = pd.DataFrame(rng.normal(size=(100, 4)), columns=["a", "b", "c", "d"])
df["b"] += df["a"]
corr = df.corr()
mask = np.triu(np.ones_like(corr, dtype=bool))
sns.heatmap(corr, mask=mask, annot=True, fmt=".2f", cmap="RdBu_r", vmin=-1, vmax=1)
plt.show()
```

### 2. جدول محوري: النشاط حسب اليوم والشهر

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["month"] = orders["date"].dt.strftime("%m-%b")
orders["weekday"] = orders["date"].dt.day_name().str[:3]
days = ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"]

pt = orders.pivot_table(index="weekday", columns="month", values="qty", aggfunc="sum", fill_value=0).reindex(days)
fig, ax = plt.subplots(figsize=(7, 3.6))
sns.heatmap(pt, annot=True, fmt="d", cmap="Blues", linewidths=0.5, ax=ax)
ax.set_title("Units sold by weekday and month")
ax.set_xlabel("")
ax.set_ylabel("")
plt.show()
```

## اختيار لوحة الألوان

| النوع | متى | أمثلة |
|---|---|---|
| **متتابعة** (Sequential) | قيم من قليل لكثير | `"Blues"` و `"viridis"` و `"YlOrRd"` |
| **متباعدة** (Diverging) | قيم حول مركز (صفر أو متوسط) | `"RdBu_r"` و `"coolwarm"` |
| **فئوية** (Qualitative) | فئات بلا ترتيب | `"Set2"` و `"tab10"` |

> ⚠️ تجنب لوحة "قوس قزح" (`"jet"`): تخلق حدوداً وهمية بين الألوان، ولا يقرؤها المصابون بعمى الألوان. `"viridis"` بديل آمن ومدروس.

## ملخص الدرس

- `sns.heatmap(table, annot=True, fmt=..., cmap=...)` لأي جدول رقمي.
- مصفوفة الارتباط بلوحة متباعدة و `vmin=-1, vmax=1`، و `mask` لإخفاء النصف المكرر.
- `pivot_table` ثم `heatmap` لاكتشاف الأنماط بين بُعدين (يوم × شهر).
- متتابعة للمقادير، ومتباعدة حول مركز، وفئوية للفئات، وتجنب `jet`.
