## الطريقتان: pyplot و الكائنات

`plt.plot(...)` طريقة سريعة تعمل على "الرسم الحالي" ضمنياً. أما في الكود الاحترافي فالأفضل **الواجهة الكائنية (Object-Oriented)**: تنشئ **الشكل (Figure)** و **المحاور (Axes)** صراحةً:

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 3.5))
ax.plot(["Jan", "Feb", "Mar", "Apr"], [28, 30, 38, 21], marker="o")
ax.set_title("Monthly sales")
ax.set_xlabel("Month")
ax.set_ylabel("Sales (k SAR)")
plt.show()
```

```output
[[img:img/lessons/dataviz/16f511c1cf-1.png]]
```

- **Figure**: اللوحة كاملة. **Axes**: منطقة رسم واحدة داخلها (بمحوريها).
- `plt.title` تصبح `ax.set_title`، و `plt.xlabel` تصبح `ax.set_xlabel`.
- ميزتها تظهر مع الرسوم المتعددة: تعرف دائماً على أي محور ترسم.

## التخصيص: من رسم افتراضي إلى رسم احترافي

الرسم الافتراضي يعمل، لكن الرسم الذي يقنع مديرك يحتاج عناية: ألوان مقصودة، عناوين واضحة، وتقليل التشويش.

```python
import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
a = [24, 29, 37, 19, 29, 22]
b = [18, 21, 25, 27, 30, 34]

fig, ax = plt.subplots(figsize=(7, 3.5))
ax.plot(months, a, color="#2c7be5", linewidth=2.5, marker="o", label="Riyadh")
ax.plot(months, b, color="#e5732c", linewidth=2.5, linestyle="--", marker="s", label="Jeddah")
ax.set_title("Monthly revenue by branch", fontsize=13, loc="left")
ax.set_ylabel("k SAR")
ax.set_ylim(0, 40)
ax.legend(frameon=False)
ax.grid(axis="y", alpha=0.3)
ax.spines[["top", "right"]].set_visible(False)
plt.show()
```

```output
[[img:img/lessons/dataviz/29f48b1648-1.png]]
```

| الخاصية | أمثلة |
|---|---|
| `color` | `"red"` أو `"#2c7be5"` أو `"C0"` (ألوان الدورة الافتراضية) |
| `linewidth` / `lw` | سمك الخط |
| `linestyle` / `ls` | `"-"` و `"--"` و `":"` و `"-."` |
| `marker` | `"o"` و `"s"` و `"^"` و `"x"` |
| `alpha` | الشفافية من 0 إلى 1 |
| `label` + `ax.legend()` | مفتاح الرسم |

```python
ax.set_ylim(0, 45)
ax.set_title("Sales peaked in March", loc="left")
ax.spines[["top", "right"]].set_visible(False)
plt.show()
```

## الرسوم المتعددة: subplots

لوحة تقرير غالباً فيها عدة رسوم متجاورة. `plt.subplots(صفوف، أعمدة)` ينشئ شبكة محاور:

```python
import pandas as pd
import matplotlib.pyplot as plt

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["total"] = orders["qty"] * orders["unit_price"]

fig, axes = plt.subplots(2, 2, figsize=(9, 6))
monthly = orders.set_index("date")["total"].resample("ME").sum()
axes[0, 0].plot(monthly.index.strftime("%b"), monthly.values, marker="o")
axes[0, 0].set_title("Monthly revenue")

orders["city"].value_counts().plot(kind="bar", ax=axes[0, 1], color="#e5732c", rot=0)
axes[0, 1].set_title("Orders by city")

axes[1, 0].hist(orders["total"], bins=20, color="#2ca05c")
axes[1, 0].set_title("Order value distribution")

orders["status"].value_counts().plot(kind="pie", ax=axes[1, 1], autopct="%1.0f%%")
axes[1, 1].set_title("Order status")
axes[1, 1].set_ylabel("")

fig.suptitle("Store dashboard: H1 2024", fontsize=14)
fig.tight_layout()
plt.show()
```

## مشاركة المحاور

لمقارنة عادلة بين رسوم متجاورة، وحّد المقياس:

```python
import pandas as pd
import matplotlib.pyplot as plt

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
top = ["Riyadh", "Jeddah", "Dammam"]

fig, axes = plt.subplots(1, 3, figsize=(10, 3), sharey=True)
for ax, city in zip(axes, top):
    data = orders[orders["city"] == city].groupby("product")["qty"].sum().reindex(
        ["Mouse", "Keyboard", "Lamp", "Chair"], fill_value=0)
    ax.bar(data.index, data.values)
    ax.set_title(city)
    ax.tick_params(axis="x", rotation=45)
fig.tight_layout()
plt.show()
```

## محوران رأسيان: twinx

لعرض مقياسين مختلفين (الإيراد بالريال وعدد الطلبات) على نفس المحور الزمني:

```python
import pandas as pd
import matplotlib.pyplot as plt

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["total"] = orders["qty"] * orders["unit_price"]
m = orders.set_index("date").resample("ME").agg({"total": "sum", "order_id": "count"})
labels = m.index.strftime("%b")

fig, ax1 = plt.subplots(figsize=(7, 3.5))
ax1.bar(labels, m["total"] / 1000, color="#c9d6ea", label="Revenue (k)")
ax2 = ax1.twinx()
ax2.plot(labels, m["order_id"], color="#e5732c", marker="o", label="Orders")
ax1.set_ylabel("Revenue (k SAR)")
ax2.set_ylabel("Orders")
ax2.set_ylim(0, 30)                 # ابدأ من الصفر حتى لا يبدو تغير بسيط كقفزة كبيرة
fig.legend(loc="upper left", bbox_to_anchor=(0.12, 0.88), frameon=False)
plt.show()
```

```output
[[img:img/lessons/dataviz/08ca688808-1.png]]
```

> ⚠️ استخدم المحورين بحذر: القارئ قد يقارن ارتفاع الخط بالأعمدة رغم اختلاف المقياسين. أحياناً رسمان منفصلان أوضح.

## ملخص الدرس

- `fig, axes = plt.subplots(r, c)` شبكة رسوم، و `axes[i, j]` للوصول.
- `ax=` لرسوم Pandas، و `suptitle` و `tight_layout` للتنسيق.
- `sharex` / `sharey` لتوحيد المقياس عند المقارنة.
- `ax.twinx()` لمحور رأسي ثانٍ بمقياس مختلف.
