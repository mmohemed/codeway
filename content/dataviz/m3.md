## Plotly: رسوم تفاعلية

رسوم Matplotlib و Seaborn **صور ثابتة**. أما **Plotly** فتنتج رسوماً **تفاعلية** في المتصفح: مرّر الفأرة لترى القيمة، كبّر جزءاً، أخفِ سلسلة بالنقر على مفتاحها. مثالية للوحات الويب والتقارير التي يستكشفها القارئ بنفسه.

أسهل طريقة: **Plotly Express** (`px`)، بنفس فكرة Seaborn: جدول + أسماء أعمدة.

```python
import pandas as pd
import plotly.express as px

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
by_city = orders.groupby("city", as_index=False)["total"].sum().sort_values("total")

fig = px.bar(by_city, x="total", y="city", orientation="h", title="Revenue by city",
             labels={"total": "Revenue (SAR)", "city": ""})
fig.show()
```

```output
[[img:img/lessons/dataviz/a266268590-1.png]]
```

الصورة أعلاه لقطة ثابتة. اضغط **«شغّل المثال»** لترى الرسم التفاعلي الحقيقي ومرّر الفأرة على الأعمدة. (عرض الرسم التفاعلي يحمّل مكتبة plotly.js من الإنترنت.)

## الأنواع الأساسية

```python
import pandas as pd
import plotly.express as px

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["total"] = orders["qty"] * orders["unit_price"]
weekly = orders.set_index("date").groupby("city")["total"].resample("W").sum().reset_index()
top = weekly[weekly["city"].isin(["Riyadh", "Jeddah", "Dammam"])]

fig = px.line(top, x="date", y="total", color="city", markers=True, title="Weekly revenue")
fig.update_layout(hovermode="x unified")
fig.show()
```

```output
[[img:img/lessons/dataviz/dc63065478-1.png]]
```

`color="city"` يرسم خطاً لكل مدينة، و `hovermode="x unified"` يعرض قيم كل المدن معاً عند تمرير الفأرة على أسبوع.

| الدالة | الرسم |
|---|---|
| `px.bar` | أعمدة |
| `px.line` | خطي |
| `px.scatter` | انتشار (مع `size` و `color` لأبعاد إضافية) |
| `px.histogram` | مدرج تكراري |
| `px.box` / `px.violin` | توزيعات |
| `px.pie` | دائري |
| `px.treemap` / `px.sunburst` | تسلسل هرمي (فئة ← منتج) |
| `px.imshow` | خريطة حرارية |

## الانتشار متعدد الأبعاد

```python
import pandas as pd
import plotly.express as px

orders = pd.read_csv("orders.csv")
products = pd.read_csv("products.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
summary = orders.groupby("product", as_index=False).agg(orders=("order_id", "count"), revenue=("total", "sum"))
summary = summary.merge(products[["product", "category", "price"]], on="product")

fig = px.scatter(summary, x="orders", y="revenue", size="price", color="category",
                 hover_name="product", text="product", title="Products: popularity vs revenue")
fig.update_traces(textposition="top center")
fig.show()
```

```output
[[img:img/lessons/dataviz/76fb8772ba-1.png]]
```

خمسة أبعاد في رسم واحد: عدد الطلبات (x)، والإيراد (y)، والسعر (حجم الدائرة)، والفئة (اللون)، والاسم (عند التمرير). اللابتوب طلباته قليلة لكنه الأعلى إيراداً.

## التسلسل الهرمي: treemap

## ملخص الدرس

- `import plotly.express as px`، ثم `px.نوع(df, x=, y=, color=, ...)` و `fig.show()`.
- الرسم تفاعلي: تمرير وتكبير وإخفاء سلاسل، ومناسب للويب.
- `color` و `size` و `hover_name` و `text` لإضافة أبعاد ومعلومات.
- `labels={...}` لتسميات المحاور، و `update_layout` و `update_traces` للتخصيص.

## تخصيص Plotly: graph_objects و make_subplots

Plotly Express سريعة، لكن لكل رسم Express هيكل تحته من **graph_objects** (`go`): الشكل `Figure` فيه **مسارات** (traces) و **تخطيط** (layout). يمكنك بناء الرسم منها مباشرة لتحكم كامل:

```python
import plotly.graph_objects as go

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
revenue = [28.1, 30.0, 38.4, 21.0, 33.7, 22.3]
target = [30, 30, 32, 32, 34, 34]

fig = go.Figure()
fig.add_trace(go.Bar(x=months, y=revenue, name="Revenue", marker_color="#2c7be5"))
fig.add_trace(go.Scatter(x=months, y=target, name="Target", mode="lines+markers", line=dict(color="#e5732c", dash="dash")))
fig.update_layout(title="Revenue vs target (k SAR)", template="plotly_white", legend=dict(orientation="h", y=1.12))
fig.show()
print([t.type for t in fig.data])
```


## لوحة من عدة رسوم: make_subplots

```python
import pandas as pd
import plotly.graph_objects as go
from plotly.subplots import make_subplots

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
city = orders.groupby("city")["total"].sum().sort_values(ascending=False)
status = orders["status"].value_counts()

fig = make_subplots(rows=1, cols=2, specs=[[{"type": "bar"}, {"type": "domain"}]],
                    subplot_titles=("Revenue by city", "Order status"))
fig.add_trace(go.Bar(x=city.index, y=city.values, showlegend=False), row=1, col=1)
fig.add_trace(go.Pie(labels=status.index, values=status.values, hole=0.5), row=1, col=2)
fig.update_layout(title="Store dashboard", template="plotly_white")
fig.show()
```

```output
[[img:img/lessons/dataviz/3228f75219-1.png]]
```

`specs` يحدد نوع كل خانة: `"domain"` للرسوم الدائرية، و `"xy"` (الافتراضي) للمحاور العادية.

## عناصر تحكم تفاعلية

أزرار داخل الرسم نفسه، دون أي خادم:

```python
import pandas as pd
import plotly.graph_objects as go

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
by_product = orders.groupby("product").agg(units=("qty", "sum"), revenue=("total", "sum"))

fig = go.Figure(go.Bar(x=by_product.index, y=by_product["units"]))
fig.update_layout(
    title="Products",
    updatemenus=[dict(type="buttons", direction="right", x=0, y=1.15, buttons=[
        dict(label="Units", method="update", args=[{"y": [by_product["units"]]}]),
        dict(label="Revenue", method="update", args=[{"y": [by_product["revenue"]]}]),
    ])],
)
fig.show()
```

## لوحات Dash

عندما تريد **تطبيق ويب** كاملاً: قوائم منسدلة وفلاتر تعيد حساب البيانات من الخادم، فالأداة هي **Dash** من نفس شركة Plotly:

```python-norun
# app.py: يعمل على جهازك بعد pip install dash  ثم  python app.py
from dash import Dash, dcc, html, Input, Output
import pandas as pd
import plotly.express as px

orders = pd.read_csv("orders.csv")
app = Dash(__name__)
app.layout = html.Div([
    html.H2("Store dashboard"),
    dcc.Dropdown(sorted(orders["city"].unique()), "Riyadh", id="city"),
    dcc.Graph(id="chart"),
])

@app.callback(Output("chart", "figure"), Input("city", "value"))
def update(city):
    data = orders[orders["city"] == city]["product"].value_counts().reset_index()
    return px.bar(data, x="product", y="count", title=f"Orders in {city}")

if __name__ == "__main__":
    app.run(debug=True)
```

- `app.layout` يصف الصفحة بمكونات Python بدلاً من HTML.
- `@app.callback`: عند تغيير القائمة (`Input`) تُستدعى الدالة ويُحدَّث الرسم (`Output`).
- افتح `http://127.0.0.1:8050`.

(تطبيقات Dash تحتاج خادماً يعمل بـ Python، لذلك لا تعمل في متصفح هذه المنصة. شغّلها على جهازك. البدائل الشائعة: **Streamlit** الأبسط، و **Power BI** الذي ستتعلمه في دورته.)

## ملخص الدرس

- `go.Figure` + `add_trace(go.Bar/Scatter/Pie...)` + `update_layout` للتحكم الكامل.
- `make_subplots` للوحات متعددة، و `specs` لأنواع الخانات.
- `updatemenus` لأزرار تفاعلية داخل الرسم دون خادم.
- `write_html` لمشاركة رسم تفاعلي، و Dash لتطبيقات لوحات كاملة بخادم.
