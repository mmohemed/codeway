## الفيزياء: Arcade Physics

حتى الآن حرّكنا العناصر بتغيير `x` و `y` يدوياً. **محرك الفيزياء** يفعل ذلك عنا: سرعة، وجاذبية، وارتداد، واصطدام. و **Arcade Physics** المدمج في Phaser سريع وبسيط ومناسب لأغلب ألعاب الـ 2D.

نفعّله في الإعداد، ثم نضيف العناصر عبر `this.physics.add` بدلاً من `this.add`:

```phaser
class Main extends Phaser.Scene {
  preload() { this.load.image("bomb", "assets/bomb.png"); }
  create() {
    this.ball = this.physics.add.image(80, 40, "bomb").setScale(2);
    this.ball.setVelocity(150, 0);
    this.ball.setBounce(0.8);
    this.ball.setCollideWorldBounds(true);
  }
}
new Phaser.Game({
  type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53",
  physics: { default: "arcade", arcade: { gravity: { y: 400 } } },
  scene: Main
});
// test
const b = scene().ball;
step(30);
print(round(b.x), round(b.y), round(b.body.velocity.y));
let bounces = 0, vy = b.body.velocity.y;
for (let i = 0; i < 150; i++) { step(); if (vy > 0 && b.body.velocity.y < 0) bounces++; vy = b.body.velocity.y; }
print("bounces in 2.5s:", bounces, "| x:", round(b.x));
```

```output
155 92 200
bounces in 2.5s: 2 | x: 416
```

- `gravity: { y: 400 }`: تسارع للأسفل 400 بكسل/ثانية².
- `setVelocity(vx, vy)` السرعة بالبكسل/ثانية، و `setBounce(0.8)` يرتد بـ 80% من سرعته.
- `setCollideWorldBounds(true)` يصطدم بحواف الشاشة.

لاحظ: لم نكتب `update` أبداً، المحرك يحرك الكرة ويطبق الجاذبية والارتداد كل إطار.

## المنصات والتصادم

لعبة المنصات الكلاسيكية: لاعب يقف على منصات لا تتحرك:

```phaser
class Main extends Phaser.Scene {
  preload() {
    this.load.image("platform", "assets/platform.png");
    this.load.spritesheet("player", "assets/player.png", { frameWidth: 32, frameHeight: 48 });
  }
  create() {
    this.platforms = this.physics.add.staticGroup();
    this.platforms.create(240, 304, "platform");          // الأرض
    this.platforms.create(380, 180, "platform").setScale(0.4).refreshBody();

    this.player = this.physics.add.sprite(60, 100, "player", 4);
    this.player.setCollideWorldBounds(true);
    this.physics.add.collider(this.player, this.platforms);
    this.cursors = this.input.keyboard.createCursorKeys();
  }
  update() {
    const p = this.player;
    if (this.cursors.left.isDown) p.setVelocityX(-160);
    else if (this.cursors.right.isDown) p.setVelocityX(160);
    else p.setVelocityX(0);
    if (this.cursors.up.isDown && p.body.touching.down) p.setVelocityY(-330);
  }
}
new Phaser.Game({
  type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53",
  physics: { default: "arcade", arcade: { gravity: { y: 600 } } },
  scene: Main
});
// test
const p = scene().player;
step(60);
print("landed:", p.body.touching.down, round(p.y));
press("up", 2);
step(10);
print("jumping:", round(p.y), round(p.body.velocity.y));
step(60);
print("back on ground:", p.body.touching.down, round(p.y));
```

```output
landed: true 264
jumping: 211 -210
back on ground: true 264
```

- `staticGroup()`: أجسام **ثابتة** لا تتأثر بالجاذبية ولا تُدفع (أرض، جدران، منصات).
- بعد `setScale` لجسم ثابت نستدعي `refreshBody()` ليتحدث حجم جسمه الفيزيائي.
- `collider(a, b)`: يمنع التداخل ويجعلهما يتصادمان.
- القفز فقط إذا كان اللاعب **على الأرض**: `body.touching.down`، وإلا لقفز في الهواء بلا نهاية.

## التداخل: جمع العناصر

`collider` يمنع العبور، أما `overlap` فيكتشف **التلامس فقط** ويستدعي دالة، مثالي لجمع العملات:

```phaser
class Main extends Phaser.Scene {
  preload() {
    this.load.image("ship", "assets/ship.png");
    this.load.image("coin", "assets/coin.png");
  }
  create() {
    this.score = 0;
    this.ship = this.physics.add.image(40, 160, "ship");
    this.coins = this.physics.add.group({ key: "coin", repeat: 4, setXY: { x: 120, y: 160, stepX: 70 }, allowGravity: false });
    this.physics.add.overlap(this.ship, this.coins, (ship, coin) => {
      coin.disableBody(true, true);
      this.score += 10;
    });
    this.ship.setVelocityX(150);
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", physics: { default: "arcade" }, scene: Main });
// test
step(60);
print(scene().score, scene().coins.countActive(true));
step(60);
print(scene().score, scene().coins.countActive(true));
```

```output
20 3
40 1
```

- `overlap(a, b, callback)`: الدالة تستلم العنصرين المتداخلين.
- `disableBody(true, true)`: يوقف الجسم ويخفيه (أسرع من حذفه، ويمكن إعادة تفعيله بـ `enableBody`).
- `countActive(true)`: عدد العناصر الفعالة الباقية في المجموعة.

## ملخص الدرس

- فعّل `physics: { default: "arcade" }`، وأضف بـ `this.physics.add.sprite/image/group`.
- `setVelocity` و `setBounce` و `setCollideWorldBounds` و `gravity` في الإعداد.
- `staticGroup` للمنصات، و `collider` للتصادم، و `body.touching.down` لاكتشاف الأرض.
- `overlap` + `disableBody` لجمع العناصر.

class Main extends Phaser.Scene {
  preload() {
    this.load.image("platform", "assets/platform.png");
    this.load.spritesheet("player", "assets/player.png", { frameWidth: 32, frameHeight: 48 });
  }
  create() {
    const ground = this.physics.add.staticGroup();
    ground.create(240, 304, "platform");
    this.player = this.physics.add.sprite(100, 200, "player", 4);
    this.physics.add.collider(this.player, ground);
    this.space = this.input.keyboard.addKey("SPACE");
    this.jumps = 0;
  }
  update() {
    if (Phaser.Input.Keyboard.JustDown(this.space) && this.player.body.touching.down) {
      this.player.setVelocityY(-300);
      this.jumps++;
    }
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, physics: { default: "arcade", arcade: { gravity: { y: 500 } } }, scene: Main });
~~~

## النقاط والحياة ونهاية اللعبة

لعبة كاملة تحتاج **حالة**: النقاط، والأرواح، والفوز والخسارة. نبني لعبة "التقط النجوم وتجنب القنابل":

```phaser
class Game extends Phaser.Scene {
  constructor() { super("game"); }
  preload() {
    this.load.image("ship", "assets/ship.png");
    this.load.image("star", "assets/star.png");
    this.load.image("bomb", "assets/bomb.png");
  }
  create() {
    this.score = 0;
    this.lives = 3;
    this.ship = this.physics.add.image(240, 290, "ship").setCollideWorldBounds(true);
    this.stars = this.physics.add.group();
    this.bombs = this.physics.add.group();
    this.hud = this.add.text(10, 10, "", { fontSize: "16px" });

    // كل 600 مللي ثانية يسقط نجم، وكل 1500 قنبلة
    this.time.addEvent({ delay: 600, loop: true, callback: () => this.drop(this.stars, "star", 120) });
    this.time.addEvent({ delay: 1500, loop: true, callback: () => this.drop(this.bombs, "bomb", 160) });

    this.physics.add.overlap(this.ship, this.stars, (ship, star) => { star.destroy(); this.score += 10; });
    this.physics.add.overlap(this.ship, this.bombs, (ship, bomb) => {
      bomb.destroy();
      this.lives -= 1;
      this.cameras.main.shake(150, 0.01);
      if (this.lives <= 0) this.scene.start("over", { score: this.score });
    });
    this.cursors = this.input.keyboard.createCursorKeys();
    this.nextX = 60;
  }
  drop(group, key, speed) {
    // مواقع ثابتة بدلاً من العشوائية لتكون الدروس قابلة للتكرار (في لعبتك استخدم Phaser.Math.Between)
    this.nextX = (this.nextX + 170) % 440 + 20;
    group.create(this.nextX, -10, key).setVelocityY(speed);
  }
  update() {
    this.ship.setVelocityX(this.cursors.left.isDown ? -260 : this.cursors.right.isDown ? 260 : 0);
    this.hud.setText(`Score: ${this.score}   Lives: ${this.lives}`);
  }
}
class Over extends Phaser.Scene {
  constructor() { super("over"); }
  create(data) {
    this.finalScore = data.score;
    this.add.text(240, 140, "GAME OVER", { fontSize: "36px", color: "#ff5c5c" }).setOrigin(0.5);
    this.add.text(240, 190, `Score: ${data.score}  (SPACE to retry)`, { fontSize: "18px" }).setOrigin(0.5);
    this.input.keyboard.once("keydown-SPACE", () => this.scene.start("game"));
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", physics: { default: "arcade" }, scene: [Game, Over] });
// test
step(300);
print(scene().scene.key, scene().hud.text);
step(1200);
print(scene().scene.key, scene().finalScore);
```

```output
game Score: 10   Lives: 3
over 20
```

(في المعاينة: حرّك السفينة بالأسهم لالتقاط النجوم وتجنب القنابل.)

- `this.time.addEvent({ delay, loop, callback })`: مؤقت داخل اللعبة (يتوقف مع الإيقاف المؤقت بعكس `setInterval`).
- `this.scene.start("over", { score })`: الانتقال مع **تمرير بيانات**، يستلمها `create(data)`.
- `this.cameras.main.shake(...)`: اهتزاز الشاشة، وهو تأثير بسيط يجعل الضربة "محسوسة".

## المستويات

طريقة نظيفة للمستويات: **بيانات** لكل مستوى، ومشهد واحد يقرؤها:

```phaser
const LEVELS = [
  { name: "Level 1", coins: 3, speed: 100 },
  { name: "Level 2", coins: 5, speed: 160 },
  { name: "Level 3", coins: 8, speed: 220 }
];
class Play extends Phaser.Scene {
  constructor() { super("play"); }
  init(data) { this.level = data.level || 0; }
  preload() { this.load.image("coin", "assets/coin.png"); }
  create() {
    const cfg = LEVELS[this.level];
    this.coins = this.physics.add.group({ key: "coin", repeat: cfg.coins - 1, setXY: { x: 40, y: 160, stepX: 50 } });
    this.coins.getChildren().forEach(c => c.setVelocityY(cfg.speed));
    this.title = cfg.name;
    this.add.text(10, 10, cfg.name, { fontSize: "18px" });
  }
  nextLevel() {
    if (this.level + 1 < LEVELS.length) this.scene.restart({ level: this.level + 1 });
    else this.scene.start("win");
  }
}
class Win extends Phaser.Scene {
  constructor() { super("win"); }
  create() { this.add.text(240, 160, "YOU WIN!", { fontSize: "36px", color: "#ffd84d" }).setOrigin(0.5); }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", physics: { default: "arcade" }, scene: [Play, Win] });
// test
print(scene().title, scene().coins.getLength());
scene().nextLevel(); step(2);
print(scene().title, scene().coins.getLength(), scene().coins.getChildren()[0].body.velocity.y);
scene().nextLevel(); step(2);
scene().nextLevel(); step(2);
print(scene().scene.key);
```

```output
Level 1 3
Level 2 5 160
win
```

- `init(data)` تُستدعى قبل `preload` وتستلم بيانات البدء.
- `this.scene.restart({ level })` يعيد تشغيل المشهد نفسه ببيانات جديدة.
- فصل **البيانات** (مصفوفة المستويات) عن **المنطق** يجعل إضافة مستوى جديد مجرد سطر.
