## ما هو Phaser؟

**Phaser** أشهر إطار لألعاب المتصفح بلغة JavaScript: مجاني ومفتوح المصدر، ويعمل على الكمبيوتر والجوال دون تثبيت، ويرسم بـ WebGL بسرعة. وتُبنى به ألعاب الويب والإعلانات التفاعلية والألعاب التعليمية وألعاب منصات الرسائل.

```bash
npm create @phaserjs/game@latest
```

أو أبسط: سطر واحد في صفحة HTML:

```html
<script src="https://cdn.jsdelivr.net/npm/phaser@4.2.1/dist/phaser.min.js"></script>
```

كل كتلة **Phaser** في هذه الدورة لعبة حقيقية تعمل بـ Phaser 4 تحت الكود مباشرة: **انقر عليها ثم استخدم لوحة المفاتيح**.

## اللعبة والمشهد (Scene)

لعبة Phaser تتكون من:

1. **الإعداد** (config): الحجم، والمحرك، والفيزياء، والمشاهد.
2. **المشاهد** (Scenes): كل شاشة في اللعبة مشهد: القائمة، المستوى الأول، شاشة الخسارة.

والمشهد صنف يرث `Phaser.Scene` وفيه ثلاث دوال تستدعيها Phaser تلقائياً:

| الدالة | متى | ماذا تضع فيها |
|---|---|---|
| `preload()` | مرة قبل البدء | تحميل الصور والأصوات |
| `create()` | مرة بعد التحميل | إنشاء العناصر وضبط اللعبة |
| `update(time, delta)` | **كل إطار** (60 مرة في الثانية) | الحركة والمنطق |

```phaser
class Main extends Phaser.Scene {
  create() {
    this.add.text(240, 140, "Hello Phaser!", { fontSize: "32px", color: "#ffffff" }).setOrigin(0.5);
    this.counter = this.add.text(240, 190, "Frames: 0", { fontSize: "18px", color: "#ffd84d" }).setOrigin(0.5);
    this.frames = 0;
  }
  update() {
    this.frames++;
    this.counter.setText("Frames: " + this.frames);
  }
}

new Phaser.Game({
  type: Phaser.AUTO,
  width: 480,
  height: 320,
  backgroundColor: "#1d2b53",
  scene: Main
});
// test
step(60);
print(scene().frames, "|", scene().counter.text);
```

```output
60 | Frames: 60
```

- `type: Phaser.AUTO`: يختار WebGL إن توفر، وإلا Canvas.
- `this.add.text(x, y, نص, نمط)`: كل شيء في المشهد يُضاف عبر `this.add`.
- الإحداثيات من الزاوية **العلوية اليسرى**: x يزيد يميناً و y يزيد **للأسفل**.
- `setOrigin(0.5)`: نقطة الارتكاز في منتصف العنصر بدلاً من زاويته.

بعد 60 إطاراً (ثانية واحدة) استُدعيت `update` ستين مرة.

## الأشكال والحركة بالوقت

```phaser
class Main extends Phaser.Scene {
  create() {
    this.ball = this.add.circle(40, 160, 16, 0xffd84d);
    this.speed = 120;   // بكسل في الثانية
  }
  update(time, delta) {
    this.ball.x += this.speed * (delta / 1000);
    if (this.ball.x > 440 || this.ball.x < 40) this.speed *= -1;
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: Main });
// test
step(60);
print(Math.round(scene().ball.x));
step(240);
print(Math.round(scene().ball.x), scene().speed);
```

```output
160
244 -120
```

> 💡 **اضرب الحركة دائماً في `delta`** (الزمن منذ الإطار السابق بالمللي ثانية). جهاز يعرض 60 إطاراً وآخر يعرض 144: بدون delta تتحرك الكرة على الثاني أسرع بمرتين ونصف! مع delta السرعة ثابتة بالبكسل في الثانية.

## عدة مشاهد

```phaser
class Menu extends Phaser.Scene {
  constructor() { super("menu"); }
  create() {
    this.add.text(240, 160, "Press SPACE to start", { fontSize: "22px" }).setOrigin(0.5);
    this.input.keyboard.once("keydown-SPACE", () => this.scene.start("level"));
  }
}
class Level extends Phaser.Scene {
  constructor() { super("level"); }
  create() {
    this.add.text(240, 160, "Level 1", { fontSize: "32px", color: "#ffd84d" }).setOrigin(0.5);
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: [Menu, Level] });
// test
print(scene().scene.key);
press("space");
step(2);
print(scene().scene.key);
```

```output
menu
level
```

- `super("menu")` يعطي المشهد **مفتاحاً** (اسماً).
- `scene: [Menu, Level]`: أول مشهد في القائمة يبدأ تلقائياً.
- `this.scene.start("level")` ينتقل لمشهد آخر.

## ملخص الدرس

- اللعبة = إعداد `new Phaser.Game(config)` + مشاهد ترث `Phaser.Scene`.
- `preload` للتحميل، و `create` للإنشاء مرة، و `update` كل إطار.
- الإحداثيات من أعلى اليسار، و y يزيد للأسفل.
- الحركة = السرعة × `delta / 1000` لتكون ثابتة على كل الأجهزة.
- `this.scene.start("key")` للتنقل بين المشاهد.

  create() {

## الصور والـ Sprites

**الـ Sprite** صورة لها موقع وحجم ودوران وتتحرك في اللعبة: اللاعب، الأعداء، العملات. نحمّل الصور في `preload` ثم نضيفها في `create`:

```phaser
class Main extends Phaser.Scene {
  preload() {
    this.load.image("sky", "assets/sky.png");
    this.load.image("ship", "assets/ship.png");
    this.load.image("coin", "assets/coin.png");
  }
  create() {
    this.add.image(240, 160, "sky");
    this.ship = this.add.sprite(240, 260, "ship");
    this.coin = this.add.sprite(100, 80, "coin").setScale(2);
    this.coin.setTint(0xff8888);
  }
  update() {
    this.ship.angle += 1;            // الدوران بالدرجات
    this.coin.y = 80 + Math.sin(this.time.now / 300) * 10;
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, scene: Main });
// test
step(90);
print(scene().ship.angle, scene().coin.scale, scene().coin.width, scene().coin.displayWidth);
```

```output
90 2 16 32
```

- `this.load.image(مفتاح, مسار)` ثم `this.add.image` أو `this.add.sprite` بالمفتاح.
- **الطبقات بالترتيب**: ما يُضاف أولاً يُرسم خلف ما بعده (لذلك السماء أولاً).
- `setScale(2)` ضعف الحجم: `width` الحقيقي 16، و `displayWidth` المعروض 32.
- `angle` بالدرجات، و `setTint` يلوّن الصورة، و `setAlpha` للشفافية، و `setFlipX(true)` للانعكاس.

## ورقة الإطارات (Spritesheet) والرسوم المتحركة

الشخصية المتحركة صورة واحدة فيها كل إطارات الحركة متجاورة. ملف `assets/player.png` فيه 9 إطارات بحجم 32×48: المشي يساراً (0-3)، والوقوف (4)، والمشي يميناً (5-8):

```phaser
class Main extends Phaser.Scene {
  preload() {
    this.load.spritesheet("player", "assets/player.png", { frameWidth: 32, frameHeight: 48 });
  }
  create() {
    this.anims.create({
      key: "walk-right",
      frames: this.anims.generateFrameNumbers("player", { start: 5, end: 8 }),
      frameRate: 10,
      repeat: -1
    });
    this.anims.create({ key: "idle", frames: [{ key: "player", frame: 4 }] });

    this.walker = this.add.sprite(120, 160, "player").setScale(2).play("walk-right");
    this.stander = this.add.sprite(340, 160, "player").setScale(2).play("idle");
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: Main });
// test
const s = scene();
print(s.walker.anims.currentAnim.key, s.walker.frame.name);
step(30);
print(s.walker.frame.name, s.stander.frame.name);
```

```output
walk-right 5
6 4
```

- `anims.create`: مفتاح الحركة، وإطاراتها، وسرعتها (`frameRate` إطارات في الثانية)، و `repeat: -1` للتكرار بلا نهاية.
- `generateFrameNumbers("player", { start, end })` يولّد قائمة الإطارات.
- `sprite.play("walk-right")` يشغّل الحركة. والحركات تُعرّف مرة وتُستخدم لأي عدد من الـ Sprites.

## المجموعات (Groups)

لإنشاء عناصر كثيرة متشابهة (عملات، أعداء):

```phaser
class Main extends Phaser.Scene {
  preload() { this.load.image("coin", "assets/coin.png"); }
  create() {
    this.coins = this.add.group({ key: "coin", repeat: 9, setXY: { x: 40, y: 60, stepX: 44 } });
    this.coins.getChildren().forEach((coin, i) => coin.setY(60 + (i % 2) * 30));
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: Main });
// test
const c = scene().coins.getChildren();
print(c.length, c[0].x, c[1].x, c[9].x, c[1].y);
```

```output
10 40 84 436 90
```

`repeat: 9` يعني العنصر الأول + 9 تكرارات = 10، و `setXY` يحدد البداية والمسافة بينها.

## ملخص الدرس

- `this.load.image` و `this.load.spritesheet` في `preload`، ثم `this.add.sprite` في `create`.
- خصائص الـ Sprite: `x` و `y` و `angle` و `setScale` و `setTint` و `setAlpha` و `setFlipX`.
- `anims.create` + `generateFrameNumbers` + `play` للرسوم المتحركة.
- `this.add.group({ key, repeat, setXY })` لعناصر كثيرة متشابهة.

## الإدخال: لوحة المفاتيح

أسهل طريقة لأسهم الحركة:

```phaser
class Main extends Phaser.Scene {
  preload() { this.load.image("ship", "assets/ship.png"); }
  create() {
    this.ship = this.add.sprite(240, 160, "ship");
    this.cursors = this.input.keyboard.createCursorKeys();
    this.speed = 200;
  }
  update(time, delta) {
    const d = this.speed * delta / 1000;
    if (this.cursors.left.isDown) this.ship.x -= d;
    if (this.cursors.right.isDown) this.ship.x += d;
    if (this.cursors.up.isDown) this.ship.y -= d;
    if (this.cursors.down.isDown) this.ship.y += d;
    this.ship.x = Phaser.Math.Clamp(this.ship.x, 16, 464);
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: Main });
// test
const s = scene();
press("right", 30);
press("up", 15);
print(round(s.ship.x), round(s.ship.y));
press("right", 120);
print(round(s.ship.x));
```

```output
340 110
464
```

(انقر على اللعبة أولاً ليصلها الضغط على المفاتيح.)

- `createCursorKeys()` كائن فيه `left` و `right` و `up` و `down` و `space` و `shift`، ولكل مفتاح `isDown`.
- `Phaser.Math.Clamp(قيمة, أدنى, أعلى)` يمنع الخروج من الشاشة.

### مفاتيح أخرى وأحداث الضغط

`isDown` تبقى صحيحة طوال الضغط (للحركة المستمرة). أما للأفعال **مرة واحدة** لكل ضغطة (القفز، الإطلاق، الإيقاف المؤقت) فاستخدم الأحداث:

```phaser
class Main extends Phaser.Scene {
  create() {
    this.shots = 0;
    this.paused = false;
    this.keys = this.input.keyboard.addKeys("W,A,S,D");
    this.input.keyboard.on("keydown-SPACE", () => { this.shots++; });
    this.input.keyboard.on("keydown-P", () => { this.paused = !this.paused; });
    this.info = this.add.text(20, 20, "", { fontSize: "18px" });
  }
  update() {
    this.info.setText(`Shots: ${this.shots}  Paused: ${this.paused}  W: ${this.keys.W.isDown}`);
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: Main });
// test
press("space", 20);
press("space");
press("p");
keyDown("w"); step(1);
print(scene().info.text);
```

```output
Shots: 2  Paused: true  W: true
```

ضغطة طويلة على المسافة (20 إطاراً) حُسبت **مرة واحدة** فقط، لأن الحدث يُطلق عند لحظة الضغط.

## الفأرة واللمس

`this.input.on("pointerdown", ...)` يعمل مع الفأرة **واللمس** معاً، فاللعبة جاهزة للجوال:

```phaser
class Main extends Phaser.Scene {
  preload() { this.load.image("star", "assets/star.png"); }
  create() {
    this.score = 0;
    this.star = this.add.image(240, 160, "star").setScale(2).setInteractive();
    this.star.on("pointerdown", () => {
      this.score++;
      this.star.setPosition(Phaser.Math.Between(40, 440), Phaser.Math.Between(40, 280));
    });
    this.input.on("pointerdown", pointer => { this.lastClick = [Math.round(pointer.x), Math.round(pointer.y)]; });
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 480, height: 320, backgroundColor: "#1d2b53", scene: Main });
// test
click(240, 160);
print(scene().score, scene().lastClick);
click(10, 10);
print(scene().score, scene().lastClick);
```

```output
1 [240,160]
1 [10,10]
```

- `setInteractive()` يجعل العنصر قابلاً للنقر، ثم `on("pointerdown", ...)` عليه.
- `this.input.on("pointerdown", pointer => ...)` لأي نقرة في المشهد، و `pointer.x` و `pointer.y` موقعها.
- `Phaser.Math.Between(a, b)` رقم عشوائي صحيح.

## ملخص الدرس

- `createCursorKeys()` للأسهم، و `addKeys("W,A,S,D")` لمفاتيح أخرى، و `isDown` للحركة المستمرة.
- `keyboard.on("keydown-SPACE", ...)` لفعل مرة واحدة لكل ضغطة.
- `setInteractive()` + `on("pointerdown")` للنقر على العناصر، ويعمل مع اللمس.
