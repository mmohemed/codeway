## الدالة IF

`IF` تجعل الصيغة "تقرر": **إذا** تحقق الشرط أعطِ قيمة، **وإلا** قيمة أخرى.

`=IF(الشرط, القيمة إن صح, القيمة إن خطأ)`

```excel
| Rep | Sales | Target |
| Layla | 28000 | 25000 |
| Omar | 7400 | 8000 |
| Huda | 12000 | 12000 |
D1: Status
D2:D4: =IF(B2>=C2,"Achieved","Below")
E1: Bonus
E2:E4: =IF(B2>=C2,(B2-C2)*5%,0)
```

```output
D2 = Achieved
D3 = Below
D4 = Achieved
E2 = 150
E3 = 0
E4 = 0
```

المقارنات: `=` و `<>` (لا يساوي) و `>` و `<` و `>=` و `<=`. والنصوص بين علامتي تنصيص `"..."`.

## شروط متعددة: IFS والتداخل

```excel
| Student | Score |
| Layla | 92 |
| Omar | 78 |
| Huda | 85 |
| Fahad | 58 |
C1: Grade (IF)
C2:C5: =IF(B2>=90,"A",IF(B2>=80,"B",IF(B2>=70,"C","F")))
D1: Grade (IFS)
D2:D5: =IFS(B2>=90,"A",B2>=80,"B",B2>=70,"C",TRUE,"F")
```

```output
C2 = A
C3 = C
C4 = B
C5 = F
D2 = A
D3 = C
D4 = B
D5 = F
```

`IFS` أوضح من التداخل: أزواج (شرط، نتيجة) تُفحص بالترتيب، و `TRUE` الأخيرة تعني "وإلا".

## AND و OR و NOT

```excel
| Rep | Sales | Returns |
| Layla | 28000 | 2 |
| Omar | 9500 | 0 |
| Huda | 12000 | 6 |
D1: Star
D2:D4: =IF(AND(B2>10000,C2<5),"Yes","No")
E1: Review
E2:E4: =IF(OR(B2<10000,C2>5),"Check","OK")
```

```output
D2 = Yes
D3 = No
D4 = No
E2 = OK
E3 = Check
E4 = Check
```

- `AND(...)` صحيحة إذا تحققت **كل** الشروط.
- `OR(...)` صحيحة إذا تحقق **أي** شرط.

## IFERROR: إخفاء الأخطاء بأناقة

```excel
| Item | Revenue | Units |
| A | 5000 | 50 |
| B | 0 | 0 |
| C | 1200 | 8 |
D1: Price
D2:D4: =B2/C2
E1: Safe price
E2:E4: =IFERROR(B2/C2,"-")
```

```output
D2 = 100
D3 = #DIV/0!
D4 = 150
E2 = 100
E3 = -
E4 = 150
```

> ⚠️ لا تغلّف كل صيغة بـ `IFERROR` تلقائياً: قد تخفي خطأً حقيقياً في بياناتك. استخدمها حين تعرف سبب الخطأ المتوقع.

## الشرط على مجموعة: COUNTIF و SUMIF

أهم دوال التحليل في Excel: تعدّ أو تجمع **الصفوف التي تحقق شرطاً**.

```excel
| Region | Product | Units |
| Riyadh | Laptop | 2 |
| Jeddah | Mouse | 12 |
| Riyadh | Mouse | 15 |
| Dammam | Laptop | 2 |
| Riyadh | Chair | 4 |
E1: Riyadh rows
F1: =COUNTIF(A2:A6,"Riyadh")
E2: Riyadh units
F2: =SUMIF(A2:A6,"Riyadh",C2:C6)
E3: Riyadh mice
F3: =SUMIFS(C2:C6,A2:A6,"Riyadh",B2:B6,"Mouse")
E4: Big orders
F4: =COUNTIF(C2:C6,">=10")
E5: Not Riyadh
F5: =COUNTIF(A2:A6,"<>Riyadh")
E6: Starts with M
F6: =COUNTIF(B2:B6,"M*")
E7: Avg (not Riyadh)
F7: =AVERAGEIF(A2:A6,"<>Riyadh",C2:C6)
```

```output
F1 = 3
F2 = 21
F3 = 15
F4 = 2
F5 = 2
F6 = 2
F7 = 7
```

| الدالة | الصيغة |
|---|---|
| `COUNTIF(نطاق, شرط)` | عدد الخلايا المحققة |
| `SUMIF(نطاق_الشرط, شرط, نطاق_الجمع)` | مجموع المحقق |
| `SUMIFS(نطاق_الجمع, نطاق1, شرط1, نطاق2, شرط2...)` | عدة شروط معاً (و) |
| `COUNTIFS` و `AVERAGEIFS` و `MAXIFS` و `MINIFS` | مثلها |

الشروط نصوص: `"Riyadh"` و `">=10"` و `"<>Riyadh"` و `"M*"` (يبدأ بـ M). ولشرط من خلية: `">="&H1`.

## ملخص الدرس

- `IF(شرط, صح, خطأ)`، و `IFS` لشروط متعددة بالترتيب.
- `AND` كل الشروط، و `OR` أي شرط، و `NOT` النفي.
- `IFERROR(صيغة, بديل)` لأخطاء متوقعة فقط.
- `COUNTIF(S)` و `SUMIF(S)` و `AVERAGEIF(S)` للتحليل حسب الشروط.

## البحث عن قيمة في جدول آخر

سيناريو يومي: في جدول المبيعات اسم المنتج فقط، والتكلفة في جدول المنتجات. نحتاج "استدعاء" التكلفة لكل صف. هذا عمل دوال **البحث**.

## XLOOKUP: الدالة الحديثة

`=XLOOKUP(ما_تبحث_عنه, أين_تبحث, ماذا_تُرجع, [إن_لم_يوجد])`

```excel
== Sales
| Product | Units |
| Laptop | 2 |
| Mouse | 12 |
| Desk | 1 |
| Tablet | 3 |
C1: Cost
C2:C5: =XLOOKUP(A2,Products!A2:A5,Products!C2:C5,"Not found")
D1: Category
D2:D5: =XLOOKUP(A2,Products!A2:A5,Products!B2:B5,"-")
== Products
| Product | Category | Cost |
| Laptop | Electronics | 2600 |
| Mouse | Accessories | 40 |
| Desk | Furniture | 700 |
| Chair | Furniture | 420 |
```

```output
C2 = 2600
C3 = 40
C4 = 700
C5 = Not found
D2 = Electronics
D3 = Accessories
D4 = Furniture
D5 = -
```

- `Products!A2:A5` مرجع لورقة أخرى: اسم الورقة ثم `!`.
- الوسيط الرابع اختياري: ما يُعرض إن لم تُوجد القيمة، وإلا `#N/A`.
- انقر تبويب `Products` تحت الجدول لرؤية الورقة الثانية.

## VLOOKUP: الدالة الكلاسيكية

ستجدها في كل ملف قديم، فلا بد أن تفهمها:

`=VLOOKUP(ما_تبحث_عنه, الجدول, رقم_العمود, FALSE)`

```excel
| Product | Category | Cost |
| Laptop | Electronics | 2600 |
| Mouse | Accessories | 40 |
| Desk | Furniture | 700 |
E1: Lookup
F1: Mouse
E2: Category
F2: =VLOOKUP(F1,A2:C4,2,FALSE)
E3: Cost
F3: =VLOOKUP(F1,A2:C4,3,FALSE)
E4: Missing
F4: =VLOOKUP("Tablet",A2:C4,3,FALSE)
```

```output
F2 = Accessories
F3 = 40
F4 = #N/A
```

قيود VLOOKUP التي حلّتها XLOOKUP:

| | VLOOKUP | XLOOKUP |
|---|---|---|
| عمود البحث | يجب أن يكون **الأول** في الجدول | أي عمود |
| تحديد النتيجة | **رقم** عمود (ينكسر إذا أضفت عموداً) | نطاق مباشر |
| الافتراضي | مطابقة **تقريبية** (لذلك نكتب `FALSE` دائماً!) | مطابقة تامة |
| عند عدم الوجود | `#N/A` (نحتاج `IFERROR`) | وسيط مدمج |

> ⚠️ أشهر خطأ: نسيان `FALSE` في VLOOKUP. بدونها يبحث عن "أقرب" قيمة، فيعطي نتائج **خاطئة بصمت** إذا لم يكن الجدول مرتباً.

## المطابقة التقريبية: الشرائح

المطابقة التقريبية مفيدة فعلاً عند **الشرائح**: عمولة حسب حجم المبيعات، أو تقدير حسب الدرجة:

```excel
| Sales | Rate |
| 0 | 2% |
| 10000 | 4% |
| 20000 | 6% |
| 50000 | 8% |
D1: Rep sales
E1: Rate (VLOOKUP)
F1: Rate (XLOOKUP)
D2: 8500
D3: 27000
D4: 50000
E2:E4: =VLOOKUP(D2,$A$2:$B$5,2,TRUE)
F2:F4: =XLOOKUP(D2,$A$2:$A$5,$B$2:$B$5,,-1)
```

```output
E2 = 2%
E3 = 6%
E4 = 8%
F2 = 2%
F3 = 6%
F4 = 8%
```

`TRUE` في VLOOKUP و `-1` في XLOOKUP: "إن لم تجد تطابقاً فخذ أكبر قيمة أصغر منها". 27000 تقع في شريحة 20000.

## INDEX و MATCH

قبل XLOOKUP كان المحترفون يستخدمون الثنائي `INDEX` + `MATCH`، وما زال شائعاً:

```excel
| Product | Q1 | Q2 | Q3 |
| Laptop | 12 | 15 | 9 |
| Mouse | 40 | 38 | 51 |
| Desk | 6 | 4 | 7 |
F1: Product
G1: Mouse
F2: Quarter
G2: Q3
F3: Row #
G3: =MATCH(G1,A2:A4,0)
F4: Value
G4: =INDEX(B2:D4,MATCH(G1,A2:A4,0),MATCH(G2,B1:D1,0))
F5: Best Q1
G5: =INDEX(A2:A4,MATCH(MAX(B2:B4),B2:B4,0))
```

```output
G3 = 2
G4 = 51
G5 = Mouse
```

- `MATCH(قيمة, نطاق, 0)` يُرجع **موضع** القيمة.
- `INDEX(نطاق, صف, عمود)` يُرجع القيمة في ذلك الموضع.
- معاً: بحث في جدول ثنائي الأبعاد (منتج × ربع).

## ملخص الدرس

- `XLOOKUP(قيمة, نطاق_البحث, نطاق_النتيجة, إن_لم_يوجد)`: الخيار الأول اليوم.
- `VLOOKUP(قيمة, جدول, رقم_عمود, FALSE)`: لا تنسَ `FALSE`.
- المطابقة التقريبية (`TRUE` أو `-1`) للشرائح المرتبة.
- `INDEX` + `MATCH` للبحث المرن وثنائي الأبعاد.
- `Sheet!A1` للمرجع من ورقة أخرى.

## دوال النصوص

البيانات النصية تأتي فوضوية: مسافات زائدة، حالة أحرف عشوائية، أكواد مدمجة. دوال النصوص تنظفها وتقسمها وتجمعها:

```excel
| Raw name | Code |
|   ahmed ALI | SA-RUH-0042 |
| sara khalid  | SA-JED-0107 |
C1: Clean name
C2:C3: =PROPER(TRIM(A2))
D1: City code
D2:D3: =MID(B2,4,3)
E1: Number
E2:E3: =VALUE(RIGHT(B2,4))
F1: Email
F2:F3: =LOWER(SUBSTITUTE(TRIM(A2)," ","."))&"@codeway.dev"
G1: Length
G2:G3: =LEN(TRIM(A2))
```

```output
C2 = Ahmed Ali
C3 = Sara Khalid
D2 = RUH
D3 = JED
E2 = 42
E3 = 107
F2 = ahmed.ali@codeway.dev
F3 = sara.khalid@codeway.dev
G2 = 9
G3 = 11
```

| الدالة | الوظيفة |
|---|---|
| `TRIM` | إزالة المسافات الزائدة |
| `UPPER` / `LOWER` / `PROPER` | حالة الأحرف |
| `LEFT(t, n)` / `RIGHT(t, n)` / `MID(t, start, n)` | اقتطاع |
| `LEN` | الطول |
| `SUBSTITUTE(t, قديم, جديد)` | استبدال |
| `FIND` / `SEARCH` | موضع نص داخل نص (SEARCH بلا حساسية للحالة) |
| `VALUE` | نص إلى رقم |
| `&` أو `CONCAT` | ربط |

### الدوال الحديثة: TEXTBEFORE و TEXTAFTER و TEXTSPLIT و TEXTJOIN

```excel
| Full name | Tags |
| Layla Ahmed | excel,sql,python |
C1: First
C2: =TEXTBEFORE(A2," ")
D1: Last
D2: =TEXTAFTER(A2," ")
A4: =TEXTSPLIT(B2,",")

```

```output
C2 = Layla
D2 = Ahmed
A4# =
  excel | sql | python
A6 = excel | sql | python
```

`TEXTSPLIT` نتيجته عدة خلايا: **تنسكب** تلقائياً في الخلايا المجاورة (الخلايا الزرقاء). هذه **المصفوفات الديناميكية** في Excel الحديث.

## دوال التاريخ

```excel
| Order date | Delivered |
| 2024-01-15 | 2024-01-22 |
| 2024-02-27 | 2024-03-04 |
C1: Days
C2:C3: =B2-A2
D1: Year
D2:D3: =YEAR(A2)
E1: Month
E2:E3: =TEXT(A2,"mmm yyyy")
F1: Month end
F2:F3: =EOMONTH(A2,0)
G1: +3 months
G2:G3: =EDATE(A2,3)
H1: Weekday
H2:H3: =TEXT(A2,"dddd")
```

```output
C2 = 7
C3 = 6
D2 = 2024
D3 = 2024
E2 = Jan 2024
E3 = Feb 2024
F2 = 2024-01-31
F3 = 2024-02-29
G2 = 2024-04-15
G3 = 2024-05-27
H2 = Monday
H3 = Tuesday
```

| الدالة | الوظيفة |
|---|---|
| `DATE(y, m, d)` | إنشاء تاريخ |
| `YEAR` / `MONTH` / `DAY` | الأجزاء |
| `TODAY()` | تاريخ اليوم (يتغير يومياً) |
| `EDATE(d, n)` | بعد n أشهر |
| `EOMONTH(d, n)` | آخر يوم في الشهر |
| `DATEDIF(start, end, "y"/"m"/"d")` | الفرق بالسنوات أو الأشهر أو الأيام |
| `NETWORKDAYS.INTL(start, end, 7)` | أيام العمل (7 = عطلة الجمعة والسبت) |
| `TEXT(d, "صيغة")` | تاريخ كنص منسق |

### العمر والخبرة وأيام العمل

```excel
| Employee | Hired |
| Layla | 2019-09-01 |
| Omar | 2023-02-15 |

D1: Months

E1: Today
E2: =TODAY()
F1: Workdays in June
F2: =NETWORKDAYS.INTL(DATE(2024,6,1),DATE(2024,6,30),7)
```

```output
C2 = 4
C3 = 1
D2 = 58
D3 = 16
E2 = 2024-07-01
F2 = 21
```

(في المحاكي `TODAY()` ثابتة على 2024-07-01 لتبقى نتائج الدروس ثابتة. في Excel الحقيقي تتغير كل يوم.)

## ملخص الدرس

- نظّف النصوص بـ `TRIM` و `PROPER` و `SUBSTITUTE`، واقتطع بـ `LEFT` و `RIGHT` و `MID`.
- `TEXTBEFORE` و `TEXTAFTER` و `TEXTSPLIT` للتقسيم الحديث، و `TEXTJOIN` للجمع بفاصل.
- التاريخ رقم: الطرح يعطي أياماً، و `YEAR/MONTH` و `EOMONTH` و `EDATE` و `DATEDIF`.
- `TEXT(d, "mmm yyyy")` لعرض التاريخ بأي صيغة.
