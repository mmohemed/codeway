## Excel: نقطة البداية لكل محلل

**Excel** أكثر أداة بيانات انتشاراً في العالم: في كل شركة وجهة حكومية وبنك. حتى أقوى محللي Python يحتاجونه يومياً، لأن المدير والمحاسب والعميل يرسلون ملفاتهم بـ Excel ويريدون التقارير به.

### المصطلحات الأساسية

| المصطلح | المعنى |
|---|---|
| **المصنف** (Workbook) | الملف كاملاً `.xlsx` |
| **الورقة** (Sheet) | تبويب داخل المصنف: `Sales` و `Products` |
| **الخلية** (Cell) | تقاطع عمود وصف، وعنوانها مثل `B3`: العمود B والصف 3 |
| **النطاق** (Range) | مجموعة خلايا متجاورة: `A1:C10` |
| **الصيغة** (Formula) | تبدأ دائماً بـ `=`، مثل `=B2*C2` |
| **شريط الصيغة** (fx) | يُظهر الصيغة الحقيقية خلف القيمة المعروضة |

## كيف يعمل المحاكي في هذه الدورة

Excel برنامج سطح مكتب، لذلك نستخدم في الدورة **محاكياً** لحساب الصيغ يتبع قواعد Excel نفسها. تكتب كل خلية في سطر:

- `A1: Product` نص، و `B2: 95` رقم، و `C2: =A2*B2` صيغة.
- البيانات الجاهزة تكتبها كجدول بخطوط عمودية `| ... |`، ويبدأ من `A1`.

```excel
| Product | Price | Qty |
| Mouse | 95 | 3 |
| Laptop | 3200 | 1 |
| Chair | 750 | 2 |
D1: Total
D2: =B2*C2
D3: =B3*C3
D4: =B4*C4
```

```output
D2 = 285
D3 = 3200
D4 = 1500
```

تحت كل مثال ورقة العمل المحسوبة: **انقر أي خلية** لترى صيغتها في شريط الصيغة. الخلايا الصفراء فيها صيغ.

## أنواع البيانات

```excel
| Value | Type check |
| 125 | =ISNUMBER(A2) |
| Riyadh | =ISTEXT(A3) |
| 2024-03-15 | =ISNUMBER(A4) |
| 15% | =A5*200 |
| TRUE | =ISTEXT(A6) |
```

```output
B2 = TRUE
B3 = TRUE
B4 = TRUE
B5 = 30
B6 = FALSE
```

- **الأرقام** تُحاذى لليمين، و**النصوص** لليسار.
- **التاريخ في Excel رقم!** `2024-03-15` مخزّن كرقم تسلسلي (عدد الأيام منذ 1900)، ويُعرض كتاريخ بالتنسيق. لهذا يمكنك طرح تاريخين أو إضافة أيام لتاريخ.
- `15%` رقم قيمته 0.15 بتنسيق نسبة مئوية.

## التعبئة والمراجع النسبية

في Excel الحقيقي لا تكتب الصيغة في كل صف: تكتبها مرة ثم **تسحبها لأسفل** (أو تنقر مقبض التعبئة مرتين). Excel يعدّل المراجع تلقائياً: `=B2*C2` تصبح في الصف التالي `=B3*C3`. هذه **المراجع النسبية**.

في المحاكي تكتب النطاق بدلاً من السحب:

```excel
| Product | Price | Qty |
| Mouse | 95 | 3 |
| Laptop | 3200 | 1 |
| Chair | 750 | 2 |
| Desk | 1100 | 1 |
D1: Total
D2:D5: =B2*C2
```

```output
D2 = 285
D3 = 3200
D4 = 1500
D5 = 1100
```

`D2:D5: =B2*C2` تعني: اكتب الصيغة في D2 ثم اسحبها حتى D5. انقر على D4 لترى أنها أصبحت `=B4*C4`.

## المراجع المطلقة: $

ماذا لو أردنا ضرب كل سعر في **خلية واحدة ثابتة** (نسبة الضريبة)؟ السحب سيحرّك المرجع أيضاً فيفسد الصيغة. الحل: علامة `$` تثبّت العمود أو الصف:

```excel
| Product | Price | With VAT |
| Mouse | 95 | |
| Laptop | 3200 | |
| Chair | 750 | |
E1: VAT
F1: 15%
C2:C4: =B2*(1+$F$1)
```

```output
C2 = 109.25
C3 = 3680
C4 = 862.5
```

| المرجع | عند السحب لأسفل | عند السحب لليمين |
|---|---|---|
| `F1` | يتغير الصف | يتغير العمود |
| `$F$1` | ثابت | ثابت |
| `F$1` | الصف ثابت | يتغير العمود |
| `$F1` | يتغير الصف | العمود ثابت |

> 💡 في Excel اضغط **F4** وأنت على المرجع داخل الصيغة للتبديل بين الأشكال الأربعة.

## جداول Excel (Ctrl + T)

في Excel الحقيقي، حوّل بياناتك إلى **جدول** (حدد البيانات ← Ctrl + T): تتلون الصفوف، وتُضاف أزرار الفلترة، وتتمدد الصيغ تلقائياً للصفوف الجديدة، وتستطيع كتابة مراجع **منظمة** مثل `=[@Price]*[@Qty]` بدل `=B2*C2`. وهذه أفضل ممارسة لأي بيانات جدولية. (المحاكي يستخدم المراجع العادية فقط.)

## ملخص الدرس

- المصنف ← الأوراق ← الخلايا، والصيغة تبدأ بـ `=`.
- الأرقام والتواريخ أرقام (التاريخ رقم تسلسلي)، والنصوص نصوص.
- التعبئة لأسفل تعدّل المراجع النسبية تلقائياً.
- `$` تثبّت المرجع: `$F$1` ثابت تماماً، و `F$1` و `$F1` تثبيت جزئي.

## الدوال الأساسية

**الدالة** صيغة جاهزة: اسمها ثم المدخلات بين قوسين، مفصولة بفواصل: `=SUM(A1:A10)`.

```excel
| Month | Sales |
| Jan | 28100 |
| Feb | 29970 |
| Mar | 38390 |
| Apr | 21020 |
| May | 33745 |
| Jun | 22335 |
D1: Total
E1: =SUM(B2:B7)
D2: Average
E2: =AVERAGE(B2:B7)
D3: Best
E3: =MAX(B2:B7)
D4: Worst
E4: =MIN(B2:B7)
D5: Months
E5: =COUNT(B2:B7)
D6: Rounded avg
E6: =ROUND(E2,0)
```

```output
E1 = 173560
E2 = 28926.66667
E3 = 38390
E4 = 21020
E5 = 6
E6 = 28927
```

| الدالة | الوظيفة |
|---|---|
| `SUM` | المجموع |
| `AVERAGE` | المتوسط |
| `MIN` / `MAX` | الأصغر / الأكبر |
| `COUNT` | عدد الخلايا **الرقمية** |
| `COUNTA` | عدد الخلايا **غير الفارغة** (أي نوع) |
| `COUNTBLANK` | عدد الفارغة |
| `MEDIAN` | الوسيط |
| `ROUND(x, n)` | تقريب لـ n خانات (و `ROUNDUP` و `ROUNDDOWN`) |

### COUNT أم COUNTA؟

```excel
| Name | Score |
| Layla | 88 |
| Omar | absent |
| Huda | 95 |
| Fahad | |
| Sara | 72 |
D1: COUNT
E1: =COUNT(B2:B6)
D2: COUNTA
E2: =COUNTA(B2:B6)
D3: Blank
E3: =COUNTBLANK(B2:B6)
D4: AVERAGE
E4: =AVERAGE(B2:B6)
```

```output
E1 = 3
E2 = 4
E3 = 1
E4 = 85
```

`AVERAGE` تتجاهل النص والفراغ: متوسط 3 درجات فقط، لا 5. انتبه لهذا عند البيانات الناقصة.

## العمليات الحسابية والأسبقية

| العملية | الرمز | مثال |
|---|---|---|
| جمع وطرح | `+` `-` | `=A1+B1` |
| ضرب وقسمة | `*` `/` | `=A1/B1` |
| أس | `^` | `=A1^2` |
| نسبة | `%` | `=A1*15%` |
| ربط نصوص | `&` | `=A1&" "&B1` |

الأسبقية مثل الرياضيات: الأقواس، ثم الأس، ثم الضرب والقسمة، ثم الجمع والطرح:

```excel
A1: =2+3*4
A2: =(2+3)*4
A3: =10/4*2
A4: =2^3+1
```

```output
A1 = 14
A2 = 20
A3 = 5
A4 = 9
```

## نسب النمو والحصص

```excel
| Month | Sales |
| Jan | 28100 |
| Feb | 29970 |
| Mar | 38390 |
| Apr | 21020 |
C1: Growth
C3:C5: =ROUND((B3-B2)/B2*100,1)
D1: Share %
D2:D5: =ROUND(B2/SUM($B$2:$B$5)*100,1)
```

```output
C3 = 6.7
C4 = 28.1
C5 = -45.2
D2 = 23.9
D3 = 25.5
D4 = 32.7
D5 = 17.9
```

- **النمو** = (الجديد - القديم) ÷ القديم.
- **الحصة** = القيمة ÷ المجموع، مع `$` لتثبيت نطاق المجموع عند التعبئة.

> 💡 في Excel الحقيقي تكتب `=(B3-B2)/B2` ثم تختار تنسيق النسبة المئوية `%` من شريط الأدوات بدلاً من الضرب في 100.

## الأخطاء الشائعة

```excel
| a | b |
| 10 | 0 |
| 5 | text |
C2: =A2/B2
C3: =A3+B3
C4: =SUMM(A2:A3)
```

```output
C2 = #DIV/0!
C3 = #VALUE!
C4 = #NAME?
```

| الخطأ | السبب |
|---|---|
| `#DIV/0!` | قسمة على صفر أو خلية فارغة |
| `#VALUE!` | عملية حسابية على نص |
| `#NAME?` | اسم دالة خاطئ (إملاء) |
| `#REF!` | مرجع لخلية محذوفة |
| `#N/A` | قيمة غير موجودة (في دوال البحث) |
| `#SPILL!` | نتيجة المصفوفة لا تجد مكاناً فارغاً لتنسكب |
| `####` | العمود ضيق على الرقم (وسّع العمود) |

## ملخص الدرس

- `SUM` و `AVERAGE` و `MIN` و `MAX` و `COUNT` و `COUNTA` و `ROUND` أساس كل تقرير.
- `COUNT` للأرقام فقط، و `COUNTA` لغير الفارغ، و `AVERAGE` تتجاهل النصوص والفراغ.
- الأسبقية: أقواس ← أس ← ضرب وقسمة ← جمع وطرح.
- النمو (جديد-قديم)/قديم، والحصة قيمة/مجموع مع `$`.
- تعرّف على رموز الأخطاء: `#DIV/0!` و `#VALUE!` و `#NAME?` و `#N/A`.
