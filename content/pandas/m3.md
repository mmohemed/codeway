## اكتشاف القيم المفقودة

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
print(survey.isna().sum())
print("صفوف فيها أي مفقود:", survey.isna().any(axis=1).sum())
print(survey[survey["age"].isna()][["name", "age"]])
```

```output
id           0
name         0
city         0
age          2
salary       0
join_date    0
rating       1
dtype: int64
صفوف فيها أي مفقود: 3
          name  age
1  sara KHALID  NaN
6  Huda Nasser  NaN
```

- `isna()` (أو `isnull()`) قناع `True` حيث القيمة مفقودة، و `notna()` عكسه.
- `NaN` لا تساوي نفسها! `survey["age"] == None` لا يعمل، استخدم دائماً `isna()`.

## الحذف: dropna

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
print(len(survey.dropna()))                          # حذف أي صف فيه مفقود
print(len(survey.dropna(subset=["rating"])))          # فقط إن كان التقييم مفقوداً
print(survey.dropna(axis=1).columns.tolist())         # حذف الأعمدة التي فيها مفقود
```

```output
5
7
['id', 'name', 'city', 'salary', 'join_date']
```

> ⚠️ الحذف سهل لكنه خطير: قد تخسر جزءاً كبيراً من بياناتك. احذف فقط عندما يكون المفقود قليلاً، أو عندما يكون الصف بلا فائدة دون تلك القيمة.

## التعويض: fillna

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
survey["age"] = survey["age"].fillna(survey["age"].median())   # بالوسيط
survey["rating"] = survey["rating"].fillna(0)                   # بقيمة ثابتة
print(survey[["name", "age", "rating"]])
```

```output
           name   age  rating
0    Ahmed Ali   29.0     4.0
1   sara KHALID  32.0     5.0
2    Omar Saleh  35.0     0.0
3    Ahmed Ali   29.0     4.0
4    Mona Fahad  41.0     3.0
5   khalid omar  27.0     5.0
6   Huda Nasser  32.0     2.0
7    Ali Hassan  52.0     4.0
```

| الطريقة | متى تستخدمها |
|---|---|
| `fillna(df["c"].median())` | أرقام فيها قيم شاذة (الأعمار، الرواتب) |
| `fillna(df["c"].mean())` | أرقام متوزعة بشكل طبيعي |
| `fillna(df["c"].mode()[0])` | فئات نصية: القيمة الأكثر تكراراً |
| `fillna("غير محدد")` | عندما يكون الفقد نفسه معلومة |
| `ffill()` / `bfill()` | السلاسل الزمنية: القيمة السابقة أو التالية |

## ملخص الدرس

- `isna().sum()` لعدّ المفقود في كل عمود، و `isna()` وليس `== None` للمقارنة.
- `dropna()` للحذف، مع `subset=[...]` لتحديد الأعمدة.
- `fillna(...)` للتعويض: الوسيط للأرقام، والمنوال للفئات، و `ffill` للسلاسل الزمنية.
- `groupby(...).transform("median")` للتعويض بقيمة كل مجموعة.

## الصفوف المكررة

التكرار شائع: إرسال النموذج مرتين، أو دمج ملفين متداخلين. والتكرار **يضخّم** المجاميع ويفسد التحليل.

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
cols = ["name", "city", "age", "salary", "join_date"]
print(survey.duplicated(subset=cols))
print("مكرر:", survey.duplicated(subset=cols).sum())
```

```output
0    False
1    False
2    False
3     True
4    False
5    False
6    False
7    False
dtype: bool
مكرر: 1
```

- `duplicated()` يُعلّم التكرارات (ما عدا الظهور الأول افتراضياً).
- استخدمنا `subset` لأن `id` مختلف في النسختين، فالصفان متطابقان فعلياً لكن ليسا متطابقين حرفياً.

### الحذف

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
cols = ["name", "city", "age", "salary", "join_date"]
clean = survey.drop_duplicates(subset=cols, keep="first")
print(len(survey), "←", len(clean))
print(clean["id"].tolist())
```

```output
8 ← 7
[1, 2, 3, 5, 6, 7, 8]
```

| `keep=` | يُبقي |
|---|---|
| `"first"` (الافتراضي) | أول ظهور |
| `"last"` | آخر ظهور (مفيد إذا كان الأحدث هو الأصح) |
| `False` | لا شيء: يحذف كل النسخ المكررة |

## التكرار في عمود واحد

أحياناً السؤال ليس "هل الصف مكرر؟" بل "هل هذا البريد مسجل مرتين؟":

```python
import pandas as pd

users = pd.DataFrame({
    "email": ["a@x.com", "b@x.com", "a@x.com", "c@x.com", "b@x.com"],
    "signup": ["2024-01-03", "2024-01-05", "2024-02-10", "2024-02-11", "2024-03-01"],
})
print(users["email"].duplicated(keep=False))
latest = users.sort_values("signup").drop_duplicates("email", keep="last")
print(latest)
print(users["email"].nunique(), "مستخدمين فعليين")
```

```output
0     True
1     True
2     True
3    False
4     True
Name: email, dtype: bool
     email      signup
2  a@x.com  2024-02-10
3  c@x.com  2024-02-11
4  b@x.com  2024-03-01
3 مستخدمين فعليين
```

`keep=False` يُعلّم **كل** النسخ المكررة (لمراجعتها)، والترتيب ثم `keep="last"` يُبقي أحدث تسجيل لكل بريد.

> 💡 قبل البحث عن التكرار، **وحّد النصوص أولاً**: "Ahmed Ali" و " ahmed ali " لن يُعتبرا مكررين. ستتعلم ذلك في درس تنظيف النصوص.

## ملخص الدرس

- `duplicated()` لتعليم التكرارات، و `.sum()` لعدّها.
- `drop_duplicates(subset=[...], keep=...)` للحذف.
- `keep="first"` أو `"last"` أو `False`.
- رتّب قبل الحذف لتتحكم في أي نسخة تبقى، ووحّد النصوص قبل البحث عن التكرار.

## تحويل النصوص لأرقام

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
s = survey["salary"].str.replace(",", "")          # إزالة فاصل الآلاف
survey["salary"] = pd.to_numeric(s, errors="coerce")  # ما لا يُحوَّل يصبح NaN
print(survey["salary"].tolist())
print(survey["salary"].dtype, survey["salary"].mean())
```

```output
[12500.0, 9800.0, 15000.0, 12500.0, nan, 8700.0, 11200.0, 21000.0]
float64 12957.142857142857
```

| `errors=` | عند وجود قيمة لا تُحوَّل |
|---|---|
| `"raise"` (الافتراضي) | خطأ يوقف البرنامج |
| `"coerce"` | تصبح `NaN` (ثم تعالجها كمفقود) |

## الفئات: category

للأعمدة النصية ذات القيم القليلة المتكررة (المدينة، الحالة، الفئة)، النوع `category` يوفر الذاكرة ويسمح بترتيب مخصص:

```python
import pandas as pd

size_type = pd.CategoricalDtype(["S", "M", "L", "XL"], ordered=True)
sizes = pd.Series(["M", "S", "XL", "M", "L", "S"], dtype=size_type)
print(sizes.sort_values().tolist())       # حسب ترتيب الفئات لا الأبجدية
print(sizes.max(), "|", (sizes > "M").sum(), "أكبر من M")
```

```output
['S', 'S', 'M', 'M', 'L', 'XL']
XL | 2 أكبر من M
```

## ملخص الدرس

- `dtypes` لمعرفة الأنواع، و `object` يعني نصاً غالباً.
- `pd.to_numeric(..., errors="coerce")` للنصوص التي فيها قيم غير رقمية.
- `astype(...)` للتحويل المباشر، و `"Int64"` لأعداد صحيحة مع قيم مفقودة.
- `pd.to_datetime` للتواريخ، و `category` للفئات المتكررة والمرتبة.

## تنظيف النصوص: str

كل الدوال النصية في Pandas تعمل على العمود كاملاً عبر `.str`، تماماً مثل دوال نصوص Python:

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
print(survey["name"].tolist())
survey["name"] = survey["name"].str.strip().str.title()
survey["city"] = survey["city"].str.strip().str.capitalize()
print(survey["name"].tolist())
print(survey["city"].value_counts().to_dict())
```

```output
['  Ahmed Ali ', 'sara KHALID', 'Omar Saleh', '  Ahmed Ali ', 'Mona Fahad', 'khalid omar', 'Huda Nasser', 'Ali Hassan']
['Ahmed Ali', 'Sara Khalid', 'Omar Saleh', 'Ahmed Ali', 'Mona Fahad', 'Khalid Omar', 'Huda Nasser', 'Ali Hassan']
{'Riyadh': 3, 'Jeddah': 2, 'Dammam': 2, 'Mecca': 1}
```

قبل التنظيف كان في عمود المدينة 6 قيم مختلفة، لأن `riyadh` و `RIYADH` و `jeddah ` (بمسافة) تُعامل كمدن مختلفة! بعده أصبحت 4 مدن فعلية.

| الدالة | الوظيفة |
|---|---|
| `str.strip()` | إزالة المسافات من الطرفين |
| `str.lower()` / `upper()` / `title()` / `capitalize()` | حالة الأحرف |
| `str.replace("a", "b")` | استبدال |
| `str.contains("x")` / `startswith` / `endswith` | البحث (قناع منطقي) |
| `str.len()` | الطول |
| `str.split(" ")` | التقسيم |
| `str[0:3]` | التقطيع |

## التقسيم والاستخراج

```python
import pandas as pd

survey = pd.read_csv("survey.csv")
survey["name"] = survey["name"].str.strip().str.title()
parts = survey["name"].str.split(" ", n=1, expand=True)
survey["first"], survey["last"] = parts[0], parts[1]
print(survey[["first", "last"]].head(3))

codes = pd.Series(["ORD-2024-001", "ORD-2023-417", "REF-2024-090"])
print(codes.str.extract(r"(\w+)-(\d{4})-(\d+)"))
```

```output
   first    last
0  Ahmed     Ali
1   Sara  Khalid
2   Omar   Saleh
     0     1    2
0  ORD  2024  001
1  ORD  2023  417
2  REF  2024  090
```

- `split(..., expand=True)` يقسم إلى أعمدة.
- `str.extract(regex)` يستخرج أجزاء بالتعبير النمطي، كل مجموعة `( )` عمود.

## الاستبدال بقاموس: replace و map

لتوحيد كتابات مختلفة لنفس القيمة:

```python
import pandas as pd

answers = pd.Series(["yes", "Y", "no", "N", "Yes", "n"])
clean = answers.str.lower().replace({"y": "yes", "n": "no"})
print(clean.tolist())

codes = pd.Series(["RUH", "JED", "DMM", "RUH"])
print(codes.map({"RUH": "Riyadh", "JED": "Jeddah", "DMM": "Dammam"}).tolist())
```

```output
['yes', 'yes', 'no', 'no', 'yes', 'no']
['Riyadh', 'Jeddah', 'Dammam', 'Riyadh']
```

- `replace({...})` يستبدل القيم الموجودة في القاموس ويترك غيرها.
- `map({...})` يحوّل كل قيمة حسب القاموس، وما ليس فيه يصبح `NaN`.

## ملخص الدرس

- `.str` يطبق دوال النصوص على العمود كاملاً.
- وحّد النصوص بـ `strip` و `lower` / `title` قبل التحليل والبحث عن التكرار.
- `str.split(expand=True)` و `str.extract(regex)` لتقسيم واستخراج الأجزاء.
- `replace({...})` لتوحيد القيم، و `map({...})` لتحويلها.
