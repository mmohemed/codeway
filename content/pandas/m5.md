## التواريخ في Pandas

المبيعات والزيارات والقراءات كلها مرتبطة بالزمن. أول خطوة دائماً: تحويل عمود التاريخ من نص إلى نوع **datetime**:

```python
import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])
print(orders["date"].dtype)
print(orders["date"].min(), "→", orders["date"].max())
print((orders["date"].max() - orders["date"].min()).days, "يوماً")
```

```output
datetime64[ns]
2024-01-02 00:00:00 → 2024-06-29 00:00:00
179 يوماً
```

أو بعد القراءة: `orders["date"] = pd.to_datetime(orders["date"])`.

### صيغ التواريخ

```python
import pandas as pd

print(pd.to_datetime("15/03/2024", format="%d/%m/%Y"))
print(pd.to_datetime("March 5, 2024"))
print(pd.to_datetime(["2024-01-10", "not a date"], errors="coerce").tolist())
```

```output
2024-03-15 00:00:00
2024-03-05 00:00:00
[Timestamp('2024-01-10 00:00:00'), NaT]
```

| الرمز | المعنى | مثال |
|---|---|---|
| `%Y` | السنة كاملة | 2024 |
| `%m` | الشهر برقمين | 03 |
| `%d` | اليوم برقمين | 15 |
| `%H:%M` | الساعة والدقيقة | 14:30 |
| `%B` / `%A` | اسم الشهر / اليوم | March / Friday |

> 💡 حدد `format` دائماً عندما تعرف الصيغة: أسرع، ويمنع الالتباس بين `03/04` (3 أبريل أم 4 مارس؟).

## استخراج الأجزاء: dt

```python
import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["year"] = orders["date"].dt.year
orders["month"] = orders["date"].dt.month
orders["weekday"] = orders["date"].dt.day_name()
orders["is_weekend"] = orders["date"].dt.dayofweek.isin([4, 5])   # الجمعة والسبت
print(orders[["date", "month", "weekday", "is_weekend"]].head(4))
print(orders["weekday"].value_counts().head(3).to_dict())
```

```output
        date  month   weekday  is_weekend
0 2024-01-02      1   Tuesday       False
1 2024-01-02      1   Tuesday       False
2 2024-01-04      1  Thursday       False
3 2024-01-05      1    Friday        True
{'Tuesday': 21, 'Wednesday': 19, 'Saturday': 19}
```

`dt.year` و `dt.month` و `dt.day` و `dt.day_name()` و `dt.dayofweek` (الاثنين 0 ... الأحد 6) و `dt.quarter` و `dt.to_period("M")`.

## الحساب بالتواريخ

```python
import pandas as pd

customers = pd.read_csv("customers.csv", parse_dates=["signup_date"])
today = pd.Timestamp("2024-07-01")
customers["days_member"] = (today - customers["signup_date"]).dt.days
customers["renewal"] = customers["signup_date"] + pd.DateOffset(years=1)
print(customers[["name", "signup_date", "days_member", "renewal"]].head(3))

print(customers[customers["signup_date"] >= "2024-01-01"]["name"].tolist())
```

```output
    name signup_date  days_member    renewal
0  Layla  2023-02-14          503 2024-02-14
1   Omar  2023-05-03          425 2024-05-03
2   Huda  2023-07-21          346 2024-07-21
['Sara', 'Khalid', 'Noura', 'Ali']
```

- طرح تاريخين يعطي **مدة** (Timedelta)، و `.dt.days` عدد أيامها.
- `pd.DateOffset(months=1)` أو `pd.Timedelta(days=7)` للإضافة.
- المقارنة بنص التاريخ مباشرة تعمل: `df["date"] >= "2024-01-01"`.

import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])

orders["period"] = orders["date"].dt.to_period("M")
orders.groupby("period")["total"].sum()

## ملخص الدرس

- `pd.to_datetime` أو `parse_dates` لتحويل النصوص لتواريخ، مع `format` و `errors="coerce"`.
- `.dt.year/month/day_name()/dayofweek/quarter` لاستخراج الأجزاء.
- طرح التواريخ يعطي مدة، و `DateOffset` و `Timedelta` للإضافة.
- `dt.to_period("M")` ثم `groupby` للتجميع الشهري.

## السلاسل الزمنية: الفهرس الزمني

عندما يصبح التاريخ **فهرساً** للجدول، تفتح Pandas أدوات قوية للسلاسل الزمنية:

import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])

ts = orders.set_index("date").sort_index()
print(ts.loc["2024-03", "total"].sum())                    # كل مارس

## resample: إعادة التشكيل الزمني

`resample` مثل `groupby` لكن للزمن: يجمع البيانات في فترات منتظمة (يومية، أسبوعية، شهرية):

```python
import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["total"] = orders["qty"] * orders["unit_price"]
ts = orders.set_index("date").sort_index()
monthly = ts["total"].resample("ME").sum()
print(monthly)
print(ts["order_id"].resample("W").count().head(4))
```

```output
date
2024-01-31    28110
2024-02-29    29970
2024-03-31    38390
2024-04-30    21020
2024-05-31    33745
2024-06-30    22335
Freq: ME, Name: total, dtype: int64
date
2024-01-07    5
2024-01-14    5
2024-01-21    4
2024-01-28    4
Freq: W-SUN, Name: order_id, dtype: int64
```

| الرمز | الفترة |
|---|---|
| `"D"` | يومي |
| `"W"` | أسبوعي (ينتهي الأحد افتراضياً) |
| `"ME"` / `"MS"` | شهري (بنهاية الشهر / ببدايته) |
| `"QE"` | ربع سنوي |
| `"YE"` | سنوي |
| `"h"` | كل ساعة |

> 💡 في إصدارات Pandas قبل 2.2 كانت الرموز `"M"` و `"Q"` و `"Y"` بدلاً من `"ME"` و `"QE"` و `"YE"`. ستجدها كثيراً في الشروحات القديمة.

### ملء الفترات الفارغة

أهم فرق بين `resample` و `groupby`: الفترة التي ليس فيها بيانات **تظهر** في `resample`:

```python
import pandas as pd

visits = pd.Series([5, 8, 3], index=pd.to_datetime(["2024-01-01", "2024-01-02", "2024-01-05"]))
print(visits.resample("D").sum())
print(visits.resample("D").asfreq().ffill())
```

## المتوسط المتحرك: rolling

البيانات اليومية متذبذبة. **المتوسط المتحرك** يُنعّمها ليظهر الاتجاه العام:

```python
import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["total"] = orders["qty"] * orders["unit_price"]
weekly = orders.set_index("date")["total"].resample("W").sum()
trend = pd.DataFrame({"weekly": weekly, "avg_4w": weekly.rolling(4).mean().round(0)})
print(trend.head(6))
```

```output
            weekly  avg_4w
date                      
2024-01-07    1180     NaN
2024-01-14    1890     NaN
2024-01-21   11610     NaN
2024-01-28   10600  6320.0
2024-02-04   15760  9965.0
2024-02-11    1640  9902.0
```

أول 3 أسابيع `NaN` لأن النافذة تحتاج 4 قيم. (`rolling(4, min_periods=1)` يحسب بما يتوفر.)

## التغير والنمو

```python
import pandas as pd

orders = pd.read_csv("orders.csv", parse_dates=["date"])
orders["total"] = orders["qty"] * orders["unit_price"]
m = orders.set_index("date")["total"].resample("ME").sum()
report = pd.DataFrame({
    "revenue": m,
    "prev": m.shift(1),
    "growth_%": (m.pct_change() * 100).round(1),
    "cumulative": m.cumsum(),
})
report.index = report.index.strftime("%Y-%m")
report
```

```output
         revenue     prev  growth_%  cumulative
date                                           
2024-01    28110      NaN       NaN       28110
2024-02    29970  28110.0       6.6       58080
2024-03    38390  29970.0      28.1       96470
2024-04    21020  38390.0     -45.2      117490
2024-05    33745  21020.0      60.5      151235
2024-06    22335  33745.0     -33.8      173570
```

- `shift(1)` يزيح القيم فترة للأمام (قيمة الشهر السابق).
- `pct_change()` نسبة التغير عن الفترة السابقة، و `cumsum()` المجموع التراكمي.

## ملخص الدرس

- `set_index("date")` يجعل التاريخ فهرساً، و `ts.loc["2024-03"]` يختار شهراً كاملاً.
- `resample("ME").sum()` للتجميع الزمني المنتظم، وتظهر فيه الفترات الفارغة.
- `rolling(n).mean()` للمتوسط المتحرك.
- `shift` و `pct_change` و `cumsum` لتحليل النمو.
