## ما هي Pandas؟

**Pandas** هي المكتبة الأهم لمحلل البيانات في Python. تتعامل مع البيانات **الجدولية** (مثل جداول Excel وقواعد البيانات): قراءتها، تنظيفها، تصفيتها، تجميعها، ودمجها. مبنية على NumPy، والعرف أن تُستورد باسم `pd`:

```bash
pip install pandas
```

فيها نوعان أساسيان:

| النوع | ما هو | يشبه |
|---|---|---|
| `Series` | عمود واحد من القيم مع **فهرس** (index) | عمود في Excel |
| `DataFrame` | جدول من عدة أعمدة تتشارك نفس الفهرس | ورقة Excel كاملة |

## Series

```python
import pandas as pd

sales = pd.Series([120, 340, 90, 410], index=["Riyadh", "Jeddah", "Dammam", "Mecca"], name="sales")
sales
```

```output
Riyadh    120
Jeddah    340
Dammam     90
Mecca     410
Name: sales, dtype: int64
```

كما في Jupyter: **قيمة آخر سطر تُعرض تلقائياً** دون `print`. وعند تشغيل المثال في المتصفح تظهر الجداول بشكل منسق.

الـ Series تجمع مزايا مصفوفة NumPy (العمليات دون حلقات) والقاموس (الوصول بالاسم):

```python
import pandas as pd

sales = pd.Series([120, 340, 90, 410], index=["Riyadh", "Jeddah", "Dammam", "Mecca"])
print(sales["Jeddah"])
print(sales.sum(), sales.mean())
print(sales[sales > 100].index.tolist())
print((sales * 1.15).round(1).to_dict())
```

```output
340
960 240.0
['Riyadh', 'Jeddah', 'Mecca']
{'Riyadh': 138.0, 'Jeddah': 391.0, 'Dammam': 103.5, 'Mecca': 471.5}
```

## DataFrame

أشهر طريقة لإنشائه: **قاموس**، كل مفتاح اسم عمود وقيمته قائمة:

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["Layla", "Omar", "Huda", "Fahad"],
    "city": ["Riyadh", "Jeddah", "Dammam", "Riyadh"],
    "age": [28, 35, 41, 30],
    "salary": [12000, 9500, 15000, 11000],
})
df
```

```output
    name    city  age  salary
0  Layla  Riyadh   28   12000
1   Omar  Jeddah   35    9500
2   Huda  Dammam   41   15000
3  Fahad  Riyadh   30   11000
```

- العمود الأيسر (0، 1، 2...) هو **الفهرس** (index): اسم كل صف.
- كل عمود هو Series: `df["age"]`.

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["Layla", "Omar", "Huda", "Fahad"],
    "city": ["Riyadh", "Jeddah", "Dammam", "Riyadh"],
    "age": [28, 35, 41, 30],
    "salary": [12000, 9500, 15000, 11000],
})
print(type(df["age"]).__name__)
print(df.columns.tolist())
print(df.shape)                            # (صفوف، أعمدة)

df["bonus"] = df["salary"] * 0.1           # عمود جديد محسوب
df["senior"] = df["age"] >= 35
print(df[["name", "bonus", "senior"]])     # اختيار عدة أعمدة بقائمة
```

```output
Series
['name', 'city', 'age', 'salary']
(4, 4)
    name   bonus  senior
0  Layla  1200.0   False
1   Omar   950.0    True
2   Huda  1500.0    True
3  Fahad  1100.0   False
```

> 💡 لاختيار عمود واحد `df["age"]` (يُرجع Series)، ولعدة أعمدة قائمة داخل الأقواس `df[["name", "age"]]` (يُرجع DataFrame).

## إنشاء DataFrame من صفوف

البيانات القادمة من واجهات API تأتي عادة كقائمة قواميس، كل قاموس صف:

```python
import pandas as pd

records = [
    {"product": "Laptop", "price": 3200, "stock": 5},
    {"product": "Mouse", "price": 95},
    {"product": "Desk", "price": 1100, "stock": 2},
]
pd.DataFrame(records)
```

```output
  product  price  stock
0  Laptop   3200    5.0
1   Mouse     95    NaN
2    Desk   1100    2.0
```

المفتاح الناقص في الصف الثاني أصبح `NaN` (قيمة مفقودة)، وصار العمود عشرياً لأن `NaN` رقم عشري. ستتعلم معالجة ذلك في وحدة التنظيف.

## ملخص الدرس

- `Series` عمود واحد بفهرس، و `DataFrame` جدول من أعمدة.
- `pd.DataFrame({...})` من قاموس أعمدة، أو `pd.DataFrame([...])` من قائمة صفوف.
- `df["col"]` عمود (Series)، و `df[["a", "b"]]` عدة أعمدة (DataFrame).
- `df["new"] = ...` لإضافة عمود محسوب، و `shape` و `columns` لوصف الجدول.

~~~solution
import pandas as pd

data = {
    "product": ["Laptop", "Headphones", "Keyboard", "Chair"],
    "price": [3200, 250, 180, 750],
    "cost": [2600, 140, 90, 420],
    "sold": [10, 18, 21, 12],
}
df = pd.DataFrame(data)
df["revenue"] = df["price"] * df["sold"]
df["profit"] = (df["price"] - df["cost"]) * df["sold"]
best = df.loc[df["profit"].idxmax(), "product"]
~~~

## قراءة ملفات CSV

في العمل الحقيقي البيانات تأتي من ملفات. أشهرها **CSV**: نص بسيط، كل سطر صف، والقيم مفصولة بفواصل.

في هذه الدورة يوجد مجلد عمل فيه ملفات بيانات متجر إلكتروني: `orders.csv` (الطلبات) و `products.csv` (المنتجات) و `customers.csv` (العملاء) و `survey.csv` (بيانات تحتاج تنظيفاً).

### خيارات مهمة في read_csv

```python
import pandas as pd

products = pd.read_csv(
    "products.csv",
    usecols=["product", "category", "price"],  # أعمدة محددة فقط
    index_col="product",                        # عمود يصبح الفهرس
)
print(products)
print(products.loc["Desk", "price"])
```

```output
               category  price
product                       
Laptop      Electronics   3200
Headphones  Electronics    250
Monitor     Electronics    900
Keyboard    Accessories    180
Mouse       Accessories     95
Desk          Furniture   1100
Chair         Furniture    750
Lamp          Furniture    130
1100
```

| الخيار | الوظيفة |
|---|---|
| `sep=";"` | فاصل مختلف (شائع في الملفات الأوروبية) |
| `usecols=[...]` | قراءة أعمدة محددة |
| `index_col="col"` | عمود كفهرس |
| `parse_dates=["date"]` | تحويل أعمدة لتواريخ |
| `nrows=100` | أول 100 صف فقط (للملفات الضخمة) |
| `encoding="utf-8"` | ترميز النص (للعربية استخدم utf-8) |
| `na_values=["unknown", "-"]` | نصوص تُعامل كقيم مفقودة |
| `thousands=","` | فاصل الآلاف في الأرقام مثل "12,500" |

## قراءة ملفات Excel

```python
import pandas as pd

# ننشئ ملف Excel أولاً من بيانات المنتجات (بورقتين)
products = pd.read_csv("products.csv")
with pd.ExcelWriter("store.xlsx") as writer:
    products.to_excel(writer, sheet_name="products", index=False)
    products.groupby("category", as_index=False)["price"].mean().to_excel(writer, sheet_name="summary", index=False)

# ثم نقرؤه
summary = pd.read_excel("store.xlsx", sheet_name="summary")
print(summary)
sheets = pd.read_excel("store.xlsx", sheet_name=None)   # كل الأوراق في قاموس
print(list(sheets))
```

```output
      category   price
0  Accessories   137.5
1  Electronics  1450.0
2    Furniture   660.0
['products', 'summary']
```

- `read_excel` تحتاج مكتبة `openpyxl` (`pip install openpyxl`). في هذه المنصة تُثبَّت تلقائياً.
- `sheet_name` اسم الورقة أو رقمها، و `None` لقراءة كل الأوراق.

قراءة مصادر أخرى: `pd.read_json` و `pd.read_sql` (من قاعدة بيانات) و `pd.read_parquet` (صيغة سريعة مضغوطة للبيانات الكبيرة) و `pd.read_html` (جداول صفحات الويب).

## ملخص الدرس

- `pd.read_csv("file.csv")` لقراءة CSV، مع خيارات مثل `usecols` و `index_col` و `parse_dates` و `na_values` و `thousands`.
- `pd.read_excel("file.xlsx", sheet_name=...)` لملفات Excel.
- `df.to_csv(..., index=False)` و `df.to_excel(...)` للحفظ.
- `head()` و `tail()` لنظرة أولى على البيانات.

## الاستكشاف السريع

أول ما تفعله مع أي بيانات جديدة: **تعرّف عليها** قبل التحليل. كم صفاً؟ ما الأعمدة وأنواعها؟ هل توجد قيم مفقودة؟ ما نطاق القيم؟

import pandas as pd

### value_counts: تكرار القيم

للأعمدة النصية (الفئات)، أهم سؤال: كم مرة تكررت كل قيمة؟

orders = pd.read_csv("orders.csv")
print(orders["city"].value_counts())
print(orders["status"].value_counts(normalize=True).round(3))   # كنسب
print(orders["product"].nunique(), "منتجات مختلفة")

## ملخص الدرس

- `info()` للبنية والأنواع والمفقود، و `describe()` للإحصاءات الرقمية.
- `value_counts()` لتكرار الفئات (و `normalize=True` للنسب)، و `nunique()` لعدد القيم المختلفة.
- `dtypes` و `isna().sum()` و `sample()` أدوات سريعة للتعرف على البيانات.
