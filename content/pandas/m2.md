## loc و iloc

لاختيار صفوف وأعمدة معاً في Pandas أداتان:

| | `loc` | `iloc` |
|---|---|---|
| تختار بـ | **الأسماء** (الفهرس وأسماء الأعمدة) | **المواضع** الرقمية (0، 1، 2...) |
| نهاية التقطيع | **تُشمل** | لا تُشمل (مثل Python) |
| الصيغة | `df.loc[صفوف, أعمدة]` | `df.iloc[صفوف, أعمدة]` |

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
print(products.loc["Desk"])                         # صف واحد بالاسم
print(products.loc["Desk", "price"])                # خلية
print(products.loc[["Laptop", "Mouse"], ["price", "cost"]])
```

```output
category    Furniture
price            1100
cost              700
Name: Desk, dtype: object
1100
         price  cost
product             
Laptop    3200  2600
Mouse       95    40
```

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
print(products.iloc[0])                 # أول صف
print(products.iloc[-1, 1])             # آخر صف، العمود الثاني
print(products.iloc[:3, :2])            # أول 3 صفوف وأول عمودين
```

```output
category    Electronics
price              3200
cost               2600
Name: Laptop, dtype: object
130
               category  price
product                       
Laptop      Electronics   3200
Headphones  Electronics    250
Monitor     Electronics    900
```

### التقطيع بالأسماء يشمل النهاية

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
print(products.loc["Monitor":"Mouse", "price":"cost"])
```

```output
          price  cost
product              
Monitor     900   650
Keyboard    180    90
Mouse        95    40
```

`"Monitor":"Mouse"` شمل `Mouse`، بعكس `iloc[2:5]` التي لا تشمل 5.

## loc مع الشروط

`loc` تقبل **قناع True/False** مكان الصفوف، وهذا أهم استخداماتها: اختيار صفوف بشرط **وأعمدة** محددة معاً:

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
print(products.loc[products["price"] > 500, ["category", "price"]])
```

```output
            category  price
product                    
Laptop   Electronics   3200
Monitor  Electronics    900
Desk       Furniture   1100
Chair      Furniture    750
```

## التعديل بـ loc

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
products.loc["Mouse", "price"] = 110                          # خلية واحدة
products.loc[products["category"] == "Furniture", "price"] -= 50    # خصم 50 ريالاً على الأثاث
products["margin"] = products["price"] - products["cost"]
print(products.loc[["Mouse", "Desk", "Lamp"], ["price", "margin"]])
```

```output
         price  margin
product               
Mouse      110      70
Desk      1050     350
Lamp        80      20
```

> ⚠️ لا تكتب `df[df["a"] > 5]["b"] = 0`: هذا "تعيين متسلسل" قد يعدّل نسخة مؤقتة لا الجدول الأصلي، وتظهر معه تحذيرات `SettingWithCopyWarning`. الصحيح دائماً: `df.loc[df["a"] > 5, "b"] = 0`.

## at و iat: خلية واحدة بسرعة

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
print(products.at["Chair", "cost"], products.iat[0, 1])
```

```output
420 3200
```

## ملخص الدرس

- `loc[صفوف, أعمدة]` بالأسماء ونهاية التقطيع مشمولة، و `iloc` بالمواضع ونهايتها غير مشمولة.
- `loc` تقبل قناعاً منطقياً: `df.loc[شرط, ["a", "b"]]`.
- للتعديل استخدم `df.loc[شرط, "col"] = قيمة` وليس التعيين المتسلسل.
- `at` و `iat` لخلية واحدة.

--- quiz
? ما الفرق الأساسي بين `loc` و `iloc`؟
+ loc بالأسماء (والنهاية مشمولة)، و iloc بالمواضع الرقمية (والنهاية غير مشمولة)
- لا فرق
- iloc للأعمدة فقط
> loc = label، و iloc = integer location.

? ما الطريقة الصحيحة لتصفير عمود "b" في الصفوف التي فيها a > 5؟
+ `df.loc[df["a"] > 5, "b"] = 0`
- `df[df["a"] > 5]["b"] = 0`
- `df["b"][df["a"] > 5] == 0`
> التعيين المتسلسل قد يعدل نسخة مؤقتة.

? كم صفاً يُرجع `df.iloc[2:5]`؟
+ 3 صفوف (المواضع 2 و 3 و 4)
- 4 صفوف
- صفين
> النهاية غير مشمولة في iloc.

## التصفية بالشروط

أكثر ما تفعله في التحليل: "أريد فقط الصفوف التي...". الفكرة نفسها التي تعلمتها في NumPy: شرط ← قناع ← صفوف.

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
big = orders[orders["qty"] >= 4]
print(len(big), "طلبات كبيرة")

riyadh_laptops = orders[(orders["city"] == "Riyadh") & (orders["product"] == "Laptop")]
print(riyadh_laptops[["order_id", "date", "qty"]])
```

```output
33 طلبات كبيرة
     order_id        date  qty
12       1013  2024-01-20    3
22       1023  2024-02-03    4
51       1052  2024-03-17    1
91       1092  2024-05-18    5
116      1117  2024-06-24    1
```

تذكر: `&` (و) و `|` (أو) و `~` (نفي)، وكل شرط بين **أقواس**.

## isin و between

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
west = orders[orders["city"].isin(["Jeddah", "Mecca", "Medina"])]
print(west["city"].value_counts().to_dict())

mid = orders[orders["unit_price"].between(100, 1000)]
print(mid["product"].unique())

not_delivered = orders[~(orders["status"] == "delivered")]
print(len(not_delivered))
```

```output
{'Jeddah': 40, 'Medina': 13, 'Mecca': 11}
['Keyboard' 'Headphones' 'Chair' 'Lamp' 'Monitor']
20
```

- `isin([...])` بدلاً من سلسلة `|` طويلة.
- `between(a, b)` يشمل الطرفين.

## query: صيغة أوضح

`query` تكتب الشرط كنص، وهي أسهل قراءة مع الشروط الطويلة:

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
limit = 3
result = orders.query("city == 'Jeddah' and qty > @limit and status == 'delivered'")
print(result[["order_id", "product", "qty"]])
```

```output
     order_id   product  qty
1        1002     Mouse    5
8        1009  Keyboard    5
14       1015     Chair    5
39       1040      Desk    5
48       1049     Chair    5
55       1056    Laptop    4
74       1075   Monitor    4
87       1088     Mouse    5
112      1113     Chair    5
```

- داخل `query` استخدم `and` و `or` و `not` العادية.
- `@limit` يشير إلى متغير Python خارج النص.

## العدّ والنسب بالشروط

بما أن `True` تساوي 1، فمجموع القناع **عدد**، ومتوسطه **نسبة**:

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
cancelled = orders["status"] == "cancelled"
print("ملغاة:", cancelled.sum(), "| النسبة:", round(cancelled.mean() * 100, 1), "%")
print("أي طلب بكمية 5؟", (orders["qty"] == 5).any())
```

```output
ملغاة: 10 | النسبة: 8.3 %
أي طلب بكمية 5؟ True
```

## ملخص الدرس

- `df[شرط]` للتصفية، مع `&` و `|` و `~` والأقواس.
- `isin` لقائمة قيم، و `between` لنطاق، و `.str.contains/startswith` للنصوص.
- `query("...")` صيغة نصية مقروءة، و `@var` للمتغيرات.
- `mask.sum()` عدد، و `mask.mean()` نسبة، و `mask.any()` هل يوجد.

## الأكبر والأصغر: nlargest و nsmallest

أسرع وأوضح من الترتيب ثم `head`:

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
print(orders.nlargest(3, "total")[["order_id", "product", "qty", "total"]])
print(orders.nsmallest(2, "total")[["order_id", "product", "total"]])
```

## ترتيب الفهرس وإعادة ضبطه

```python
import pandas as pd

products = pd.read_csv("products.csv", index_col="product")
by_name = products.sort_index()
print(by_name.index.tolist())

top = products.sort_values("price", ascending=False).head(3).reset_index()
print(top[["product", "price"]])
```

```output
['Chair', 'Desk', 'Headphones', 'Keyboard', 'Lamp', 'Laptop', 'Monitor', 'Mouse']
   product  price
0   Laptop   3200
1     Desk   1100
2  Monitor    900
```

- `sort_index()` يرتب حسب الفهرس.
- بعد الترتيب أو التصفية يبقى الفهرس الأصلي مبعثراً. `reset_index()` يعيد ترقيمه من 0 (ويحوّل الفهرس القديم لعمود، أو `drop=True` لحذفه).

## الترتيب النسبي rank

```python
import pandas as pd

scores = pd.DataFrame({"name": ["Layla", "Omar", "Huda", "Fahad", "Sara"],
                       "score": [88, 95, 88, 70, 99]})
scores["rank"] = scores["score"].rank(ascending=False, method="min").astype(int)
scores.sort_values("rank")
```

```output
    name  score  rank
4   Sara     99     1
1   Omar     95     2
0  Layla     88     3
2   Huda     88     3
3  Fahad     70     5
```

`method="min"`: المتساويان (ليلى وهدى) يأخذان نفس المرتبة 3، والتالي يأخذ 5، كما في ترتيب المسابقات.

## ملخص الدرس

- `sort_values("col", ascending=False)` للترتيب، ويقبل قائمة أعمدة وقائمة اتجاهات.
- `nlargest(n, "col")` و `nsmallest` لأعلى وأقل n قيم.
- `sort_index()` لترتيب الفهرس، و `reset_index(drop=True)` لإعادة الترقيم.
- `rank()` لحساب المرتبة مع التعامل مع التساوي.
