## groupby: التجميع

أهم سؤال في التحليل: **"ما المجموع/المتوسط لكل ...؟"** لكل مدينة، لكل منتج، لكل شهر. هذا عمل `groupby`، ويتبع نمطاً يسمى **قسّم ← طبّق ← اجمع (Split-Apply-Combine)**:

1. **قسّم** الصفوف إلى مجموعات حسب عمود.
2. **طبّق** دالة على كل مجموعة (مجموع، متوسط، عدد...).
3. **اجمع** النتائج في جدول واحد.

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
orders.groupby("city")["total"].sum().sort_values(ascending=False)
```

```output
city
Jeddah    64925
Riyadh    64410
Dammam    21490
Mecca     15400
Medina     7345
Name: total, dtype: int64
```

اقرأها هكذا: "جمّع الطلبات حسب المدينة، ثم خذ عمود الإجمالي، ثم اجمعه".

## transform: النتيجة بحجم الجدول الأصلي

`agg` يُرجع صفاً لكل مجموعة، أما `transform` فيُرجع قيمة **لكل صف** في الجدول الأصلي. مفيد لمقارنة كل صف بمجموعته:

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
orders["city_avg"] = orders.groupby("city")["total"].transform("mean").round(0)
orders["above_avg"] = orders["total"] > orders["city_avg"]
print(orders[["city", "total", "city_avg", "above_avg"]].head(4))
```

```output
     city  total  city_avg  above_avg
0  Dammam    180     977.0      False
1  Jeddah    475    1623.0      False
2  Riyadh    180    1894.0      False
3  Jeddah    250    1623.0      False
```

## ملخص الدرس

- `df.groupby("col")["val"].sum()`: قسّم ← طبّق ← اجمع.
- `size()` لعدد الصفوف في كل مجموعة، و `count()` للقيم غير المفقودة.
- `agg(name=("col", "func"), ...)` لعدة مقاييس بأسماء واضحة.
- التجميع بعدة أعمدة يعطي فهرساً متعدداً، و `unstack()` يحوّله لجدول.
- `transform` يُرجع قيمة المجموعة لكل صف.

## الجداول المحورية pivot_table

إذا كنت تعرف **الجدول المحوري (Pivot Table)** في Excel، فهذا هو نفسه في Pandas: صفوف من عمود، وأعمدة من عمود آخر، وقيم مجمّعة في التقاطع.

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
pd.pivot_table(orders, index="city", columns="status", values="total", aggfunc="sum", fill_value=0)
```

```output
status  cancelled  delivered  returned
city                                  
Dammam       1230      16660      3600
Jeddah       4550      60150       225
Mecca         180      15220         0
Medina        475       6040       830
Riyadh        190      62610      1610
```

| المعامل | يقابله في Excel |
|---|---|
| `index` | Rows (الصفوف) |
| `columns` | Columns (الأعمدة) |
| `values` | Values (القيم) |
| `aggfunc` | Summarize by (طريقة التجميع) |
| `margins=True` | Grand Total (الإجمالي) |

## من العريض إلى الطويل: melt

الجدول المحوري يحوّل البيانات من **طويلة** (صف لكل عملية) إلى **عريضة** (عمود لكل شهر). أحياناً تحتاج العكس، خاصة لأدوات الرسم:

```python
import pandas as pd

wide = pd.DataFrame({"branch": ["Riyadh", "Jeddah"], "Jan": [120, 90], "Feb": [135, 95], "Mar": [150, 70]})
long = wide.melt(id_vars="branch", var_name="month", value_name="sales")
print(long)
print(long.pivot(index="branch", columns="month", values="sales"))
```

## ملخص الدرس

- `pd.pivot_table(df, index=, columns=, values=, aggfunc=)` الجدول المحوري كما في Excel.
- `fill_value=0` للخانات الفارغة، و `margins=True` للإجماليات.
- `pd.crosstab(a, b)` لجداول التكرار، و `normalize="index"` للنسب.
- `melt` من العريض للطويل، و `pivot` من الطويل للعريض دون تجميع.

## الدمج merge

البيانات الحقيقية موزعة على عدة جداول، تماماً كقواعد البيانات: الطلبات في جدول، وتفاصيل المنتجات في آخر، والعملاء في ثالث. `merge` يربطها بعمود مشترك، مثل `JOIN` في SQL:

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
products = pd.read_csv("products.csv")
full = orders.merge(products[["product", "category", "cost"]], on="product", how="left")
print(full[["order_id", "product", "category", "cost"]].head(4))
print(orders.shape, "→", full.shape)
```

```output
   order_id     product     category  cost
0      1001    Keyboard  Accessories    90
1      1002       Mouse  Accessories    40
2      1003    Keyboard  Accessories    90
3      1004  Headphones  Electronics   140
(120, 8) → (120, 10)
```

الآن يمكنك حساب الربح، والتجميع حسب الفئة، وهو ما لم يكن ممكناً من جدول الطلبات وحده:

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
products = pd.read_csv("products.csv")
full = orders.merge(products[["product", "category", "cost"]], on="product", how="left")
full["profit"] = (full["unit_price"] - full["cost"]) * full["qty"]
full.groupby("category")["profit"].sum().sort_values(ascending=False)
```

```output
category
Furniture      24210
Electronics    22910
Accessories     7320
Name: profit, dtype: int64
```

## أنواع الدمج how

```python
import pandas as pd

students = pd.DataFrame({"id": [1, 2, 3], "name": ["Layla", "Omar", "Huda"]})
grades = pd.DataFrame({"id": [2, 3, 4], "grade": [88, 95, 70]})

for how in ["inner", "left", "right", "outer"]:
    print(how, "→", students.merge(grades, on="id", how=how).to_dict("records"))
```

```output
inner → [{'id': 2, 'name': 'Omar', 'grade': 88}, {'id': 3, 'name': 'Huda', 'grade': 95}]
left → [{'id': 1, 'name': 'Layla', 'grade': nan}, {'id': 2, 'name': 'Omar', 'grade': 88.0}, {'id': 3, 'name': 'Huda', 'grade': 95.0}]
right → [{'id': 2, 'name': 'Omar', 'grade': 88}, {'id': 3, 'name': 'Huda', 'grade': 95}, {'id': 4, 'name': nan, 'grade': 70}]
outer → [{'id': 1, 'name': 'Layla', 'grade': nan}, {'id': 2, 'name': 'Omar', 'grade': 88.0}, {'id': 3, 'name': 'Huda', 'grade': 95.0}, {'id': 4, 'name': nan, 'grade': 70.0}]
```

| `how=` | يُبقي | يقابله في SQL |
|---|---|---|
| `"inner"` (الافتراضي) | المتطابق في الجدولين فقط | `INNER JOIN` |
| `"left"` | كل صفوف الأيسر | `LEFT JOIN` |
| `"right"` | كل صفوف الأيمن | `RIGHT JOIN` |
| `"outer"` | كل الصفوف من الجدولين | `FULL OUTER JOIN` |

## أسماء أعمدة مختلفة، والتحقق

```python
import pandas as pd

orders = pd.read_csv("orders.csv")
customers = pd.read_csv("customers.csv").rename(columns={"customer_id": "id", "city": "home_city"})
m = orders.merge(customers, left_on="customer_id", right_on="id", how="left",
                 validate="many_to_one", indicator=True)
print(m["_merge"].value_counts().to_dict())
print(m.groupby("segment")["order_id"].count().to_dict())
```

```output
{'both': 120, 'left_only': 0, 'right_only': 0}
{'Premium': 45, 'Regular': 75}
```

- `left_on` و `right_on` عندما يختلف اسم العمود في الجدولين.
- `validate="many_to_one"`: تحقق أن كل عميل يظهر **مرة واحدة** في جدول العملاء، وإلا خطأ. يحميك من التكرار الصامت.
- `indicator=True` يضيف عمود `_merge` يبيّن مصدر كل صف: مفيد لاكتشاف الصفوف التي لم تتطابق.

> ⚠️ أخطر خطأ في الدمج: مفتاح مكرر في الجدول الأيمن **يضاعف** الصفوف. قارن دائماً عدد الصفوف قبل الدمج وبعده.

## join: الدمج بالفهرس

```python
import pandas as pd

prices = pd.read_csv("products.csv", index_col="product")[["price"]]
stock = pd.DataFrame({"stock": [5, 0, 40]}, index=["Laptop", "Mouse", "Lamp"])
print(stock.join(prices))
```

```output
        stock  price
Laptop      5   3200
Mouse       0     95
Lamp       40    130
```

## ملخص الدرس

- `a.merge(b, on="key", how="left")` لربط الجداول بعمود مشترك.
- `inner` و `left` و `right` و `outer` مثل أنواع JOIN في SQL.
- `left_on` و `right_on` للأسماء المختلفة، و `validate` و `indicator` للتحقق.
- `join` للدمج حسب الفهرس.

## concat: الإلحاق

`merge` يربط جداول **مختلفة** جنباً إلى جنب. أما `concat` فيُلحق جداول **بنفس الأعمدة** فوق بعضها، مثل ملف مبيعات لكل شهر تريد جمعها في جدول واحد:

```python
import pandas as pd

jan = pd.DataFrame({"branch": ["Riyadh", "Jeddah"], "sales": [120, 90]})
feb = pd.DataFrame({"branch": ["Riyadh", "Jeddah", "Dammam"], "sales": [135, 95, 40]})
all_months = pd.concat([jan, feb], ignore_index=True)
all_months
```

```output
   branch  sales
0  Riyadh    120
1  Jeddah     90
2  Riyadh    135
3  Jeddah     95
4  Dammam     40
```

`ignore_index=True` يعيد الترقيم، وإلا تكررت الفهارس (0، 1، 0، 1، 2).

### تمييز المصدر

```python
import pandas as pd

jan = pd.DataFrame({"branch": ["Riyadh", "Jeddah"], "sales": [120, 90]})
feb = pd.DataFrame({"branch": ["Riyadh", "Jeddah", "Dammam"], "sales": [135, 95, 40]})
combined = pd.concat([jan.assign(month="Jan"), feb.assign(month="Feb")], ignore_index=True)
print(combined)
print(combined.groupby("branch")["sales"].sum().to_dict())
```

```output
   branch  sales month
0  Riyadh    120   Jan
1  Jeddah     90   Jan
2  Riyadh    135   Feb
3  Jeddah     95   Feb
4  Dammam     40   Feb
{'Dammam': 40, 'Jeddah': 185, 'Riyadh': 255}
```

`assign(month="Jan")` يضيف عموداً ثابتاً قبل الإلحاق، لتعرف مصدر كل صف.

## أعمدة غير متطابقة

```python
import pandas as pd

a = pd.DataFrame({"name": ["Layla"], "age": [28]})
b = pd.DataFrame({"name": ["Omar"], "city": ["Jeddah"]})
print(pd.concat([a, b], ignore_index=True))
print(pd.concat([a, b], join="inner", ignore_index=True))
```

```output
    name   age    city
0  Layla  28.0     NaN
1   Omar   NaN  Jeddah
    name
0  Layla
1   Omar
```

العمود الناقص يُملأ بـ `NaN`، و `join="inner"` يُبقي الأعمدة المشتركة فقط.

## قراءة عدة ملفات وإلحاقها

السيناريو الأكثر شيوعاً في العمل: مجلد فيه ملف لكل شهر أو فرع:

```python
import pandas as pd
import glob

orders = pd.read_csv("orders.csv")
for q, months in {"q1": ["01", "02", "03"], "q2": ["04", "05", "06"]}.items():
    part = orders[orders["date"].str[5:7].isin(months)]
    part.to_csv(f"orders_2024_{q}.csv", index=False)

files = sorted(glob.glob("orders_2024_q*.csv"))
print(files)
merged = pd.concat((pd.read_csv(f).assign(source=f) for f in files), ignore_index=True)
print(merged.shape, merged.groupby("source").size().to_dict())
```

```output
['orders_2024_q1.csv', 'orders_2024_q2.csv']
(120, 9) {'orders_2024_q1.csv': 61, 'orders_2024_q2.csv': 59}
```

## أفقياً: axis=1

```python
import pandas as pd

names = pd.Series(["Layla", "Omar"], name="name")
scores = pd.Series([88, 95], name="score")
pd.concat([names, scores], axis=1)
```

```output
    name  score
0  Layla     88
1   Omar     95
```

مع `axis=1` تُلصق الأعمدة جنباً إلى جنب حسب الفهرس. (لربط الجداول بعمود مشترك استخدم `merge` دائماً.)

## ملخص الدرس

- `pd.concat([a, b], ignore_index=True)` لإلحاق جداول بنفس الأعمدة.
- `assign(col=value)` قبل الإلحاق لتمييز المصدر.
- الأعمدة غير المشتركة تُملأ بـ `NaN`، و `join="inner"` للمشتركة فقط.
- `glob` + `concat` لجمع ملفات كثيرة، و `axis=1` للإلصاق الأفقي.

لديك مبيعات ثلاثة فروع في ثلاثة جداول منفصلة:

1. `all_sales`: ألحقها في جدول واحد مع عمود `branch` يحمل اسم الفرع (`Riyadh` و `Jeddah` و `Dammam`)، وأعد الترقيم.
2. `totals`: مجموع `amount` لكل فرع كقاموس.

~~~starter

~~~
~~~solution
import pandas as pd

riyadh = pd.DataFrame({"day": ["Sun", "Mon", "Tue"], "amount": [500, 650, 420]})
jeddah = pd.DataFrame({"day": ["Sun", "Mon", "Tue"], "amount": [380, 300, 610]})
dammam = pd.DataFrame({"day": ["Sun", "Mon", "Tue"], "amount": [150, 220, 190]})

all_sales = pd.concat([riyadh.assign(branch="Riyadh"), jeddah.assign(branch="Jeddah"),
                       dammam.assign(branch="Dammam")], ignore_index=True)
totals = all_sales.groupby("branch")["amount"].sum().to_dict()
best_day = all_sales.groupby("day")["amount"].sum().idxmax()
wide = all_sales.pivot(index="day", columns="branch", values="amount")
~~~

--- quiz
? ما الفرق بين concat و merge؟
+ concat يُلحق جداول متشابهة فوق بعضها، و merge يربط جداول مختلفة بعمود مشترك
- لا فرق
- merge أسرع دائماً
> concat = إلحاق، و merge = ربط.

? ماذا يحدث عند إلحاق جدولين أحدهما فيه عمود لا يوجد في الآخر؟
+ يظهر العمود وقيمه NaN في صفوف الجدول الذي لا يحتويه
- خطأ
- يُحذف العمود
> إلا إذا استخدمت join="inner".

? لماذا `ignore_index=True` مع concat؟
+ لإعادة ترقيم الصفوف بدلاً من تكرار فهارس الجداول الأصلية
- لتجاهل القيم المفقودة
- لحذف التكرار
> بدونها قد تجد صفين بالفهرس 0.
