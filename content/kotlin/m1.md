## لغة Android الرسمية

**Kotlin** لغة حديثة طورتها شركة JetBrains عام 2011، وأعلنتها Google عام 2019 **اللغة المفضلة لتطوير Android**. اليوم أكثر من 95% من أفضل تطبيقات Android تستخدمها، وتُستخدم أيضاً في الخوادم (مع Spring Boot) وفي التطبيقات متعددة المنصات (Kotlin Multiplatform).

لماذا يحبها المطورون؟

- **مختصرة:** تكتب أقل بكثير مما تكتبه في Java لنفس النتيجة.
- **آمنة:** نظام يحميك من أخطاء `null` الشهيرة.
- **متوافقة مع Java:** تستخدم أي مكتبة Java مباشرة.
- **حديثة:** دوال مجهولة، و Coroutines للبرمجة غير المتزامنة، ودوال امتداد.

## أول برنامج

```kotlin
fun main() {
    println("مرحباً بالعالم!")
}
```

```output
مرحباً بالعالم!
```

- `fun` تعريف دالة، و `main` نقطة بداية البرنامج.
- `println` تطبع ثم تنتقل لسطر جديد، و `print` تطبع دون سطر جديد.
- **لا حاجة للفاصلة المنقوطة** في نهاية الأسطر.

## الطباعة والقوالب النصية

```kotlin
fun main() {
    val language = "Kotlin"
    val year = 2011
    println("أتعلم $language")
    println("عمرها ${2026 - year} سنة")
    print("بدون ")
    print("سطر جديد")
    println()
    println("عدد الأحرف: ${language.length}")
}
```

```output
أتعلم Kotlin
عمرها 15 سنة
بدون سطر جديد
عدد الأحرف: 6
```

`$name` لإدراج متغير في النص، و `${...}` لأي تعبير.

## val و var

في Kotlin نوعان من المتغيرات:

```kotlin
fun main() {
    val name = "ريم"
    var score = 10
    score += 5
    println("$name: $score")
}
```

```output
ريم: 15
```

| الكلمة | المعنى |
|---|---|
| `val` | قيمة **لا يمكن إعادة إسنادها** (من value) |
| `var` | متغير **يمكن تغييره** (من variable) |

```kotlin
fun main() {
    val pi = 3.14
    pi = 3.0
}
```

```output
ERR: line 3: 'val' cannot be reassigned.
```

> 💡 القاعدة في Kotlin: استخدم `val` دائماً، وانتقل إلى `var` فقط عندما تحتاج التغيير فعلاً. هذا يجعل الكود أوضح وأكثر أماناً.

## الأنواع

Kotlin تستنتج النوع تلقائياً، ويمكنك كتابته صراحة بعد نقطتين:

```kotlin
fun main() {
    val age: Int = 25
    val price: Double = 19.99
    val initial: Char = 'K'
    val isActive: Boolean = true
    val city: String = "جدة"
    val bigNumber: Long = 8_000_000_000

    println("$age $price $initial $isActive $city $bigNumber")
}
```

```output
25 19.99 K true جدة 8000000000
```

| النوع | يخزّن |
|---|---|
| `Int` | أعداد صحيحة (حتى حوالي 2 مليار) |
| `Long` | أعداد صحيحة كبيرة |
| `Double` | أعداد عشرية |
| `Float` | أعداد عشرية بدقة أقل، تنتهي بـ `f` |
| `Boolean` | `true` أو `false` |
| `Char` | حرف واحد بين `' '` |
| `String` | نص بين `" "` |

النوع ثابت بعد التعريف:

```kotlin
fun main() {
    var count = 5
    count = "خمسة"
}
```

```output
ERR: line 3: assignment type mismatch: actual type is 'String', but 'Int' was expected.
```

## العمليات والتحويل

```kotlin
fun main() {
    println(17 / 5)
    println(17 % 5)
    println(17.0 / 5)
    println(17 / 5.0)

    val text = "42"
    val number = text.toInt()
    println(number + 8)
    println("3.5".toDouble() * 2)
    println(100.toString() + "!")
    println("abc".toIntOrNull())
}
```

```output
3
2
3.4
3.4
50
7.0
100!
null
```

- قسمة عددين صحيحين `17 / 5` تعطي عدداً صحيحاً `3`. لنتيجة عشرية اجعل أحدهما `Double`.
- `toInt()` و `toDouble()` و `toString()` للتحويل.
- `toIntOrNull()` تُرجع `null` بدل الانهيار إذا لم يكن النص رقماً.

## النصوص متعددة الأسطر

```kotlin

    val poem = """
        السطر الأول
        السطر الثاني
    """.trimIndent()
    println(poem)
}
```

```output

السطر الثاني
```

## ملخص الدرس

- `val` للثوابت (المفضلة)، و `var` للمتغيرات.
- الأنواع: `Int` و `Long` و `Double` و `Boolean` و `Char` و `String`، وتُستنتج تلقائياً.
- قسمة الأعداد الصحيحة تُرجع عدداً صحيحاً.
- `toInt()` و `toIntOrNull()` و `toString()` للتحويل.

## وداعاً لـ NullPointerException

أشهر خطأ في عالم Java هو `NullPointerException`: محاولة استخدام شيء غير موجود. Kotlin تحل هذه المشكلة في **نظام الأنواع نفسه**.

## الأنواع لا تقبل null افتراضياً

```kotlin
fun main() {
    var name: String = "سلمى"
    name = null
}
```

```output
ERR: line 3: null cannot be a value of a non-null type 'String'.
```

`String` في Kotlin تعني "نص موجود دائماً". لذلك `name.length` آمن تماماً ولن ينهار أبداً.

## الأنواع القابلة لـ null: ?

```kotlin
fun main() {
    var nickname: String? = null
    println(nickname)
    nickname = "أبو خالد"
    println(nickname)
}
```

```output
null
أبو خالد
```

## المترجم يمنعك من الخطأ

```kotlin
fun main() {
    val email: String? = null
    println(email.length)
}
```

```output
ERR: line 3: only safe (?.) or non-null asserted (!!.) calls are allowed on a nullable receiver of type 'String?'.
```

يجب التعامل مع احتمال null أولاً. ولديك أدوات أنيقة:

## الاستدعاء الآمن ?.

```kotlin
fun main() {
    val city: String? = null
    println(city?.length)

    val country: String? = "السعودية"
    println(country?.length)
}
```

```output
null
8
```

`?.` تعني: إذا كانت القيمة null أرجع null، وإلا نفّذ.

## عامل إلفيس ?:

```kotlin
fun main() {
    val username: String? = null
    val display = username ?: "زائر"
    println("مرحباً $display")

    val input: String? = "abc"
    val age = input?.toIntOrNull() ?: 0
    println(age)
}
```

```output
مرحباً زائر
0
```

`a ?: b` تُرجع `a` إن لم تكن null، وإلا `b`. اسمه من شكله الذي يشبه تسريحة شعر إلفيس بريسلي `?:`

## الفحص بـ if: التحويل الذكي

```kotlin
fun main() {
    val text: String? = "Kotlin"
    if (text != null) {
        println(text.uppercase())
    }
}
```

```output
KOTLIN
```

بعد `if (text != null)`، يعرف المترجم أن `text` ليس null داخل الكتلة، فيحوّل نوعه تلقائياً إلى `String`. هذا يسمى **Smart Cast**.

## let مع ?.

```kotlin
fun main() {
    val phone: String? = "0500000000"
    phone?.let { println("سنرسل رسالة إلى $it") }

    val missing: String? = null
    missing?.let { println("لن يُطبع هذا") }
}
```

```output
سنرسل رسالة إلى 0500000000
```

`?.let { }` تنفّذ الكتلة فقط إذا لم تكن القيمة null، و `it` هي القيمة داخل الكتلة.

## عامل التأكيد !! (احذره)

```kotlin
fun main() {
    val token: String? = null
    println(token!!.length)
}
```

```output
ERR: Exception: java.lang.NullPointerException
```

`!!` تقول: "أنا متأكد أنها ليست null". وإذا كنت مخطئاً، ينهار البرنامج بـ `NullPointerException`.

> ⚠️ وجود `!!` في الكود علامة تحذير. في الغالب يوجد حل أفضل بـ `?.` أو `?:` أو `if`.

## ملخص الدرس

- الأنواع لا تقبل null إلا مع `?`: `String?`.
- `?.` استدعاء آمن، و `?:` قيمة بديلة (إلفيس).
- `if (x != null)` يحوّل النوع تلقائياً (Smart Cast).
- `?.let { }` لتنفيذ كود عند وجود القيمة فقط، و `!!` خطيرة.

--- exercise
اكتب دالة `greeting` تستقبل اسماً قد يكون `null` (`String?`) وتُرجع نصاً:

- إذا كان الاسم موجوداً: `مرحباً يا X (N أحرف)`
- إذا كان null: `مرحباً يا ضيف`

~~~starter
fun greeting(name: String?): String {
    return "مرحباً يا " + name.length
}

~~~

~~~solution
fun greeting(name: String?): String {
    return if (name != null) "مرحباً يا $name (${name.length} أحرف)" else "مرحباً يا ضيف"
}

fun main() {
    println(greeting("سلطان"))
    println(greeting(null))
}
~~~

## if كتعبير

في Kotlin، `if` **تُرجع قيمة**، لذلك لا يوجد عامل ثلاثي `? :`:

```kotlin
fun main() {
    val temperature = 34
    val feeling = if (temperature > 30) "حار" else "معتدل"
    println(feeling)

    val max = if (10 > 7) 10 else 7
    println(max)
}
```

```output
حار
10
```

## when: switch المحسّنة

`when` من أجمل ميزات Kotlin، وهي أقوى بكثير من switch:

```kotlin
fun main() {
    val day = 5
    val name = when (day) {
        1 -> "الأحد"
        2 -> "الاثنين"
        5 -> "الخميس"
        6, 7 -> "عطلة نهاية الأسبوع"
        else -> "يوم آخر"
    }
    println(name)

    val score = 82
    val grade = when {
        score >= 90 -> "ممتاز"
        score >= 80 -> "جيد جداً"
        score >= 60 -> "جيد"
        else -> "راسب"
    }
    println(grade)
}
```

```output
الخميس
جيد جداً
```

- `when (value)` تقارن قيمة بحالات، و `6, 7` حالتان لنفس النتيجة.
- `when { }` بدون قيمة: كل فرع شرط مستقل.
- `else` الحالة الافتراضية، وهي إلزامية عندما تُستخدم when كتعبير.

## when مع النطاقات والأنواع

```kotlin
fun describe(x: Any): String = when (x) {
    in 1..9 -> "رقم من خانة واحدة"
    is Int -> "عدد صحيح كبير"
    is String -> "نص طوله ${x.length}"
    else -> "شيء آخر"
}

fun main() {
    println(describe(7))
    println(describe(150))
    println(describe("مرحبا"))
    println(describe(true))
}
```

```output
رقم من خانة واحدة
عدد صحيح كبير
نص طوله 5
شيء آخر
```

- `in 1..9` هل القيمة ضمن النطاق.
- `is String` هل القيمة من هذا النوع، وبعدها يتحول النوع تلقائياً فنستخدم `x.length`.

## الحلقات والنطاقات

```kotlin
fun main() {
    for (i in 1..3) print("$i ")
    println()

    for (i in 1 until 4) print("$i ")
    println()

    for (i in 10 downTo 0 step 5) print("$i ")
    println()

    val fruits = listOf("تفاح", "موز")
    for (fruit in fruits) println(fruit)

    for ((index, fruit) in fruits.withIndex()) {
        println("$index: $fruit")
    }
}
```

```output
1 2 3 
1 2 3 
10 5 0 
تفاح
موز
0: تفاح
1: موز
```

| النطاق | يشمل |
|---|---|
| `1..5` | من 1 إلى 5 (يشمل الطرفين) |
| `1 until 5` | من 1 إلى 4 |
| `5 downTo 1` | تنازلي |
| `step 2` | القفز بخطوة |

```kotlin
fun main() {
    var balance = 100
    var months = 0

        balance -= 30
        months++
```


## ملخص الدرس

- `if` و `when` تعبيرات تُرجع قيمة.
- `when` تدعم القيم المتعددة، والنطاقات `in`، والأنواع `is`، والشروط.
- النطاقات `1..5` و `until` و `downTo` و `step`.
- `for (x in list)` و `withIndex()` للمرور مع الفهرس.
