## أضف دوالاً لأصناف لا تملكها

**دوال الامتداد (Extension Functions)** تتيح لك إضافة دوال جديدة لأي صنف، حتى أصناف Kotlin المدمجة مثل `String` و `Int`، دون تعديلها أو الوراثة منها:

```kotlin
fun String.isValidEmail(): Boolean = contains("@") && contains(".")

fun Int.isEven(): Boolean = this % 2 == 0

fun Double.toRiyal(): String = "%.2f ر.س".format(this)

fun main() {
    println("ali@mail.com".isValidEmail())
    println("ali-mail".isValidEmail())
    println(7.isEven())
    println(149.5.toRiyal())
}
```

```output
true
false
false
149.50 ر.س
```

- `fun String.name()` تعني: دالة جديدة لكل النصوص.
- داخل الدالة، `this` هي القيمة التي استُدعيت عليها الدالة، ويمكن حذفها: `contains("@")` تعني `this.contains("@")`.

## دوال امتداد مع معاملات

```kotlin
fun String.truncate(max: Int, suffix: String = "..."): String =
    if (length <= max) this else take(max) + suffix

fun List<Int>.secondLargest(): Int? = sortedDescending().drop(1).firstOrNull()

fun main() {
    println("تعلم البرمجة بلغة Kotlin".truncate(10))
    println("قصير".truncate(10))
    println(listOf(4, 9, 2, 7).secondLargest())
    println(listOf(5).secondLargest())
}
```

```output
تعلم البرم...
قصير
7
null
```

## خصائص الامتداد

```kotlin
val String.wordCount: Int
    get() = trim().split(" ").filter { it.isNotEmpty() }.size

val Int.minutes: Int
    get() = this * 60

fun main() {
    println("Kotlin لغة رائعة جداً".wordCount)
    println(5.minutes)
}
```

```output
4
300
```

## امتداد الأنواع القابلة لـ null

```kotlin
fun String?.orDash(): String = if (this.isNullOrBlank()) "—" else this

fun main() {
    val phone: String? = null
    val name: String? = "رهف"
    println(phone.orDash())
    println(name.orDash())
}
```

```output
—
رهف
```

يمكن استدعاء هذه الدالة حتى على `null` بأمان، لأنها معرّفة على `String?`.

## لماذا هي مهمة؟

مكتبات Android الحديثة (Android KTX) مبنية على الامتدادات، فتجعل الكود أقصر وأوضح:

```kotlin-error
// بدون امتدادات
view.setVisibility(View.GONE)
// مع Android KTX
view.isVisible = false
```

> 💡 الامتداد لا يعدّل الصنف فعلاً ولا يصل إلى خصائصه الخاصة (private). هو دالة عادية بصيغة أجمل.

## ملخص الدرس

- `fun Type.name()` يضيف دالة لأي نوع، و `this` هي القيمة المستدعى عليها.
- يمكن إضافة خصائص امتداد بـ `get()`.
- الامتداد على `Type?` يمكن استدعاؤه على null.
- لا يصل للأعضاء الخاصة، وهو تجميل للاستدعاء.

## دوال النطاق

Kotlin توفر خمس دوال صغيرة تسمى **دوال النطاق (Scope Functions)**: `let` و `run` و `with` و `apply` و `also`. كلها تنفّذ كتلة كود على كائن، والفرق في **كيف تشير للكائن** و**ماذا تُرجع**.

| الدالة | الإشارة للكائن | تُرجع | الاستخدام الأشهر |
|---|---|---|---|
| `let` | `it` | نتيجة الكتلة | التعامل مع null، وتحويل قيمة |
| `apply` | `this` | الكائن نفسه | تهيئة الكائنات |
| `also` | `it` | الكائن نفسه | إجراء جانبي كالطباعة والتسجيل |
| `run` | `this` | نتيجة الكتلة | حساب نتيجة من كائن |
| `with` | `this` | نتيجة الكتلة | استدعاء طرق كثيرة على كائن |

## let: مع null والتحويل

```kotlin
fun main() {
    val email: String? = "LAYAN@MAIL.COM"
    email?.let {
        println("سنرسل إلى ${it.lowercase()}")
    }

    val missing: String? = null
    val length = missing?.let { it.length } ?: 0
    println(length)

    val result = "  kotlin  ".let { it.trim().uppercase() }
    println(result)
}
```

```output
سنرسل إلى layan@mail.com
0
KOTLIN
```

## apply: تهيئة الكائنات

```kotlin
class Request {
    var url = ""
    var method = "GET"
    var timeout = 30
    override fun toString() = "$method $url (${timeout}s)"
}

fun main() {
    val request = Request().apply {
        url = "https://api.example.com/users"
        method = "POST"
        timeout = 10
    }
    println(request)
}
```

```output
POST https://api.example.com/users (10s)
```

داخل `apply` تكتب `url` مباشرة بدل `request.url`، والنتيجة هي الكائن نفسه بعد التهيئة. نمط شائع جداً في Android لتهيئة الكائنات والإعدادات.

## also: إجراء جانبي

```kotlin
fun main() {
    val numbers = mutableListOf(3, 1, 2)
        .also { println("قبل الترتيب: $it") }
        .apply { sort() }
        .also { println("بعد الترتيب: $it") }
    println(numbers.size)
}
```

```output
قبل الترتيب: [3, 1, 2]
بعد الترتيب: [1, 2, 3]
3
```

`also` لا تغيّر شيئاً في السلسلة، بل تضيف إجراءً جانبياً مثل التسجيل.

## run و with: حساب نتيجة

```kotlin
data class Rect(val width: Int, val height: Int)

fun main() {
    val rect = Rect(4, 6)

    val area = rect.run { width * height }
    println(area)

    val description = with(rect) {
        val perimeter = 2 * (width + height)
        "مستطيل ${width}×${height}، محيطه $perimeter"
    }
    println(description)
}
```

```output
24
مستطيل 4×6، محيطه 20
```

## كيف تختار؟

- قيمة قد تكون null؟ **`?.let`**
- تهيئة كائن جديد؟ **`apply`**
- طباعة أو تسجيل في منتصف سلسلة؟ **`also`**
- حساب نتيجة من خصائص كائن؟ **`run`** أو **`with`**

> ⚠️ لا تبالغ فيها. التداخل العميق بين دوال النطاق يجعل الكود صعب القراءة، وأحياناً يكون المتغير العادي أوضح.

## ملخص الدرس

- دوال النطاق تنفّذ كتلة على كائن، وتختلف في `it` أو `this` وفي القيمة المُرجعة.
- `let` لـ null والتحويل، و `apply` للتهيئة، و `also` للإجراءات الجانبية.
- `run` و `with` لحساب نتيجة من كائن.

--- exercise
1. أنشئ كائناً من الصنف `Profile` باستخدام `apply`: الاسم `عزيز`، والمدينة `تبوك`، والعمر `29`.
2. استخدم `also` لطباعة: `تم إنشاء: X`.
3. استخدم `let` على البريد الذي قد يكون null: إذا وُجد اطبع `البريد: X`، وإلا اطبع `لا يوجد بريد` (استخدم `?: println(...)`).
4. استخدم `run` لحساب واطباعة: `عزيز من تبوك، 29 سنة`.

~~~starter
class Profile {
    var name = ""
    var city = ""
    var age = 0
    var email: String? = null
}

fun main() {
    // أكمل هنا
}
~~~
~~~expected
تم إنشاء: عزيز
لا يوجد بريد
عزيز من تبوك، 29 سنة
~~~
~~~solution
class Profile {
    var name = ""
    var city = ""
    var age = 0
    var email: String? = null
}

fun main() {
    val profile = Profile().apply {
        name = "عزيز"
        city = "تبوك"
        age = 29
    }.also { println("تم إنشاء: ${it.name}") }

    profile.email?.let { println("البريد: $it") } ?: println("لا يوجد بريد")

    val summary = profile.run { "$name من $city، $age سنة" }
    println(summary)
}
~~~
