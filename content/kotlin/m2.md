## تعريف الدوال

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}

fun greet(name: String): String {
    return "أهلاً يا $name"
}

fun printLine() {
    println("----------")
}

fun main() {
    println(add(3, 4))
    println(greet("هيا"))
    printLine()
}
```

```output
7
أهلاً يا هيا
----------
```

- `fun name(param: Type): ReturnType` الصيغة الكاملة.
- الدالة التي لا تُرجع قيمة نوعها `Unit`، ويمكن حذفه كما في `printLine`.

## دوال التعبير الواحد

```kotlin
fun square(n: Int) = n * n
fun isEven(n: Int) = n % 2 == 0
fun max(a: Int, b: Int) = if (a > b) a else b

fun main() {
    println(square(9))
    println(isEven(7))
    println(max(12, 30))
}
```

```output
81
false
30
```

`= تعبير` بدل الأقواس و `return`، والنوع يُستنتج تلقائياً.

## القيم الافتراضية والمعاملات المسماة

```kotlin
fun createUser(name: String, age: Int = 18, city: String = "غير محددة") =
    "$name، $age سنة، $city"

fun main() {
    println(createUser("فيصل", 30, "أبها"))
    println(createUser("منيرة"))
    println(createUser("زياد", city = "جدة"))
    println(createUser(city = "مكة", name = "رنا"))
}
```

```output
فيصل، 30 سنة، أبها
منيرة، 18 سنة، غير محددة
زياد، 18 سنة، جدة
رنا، 18 سنة، مكة
```

- القيم الافتراضية تجعل المعاملات اختيارية.
- **المعاملات المسماة** `city = "جدة"` تسمح بتخطي بعض المعاملات، وبأي ترتيب. وهي تجعل الاستدعاء واضحاً جداً.

> 💡 في Jetpack Compose (واجهات Android الحديثة) ستستخدم المعاملات المسماة في كل مكان: `Text(text = "مرحبا", fontSize = 20.sp, color = Color.Blue)`.

## عدد متغير من المعاملات: vararg

```kotlin
fun sum(vararg numbers: Int): Int {
    var total = 0
    for (n in numbers) total += n
    return total
}

fun main() {
    println(sum(1, 2))
    println(sum(5, 10, 15, 20))
    println(sum())
}
```

```output
3
50
0
```

## ملخص الدرس

- `fun name(p: Type): Return { }` والدالة بلا قيمة إرجاع نوعها `Unit`.
- `fun f(x: Int) = x * 2` لدالة من تعبير واحد.
- القيم الافتراضية والمعاملات المسماة تغني عن تعريف دوال كثيرة متشابهة.
- `vararg` لعدد متغير من المعاملات.

--- exercise
اكتب دالة `calculatePrice` تُرجع `Double` وتستقبل:

- `price: Double` (إلزامي)
- `discount: Int = 0` نسبة الخصم بالمئة
- `tax: Int = 15` نسبة الضريبة بالمئة

النتيجة: السعر بعد الخصم، ثم تُضاف الضريبة. الاستدعاءات جاهزة وتستخدم المعاملات المسماة.

~~~starter
// اكتب الدالة هنا

fun main() {
    println(calculatePrice(100.0))
    println(calculatePrice(200.0, discount = 50))
    println(calculatePrice(tax = 0, price = 80.0, discount = 25))
}
~~~
~~~expected
115.0
115.0
60.0
~~~
~~~solution
fun calculatePrice(price: Double, discount: Int = 0, tax: Int = 15): Double {
    val afterDiscount = price * (100 - discount) / 100
    return afterDiscount * (100 + tax) / 100
}

fun main() {
    println(calculatePrice(100.0))
    println(calculatePrice(200.0, discount = 50))
    println(calculatePrice(tax = 0, price = 80.0, discount = 25))
}
~~~

## الدوال كقيم

**Lambda** دالة بلا اسم تُكتب بين أقواس معقوفة، ويمكن تخزينها في متغير:

```kotlin
fun main() {
    val multiply = { a: Int, b: Int -> a * b }
    println(multiply(6, 7))

    val greet: (String) -> String = { name -> "أهلاً $name" }
    println(greet("لمى"))

    val shout: (String) -> String = { it.uppercase() + "!" }
    println(shout("kotlin"))
}
```

```output
42
أهلاً لمى
KOTLIN!
```

- الصيغة: `{ المعاملات -> الجسم }`، وآخر سطر هو القيمة المُرجعة تلقائياً.
- `(String) -> String` **نوع الدالة**: تستقبل نصاً وتُرجع نصاً.
- إذا كان للـ lambda معامل واحد، يمكن حذفه واستخدام الاسم الضمني **`it`**.

## lambda متعددة الأسطر

```kotlin
fun main() {
    val describe = { score: Int ->
        val level = if (score >= 50) "ناجح" else "راسب"
        "الدرجة $score: $level"
    }
    println(describe(72))
    println(describe(40))
}
```

```output
الدرجة 72: ناجح
الدرجة 40: راسب
```

## مع المجموعات: الاستخدام الأشهر

```kotlin
fun main() {
    val prices = listOf(120, 45, 300, 80)

    val cheap = prices.filter { it < 100 }
    val doubled = prices.map { it * 2 }
    val total = prices.sum()

    println(cheap)
    println(doubled)
    println(total)
    prices.forEach { println("السعر: $it") }
}
```

```output
[45, 80]
[240, 90, 600, 160]
545
السعر: 120
السعر: 45
السعر: 300
السعر: 80
```

لاحظ أننا كتبنا `filter { ... }` دون أقواس عادية. هذه ميزة **Trailing Lambda**: إذا كانت الـ lambda آخر معامل، تُكتب خارج الأقواس.

## ملخص الدرس

- Lambda: `{ a: Int, b: Int -> a + b }` وآخر تعبير فيها هو القيمة المُرجعة.
- نوع الدالة: `(Int, Int) -> Int`.
- `it` اسم ضمني للمعامل الوحيد.
- الـ lambda الأخيرة تُكتب خارج الأقواس: `list.filter { it > 0 }`.

--- exercise
1. عرّف lambda اسمها `isAdult` من نوع `(Int) -> Boolean` تُرجع `true` إذا كان العمر 18 فأكثر.
2. عرّف lambda اسمها `format` تستقبل اسماً (String) وعمراً (Int) وتُرجع `X (N سنة)`.
3. صفِّ قائمة الأشخاص لتبقي البالغين فقط، واطبع كل منهم باستخدام `format`.

~~~starter
fun main() {
    val people = listOf("علي" to 25, "سما" to 15, "ماجد" to 40)
    // أكمل هنا
}
~~~
~~~expected
علي (25 سنة)
ماجد (40 سنة)
~~~
~~~solution
fun main() {
    val people = listOf("علي" to 25, "سما" to 15, "ماجد" to 40)
    val isAdult: (Int) -> Boolean = { it >= 18 }
    val format = { name: String, age: Int -> "$name ($age سنة)" }
    people.filter { isAdult(it.second) }
        .forEach { println(format(it.first, it.second)) }
}
~~~

## دوال تستقبل دوالاً

**الدالة من الرتبة العليا (Higher-Order Function)** دالة تستقبل دالة أخرى كمعامل، أو تُرجع دالة:

```kotlin
fun applyTwice(value: Int, operation: (Int) -> Int): Int {
    return operation(operation(value))
}

fun main() {
    println(applyTwice(3) { it + 10 })
    println(applyTwice(2) { it * it })
}
```

```output
23
16
```

## بناء أدواتك الخاصة

```kotlin
fun repeatAction(times: Int, action: (Int) -> Unit) {
    for (i in 1..times) action(i)
}

fun measure(label: String, block: () -> Int): Int {
    val result = block()
    println("$label = $result")
    return result
}

fun main() {
    repeatAction(3) { println("المحاولة $it") }
    measure("المجموع") { (1..100).sum() }
}
```

```output
المحاولة 1
المحاولة 2
المحاولة 3
المجموع = 5050
```

هكذا بُنيت دوال Kotlin القياسية نفسها، مثل `repeat(3) { }`.

## دوال تُرجع دوالاً

```kotlin
fun multiplier(factor: Int): (Int) -> Int = { it * factor }

fun counter(): () -> Int {
    var count = 0
    return { ++count }
}

fun main() {
    val double = multiplier(2)
    val triple = multiplier(3)
    println(double(7))
    println(triple(7))

    val next = counter()
    next()
    next()
    println(next())
}
```

```output
14
21
3
```

الـ lambda المُرجعة **تتذكر** المتغيرات المحيطة بها (`factor` و `count`)، وهذا يسمى **الإغلاق (Closure)**.

## مراجع الدوال ::

يمكن تمرير دالة موجودة باسمها مسبوقاً بـ `::`:

```kotlin
fun isPositive(n: Int) = n > 0
fun square(n: Int) = n * n

fun main() {
    val numbers = listOf(-2, 3, -1, 4)
    println(numbers.filter(::isPositive))
    println(numbers.map(::square))
}
```

```output
[3, 4]
[4, 9, 1, 16]
```

## في Android

ستمرر الدوال في كل مكان، مثلاً عند الضغط على زر في Jetpack Compose:

```kotlin-error
Button(onClick = { counter++ }) {
    Text("اضغط")
}
```

`onClick` معامل من نوع `() -> Unit`، والمحتوى نفسه lambda أخيرة تُكتب خارج الأقواس.

## ملخص الدرس

- الدالة من الرتبة العليا تستقبل دالة `(Int) -> Int` أو تُرجعها.
- الـ lambda الأخيرة تُكتب خارج الأقواس.
- الإغلاق: الدالة تتذكر متغيراتها المحيطة.
- `::functionName` لتمرير دالة موجودة.

--- exercise
اكتب دالة `transform` تستقبل `List<Int>` ودالة `(Int) -> Int`، وتُرجع قائمة جديدة بعد تطبيق الدالة على كل عنصر، **باستخدام حلقة for** وقائمة قابلة للتعديل `mutableListOf<Int>()`.

ثم استدعها مرتين بـ lambda: مرة للمضاعفة، ومرة للتربيع.

~~~starter
fun transform(numbers: List<Int>, fn: (Int) -> Int): List<Int> {
    // أكمل هنا
}

fun main() {
    val nums = listOf(1, 2, 3, 4)
    // اطبع النتيجتين
}
~~~
~~~expected
[2, 4, 6, 8]
[1, 4, 9, 16]
~~~
~~~solution
fun transform(numbers: List<Int>, fn: (Int) -> Int): List<Int> {
    val result = mutableListOf<Int>()
    for (n in numbers) result.add(fn(n))
    return result
}

fun main() {
    val nums = listOf(1, 2, 3, 4)
    println(transform(nums) { it * 2 })
    println(transform(nums) { it * it })
}
~~~
