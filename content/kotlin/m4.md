## للقراءة فقط أو قابلة للتعديل

Kotlin تفرّق بوضوح بين المجموعات **للقراءة فقط** والمجموعات **القابلة للتعديل**:

| للقراءة فقط | قابلة للتعديل |
|---|---|
| `listOf(...)` | `mutableListOf(...)` |
| `setOf(...)` | `mutableSetOf(...)` |
| `mapOf(...)` | `mutableMapOf(...)` |

```kotlin
fun main() {
    val fixed = listOf("أ", "ب")
    val tasks = mutableListOf("الدراسة")
    tasks.add("الرياضة")
    tasks.add(0, "الاستيقاظ")
    tasks.remove("الرياضة")
    println(fixed)
    println(tasks)
}
```

```output
[أ, ب]
[الاستيقاظ, الدراسة]
```

> 💡 ابدأ بالمجموعة للقراءة فقط، واستخدم `mutable` عندما تحتاج التعديل فعلاً، تماماً كقاعدة `val` و `var`.

## List

```kotlin
fun main() {
    val scores = listOf(90, 75, 88, 62)
    println(scores.size)
    println(scores[0])
    println(scores.first())
    println(scores.last())
    println(scores.getOrNull(10))
    println(scores.contains(88))
    println(88 in scores)
    println(scores.indexOf(75))
    println(scores.sorted())
    println(scores.reversed())
}
```

```output
4
90
90
62
null
true
true
1
[62, 75, 88, 90]
[62, 88, 75, 90]
```

`getOrNull` آمنة: تُرجع `null` بدل الانهيار عند فهرس غير موجود.

## Map

```kotlin
fun main() {
    val stock = mutableMapOf("قلم" to 40, "دفتر" to 15)
    stock["مسطرة"] = 8
    stock["قلم"] = (stock["قلم"] ?: 0) - 5

    println(stock)
    println(stock["دفتر"])
    println(stock["ممحاة"])
    println(stock.getOrDefault("ممحاة", 0))
    println(stock.keys)
    println(stock.values)

    for ((item, qty) in stock) {
        println("$item: $qty")
    }
}
```

```output
{قلم=35, دفتر=15, مسطرة=8}
15
null
0
[قلم, دفتر, مسطرة]
[35, 15, 8]
قلم: 35
دفتر: 15
مسطرة: 8
```

- `"قلم" to 40` تنشئ زوجاً (Pair).
- `map[key]` تُرجع نوعاً يقبل null، لأن المفتاح قد لا يوجد.

## Set

```kotlin
fun main() {
    val tags = mutableSetOf("kotlin", "android")
    tags.add("kotlin")
    tags.add("mobile")
    println(tags)
    println(tags.size)

    val a = setOf(1, 2, 3, 4)
    val b = setOf(3, 4, 5)
    println(a union b)
    println(a intersect b)
    println(a subtract b)

    println(listOf(1, 1, 2, 3, 3).toSet())
}
```

```output
[kotlin, android, mobile]
3
[1, 2, 3, 4, 5]
[3, 4]
[1, 2]
[1, 2, 3]
```

## ملخص الدرس

- `listOf` و `setOf` و `mapOf` للقراءة فقط، و `mutable...` للتعديل.
- `getOrNull` و `getOrDefault` للوصول الآمن.
- `"key" to value` تنشئ زوجاً في Map.
- Set لا تقبل التكرار، وتدعم `union` و `intersect` و `subtract`.

## قوة الأسلوب الوظيفي

مجموعات Kotlin تأتي بعشرات الدوال الجاهزة التي تغنيك عن كتابة الحلقات يدوياً.

## map و filter

```kotlin
fun main() {
    val prices = listOf(100, 250, 80, 40)
    println(prices.map { it * 2 })
    println(prices.filter { it >= 80 })
    println(prices.filterNot { it >= 80 })
    println(prices.mapIndexed { i, p -> "${i + 1}: $p" })
}
```

```output
[200, 500, 160, 80]
[100, 250, 80]
[40]
[1: 100, 2: 250, 3: 80, 4: 40]
```

## مع الكائنات: الاستخدام الحقيقي

```kotlin
data class Product(val name: String, val category: String, val price: Double)

fun main() {
    val products = listOf(
        Product("ساعة", "إلكترونيات", 900.0),
        Product("قميص", "ملابس", 120.0),
        Product("سماعة", "إلكترونيات", 250.0),
        Product("حذاء", "ملابس", 300.0)
    )

    println(products.sortedByDescending { it.price }.map { it.name })
    println(products.maxByOrNull { it.price }?.name)
    println(products.sumOf { it.price })

    val byCategory = products.groupBy { it.category }
    for ((category, items) in byCategory) {
        println("$category: ${items.map { it.name }}")
    }

    val (cheap, expensive) = products.partition { it.price < 200 }
    println("رخيص: ${cheap.size}، غالٍ: ${expensive.size}")

    println(products.associate { it.name to it.price })
}
```

```output
[ساعة, حذاء, سماعة, قميص]
ساعة
1570.0
إلكترونيات: [ساعة, سماعة]
ملابس: [قميص, حذاء]
رخيص: 1، غالٍ: 3
{ساعة=900.0, قميص=120.0, سماعة=250.0, حذاء=300.0}
```

| الدالة | الناتج |
|---|---|
| `sortedBy` و `sortedByDescending` | قائمة مرتبة حسب خاصية |
| `maxByOrNull` و `minByOrNull` | العنصر الأعلى أو الأدنى |
| `sumOf { }` | مجموع قيمة محسوبة |
| `groupBy { }` | `Map` من المجموعات |
| `partition { }` | قائمتان: ما يحقق الشرط وما لا يحققه |
| `associate { }` | `Map` من العناصر |
| `distinctBy { }` | حذف التكرار حسب خاصية |
| `take(n)` و `drop(n)` | أول n أو تخطي n |

- `map` و `filter` للتحويل والتصفية، و `sum` و `average` و `count` و `fold` للتجميع.
- `any` و `all` و `none` و `find` للبحث.

## التقييم الكسول

دوال المجموعات العادية **حريصة (Eager)**: كل خطوة تنشئ قائمة جديدة كاملة. مع `filter` ثم `map` ثم `take`، تُعالج كل العناصر في كل مرحلة حتى لو احتجت عنصرين فقط!

**Sequence** تعمل **بكسل (Lazy)**: تمرر كل عنصر عبر كل الخطوات واحداً بعد الآخر، وتتوقف عندما تحصل على ما تحتاجه.

## رؤية الفرق

```kotlin
fun main() {
    val numbers = listOf(1, 2, 3, 4, 5, 6)

    println("--- List ---")
    val a = numbers
        .map { println("map $it"); it * 2 }
        .filter { println("filter $it"); it > 4 }
        .first()
    println("النتيجة $a")

    println("--- Sequence ---")
    val b = numbers.asSequence()
        .map { println("map $it"); it * 2 }
        .filter { println("filter $it"); it > 4 }
        .first()
    println("النتيجة $b")
}
```

```output
--- List ---
map 1
map 2
map 3
map 4
map 5
map 6
filter 2
filter 4
filter 6
filter 8
filter 10
filter 12
النتيجة 6
--- Sequence ---
map 1
filter 2
map 2
filter 4
map 3
filter 6
النتيجة 6
```

- مع **List**: نُفّذت `map` على العناصر الستة كلها، ثم `filter` على الستة، ثم أُخذ الأول.
- مع **Sequence**: عنصر 1 مر بـ map ثم filter فرُفض، وعنصر 2 كذلك، وعنصر 3 نجح فتوقف كل شيء. **6 عمليات بدل 12**.

## سلاسل لا نهائية

لأنها كسولة، يمكن للـ Sequence أن تكون **بلا نهاية**:

```kotlin
fun main() {
    val evens = generateSequence(2) { it + 2 }
    println(evens.take(5).toList())

    val powers = generateSequence(1) { it * 2 }
        .takeWhile { it < 100 }
        .toList()
    println(powers)
}
```

```output
[2, 4, 6, 8, 10]
[1, 2, 4, 8, 16, 32, 64]
```

`generateSequence(بداية) { التالي }` تولّد عناصر عند الطلب فقط.

## متى أستخدم Sequence؟

| استخدم List | استخدم Sequence |
|---|---|
| مجموعات صغيرة إلى متوسطة | مجموعات ضخمة جداً |
| خطوة أو خطوتان | سلاسل طويلة من العمليات |
| تحتاج كل النتائج | تحتاج جزءاً منها (`first` و `take`) |
| | بيانات لا نهائية أو مولّدة |

> 💡 للمجموعات الصغيرة، List أسرع فعلياً بسبب تكلفة إدارة الكسل. لا تحوّل كل شيء إلى Sequence تلقائياً.

## العمليات الوسيطة والنهائية

```kotlin
fun main() {
    val seq = sequenceOf(5, 3, 8, 1).map { it * 10 }
    println("لم يُحسب شيء بعد")
    println(seq.sorted().toList())
}
```

```output
لم يُحسب شيء بعد
[10, 30, 50, 80]
```

- العمليات **الوسيطة** (`map` و `filter`) لا تنفّذ شيئاً، بل تبني الخطة.
- العمليات **النهائية** (`toList` و `first` و `sum` و `count`) هي التي تشغّل الحساب.

## ملخص الدرس

- Sequence كسولة: كل عنصر يمر بكل الخطوات، وتتوقف عند الحاجة.
- `asSequence()` للتحويل، و `generateSequence` للتوليد.
- مفيدة للبيانات الضخمة واللانهائية، و List أفضل للصغيرة.
- لا يحدث حساب حتى تُستدعى عملية نهائية.
