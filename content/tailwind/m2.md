## Flexbox

`flex` يرتب الأبناء في صف، ثم تتحكم في المحاذاة والتوزيع والمسافات:

```tw
<nav class="flex items-center justify-between bg-slate-900 text-white px-6 py-3">
  <span class="text-xl font-bold">CodeWay</span>
  <div class="flex gap-6 text-sm">
    <a href="#" class="hover:text-sky-300">الدورات</a>
    <a href="#" class="hover:text-sky-300">المسارات</a>
    <a href="#" class="hover:text-sky-300">الأسعار</a>
  </div>
  <button class="bg-sky-500 px-4 py-1.5 rounded-lg">دخول</button>
</nav>
```

| الصنف | CSS | الدور |
|---|---|---|
| `flex` | `display: flex` | تفعيل Flexbox |
| `flex-col` | `flex-direction: column` | عمودي بدل أفقي |
| `items-center` | `align-items: center` | محاذاة على المحور العرضي |
| `justify-between` | `justify-content: space-between` | توزيع على المحور الرئيسي |
| `justify-center` | `justify-content: center` | توسيط |
| `gap-4` | `gap: 1rem` | مسافة بين الأبناء |
| `flex-1` | `flex: 1` | يأخذ المساحة المتبقية |
| `flex-wrap` | `flex-wrap: wrap` | النزول لسطر جديد عند ضيق المساحة |
| `shrink-0` | `flex-shrink: 0` | يمنع انضغاط العنصر |

## توسيط أي شيء

أشهر سؤال في CSS، وجوابه في Tailwind ثلاثة أصناف:

```tw
<div class="flex items-center justify-center h-40 bg-gradient-to-l from-sky-500 to-indigo-600">
  <div class="bg-white px-6 py-3 rounded-xl font-bold">في المنتصف تماماً</div>
</div>
```

## عنصر يأخذ المساحة المتبقية

```tw
<div class="p-4">
  <div class="flex items-center gap-3 p-3 border rounded-xl max-w-md">
    <div class="size-12 rounded-full bg-amber-400 shrink-0"></div>
    <div class="flex-1">
      <p class="font-bold">سالم الحربي</p>
      <p class="text-sm text-gray-500">أرسل لك رسالة جديدة</p>
    </div>
    <span class="text-xs text-gray-400">5د</span>
  </div>
</div>
```

## Grid

`grid` مع `grid-cols-N` يقسم المساحة إلى أعمدة متساوية، مثالي لشبكات البطاقات:

```tw
<div class="grid grid-cols-3 gap-4 p-4">
  <div class="bg-rose-100 p-4 rounded-lg">1</div>
  <div class="bg-rose-100 p-4 rounded-lg">2</div>
  <div class="bg-rose-100 p-4 rounded-lg">3</div>
  <div class="bg-rose-200 p-4 rounded-lg col-span-2">col-span-2: عرض عمودين</div>
  <div class="bg-rose-100 p-4 rounded-lg">5</div>
</div>
```

| الصنف | الدور |
|---|---|
| `grid` | تفعيل Grid |
| `grid-cols-3` | ثلاثة أعمدة متساوية |
| `col-span-2` | العنصر يمتد على عمودين |
| `gap-4` / `gap-x-4` / `gap-y-8` | المسافات بين الخلايا |
| `place-items-center` | توسيط محتوى كل خلية |

## Flex أم Grid؟

- **Flex** لترتيب في اتجاه واحد: شريط تنقل، صف أزرار، عنصر بجانب نص.
- **Grid** للتخطيط في اتجاهين: شبكة بطاقات، معرض صور، هيكل صفحة.

## ملخص الدرس

- `flex` مع `items-*` و `justify-*` و `gap-*` للترتيب في اتجاه واحد.
- `flex items-center justify-center` يوسّط أي شيء.
- `flex-1` يأخذ المساحة المتبقية، و `shrink-0` يمنع الانضغاط.
- `grid grid-cols-N gap-*` للشبكات، و `col-span-N` للامتداد.

## الجوال أولاً (Mobile First)

أكثر من نصف زوار المواقع من الجوال. Tailwind يتبع مبدأ **الجوال أولاً**: الأصناف بدون بادئة تنطبق على كل الشاشات، والبادئات مثل `md:` تنطبق **من هذا العرض فما فوق**.

| البادئة | أقل عرض | الأجهزة المعتادة |
|---|---|---|
| (بدون) | 0 | كل الشاشات |
| `sm:` | 640px | جوال بالعرض |
| `md:` | 768px | جهاز لوحي |
| `lg:` | 1024px | حاسوب محمول |
| `xl:` | 1280px | شاشة كبيرة |
| `2xl:` | 1536px | شاشة كبيرة جداً |

```tw
<div class="p-4">
  <div class="p-4 rounded-lg text-white font-bold bg-rose-500 md:bg-amber-500 lg:bg-emerald-500">
    أحمر على الجوال، برتقالي من 768px، أخضر من 1024px
  </div>
</div>
```

> 💡 جرّب تصغير نافذة المتصفح وتكبيرها لترى الألوان تتغير، أو افتح الدرس على جوالك.

## اقرأها بالترتيب الصحيح

`text-xl md:text-3xl` لا تعني «text-xl على الجوال فقط»، بل: «text-xl للجميع، ثم من 768px فما فوق استبدلها بـ text-3xl». لذلك اكتب تصميم الجوال أولاً بلا بادئات، ثم أضف التعديلات للشاشات الأكبر.

## شبكة متجاوبة

أشهر نمط: عمود واحد على الجوال، وعمودان على اللوحي، وثلاثة أو أربعة على الحاسوب:

```tw
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4 p-4">
  <div class="bg-indigo-100 p-6 rounded-lg">منتج 1</div>
  <div class="bg-indigo-100 p-6 rounded-lg">منتج 2</div>
  <div class="bg-indigo-100 p-6 rounded-lg">منتج 3</div>
  <div class="bg-indigo-100 p-6 rounded-lg">منتج 4</div>
</div>
```

## الإظهار والإخفاء

`hidden` يخفي العنصر، و `md:flex` أو `md:block` يُظهره من عرض معيّن، والعكس بـ `md:hidden`:

```tw
<nav class="flex items-center justify-between bg-slate-900 text-white p-4">
  <span class="font-bold">CodeWay</span>
  <div class="hidden md:flex gap-6">
    <a href="#">الدورات</a><a href="#">المسارات</a><a href="#">الأسعار</a>
  </div>
  <button class="md:hidden text-2xl">☰</button>
</nav>
```

على الحاسوب تظهر الروابط، وعلى الجوال يظهر زر القائمة ☰ بدلاً منها.

## تخطيط يتغير اتجاهه

```tw
<div class="flex flex-col md:flex-row gap-6 p-4 items-center">
  <div class="size-32 rounded-2xl bg-gradient-to-br from-sky-400 to-indigo-500 shrink-0"></div>
  <div class="text-center md:text-start">
    <h2 class="text-2xl md:text-3xl font-bold">تعلّم البرمجة بالعربية</h2>
    <p class="text-gray-600 mt-2">الصورة فوق النص على الجوال، وبجانبه على الشاشات الأكبر.</p>
  </div>
</div>
```

## ملخص الدرس

- Tailwind يتبع الجوال أولاً: الأصناف بلا بادئة للجميع، والبادئات للشاشات الأكبر.
- `sm:` 640، و `md:` 768، و `lg:` 1024، و `xl:` 1280، و `2xl:` 1536.
- الشبكة المتجاوبة: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`.
- `hidden md:block` و `md:hidden` للإظهار والإخفاء، و `flex-col md:flex-row` لتغيير الاتجاه.

## الوضع الليلي

البادئة `dark:` تطبّق الصنف عندما يكون الوضع الليلي مفعلاً:

```tw
<div class="p-4 space-y-3">
  <div class="p-4 rounded-xl bg-white text-slate-900 border dark:bg-slate-900 dark:text-white dark:border-slate-700">
    بطاقة تتبع إعداد نظامك: فاتحة أو داكنة
  </div>
</div>
```

افتراضياً، Tailwind يتبع **إعداد نظام التشغيل** للمستخدم عبر `prefers-color-scheme`. إذا كان جهازك على الوضع الداكن ستظهر البطاقة داكنة.

## زر تبديل يدوي

معظم المواقع تضع زراً يختار به المستخدم الوضع بنفسه. لذلك نجعل `dark:` يعمل عند وجود الصنف `dark` على عنصر `html`، بسطر واحد في CSS:

```css
@custom-variant dark (&:where(.dark, .dark *));
```

في المعاينات نضعه في وسم `<style type="text/tailwindcss">`، وفي مشروعك الحقيقي تضعه في ملف CSS بعد `@import "tailwindcss";`:

```tw
<style type="text/tailwindcss">
  @custom-variant dark (&:where(.dark, .dark *));
</style>
<div class="p-4 bg-gray-100 dark:bg-gray-950 transition-colors">
  <button onclick="document.documentElement.classList.toggle('dark')"
    class="px-4 py-2 rounded-lg bg-slate-900 text-white dark:bg-yellow-300 dark:text-slate-900 font-bold">
    🌓 بدّل الوضع
  </button>
  <div class="mt-4 p-4 rounded-xl bg-white dark:bg-slate-800">
    <h3 class="font-bold text-slate-900 dark:text-white">عنوان البطاقة</h3>
    <p class="text-slate-600 dark:text-slate-300">النص يبقى مقروءاً في الوضعين.</p>
  </div>
</div>
```

اضغط الزر في المعاينة لترى التبديل.

## حفظ اختيار المستخدم

لتذكّر الاختيار بين الزيارات، احفظه في `localStorage` وطبّقه قبل ظهور الصفحة:

```js
// في <head> حتى لا تظهر الصفحة فاتحة ثم تتحول
const saved = localStorage.getItem("theme");
const prefersDark = matchMedia("(prefers-color-scheme: dark)").matches;
document.documentElement.classList.toggle("dark", saved === "dark" || (!saved && prefersDark));

function toggleTheme() {
  const isDark = document.documentElement.classList.toggle("dark");
  localStorage.setItem("theme", isDark ? "dark" : "light");
}
```

## نصائح للوضع الليلي

- لا تستخدم الأسود الخالص `bg-black` للخلفيات، فـ `bg-slate-900` و `bg-gray-950` أريح للعين.
- خفّف لون النصوص الثانوية: `text-gray-600 dark:text-gray-400`.
- الظلال لا تظهر على الخلفيات الداكنة، فاستخدم الإطارات `dark:border-gray-700` بدلاً منها.
- اختبر التباين في الوضعين.

## ملخص الدرس

- `dark:` يطبّق الصنف في الوضع الليلي.
- افتراضياً يتبع إعداد النظام، و `@custom-variant dark (&:where(.dark, .dark *));` يجعله يتبع الصنف `dark` على html.
- زر التبديل يضيف الصنف ويزيله، ويحفظ الاختيار في `localStorage`.
