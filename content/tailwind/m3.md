## لماذا نخصص Tailwind؟

لكل علامة تجارية ألوانها وخطوطها. بدل تكرار `bg-[#7c3aed]` في كل مكان، نعرّف لون العلامة مرة واحدة باسم، فيصبح صنفاً مثل أي صنف آخر: `bg-brand-600`. وإذا تغيّر اللون يوماً، تعدّله في مكان واحد.

## التخصيص في Tailwind v4: ‎@theme

في v4 تتم الإعدادات في ملف CSS نفسه، داخل `@theme`، بمتغيرات CSS:

```css
@import "tailwindcss";

@theme {
  --color-brand-500: #8b5cf6;
  --color-brand-600: #7c3aed;
  --font-display: "Cairo", sans-serif;
  --breakpoint-3xl: 1920px;
}
```

اسم المتغير يحدد الأصناف التي تولد منه:

| المتغير | الأصناف الناتجة |
|---|---|
| `--color-brand-600` | `bg-brand-600` و `text-brand-600` و `border-brand-600` ... |
| `--font-display` | `font-display` |
| `--breakpoint-3xl` | البادئة `3xl:` |
| `--spacing` | أساس مقياس المسافات (افتراضياً `0.25rem`) |
| `--radius-card` | `rounded-card` |
| `--shadow-soft` | `shadow-soft` |

في المعاينة:

```tw
<style type="text/tailwindcss">
  @theme {
    --color-brand-100: #ede9fe;
    --color-brand-600: #7c3aed;
    --radius-card: 18px;
  }
</style>
<div class="p-6">
  <div class="bg-brand-100 rounded-card p-6 max-w-sm">
    <h3 class="text-brand-600 text-xl font-bold">ألوان العلامة</h3>
    <button class="mt-3 bg-brand-600 text-white px-4 py-2 rounded-lg">bg-brand-600</button>
  </div>
</div>
```

## الاستبدال بدل الإضافة

`@theme` يضيف قيماً جديدة بجانب الافتراضية. لإلغاء لوحة الألوان الافتراضية كلها واستخدام ألوانك فقط:

```css
@theme {
  --color-*: initial;
  --color-white: #fff;
  --color-primary: #0ea5e9;
  --color-dark: #0f172a;
}
```

## الخطوط

لاستخدام خط من Google Fonts: حمّله في HTML، ثم عرّفه في `@theme`:

```html
<link href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;700&display=swap" rel="stylesheet">
```

```css
@theme {
  --font-sans: "Cairo", system-ui, sans-serif;  /* يغير الخط الافتراضي للموقع كله */
  --font-display: "Cairo", serif;              /* صنف جديد font-display */
}
```

## المقارنة مع Tailwind v3

في الإصدار 3 كانت الإعدادات في ملف JavaScript اسمه `tailwind.config.js`، وستجده في مشاريع كثيرة قائمة:

```js
// tailwind.config.js في v3
export default {
  content: ["./index.html", "./src/**/*.{js,jsx}"],
  theme: {
    extend: {
      colors: { brand: { 600: "#7c3aed" } },
      fontFamily: { display: ["Cairo", "sans-serif"] },
    },
  },
};
```

| | v3 | v4 |
|---|---|---|
| مكان الإعدادات | `tailwind.config.js` | `@theme` في CSS |
| تحديد الملفات المفحوصة | `content: [...]` | تلقائي |
| تفعيل Tailwind | `@tailwind base; @tailwind components; @tailwind utilities;` | `@import "tailwindcss";` |

> 💡 ميزة إضافية في v4: كل قيم `@theme` تصبح متغيرات CSS حقيقية، فتستطيع استخدامها في CSS عادي: `color: var(--color-brand-600);`.

## ملخص الدرس

- في v4 التخصيص في CSS داخل `@theme` بمتغيرات مثل `--color-brand-600`.
- اسم المتغير يحدد الأصناف: `--color-*` للألوان، و `--font-*` للخطوط، و `--breakpoint-*` للبادئات.
- `--color-*: initial;` يلغي الألوان الافتراضية.
- في v3 كانت الإعدادات في `tailwind.config.js` تحت `theme.extend`.

## مشكلة التكرار

بعد بناء عدة صفحات، ستلاحظ أن نفس مجموعة الأصناف تتكرر لكل زر:

```html
<button class="bg-blue-600 text-white px-4 py-2 rounded-lg font-semibold hover:bg-blue-700">حفظ</button>
<button class="bg-blue-600 text-white px-4 py-2 rounded-lg font-semibold hover:bg-blue-700">إرسال</button>
<button class="bg-blue-600 text-white px-4 py-2 rounded-lg font-semibold hover:bg-blue-700">تأكيد</button>
```

وإذا أردت تغيير شكل الأزرار، ستعدّل في عشرات الأماكن. هناك ثلاثة حلول، بالترتيب الذي توصي به وثائق Tailwind.

## الحل 1: المكونات والحلقات

في المشاريع الحقيقية تستخدم React أو Vue أو قوالب الخادم، فتكتب الأصناف **مرة واحدة** في مكون، وتستخدمه في كل مكان:

```jsx
function Button({ children }) {
  return (
    <button className="bg-blue-600 text-white px-4 py-2 rounded-lg font-semibold hover:bg-blue-700">
      {children}
    </button>
  );
}

<Button>حفظ</Button>
<Button>إرسال</Button>
```

وإذا تكرر العنصر في قائمة، فالحلقة تكتبه مرة واحدة أصلاً:

```js
const links = ["الدورات", "المسارات", "الأسعار"];
nav.innerHTML = links.map(l => `<a class="px-3 py-2 rounded hover:bg-gray-100">${l}</a>`).join("");
```

هذا هو الحل الأفضل: المكون يجمع الشكل والسلوك والمحتوى في مكان واحد.

## الحل 2: صنف خاص بـ ‎@apply

لعناصر صغيرة متكررة في HTML عادي، يمكن تعريف صنف يجمع أصناف Tailwind بـ `@apply` داخل `@layer components`:

```tw
<style type="text/tailwindcss">
  @layer components {
    .btn {
      @apply px-4 py-2 rounded-lg font-semibold transition-colors;
    }
    .btn-primary {
      @apply bg-blue-600 text-white hover:bg-blue-700;
    }
    .btn-outline {
      @apply border-2 border-blue-600 text-blue-600 hover:bg-blue-50;
    }
  }
</style>
<div class="p-6 flex gap-3">
  <button class="btn btn-primary">حفظ</button>
  <button class="btn btn-outline">إلغاء</button>
  <button class="btn btn-primary text-sm">أصغر قليلاً</button>
</div>
```

لاحظ الزر الأخير: يمكن إضافة أصناف Tailwind فوق صنفك لتعديل نسخة واحدة، لأن `@layer components` يأتي قبل الأصناف العادية في الأولوية.

## الحل 3: ‎@utility لأصناف جديدة

لإنشاء صنف «أداة» جديد يعمل مع البادئات مثل `hover:` و `md:`، استخدم `@utility` في v4:

```tw
<style type="text/tailwindcss">
  @utility content-auto {
    content-visibility: auto;
  }
  @utility text-shadow-soft {
    text-shadow: 0 2px 6px rgb(0 0 0 / 0.25);
  }
</style>
<div class="p-6 bg-sky-500">
  <h2 class="text-3xl font-bold text-white text-shadow-soft">عنوان بظل خفيف</h2>
</div>
```

## متى تستخدم @apply؟

> ⚠️ لا تحوّل كل شيء إلى `@apply`، وإلا رجعت إلى CSS التقليدي بأسمائه الكثيرة وخسرت مزايا Tailwind. استخدمه لعناصر صغيرة جداً تتكرر كثيراً (أزرار، حقول إدخال، شارات)، وفضّل المكونات لما هو أكبر.

## ملخص الدرس

- التكرار يُحل أولاً بالمكونات والحلقات: الأصناف تُكتب مرة واحدة.
- `@apply` داخل `@layer components` يعرّف صنفاً مثل `.btn` من أصناف Tailwind.
- `@utility` ينشئ صنف أداة جديداً يعمل مع البادئات.
- أصناف Tailwind العادية تتغلب على أصناف `@layer components`، فتعدّل بها نسخة واحدة.

--- exercise
عرّف مكوّن «شارة» داخل `@layer components`:

1. `.badge`: حشوة `px-3 py-1`، وزوايا `rounded-full`، وحجم `text-sm`، وخط `font-medium`.
2. `.badge-success`: خلفية `bg-green-100` ونص `text-green-800`.
3. `.badge-danger`: خلفية `bg-red-100` ونص `text-red-800`.

ثم استخدمها على الشارتين: الأولى `badge badge-success` والثانية `badge badge-danger`.

~~~starter
<style type="text/tailwindcss">
  @layer components {
  }
</style>
<div class="p-6 flex gap-2">
  <span class="ok">مدفوع</span>
  <span class="no">ملغى</span>
</div>
~~~
~~~solution
<style type="text/tailwindcss">
  @layer components {
    .badge {
      @apply px-3 py-1 rounded-full text-sm font-medium;
    }
    .badge-success {
      @apply bg-green-100 text-green-800;
    }
    .badge-danger {
      @apply bg-red-100 text-red-800;
    }
  }
</style>
<div class="p-6 flex gap-2">
  <span class="ok badge badge-success">مدفوع</span>
  <span class="no badge badge-danger">ملغى</span>
</div>
~~~
~~~test
const base = ["padding-left", "padding-top", "border-top-left-radius", "font-size", "font-weight"];
check("الشارة الأولى تستخدم الصنفين badge و badge-success", $(".ok").classList.contains("badge") && $(".ok").classList.contains("badge-success"));
check("شكل الشارة الأساسي", await same(".ok", "px-3 py-1 rounded-full text-sm font-medium", base));
check("ألوان النجاح", await same(".ok", "bg-green-100 text-green-800", ["background-color", "color"]));
check("الشارة الثانية تستخدم badge و badge-danger", $(".no").classList.contains("badge") && $(".no").classList.contains("badge-danger"));
check("ألوان الخطر بنفس الشكل", await same(".no", "px-3 py-1 rounded-full text-sm font-medium bg-red-100 text-red-800", [...base, "background-color", "color"]));
~~~
~~~expected
✓ الشارة الأولى تستخدم الصنفين badge و badge-success
✓ شكل الشارة الأساسي
✓ ألوان النجاح
✓ الشارة الثانية تستخدم badge و badge-danger
✓ ألوان الخطر بنفس الشكل
~~~
