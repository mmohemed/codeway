## ما هو Tailwind CSS؟

**Tailwind CSS** إطار CSS مختلف عن Bootstrap وأمثاله: لا يعطيك مكونات جاهزة مثل «زر» أو «بطاقة»، بل يعطيك آلاف **الأصناف الصغيرة (Utility Classes)**، كل صنف يفعل شيئاً واحداً، وتبني التصميم بتركيبها مباشرة في HTML:

```tw
<div class="p-6 bg-white rounded-xl shadow-md max-w-sm mx-auto my-4">
  <h2 class="text-xl font-bold text-gray-900">بطاقة أولى</h2>
  <p class="mt-2 text-gray-600">صممناها دون كتابة سطر CSS واحد.</p>
</div>
```

كل كتلة **HTML + Tailwind** في هذه الدورة تحتها معاينة حية بمكتبة Tailwind الحقيقية.

اقرأ الأصناف: `p-6` حشوة، و `bg-white` خلفية بيضاء، و `rounded-xl` زوايا دائرية، و `shadow-md` ظل متوسط، و `max-w-sm` أقصى عرض صغير، و `mx-auto` توسيط أفقي.

## لماذا انتشر بهذه السرعة؟

- **لا تخترع أسماء**: لا مزيد من `.card-wrapper-inner-left`.
- **CSS لا يتضخم**: Tailwind يولّد فقط الأصناف التي استخدمتها فعلاً، فيبقى الملف صغيراً مهما كبر المشروع.
- **نظام تصميم جاهز**: المسافات والألوان والأحجام مقاييس متناسقة، فيبدو التصميم احترافياً تلقائياً.
- **التعديل آمن**: تغيير أصناف عنصر لا يكسر عنصراً آخر في صفحة بعيدة.

## طريقة 1: للتجربة السريعة

سطر واحد في `<head>` يكفي لتجربة Tailwind في أي صفحة HTML، وهي نفس الطريقة التي تعمل بها المعاينات هنا:

```html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

> ⚠️ هذه الطريقة للتجربة والنماذج فقط. في المواقع الحقيقية تُبنى الأنماط مسبقاً حتى لا يعمل Tailwind في متصفح كل زائر.

## طريقة 2: مع Vite (الطريقة الاحترافية)

في مشروع Vite (تعلمته في دورة Vite و npm):

```bash
npm install tailwindcss @tailwindcss/vite
```

ثم أضف الإضافة في `vite.config.js`:

```js
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [tailwindcss()],
});
```

ثم سطراً واحداً في ملف CSS الرئيسي (مثل `src/style.css`):

```css
@import "tailwindcss";
```

انتهى! Tailwind يفحص ملفات مشروعك ويولّد CSS للأصناف المستخدمة فقط، أثناء التطوير وعند البناء.

## طريقة 3: أداة سطر الأوامر

لمشاريع بلا Vite، مثل موقع HTML بسيط:

```bash
npm install tailwindcss @tailwindcss/cli
npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch
```

## أدوات تجعل العمل أسهل

- إضافة **Tailwind CSS IntelliSense** لـ VS Code: إكمال تلقائي للأصناف، ومعاينة الألوان، وعرض CSS الناتج عند الوقوف على الصنف.
- **prettier-plugin-tailwindcss**: يرتب الأصناف تلقائياً بترتيب ثابت.

> 💡 هذه الدورة تشرح **Tailwind v4** (الإصدار الحالي). ستجد في شروحات قديمة ملف `tailwind.config.js` و `@tailwind base;`، وهي طريقة v3 وسنقارن بينهما في درس الإعدادات.

## ملخص الدرس

- Tailwind يوفر أصنافاً صغيرة تركّب بها التصميم في HTML.
- يولّد CSS للأصناف المستخدمة فقط.
- للتجربة: سطر `<script>` من CDN. وللمشاريع: `@tailwindcss/vite` و `@import "tailwindcss";`.

## الطريقة التقليدية

لنصمم زراً بالطريقة التقليدية: نخترع اسماً، ونكتب CSS في ملف آخر:

```html
<button class="btn-primary">اشترك الآن</button>

<style>
  .btn-primary {
    background-color: #2563eb;
    color: white;
    padding: 8px 16px;
    border-radius: 8px;
    font-weight: 600;
  }
  .btn-primary:hover {
    background-color: #1d4ed8;
  }
</style>
```

## طريقة Utility First

نفس الزر بأصناف Tailwind، كل خاصية صنف:

```tw
<div class="p-6">
  <button class="bg-blue-600 text-white px-4 py-2 rounded-lg font-semibold hover:bg-blue-700">
    اشترك الآن
  </button>
</div>
```

مرّر الفأرة على الزر في المعاينة: `hover:bg-blue-700` يغمّق اللون عند المرور.

| الصنف | CSS المقابل |
|---|---|
| `bg-blue-600` | `background-color: #2563eb` (تقريباً) |
| `text-white` | `color: white` |
| `px-4` | `padding-left/right: 1rem` |
| `py-2` | `padding-top/bottom: 0.5rem` |
| `rounded-lg` | `border-radius: 0.5rem` |
| `font-semibold` | `font-weight: 600` |

## «لكن هذا يشبه style المضمّن!»

اعتراض شائع، والفرق كبير:

- **قيود التصميم**: `style="padding: 13px"` يسمح بأي رقم، أما Tailwind فيعطيك مقياساً متناسقاً (`p-3` و `p-4`...)، فتتسق الصفحات.
- **الحالات**: `style` لا يدعم `:hover` و `:focus`، و Tailwind يدعمها بالبادئات.
- **التصميم المتجاوب**: `style` لا يدعم media queries، و Tailwind يدعمها بـ `md:` و `lg:`.
- **الأداء**: أصناف مشتركة يعيد المتصفح استخدامها بدل أنماط مكررة في كل عنصر.

## بادئات الحالات

أي صنف يمكن أن يعمل في حالة معيّنة فقط بإضافة بادئة:

| البادئة | تعمل عندما |
|---|---|
| `hover:` | تمر الفأرة فوق العنصر |
| `focus:` | يكون العنصر محدداً (مثل حقل إدخال تكتب فيه) |
| `active:` | أثناء الضغط |
| `disabled:` | يكون العنصر معطلاً |
| `group-hover:` | تمر الفأرة فوق عنصر أب عليه صنف `group` |

```tw
<div class="p-6 space-y-3">
  <input class="border border-gray-300 rounded-lg px-3 py-2 w-64 outline-none focus:border-blue-500 focus:ring-4 focus:ring-blue-100" placeholder="اضغط هنا واكتب">
  <button class="bg-gray-900 text-white px-4 py-2 rounded-lg active:scale-95 disabled:opacity-40" disabled>زر معطل</button>
  <a href="#" class="group block w-64 p-4 border rounded-lg hover:bg-blue-50">
    <span class="font-bold group-hover:text-blue-600">مرّر فوق البطاقة</span>
  </a>
</div>
```

## القيم الخاصة (Arbitrary Values)

إذا احتجت قيمة خارج المقياس، اكتبها بين قوسين مربعين:

```tw
<div class="p-6">
  <div class="w-[260px] bg-[#1da1f2] text-white p-4 rounded-[14px] text-[15px]">
    لون وعرض وزوايا بقيم محددة
  </div>
</div>
```

> 💡 استخدم القيم الخاصة باعتدال، فكثرتها تُضيع فائدة نظام التصميم المتناسق.

## ملخص الدرس

- Utility First: تبني التصميم بأصناف صغيرة مباشرة في HTML بدل أسماء و CSS منفصل.
- يختلف عن `style` المضمّن: مقاييس متناسقة، وحالات، وتصميم متجاوب.
- البادئات `hover:` و `focus:` و `active:` و `disabled:` و `group-hover:` تطبّق الأصناف في حالات معيّنة.
- القيم الخاصة بين أقواس مربعة مثل `w-[260px]` للحالات الاستثنائية.

## الألوان

Tailwind يأتي بلوحة ألوان مدروسة: 22 لوناً، لكل لون 11 درجة من `50` (الأفتح) إلى `950` (الأغمق):

```tw
<div class="p-4 flex gap-1">
  <div class="w-10 h-10 rounded bg-sky-50"></div>
  <div class="w-10 h-10 rounded bg-sky-100"></div>
  <div class="w-10 h-10 rounded bg-sky-200"></div>
  <div class="w-10 h-10 rounded bg-sky-300"></div>
  <div class="w-10 h-10 rounded bg-sky-400"></div>
  <div class="w-10 h-10 rounded bg-sky-500"></div>
  <div class="w-10 h-10 rounded bg-sky-600"></div>
  <div class="w-10 h-10 rounded bg-sky-700"></div>
  <div class="w-10 h-10 rounded bg-sky-800"></div>
  <div class="w-10 h-10 rounded bg-sky-900"></div>
  <div class="w-10 h-10 rounded bg-sky-950"></div>
</div>
```

الصيغة: `{الخاصية}-{اللون}-{الدرجة}`:

| البادئة | الخاصية | مثال |
|---|---|---|
| `bg-` | الخلفية | `bg-rose-500` |
| `text-` | لون النص | `text-slate-700` |
| `border-` | لون الإطار | `border-amber-300` |
| `ring-` | لون الحلقة حول العنصر | `ring-indigo-200` |

والشفافية بعد شرطة مائلة: `bg-black/50` أسود بشفافية 50%.

## المسافات

مقياس المسافات: **كل وحدة = 0.25rem = 4px**. فـ `p-4` تعني 16px، و `m-8` تعني 32px:

| الصنف | الاتجاه |
|---|---|
| `p-4` | كل الجهات |
| `px-4` / `py-4` | أفقي / عمودي |
| `pt-4` `pb-4` | أعلى / أسفل |
| `ps-4` / `pe-4` | بداية السطر / نهايته |
| `m-4` `mx-auto` | الهامش، والتوسيط الأفقي |
| `gap-4` | المسافة بين عناصر flex و grid |
| `space-y-4` | مسافة عمودية بين الأبناء |

> 💡 في المواقع العربية (RTL) استخدم `ps-` و `pe-` و `ms-` و `me-` بدل `pl-` و `pr-`: الـ s تعني start (بداية السطر) و e تعني end، فتعمل صحيحة في الاتجاهين.

```tw
<div class="p-4 space-y-2">
  <div class="bg-amber-100 ps-8 py-2">ps-8: حشوة من جهة بداية السطر (اليمين في العربية)</div>
  <div class="bg-amber-100 px-8 py-4">px-8 py-4</div>
  <div class="bg-amber-100 p-2 mx-auto w-1/2 text-center">mx-auto مع w-1/2</div>
</div>
```

## الأحجام

| الصنف | المعنى |
|---|---|
| `w-64` / `h-32` | عرض 16rem / ارتفاع 8rem |
| `w-full` / `w-1/2` | 100% / 50% |
| `max-w-md` / `max-w-3xl` | أقصى عرض (مفيد للنصوص والبطاقات) |
| `min-h-screen` | ارتفاع لا يقل عن الشاشة |
| `size-12` | عرض وارتفاع معاً |

## الخطوط والنصوص

```tw
<div class="p-4 space-y-1">
  <p class="text-xs">text-xs صغير جداً</p>
  <p class="text-base">text-base الحجم الافتراضي</p>
  <p class="text-2xl font-semibold">text-2xl شبه عريض</p>
  <p class="text-4xl font-black tracking-tight">text-4xl font-black</p>
  <p class="text-gray-500 leading-loose max-w-md">leading-loose يزيد المسافة بين الأسطر، فيصبح النص الطويل أسهل في القراءة على الشاشات.</p>
  <p class="text-center underline decoration-wavy decoration-pink-500">نص في المنتصف بخط سفلي متموج</p>
</div>
```

| المجموعة | الأصناف |
|---|---|
| الحجم | `text-xs` `text-sm` `text-base` `text-lg` `text-xl` ... `text-9xl` |
| السُمك | `font-light` `font-normal` `font-medium` `font-semibold` `font-bold` `font-black` |
| المحاذاة | `text-start` `text-center` `text-end` |
| تباعد الأسطر | `leading-tight` `leading-normal` `leading-loose` |

## الإطارات والزوايا والظلال

```tw
<div class="p-6 flex gap-4">
  <div class="p-4 border-2 border-dashed border-gray-300 rounded">إطار متقطع</div>
  <div class="p-4 rounded-2xl shadow-lg">ظل كبير</div>
  <div class="p-4 rounded-full ring-4 ring-violet-200 bg-violet-500 text-white">حلقة</div>
</div>
```

## ملخص الدرس

- الألوان: `bg-` و `text-` و `border-` مع اسم اللون والدرجة من 50 إلى 950، والشفافية بـ `/50`.
- المسافات: كل وحدة 4px، و `p` للحشوة و `m` للهامش، و `ps` و `pe` تراعي اتجاه RTL.
- الأحجام: `w-` و `h-` و `max-w-` و `size-`.
- النصوص: `text-{حجم}` و `font-{سمك}` و `leading-` و `text-center`.
