## لماذا الإحصاء؟

الإحصاء هو اللغة التي تحوّل الأرقام إلى قرارات: هل الحملة الإعلانية نجحت فعلاً أم هي صدفة؟ ما الراتب "المعتاد" في هذه الوظيفة؟ هل التصميم الجديد للصفحة أفضل؟ وهو الأساس الرياضي لتعلم الآلة كله.

في هذه الدورة نتعلم المفاهيم ونطبقها مباشرة بـ Python: مكتبة `statistics` المدمجة، و NumPy، و **SciPy** (مكتبة الحوسبة العلمية التي فيها الاختبارات الإحصائية).

## مقاييس النزعة المركزية

سؤال: "ما القيمة **النموذجية** في هذه البيانات؟" ثلاث إجابات:

| المقياس | التعريف | متى يُستخدم |
|---|---|---|
| **المتوسط** (Mean) | المجموع ÷ العدد | بيانات متماثلة بلا قيم شاذة |
| **الوسيط** (Median) | القيمة في المنتصف بعد الترتيب | بيانات فيها قيم شاذة (رواتب، أسعار) |
| **المنوال** (Mode) | الأكثر تكراراً | بيانات فئوية (المقاس الأكثر مبيعاً) |

```python
import statistics as st

delivery_days = [2, 3, 3, 4, 3, 5, 2, 3, 4, 21]

print("المتوسط:", st.mean(delivery_days))
print("الوسيط:", st.median(delivery_days))
print("المنوال:", st.mode(delivery_days))
```

```output
المتوسط: 5
الوسيط: 3.0
المنوال: 3
```

شحنة واحدة تأخرت 21 يوماً رفعت المتوسط إلى 5 أيام، مع أن 9 من 10 شحنات وصلت خلال 5 أيام أو أقل. الوسيط (3) يعبّر عن التجربة المعتادة بصدق أكبر.

## القيم الشاذة وأثرها

```python
import numpy as np

salaries = np.array([8000, 8500, 9000, 9200, 9500, 10000, 10500])
print("قبل:", salaries.mean().round(), np.median(salaries))

with_ceo = np.append(salaries, 150000)
print("بعد إضافة راتب المدير:", with_ceo.mean().round(), np.median(with_ceo))
```

```output
قبل: 9243.0 9200.0
بعد إضافة راتب المدير: 26838.0 9350.0
```

قيمة واحدة رفعت المتوسط إلى نحو ثلاثة أضعافه، بينما تحرك الوسيط قليلاً. لهذا تُنشر **أسعار المنازل** و **الرواتب** في التقارير بالوسيط.

### المتوسط المقصوص والمتوسط الموزون

```python
import numpy as np
from scipy import stats

judges = [8.5, 9.0, 8.8, 9.2, 3.0, 8.9]          # حكم واحد أعطى درجة غريبة
print("المتوسط:", round(np.mean(judges), 2))
print("المتوسط المقصوص 20%:", round(stats.trim_mean(judges, 0.2), 2))

grades = [90, 75, 85]
credits = [4, 2, 3]                              # ساعات كل مادة
print("المعدل الموزون:", round(np.average(grades, weights=credits), 2))
```

```output
المتوسط: 7.9
المتوسط المقصوص 20%: 8.8
المعدل الموزون: 85.0
```

- **المقصوص** يحذف نسبة من الطرفين ثم يحسب المتوسط (كما في تحكيم المسابقات الأولمبية).
- **الموزون** يعطي كل قيمة وزناً، مثل المعدل الجامعي بالساعات.

## العلاقة بين الثلاثة تكشف شكل البيانات

- المتوسط ≈ الوسيط: البيانات **متماثلة**.
- المتوسط > الوسيط: **ملتوية لليمين** (ذيل طويل من القيم الكبيرة) مثل الدخل.
- المتوسط < الوسيط: **ملتوية لليسار** مثل درجات اختبار سهل.

## ملخص الدرس

- المتوسط يتأثر بالقيم الشاذة، والوسيط مقاوم لها، والمنوال للفئات.
- `statistics.mean/median/mode` أو `np.mean/np.median`.
- `stats.trim_mean` للمتوسط المقصوص، و `np.average(..., weights=)` للموزون.
- مقارنة المتوسط والوسيط تكشف التواء البيانات.

```python
import numpy as np

store_a = np.array([4, 4, 3, 5, 4, 4, 4])
```


المتجر A **موثوق**: تعرف متى تصلك طلبيتك. المتجر B قد تصل خلال يوم أو أسبوع. المتوسط وحده لا يكفي، تحتاج دائماً مقياساً **للتشتت**.

## التباين والانحراف المعياري

**التباين** = متوسط مربعات البعد عن المتوسط. **الانحراف المعياري** = جذره، فيعود بنفس وحدة البيانات (أيام، ريالات):

```python
import numpy as np

x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
mean = x.mean()
deviations = x - mean
print("الانحرافات:", deviations)
print("التباين (المجتمع):", (deviations ** 2).mean(), "=", x.var())
print("الانحراف المعياري:", np.sqrt(x.var()), "=", x.std())
print("للعينة (ddof=1):", round(x.std(ddof=1), 3))
```

```output
الانحرافات: [-3. -1. -1. -1.  0.  0.  2.  4.]
التباين (المجتمع): 4.0 = 4.0
الانحراف المعياري: 2.0 = 2.0
للعينة (ddof=1): 2.138
```

> 💡 **المجتمع أم العينة؟** إذا كانت بياناتك هي **كل** المجتمع، اقسم على n (`ddof=0`، الافتراضي في NumPy). إذا كانت **عينة** منه (الحالة الغالبة)، اقسم على n-1 (`ddof=1`، الافتراضي في Pandas و `statistics.stdev`). القسمة على n-1 تصحح ميل العينة للاستهانة بالتشتت الحقيقي.

## الربيعيات و IQR

مقياس تشتت **مقاوم للقيم الشاذة** مثل الوسيط:

```python
import numpy as np

times = np.array([12, 15, 14, 10, 18, 16, 13, 45, 15, 11, 14, 17])
q1, q3 = np.percentile(times, [25, 75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print("Q1 =", q1, "| Q3 =", q3, "| IQR =", iqr)
print("حدود القيم الطبيعية:", low, "إلى", high)
print("قيم شاذة:", times[(times < low) | (times > high)])
```

```output
Q1 = 12.75 | Q3 = 16.25 | IQR = 3.5
حدود القيم الطبيعية: 7.5 إلى 21.5
قيم شاذة: [45]
```

قاعدة **1.5 × IQR** هي نفسها التي يرسم بها مخطط الصندوق (Box Plot) النقاط الشاذة.

## معامل الاختلاف: مقارنة تشتت أشياء مختلفة

أيهما أكثر تذبذباً: سعر سهم 500 ريال يتحرك ±20، أم سهم 20 ريالاً يتحرك ±4؟

```python
import numpy as np

big = np.array([480, 510, 495, 520, 500, 490])
small = np.array([18, 24, 21, 16, 22, 19])
for name, s in [("السهم الكبير", big), ("السهم الصغير", small)]:
    cv = s.std(ddof=1) / s.mean() * 100
    print(f"{name}: الانحراف {s.std(ddof=1):.1f} | معامل الاختلاف {cv:.1f}%")
```

```output
السهم الكبير: الانحراف 14.3 | معامل الاختلاف 2.9%
السهم الصغير: الانحراف 2.9 | معامل الاختلاف 14.5%
```

الانحراف المعياري للسهم الكبير أكبر، لكن **نسبياً** السهم الصغير أكثر تذبذباً بكثير.

## ملخص الدرس

- المتوسط وحده لا يكفي: قِس التشتت دائماً.
- التباين متوسط مربعات الانحرافات، والانحراف المعياري جذره بنفس وحدة البيانات.
- `ddof=1` للعينة (الغالب)، و `ddof=0` للمجتمع كاملاً.
- IQR = Q3 - Q1 مقاوم للشواذ، والقيم خارج 1.5 × IQR تُعتبر شاذة.
- معامل الاختلاف (الانحراف ÷ المتوسط) لمقارنة تشتت مقاييس مختلفة.

## التوزيع: شكل البيانات

الأرقام الملخصة (متوسط، انحراف) تخفي الكثير. **التوزيع** يُظهر كيف تنتشر القيم، وأفضل طريقة لرؤيته **المدرج التكراري (Histogram)**:

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
heights = rng.normal(170, 8, 1000)                     # متماثل
incomes = rng.lognormal(mean=9, sigma=0.6, size=1000)  # ملتوٍ لليمين

fig, axes = plt.subplots(1, 2, figsize=(9, 3.2))
axes[0].hist(heights, bins=30, color="#2c7be5")
axes[0].set_title("Heights (symmetric)")
axes[1].hist(incomes, bins=30, color="#e5732c")
axes[1].set_title("Incomes (right-skewed)")
plt.tight_layout()
```

## الالتواء والتفلطح

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(1)
heights = rng.normal(170, 8, 1000)
incomes = rng.lognormal(mean=9, sigma=0.6, size=1000)

for name, data in [("الأطوال", heights), ("الدخل", incomes)]:
    print(f"{name}: المتوسط {data.mean():.0f} | الوسيط {np.median(data):.0f} | الالتواء {stats.skew(data):.2f}")
```

```output
الأطوال: المتوسط 170 | الوسيط 170 | الالتواء 0.00
الدخل: المتوسط 9970 | الوسيط 8057 | الالتواء 2.03
```

| الالتواء (Skewness) | الشكل |
|---|---|
| قريب من 0 | متماثل |
| موجب | ذيل لليمين (المتوسط > الوسيط) |
| سالب | ذيل لليسار (المتوسط < الوسيط) |

## الدرجة المعيارية z-score

كيف تقارن طالباً حصل على 85 في اختبار صعب بطالب حصل على 92 في اختبار سهل؟ حوّل كل درجة إلى **عدد الانحرافات المعيارية عن المتوسط**:

z = (القيمة - المتوسط) ÷ الانحراف المعياري

```python
import numpy as np

math = np.array([60, 65, 70, 72, 85, 68, 62, 75])     # اختبار صعب
arabic = np.array([88, 92, 90, 85, 94, 91, 89, 93])   # اختبار سهل

z_math = (85 - math.mean()) / math.std()
z_arabic = (92 - arabic.mean()) / arabic.std()
print(f"85 في الرياضيات: z = {z_math:.2f}")
print(f"92 في العربي: z = {z_arabic:.2f}")
```

```output
85 في الرياضيات: z = 2.06
92 في العربي: z = 0.64
```

85 في الرياضيات **أفضل نسبياً** بكثير: صاحبها متقدم على زملائه بانحرافين معياريين تقريباً.

### z-score لاكتشاف الشذوذ

```python
import numpy as np
from scipy import stats

daily_sales = np.array([210, 198, 225, 205, 215, 640, 202, 219, 207, 211])
z = stats.zscore(daily_sales)
print(z.round(2))
print("أيام شاذة:", np.where(np.abs(z) > 2)[0].tolist())
```

```output
[-0.33 -0.43 -0.22 -0.37 -0.3   2.99 -0.4  -0.26 -0.36 -0.33]
أيام شاذة: [5]
```

قاعدة شائعة: |z| > 2 غير معتاد، و |z| > 3 شاذ جداً (في التوزيع الطبيعي).

## ملخص الدرس

- المدرج التكراري (`plt.hist`) يُظهر شكل التوزيع.
- الالتواء (`stats.skew`): موجب ذيل يمين، وسالب ذيل يسار.
- z = (x - المتوسط) ÷ الانحراف: يقارن قيماً من مقاييس مختلفة.
- `stats.zscore` لحساب z لكل القيم، و |z| > 2 أو 3 لاكتشاف الشذوذ.

~~~solution
import numpy as np
from scipy import stats

branch_a = np.array([10200, 11000, 9800, 10500, 12000, 10800, 9900, 10400, 11200, 10100])
branch_b = np.array([7000, 7200, 6900, 7100, 9500, 7050, 6950, 7150, 7000, 7100])

z_a = round((12000 - branch_a.mean()) / branch_a.std(), 2)

better = "A" if z_a > z_b else "B"
skew_a = round(stats.skew(branch_a), 2)
anomalies = np.where(np.abs(stats.zscore(branch_b)) > 2)[0].tolist()
~~~
