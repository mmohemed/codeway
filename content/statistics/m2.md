## الاحتمال

**الاحتمال** رقم بين 0 (مستحيل) و 1 (مؤكد) يقيس فرصة حدوث شيء:

الاحتمال = عدد النتائج المطلوبة ÷ عدد كل النتائج الممكنة (إذا كانت متساوية الفرص)

```python
from fractions import Fraction

die = [1, 2, 3, 4, 5, 6]
even = [x for x in die if x % 2 == 0]
print("P(زوجي) =", Fraction(len(even), len(die)))
print("P(أكبر من 4) =", Fraction(len([x for x in die if x > 4]), len(die)))
```

```output
P(زوجي) = 1/2
P(أكبر من 4) = 1/3
```

## المحاكاة: اختبر الاحتمال بالتجربة

أقوى أداة لفهم الاحتمال: **كرر التجربة آلاف المرات** واحسب النسبة. كلما زاد عدد التكرارات اقتربت النسبة من الاحتمال الحقيقي (**قانون الأعداد الكبيرة**):

```python
import numpy as np

rng = np.random.default_rng(0)
for n in [10, 100, 10_000, 1_000_000]:
    rolls = rng.integers(1, 7, size=n)
    print(f"{n:>9} رمية: نسبة الستة = {(rolls == 6).mean():.4f}")
print("الاحتمال النظري:", round(1 / 6, 4))
```

```output
       10 رمية: نسبة الستة = 0.1000
      100 رمية: نسبة الستة = 0.1600
    10000 رمية: نسبة الستة = 0.1689
  1000000 رمية: نسبة الستة = 0.1668
الاحتمال النظري: 0.1667
```

## قواعد أساسية

| القاعدة | الصيغة | مثال |
|---|---|---|
| المتمم | P(ليس A) = 1 - P(A) | احتمال عدم المطر |
| "و" لحدثين مستقلين | P(A و B) = P(A) × P(B) | ستة في رميتين متتاليتين |
| "أو" لحدثين متنافيين | P(A أو B) = P(A) + P(B) | 1 أو 2 في رمية واحدة |
| "أو" عموماً | P(A) + P(B) - P(A و B) | |

```python
import numpy as np

rng = np.random.default_rng(1)
n = 200_000
a = rng.integers(1, 7, n)
b = rng.integers(1, 7, n)
print("ستة مرتين: محاكاة", round(((a == 6) & (b == 6)).mean(), 4), "| نظري", round(1 / 36, 4))
print("ستة واحدة على الأقل: محاكاة", round(((a == 6) | (b == 6)).mean(), 4), "| نظري", round(1 - (5 / 6) ** 2, 4))
```

```output
ستة مرتين: محاكاة 0.0278 | نظري 0.0278
ستة واحدة على الأقل: محاكاة 0.3046 | نظري 0.3056
```

"واحد على الأقل" يُحسب غالباً بالمتمم: 1 - P(لا شيء).

## مثال مفاجئ: مسألة أعياد الميلاد

في فصل فيه 23 طالباً، ما احتمال أن يتشارك اثنان على الأقل نفس يوم الميلاد؟ أغلب الناس يخمّنون رقماً صغيراً:

```python
import numpy as np

def shared_birthday(n, trials=20_000, seed=2):
    rng = np.random.default_rng(seed)
    days = rng.integers(0, 365, size=(trials, n))
    s = np.sort(days, axis=1)
    return (s[:, 1:] == s[:, :-1]).any(axis=1).mean()

for n in [10, 23, 40, 60]:
    print(f"{n} طالباً: {shared_birthday(n):.1%}")
```

```output
10 طالباً: 11.8%
23 طالباً: 50.6%
40 طالباً: 89.5%
60 طالباً: 99.4%
```

أكثر من 50% مع 23 طالباً فقط! الحدس البشري ضعيف في الاحتمالات، ولهذا نحسب ولا نخمّن.

## ملخص الدرس

- الاحتمال بين 0 و 1، ويُقدَّر بالمحاكاة: كرر التجربة واحسب النسبة.
- قانون الأعداد الكبيرة: النسبة تقترب من الاحتمال الحقيقي مع زيادة التكرارات.
- المتمم 1 - P، و "و" للمستقلين ضرب، و "أو" للمتنافيين جمع.

## قاعدة 68 - 95 - 99.7

في أي توزيع طبيعي:

- **68%** من القيم ضمن انحراف معياري واحد من المتوسط.
- **95%** ضمن انحرافين.
- **99.7%** ضمن ثلاثة.

```python
from scipy import stats

for k in [1, 2, 3]:
    p = stats.norm.cdf(k) - stats.norm.cdf(-k)
    print(f"ضمن {k} انحراف: {p:.1%}")
```

```output
ضمن 1 انحراف: 68.3%
ضمن 2 انحراف: 95.4%
ضمن 3 انحراف: 99.7%
```

مثال: إذا كانت أطوال الرجال بمتوسط 170 سم وانحراف 7 سم، فإن 95% منهم بين 156 و 184 سم.

## حساب الاحتمالات بـ scipy.stats.norm

| الدالة | السؤال الذي تجيبه |
|---|---|
| `norm.cdf(x, mu, sigma)` | ما احتمال أن تكون القيمة **أقل من** x؟ |
| `norm.sf(x, mu, sigma)` | ما احتمال أن تكون **أكبر من** x؟ (1 - cdf) |
| `norm.ppf(p, mu, sigma)` | ما القيمة التي يقع تحتها p من البيانات؟ (عكس cdf) |
| `norm.pdf(x, mu, sigma)` | ارتفاع الجرس عند x (للرسم) |
| `norm.rvs(mu, sigma, size)` | توليد قيم عشوائية |

```python
from scipy import stats

# درجات اختبار القدرات: متوسط 65 وانحراف 10
mu, sigma = 65, 10
print(f"أقل من 50: {stats.norm.cdf(50, mu, sigma):.1%}")
print(f"أكثر من 85: {stats.norm.sf(85, mu, sigma):.1%}")
print(f"بين 60 و 75: {stats.norm.cdf(75, mu, sigma) - stats.norm.cdf(60, mu, sigma):.1%}")
print(f"درجة أفضل 10%: {stats.norm.ppf(0.90, mu, sigma):.1f}")
```

```output
أقل من 50: 6.7%
أكثر من 85: 2.3%
بين 60 و 75: 53.3%
درجة أفضل 10%: 77.8
```

## هل بياناتي طبيعية؟

كثير من الاختبارات الإحصائية تفترض أن البيانات طبيعية. تحقق قبل أن تفترض:

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(3)
normal_data = rng.normal(50, 5, 200)
skewed_data = rng.exponential(10, 200)

for name, d in [("طبيعية", normal_data), ("ملتوية", skewed_data)]:
    stat, p = stats.shapiro(d)
    print(f"{name}: p = {p:.4f} →", "تبدو طبيعية" if p > 0.05 else "ليست طبيعية")
```

```output
طبيعية: p = 0.7751 → تبدو طبيعية
ملتوية: p = 0.0000 → ليست طبيعية
```

اختبار **Shapiro-Wilk**: إذا كانت p أصغر من 0.05 نرفض أن البيانات طبيعية. (ستفهم معنى p بدقة في درس اختبار الفرضيات.)

## ملخص الدرس

- التوزيع الطبيعي جرس متماثل يحدده المتوسط والانحراف المعياري.
- قاعدة 68-95-99.7 لنسب القيم ضمن 1 و 2 و 3 انحرافات.
- `norm.cdf` لاحتمال "أقل من"، و `norm.sf` لـ "أكبر من"، و `norm.ppf` للقيمة عند نسبة معينة.
- `stats.shapiro` لاختبار طبيعية البيانات.

## الاحتمال الشرطي

**P(A | B)** = احتمال A **إذا علمنا** أن B حدث. مثال: احتمال أن يكون البريد مزعجاً **إذا كان** فيه كلمة "مجاني".

P(A | B) = P(A و B) ÷ P(B)

```python
import pandas as pd

emails = pd.DataFrame({
    "has_free": [True] * 40 + [False] * 160,
    "spam":     [True] * 30 + [False] * 10 + [True] * 20 + [False] * 140,
})
print(pd.crosstab(emails["has_free"], emails["spam"], margins=True))
p_spam = emails["spam"].mean()
p_spam_given_free = emails.loc[emails["has_free"], "spam"].mean()
print(f"P(مزعج) = {p_spam:.2f}")
print(f"P(مزعج | فيه 'مجاني') = {p_spam_given_free:.2f}")
```

```output
spam      False  True  All
has_free                  
False       140    20  160
True         10    30   40
All         150    50  200
P(مزعج) = 0.25
P(مزعج | فيه 'مجاني') = 0.75
```

معرفة أن الرسالة فيها "مجاني" رفعت احتمال كونها مزعجة من 25% إلى 75%. هذا أساس مرشحات البريد المزعج (Naive Bayes).

## نظرية بايز

تقلب الاحتمال الشرطي: من P(B | A) إلى P(A | B):

**P(A | B) = P(B | A) × P(A) ÷ P(B)**

| الرمز | الاسم | المعنى |
|---|---|---|
| P(A) | الاحتمال المسبق (Prior) | ما نعرفه قبل الدليل |
| P(B \| A) | الأرجحية (Likelihood) | احتمال الدليل إذا كانت A صحيحة |
| P(A \| B) | الاحتمال اللاحق (Posterior) | اعتقادنا المحدَّث بعد الدليل |

## المثال الكلاسيكي: فحص طبي

مرض نادر يصيب **1%** من الناس. فحص دقته **95%** (يكشف 95% من المرضى)، ويعطي نتيجة إيجابية خاطئة لـ **5%** من الأصحاء. ظهرت نتيجتك **إيجابية**. ما احتمال أنك مريض فعلاً؟

```python
p_disease = 0.01             # الاحتمال المسبق
p_pos_if_sick = 0.95         # الحساسية
p_pos_if_healthy = 0.05      # الإيجابية الخاطئة

p_pos = p_pos_if_sick * p_disease + p_pos_if_healthy * (1 - p_disease)
p_sick_if_pos = p_pos_if_sick * p_disease / p_pos
print(f"P(إيجابي) = {p_pos:.4f}")
print(f"P(مريض | إيجابي) = {p_sick_if_pos:.1%}")
```

```output
P(إيجابي) = 0.0590
P(مريض | إيجابي) = 16.1%
```

**16% فقط!** رغم أن الفحص "دقيق 95%". لماذا؟ لأن المرض نادر جداً، فعدد الأصحاء ضخم، و 5% منهم (إيجابية خاطئة) أكثر من المرضى الحقيقيين.

### تأكيد بالعدّ

تخيّل 10,000 شخص:

```python
people = 10_000
sick = people * 0.01                    # 100 مريض
healthy = people - sick                 # 9900 سليم
true_pos = sick * 0.95                  # 95 مريضاً نتيجتهم إيجابية
false_pos = healthy * 0.05              # 495 سليماً نتيجتهم إيجابية!
print(f"إيجابيون: {true_pos + false_pos:.0f} | منهم مرضى فعلاً: {true_pos:.0f}")
print(f"النسبة: {true_pos / (true_pos + false_pos):.1%}")
```

```output
إيجابيون: 590 | منهم مرضى فعلاً: 95
النسبة: 16.1%
```

### التحديث المتكرر

إذا أعدت الفحص وجاء إيجابياً **مرة ثانية**؟ الاحتمال اللاحق يصبح هو المسبق الجديد:

```python
def bayes(prior, sens=0.95, fpr=0.05):
    return sens * prior / (sens * prior + fpr * (1 - prior))

p = 0.01
for test in range(1, 4):
    p = bayes(p)
    print(f"بعد الفحص الإيجابي رقم {test}: {p:.1%}")
```

```output
بعد الفحص الإيجابي رقم 1: 16.1%
بعد الفحص الإيجابي رقم 2: 78.5%
بعد الفحص الإيجابي رقم 3: 98.6%
```

هذا جوهر التفكير البايزي: **ابدأ باعتقاد، وحدّثه مع كل دليل جديد**.

## ملخص الدرس

- P(A | B) احتمال A بعد معرفة B، ويُحسب من الجدول بتصفية B أولاً.
- بايز: P(A | B) = P(B | A) × P(A) ÷ P(B).
- الاحتمال المسبق مهم جداً: الفحص الدقيق لمرض نادر ينتج إيجابيات خاطئة كثيرة.
- اللاحق يصبح مسبقاً للدليل التالي.

4. `after_two`: إذا أطلق نظامان مستقلان بنفس المواصفات تنبيهاً على نفس العملية، ما احتمال الاحتيال (نسبة مئوية مقربة لخانة)؟

sens = 0.98
fpr = 0.01

post = sens * p_fraud / (sens * p_fraud + fpr * (1 - p_fraud))
p_fraud_given_alert = round(post * 100, 1)
false_alerts = round(1_000_000 * (1 - p_fraud) * fpr)
post2 = sens * post / (sens * post + fpr * (1 - post))
after_two = round(post2 * 100, 1)
~~~
