## المبدّل (Switch): داخل الشبكة المحلية

**المبدّل** يربط الأجهزة في نفس الشبكة المحلية (LAN) ويعمل في الطبقة 2 بعناوين **MAC** (عنوان فريد لكل بطاقة شبكة مثل `aa:bb:cc:00:11:22`). يتعلم مكان كل جهاز تلقائياً:

1. تصله إطار من منفذ ← يسجّل: "عنوان المصدر هذا خلف هذا المنفذ" (جدول MAC).
2. يبحث عن عنوان الوجهة في الجدول: إن وجده أرسل الإطار لذلك المنفذ فقط، وإلا **أغرقه (Flood)** لكل المنافذ عدا مصدره.

```python
class Switch:
    def __init__(self, ports):
        self.ports = ports
        self.table = {}

    def receive(self, port, src, dst):
        self.table[src] = port
        if dst in self.table:
            out = [self.table[dst]]
        else:
            out = [p for p in range(1, self.ports + 1) if p != port]
        print(f"frame {src[-2:]}->{dst[-2:]} on port {port}: forward to {out}")

sw = Switch(4)
sw.receive(1, "aa:aa:aa:aa:aa:01", "aa:aa:aa:aa:aa:03")   # لا يعرف 03 بعد
sw.receive(3, "aa:aa:aa:aa:aa:03", "aa:aa:aa:aa:aa:01")   # يعرف 01 الآن
sw.receive(1, "aa:aa:aa:aa:aa:01", "aa:aa:aa:aa:aa:03")
print(sw.table)
```

```output
frame 01->03 on port 1: forward to [2, 3, 4]
frame 03->01 on port 3: forward to [1]
frame 01->03 on port 1: forward to [3]
{'aa:aa:aa:aa:aa:01': 1, 'aa:aa:aa:aa:aa:03': 3}
```

ومن هنا تأتي هجمات الطبقة 2: إغراق الجدول بعناوين مزيفة حتى يمتلئ فيبدأ المبدّل بإرسال كل شيء لكل المنافذ (MAC flooding)، وتزوير **ARP** (البروتوكول الذي يربط IP بـ MAC). الدفاعات: **Port Security** لتحديد عدد العناوين لكل منفذ، و **Dynamic ARP Inspection**، و **VLANs** لفصل الأقسام منطقياً على نفس المبدّل.

## الموجّه (Router): بين الشبكات

**الموجّه** يعمل في الطبقة 3 ويقرر إلى أين ترسل الحزمة بحسب **جدول التوجيه**. والقاعدة الذهبية: **أطول بادئة مطابقة (Longest Prefix Match)**، أي المسار الأكثر تحديداً يفوز. و `0.0.0.0/0` هو **المسار الافتراضي** (Default Route) لكل ما لا يطابق غيره، عادة نحو الإنترنت:

```python
import ipaddress

routes = [
    ("0.0.0.0/0", "isp-gateway"),
    ("10.0.0.0/8", "core-router"),
    ("10.1.0.0/16", "branch-riyadh"),
    ("10.1.5.0/24", "finance-firewall"),
]
table = [(ipaddress.ip_network(n), hop) for n, hop in routes]

def route(dst):
    ip = ipaddress.ip_address(dst)
    matches = [(net, hop) for net, hop in table if ip in net]
    net, hop = max(matches, key=lambda m: m[0].prefixlen)
    return f"{dst:12} -> {hop:16} (via {net})"

for d in ["10.1.5.20", "10.1.9.9", "10.200.0.1", "8.8.8.8"]:
    print(route(d))
```

```output
10.1.5.20    -> finance-firewall (via 10.1.5.0/24)
10.1.9.9     -> branch-riyadh    (via 10.1.0.0/16)
10.200.0.1   -> core-router      (via 10.0.0.0/8)
8.8.8.8      -> isp-gateway      (via 0.0.0.0/0)
```

`10.1.5.20` يطابق أربعة مسارات، لكن `/24` هو الأطول فيفوز.

## traceroute و TTL

كل موجّه ينقص TTL بواحد، وعند الصفر يرمي الحزمة ويرسل للمصدر رسالة ICMP "Time Exceeded". أداة **traceroute** تستغل ذلك: ترسل حزماً بـ TTL = 1 ثم 2 ثم 3... فيكشف كل موجّه نفسه:

```python
path = ["192.168.1.1", "10.20.0.1", "62.149.32.1", "93.184.216.34"]

def send(ttl):
    for hop_ip in path:
        ttl -= 1
        if hop_ip == path[-1]:
            return hop_ip, "reply"
        if ttl == 0:
            return hop_ip, "time exceeded"

for ttl in range(1, 6):
    hop, kind = send(ttl)
    print(ttl, hop, kind)
    if kind == "reply":
        break
```

```output
1 192.168.1.1 time exceeded
2 10.20.0.1 time exceeded
3 62.149.32.1 time exceeded
4 93.184.216.34 reply
```

~~~solution
import ipaddress

class Router:
    def __init__(self):
        self.routes = {}

    def add(self, network, hop):
        self.routes[ipaddress.ip_network(network)] = hop

    def lookup(self, dst):
        ip = ipaddress.ip_address(dst)
        best = None
        for net, hop in self.routes.items():
            if ip in net and (best is None or net.prefixlen > best[0].prefixlen):
                best = (net, hop)
        return best[1] if best else None

    def remove(self, network):
        self.routes.pop(ipaddress.ip_network(network), None)
~~~

## الجدار الناري (Firewall)

**الجدار الناري** يقرر أي حركة مسموحة بين الشبكات بحسب **قواعد** تُفحص **بالترتيب**، وأول قاعدة تطابق تُطبَّق. وأهم مبدأ: **الرفض الافتراضي (Default Deny)**: كل ما لم يُسمح به صراحة ممنوع.

كل قاعدة تحدد: الاتجاه، والمصدر، والوجهة، والبروتوكول، والمنفذ، والقرار.

```python
import ipaddress

rules = [
    {"src": "0.0.0.0/0",   "dst": "10.0.1.10/32", "proto": "tcp", "port": 443, "action": "allow"},  # الموقع للجميع
    {"src": "10.0.9.0/24", "dst": "10.0.1.0/24",  "proto": "tcp", "port": 22,  "action": "allow"},  # SSH من شبكة الإدارة فقط
    {"src": "0.0.0.0/0",   "dst": "10.0.1.0/24",  "proto": "tcp", "port": 22,  "action": "deny"},
    {"src": "0.0.0.0/0",   "dst": "0.0.0.0/0",    "proto": "any", "port": None, "action": "deny"},   # الرفض الافتراضي
]

def check(src, dst, proto, port):
    for i, r in enumerate(rules):
        if (ipaddress.ip_address(src) in ipaddress.ip_network(r["src"])
                and ipaddress.ip_address(dst) in ipaddress.ip_network(r["dst"])
                and r["proto"] in (proto, "any")
                and r["port"] in (port, None)):
            return f"{r['action']:5} (rule {i})"

print(check("203.0.113.5", "10.0.1.10", "tcp", 443))
print(check("10.0.9.7", "10.0.1.20", "tcp", 22))
print(check("203.0.113.5", "10.0.1.20", "tcp", 22))
print(check("203.0.113.5", "10.0.1.10", "tcp", 3306))
```

```output
allow (rule 0)
allow (rule 1)
deny  (rule 2)
deny  (rule 3)
```

ترتيب القواعد حاسم: لو وضعنا قاعدة رفض SSH للجميع قبل قاعدة السماح لشبكة الإدارة، لمُنع المدير أيضاً.

## عديم الحالة مقابل ذي الحالة

- **عديم الحالة (Stateless)**: يفحص كل حزمة وحدها، فيجب أن تسمح صراحة بحركة الرد أيضاً.
- **ذو الحالة (Stateful)**: يتذكر الاتصالات التي بدأت من الداخل ويسمح بردودها تلقائياً، ويرفض أي "رد" لم يُطلب. هذا هو الأشيع اليوم.

```python
class StatefulFirewall:
    def __init__(self):
        self.connections = set()

    def outbound(self, src, sport, dst, dport):
        self.connections.add((src, sport, dst, dport))
        return "allow (new outbound)"

    def inbound(self, src, sport, dst, dport):
        if (dst, dport, src, sport) in self.connections:
            return "allow (reply to known connection)"
        return "deny (unsolicited)"

fw = StatefulFirewall()
print(fw.outbound("192.168.1.10", 51000, "93.184.216.34", 443))
print(fw.inbound("93.184.216.34", 443, "192.168.1.10", 51000))
print(fw.inbound("203.0.113.66", 443, "192.168.1.10", 51000))
print(fw.inbound("93.184.216.34", 443, "192.168.1.10", 51001))
```

```output
allow (new outbound)
allow (reply to known connection)
deny (unsolicited)
deny (unsolicited)
```

- **الجدار الناري للمضيف**: على الجهاز نفسه، مثل `ufw` في Linux (في دورة Linux) و Windows Defender Firewall.

اكتب دالة `evaluate(rules, packet)` لجدار ناري بالرفض الافتراضي:

- `rules` قائمة قواعد، كل قاعدة قاموس فيه `action` (`"allow"` أو `"deny"`) و `src` (شبكة CIDR) و `ports` (قائمة منافذ، أو `"any"`).

- ارجع زوجاً `(القرار, رقم القاعدة)`، ورقم القاعدة `None` عند الرفض الافتراضي.

ثم اكتب دالة `shadowed(rules)` ترجع أرقام القواعد التي **لن تطابق أبداً** لأن قاعدة قبلها تغطيها كلياً: شبكتها جزء من شبكة القاعدة السابقة (`subnet_of`)، ومنافذها كلها مغطاة (القاعدة السابقة `"any"` أو تحوي كل منافذها).

~~~starter

    return ("allow", None)

    return []
~~~
~~~solution
import ipaddress

def _ports_cover(a, b):
    if a == "any":
        return True
    if b == "any":
        return False
    return set(b) <= set(a)

def evaluate(rules, packet):
    ip = ipaddress.ip_address(packet["src"])
    for i, r in enumerate(rules):
        if ip in ipaddress.ip_network(r["src"]) and (r["ports"] == "any" or packet["port"] in r["ports"]):
            return (r["action"], i)
    return ("deny", None)

def shadowed(rules):
    result = []
    for j, later in enumerate(rules):
        for earlier in rules[:j]:
            if (ipaddress.ip_network(later["src"]).subnet_of(ipaddress.ip_network(earlier["src"]))
                    and _ports_cover(earlier["ports"], later["ports"])):
                result.append(j)
                break
    return result
~~~

## VPN: شبكة خاصة فوق شبكة عامة

**VPN** (الشبكة الافتراضية الخاصة) تبني **نفقاً مشفراً** عبر الإنترنت، فيبدو جهازك كأنه داخل شبكة الشركة، ولا يرى من في الطريق (شبكة المقهى أو مزود الخدمة) إلا بيانات مشفرة.

استخداماتها:

- **وصول عن بعد**: موظف يصل لخوادم الشركة الداخلية من بيته.
- **موقع لموقع (Site-to-Site)**: ربط فرعين للشركة دائماً عبر الإنترنت.

وأشهر تقنياتها: **IPsec** و **WireGuard** و **OpenVPN** و SSL VPN.

## كيف يعمل النفق

الحزمة الأصلية (بعناوينها الداخلية) **تُشفَّر كاملة** وتُوضع داخل حزمة جديدة بعناوين عامة بين طرفي النفق. نحاكي ذلك بتشفير **AES-GCM** الحقيقي من مكتبة `cryptography`:

```python
import os, json
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

key = AESGCM.generate_key(bit_length=256)    # مفتاح مشترك يُتفق عليه عند إنشاء النفق
tunnel = AESGCM(key)

inner = {"src": "10.8.0.2", "dst": "10.0.5.20", "data": "GET /payroll"}
nonce = os.urandom(12)
encrypted = tunnel.encrypt(nonce, json.dumps(inner).encode(), None)

outer = {"src": "198.51.100.7", "dst": "203.0.113.1", "proto": "UDP 51820", "payload": encrypted}
print("on the internet:", outer["src"], "->", outer["dst"], outer["proto"])
print("payload readable?", b"payroll" in outer["payload"], "| size:", len(outer["payload"]))

# الطرف الآخر من النفق يفك التشفير ويمرر الحزمة الداخلية
decrypted = json.loads(tunnel.decrypt(nonce, outer["payload"], None))
print("inside the company:", decrypted)

# أي تعديل في الطريق يُكتشف
tampered = bytearray(encrypted); tampered[0] ^= 1
try:
    tunnel.decrypt(nonce, bytes(tampered), None)
except Exception as e:
    print("tampered packet rejected:", type(e).__name__)
```

```output
on the internet: 198.51.100.7 -> 203.0.113.1 UDP 51820
payload readable? False | size: 79
inside the company: {'src': '10.8.0.2', 'dst': '10.0.5.20', 'data': 'GET /payroll'}
tampered packet rejected: InvalidTag
```

- المراقب في الطريق يرى فقط أن جهازك يتحدث مع بوابة VPN، لا ما بداخل الحزمة.
- **AES-GCM** يوفر السرية والسلامة معاً: الحزمة المعدّلة تُرفض.
- WireGuard يعمل على UDP 51820 افتراضياً، و IPsec على UDP 500 و 4500.

## النفق الكامل والنفق المقسوم

- **النفق الكامل (Full Tunnel)**: كل حركتك تمر عبر الشركة، فتراقبها وتحميها، لكنه أبطأ.
- **النفق المقسوم (Split Tunnel)**: فقط حركة شبكات الشركة تدخل النفق، والباقي يذهب للإنترنت مباشرة. أسرع، لكن الجهاز يبقى معرضاً للإنترنت دون حماية الشركة.

```python
import ipaddress

company_routes = [ipaddress.ip_network(n) for n in ["10.0.0.0/16", "172.20.0.0/16"]]

def via(dst, split=True):
    ip = ipaddress.ip_address(dst)
    if not split or any(ip in n for n in company_routes):
        return "tunnel"
    return "direct"

for d in ["10.0.5.20", "172.20.3.3", "142.250.74.14"]:
    print(f"{d:15} split={via(d):7} full={via(d, split=False)}")
```

```output
10.0.5.20       split=tunnel  full=tunnel
172.20.3.3      split=tunnel  full=tunnel
142.250.74.14   split=direct  full=tunnel
```

## ما لا تفعله VPN

VPN تحمي الطريق فقط: لا تحميك من موقع خبيث تزوره، ولا من برمجية خبيثة على جهازك، وخدمات VPN التجارية ترى حركتك هي بدلاً من مزود الإنترنت. والاتجاه الحديث في الشركات: **Zero Trust**، أي لا ثقة تلقائية حتى داخل الشبكة، وكل طلب يُتحقق منه.

~~~solution
import os, json
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.exceptions import InvalidTag

def seal(key, packet):
    nonce = os.urandom(12)
    return nonce + AESGCM(key).encrypt(nonce, json.dumps(packet).encode("utf-8"), None)

def open_sealed(key, blob):
    nonce, data = blob[:12], blob[12:]
    try:
        return json.loads(AESGCM(key).decrypt(nonce, data, None))
    except InvalidTag:
~~~

- المقسوم بلا تشفير
> المقسوم أسرع لكنه أقل حماية.

? لماذا رُفضت الحزمة المعدّلة في مثال AES-GCM؟

- لأن المفتاح انتهى
> التشفير الموثّق (AEAD) يجمع السرية والسلامة.

? هل تحميك VPN من موقع تصيّد تفتحه بنفسك؟

- نعم إذا كانت مدفوعة
