## لماذا الشبكات أولاً؟

كل هجوم وكل دفاع يمر عبر الشبكة: رسالة تصيّد تصل عبر SMTP، وموقع مخترق يُزار عبر HTTP، وجدار ناري يقرر بناءً على عناوين IP والمنافذ. لا يمكنك حماية ما لا تفهمه، لذلك هذه الدورة أساس مجال الأمن السيبراني والحوسبة السحابية معاً.

في هذه الدورة نفهم كل مفهوم ثم نطبقه بـ **Python**: نبني الحزم بايتاً بايتاً بمكتبة `struct`، ونحسب الشبكات الفرعية بمكتبة `ipaddress`، ونحاكي المبدل والموجه والجدار الناري بكود بسيط.

> **ملاحظة:** Python هنا يعمل داخل متصفحك (Pyodide) ولا يستطيع إرسال حزم حقيقية على شبكتك. لذلك نبني الحزم ونحللها في الذاكرة، ونحاكي سلوك الأجهزة بكود نكتبه بأنفسنا. المنطق هو نفسه ما تفعله الأجهزة الحقيقية.

## المشكلة: كيف تتحدث أجهزة مختلفة؟

جهاز Apple في الرياض يفتح موقعاً على خادم Linux في ألمانيا عبر كابلات وألياف وموجات Wi-Fi من شركات مختلفة. الحل: تقسيم المهمة إلى **طبقات**، كل طبقة تؤدي وظيفة واحدة وتعتمد على التي تحتها فقط.

## نموذج OSI: سبع طبقات

| # | الطبقة | وظيفتها | أمثلة |
|---|---|---|---|
| 7 | التطبيقات (Application) | الخدمة التي يستخدمها البرنامج | HTTP و DNS و SMTP |
| 6 | العرض (Presentation) | تنسيق البيانات وتشفيرها | TLS و JPEG و UTF-8 |
| 5 | الجلسة (Session) | فتح الحوار وإدارته | جلسات RPC |
| 4 | النقل (Transport) | توصيل البيانات بين برنامجين (منافذ) | TCP و UDP |
| 3 | الشبكة (Network) | التوجيه بين الشبكات (عناوين IP) | IP و ICMP |
| 2 | ربط البيانات (Data Link) | التوصيل داخل الشبكة المحلية (عناوين MAC) | Ethernet و Wi-Fi |
| 1 | الطبقة المادية (Physical) | الإشارات على الوسط | الكابلات والألياف والموجات |

حيلة للحفظ من الأسفل: **P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way.

## التغليف (Encapsulation)

عند الإرسال تضيف كل طبقة **ترويسة (Header)** خاصة بها حول بيانات الطبقة التي فوقها، وعند الاستقبال تنزع كل طبقة ترويستها:

```python
message = "GET /index.html"

layers = [
    ("Transport", "TCP sport=51000 dport=80"),
    ("Network",   "IP src=192.168.1.10 dst=93.184.216.34"),
    ("Data Link", "ETH src=aa:aa:aa:aa:aa:aa dst=bb:bb:bb:bb:bb:bb"),
]

packet = message
for name, header in layers:
    packet = f"[{header}] {packet}"
    print(f"{name:9} -> {packet}")

print()
# الاستقبال: كل طبقة تنزع ترويستها بالعكس
for name, header in reversed(layers):
    packet = packet.removeprefix(f"[{header}] ")
    print(f"{name:9} removed -> {packet}")
```

```output
Transport -> [TCP sport=51000 dport=80] GET /index.html
Network   -> [IP src=192.168.1.10 dst=93.184.216.34] [TCP sport=51000 dport=80] GET /index.html
Data Link -> [ETH src=aa:aa:aa:aa:aa:aa dst=bb:bb:bb:bb:bb:bb] [IP src=192.168.1.10 dst=93.184.216.34] [TCP sport=51000 dport=80] GET /index.html

Data Link removed -> [IP src=192.168.1.10 dst=93.184.216.34] [TCP sport=51000 dport=80] GET /index.html
Network   removed -> [TCP sport=51000 dport=80] GET /index.html
Transport removed -> GET /index.html
```

ولكل طبقة اسم لوحدة بياناتها: **Segment** في النقل، و **Packet** في الشبكة، و **Frame** في ربط البيانات، و **Bits** في المادية.

## لماذا يهم ذلك أمنياً؟

كل طبقة لها هجماتها ودفاعاتها، ومعرفة الطبقة تحدد الأداة المناسبة:

```python
defenses = {
    7: ("Application", "SQL Injection, XSS", "WAF, input validation"),
    4: ("Transport", "SYN flood", "SYN cookies, rate limiting"),
    3: ("Network", "IP spoofing", "ingress filtering, firewall"),
    2: ("Data Link", "ARP spoofing", "Dynamic ARP Inspection"),
    1: ("Physical", "cable tapping", "locked rooms, fiber"),
}
for layer in sorted(defenses, reverse=True):
    name, attack, defense = defenses[layer]
    print(f"L{layer} {name:12} attack: {attack:20} defense: {defense}")
```

```output
L7 Application  attack: SQL Injection, XSS   defense: WAF, input validation
L4 Transport    attack: SYN flood            defense: SYN cookies, rate limiting
L3 Network      attack: IP spoofing          defense: ingress filtering, firewall
L2 Data Link    attack: ARP spoofing         defense: Dynamic ARP Inspection
L1 Physical     attack: cable tapping        defense: locked rooms, fiber
```

~~~starter
osi = {}

def layer_of(protocol):
    return None

def encapsulate(data, headers):
    return data
~~~
~~~solution
osi = {
    7: ["HTTP", "DNS", "SMTP", "FTP"],
    6: ["TLS"],
    4: ["TCP", "UDP"],
    3: ["IP", "ICMP"],
    2: ["Ethernet", "ARP"],
}

def layer_of(protocol):
    for layer, names in osi.items():
        if protocol.lower() in [n.lower() for n in names]:
            return layer
    return None

def encapsulate(data, headers):
    for h in headers:
        data = f"[{h}] {data}"
    return data
~~~
~~~test
print(layer_of("HTTP"), layer_of("tcp"), layer_of("ICMP"), layer_of("arp"), layer_of("TLS"), layer_of("QUIC2"))
print(encapsulate("hi", ["UDP", "IP", "ETH"]))
~~~
~~~expected
7 4 3 2 6 None
[ETH] [IP] [UDP] hi
~~~

## نموذج TCP/IP: النموذج الذي يعمل فعلاً

OSI نموذج مرجعي للفهم، أما الإنترنت فيعمل بنموذج **TCP/IP** الأبسط بأربع طبقات:

| TCP/IP | يقابل في OSI | البروتوكولات |
|---|---|---|
| التطبيقات | 7 و 6 و 5 | HTTP و DNS و TLS و SSH |
| النقل | 4 | TCP و UDP |
| الإنترنت | 3 | IP و ICMP |
| الوصول للشبكة (Link) | 2 و 1 | Ethernet و Wi-Fi |

## الحزمة الحقيقية بايتات

الترويسات ليست نصوصاً بل **بايتات بترتيب محدد**. ترويسة IPv4 مثلاً 20 بايتاً على الأقل:

| البايت | الحقل |
|---|---|
| 0 | الإصدار (4 بت) وطول الترويسة (4 بت) |
| 1 | نوع الخدمة |
| 2-3 | الطول الكلي |
| 4-7 | المعرّف والأعلام وإزاحة التجزئة |
| 8 | TTL: عدد القفزات المسموحة |
| 9 | البروتوكول: 6 = TCP و 17 = UDP و 1 = ICMP |
| 10-11 | مجموع التحقق (Checksum) |
| 12-15 | عنوان المصدر |
| 16-19 | عنوان الوجهة |

نبنيها ونحللها بـ `struct`: الصيغة `!` تعني ترتيب الشبكة (Big-endian)، و `B` بايت واحد، و `H` بايتان، و `4s` أربعة بايتات:

```python
import struct
import socket

def ipv4_header(src, dst, proto, payload_len, ttl=64):
    version_ihl = (4 << 4) | 5          # IPv4 وطول الترويسة 5 كلمات = 20 بايتاً
    total = 20 + payload_len
    return struct.pack("!BBHHHBBH4s4s",
        version_ihl, 0, total, 0x1c46, 0x4000, ttl, proto, 0,
        socket.inet_aton(src), socket.inet_aton(dst))

hdr = ipv4_header("192.168.1.10", "8.8.8.8", proto=17, payload_len=8)
print(len(hdr), "bytes")
print(hdr.hex(" "))

fields = struct.unpack("!BBHHHBBH4s4s", hdr)
print("version:", fields[0] >> 4, "| header length:", (fields[0] & 0x0F) * 4)
print("total:", fields[2], "| ttl:", fields[5], "| protocol:", fields[6])
print("src:", socket.inet_ntoa(fields[8]), "dst:", socket.inet_ntoa(fields[9]))
```

```output
20 bytes
45 00 00 1c 1c 46 40 00 40 11 00 00 c0 a8 01 0a 08 08 08 08
version: 4 | header length: 20
total: 28 | ttl: 64 | protocol: 17
src: 192.168.1.10 dst: 8.8.8.8
```

هذا بالضبط ما تعرضه أدوات مثل **Wireshark** و **tcpdump**: تقرأ البايتات وتفسّر كل حقل.

## مجموع التحقق (Checksum)

الموجّه يتحقق من سلامة ترويسة IP بمجموع تحقق: نجمع الترويسة كأعداد من 16 بت، ونطوي الفائض، ثم نعكس البتات:

```python
import struct, socket

def checksum(data: bytes) -> int:
    if len(data) % 2:
        data += b"\x00"
    total = sum(struct.unpack(f"!{len(data)//2}H", data))
    while total >> 16:
        total = (total & 0xFFFF) + (total >> 16)
    return ~total & 0xFFFF

hdr = bytearray(struct.pack("!BBHHHBBH4s4s", 0x45, 0, 28, 0x1c46, 0x4000, 64, 17, 0,
                            socket.inet_aton("192.168.1.10"), socket.inet_aton("8.8.8.8")))
c = checksum(bytes(hdr))
hdr[10:12] = struct.pack("!H", c)
print("checksum:", hex(c))
print("verify (should be 0):", checksum(bytes(hdr)))

hdr[8] = 1   # غيّرنا TTL دون تحديث المجموع
print("after tampering:", checksum(bytes(hdr)))
```

```output
checksum: 0x4cc9
verify (should be 0): 0
after tampering: 16128
```

إذا تغيّر أي بايت أثناء النقل لا يصبح الناتج صفراً فتُرمى الحزمة. لكن انتبه: هذا يكشف **الأخطاء العرضية** فقط، لا التلاعب المتعمّد، فالمهاجم يستطيع إعادة حسابه. لحماية السلامة من المهاجمين نحتاج التشفير (TLS و IPsec) كما سنرى.

--- exercise
اكتب دالة `parse_ipv4(data)` تأخذ بايتات حزمة IPv4 (أول 20 بايتاً ترويسة) وترجع قاموساً فيه:

- `"version"`: الإصدار (أعلى 4 بتات من البايت الأول).
- `"ttl"`: البايت 8.
- `"protocol"`: الاسم: `"TCP"` للرقم 6، و `"UDP"` لـ 17، و `"ICMP"` لـ 1، وإلا `"OTHER"`.
- `"src"` و `"dst"`: العنوانان كنص (استخدم `socket.inet_ntoa`).
- `"payload"`: البايتات بعد الترويسة. احسب طول الترويسة من أدنى 4 بتات في البايت الأول مضروبة في 4.

~~~starter
import struct, socket

def parse_ipv4(data):
    return {}
~~~
~~~solution
import struct, socket

def parse_ipv4(data):
    names = {6: "TCP", 17: "UDP", 1: "ICMP"}
    ihl = (data[0] & 0x0F) * 4
    return {
        "version": data[0] >> 4,
        "ttl": data[8],
        "protocol": names.get(data[9], "OTHER"),
        "src": socket.inet_ntoa(data[12:16]),
        "dst": socket.inet_ntoa(data[16:20]),
        "payload": data[ihl:],
    }
~~~
~~~test
pkt = bytes.fromhex("4500002400004000400600000a000005c0a80001") + b"HELLO"
r = parse_ipv4(pkt)
print(r["version"], r["ttl"], r["protocol"], r["src"], r["dst"], r["payload"])
pkt2 = bytes.fromhex("45000020000000008001000008080808ac100001") + b"ping"
r2 = parse_ipv4(pkt2)
print(r2["ttl"], r2["protocol"], r2["src"], r2["dst"], r2["payload"])
~~~
~~~expected
4 64 TCP 10.0.0.5 192.168.0.1 b'HELLO'
128 ICMP 8.8.8.8 172.16.0.1 b'ping'
~~~
