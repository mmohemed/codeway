## عنوان IPv4

عنوان IPv4 رقم من **32 بت** يُكتب أربعة أجزاء (Octets) من 0 إلى 255: `192.168.1.10`. وكل عنوان جزآن:

- **جزء الشبكة**: يحدد الشبكة التي ينتمي لها الجهاز.
- **جزء المضيف (Host)**: يحدد الجهاز داخل الشبكة.

و **قناع الشبكة** أو صيغة **CIDR** يحدد أين ينتهي جزء الشبكة: `/24` تعني أن أول 24 بتاً للشبكة (`255.255.255.0`) و 8 بتات للأجهزة.

مكتبة `ipaddress` المدمجة في Python تحسب كل هذا:

```python
import ipaddress

ip = ipaddress.ip_address("192.168.1.10")
print(int(ip), format(int(ip), "032b"))

net = ipaddress.ip_network("192.168.1.0/24")
print("network:  ", net.network_address)
print("netmask:  ", net.netmask)
print("broadcast:", net.broadcast_address)
print("addresses:", net.num_addresses, "| usable hosts:", net.num_addresses - 2)
hosts = list(net.hosts())
print("first host:", hosts[0], "| last host:", hosts[-1])
print(ip in net, ipaddress.ip_address("192.168.2.10") in net)
```

```output
3232235786 11000000101010000000000100001010
network:   192.168.1.0
netmask:   255.255.255.0
broadcast: 192.168.1.255
addresses: 256 | usable hosts: 254
first host: 192.168.1.1 | last host: 192.168.1.254
True False
```

أول عنوان (عنوان الشبكة) وآخر عنوان (البث Broadcast) لا يُعطيان لأجهزة، لذلك الأجهزة الصالحة في `/24` هي 254.

## العناوين الخاصة و NAT

بعض النطاقات **خاصة** (RFC 1918) تُستخدم داخل البيوت والشركات ولا تُوجَّه على الإنترنت: `10.0.0.0/8` و `172.16.0.0/12` و `192.168.0.0/16`. والموجه المنزلي يترجمها لعنوان عام واحد بتقنية **NAT**:

```python
import ipaddress

for a in ["10.20.30.40", "172.20.1.1", "172.32.0.1", "192.168.100.1", "8.8.8.8", "127.0.0.1", "169.254.10.10"]:
    ip = ipaddress.ip_address(a)
    kind = ("loopback" if ip.is_loopback else
            "link-local" if ip.is_link_local else
            "private" if ip.is_private else "public")
    print(f"{a:15} {kind}")
```

```output
10.20.30.40     private
172.20.1.1      private
172.32.0.1      public
192.168.100.1   private
8.8.8.8         public
127.0.0.1       loopback
169.254.10.10   link-local
```

- `127.0.0.1` هو الجهاز نفسه (localhost).
- `169.254.x.x` يأخذه الجهاز تلقائياً عندما لا يجد خادم DHCP: علامة على مشكلة في الشبكة.
- انتبه: `172.32.0.1` **عام**، فالنطاق الخاص هو `172.16` حتى `172.31` فقط.

## تقسيم الشبكات (Subnetting)

شركة لديها `10.0.0.0/24` وتريد فصل الأقسام أمنياً (المالية عن الضيوف). نقسم الشبكة إلى شبكات فرعية أصغر:

```python
import ipaddress

company = ipaddress.ip_network("10.0.0.0/24")
for sub in company.subnets(new_prefix=26):
    print(sub, "| hosts:", sub.num_addresses - 2, "| range:", sub[1], "-", sub[-2])

print()
# كم بتاً تحتاج لـ 50 جهازاً؟
import math
needed = 50
host_bits = math.ceil(math.log2(needed + 2))
print("need /", 32 - host_bits, "->", 2 ** host_bits - 2, "hosts")
```

```output

10.0.0.64/26 | hosts: 62 | range: 10.0.0.65 - 10.0.0.126
10.0.0.128/26 | hosts: 62 | range: 10.0.0.129 - 10.0.0.190
10.0.0.192/26 | hosts: 62 | range: 10.0.0.193 - 10.0.0.254

need / 26 -> 62 hosts
```

~~~solution
import ipaddress, math

def plan(network, departments):
    net = ipaddress.ip_network(network)
    used = []
    result = {}
    for name, hosts in sorted(departments, key=lambda d: -d[1]):
        prefix = 32 - math.ceil(math.log2(hosts + 2))
        if prefix < net.prefixlen:
            raise ValueError(name)
        for sub in net.subnets(new_prefix=prefix):
            if not any(sub.overlaps(u) for u in used):
                used.append(sub)
                result[name] = str(sub)
                break
        else:
            raise ValueError(name)
    return result
~~~

## طبقة النقل: المنافذ (Ports)

عنوان IP يوصل البيانات للجهاز، و **المنفذ** (0 إلى 65535) يوصلها للبرنامج داخل الجهاز. والاتصال يتحدد بخمسة أشياء: **IP المصدر ومنفذه، و IP الوجهة ومنفذها، والبروتوكول**.

| المنفذ | الخدمة | | المنفذ | الخدمة |
|---|---|---|---|---|
| 22 | SSH | | 443 | HTTPS |
| 25 | SMTP | | 3306 | MySQL |
| 53 | DNS | | 3389 | RDP |
| 80 | HTTP | | 5432 | PostgreSQL |

المنافذ تحت 1024 **معروفة** وتحتاج صلاحيات المدير لفتحها، والعميل يأخذ منفذاً **مؤقتاً** عشوائياً كبيراً (مثل 51000).

## TCP مقابل UDP

| | TCP | UDP |
|---|---|---|
| الاتصال | يبدأ بمصافحة | بلا اتصال |
| الضمان | يضمن الوصول والترتيب ويعيد المفقود | لا ضمان |
| السرعة | أبطأ قليلاً | أسرع وأخف |
| الاستخدام | الويب والبريد ونقل الملفات و SSH | DNS والبث المباشر والألعاب والاتصال الصوتي |

## المصافحة الثلاثية (Three-way Handshake)

قبل أي بيانات في TCP:

1. العميل ← **SYN** (رقم تسلسل ابتدائي عشوائي).
2. الخادم ← **SYN-ACK** (رقمه، ويؤكد رقم العميل + 1).
3. العميل ← **ACK**.

```python
import random
random.seed(7)

def handshake():
    c_isn = random.randint(1000, 9999)
    s_isn = random.randint(1000, 9999)
    log = [
        ("client -> server", "SYN", c_isn, None),
        ("server -> client", "SYN-ACK", s_isn, c_isn + 1),
        ("client -> server", "ACK", c_isn + 1, s_isn + 1),
    ]
    for who, flags, seq, ack in log:
        print(f"{who}  {flags:8} seq={seq}" + (f" ack={ack}" if ack else ""))
    return c_isn + 1, s_isn + 1

seq, ack = handshake()
data = b"GET / HTTP/1.1\r\n\r\n"
print(f"client -> server  PSH-ACK  seq={seq} ack={ack} len={len(data)}")
print(f"server -> client  ACK      ack={seq + len(data)}  (next byte expected)")
```

```output
client -> server  SYN      seq=6305
server -> client  SYN-ACK  seq=3471 ack=6306
client -> server  ACK      seq=6306 ack=3472
client -> server  PSH-ACK  seq=6306 ack=3472 len=18
server -> client  ACK      ack=6324  (next byte expected)
```

رقم ACK يعني "استلمت كل شيء حتى هذا الرقم، أرسل التالي". هكذا يكتشف TCP المفقود ويعيده.

## أعلام TCP بايتاً واحداً

الأعلام بتات في بايت واحد من ترويسة TCP. قراءتها مهارة أساسية في تحليل الحزم:

```python
FLAGS = ["FIN", "SYN", "RST", "PSH", "ACK", "URG", "ECE", "CWR"]

def flags_of(byte):
    return [name for i, name in enumerate(FLAGS) if byte & (1 << i)]

for b in [0x02, 0x12, 0x10, 0x18, 0x11, 0x04]:
    print(hex(b), flags_of(b))
```

```output
0x2 ['SYN']
0x12 ['SYN', 'ACK']
0x10 ['ACK']
0x18 ['PSH', 'ACK']
0x11 ['FIN', 'ACK']
0x4 ['RST']
```

ونمط أمني مهم: سيل من **SYN** دون ACK بعدها هو هجوم **SYN flood** يملأ ذاكرة الخادم باتصالات نصف مفتوحة، ويُدافَع عنه بـ **SYN cookies** وتحديد المعدل. أما **RST** فيقطع الاتصال فوراً.

~~~solution
from collections import Counter

def syn_suspects(packets, threshold):
    syns = Counter(p["src"] for p in packets if p["flags"] == 0x02)
    completed = {p["src"] for p in packets if p["flags"] == 0x10}
    return sorted(ip for ip, n in syns.items() if n >= threshold and ip not in completed)
~~~

## DNS: دليل هاتف الإنترنت

البشر يتذكرون `example.com` والأجهزة تحتاج `93.184.216.34`. **DNS** يترجم الأسماء إلى عناوين، وهو من أول ما يحدث عند فتح أي موقع، ويعمل غالباً على **UDP منفذ 53**.

## أنواع السجلات

| النوع | يربط الاسم بـ | مثال |
|---|---|---|
| `A` | عنوان IPv4 | `example.com → 93.184.216.34` |
| `AAAA` | عنوان IPv6 | |
| `CNAME` | اسم آخر (اسم مستعار) | `www → example.com` |
| `MX` | خادم البريد | `mail.example.com` |
| `TXT` | نص (التحقق و SPF و DMARC لحماية البريد) | `v=spf1 ...` |
| `NS` | الخوادم المسؤولة عن النطاق | |

## رحلة الاستعلام

عندما تسأل عن `www.shop.example`:

1. جهازك يسأل **المحلّل (Resolver)** لدى مزود الخدمة.
2. المحلّل يسأل **خادم الجذر (Root)**: "من المسؤول عن `.example`؟"
3. ثم خادم **TLD** لـ `.example`: "من المسؤول عن `shop.example`؟"
4. ثم **الخادم الموثوق (Authoritative)** فيعطيه الإجابة.
5. المحلّل يحفظ الإجابة في **ذاكرة مؤقتة (Cache)** مدة **TTL** ويعيدها لك.

نحاكي هذه الرحلة بقواميس تمثل الخوادم (المتصفح هنا لا يرسل استعلامات DNS حقيقية):

```python
ROOT = {"example.": "tld-server"}
SERVERS = {
    "tld-server": {"shop.example.": "ns1.shop"},
    "ns1.shop": {
        "shop.example.": {"A": "203.0.113.10", "MX": "mail.shop.example.", "TXT": "v=spf1 ip4:203.0.113.0/24 -all"},
        "www.shop.example.": {"CNAME": "shop.example."},
        "mail.shop.example.": {"A": "203.0.113.25"},
    },
}

def resolve(name, rtype="A", trace=True):
    name = name.rstrip(".") + "."
    labels = name.rstrip(".").split(".")
    tld = labels[-1] + "."                     # example.
    zone = ".".join(labels[-2:]) + "."         # shop.example.
    tld_server = ROOT[tld]
    if trace: print(f"  root: {tld} is served by {tld_server}")
    auth = SERVERS[tld_server][zone]
    if trace: print(f"  {tld_server}: {zone} is served by {auth}")
    record = SERVERS[auth].get(name)
    if record is None:
        return "NXDOMAIN"
    if rtype in record:
        return record[rtype]
    if "CNAME" in record:
        if trace: print(f"  {auth}: {name} is an alias of {record['CNAME']}")
        return resolve(record["CNAME"], rtype, trace)
    return "NODATA"

print("www A:", resolve("www.shop.example"))
print("MX:", resolve("shop.example", "MX", trace=False))
print("TXT:", resolve("shop.example", "TXT", trace=False))
print("nope:", resolve("nope.shop.example", trace=False))
```

```output
  root: example. is served by tld-server
  tld-server: shop.example. is served by ns1.shop
  ns1.shop: www.shop.example. is an alias of shop.example.
  root: example. is served by tld-server
  tld-server: shop.example. is served by ns1.shop
www A: 203.0.113.10
MX: mail.shop.example.
TXT: v=spf1 ip4:203.0.113.0/24 -all
nope: NXDOMAIN
```

## DNS والأمن

DNS أصلاً بلا تشفير ولا توثيق، لذلك هو هدف شائع:

- **تسميم الذاكرة المؤقتة (Cache Poisoning)**: إقناع المحلّل بإجابة مزورة فيُوجَّه المستخدمون لموقع المهاجم. الدفاع: **DNSSEC** الذي يوقّع السجلات رقمياً.
- **التنصت**: أي أحد على الشبكة يرى المواقع التي تزورها. الدفاع: **DNS over HTTPS (DoH)** أو **DNS over TLS**.
- **حماية البريد من الانتحال**: سجلات TXT لـ **SPF** (من يحق له الإرسال باسمك) و **DMARC**.
- مراقبة استعلامات DNS في الشركة تكشف أجهزة مصابة تتصل بنطاقات خبيثة.

## الذاكرة المؤقتة و TTL

```python
class CachingResolver:
    def __init__(self, upstream):
        self.upstream, self.cache, self.queries = upstream, {}, 0

    def lookup(self, name, now):
        hit = self.cache.get(name)
        if hit and hit["expires"] > now:
            return hit["ip"], "cache"
        self.queries += 1
        ip, ttl = self.upstream[name]
        self.cache[name] = {"ip": ip, "expires": now + ttl}
        return ip, "upstream"

r = CachingResolver({"example.com": ("93.184.216.34", 300)})
for t in [0, 10, 299, 300, 450]:
    print(t, r.lookup("example.com", now=t))
print("upstream queries:", r.queries)
```

```output
0 ('93.184.216.34', 'upstream')
10 ('93.184.216.34', 'cache')
299 ('93.184.216.34', 'cache')
300 ('93.184.216.34', 'upstream')
450 ('93.184.216.34', 'cache')
upstream queries: 2
```

TTL الكبير يخفف الحمل لكنه يبطئ انتشار أي تغيير. ولهذا يُخفَّض TTL قبل نقل موقع لخادم جديد.

اكتب صنف `Resolver` يأخذ في البنّاء قاموس سجلات `zone` بالشكل `{الاسم: {"A": ..., "CNAME": ..., "ttl": ...}}`، وفيه:

~~~solution
class Resolver:
    def __init__(self, zone):
        self.zone = zone
        self.upstream_calls = 0
        self.cache = {}

    def lookup(self, name, now):
        hit = self.cache.get(name)
        if hit and hit[1] > now:
            return hit[0]
        current = name
        for _ in range(5):
            self.upstream_calls += 1
            rec = self.zone.get(current)
            if rec is None:
                return "NXDOMAIN"
            if "A" in rec:
                self.cache[name] = (rec["A"], now + rec.get("ttl", 0))
                return rec["A"]
            current = rec["CNAME"]
        return "SERVFAIL"
~~~

## HTTP: لغة الويب

**HTTP** بروتوكول نصي بين المتصفح والخادم: طلب (Request) ثم استجابة (Response).

الطلب: سطر البداية (الطريقة والمسار والإصدار) ثم الترويسات ثم سطر فارغ ثم الجسم:

```text
POST /login HTTP/1.1
Host: shop.example
Content-Type: application/x-www-form-urlencoded
Cookie: lang=ar

user=sara&pass=secret
```

| الطريقة | الاستخدام |
|---|---|
| `GET` | جلب مورد (بلا جسم، والمعاملات في الرابط) |
| `POST` | إرسال بيانات (نموذج، إنشاء) |
| `PUT` / `PATCH` | تعديل |
| `DELETE` | حذف |

ورموز الحالة: `2xx` نجاح (200 OK و 201 Created)، و `3xx` تحويل (301 و 302)، و `4xx` خطأ العميل (400 و 401 غير موثّق و 403 ممنوع و 404 غير موجود)، و `5xx` خطأ الخادم (500).

## تحليل الطلب والاستجابة

```python
from urllib.parse import urlsplit, parse_qs

raw = (
    "GET /search?q=laptop&page=2 HTTP/1.1\r\n"
    "Host: shop.example\r\n"
    "User-Agent: Mozilla/5.0\r\n"
    "Cookie: session=abc123; lang=ar\r\n"
    "\r\n"
)

head, body = raw.split("\r\n\r\n", 1)
lines = head.split("\r\n")
method, target, version = lines[0].split(" ")
headers = dict(l.split(": ", 1) for l in lines[1:])
url = urlsplit(target)

print(method, url.path, version)
print("query:", parse_qs(url.query))
print("host:", headers["Host"])
cookies = dict(c.split("=", 1) for c in headers["Cookie"].split("; "))
print("cookies:", cookies)

response = "HTTP/1.1 302 Found\r\nLocation: https://shop.example/login\r\nSet-Cookie: session=xyz; HttpOnly; Secure; SameSite=Lax\r\n\r\n"
status_line = response.split("\r\n")[0]
print(status_line.split(" ", 2))
```

```output

query: {'q': ['laptop'], 'page': ['2']}
host: shop.example
cookies: {'session': 'abc123', 'lang': 'ar'}
['HTTP/1.1', '302', 'Found']
```

## الكوكيز والأمان

HTTP **بلا حالة**: كل طلب مستقل، لذلك يحفظ الموقع جلستك في **كوكي**. ومن يسرق كوكي الجلسة يدخل حسابك، لذلك خصائصه الأمنية مهمة:

| الخاصية | الحماية |
|---|---|
| `HttpOnly` | JavaScript لا يقرؤه (يحد من سرقته بـ XSS) |
| `Secure` | يُرسل عبر HTTPS فقط |
| `SameSite=Lax` أو `Strict` | لا يُرسل مع طلبات المواقع الأخرى (يحد من CSRF) |

## HTTPS = HTTP فوق TLS

HTTP عادي نص مكشوف: أي أحد في شبكة المقهى يقرأ كلمة مرورك. **HTTPS** يمرر نفس HTTP داخل نفق **TLS** يوفر:

1. **السرية**: التشفير.
2. **السلامة**: أي تعديل يُكتشف.
3. **التوثيق**: الشهادة تثبت أنك تحادث `shop.example` الحقيقي.

```python
steps = [
    "TCP handshake (SYN, SYN-ACK, ACK) to port 443",
    "ClientHello: supported TLS versions + cipher suites + key share",
    "ServerHello: chosen cipher + key share + certificate",
    "Client verifies certificate chain up to a trusted CA",
    "Both derive the same session keys (ECDHE)",
    "Encrypted HTTP request and response",
]
for i, s in enumerate(steps, 1):
    print(i, s)
```

```output
1 TCP handshake (SYN, SYN-ACK, ACK) to port 443
2 ClientHello: supported TLS versions + cipher suites + key share
3 ServerHello: chosen cipher + key share + certificate
4 Client verifies certificate chain up to a trusted CA
5 Both derive the same session keys (ECDHE)
6 Encrypted HTTP request and response
```

وترويسة **HSTS** (`Strict-Transport-Security`) تُلزم المتصفح بـ HTTPS دائماً لذلك الموقع، فتمنع هجمات تخفيض الاتصال إلى HTTP. وتفاصيل التشفير والشهادات في دورة أساسيات الأمن.

--- exercise
اكتب دالة `audit_cookie(header)` تأخذ قيمة ترويسة `Set-Cookie` كاملة (مثل `"session=xyz; HttpOnly; Secure"`) وترجع قائمة بالمشاكل الأمنية مرتبة أبجدياً:

- `"missing HttpOnly"` إن لم توجد الخاصية.
- `"missing Secure"` إن لم توجد.
- `"missing SameSite"` إن لم توجد `SameSite`، و `"weak SameSite"` إن كانت قيمتها `None`.

الخصائص لا تتأثر بحالة الأحرف (`httponly` مثل `HttpOnly`). وإذا لم تكن هناك مشاكل ارجع قائمة فارغة.

ثم اكتب `parse_status(response)` ترجع رمز الحالة **كعدد** من أول سطر في استجابة HTTP.

~~~starter
def audit_cookie(header):
    return []

def parse_status(response):
    return 0
~~~
~~~solution
def audit_cookie(header):
    parts = [p.strip() for p in header.split(";")][1:]
    attrs = {}
    for p in parts:
        k, _, v = p.partition("=")
        attrs[k.lower()] = v
    problems = []
    if "httponly" not in attrs:
        problems.append("missing HttpOnly")
    if "secure" not in attrs:
        problems.append("missing Secure")
    if "samesite" not in attrs:
        problems.append("missing SameSite")
    elif attrs["samesite"].lower() == "none":
        problems.append("weak SameSite")
    return sorted(problems)

def parse_status(response):
    return int(response.split("\r\n")[0].split(" ")[1])
~~~

~~~test
print(parse_status("HTTP/1.1 404 Not Found\r\nContent-Length: 0\r\n\r\n"), parse_status("HTTP/2 201 Created\r\n\r\n") + 1)
~~~
