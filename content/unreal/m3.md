=== lesson
## C++ في Unreal

تحتاج C++ عندما يكبر المشروع: الأداء، والأنظمة المعقدة، والوصول لكل المحرك. والأسلوب الشائع: **الأنظمة الأساسية بـ C++، والتفاصيل والتعديل السريع بـ Blueprints ترث منها**.

الإعداد: مشروع C++ (أو Tools ← New C++ Class في مشروع Blueprint)، ومحرر كود: **Visual Studio** مع حزمة "Game development with C++" أو **JetBrains Rider**. ثم:

- **Tools ← New C++ Class ← Actor** ينشئ ملفين: `MyActor.h` (التعريف) و `MyActor.cpp` (التنفيذ).
- **Live Coding** (Ctrl+Alt+F11) يعيد ترجمة التغييرات والمحرر مفتوح.

## شكل صنف Actor

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Bobber: AFloatingActor pos=(0,150) mesh=Cube Amplitude=60

// file: FloatingActor.h
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "FloatingActor.generated.h"

UCLASS()
class MYGAME_API AFloatingActor : public AActor
{
    GENERATED_BODY()

public:
    AFloatingActor();
    virtual void Tick(float DeltaTime) override;

protected:
    virtual void BeginPlay() override;

    UPROPERTY(EditAnywhere, Category = "Floating")
    float Amplitude = 50.f;

    UPROPERTY(EditAnywhere, Category = "Floating")
    float Speed = 2.f;

private:
    UPROPERTY(VisibleAnywhere)
    UStaticMeshComponent* Mesh;

    FVector StartLocation;
    float RunningTime = 0.f;
};

// file: FloatingActor.cpp
#include "FloatingActor.h"

AFloatingActor::AFloatingActor()
{
    PrimaryActorTick.bCanEverTick = true;
    Mesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
    RootComponent = Mesh;
}

void AFloatingActor::BeginPlay()
{
    Super::BeginPlay();
    StartLocation = GetActorLocation();
    UE_LOG(LogTemp, Warning, TEXT("%s starts at Z=%.1f, amplitude %.1f"), *GetName(), StartLocation.Z, Amplitude);
}

void AFloatingActor::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);
    RunningTime += DeltaTime;
    FVector NewLocation = StartLocation;
    NewLocation.Z += FMath::Sin(RunningTime * Speed) * Amplitude;
    SetActorLocation(NewLocation);
}
// test
step(47);
print(pos("Bobber"));
```

```output
LogTemp: Warning: FloatingActor_0 starts at Z=150.0, amplitude 60.0
[0,210]
```

ما الجديد مقارنة بـ C++ العادية:

- `UCLASS()` و `GENERATED_BODY()`: ماكروهات يقرأها **Unreal Header Tool** ليولّد كود الانعكاس (Reflection)، فيعرف المحرر الصنف ويعرضه.
- **البادئات إلزامية**: `A` للـ Actors (`AFloatingActor`)، و `U` للكائنات والمكوّنات (`UStaticMeshComponent`)، و `F` للهياكل (`FVector`)، و `T` للقوالب (`TArray`)، و `E` للتعدادات، و `b` قبل أسماء المتغيرات المنطقية (`bIsOpen`).
- `UPROPERTY(EditAnywhere)` يُظهر المتغير في Details (هنا `Amplitude=60` من المستوى). و `VisibleAnywhere` يعرضه للقراءة فقط.
- **البنّاء** يُنشئ المكوّنات بـ `CreateDefaultSubobject`، و`BeginPlay` لما يحدث عند بداية اللعب.
- `Super::BeginPlay()` **إلزامي** في كل override: ينفّذ كود الأب (ومنه BeginPlay المكوّنات و Event BeginPlay في Blueprint الابن).
- `PrimaryActorTick.bCanEverTick = true` وإلا لا تُستدعى `Tick`.

## الأنواع والطباعة

| Unreal | بدل | ملاحظة |
|---|---|---|
| `int32` و `int64` | int | حجم مضمون على كل المنصات |
| `float` و `double` | | `1.5f` |
| `bool` | | |
| `FString` | std::string | `TEXT("...")` للنصوص الحرفية |
| `FName` و `FText` | | أسماء سريعة، ونصوص للعرض |
| `FVector` و `FRotator` | | الموقع والدوران |
| `TArray<T>` و `TMap<K,V>` | vector و map | |

```unreal
[level]
Demo: ATypesDemo pos=(0,100)

// file: TypesDemo.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "TypesDemo.generated.h"

UCLASS()
class ATypesDemo : public AActor
{
    GENERATED_BODY()
protected:
    virtual void BeginPlay() override;
};

// file: TypesDemo.cpp
#include "TypesDemo.h"

void ATypesDemo::BeginPlay()
{
    Super::BeginPlay();

    int32 Lives = 3;
    float Health = 72.5f;
    bool bIsAlive = Health > 0.f;
    FString PlayerName = TEXT("Sara");

    UE_LOG(LogTemp, Log, TEXT("%s: lives=%d health=%f alive=%d"), *PlayerName, Lives, Health, bIsAlive);
    UE_LOG(LogTemp, Warning, TEXT("Health rounded: %.1f"), Health);

    FString Message = PlayerName + TEXT(" has ") + FString::FromInt(Lives) + TEXT(" lives");
    UE_LOG(LogTemp, Log, TEXT("%s (length %d)"), *Message, Message.Len());

    TArray<int32> Scores = { 40, 95, 70 };
    Scores.Add(88);
    int32 Best = 0;
    for (int32 S : Scores)
    {
        Best = FMath::Max(Best, S);
    }
    UE_LOG(LogTemp, Log, TEXT("%d scores, best %d, has 70: %d"), Scores.Num(), Best, Scores.Contains(70));

    FVector A(100.f, 0.f, 0.f);
    FVector B = A + FVector(0.f, 0.f, 50.f);
    UE_LOG(LogTemp, Log, TEXT("B = %s, distance = %.2f"), *B.ToString(), FVector::Dist(A, B));
    UE_LOG(LogTemp, Error, TEXT("Something went wrong (just a demo)"));
}
```

```output
LogTemp: Sara: lives=3 health=72.500000 alive=1
LogTemp: Warning: Health rounded: 72.5
LogTemp: Sara has 3 lives (length 16)
LogTemp: 4 scores, best 95, has 70: 1
LogTemp: B = X=100.000 Y=0.000 Z=50.000, distance = 50.00
LogTemp: Error: Something went wrong (just a demo)
```

- `UE_LOG(الفئة, المستوى, TEXT("..."), قيم)`: `%d` للأعداد الصحيحة، و `%f` للعشرية (`%.1f` بخانة واحدة)، و `%s` للنصوص مع **نجمة** قبل الـ FString (`*PlayerName`) لتحويله لنص C.
- المستوى `Warning` يظهر أصفر و `Error` أحمر في Output Log.
- `GEngine->AddOnScreenDebugMessage(-1, 5.f, FColor::Yellow, Text)` يطبع على الشاشة مثل Print String.

// file: Countdown.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "Countdown.generated.h"

UCLASS()
class ACountdown : public AActor
{
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere)
    int32 StartFrom = 5;

protected:
    virtual void BeginPlay() override;

private:
    int32 Current;
    FTimerHandle TimerHandle;
    void Tock();
};

// file: Countdown.cpp
#include "Countdown.h"

void ACountdown::BeginPlay()
{
    Super::BeginPlay();
    Current = StartFrom;
    GetWorldTimerManager().SetTimer(TimerHandle, this, &ACountdown::Tock, 1.0f, true);
}

void ACountdown::Tock()
{
    UE_LOG(LogTemp, Log, TEXT("%d"), Current);
    Current--;
    if (Current < 1)
    {
        UE_LOG(LogTemp, Warning, TEXT("Liftoff!"));
        GetWorldTimerManager().ClearTimer(TimerHandle);
    }
}

## الوراثة والدوال الافتراضية

صنف أب يحدد السلوك المشترك، والأبناء يعدّلونه بـ `virtual` و `override`:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Grunt: AEnemyBase pos=(-300,50) mesh=Cube
Brute: ABrute pos=(0,50) mesh=Cube
Wizard: AWizard pos=(300,50) mesh=Sphere
Arena: AArena pos=(0,300)

// file: EnemyBase.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "EnemyBase.generated.h"

UCLASS()
class AEnemyBase : public AActor
{
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere)
    int32 Health = 50;

    virtual int32 GetDamage() const { return 5; }
    virtual FString Describe() const
    {
        return FString::Printf(TEXT("%s hp=%d dmg=%d"), *GetActorNameOrLabel(), Health, GetDamage());
    }
};

UCLASS()
class ABrute : public AEnemyBase
{
    GENERATED_BODY()
public:
    ABrute() { Health = 120; }
    virtual int32 GetDamage() const override { return 15; }
};

UCLASS()
class AWizard : public AEnemyBase
{
    GENERATED_BODY()
public:
    virtual int32 GetDamage() const override { return AEnemyBase::GetDamage() * 3; }
    virtual FString Describe() const override { return Super::Describe() + TEXT(" (casts spells)"); }
};

// file: Arena.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "Kismet/GameplayStatics.h"
#include "Arena.generated.h"

UCLASS()
class AArena : public AActor
{
    GENERATED_BODY()
protected:
    virtual void BeginPlay() override
    {
        Super::BeginPlay();
        TArray<AActor*> Found;
        UGameplayStatics::GetAllActorsOfClass(GetWorld(), AEnemyBase::StaticClass(), Found);
        int32 Total = 0;
        for (AActor* Actor : Found)
        {
            AEnemyBase* Enemy = Cast<AEnemyBase>(Actor);
            if (Enemy)
            {
                UE_LOG(LogTemp, Log, TEXT("%s"), *Enemy->Describe());
                Total += Enemy->GetDamage();
            }
        }
        UE_LOG(LogTemp, Warning, TEXT("%d enemies, total damage %d"), Found.Num(), Total);
    }
};
```

```output
LogTemp: Grunt hp=50 dmg=5
LogTemp: Brute hp=120 dmg=15
LogTemp: Wizard hp=50 dmg=15 (casts spells)
LogTemp: Warning: 3 enemies, total damage 35
```

- `Cast<AEnemyBase>(Actor)` يرجع المؤشر بالنوع المطلوب أو `nullptr` إن لم يكن منه، فافحصه دائماً قبل الاستخدام.
- `Enemy->Describe()`: السهم `->` للوصول عبر مؤشر.
- `GetDamage` افتراضية، فكل عدو يرجع ضرره الخاص رغم أننا نتعامل معهم كلهم كـ `AEnemyBase`.

## مكوّن مخصص (Actor Component)

بدل تكرار نظام الصحة في كل Actor، اكتبه **مكوّناً** واحداً يُضاف لأي Actor: لاعب أو عدو أو صندوق قابل للكسر:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Crate: ACrate pos=(0,50) mesh=Cube

// file: HealthComponent.h
#pragma once
#include "CoreMinimal.h"
#include "Components/ActorComponent.h"
#include "HealthComponent.generated.h"

UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))
class UHealthComponent : public UActorComponent
{
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    float MaxHealth = 100.f;

    UFUNCTION(BlueprintCallable)
    void TakeDamage(float Amount)
    {
        Health = FMath::Clamp(Health - Amount, 0.f, MaxHealth);
        UE_LOG(LogTemp, Log, TEXT("%s health: %.0f"), *GetOwner()->GetActorNameOrLabel(), Health);
        if (Health <= 0.f)
        {
            UE_LOG(LogTemp, Warning, TEXT("%s destroyed"), *GetOwner()->GetActorNameOrLabel());
            GetOwner()->Destroy();
        }
    }

    UFUNCTION(BlueprintPure)
    bool IsAlive() const { return Health > 0.f; }

protected:
    virtual void BeginPlay() override
    {
        Super::BeginPlay();
        Health = MaxHealth;
    }

private:
    float Health = 0.f;
};

// file: Crate.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "HealthComponent.h"
#include "Crate.generated.h"

UCLASS()
class ACrate : public AActor
{
    GENERATED_BODY()
public:
    ACrate()
    {
        Mesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
        RootComponent = Mesh;
        Health = CreateDefaultSubobject<UHealthComponent>(TEXT("Health"));
        Health->MaxHealth = 30.f;
    }

    UPROPERTY(VisibleAnywhere)
    UStaticMeshComponent* Mesh;

    UPROPERTY(VisibleAnywhere)
    UHealthComponent* Health;
};
// test
step(1);
call("Crate", "Health.TakeDamage", 12);
call("Crate", "Health.TakeDamage", 20);
print("exists:", exists("Crate"));
```

```output
LogTemp: Crate health: 18
LogTemp: Crate health: 0
LogTemp: Warning: Crate destroyed
exists: false
```

- المكوّن يرث `UActorComponent`، و`GetOwner()` يعطيه الـ Actor الذي يحمله.
- `UFUNCTION(BlueprintCallable)` يجعل الدالة **عقدة** في Blueprints، و `BlueprintPure` عقدة نقية بلا دبابيس تنفيذ.
- و `meta=(BlueprintSpawnableComponent)` يُظهر المكوّن في قائمة Add Component في محرر Blueprint.

## من C++ إلى Blueprint

الأسلوب الاحترافي: صنف C++ فيه المنطق، و **Blueprint يرث منه** للتعديل البصري والقيم. هنا Blueprint أبوه صنف C++، ويرد على `Event BeginPlay` الذي يستدعيه `Super::BeginPlay()` في C++:

```unreal
[level]
Pickup: BP_GoldCoin pos=(0,100)

// file: PickupBase.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "PickupBase.generated.h"

UCLASS(Blueprintable)
class APickupBase : public AActor
{
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    int32 Points = 10;

    UFUNCTION(BlueprintCallable)
    int32 Collect() { UE_LOG(LogTemp, Log, TEXT("C++ Collect: +%d"), Points); return Points; }

protected:
    virtual void BeginPlay() override
    {
        UE_LOG(LogTemp, Log, TEXT("C++ BeginPlay before Super"));
        Super::BeginPlay();
        UE_LOG(LogTemp, Log, TEXT("C++ BeginPlay after Super"));
    }
};

Blueprint BP_GoldCoin : APickupBase
Event BeginPlay
  Set Points = 50
  PrintString("Blueprint BeginPlay, points " + ToString(Points))
  PrintString("Collected " + ToString(Collect()))
```

```output
LogTemp: C++ BeginPlay before Super
Blueprint BeginPlay, points 50
LogTemp: C++ Collect: +50
Collected 50
LogTemp: C++ BeginPlay after Super
```

ترتيب الرسائل يوضح السلسلة: C++ BeginPlay ← `Super::BeginPlay()` ← Event BeginPlay في الـ Blueprint ← ثم يكمل C++.

// file: ScoreComponent.h
#pragma once
#include "CoreMinimal.h"
#include "Components/ActorComponent.h"
#include "ScoreComponent.generated.h"

UCLASS()
class UScoreComponent : public UActorComponent
{
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere)
    int32 WinScore = 100;

    UFUNCTION(BlueprintCallable)
    void AddPoints(int32 Amount)
    {
        Score += Amount;
        UE_LOG(LogTemp, Log, TEXT("Score: %d"), Score);
        if (Score >= WinScore && !bHasWon)
        {
            bHasWon = true;
            UE_LOG(LogTemp, Warning, TEXT("%s wins!"), *GetOwner()->GetActorNameOrLabel());
        }
    }

    UFUNCTION(BlueprintPure)
    int32 GetScore() const { return Score; }

private:
    int32 Score = 0;
    bool bHasWon = false;
};
