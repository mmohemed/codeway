## ما هو Unreal Engine؟

**Unreal Engine** محرك Epic Games، وأقوى المحركات رسومياً: تُصنع به ألعاب كبيرة (Fortnite وغيرها)، ويُستخدم في السينما والعمارة والمحاكاة. مجاني للتعلم والتطوير، وتدفع نسبة من الأرباح فقط بعد تجاوز حد كبير من الإيرادات.

تبرمجه بطريقتين، وغالباً تجمع بينهما:

- **Blueprints**: برمجة مرئية بعقد (Nodes) تصلها بأسلاك، دون كتابة كود.
- **C++**: للأداء والأنظمة الكبيرة، مع إضافات Unreal الخاصة.

التثبيت: تنزّل **Epic Games Launcher**، ثم Unreal Engine ← Library ← تثبيت الإصدار (5.x)، ثم تنشئ مشروعاً من قالب (Third Person أو First Person أو Blank) وتختار Blueprint أو C++.

> **عن أمثلة هذه الدورة:** Unreal محرك ثلاثي الأبعاد ضخم يحتاج جهازاً قوياً، فنستخدم هنا **محاكياً تعليمياً** في المتصفح: يعرض المستوى من الجانب (المحور X أفقياً و Z للأعلى) بأشكال مبسطة، ويشغّل Blueprints مكتوبة **نصاً** (كل سطر عقدة بنفس اسمها في المحرر) ومجموعة من C++ بأسلوب Unreal. المفاهيم وأسماء العقد والدوال هي نفسها، لكن الرسوميات والفيزياء الحقيقية أعقد بكثير.

## نوافذ المحرر

| النافذة | ما فيها |
|---|---|
| **Viewport** | المستوى ثلاثي الأبعاد: تتجول فيه بالزر الأيمن للفأرة مع W A S D |
| **Outliner** | كل الـ Actors في المستوى الحالي |
| **Details** | خصائص الـ Actor المحدد ومكوّناته |
| **Content Browser** | ملفات المشروع: Blueprints والمجسمات والمواد والأصوات |
| **Output Log** | الرسائل والأخطاء (Window ← Output Log) |

وزر **Play** يشغّل اللعبة داخل المحرر (PIE: Play In Editor)، و **Esc** يوقفها. وكما في المحركات الأخرى: تعديلات وقت التشغيل تضيع عند الإيقاف.

## الوحدات والمحاور

- الوحدة في Unreal **سنتيمتر**: مكعب البداية 100×100×100 أي متر.
- **X للأمام** و **Y لليمين** و **Z للأعلى** (عكس Unity الذي فيه Y للأعلى).
- الجاذبية -980 سم/ث².

## المستوى (Level) في هذه الدورة

نكتب الـ Outliner نصاً بعد `[level]`: كل سطر `الاسم: الصنف` ثم خصائص مثل `pos=(X, Z)` والمجسم `mesh=Cube` واللون. وبعده الـ Blueprints:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Crate: StaticMeshActor mesh=Cube pos=(-300,50) color=#a0522d
Ball: StaticMeshActor mesh=Sphere pos=(200,400) simulate=true color=#e0b84f
Greeter: BP_Greeter pos=(0,300)

Blueprint BP_Greeter : Actor
Event BeginPlay
  PrintString("Hello Unreal!")
  PrintString("I am at " + ToString(GetActorLocation()))
// test
step(90);
print(pos("Ball"), pos("Crate"));
```

```output
Hello Unreal!
I am at X=0.000 Y=0.000 Z=300.000
[200,50] [-300,50]
```

- `PrintString` أشهر عقدة: تكتب النص على الشاشة وفي Output Log (المحرر الحقيقي يضيف قبلها اسم الـ Blueprint).
- `Event BeginPlay` حدث يستدعيه المحرك مرة عند بداية اللعب، والأسطر المزاحة تحته هي العقد المتصلة بمخرج التنفيذ بالترتيب.
- الموقع `FVector` يُطبع بالصيغة `X=... Y=... Z=...`.
- الكرة مفعّل فيها **Simulate Physics** فسقطت على الأرض، والصندوق ثابت.

## الـ Actor: كل ما في المستوى

**Actor** أي شيء يمكن وضعه في المستوى: صندوق، باب، ضوء، كاميرا، عدو، اللاعب. ومثل Unity، الـ Actor يتكون من **مكوّنات (Components)**:

| المكوّن | وظيفته |
|---|---|
| `StaticMesh` | مجسم مرئي (ومعه تصادم) |
| `BoxCollision` / `SphereCollision` | منطقة تصادم أو تداخل غير مرئية |
| `TextRender` | نص فوق الـ Actor في العالم |
| `ProjectileMovement` | حركة مقذوف (رصاصة) |
| `RotatingMovement` | دوران مستمر |
| `PointLight` و `Audio` و `Camera` | ضوء وصوت وكاميرا |

ويرث الـ Actors من بعضها: **Actor** ← **Pawn** (يمكن التحكم به) ← **Character** (Pawn بجسم وحركة مشي وقفز جاهزة).

## Blueprint Class بمكوّنات

تنشئ Blueprint من Content Browser ← Add ← **Blueprint Class** ← Actor. وفي محرره لوحة **Components** تضيف منها المكوّنات. هنا نكتبها بعد `Components`، وكل مكوّن يصبح متغيراً باسمه:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Sign: BP_Sign pos=(0,100)

Blueprint BP_Sign : Actor
Components
  Body: StaticMesh Cube
  Label: TextRender "Welcome"
Event BeginPlay
  PrintString("Location: " + ToString(GetActorLocation()))
  Label.SetText("Hello!")
  SetActorLocation(Vector(-200, 0, 100))
  AddActorWorldOffset(Vector(0, 0, 50))
  PrintString("New location: " + ToString(GetActorLocation()))
  PrintString("Name: " + GetName())
```

```output
Location: X=0.000 Y=0.000 Z=100.000
New location: X=-200.000 Y=0.000 Z=150.000
Name: BP_Sign_C_0
```

- `GetActorLocation` و `SetActorLocation` و `AddActorWorldOffset` أشهر عقد التحريك.
- `Vector(X, Y, Z)` تصنع FVector (في المحرر عقدة **Make Vector**).
- `GetName()` الاسم الداخلي: اسم الصنف ثم `_C_` ثم رقم، و `GetActorNameOrLabel()` الاسم الظاهر في Outliner.

## Spawn و Destroy

تُنشئ Actors أثناء اللعب بعقدة **Spawn Actor from Class** وتحذفها بـ **Destroy Actor**:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Spawner: BP_Spawner pos=(0,300)

Blueprint BP_Coin : Actor
Components
  Mesh: StaticMesh Sphere

Blueprint BP_Spawner : Actor
Variables
  Count: Integer = 4 (Instance Editable)
Event BeginPlay
  ForLoop Index from 0 to Count - 1
    SpawnActorFromClass(BP_Coin, Vector(-300 + Index * 200, 0, 50))
  PrintString("Coins: " + ToString(GetAllActorsOfClass(BP_Coin).Length()))
  Delay 1
  GetAllActorsOfClass(BP_Coin).Get(0).DestroyActor()
  PrintString("After destroy: " + ToString(GetAllActorsOfClass(BP_Coin).Length()))
// test
step(90);
```

```output
Coins: 4
After destroy: 3
```

- `ForLoop` في Blueprint يشمل **آخر رقم** (Last Index)، لذلك كتبنا `Count - 1`.
- `GetAllActorsOfClass` ترجع مصفوفة كل الـ Actors من ذلك الصنف، وهي بطيئة نسبياً فلا تستدعها كل إطار.
- `Delay` توقف التنفيذ ثانية دون تجميد اللعبة.

## الوسوم (Tags)

لكل Actor قائمة **Tags** (في Details ← Actor ← Tags) تفحصها بـ `ActorHasTag`. هنا `tags=Player` في سطر المستوى:

```unreal
[level]
Hero: Character pos=(-200,100) tags=Player
Bot: StaticMeshActor mesh=Cube pos=(200,50) tags=Enemy
Checker: BP_Tags pos=(0,300)

Blueprint BP_Tags : Actor
Event BeginPlay
  ForEachLoop A in GetAllActorsWithTag("Enemy")
    PrintString(A.GetActorNameOrLabel() + " is an enemy")
  PrintString("Hero is player: " + ToString(GetPlayerCharacter(0).ActorHasTag("Player")))
```

```output
Bot is an enemy
Hero is player: true
```

~~~setup

Components
  Mesh: StaticMesh Cylinder

Blueprint BP_Fence : Actor
Variables
  Posts: Integer = 3 (Instance Editable)
Event BeginPlay
  PrintString("TODO")
~~~
~~~solution
Blueprint BP_Fence : Actor
Variables
  Posts: Integer = 3 (Instance Editable)
  Gap: Float = 150 (Instance Editable)
Event BeginPlay
  ForLoop I from 0 to Posts - 1
    SpawnActorFromClass(BP_Post, Vector(GetActorLocation().X + I * Gap, 0, 50))
  PrintString("Posts: " + ToString(GetAllActorsOfClass(BP_Post).Length()))
~~~

step(1);

~~~

4
