## البرمجة المرئية: العقد والأسلاك

في محرر Blueprint (تبويب **Event Graph**) تضغط بالزر الأيمن وتبحث عن عقدة، ثم تصل بينها بأسلاك. للعقد نوعان من الدبابيس (Pins):

- **دبابيس التنفيذ** (Exec، سهم أبيض): تحدد **الترتيب**: العقدة تعمل عندما يصلها التنفيذ، ثم تمرره للتالية.
- **دبابيس البيانات** (ملونة حسب النوع): قيم تدخل للعقدة وتخرج منها. أحمر Boolean، أخضر فاتح Integer، أخضر Float، وردي String، أصفر Vector، أزرق Object.

والعقد **النقية (Pure)** بلا دبابيس تنفيذ، مثل `GetActorLocation` و `+` و `ToString`: تحسب قيمة فقط حين يحتاجها غيرها.

## كيف نكتب العقد نصاً في هذه الدورة

| في المحرر | هنا |
|---|---|
| حدث أحمر Event BeginPlay | `Event BeginPlay` ثم العقد المتصلة به مزاحة تحته |
| عقدة تنفيذ Print String | `PrintString("Hi")` (اسم العقدة بلا مسافات) |
| عقد نقية متصلة بدبوس | تعبير داخل القوسين: `ToString(Score * 2)` |
| Set Variable | `Set Score = Score + 1` |
| Branch بمخرجي True و False | `Branch شرط` ثم `True:` و `False:` |
| Sequence بمخارج Then 0 و Then 1 | `Sequence` ثم `Then 0:` و `Then 1:` |
| For Loop: Loop Body ثم Completed | `ForLoop I from 0 to 9` ثم العقد المزاحة (Loop Body)، وما بعدها في نفس المستوى يمثل Completed |
| Append لدمج النصوص | `"Score: " + ToString(Score)` |

## Branch: اتخاذ القرار

```unreal
[level]
Tester: BP_Grade pos=(0,100)

Blueprint BP_Grade : Actor
Variables
  Score: Integer = 75
Event BeginPlay
  Branch Score >= 90
    True:
      PrintString("Excellent")
    False:
      Branch Score >= 60
        True:
          PrintString("Passed with " + ToString(Score))
        False:
          PrintString("Try again")
  PrintString("Done")
```

```output
Passed with 75
Done
```

`Branch` يتطلب Boolean، والعقد بعده في نفس المستوى (`Done`) تعمل بعد انتهاء الفرع الذي نُفّذ. في المحرر الحقيقي تصل `Done` بنهاية **كلا** الفرعين، أو تستخدم **Sequence**.

## Sequence و الحلقات

```unreal
[level]
Tester: BP_Loops pos=(0,100)

Blueprint BP_Loops : Actor
Variables
  Names: String[] = ["Ali", "Sara", "Omar"]
Event BeginPlay
  Sequence
    Then 0:
      ForLoop I from 1 to 3
        PrintString("Wave " + ToString(I))
      PrintString("Loop completed")
    Then 1:
      ForEachLoop Name, Index in Names
        PrintString(ToString(Index) + ": " + Name)
    Then 2:
      Local Total: Integer = 0
      Local N: Integer = 1
      WhileLoop N <= 5
        Set Total = Total + N
        Set N = N + 1
      PrintString("Sum 1..5 = " + ToString(Total))
```

```output
Wave 1
Wave 2
Wave 3
Loop completed
0: Ali
1: Sara
2: Omar
Sum 1..5 = 15
```

- **Sequence** ينفّذ مخارجه بالترتيب، ويُستخدم لتنظيم الرسم بدل سلسلة طويلة.
- **ForEachLoop** يعطيك العنصر (Array Element) ورقمه (Array Index).
- `Local` متغير محلي (داخل الدوال في المحرر، **Local Variables**).

## Functions مقابل Events

| | Function | Custom Event |
|---|---|---|
| ترجع قيمة | نعم (Return Node) | لا |
| يمكن أن تحوي Delay | **لا** | نعم |
| تُنفذ | فوراً وتنتظر نتيجتها | فوراً، وتكمل بعد Delay لاحقاً |

```unreal
[level]
Shop: BP_Shop pos=(0,100)

Blueprint BP_Shop : Actor
Variables
  Gold: Integer = 100
Function PriceWithTax (Price: Integer) -> Integer
  Return Price + Price / 10
Function CanAfford (Price: Integer) -> Boolean
  Return Gold >= PriceWithTax(Price)
Custom Event Buy (Price: Integer)
  Branch CanAfford(Price)
    True:
      Set Gold = Gold - PriceWithTax(Price)
      PrintString("Bought! Gold left: " + ToString(Gold))
    False:
      PrintString("Not enough gold")
Event BeginPlay
  PrintString("Price of 50 with tax: " + ToString(PriceWithTax(50)))
  Buy(50)
  Buy(50)
```

```output
Price of 50 with tax: 55
Bought! Gold left: 45
Not enough gold
```

قسمة Integer على Integer صحيحة: `50 / 10 = 5`.

## Delay: الانتظار

`Delay` عقدة **كامنة** (Latent، عليها رمز ساعة): توقف هذا التنفيذ مدة ثم تكمل، واللعبة تعمل. لكنها لا تُستخدم إلا في Event Graph، ولو وصلها التنفيذ مرة ثانية وهي تنتظر **تتجاهله**:

```unreal
[level]
Bomb: BP_Bomb pos=(0,100)

Blueprint BP_Bomb : Actor
Components
  Mesh: StaticMesh Sphere
Event BeginPlay
  Ignite()
  Ignite()
Custom Event Ignite
  PrintString("Fuse lit at " + ToString(GetGameTimeInSeconds()))
  Delay 2
  PrintString("BOOM at " + ToString(GetGameTimeInSeconds()))
  DestroyActor()
// test
step(150);
print("exists:", exists("Bomb"));
```

```output
Fuse lit at 0.0
Fuse lit at 0.0
BOOM at 2.0
exists: false
```

استُدعي `Ignite` مرتين، فطُبع "Fuse lit" مرتين، لكن الانفجار مرة واحدة: التنفيذ الثاني وصل Delay وهي تعمل فتوقف عندها. (لتشغيل مؤقتات متعددة استخدم **Retriggerable Delay** أو **Set Timer by Event**.)

~~~setup

~~~
~~~starter
Blueprint BP_Counter : Actor
~~~

~~~solution
Blueprint BP_Counter : Actor
Variables

    Branch IsEven(I)
~~~

## المتغيرات وأنواعها

من لوحة **My Blueprint** ← Variables ← (+). لكل متغير نوع ولون:

| النوع | مثال | ملاحظة |
|---|---|---|
| Boolean | `IsOpen: Boolean = false` | |
| Integer | `Lives: Integer = 3` | |
| Float | `Speed: Float = 250.5` | في UE5 دقته مزدوجة (double) |
| String / Name / Text | `Title: String = "Door"` | Text للنصوص المعروضة للاعب (قابلة للترجمة) |
| Vector | `Offset: Vector` | X و Y و Z |
| Actor (مرجع) | `Target: Actor` | يشير لـ Actor آخر |
| مصفوفة | `Keys: String[]` | Array |

و **Instance Editable** (أيقونة العين) يجعل المتغير يظهر في Details لكل نسخة في المستوى، فيكون للباب الأول سرعة وللثاني سرعة أخرى. هنا تكتب القيمة في سطر المستوى.

## Event Tick و Delta Seconds

`Event Tick` يُستدعى **كل إطار**، ومعه `DeltaSeconds`: زمن الإطار. اضرب السرعة فيه لتكون "سم في الثانية":

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Platform: BP_Mover pos=(-300,100) Speed=200
Slow: BP_Mover pos=(-300,300) Speed=50

Blueprint BP_Mover : Actor
Components
  Mesh: StaticMesh Cube
Variables
  Speed: Float = 100 (Instance Editable)
  Distance: Float = 0
Event Tick (DeltaSeconds)
  AddActorWorldOffset(Vector(Speed * DeltaSeconds, 0, 0))
  Set Distance = Distance + Speed * DeltaSeconds
  Branch Distance >= 400
    True:
      Set Speed = Speed * -1
      Set Distance = 0
// test
step(60);
print(pos("Platform"), pos("Slow"));
step(90);
print(pos("Platform"), get("Platform", "Speed"));
```

```output
[-100,100] [-250,300]
[6.7,100] -200.0
```

انتبه: Tick كل إطار، فلا تضع فيه عملاً ثقيلاً (مثل GetAllActorsOfClass). وكثير مما يُكتب في Tick أفضل منه **Timer** أو حدث.

## أحداث التداخل: Overlap

إذا كان مكوّن التصادم يسمح بالتداخل (Overlap)، يصلك `Event ActorBeginOverlap` بالـ Actor الآخر عند الدخول، و `Event ActorEndOverlap` عند الخروج:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Player: Character pos=(-400,100) tags=Player
Zone: BP_Zone pos=(0,100)

Blueprint BP_Zone : Actor
Components
  Area: BoxCollision (200, 200)
Variables
  Visitors: Integer = 0
Event ActorBeginOverlap (OtherActor)
  Branch OtherActor.ActorHasTag("Player")
    True:
      Set Visitors = Visitors + 1
      PrintString("Welcome! visits: " + ToString(Visitors))
Event ActorEndOverlap (OtherActor)
  PrintString(OtherActor.GetActorNameOrLabel() + " left")
// test
keyDown("right"); step(150); keyUp("right");
step(30);
```

```output
Welcome! visits: 1
Player left
```

في المعاينة حرّك الـ Character بالأسهم ومرّ خلال المنطقة.

## التواصل بين الـ Blueprints

لكي يطلب Blueprint شيئاً من آخر يحتاج **مرجعاً** إليه: متغير من نوع ذلك الـ Blueprint تضبطه في Details (هنا `Door=@Gate`)، ثم تستدعي دواله وأحداثه. و **Cast To** يتحقق أن Actor عام من صنف معيّن:

```unreal
[level]
Floor: StaticMeshActor mesh=Floor pos=(0,-50)
Gate: BP_Door pos=(200,100)
Lever: BP_Lever pos=(-200,50) Door=@Gate

Blueprint BP_Door : Actor
Components
  Mesh: StaticMesh Cube
Variables
  IsOpen: Boolean = false
Custom Event Open
  Branch IsOpen
    False:
      Set IsOpen = true
      AddActorWorldOffset(Vector(0, 0, 200))
      PrintString("Door opened")

Blueprint BP_Lever : Actor
Variables
  Door: BP_Door (Instance Editable)
  Anything: Actor
Event BeginPlay
  Door.Open()
  Door.Open()
  Set Anything = Door
  CastTo BP_Door (Anything) as AsDoor
    Succeeded:
      PrintString("Cast OK, open = " + ToString(AsDoor.IsOpen))
    Failed:
      PrintString("Not a door")
  CastTo BP_Door (Self) as Me
    Failed:
      PrintString("The lever is not a door")
// test
step(1);
print(pos("Gate"));
```

```output
Door opened
Cast OK, open = true
The lever is not a door
[200,300]
```

البديل الأنظف لربط Blueprints كثيرة: **Blueprint Interfaces** و **Event Dispatchers**، وهي خطوة لاحقة بعد إتقان المراجع والـ Cast.

اكتب `BP_PressurePlate` (Actor):

1. مكوّن `Area: BoxCollision (150, 100)` (تحت `Components`).
2. متغير `Door: BP_SlidingDoor (Instance Editable)` (المستوى يربطه بالباب).
3. في `Event ActorBeginOverlap (OtherActor)`: إذا كان للـ Actor الآخر الوسم `"Player"`:

~~~setup

Player: Character pos=(-400,100) tags=Player

  IsOpen: Boolean = false

  Branch Open != IsOpen
    True:
      Set IsOpen = Open
      Branch Open
        True:
          AddActorWorldOffset(Vector(0, 0, 200))
        False:
          AddActorWorldOffset(Vector(0, 0, -200))
      PrintString("Door open: " + ToString(IsOpen))
~~~

~~~starter
Blueprint BP_PressurePlate : Actor
Event BeginPlay
  PrintString("Plate ready")
~~~
~~~solution
Blueprint BP_PressurePlate : Actor
Components
  Area: BoxCollision (150, 100)
Variables
  Door: BP_SlidingDoor (Instance Editable)
Event ActorBeginOverlap (OtherActor)
  Branch OtherActor.ActorHasTag("Player")
    True:
      Door.SetOpen(true)
      Delay 2
      Door.SetOpen(false)
~~~
