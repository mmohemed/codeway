## _process و _physics_process

Godot يستدعي دالتين كل إطار:

| الدالة | متى | استخدامها |
|---|---|---|
| `_process(delta)` | كل إطار رسم | المنطق العام والواجهة |
| `_physics_process(delta)` | 60 مرة في الثانية بالضبط | **الحركة والفيزياء** |

و`delta` الزمن بالثواني منذ الإطار السابق (1/60 ≈ 0.0167). نضرب السرعة فيه لتكون الحركة "بكسل في الثانية" على كل الأجهزة:

```godot
[scene]
Main: Node2D
  Ball: Node2D pos=(40,160) script=ball.gd color=#ffd84d
    Shape: CollisionShape2D circle=14

# file: ball.gd
extends Node2D

var speed = 200.0

func _physics_process(delta):
	position.x += speed * delta
	if position.x > 440 or position.x < 40:
		speed = -speed
# test
step(60);
print(pos("Ball"), get("Ball", "speed"));
step(70);
print(pos("Ball"), get("Ball", "speed"));
```

```output
[240,160] 200.0
[413.3,160] -200.0
```

بعد ثانية قطعت الكرة 200 بكسل. وعندما تتجاوز 440 تنعكس السرعة.

## الإدخال: Input والأفعال (Actions)

Godot لا يربط الكود بمفاتيح بعينها، بل بـ **أفعال** تُعرَّف في Project Settings ← Input Map. الأفعال الجاهزة: `ui_left` و `ui_right` و `ui_up` و `ui_down` و `ui_accept` (Enter أو المسافة). ويمكنك تعريف أفعالك مثل `jump` و `shoot`:

| الدالة | ترجع true عندما |
|---|---|
| `Input.is_action_pressed("x")` | المفتاح مضغوط الآن (مستمر) |
| `Input.is_action_just_pressed("x")` | ضُغط في هذا الإطار فقط (مرة) |
| `Input.is_action_just_released("x")` | رُفع في هذا الإطار |
| `Input.get_axis("ui_left", "ui_right")` | -1 أو 0 أو 1 |
| `Input.get_vector(...)` | اتجاه Vector2 لأربعة أفعال |

## CharacterBody2D و move_and_slide

**CharacterBody2D** عقدة الشخصية: تضبط سرعتها `velocity` ثم تستدعي `move_and_slide()`، فيحركها Godot ويوقفها عند الجدران والأرض ويجعلها **تنزلق** عليها، ويخبرك هل هي على الأرض بـ `is_on_floor()`.

هذا هو قالب الحركة الذي يولّده Godot نفسه لأي شخصية (مع تعديل بسيط): جاذبية، وحركة يمين ويسار، وقفز. **انقر على المشهد واستخدم الأسهم والمسافة**:

```godot
[input]
jump = space, up

[scene]
Main: Node2D
  Floor: StaticBody2D pos=(240,304) color=#3a7d44
    Shape: CollisionShape2D rect=(480,32)
  Box: StaticBody2D pos=(360,268) color=#8b5a2b
    Shape: CollisionShape2D rect=(60,40)
  Player: CharacterBody2D pos=(100,200) script=player.gd sprite=player
    Shape: CollisionShape2D rect=(32,48)

# file: player.gd
extends CharacterBody2D

const SPEED = 200.0
const JUMP_VELOCITY = -420.0

func _physics_process(delta):
	if not is_on_floor():
		velocity += get_gravity() * delta

	if Input.is_action_just_pressed("jump") and is_on_floor():
		velocity.y = JUMP_VELOCITY

	var direction = Input.get_axis("ui_left", "ui_right")
	if direction:
		velocity.x = direction * SPEED
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)

	move_and_slide()
# test
step(40);
print(pos("Player"), get("Player", "is_on_floor()"));
keyDown("right"); step(90);
print(pos("Player"), "wall:", get("Player", "is_on_wall()"));
keyUp("right"); step(1);
press("space"); step(10);
print("in air:", pos("Player")[1] < 264);
```

```output
[100,264] true
[314,264] wall: true
in air: true
```

- **الجاذبية**: إذا لم تكن على الأرض نزيد السرعة للأسفل كل إطار (`get_gravity()` = 980 بكسل/ث² افتراضياً). لاحظ أن y موجب للأسفل، فالقفز سرعة **سالبة**.
- **القفز**: `just_pressed` حتى لا يقفز مراراً وهو مضغوط، و`is_on_floor()` حتى لا يقفز في الهواء.
- **التوقف**: `move_toward(velocity.x, 0, SPEED)` يُبطئ للصفر بسلاسة.
- `move_and_slide()` يستخدم `velocity` و delta بنفسه، فلا تضربها في delta.
- اصطدم اللاعب بالصندوق فتوقف عنده، و`is_on_wall()` صارت true.

```

```

## أنواع الأجسام الفيزيائية

| العقدة | تتحرك؟ | مثال |
|---|---|---|
| `StaticBody2D` | لا | الأرض، الجدران، المنصات |
| `CharacterBody2D` | بالكود (`move_and_slide`) | اللاعب، الأعداء |
| `RigidBody2D` | بالفيزياء (جاذبية وارتداد) | صناديق، كرات، حطام |
| `Area2D` | لا تصطدم، **تكتشف** التداخل | عملة، فخ، نقطة حفظ، منطقة ماء |

وكل جسم يحتاج ابناً **CollisionShape2D** يحدد شكله: `RectangleShape2D` أو `CircleShape2D` وغيرها. بدون شكل لا تصادم (ويعرض Godot تحذيراً ⚠️ بجانب العقدة).

## Area2D وإشارة body_entered

المنطقة ترسل `body_entered(body)` عندما يدخلها جسم، و`body_exited(body)` عندما يخرج. نربطها بدالة في `_ready`، أو من لوحة **Node ← Signals** في المحرر:

```godot
[scene]
Main: Node2D
  Floor: StaticBody2D pos=(240,304) color=#3a7d44
    Shape: CollisionShape2D rect=(480,32)
  Player: CharacterBody2D pos=(60,260) script=player.gd sprite=player
    Shape: CollisionShape2D rect=(32,48)
  Coin: Area2D pos=(200,272) script=coin.gd sprite=coin
    Shape: CollisionShape2D rect=(16,16)
  Spikes: Area2D pos=(380,280) script=spikes.gd color=#e74c3c
    Shape: CollisionShape2D rect=(40,16)

# file: player.gd
extends CharacterBody2D

var coins = 0

func _physics_process(delta):
	velocity.y += 980 * delta
	velocity.x = 120
	move_and_slide()

# file: coin.gd
extends Area2D

func _ready():
	body_entered.connect(_on_body_entered)

func _on_body_entered(body):
	if body.name == "Player":
		body.coins += 1
		print("coin! total: ", body.coins)
		queue_free()

# file: spikes.gd
extends Area2D

func _ready():
	body_entered.connect(func(body): print(body.name, " hit the spikes!"))
	body_exited.connect(func(body): print(body.name, " left the spikes"))
# test
step(180);
print("coin exists:", exists("Coin"));
```

```output
coin! total: 1
Player hit the spikes!
Player left the spikes
coin exists: false
```

- `queue_free()`: يحذف العقدة (وأبناءها) بأمان في نهاية الإطار.
- لاحظ أن المنطقة لم توقف اللاعب: المناطق تكتشف فقط ولا تصطدم.

## AnimatedSprite2D

**AnimatedSprite2D** تعرض حركات (Animations) مكوّنة من إطارات صور. في المحرر تنشئ مورد **SpriteFrames** وتضيف حركات بأسماء مثل `idle` و `walk` و `jump`، ولكل حركة صورها وسرعتها.

في هذه الدورة صورة اللاعب `player` فيها جاهزة: `idle` (إطار واحد) و `walk` (4 إطارات) و `jump`. والكود يختار الحركة:

| الكود | معناه |
|---|---|
| `$Sprite.play("walk")` | شغّل الحركة (ولا يعيدها من البداية إن كانت تعمل) |
| `$Sprite.stop()` | أوقفها |
| `$Sprite.animation` | اسم الحركة الحالية |
| `$Sprite.flip_h = true` | اقلب الصورة أفقياً (للنظر يساراً) |
| `$Sprite.frame` | رقم الإطار الحالي |

```godot
[scene]
Main: Node2D
  Floor: StaticBody2D pos=(240,304) color=#3a7d44
    Shape: CollisionShape2D rect=(480,32)
  Player: CharacterBody2D pos=(240,200) script=player.gd
    Shape: CollisionShape2D rect=(32,48)
    Sprite: AnimatedSprite2D sprite=player animations=idle,walk,jump

# file: player.gd
extends CharacterBody2D

const SPEED = 160.0
@onready var sprite = $Sprite

func _physics_process(delta):
	if not is_on_floor():
		velocity += get_gravity() * delta
	if Input.is_action_just_pressed("ui_accept") and is_on_floor():
		velocity.y = -400
	var dir = Input.get_axis("ui_left", "ui_right")
	velocity.x = dir * SPEED
	move_and_slide()
	update_animation(dir)

func update_animation(dir):
	if dir != 0:
		sprite.flip_h = dir < 0
	if not is_on_floor():
		sprite.play("jump")
	elif dir != 0:
		sprite.play("walk")
	else:
		sprite.play("idle")
# test
step(30);
print(get("Player/Sprite", "animation"));
keyDown("left"); step(20);
print(get("Player/Sprite", "animation"), get("Player/Sprite", "flip_h"), get("Player/Sprite", "frame"));
keyUp("left"); press("space");
print(get("Player/Sprite", "animation"));
```

```output
idle
walk true 3
jump
```

- `@onready var sprite = $Sprite`: يُحسب عند `_ready`، أي بعد أن تصبح العقد الأبناء جاهزة. لا تكتب `var sprite = $Sprite` بدون `@onready` لأن الأبناء لم يدخلوا الشجرة بعد.
- فصلنا اختيار الحركة في دالة `update_animation`: الحركة تابعة **للحالة** (على الأرض؟ يتحرك؟) لا للمفتاح.
- هذا شكل بسيط من **آلة الحالات** (State Machine)، وهو أسلوب أساسي في برمجة الشخصيات.

## المؤقت Timer و await

**Timer** عقدة ترسل `timeout` بعد مدة (`wait_time`). مفيد للأعداء الذين يطلقون كل ثانية، أو للعد التنازلي:

```godot
[scene]
Main: Node2D script=main.gd
  Spawner: Timer wait_time=0.5 autostart=true
  Label: Label pos=(20,20) text="Waves: 0"

# file: main.gd
extends Node2D

var waves = 0

func _ready():
	$Spawner.timeout.connect(_on_spawn)
	print("start")
	await get_tree().create_timer(1.2).timeout
	print("1.2 seconds later, waves = ", waves)

func _on_spawn():
	waves += 1
	$Label.text = "Waves: " + str(waves)
	if waves == 4:
		$Spawner.stop()
		print("spawner stopped")
# test
step(150);
print(get("Label", "text"));
```

```output
start
1.2 seconds later, waves = 2
spawner stopped
Waves: 4
```

- `autostart=true` يبدأ المؤقت تلقائياً، وإلا تستدعي `$Spawner.start()`.
- `await إشارة`: توقف الدالة **حتى** تصل الإشارة ثم تكمل، دون تجميد اللعبة. و`get_tree().create_timer(ث)` يُنشئ مؤقتاً لمرة واحدة.

~~~solution
extends CharacterBody2D

@onready var sprite = $Sprite

func _physics_process(delta):
	if not is_on_floor():
		velocity += get_gravity() * delta
	if Input.is_action_just_pressed("jump") and is_on_floor():
		velocity.y = -400
	velocity.x = Input.get_axis("ui_left", "ui_right") * 150
	move_and_slide()
	update_animation()

func update_animation():
	if not is_on_floor():
		sprite.play("jump")
	elif velocity.x != 0:
		sprite.play("walk")
	else:
		sprite.play("idle")
	if velocity.x < 0:
		sprite.flip_h = true
	elif velocity.x > 0:
		sprite.flip_h = false
~~~
