## ما هو Godot؟

**Godot** محرك ألعاب مجاني ومفتوح المصدر بالكامل (رخصة MIT): لا رسوم ولا نسبة من الأرباح، وحجمه صغير، ويصدّر للكمبيوتر والجوال والويب. وهو ممتاز للألعاب ثنائية الأبعاد وللبداية في تطوير الألعاب.

تنزّله من موقعه الرسمي godotengine.org وتفتحه مباشرة دون تثبيت، ثم تنشئ مشروعاً جديداً.

> **عن أمثلة هذه الدورة:** محرك Godot الحقيقي برنامج على جهازك، لذلك نستخدم هنا **محاكياً تعليمياً** يعمل في المتصفح: يفهم مجموعة كبيرة من لغة GDScript في Godot 4 ويبني المشهد من العقد ويحرّكه بفيزياء مبسطة. الكود الذي تكتبه هنا هو نفسه الذي تكتبه في Godot، لكن المحرك الحقيقي فيه أكثر بكثير.

## العقد (Nodes)

كل شيء في Godot **عقدة**: الشخصية عقدة، والصورة عقدة، والنص عقدة، والكاميرا عقدة، والصوت عقدة. ولكل نوع وظيفة واحدة:

| العقدة | وظيفتها |
|---|---|
| `Node2D` | عقدة لها موقع في عالم ثنائي الأبعاد |
| `Sprite2D` | تعرض صورة |
| `Label` | تعرض نصاً |
| `CharacterBody2D` | شخصية تتحرك وتصطدم (اللاعب) |
| `StaticBody2D` | جسم ثابت لا يتحرك (أرض، جدار) |
| `Area2D` | منطقة تكتشف من يدخلها (عملة، فخ) |
| `CollisionShape2D` | شكل التصادم لجسم أو منطقة |
| `Timer` | مؤقت |

## المشهد (Scene) وشجرة العقد

العقد تُرتَّب في **شجرة**: لكل عقدة أب وأبناء، و**المشهد** شجرة عقد محفوظة في ملف `.tscn`. في المحرر تراها في لوحة **Scene** هكذا:

```text
Main (Node2D)
├── Player (Sprite2D)
├── Enemy (Sprite2D)
│   └── Eye (Node2D)
└── Title (Label)
```

في هذه الدورة نكتب الشجرة نفسها نصاً بعد `[scene]`: كل سطر `الاسم: النوع` ثم خصائص مثل `pos=(x, y)`، والمسافة البادئة تعني "ابن لما فوقه". و`script=main.gd` تربط سكربتاً بالعقدة، وكود السكربت يأتي بعد `# file: main.gd`:

```godot
[scene]
Main: Node2D script=main.gd
  Player: Sprite2D pos=(100,160) sprite=player
  Enemy: Sprite2D pos=(320,160) sprite=enemy
    Eye: Node2D pos=(0,-10)
  Title: Label pos=(20,20) text="Hello Godot"

# file: main.gd
extends Node2D

func _ready():
	for child in get_children():
		print(child.name, " at ", child.position)
	print("Eye global: ", $Enemy/Eye.global_position)
	$Title.text = "My first scene"
```

```output
Player at (100, 160)
Enemy at (320, 160)
Title at (20, 20)
Eye global: (320, 150)
```

- `extends Node2D`: السكربت **يوسّع** عقدته، فيرث كل خصائصها ودوالها.
- `_ready()`: يستدعيها Godot مرة واحدة عندما تدخل العقدة وأبناؤها الشجرة.
- `get_children()`: أبناء العقدة المباشرون.
- `$Enemy/Eye`: اختصار لـ `get_node("Enemy/Eye")`: مسار العقدة نسبةً للعقدة الحالية.
- `position` نسبةً للأب، و`global_position` في العالم: العين في (0, -10) من العدو، فموقعها الحقيقي (320, 150).

## الإحداثيات في Godot

في Godot ثنائي الأبعاد النقطة (0, 0) في **الزاوية العلوية اليسرى**، و x يزيد يميناً و **y يزيد للأسفل**. والموقع `Vector2` فيه x و y:

```godot
[scene]
Main: Node2D script=main.gd
  Box: Node2D pos=(240,160) color=#ffd84d
    Shape: CollisionShape2D rect=(40,40)

# file: main.gd
extends Node2D

func _ready():
	var box = $Box
	box.position.x += 100
	box.position = box.position + Vector2(0, -50)
	print(box.position)
	print(Vector2(3, 4).length())
	print(Vector2.RIGHT * 10)
```

```output
(340, 110)
5.0
(10, 0)
```

`Vector2` نوع أساسي في كل لعبة ثنائية الأبعاد: للموقع والسرعة والاتجاه، وفيه دوال مثل `length()` و `normalized()` و `distance_to()`.

## المشاهد كقوالب: preload و instantiate

قوة Godot أن **أي مشهد يمكن أن يصبح جزءاً من مشهد آخر**. تصمم العملة مرة في `coin.tscn`، ثم تنشئ منها نسخاً كثيرة بالكود:

```godot
[template coin.tscn]
Coin: Area2D sprite=coin
  Shape: CollisionShape2D rect=(16,16)

[scene]
Main: Node2D script=main.gd

# file: main.gd
extends Node2D

const CoinScene = preload("res://coin.tscn")

func _ready():
	for i in 5:
		var coin = CoinScene.instantiate()
		coin.position = Vector2(80 + i * 80, 160)
		add_child(coin)
	print("children: ", get_child_count())
```

```output
children: 5
```

- `preload("res://...")`: يحمّل المشهد مرة عند تحميل السكربت. و`res://` جذر مجلد المشروع.
- `instantiate()`: ينشئ نسخة جديدة من شجرة المشهد.
- `add_child(node)`: يضيفها للشجرة كابن، وعندها تظهر وتُستدعى `_ready` فيها.
- `for i in 5`: تكرار من 0 إلى 4.

وبنفس الطريقة تُبنى الأعداء والطلقات والمستويات: مشهد صغير لكل شيء، ثم تجميعها.

## لغة GDScript

**GDScript** لغة Godot الأساسية: تشبه Python في شكلها (المسافة البادئة بدل الأقواس)، ومصممة للألعاب ومدمجة في المحرر. ويدعم Godot أيضاً C#، لكن GDScript هي الأسهل والأكثر استخداماً.

كل ملف `.gd` **صنف** (class) يبدأ بـ `extends` نوع العقدة.

## المتغيرات والأنواع

```godot
extends Node2D

var health = 100
var speed: float = 250.5
var player_name := "Sara"
const MAX_HEALTH = 100

func _ready():
	print(health, " / ", MAX_HEALTH)
	print(player_name, " speed: ", speed)
	print(7 / 2, " ", 7 / 2.0, " ", 7 % 2)
	print(typeof(health) == TYPE_INT)
```

```output
100 / 100
Sara speed: 250.5
3 3.5 1
true
```

- `var` متغير، و`const` ثابت لا يتغير.
- `: float` نوع صريح، و`:=` يستنتج النوع من القيمة ويثبّته. **الأنواع الثابتة تكشف الأخطاء مبكراً** وهي الأسلوب المنصوح به.
- انتبه: `7 / 2` بين عددين صحيحين = **3** (قسمة صحيحة)، و`7 / 2.0` = 3.5.

## الدوال والشروط

```godot
extends Node2D

func damage(hp: int, amount: int) -> int:
	return max(hp - amount, 0)

func rank(score: int) -> String:
	if score >= 90:
		return "A"
	elif score >= 70:
		return "B"
	else:
		return "C"

func _ready():
	print(damage(100, 30), " ", damage(20, 50))
	print(rank(95), rank(75), rank(10))
	var state = "jump"
	match state:
		"idle":
			print("standing")
		"run", "jump":
			print("moving")
		_:
			print("unknown")
```

```output
70 0
ABC
moving
```

- `func اسم(معامل: نوع) -> نوع_الإرجاع:`.
- `if` و `elif` و `else`، والعوامل المنطقية `and` و `or` و `not`.
- `match` مثل switch: `_` تعني "أي قيمة أخرى".

## المصفوفات والقواميس والحلقات

```godot
extends Node2D

var inventory = ["sword", "shield"]
var stats = {"hp": 100, "mp": 40}

func _ready():
	inventory.append("potion")
	print(inventory, " size: ", inventory.size())
	print("has shield: ", "shield" in inventory)
	for item in inventory:
		print("- ", item)
	stats["hp"] -= 25
	for key in stats:
		print(key, " = ", stats[key])
	var total = 0
	for i in range(1, 6):
		total += i
	print("total: ", total)
```

```output
["sword", "shield", "potion"] size: 3
has shield: true
- sword
- shield
- potion
hp = 75
mp = 40
total: 15
```

## @export: متغيرات تظهر في المحرر

```gdscript
@export var speed: float = 200.0
@export var max_jumps: int = 2
```

`@export` تجعل المتغير يظهر في لوحة **Inspector** في المحرر، فيغيّر المصمم القيمة لكل عقدة دون لمس الكود. في مشاهد هذه الدورة تكتب القيمة في سطر العقدة، مثل `speed=300`.

## الإشارات (Signals)

**الإشارة** رسالة ترسلها العقدة عندما يحدث شيء، وأي عقدة أخرى يمكنها **الاتصال** بها. هكذا تتواصل العقد دون أن تعرف تفاصيل بعضها:

```godot
extends Node2D

signal health_changed(new_value)
signal died

var health = 100

func _ready():
	health_changed.connect(_on_health_changed)
	died.connect(func(): print("Game Over"))
	take_damage(40)
	take_damage(70)

func take_damage(amount):
	health = max(health - amount, 0)
	health_changed.emit(health)
	if health == 0:
		died.emit()

func _on_health_changed(value):
	print("HP: ", value)
```

```output
HP: 60
HP: 0
Game Over
```

- `signal اسم(معاملات)`: تعريف الإشارة.
- `.connect(دالة)`: اربط دالة تُستدعى عند الإرسال، ويمكن أن تكون دالة مجهولة `func(): ...`.
- `.emit(قيم)`: أرسل الإشارة.

العقد الجاهزة لها إشارات أيضاً: الزر `pressed`، والمؤقت `timeout`، والمنطقة `body_entered`. وسنستخدمها في الدروس القادمة.

~~~solution
extends Node2D

func heal(hp: int, amount: int) -> int:
	return min(hp + amount, 100)

func grade(score: int) -> String:
	if score >= 1000:
		return "gold"
	elif score >= 500:
		return "silver"
	return "bronze"

func total_damage(hits: Array) -> int:
	var total = 0
	for h in hits:
		total += h
	return total
~~~
