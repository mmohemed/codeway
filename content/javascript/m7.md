## استخراج القيم بسطر واحد

**التفكيك (Destructuring)** صيغة تتيح لك استخراج قيم من مصفوفة أو كائن وتخزينها في متغيرات مباشرة. ستراها في كل كود حديث، خاصة في React.

## تفكيك الكائنات

بدلاً من:

```js
const user = { name: "ياسر", age: 27, city: "الدمام" };
const name1 = user.name;
const age1 = user.age;
console.log(name1, age1);
```

```output
ياسر 27
```

نكتب:

```js
const user = { name: "ياسر", age: 27, city: "الدمام" };
const { name, age } = user;
console.log(name, age);
```

```output
ياسر 27
```

أسماء المتغيرات بين `{ }` يجب أن تطابق أسماء الخصائص، والترتيب لا يهم.

### إعادة التسمية والقيم الافتراضية

```js
const product = { title: "حقيبة", price: 120 };

const { title: productName, price, discount = 0 } = product;
console.log(productName, price, discount);
```

```output
حقيبة 120 0
```

- `title: productName` يعني: خذ الخاصية `title` وخزّنها في متغير اسمه `productName`.
- `discount = 0` قيمة افتراضية إذا لم تكن الخاصية موجودة.

### التفكيك المتداخل

```js
const order = { id: 5, customer: { name: "رنا", address: { city: "مكة" } } };
const { customer: { name, address: { city } } } = order;
console.log(name, city);
```

```output
رنا مكة
```

## تفكيك المصفوفات

هنا يعتمد التفكيك على **الترتيب** وليس الأسماء:

```js
const rgb = [255, 128, 0];
const [red, green, blue] = rgb;
console.log(red, green, blue);

const [first, , third] = ["أ", "ب", "ج"];
console.log(first, third);
```

```output
255 128 0
أ ج
```

الفاصلة الفارغة تتخطى عنصراً.

### حيلة: تبديل متغيرين

```js
let a = 1;
let b = 2;
[a, b] = [b, a];
console.log(a, b);
```

```output
2 1
```

## التفكيك في معاملات الدوال

هذا هو الاستخدام الأكثر شيوعاً على الإطلاق:

```js
function createCard({ name, role = "عضو", skills }) {
  return `${name} (${role}) - ${skills.length} مهارات`;
}

console.log(createCard({ name: "دانة", skills: ["JS", "CSS"] }));
console.log(createCard({ name: "فارس", role: "مدير", skills: ["قيادة"] }));
```

```output
دانة (عضو) - 2 مهارات
فارس (مدير) - 1 مهارات
```

مزايا تمرير كائن بدلاً من معاملات متعددة: الترتيب لا يهم، والخيارات الاختيارية واضحة، ومن يقرأ الاستدعاء يعرف معنى كل قيمة.

## مع الحلقات

```js
const scores = { "علي": 90, "منى": 85 };
for (const [student, score] of Object.entries(scores)) {
  console.log(`${student}: ${score}`);
}

const users = [{ id: 1, name: "هيا" }, { id: 2, name: "بدر" }];
console.log(users.map(({ name }) => name));
```

```output
علي: 90
منى: 85
["هيا","بدر"]
```

## ملخص الدرس

- تفكيك الكائن `const { a, b } = obj` يعتمد على الأسماء.
- تفكيك المصفوفة `const [x, y] = arr` يعتمد على الترتيب.
- يمكن إعادة التسمية `{ a: newName }` ووضع قيم افتراضية `{ a = 5 }`.
- التفكيك في معاملات الدوال يجعلها أوضح وأكثر مرونة.

## ثلاث نقاط بوظيفتين

العلامة `...` لها وظيفتان متعاكستان حسب مكانها:

- **الانتشار (Spread):** تفرد عناصر المصفوفة أو خصائص الكائن.
- **التجميع (Rest):** تجمع عدة عناصر في مصفوفة أو كائن واحد.

## Spread مع المصفوفات

```js
const fruits = ["تفاح", "موز"];
const veggies = ["جزر", "خس"];

const all = [...fruits, ...veggies, "ليمون"];
console.log(all);

const copy = [...fruits];
copy.push("عنب");
console.log(fruits.length, copy.length);

console.log(Math.max(...[4, 18, 7]));
```

```output
["تفاح","موز","جزر","خس","ليمون"]
2 3
18
```

- دمج المصفوفات بسهولة.
- إنشاء **نسخة** مستقلة، فتعديل `copy` لا يغيّر `fruits`.
- تمرير عناصر مصفوفة كوسائط منفصلة لدالة.

## Spread مع الكائنات

```js
const defaults = { theme: "light", fontSize: 14, lang: "ar" };
const userSettings = { fontSize: 18 };

const settings = { ...defaults, ...userSettings };
console.log(settings);
```

```output
{"theme":"light","fontSize":18,"lang":"ar"}
```

عند تكرار خاصية، **الأخيرة تفوز**. وهذا نمط شائع لدمج الإعدادات الافتراضية مع إعدادات المستخدم.

## التحديث دون تعديل الأصل

في React والتطبيقات الحديثة نفضّل **عدم تعديل** البيانات الأصلية، بل إنشاء نسخة جديدة معدّلة:

```js
const user = { name: "لمى", age: 24, city: "جدة" };
const updated = { ...user, age: 25 };

console.log(user.age, updated.age);

const todos = ["أ", "ب"];
const withNew = [...todos, "ج"];
const withoutFirst = todos.filter((_, i) => i !== 0);
console.log(todos, withNew, withoutFirst);
```

```output
24 25
["أ","ب"] ["أ","ب","ج"] ["ب"]
```

## تذكير: النسخ بالمرجع

```js
const original = { tags: ["js"] };

const sameRef = original;
sameRef.tags = ["css"];
console.log(original.tags);

const shallow = { ...original };
shallow.tags.push("html");
console.log(original.tags);

const deep = structuredClone(original);
deep.tags.push("node");
console.log(original.tags.length, deep.tags.length);
```

```output
["css"]
["css","html"]
2 3
```

> ⚠️ `...` تنشئ **نسخة سطحية**: المستوى الأول جديد، لكن الكائنات والمصفوفات المتداخلة ما زالت مشتركة. للنسخ العميق استخدم `structuredClone`.

## Rest في الدوال: عدد غير محدود من الوسائط

```js
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

console.log(sum(1, 2));
console.log(sum(5, 10, 15, 20));

function log(level, ...messages) {
  console.log(`[${level}] ${messages.join(" | ")}`);
}
log("خطأ", "فشل الاتصال", "إعادة المحاولة");
```

```output
3
50
[خطأ] فشل الاتصال | إعادة المحاولة
```

معامل الـ rest يجب أن يكون **الأخير** دائماً.

## Rest مع التفكيك

```js
const [winner, ...others] = ["سلمى", "حمد", "ريان"];
console.log(winner, others);

const { password, ...publicData } = { id: 1, name: "زيد", password: "123" };
console.log(publicData);
```

```output
سلمى ["حمد","ريان"]
{"id":1,"name":"زيد"}
```

المثال الثاني نمط مفيد جداً: إزالة خاصية حساسة قبل إرسال البيانات.

## ملخص الدرس

- `...` في مكان **القيم** = انتشار: تفرد العناصر (دمج، نسخ، تمرير).
- `...` في مكان **المتغيرات أو المعاملات** = تجميع: تجمع الباقي.
- `{ ...obj, key: newValue }` لتحديث كائن دون تعديل الأصل.
- النسخ بـ `...` سطحي، و `structuredClone` للنسخ العميق.

## تقسيم المشروع إلى ملفات

المشاريع الحقيقية فيها آلاف الأسطر. وضعها في ملف واحد كارثة. **الوحدات (Modules)** تتيح تقسيم الكود إلى ملفات صغيرة، كل ملف مسؤول عن شيء واحد، ويختار ما يشاركه مع الملفات الأخرى.

## export: ما يشاركه الملف

```js-error
// ملف math.js
export const PI = 3.14159;

export function circleArea(r) {
  return PI * r * r;
}

function secretHelper() {
  // غير مُصدَّرة، فلا يراها أي ملف آخر
}
```

## import: استخدام ما شاركه ملف آخر

```js-error
// ملف app.js
import { PI, circleArea } from "./math.js";

console.log(circleArea(2));
```

- `export` قبل التعريف يجعله متاحاً للخارج.
- `import { ... } from "مسار"` يستورد بالاسم، وصيغتها تشبه التفكيك.
- كل ما لم يُصدَّر يبقى **خاصاً** بالملف.

## التصدير الافتراضي (default)

كل ملف يمكن أن يكون له تصدير **افتراضي واحد**، عادة الشيء الرئيسي فيه:

```js-error
// ملف User.js
export default class User {
  constructor(name) { this.name = name; }
}

// ملف app.js
import User from "./User.js";       // بدون { }، وبأي اسم تختاره
import { PI as pi } from "./math.js"; // إعادة تسمية الاستيراد المسمى
import * as math from "./math.js";    // استيراد كل شيء في كائن واحد
```

| النوع | التصدير | الاستيراد |
|---|---|---|
| مسمّى | `export const x` | `import { x } from` |
| افتراضي | `export default ...` | `import anyName from` |

## استخدام الوحدات في المتصفح

نضيف `type="module"` لوسم script:

```html
<script type="module" src="app.js"></script>
```

مزايا هذا النوع: يعمل تلقائياً بعد تحميل الصفحة مثل `defer`، ويعمل بالوضع الصارم، ومتغيراته لا تتسرب للنطاق العام.

> ⚠️ الوحدات لا تعمل عند فتح الملف مباشرة بـ `file://` بسبب قيود الأمان. تحتاج خادماً محلياً مثل إضافة Live Server في VS Code، أو أداة مثل Vite.

## مكتبات npm

نفس الصيغة تستخدم لاستيراد المكتبات المثبتة بـ npm:

```js-error
import { format } from "date-fns";
import React, { useState } from "react";
```

## قبل الوحدات: نمط الوحدة (Module Pattern)

قبل وجود `import` و `export`، كان المطورون يحققون نفس الفكرة بالإغلاق (Closures) الذي تعلمناه: دالة تُستدعى فوراً، تخفي ما بداخلها، وتُرجع فقط ما تريد مشاركته:

```js
const counterModule = (() => {
  let count = 0;
  const log = msg => `[عدّاد] ${msg}`;

  return {
    increment() { count++; return log(count); },
    reset() { count = 0; return log("تم التصفير"); }
  };
})();

console.log(counterModule.increment());
console.log(counterModule.increment());
console.log(counterModule.reset());
console.log(typeof count, typeof counterModule.log);
```

```output
[عدّاد] 1
[عدّاد] 2
[عدّاد] تم التصفير
undefined undefined
```

`count` و `log` خاصّان تماماً، كما في الوحدة التي لم تُصدّرهما. ستقابل هذا النمط في الأكواد القديمة، وفهمه يعمّق فهمك للإغلاق والوحدات معاً.

## ملخص الدرس

- الوحدات تقسّم المشروع إلى ملفات، وكل ملف يختار ما يُصدّره.
- `export` و `import { x }` للتصدير المسمّى، و `export default` لتصدير رئيسي واحد.
- في المتصفح: `<script type="module">` وتحتاج خادماً محلياً.
- نمط الوحدة القديم يعتمد على الإغلاق لإخفاء التفاصيل.

## قالب لإنشاء كائنات متشابهة

تخيّل أنك تبني لعبة فيها 100 لاعب، لكل منهم اسم ونقاط ومستوى، وكلهم يستطيعون `attack()` و `levelUp()`. كتابة 100 كائن يدوياً مستحيل. **الصنف (Class)** هو **قالب** نصنع منه كائنات بنفس البنية والسلوك.

## تعريف صنف وإنشاء كائنات

```js
class Player {
  constructor(name) {
    this.name = name;
    this.score = 0;
    this.level = 1;
  }

  addPoints(points) {
    this.score += points;
    if (this.score >= 100) {
      this.level++;
      this.score -= 100;
    }
  }

  describe() {
    return `${this.name} - المستوى ${this.level} (${this.score} نقطة)`;
  }
}

const p1 = new Player("صقر");
const p2 = new Player("غيمة");
p1.addPoints(130);
p2.addPoints(40);
console.log(p1.describe());
console.log(p2.describe());
```

```output
صقر - المستوى 2 (30 نقطة)
غيمة - المستوى 1 (40 نقطة)
```

- `class Player` تعريف القالب، واسم الصنف يبدأ بحرف كبير عرفاً.
- `constructor` دالة خاصة تُنفَّذ تلقائياً عند الإنشاء بـ `new`، ومهمتها تجهيز الخصائص.
- `this` تشير إلى **الكائن الحالي** نفسه، فـ `this.name` هي خاصية هذا اللاعب تحديداً.
- `new Player("صقر")` تنشئ كائناً جديداً من القالب، ويسمى **نسخة (instance)**.

## الوراثة: extends

يمكن لصنف أن **يرث** كل ما في صنف آخر ويضيف عليه:

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    return `${this.name} يصدر صوتاً`;
  }
}

class Cat extends Animal {
  constructor(name, color) {
    super(name);
    this.color = color;
  }
  speak() {
    return `${this.name} يقول مياو`;
  }
}

const generic = new Animal("حيوان");
const cat = new Cat("مشمش", "برتقالي");
console.log(generic.speak());
console.log(cat.speak());
console.log(cat.color, cat instanceof Animal);
```

```output
حيوان يصدر صوتاً
مشمش يقول مياو
برتقالي true
```

- `extends Animal` تعني أن `Cat` يرث من `Animal`.
- `super(name)` تستدعي constructor الأب، ويجب استدعاؤها قبل استخدام `this`.
- تعريف `speak` في الابن **يتجاوز (override)** نسخة الأب.

## الخصائص الخاصة (#)

بإضافة `#` قبل اسم الخاصية تصبح **خاصة**، فلا يمكن الوصول إليها من خارج الصنف:

```js
class BankAccount {
  #balance = 0;

  deposit(amount) {
    if (amount <= 0) return "مبلغ غير صالح";
    this.#balance += amount;
    return `تم الإيداع، الرصيد: ${this.#balance}`;
  }

  get balance() {
    return this.#balance;
  }
}

const acc = new BankAccount();
console.log(acc.deposit(200));
console.log(acc.deposit(-50));
console.log(acc.balance);
console.log(acc["#balance"]);
```

```output
تم الإيداع، الرصيد: 200
مبلغ غير صالح
200
undefined
```

`get balance()` تسمى **getter**: تُقرأ كخاصية `acc.balance` دون أقواس، لكنها دالة لا تسمح إلا بالقراءة. هكذا لا يمكن تعديل الرصيد إلا عبر `deposit` التي تتحقق من المبلغ.

## الدوال الثابتة (static)

تنتمي للصنف نفسه وليس للنسخ:

```js
class Temperature {
  static toFahrenheit(c) {
    return c * 9 / 5 + 32;
  }
}
console.log(Temperature.toFahrenheit(30));
```

```output
86
```

## ملخص الدرس

- الصنف قالب، و `new` تنشئ نسخاً منه.
- `constructor` يجهّز الخصائص، و `this` تشير للكائن الحالي.
- `extends` للوراثة، و `super()` لاستدعاء الأب.
- `#prop` للخصائص الخاصة، و `get` للقراءة المحمية، و `static` لدوال الصنف نفسه.

## بناء HTML بالقوالب

هذا من أشهر الاستخدامات: توليد عناصر الصفحة من البيانات بـ `map` ثم `join`:

```js
const products = [
  { name: "ساعة", price: 300 },
  { name: "حقيبة", price: 150 }
];

const html = `
<ul class="products">
  ${products.map(p => `<li>${p.name}: ${p.price} ريال</li>`).join("\n  ")}
</ul>`;
console.log(html.trim());
```

```output
<ul class="products">
  <li>ساعة: 300 ريال</li>
  <li>حقيبة: 150 ريال</li>
</ul>
```

لاحظ القالب **داخل** قالب، وهذا مسموح تماماً.

> ⚠️ تذكّر درس DOM: إذا كانت البيانات من المستخدم، لا تضعها في `innerHTML` مباشرة دون تنظيفها، حتى لو بنيتها بقالب نصي.

## القوالب الموسومة (Tagged Templates)

ميزة متقدمة: يمكن وضع **دالة** قبل القالب لتعالجه بطريقتها. الدالة تستقبل الأجزاء النصية الثابتة، ثم القيم:

```js
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) => {
    const value = i < values.length ? `[${values[i]}]` : "";
    return result + str + value;
  }, "");
}

const user = "ماهر";
const points = 350;
console.log(highlight`المستخدم ${user} جمع ${points} نقطة`);
```

```output
المستخدم [ماهر] جمع [350] نقطة
```

- `strings` = `["المستخدم ", " جمع ", " نقطة"]` الأجزاء الثابتة.
- `values` = `["ماهر", 350]` القيم.

قد لا تكتبها كثيراً بنفسك، لكنك ستراها في مكتبات مشهورة مثل styled-components و GraphQL.

## String.raw: النص كما هو

```js
console.log(String.raw`C:\new\table`);
console.log(`C:\\new\\table`);
```

```output

C:\new\table
```

`String.raw` يتجاهل معنى `\` الخاص، وهو مفيد لمسارات الملفات والتعابير النمطية.

## ملخص الدرس

- القوالب تدعم الأسطر المتعددة مباشرة.
- أي تعبير JavaScript يمكن وضعه داخل `${ }`: عمليات، ودوال، وعامل ثلاثي.
- `map` مع `join` داخل قالب لتوليد HTML من البيانات.
- القوالب الموسومة تمرر القالب لدالة تعالجه.

اكتب دالة `receipt(customer, items)` تُرجع إيصالاً نصياً **متعدد الأسطر** بقالب واحد، بهذا الشكل بالضبط:

function receipt(customer, items) {
  const lines = items.map(i => `- ${i.name} × ${i.qty} = ${i.price * i.qty}`).join("\n");
  const total = items.reduce((sum, i) => sum + i.price * i.qty, 0);
  return `العميل: ${customer}
${lines}
الإجمالي: ${total}`;
}

console.log(receipt("نورة", [
  { name: "شاي", price: 5, qty: 2 },
  { name: "كيك", price: 15, qty: 1 }
]));
~~~
