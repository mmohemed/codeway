## ما هي الدالة؟

الدالة (Function) هي **مجموعة أوامر لها اسم**، نكتبها مرة واحدة ونستدعيها متى شئنا. فكّر فيها كوصفة طبخ: تكتب الوصفة مرة، ثم تطبخها كلما أردت دون إعادة كتابتها.

الدوال تحل ثلاث مشاكل:

- **التكرار:** بدلاً من نسخ نفس الكود في عشرة أماكن، تستدعي الدالة.
- **التنظيم:** تقسّم البرنامج الكبير إلى أجزاء صغيرة لكل منها اسم واضح.
- **سهولة التعديل:** إذا أردت تغيير السلوك، تعدّل الدالة في مكان واحد فقط.

لقد استخدمت دوالاً جاهزة بالفعل: `console.log()` و `Number()` و `toUpperCase()`. الآن ستكتب دوالك الخاصة.

## تعريف دالة

```js
function greet() {
  console.log("مرحباً!");
  console.log("أهلاً بك في CodeWay");
}
```

- `function` الكلمة التي تعني "سأعرّف دالة".
- `greet` اسم الدالة، ويُفضل أن يكون **فعلاً** يصف ما تفعله.
- `()` الأقواس، وسنضع فيها المدخلات في الدرس القادم.
- `{ }` جسم الدالة: الأوامر التي تُنفَّذ.

> ⚠️ تعريف الدالة **لا ينفّذها**. الكود السابق وحده لا يطبع شيئاً.

## استدعاء الدالة

لتنفيذ الدالة نكتب اسمها متبوعاً بالأقواس:

```js
function greet() {
  console.log("مرحباً!");
}

greet();
greet();
greet();
```

```output
مرحباً!
مرحباً!
مرحباً!
```

كل استدعاء ينفّذ جسم الدالة كاملاً من جديد.

## الدوال تجعل الكود أوضح

قارن بين برنامج طويل بلا دوال، وبرنامج مقسّم:

```js
function printHeader() {
  console.log("==========");
  console.log("  فاتورة  ");
  console.log("==========");
}

function printFooter() {
  console.log("----------");
  console.log("شكراً لزيارتكم");
}

printHeader();
console.log("قهوة: 12 ريال");
printFooter();
```

```output
==========
  فاتورة  
==========
قهوة: 12 ريال
----------
شكراً لزيارتكم
```

من يقرأ آخر ثلاثة أسطر يفهم البرنامج فوراً دون الدخول في التفاصيل.

## الاستدعاء قبل التعريف (Hoisting)

الدوال المعرّفة بالكلمة `function` يمكن استدعاؤها **قبل** سطر تعريفها، لأن JavaScript ترفعها إلى الأعلى قبل التنفيذ:

```js
sayHi();

function sayHi() {
  console.log("هاي!");
}
```

```output
هاي!
```

ومع ذلك، الأوضح عادة أن تعرّف الدوال أولاً ثم تستدعيها.

## تسمية الدوال

| جيد | سيئ | السبب |
|---|---|---|
| `calculateTotal` | `total` | الدالة تفعل شيئاً، فاسمها فعل |
| `sendEmail` | `doStuff` | الاسم يصف المهمة بدقة |
| `isValidEmail` | `check` | الدوال التي تجيب بنعم أو لا تبدأ غالباً بـ `is` أو `has` |

## ملخص الدرس

- الدالة مجموعة أوامر لها اسم، تُكتب مرة وتُستدعى مرات.
- نعرّفها بـ `function name() { ... }` ونستدعيها بـ `name()`.
- التعريف وحده لا ينفّذ شيئاً.
- اسم الدالة فعل يصف ما تفعله.

## الدوال تستقبل مدخلات

دالة `greet` في الدرس السابق تطبع نفس الرسالة دائماً. ماذا لو أردنا ترحيباً باسم مختلف كل مرة؟ نعطي الدالة **معاملات (Parameters)**:

```js
function greet(name) {
  console.log(`مرحباً يا ${name}!`);
}

greet("سارة");
greet("خالد");
```

```output
مرحباً يا سارة!
مرحباً يا خالد!
```

- `name` في التعريف يسمى **معاملاً (parameter)**، وهو متغير يعيش داخل الدالة.
- `"سارة"` عند الاستدعاء تسمى **وسيطاً (argument)**، وهي القيمة الفعلية التي تُعطى للمعامل.

## عدة معاملات

نفصل بينها بفاصلة، وترتيب الوسائط مهم:

```js
function introduce(name, city, age) {
  console.log(`أنا ${name} من ${city}، عمري ${age}`);
}

introduce("ليلى", "جدة", 24);
```

```output
أنا ليلى من جدة، عمري 24
```

## القيم الافتراضية

إذا لم يُعطَ وسيط لمعامل، تكون قيمته `undefined`. يمكننا تحديد **قيمة افتراضية**:

```js
function orderCoffee(size = "وسط") {
  console.log(`قهوة حجم ${size}`);
}

orderCoffee("كبير");
orderCoffee();
```

```output
قهوة حجم كبير
قهوة حجم وسط
```

## إرجاع قيمة باستخدام return

حتى الآن كانت دوالنا **تطبع** النتيجة. لكن الأهم أن تُرجع الدالة نتيجة يمكن استخدامها في بقية البرنامج. هنا تأتي `return`:

```js
function add(a, b) {
  return a + b;
}

const result = add(4, 6);
console.log(result);
console.log(add(10, 20) * 2);
```

```output
10
60
```

`return` تفعل أمرين: **تعيد القيمة** إلى مكان الاستدعاء، و**تنهي الدالة فوراً**.

## الفرق بين console.log و return

هذا من أهم المفاهيم للمبتدئ:

```js
function printDouble(n) {
  console.log(n * 2);
}

function getDouble(n) {
  return n * 2;
}

const a = printDouble(5);
const b = getDouble(5);
console.log(a, b);
```

```output
10
undefined 10
```

- `printDouble` **تعرض** النتيجة على الشاشة فقط ثم تختفي، ولذلك `a` قيمتها `undefined`.
- `getDouble` **تسلّم** النتيجة لك، فتخزنها في `b` وتستخدمها كما تشاء.

> 💡 القاعدة: الدالة التي تحسب شيئاً يجب أن **تُرجعه** بـ `return`، واترك قرار طباعته لمن يستدعيها.

## return تنهي الدالة مبكراً

أي كود بعد `return` لا يُنفَّذ، وهذا مفيد للتعامل مع الحالات الخاصة أولاً:

```js
function divide(a, b) {
  if (b === 0) {
    return "لا يمكن القسمة على صفر";
  }
  return a / b;
}

console.log(divide(10, 2));
console.log(divide(10, 0));
```

```output
5
لا يمكن القسمة على صفر
```

## الدوال تستدعي دوالاً

يمكن بناء دوال من دوال أصغر:

```js
function square(n) {
  return n * n;
}

function sumOfSquares(a, b) {
  return square(a) + square(b);
}

console.log(sumOfSquares(3, 4));
```

```output
25
```

## ملخص الدرس

- المعاملات تجعل الدالة مرنة، ونعطيها القيم عند الاستدعاء.
- `param = قيمة` تحدد قيمة افتراضية.
- `return` تعيد نتيجة وتنهي الدالة فوراً.
- الدالة التي لا تحتوي `return` تعيد `undefined`.
- فضّل إرجاع النتائج على طباعتها داخل الدالة.

--- exercise

- `discount` نسبة الخصم بالمئة، وقيمتها الافتراضية `0`

وتُرجع السعر بعد الخصم. مثلاً `calculatePrice(200, 25)` تُرجع `150`.

الكود الموجود يستدعي الدالة ويطبع النتائج، لا تعدّله.

~~~starter

~~~

~~~

console.log(calculatePrice(80));
console.log(calculatePrice(50, 10) + calculatePrice(50, 10));
~~~

## طريقة أقصر لكتابة الدوال

في JavaScript الحديثة توجد صيغة مختصرة تسمى **الدوال السهمية (Arrow Functions)**، وستراها في كل مكان تقريباً في الأكواد الحديثة ومكتبات مثل React.

## من دالة عادية إلى سهمية

```js
// دالة عادية
function multiply(a, b) {
  return a * b;
}

// نفس الدالة كدالة سهمية
const multiplyArrow = (a, b) => {
  return a * b;
};

console.log(multiply(3, 4), multiplyArrow(3, 4));
```

```output
12 12
```

الخطوات: نحذف كلمة `function`، ونخزّن الدالة في ثابت، ونضع السهم `=>` بين المعاملات والجسم.

## الاختصار الأقوى: الإرجاع الضمني

إذا كان جسم الدالة **تعبيراً واحداً فقط** نُرجعه، نحذف الأقواس المعقوفة وكلمة `return`:

```js
const multiply = (a, b) => a * b;
const square = n => n * n;
const sayHello = () => "مرحباً";

console.log(multiply(5, 6));
console.log(square(9));
console.log(sayHello());
```

```output
30
81
مرحباً
```

| الحالة | الصيغة |
|---|---|
| بدون معاملات | `() => ...` |
| معامل واحد | `n => ...` (الأقواس اختيارية) |
| عدة معاملات | `(a, b) => ...` |
| جسم من سطر واحد | `x => x * 2` (إرجاع تلقائي) |
| جسم من عدة أسطر | `x => { ...; return y; }` |

> ⚠️ إذا استخدمت الأقواس المعقوفة `{ }` يجب أن تكتب `return` بنفسك، وإلا ستُرجع الدالة `undefined`.

```js
const bad = n => { n * 2 };
const good = n => { return n * 2; };
console.log(bad(5), good(5));
```

```output
undefined 10
```

## الدوال قيم مثل غيرها

في JavaScript الدالة **قيمة** يمكن تخزينها في متغير، وتمريرها لدالة أخرى. وهذا أهم استخدام للدوال السهمية:

```js
function applyTwice(fn, value) {
  return fn(fn(value));
}

console.log(applyTwice(n => n + 3, 10));
console.log(applyTwice(n => n * 2, 5));
```

```output
16
20
```

مررنا دالة كاملة كوسيط! الدالة الممررة بهذا الشكل تسمى **دالة رد النداء (Callback)**، وستراها كثيراً مع المصفوفات والأحداث في الوحدات القادمة.

## تعبير الدالة (Function Expression)

يمكن أيضاً تخزين دالة عادية في متغير:

```js
const greet = function (name) {
  return `أهلاً ${name}`;
};
console.log(greet("نور"));
```

```output
أهلاً نور
```

الفرق المهم عن تعريف `function` العادي: الدوال المخزنة في متغيرات (عادية أو سهمية) **لا يمكن استدعاؤها قبل سطر تعريفها**.

## متى أستخدم أيهما؟

- **الدوال السهمية:** للدوال القصيرة، وخاصة كـ callback.
- **`function` العادية:** للدوال الرئيسية الكبيرة في البرنامج، وعندما تحتاج `this` (سنتعلمه في الوحدة 8).

## ملخص الدرس

- الصيغة السهمية: `(a, b) => a + b`.
- بدون `{ }` يكون الإرجاع تلقائياً، ومع `{ }` يجب كتابة `return`.
- الدوال قيم يمكن تخزينها وتمريرها لدوال أخرى (callbacks).

## أين يعيش المتغير؟

**النطاق (Scope)** يحدد أين يمكن رؤية المتغير واستخدامه. ليست كل المتغيرات متاحة في كل مكان، وهذا أمر جيد لأنه يمنع أجزاء البرنامج من العبث ببعضها.

## النطاق العام (Global Scope)

المتغير المعرّف خارج أي دالة أو كتلة يُرى في كل مكان:

```js
const siteName = "CodeWay";

function showName() {
  console.log(siteName);
}
showName();
```

```output
CodeWay
```

## نطاق الدالة (Function Scope)

المتغير المعرّف **داخل** دالة لا يُرى خارجها:

```js-error
function calculate() {
  const secret = 42;
  console.log(secret); // يعمل
}
calculate();
console.log(secret); // ReferenceError: secret is not defined
```

هذا يعني أن كل دالة لها "غرفتها الخاصة" من المتغيرات. ولهذا يمكن لدالتين مختلفتين استخدام نفس اسم المتغير دون تعارض:

```js
function a() {
  const x = 1;
  return x;
}
function b() {
  const x = 2;
  return x;
}
console.log(a(), b());
```

```output
1 2
```

## نطاق الكتلة (Block Scope)

المتغيرات المعرّفة بـ `let` و `const` تعيش داخل أقرب أقواس معقوفة `{ }`، سواء كانت `if` أو حلقة أو غيرها:

```js
const age = 20;

if (age >= 18) {
  const message = "بالغ";
  console.log(message);
}
// message غير موجود هنا
console.log(typeof message);
```

```output
بالغ
undefined
```

> 💡 لهذا السبب عدّاد الحلقة `let i` لا يُرى بعد انتهائها. وهذا من أسباب تفضيل `let` و `const` على `var`، فـ `var` لا تحترم نطاق الكتلة.

## سلسلة النطاقات

الدالة الداخلية ترى متغيرات الدالة الخارجية، والعكس غير صحيح. تبحث JavaScript عن المتغير في النطاق الحالي، ثم في الذي يحيط به، وهكذا حتى النطاق العام:

```js
const level1 = "عام";

function outer() {
  const level2 = "خارجي";

  function inner() {
    const level3 = "داخلي";
    console.log(level1, level2, level3);
  }
  inner();
}
outer();
```

```output
عام خارجي داخلي
```

## التظليل (Shadowing)

إذا عرّفت متغيراً داخلياً بنفس اسم متغير خارجي، فالداخلي "يظلل" الخارجي داخل نطاقه فقط:

```js
const color = "أزرق";

function paint() {
  const color = "أحمر";
  console.log(`داخل الدالة: ${color}`);
}
paint();
console.log(`خارج الدالة: ${color}`);
```

```output
داخل الدالة: أحمر
خارج الدالة: أزرق
```

## لماذا نتجنب المتغيرات العامة؟

المتغيرات العامة يمكن لأي جزء من البرنامج تعديلها، فيصعب تتبع من غيّرها ومتى. القاعدة: **عرّف المتغير في أضيق نطاق يحتاجه**، ومرّر القيم للدوال كمعاملات بدلاً من الاعتماد على متغيرات عامة.

## ملخص الدرس

- النطاق العام: يُرى في كل مكان، ويجب التقليل منه.
- نطاق الدالة: متغيرات الدالة لا تُرى خارجها.
- نطاق الكتلة: `let` و `const` تعيشان داخل أقرب `{ }`.
- الداخل يرى الخارج، والخارج لا يرى الداخل.
- عرّف المتغيرات في أضيق نطاق ممكن.

=== lesson
## الدالة تتذكر

**الإغلاق (Closure)** من المفاهيم التي تبدو صعبة في البداية، لكنه بسيط إذا فهمت النطاق جيداً. وهو من الأسئلة المفضلة في مقابلات التوظيف.

الفكرة: **الدالة تتذكر المتغيرات التي كانت حولها لحظة إنشائها، حتى بعد انتهاء الدالة الخارجية.**

## مثال أول

```js
function createGreeter(greeting) {
  return name => `${greeting} يا ${name}`;
}

const sayHello = createGreeter("مرحباً");
const sayMorning = createGreeter("صباح الخير");

console.log(sayHello("علي"));
console.log(sayMorning("هدى"));
```

```output
مرحباً يا علي
صباح الخير يا هدى
```

ماذا حدث؟

1. استدعينا `createGreeter("مرحباً")` فأرجعت دالة جديدة.
2. انتهت `createGreeter` تماماً.
3. ومع ذلك، عندما استدعينا `sayHello` بعدها، كانت **ما زالت تتذكر** أن `greeting` قيمتها "مرحباً".

الدالة الداخلية مع المتغيرات التي تتذكرها تسمى **Closure**.

## العدّاد: المثال الكلاسيكي

```js
function createCounter() {
  let count = 0;
  return () => {
    count++;
    return count;
  };
}

const counter = createCounter();
console.log(counter());
console.log(counter());
console.log(counter());
```

```output
1
2
3
```

المتغير `count` لا يُعاد إلى الصفر، لأن الدالة المُرجعة تحتفظ بنفس `count` بين الاستدعاءات.

## كل closure له ذاكرته الخاصة

```js
function createCounter() {
  let count = 0;
  return () => ++count;
}

const a = createCounter();
const b = createCounter();

a();
a();
console.log(a());
console.log(b());
```

```output
3
1
```

كل استدعاء لـ `createCounter` ينشئ `count` جديداً مستقلاً، فـ `a` و `b` لا يتشاركان العدّ.

## لماذا الإغلاق مفيد؟ إخفاء البيانات

لا يستطيع أي كود خارجي الوصول إلى `count` مباشرة وتغييره عشوائياً. الطريقة الوحيدة هي الدوال التي نوفرها. هذا يسمى **التغليف (Encapsulation)**:

```js
function createWallet(initial) {
  let balance = initial;
  return {
    deposit: amount => { balance += amount; },
    withdraw: amount => {
      if (amount > balance) return "الرصيد غير كافٍ";
      balance -= amount;
      return "تم السحب";
    },
    getBalance: () => balance
  };
}

const wallet = createWallet(100);
wallet.deposit(50);
console.log(wallet.withdraw(500));
console.log(wallet.withdraw(30));
console.log(wallet.getBalance());
console.log(wallet.balance);
```

```output
الرصيد غير كافٍ
تم السحب
120
undefined
```

لاحظ السطر الأخير: لا يمكن الوصول إلى `balance` مباشرة، فهي محمية داخل الإغلاق. (استخدمنا هنا **كائناً** `{ }` لإرجاع عدة دوال معاً، وسنتعلم الكائنات بالتفصيل في الوحدة القادمة.)

## أين ستقابل الإغلاق؟

- في معالجات الأحداث (`addEventListener`) التي تتذكر بيانات الصفحة.
- في `setTimeout` التي تُنفَّذ لاحقاً وتتذكر المتغيرات.
- في React Hooks مثل `useState`.

في الحقيقة، أنت تستخدم الإغلاق في كل مرة تكتب دالة تستخدم متغيراً من خارجها.

## ملخص الدرس

- الإغلاق: الدالة تتذكر متغيرات النطاق الذي أُنشئت فيه، حتى بعد انتهائه.
- كل استدعاء للدالة الخارجية ينشئ ذاكرة مستقلة.
- يُستخدم لإخفاء البيانات وحمايتها، ولإنشاء دوال مخصصة.

function createMultiplier(factor) {
  return n => n * factor;
}

function createIdGenerator(prefix) {
  let id = 0;
  return () => {
    id++;
    return `${prefix}-${id}`;
  };
}

const double = createMultiplier(2);
const triple = createMultiplier(3);
console.log(double(7), triple(7));

const nextOrderId = createIdGenerator("order");

console.log(nextOrderId());
