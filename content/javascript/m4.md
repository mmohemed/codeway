## قائمة من القيم

لو أردت تخزين درجات 30 طالباً، هل ستنشئ 30 متغيراً؟ بالطبع لا. **المصفوفة (Array)** قائمة مرتبة تخزّن عدة قيم في متغير واحد.

```js
const fruits = ["تفاح", "موز", "برتقال"];
console.log(fruits);
console.log(fruits.length);
```

```output
["تفاح","موز","برتقال"]
3
```

- المصفوفة تُكتب بين قوسين مربعين `[ ]`، والعناصر مفصولة بفواصل.
- `length` يعطي عدد العناصر.
- يمكن أن تحتوي أي نوع: أرقاماً ونصوصاً، وحتى مصفوفات أخرى.

> 💡 يعرض محرر CodeWay المصفوفات والكائنات بصيغة JSON المختصرة. وحدة التحكم في المتصفح تعرضها بشكل تفاعلي مختلف قليلاً، لكن المحتوى واحد.

## الوصول إلى العناصر

كل عنصر له **فهرس (index)** يبدأ من 0، تماماً مثل أحرف النص:

```js
const colors = ["أحمر", "أخضر", "أزرق"];
console.log(colors[0]);
console.log(colors[2]);
console.log(colors[colors.length - 1]);
console.log(colors[10]);
```

```output
أحمر
أزرق
أزرق
undefined
```

الوصول لفهرس غير موجود يُرجع `undefined` ولا يسبب خطأ.

## تعديل العناصر

```js
const scores = [70, 85, 90];
scores[0] = 75;
console.log(scores);
```

```output
[75,85,90]
```

لاحظ أن `scores` معرّفة بـ `const` ومع ذلك عدّلنا محتواها. `const` تمنع **إعادة إسناد** المتغير إلى مصفوفة أخرى، لكنها لا تمنع تعديل محتوى المصفوفة نفسها.

## الإضافة والحذف

| الدالة | ماذا تفعل |
|---|---|
| `push(x)` | تضيف x في **النهاية** |
| `pop()` | تحذف آخر عنصر وتُرجعه |
| `unshift(x)` | تضيف x في **البداية** |
| `shift()` | تحذف أول عنصر وتُرجعه |

```js
const cart = ["قلم"];
cart.push("دفتر");
cart.push("مسطرة");
cart.unshift("حقيبة");
console.log(cart);

const removed = cart.pop();
console.log(removed);
console.log(cart);
```

```output
["حقيبة","قلم","دفتر","مسطرة"]
مسطرة
["حقيبة","قلم","دفتر"]
```

## البحث في المصفوفة

```js
const users = ["أحمد", "سارة", "خالد"];
console.log(users.includes("سارة"));
console.log(users.indexOf("خالد"));
console.log(users.indexOf("منى"));
```

```output
true
2
-1
```

## المرور على كل العناصر

الطريقة الأوضح هي حلقة `for...of` التي تعطيك كل عنصر مباشرة:

```js
const prices = [10, 25, 40];
let total = 0;

for (const price of prices) {
  total += price;
}
console.log(`الإجمالي: ${total}`);
```

```output
الإجمالي: 75
```

وإذا احتجت الفهرس أيضاً، استخدم حلقة `for` العادية:

```js
const tasks = ["الدراسة", "الرياضة"];
for (let i = 0; i < tasks.length; i++) {
  console.log(`${i + 1}. ${tasks[i]}`);
}
```

```output
1. الدراسة
2. الرياضة
```

## دوال مفيدة أخرى

```js
const nums = [3, 1, 4, 1, 5];
console.log(nums.slice(1, 3));
console.log(nums.join(" - "));
console.log([...nums].reverse());
console.log(nums.concat([9, 2]));
```

```output
[1,4]
3 - 1 - 4 - 1 - 5
[5,1,4,1,3]
[3,1,4,1,5,9,2]
```

- `slice(a, b)` نسخة من جزء المصفوفة دون تعديل الأصلية.
- `join(x)` تحويل المصفوفة إلى نص مع فاصل.
- `reverse()` تعكس المصفوفة **وتعدّل الأصلية**، لذلك نسخناها أولاً بـ `[...nums]` (سنشرح `...` في الوحدة 7).
- `concat` دمج مصفوفتين في مصفوفة جديدة.

## ملخص الدرس

- المصفوفة قائمة مرتبة `[ ]` والفهرس يبدأ من 0.
- `push` و `pop` للنهاية، و `unshift` و `shift` للبداية.
- `includes` و `indexOf` للبحث.
- `for...of` أسهل طريقة للمرور على العناصر.

## البرمجة الوظيفية مع المصفوفات

في الدرس السابق استخدمنا الحلقات لمعالجة المصفوفات. لكن JavaScript الحديثة توفر دوالاً أقوى وأوضح تأخذ **دالة callback** وتطبقها على كل عنصر. أهمها ثلاث: `map` و `filter` و `reduce`. ستراها في كل مشروع حقيقي، خاصة في React.

## map: تحويل كل عنصر

تُنشئ مصفوفة **جديدة** بنفس الطول، كل عنصر فيها هو نتيجة تطبيق الدالة على العنصر الأصلي:

```js
const prices = [100, 250, 80];
const withTax = prices.map(p => p * 1.5);
console.log(withTax);
console.log(prices);
```

```output
[150,375,120]
[100,250,80]
```

المصفوفة الأصلية لم تتغير. `map` تُرجع مصفوفة جديدة دائماً.

```js
const names = ["sara", "ali"];
const greetings = names.map((name, index) => `${index + 1}. مرحباً ${name}`);
console.log(greetings);
```

```output
["1. مرحباً sara","2. مرحباً ali"]
```

الـ callback يستقبل العنصر، ويمكنه أيضاً استقبال الفهرس كمعامل ثانٍ.

## filter: الاختيار حسب شرط

تُنشئ مصفوفة جديدة فيها فقط العناصر التي أرجعت الدالة لها `true`:

```js
const ages = [12, 25, 17, 30, 15];
const adults = ages.filter(age => age >= 18);
console.log(adults);

const words = ["قلم", "حاسوب", "كتاب", "هاتف ذكي"];
console.log(words.filter(w => w.length > 4));
```

```output
[25,30]
["حاسوب","هاتف ذكي"]
```

## reduce: اختزال المصفوفة إلى قيمة واحدة

`reduce` تمر على العناصر وتجمعها في قيمة واحدة: مجموع، أو أكبر قيمة، أو حتى كائن:

```js
const cart = [30, 45, 25];
const total = cart.reduce((sum, price) => sum + price, 0);
console.log(total);
```

```output
100
```

الـ callback يستقبل:

- `sum` **المُجمِّع**: النتيجة حتى الآن.
- `price` العنصر الحالي.
- و `0` في النهاية هي **القيمة الابتدائية** للمُجمِّع.

خطوة بخطوة: `0 + 30 = 30`، ثم `30 + 45 = 75`، ثم `75 + 25 = 100`.

```js
const nums = [4, 9, 2, 7];
const max = nums.reduce((best, n) => (n > best ? n : best), nums[0]);
console.log(max);
```

```output
9
```

## السلسلة: قوة الدمج

لأن `map` و `filter` تُرجعان مصفوفات، يمكن ربطها معاً في سلسلة:

```js
const orders = [120, 40, 300, 75, 500];

const bigOrdersTotal = orders
  .filter(o => o >= 100)
  .map(o => o * 0.9)
  .reduce((sum, o) => sum + o, 0);

console.log(bigOrdersTotal);
```

```output
828
```

اقرأها كجملة: "من الطلبات، اختر ما يساوي 100 أو أكثر، ثم طبّق خصم 10%، ثم اجمعها".

## دوال أخرى مهمة

| الدالة | تُرجع |
|---|---|
| `find(fn)` | **أول** عنصر يحقق الشرط، أو `undefined` |
| `findIndex(fn)` | فهرس أول عنصر يحقق الشرط، أو -1 |
| `some(fn)` | `true` إذا حقق عنصر **واحد على الأقل** الشرط |
| `every(fn)` | `true` إذا حققت **كل** العناصر الشرط |
| `forEach(fn)` | لا شيء، تنفّذ الدالة على كل عنصر فقط |
| `sort(fn)` | ترتب المصفوفة **وتعدّل الأصلية** |

```js
const temps = [22, 35, 28, 41];
console.log(temps.find(t => t > 30));
console.log(temps.some(t => t > 40));
console.log(temps.every(t => t > 20));
console.log([...temps].sort((a, b) => a - b));
```

```output
35
true
true
[22,28,35,41]
```

> ⚠️ `sort()` بدون دالة مقارنة ترتب العناصر كنصوص، فيصبح `[10, 9, 100]` مرتباً `[10, 100, 9]`! استخدم دائماً `(a, b) => a - b` للأرقام تصاعدياً، و `(a, b) => b - a` تنازلياً.

## ملخص الدرس

- `map` تحوّل كل عنصر، و `filter` تختار، و `reduce` تجمع في قيمة واحدة.
- كلها تُرجع نتيجة جديدة ولا تعدّل الأصلية، ويمكن ربطها في سلسلة.
- `find` و `some` و `every` للبحث والتحقق.
- `sort` تحتاج دالة مقارنة للأرقام.

## وصف شيء بخصائصه

المصفوفة ممتازة لقائمة عناصر متشابهة. لكن كيف نخزّن بيانات **طالب**: اسمه وعمره ومدينته ودرجاته؟ هنا نستخدم **الكائن (Object)**: مجموعة أزواج من **مفتاح وقيمة**.

```js
const student = {
  name: "ريم",
  age: 21,
  city: "الرياض",
  isActive: true
};
console.log(student);
```

```output
{"name":"ريم","age":21,"city":"الرياض","isActive":true}
```

- الكائن يُكتب بين أقواس معقوفة `{ }`.
- كل خاصية: `مفتاح: قيمة`، والخصائص مفصولة بفواصل.

## الوصول للخصائص

هناك طريقتان:

```js
const car = { brand: "تويوتا", year: 2022 };

console.log(car.brand);
console.log(car["year"]);

const key = "brand";
console.log(car[key]);
console.log(car.color);
```

```output
تويوتا
2022
تويوتا
undefined
```

- **النقطة** `car.brand` هي الطريقة المعتادة.
- **الأقواس** `car["year"]` ضرورية عندما يكون اسم الخاصية في متغير، أو يحتوي مسافات.
- الخاصية غير الموجودة تُرجع `undefined`.

## الإضافة والتعديل والحذف

```js
const user = { name: "سامي" };

user.email = "sami@mail.com";
user.name = "سامي أحمد";
delete user.email;
user.age = 30;

console.log(user);
console.log("age" in user);
```

```output
{"name":"سامي أحمد","age":30}
true
```

## الدوال داخل الكائنات (Methods)

يمكن أن تكون قيمة الخاصية دالة، وتسمى عندها **طريقة (method)**:

```js
const calculator = {
  brand: "Casio",
  add(a, b) {
    return a + b;
  },
  multiply(a, b) {
    return a * b;
  }
};

console.log(calculator.add(2, 3));
console.log(calculator.multiply(4, 5));
```

```output
5
20
```

هذا ما كنت تفعله طوال الوقت: `console` كائن، و `log` طريقة فيه!

## المرور على خصائص الكائن

```js
const product = { name: "سماعة", price: 199, stock: 12 };

for (const key in product) {
  console.log(`${key}: ${product[key]}`);
}

console.log(Object.keys(product));
console.log(Object.values(product));
```

```output
name: سماعة
price: 199
stock: 12
["name","price","stock"]
["سماعة",199,12]
```

`Object.entries(obj)` تعطيك مصفوفة من أزواج `[مفتاح, قيمة]`، وهي مفيدة جداً مع `for...of`.

## مصفوفة من الكائنات

هذا الشكل هو أكثر ما ستتعامل معه في الحياة الحقيقية، فهكذا تصل البيانات من الخوادم:

```js
const products = [
  { name: "قميص", price: 80, inStock: true },
  { name: "حذاء", price: 250, inStock: false },
  { name: "قبعة", price: 45, inStock: true }
];

const available = products
  .filter(p => p.inStock)
  .map(p => p.name);
console.log(available);

const total = products.reduce((sum, p) => sum + p.price, 0);
console.log(total);
```

```output
["قميص","قبعة"]
375
```

## الكائنات المتداخلة

```js
const order = {
  id: 1024,
  customer: { name: "هند", phone: "0500000000" },
  items: ["كتاب", "قلم"]
};

console.log(order.customer.name);
console.log(order.items[1]);
console.log(order.items.length);
```

```output
هند
قلم
2
```

> ⚠️ الكائنات والمصفوفات تُنسخ **بالمرجع**: `const b = a;` لا ينشئ نسخة جديدة، بل اسماً آخر لنفس الكائن، فتعديل `b` يغيّر `a` أيضاً. لإنشاء نسخة حقيقية استخدم `{ ...a }`، وسنفصّل ذلك في الوحدة 7.

## ملخص الدرس

- الكائن أزواج `مفتاح: قيمة` داخل `{ }`.
- الوصول بـ `obj.key` أو `obj["key"]`.
- الخصائص يمكن إضافتها وتعديلها وحذفها بـ `delete`.
- `Object.keys` و `Object.values` و `Object.entries` للمرور على الخصائص.
- مصفوفة الكائنات هي الشكل الأكثر شيوعاً للبيانات.

## هياكل بيانات إضافية

المصفوفات والكائنات تغطي معظم الحالات، لكن JavaScript توفر هيكلين متخصصين يحلان مشاكل معينة بشكل أفضل: `Set` و `Map`.

## Set: مجموعة بلا تكرار

`Set` مجموعة من القيم **الفريدة**: لا يمكن أن تتكرر فيها قيمة.

```js
const tags = new Set();
tags.add("js");
tags.add("css");
tags.add("js");

console.log(tags.size);
console.log(tags.has("css"));
console.log(tags.has("python"));
tags.delete("css");
console.log(tags);
```

```output
2
true
false
Set(1) ["js"]
```

أضفنا `"js"` مرتين، لكنها خُزنت مرة واحدة.

| الدالة | وظيفتها |
|---|---|
| `add(x)` | إضافة قيمة (تُتجاهل إن كانت موجودة) |
| `has(x)` | هل القيمة موجودة؟ |
| `delete(x)` | حذف قيمة |
| `size` | عدد القيم |

## أشهر استخدام: إزالة التكرار

```js
const visits = ["أحمد", "سارة", "أحمد", "علي", "سارة"];
const uniqueVisitors = [...new Set(visits)];
console.log(uniqueVisitors);
console.log(uniqueVisitors.length);
```

```output
["أحمد","سارة","علي"]
3
```

حوّلنا المصفوفة إلى Set فزال التكرار، ثم أعدناها مصفوفة بـ `[...]`.

## Map: قاموس أكثر مرونة

`Map` تخزّن أزواج مفتاح وقيمة مثل الكائن، لكن بمزايا إضافية:

```js
const prices = new Map();
prices.set("قهوة", 12);
prices.set("شاي", 8);

console.log(prices.get("قهوة"));
console.log(prices.has("عصير"));
console.log(prices.size);

for (const [item, price] of prices) {
  console.log(`${item}: ${price} ريال`);
}
```

```output
12
false
2
قهوة: 12 ريال
شاي: 8 ريال
```

## متى أستخدم Map بدل الكائن؟

| Map | الكائن العادي |
|---|---|
| المفاتيح يمكن أن تكون **أي نوع**: أرقام، كائنات، دوال | المفاتيح نصوص فقط |
| تحفظ ترتيب الإضافة دائماً | الترتيب قد يختلف مع المفاتيح الرقمية |
| `size` مباشرة | تحتاج `Object.keys(obj).length` |
| أسرع عند الإضافة والحذف المتكرر | أنسب لوصف شيء بخصائص ثابتة |

القاعدة البسيطة: استخدم **الكائن** لوصف شيء (مستخدم، منتج)، واستخدم **Map** كقاموس بيانات يتغير كثيراً.

## مثال عملي: عدّ التكرارات

```js
const text = "تفاح موز تفاح برتقال موز تفاح";
const counts = new Map();

for (const word of text.split(" ")) {
  counts.set(word, (counts.get(word) || 0) + 1);
}

console.log(counts.get("تفاح"));
console.log([...counts]);
```

```output
3
[["تفاح",3],["موز",2],["برتقال",1]]
```

لاحظ `(counts.get(word) || 0)`: إذا لم تكن الكلمة موجودة بعد، ترجع `get` القيمة `undefined`، فنستخدم `0` بدلاً منها.

## ملخص الدرس

- `Set` تخزّن قيماً فريدة، وأشهر استخدام لها إزالة التكرار: `[...new Set(arr)]`.
- `Map` قاموس بمفاتيح من أي نوع، مع `set` و `get` و `has` و `size`.
- الكائن لوصف شيء، و Map لقاموس بيانات متغير.

## لغة تبادل البيانات

عندما يرسل تطبيقك بيانات إلى خادم، أو يستقبل منه قائمة منتجات، يجب أن تكون البيانات بصيغة **نصية** يفهمها الطرفان. الصيغة الأشهر عالمياً هي **JSON** (اختصار JavaScript Object Notation).

JSON تشبه كائنات JavaScript جداً، لكنها **نص** وليست كائناً:

```json
{
  "name": "منى",
  "age": 28,
  "skills": ["JavaScript", "SQL"],
  "isAdmin": false,
  "manager": null
}
```

## قواعد JSON الصارمة

| مسموح في JavaScript | في JSON |
|---|---|
| مفاتيح بدون علامات تنصيص `name: "x"` | يجب `"name": "x"` |
| علامات تنصيص مفردة `'x'` | مزدوجة فقط `"x"` |
| فاصلة بعد آخر عنصر | ممنوعة |
| دوال و `undefined` | غير مدعومة |
| التعليقات | غير مدعومة |

القيم المسموحة في JSON: نصوص، أرقام، `true` و `false`، `null`، مصفوفات، وكائنات.

## من كائن إلى نص: JSON.stringify

```js
const user = { name: "منى", age: 28, skills: ["JS", "SQL"] };
const json = JSON.stringify(user);

console.log(json);
console.log(typeof json);
```

```output
{"name":"منى","age":28,"skills":["JS","SQL"]}
string
```

لجعل النص منسقاً وسهل القراءة، نمرر عدد المسافات كوسيط ثالث:

```js
const settings = { theme: "light", fontSize: 16 };
console.log(JSON.stringify(settings, null, 2));
```

```output
{
  "theme": "light",
  "fontSize": 16
}
```

## من نص إلى كائن: JSON.parse

```js
const response = '{"product":"لابتوب","price":3500,"tags":["جديد","عرض"]}';
const data = JSON.parse(response);

console.log(typeof data);
console.log(data.product);
console.log(data.price * 2);
console.log(data.tags[1]);
```

```output
object
لابتوب
7000
عرض
```

بعد `JSON.parse` أصبح لدينا كائن حقيقي نتعامل معه بشكل طبيعي.

## التعامل مع JSON غير الصالح

إذا كان النص بصيغة خاطئة، يرمي `JSON.parse` خطأ يوقف البرنامج. لذلك نحميه بـ `try...catch` (سنتعلمها بالتفصيل في الوحدة 8):

```js
const badJson = "{name: 'خطأ'}";

try {
  JSON.parse(badJson);
} catch (error) {
  console.log("صيغة JSON غير صالحة");
}
```

```output
صيغة JSON غير صالحة
```

## أين ستستخدم JSON؟

- **APIs:** تقريباً كل خادم يرسل ويستقبل JSON (الوحدة 6).
- **التخزين المحلي:** `localStorage` يخزّن نصوصاً فقط، فنحوّل الكائنات بـ `stringify` (الوحدة 8).
- **ملفات الإعدادات:** مثل `package.json` في كل مشروع JavaScript.

> 💡 حيلة شائعة: `JSON.parse(JSON.stringify(obj))` تنشئ نسخة عميقة مستقلة من كائن بسيط. لكن الطريقة الحديثة هي `structuredClone(obj)`.

## ملخص الدرس

- JSON صيغة نصية لتبادل البيانات، وقواعدها أصرم من كائنات JavaScript.
- `JSON.stringify(obj)` يحوّل الكائن إلى نص.
- `JSON.parse(text)` يحوّل النص إلى كائن.
- احمِ `JSON.parse` بـ `try...catch` عند التعامل مع بيانات خارجية.
