## ما هي JavaScript؟

JavaScript هي لغة البرمجة التي تجعل صفحات الويب **تتفاعل**. عندما تضغط زر "أعجبني" فيتغير لونه، أو تكتب في خانة بحث فتظهر لك اقتراحات فورية، أو تفتح قائمة منسدلة، فهذا كله يحدث بفضل JavaScript.

كل صفحة ويب تتكون من ثلاث طبقات:

| الطبقة | دورها | مثال من الحياة |
|---|---|---|
| HTML | الهيكل والمحتوى | جدران البيت وغرفه |
| CSS | الشكل والتنسيق | الدهان والأثاث |
| JavaScript | السلوك والتفاعل | الكهرباء والأجهزة |

واليوم لم تعد JavaScript محصورة في المتصفح، فهي تعمل أيضاً على الخوادم عبر Node.js، وفي تطبيقات الجوال عبر React Native، وفي تطبيقات سطح المكتب مثل VS Code نفسه.

## أين نكتب كود JavaScript؟

لديك ثلاثة أماكن للبدء:

1. **محرر CodeWay:** المحرر الموجود أسفل كل درس. تكتب فيه وتضغط «تشغيل» مباشرة دون أي تثبيت.
2. **وحدة التحكم في المتصفح (Console):** اضغط `F12` في Chrome ثم افتح تبويب Console، واكتب أي كود واضغط Enter.
3. **ملف داخل صفحة HTML:** وهي الطريقة المستخدمة في المشاريع الحقيقية، وسنتعلمها لاحقاً.

## أول سطر برمجي: console.log

الأمر `console.log` يطبع رسالة في وحدة التحكم (المخرجات). هو أهم أداة ستستخدمها كمبتدئ، لأنه يريك ما يحدث داخل برنامجك.

```js
console.log("مرحباً بالعالم!");
```

```output
مرحباً بالعالم!
```

لاحظ ثلاثة أشياء في هذا السطر:

- النص الذي نريد طباعته يوضع بين **علامتي تنصيص** `"..."`، ويسمى في البرمجة **نصاً (String)**.
- الأقواس `( )` تحيط بما نريد طباعته.
- الفاصلة المنقوطة `;` في نهاية السطر تعني "انتهى هذا الأمر". هي اختيارية غالباً في JavaScript، لكن كتابتها عادة جيدة.

## طباعة أكثر من سطر

يُنفَّذ البرنامج **من الأعلى إلى الأسفل، سطراً بعد سطر**:

```js
console.log("السطر الأول");
console.log("السطر الثاني");
console.log(2026);
```

```output
السطر الأول
السطر الثاني
2026
```

لاحظ أن الرقم `2026` لم نضعه بين علامتي تنصيص، لأن الأرقام تُكتب كما هي.

يمكنك أيضاً طباعة عدة قيم في أمر واحد بالفصل بينها بفاصلة، فتُطبع بينها مسافة:

```js
console.log("عمري", 25, "سنة");
```

```output
عمري 25 سنة
```

## التعليقات

التعليق نص يكتبه المبرمج **لنفسه أو لزملائه** ويتجاهله الحاسوب تماماً. يُستخدم لشرح الكود:

```js
// هذا تعليق من سطر واحد

/*
  هذا تعليق
  من عدة أسطر
*/

console.log("التعليقات لا تُطبع"); // يمكن وضع تعليق بعد الكود أيضاً
```

```output
التعليقات لا تُطبع
```

> 💡 نصيحة: التعليق الجيد يشرح **لماذا** كتبت الكود بهذه الطريقة، وليس **ماذا** يفعل، لأن الكود الواضح يشرح نفسه.

## ملخص الدرس

- JavaScript هي لغة التفاعل في الويب، وتعمل أيضاً على الخوادم والجوال.
- `console.log(...)` يطبع القيم في المخرجات.
- النصوص تُكتب بين علامتي تنصيص، والأرقام تُكتب كما هي.
- الكود يُنفَّذ من الأعلى للأسفل.
- التعليقات `//` و `/* */` يتجاهلها الحاسوب.

## لماذا نحتاج المتغيرات؟

تخيّل أنك تكتب برنامج متجر، وسعر المنتج يتكرر في عشرين مكاناً. إذا تغيّر السعر، ستعدّل عشرين سطراً! الحل هو أن نخزّن السعر **مرة واحدة** في مكان له اسم، ثم نستخدم الاسم في كل مكان.

**المتغير** هو صندوق له اسم، نضع فيه قيمة لنستخدمها لاحقاً.

## إنشاء متغير باستخدام let

```js
let price = 50;
console.log(price);
```

```output
50
```

هذا السطر يعني: أنشئ صندوقاً اسمه `price` وضع فيه القيمة `50`.

- `let` كلمة محجوزة تعني "أنشئ متغيراً".
- `price` اسم المتغير.
- `=` علامة **الإسناد**، وتعني "ضع القيمة التي على اليمين داخل المتغير". هي ليست علامة مساواة كما في الرياضيات.

## تغيير قيمة المتغير

المتغير المعرّف بـ `let` يمكن تغيير قيمته لاحقاً، دون كتابة `let` مرة أخرى:

```js
let score = 0;
console.log(score);

score = 10;
console.log(score);

score = score + 5;
console.log(score);
```

```output
0
10
15
```

السطر `score = score + 5` يُقرأ هكذا: "خذ القيمة الحالية لـ score، أضف إليها 5، ثم ضع الناتج في score".

## الثوابت باستخدام const

أحياناً نريد قيمة **لا تتغير أبداً**، مثل عدد أيام الأسبوع أو نسبة الضريبة. هنا نستخدم `const`:

```js
const daysInWeek = 7;
const taxRate = 0.15;
console.log(daysInWeek, taxRate);
```

```output
7 0.15
```

إذا حاولت تغيير قيمة `const` سيظهر خطأ:

```js-error
const pi = 3.14;
pi = 3; // TypeError: Assignment to constant variable.
```

> 💡 القاعدة الذهبية: استخدم `const` دائماً بشكل افتراضي، ولا تنتقل إلى `let` إلا إذا كنت تعلم أن القيمة ستتغير. هذا يجعل كودك أوضح ويمنع أخطاء التعديل غير المقصود.

## ماذا عن var؟

ستجد في الأكواد القديمة كلمة `var`. كانت الطريقة الوحيدة قبل عام 2015، لكن لها سلوكيات مربكة. في الكود الحديث **لا نستخدم var** ونكتفي بـ `let` و `const`.

## قواعد تسمية المتغيرات

| القاعدة | صحيح | خطأ |
|---|---|---|
| يبدأ بحرف أو `_` أو `$` | `userName` | `1user` |
| بدون مسافات | `firstName` | `first name` |
| ليس كلمة محجوزة | `myClass` | `class` |
| حساس لحالة الأحرف | `age` و `Age` متغيران مختلفان | |

والعرف المتبع في JavaScript هو أسلوب **camelCase**: الكلمة الأولى بأحرف صغيرة، وكل كلمة بعدها تبدأ بحرف كبير، مثل `totalPrice` و `isLoggedIn` و `numberOfStudents`.

> ⚠️ اختر أسماء تصف المحتوى. `x` و `data2` أسماء سيئة، بينما `cartTotal` و `userEmail` واضحة لأي شخص يقرأ الكود.

## ملخص الدرس

- المتغير صندوق له اسم يخزّن قيمة.
- `let` لقيمة قد تتغير، و `const` لقيمة ثابتة، و `var` قديمة لا نستخدمها.
- `=` تعني الإسناد وليس المساواة.
- نسمّي المتغيرات بأسلوب camelCase وبأسماء واضحة.

## كل قيمة لها نوع

عندما تخزّن قيمة في متغير، فإن JavaScript تعرف **نوعها**: هل هي رقم؟ نص؟ صح أو خطأ؟ النوع يحدد ما يمكنك فعله بالقيمة. فالأرقام تُجمع وتُضرب، والنصوص تُدمج وتُقطّع.

## الأنواع الأساسية

| النوع | الوصف | أمثلة |
|---|---|---|
| `number` | الأرقام الصحيحة والعشرية | `42` و `3.14` و `-7` |
| `string` | النصوص | `"مرحبا"` و `'JS'` |
| `boolean` | قيمة منطقية: صح أو خطأ | `true` و `false` |
| `undefined` | متغير لم تُعطَ له قيمة | `let x;` |
| `null` | "لا شيء" بشكل مقصود | `let car = null;` |

وهناك أيضاً `bigint` للأرقام الضخمة جداً و `symbol` لمعرّفات فريدة، وهما نادرا الاستخدام للمبتدئ.

## معرفة النوع باستخدام typeof

```js
console.log(typeof 42);
console.log(typeof "مرحبا");
console.log(typeof true);
console.log(typeof undefined);
```

```output
number
string
boolean
undefined
```

## الأرقام (number)

لا تفرّق JavaScript بين الأرقام الصحيحة والعشرية، فكلها من نوع `number`:

```js
const age = 25;
const price = 19.5;
const temperature = -4;
console.log(age + price);
```

```output
44.5
```

هناك قيمتان خاصتان من نوع رقم: `Infinity` (اللانهاية) و `NaN`، وهي اختصار Not a Number، وتظهر عند عملية حسابية لا معنى لها:

```js
console.log(10 / 0);
console.log("تفاحة" * 3);
```

```output
Infinity
NaN
```

## النصوص (string)

النص يُكتب بين علامتي تنصيص مزدوجة `"` أو مفردة `'` أو مائلة `` ` ``. المهم أن تفتح وتغلق بنفس العلامة:

```js
const first = "أحمد";
const last = 'علي';
console.log(first, last);
```

```output
أحمد علي
```

> ⚠️ انتبه: `"5"` نص، و `5` رقم. يبدوان متشابهين لكنهما نوعان مختلفان تماماً، وسنرى في الدرس القادم كيف يسبب هذا مفاجآت.

## القيم المنطقية (boolean)

لها قيمتان فقط: `true` (صح) و `false` (خطأ). وهي أساس اتخاذ القرارات في البرنامج:

```js
const isLoggedIn = true;
const hasDiscount = false;
console.log(isLoggedIn, hasDiscount);
console.log(10 > 3);
```

```output
true false
true
```

المقارنة `10 > 3` نتيجتها قيمة منطقية.

## undefined و null

- `undefined`: يعني أن المتغير موجود لكن **لم نضع فيه قيمة بعد**. تضعها JavaScript تلقائياً.
- `null`: يعني أننا **قررنا عمداً** أن المتغير فارغ.

```js
let phone;
console.log(phone);

let selectedCar = null;
console.log(selectedCar);
```

```output
undefined
null
```

## التحويل بين الأنواع

كثيراً ما تحتاج تحويل نص إلى رقم، مثل ما يكتبه المستخدم في خانة إدخال، فهو يصل دائماً كنص:

```js
const input = "42";
const num = Number(input);
console.log(typeof input, typeof num);
console.log(num + 8);

console.log(String(100) + "!");
console.log(Number("abc"));
```

```output
string number
50
100!
NaN
```

## ملخص الدرس

- الأنواع الأساسية: `number` و `string` و `boolean` و `undefined` و `null`.
- `typeof` يخبرك بنوع القيمة.
- `"5"` نص و `5` رقم.
- `Number()` و `String()` يحوّلان بين الأنواع، و `NaN` نتيجة عملية حسابية غير صالحة.

## العمليات الحسابية

تدعم JavaScript كل العمليات الحسابية المعتادة:

| العامل | المعنى | مثال | النتيجة |
|---|---|---|---|
| `+` | جمع | `7 + 3` | `10` |
| `-` | طرح | `7 - 3` | `4` |
| `*` | ضرب | `7 * 3` | `21` |
| `/` | قسمة | `7 / 2` | `3.5` |
| `%` | باقي القسمة | `7 % 3` | `1` |
| `**` | الأس | `2 ** 3` | `8` |

عامل **باقي القسمة** `%` مفيد جداً، مثلاً لمعرفة هل الرقم زوجي:

```js
console.log(10 % 2);
console.log(7 % 2);
```

```output
0
1
```

إذا كان الباقي 0 فالرقم زوجي.

## أولوية العمليات

كما في الرياضيات: الأس أولاً، ثم الضرب والقسمة، ثم الجمع والطرح. والأقواس تغيّر الترتيب:

```js
console.log(2 + 3 * 4);
console.log((2 + 3) * 4);
```

```output
14
20
```

## اختصارات الإسناد

بدلاً من `x = x + 5` يمكنك كتابة `x += 5`:

```js
let points = 10;
points += 5;   // points = points + 5
points -= 3;   // points = points - 3
points *= 2;   // points = points * 2
console.log(points);

let count = 0;
count++;       // زيادة بمقدار 1
count++;
count--;       // نقص بمقدار 1
console.log(count);
```

```output
24
1
```

## المفاجأة: + مع النصوص

العامل `+` له وظيفتان: الجمع مع الأرقام، و**الدمج** مع النصوص. إذا كان أحد الطرفين نصاً، تحوّل JavaScript الطرف الآخر إلى نص وتدمجهما:

```js
console.log(5 + 5);
console.log("5" + 5);
console.log("5" - 2);
```

```output
10
55
3
```

لاحظ أن `-` لا تعمل مع النصوص، فتحوّل JavaScript النص إلى رقم. هذا السلوك يسمى **التحويل الضمني**، وهو مصدر شائع للأخطاء. الحل أن تحوّل بنفسك باستخدام `Number()` قبل الحساب.

## عوامل المقارنة

نتيجة المقارنة دائماً `true` أو `false`:

| العامل | المعنى |
|---|---|
| `>` و `<` | أكبر من، أصغر من |
| `>=` و `<=` | أكبر من أو يساوي، أصغر من أو يساوي |
| `===` | يساوي (القيمة والنوع) |
| `!==` | لا يساوي (القيمة أو النوع) |

```js
console.log(5 === 5);
console.log(5 === "5");
console.log(5 == "5");
console.log(3 !== 4);
```

```output
true
false
true
true
```

> ⚠️ استخدم دائماً `===` و `!==`. أما `==` فتحوّل الأنواع قبل المقارنة، لذلك تعتبر `5 == "5"` صحيحة، وهذا قد يخفي أخطاء حقيقية.

## العوامل المنطقية

نستخدمها لدمج عدة شروط:

| العامل | الاسم | يكون صحيحاً عندما |
|---|---|---|
| `&&` | و (AND) | **كلا** الطرفين صحيحان |
| `\|\|` | أو (OR) | **أحد** الطرفين على الأقل صحيح |
| `!` | ليس (NOT) | يعكس القيمة |

```js
const age = 20;
const hasTicket = true;

console.log(age >= 18 && hasTicket);
console.log(age < 12 || age > 60);
console.log(!hasTicket);
```

```output
true
false
false
```

## ملخص الدرس

- العمليات الحسابية: `+ - * / % **`، والأقواس تغيّر الأولوية.
- `+=` و `++` اختصارات مفيدة.
- `+` مع نص يعني الدمج وليس الجمع.
- استخدم `===` و `!==` دائماً.
- `&&` و `||` و `!` لدمج الشروط.

=== lesson
## النصوص في كل مكان

أسماء المستخدمين، والرسائل، والعناوين، ونتائج البحث، كلها نصوص. لذلك التعامل مع النصوص من أكثر المهارات استخداماً في البرمجة.

## دمج النصوص و Template Literals

الطريقة القديمة لدمج النصوص هي `+`:

```js
const name = "سارة";
const age = 22;
console.log("اسمي " + name + " وعمري " + age + " سنة");
```

```output
اسمي سارة وعمري 22 سنة
```

الطريقة الحديثة والأوضح هي **القوالب النصية (Template Literals)**: نستخدم العلامة المائلة `` ` `` ونضع المتغيرات داخل `${ }`:

```js
const name = "سارة";
const age = 22;
console.log(`اسمي ${name} وعمري ${age} سنة`);
console.log(`بعد 5 سنوات سيكون عمري ${age + 5}`);
```

```output
اسمي سارة وعمري 22 سنة
بعد 5 سنوات سيكون عمري 27
```

يمكنك وضع أي تعبير داخل `${ }`، حتى العمليات الحسابية.

## طول النص والوصول إلى الأحرف

```js
const word = "JavaScript";
console.log(word.length);
console.log(word[0]);
console.log(word[4]);
console.log(word[word.length - 1]);
```

```output
10
J
S
t
```

- `length` يعطي عدد الأحرف.
- `[رقم]` يعطي الحرف في موقع معين. **الترقيم يبدأ من 0** وليس من 1، لذلك آخر حرف موقعه `length - 1`.

## دوال النصوص الأكثر استخداماً

النصوص لها **دوال (methods)** جاهزة نستدعيها بنقطة بعد النص:

| الدالة | وظيفتها |
|---|---|
| `toUpperCase()` و `toLowerCase()` | تحويل الأحرف الإنجليزية لكبيرة أو صغيرة |
| `trim()` | حذف المسافات من البداية والنهاية |
| `includes(x)` | هل يحتوي النص على x؟ |
| `startsWith(x)` و `endsWith(x)` | هل يبدأ أو ينتهي بـ x؟ |
| `indexOf(x)` | موقع أول ظهور لـ x، أو -1 إن لم يوجد |
| `slice(a, b)` | جزء من النص من الموقع a حتى ما قبل b |
| `replace(a, b)` | استبدال أول ظهور لـ a بـ b |
| `split(x)` | تقسيم النص إلى قائمة عند كل x |

```js
const email = "  Ahmed@Mail.com  ";
const clean = email.trim().toLowerCase();
console.log(clean);
console.log(clean.includes("@"));
console.log(clean.endsWith(".com"));
console.log(clean.indexOf("@"));
console.log(clean.slice(0, 5));
```

```output
ahmed@mail.com
true
true
5
ahmed
```

لاحظ أننا **سلسلنا** دالتين: `trim()` ثم `toLowerCase()`. كل دالة تعيد نصاً جديداً، فنستدعي عليه الدالة التالية.

```js
const sentence = "أنا أتعلم JavaScript";
console.log(sentence.replace("JavaScript", "البرمجة"));
console.log("أحمر,أخضر,أزرق".split(","));
```

```output
أنا أتعلم البرمجة
["أحمر","أخضر","أزرق"]
```

> 💡 النصوص في JavaScript **غير قابلة للتعديل**: دوال مثل `toUpperCase()` لا تغيّر النص الأصلي، بل تعيد نصاً جديداً. إذا أردت حفظ النتيجة، خزّنها في متغير.

## ملخص الدرس

- استخدم القوالب النصية `` `مرحبا ${name}` `` للدمج.
- `length` لطول النص، و `[i]` للحرف، والترقيم يبدأ من 0.
- الدوال `trim` و `includes` و `slice` و `replace` و `split` هي الأكثر استخداماً.
- دوال النصوص تعيد نصاً جديداً ولا تغيّر الأصلي.
