## البرنامج يتخذ قرارات

حتى الآن كانت برامجنا تنفّذ كل الأسطر بالترتيب. لكن البرامج الحقيقية تتخذ قرارات: إذا كانت كلمة المرور صحيحة ادخل، وإلا اعرض رسالة خطأ. هذا ما تفعله **الجمل الشرطية**.

## الجملة if

```js
const temperature = 35;

if (temperature > 30) {
  console.log("الجو حار، اشرب ماء كثيراً");
}
console.log("انتهى البرنامج");
```

```output
الجو حار، اشرب ماء كثيراً
انتهى البرنامج
```

الصيغة: `if (شرط) { كود }`. إذا كان الشرط `true` يُنفَّذ الكود داخل الأقواس المعقوفة `{ }`، وإذا كان `false` يُتخطى.

## if و else

`else` تحدد ما يحدث عندما يكون الشرط خاطئاً:

```js
const age = 15;

if (age >= 18) {
  console.log("يمكنك استخراج رخصة قيادة");
} else {
  console.log(`انتظر ${18 - age} سنوات أخرى`);
}
```

```output
انتظر 3 سنوات أخرى
```

## شروط متعددة: else if

عندما يكون لدينا أكثر من احتمالين:

```js
const score = 78;

if (score >= 90) {
  console.log("ممتاز");
} else if (score >= 75) {
  console.log("جيد جداً");
} else if (score >= 60) {
  console.log("جيد");
} else {
  console.log("راسب");
}
```

```output
جيد جداً
```

تُفحص الشروط **بالترتيب من الأعلى**، وعند أول شرط صحيح يُنفَّذ كوده ويُتجاهل الباقي. لذلك 78 لم تصل إلى شرط `>= 60` مع أنه صحيح أيضاً.

> ⚠️ الترتيب مهم: لو وضعنا `score >= 60` أولاً، لحصل كل من تجاوز 60 على "جيد" حتى صاحب الـ 95!

## دمج الشروط

نستخدم العوامل المنطقية التي تعلمناها:

```js
const hasAccount = true;
const isBanned = false;

if (hasAccount && !isBanned) {
  console.log("مرحباً بعودتك");
}

const day = "الجمعة";
if (day === "الجمعة" || day === "السبت") {
  console.log("عطلة نهاية الأسبوع");
}
```

```output
مرحباً بعودتك
عطلة نهاية الأسبوع
```

## القيم الصادقة والكاذبة (Truthy و Falsy)

الشرط لا يجب أن يكون `true` أو `false` حرفياً. أي قيمة تُعامل كصادقة، **ما عدا** هذه القيم الست الكاذبة:

`false` و `0` و `""` (نص فارغ) و `null` و `undefined` و `NaN`

```js
const username = "";

if (username) {
  console.log(`أهلاً ${username}`);
} else {
  console.log("الرجاء إدخال اسمك");
}
```

```output
الرجاء إدخال اسمك
```

## العامل الثلاثي (Ternary)

اختصار لـ if/else البسيطة التي تختار بين قيمتين:

```js
const stock = 0;
const status = stock > 0 ? "متوفر" : "نفد من المخزون";
console.log(status);
```

```output
نفد من المخزون
```

الصيغة: `شرط ? قيمة_إذا_صح : قيمة_إذا_خطأ`. استخدمه للحالات القصيرة فقط، أما المنطق الطويل فـ if أوضح.

## ملخص الدرس

- `if` تنفّذ كوداً عندما يكون الشرط صحيحاً، و `else` عندما يكون خاطئاً.
- `else if` لاحتمالات متعددة، والترتيب مهم.
- القيم الكاذبة: `false` و `0` و `""` و `null` و `undefined` و `NaN`.
- `? :` اختصار لاختيار قيمة من اثنتين.

## عندما تكثر المقارنات

تخيّل أنك تريد عرض اسم اليوم حسب رقمه من 1 إلى 7. باستخدام `if` ستكتب سبعة شروط `else if (day === ...)`. الجملة `switch` تجعل هذا أنظف عندما نقارن **متغيراً واحداً بقيم محددة**.

## صيغة switch

```js
const day = 3;

switch (day) {
  case 1:
    console.log("الأحد");
    break;
  case 2:
    console.log("الاثنين");
    break;
  case 3:
    console.log("الثلاثاء");
    break;
  default:
    console.log("يوم غير معروف");
}
```

```output
الثلاثاء
```

- `switch (day)` القيمة التي نفحصها.
- `case 3:` إذا كانت القيمة تساوي 3 (بمقارنة صارمة `===`).
- `break` تخرج من الـ switch بعد تنفيذ الحالة.
- `default` تُنفَّذ إذا لم تطابق أي حالة، وهي تشبه `else`.

## خطورة نسيان break

بدون `break` يستمر التنفيذ إلى الحالات التالية، حتى لو لم تطابق! وهذا يسمى **السقوط (fall-through)**:

```js
const level = 1;

switch (level) {
  case 1:
    console.log("المستوى الأول");
  case 2:
    console.log("المستوى الثاني");
  case 3:
    console.log("المستوى الثالث");
}
```

```output
المستوى الأول
المستوى الثاني
المستوى الثالث
```

> ⚠️ نسيان `break` من أشهر الأخطاء مع switch. اجعل كتابتها عادة بعد كل حالة.

## استخدام السقوط عمداً

أحياناً نريد أن تشترك عدة قيم في نفس الكود، فنضع الحالات متتالية:

```js
const month = "فبراير";

switch (month) {
  case "ديسمبر":
  case "يناير":
  case "فبراير":
    console.log("الشتاء");
    break;
  case "يونيو":
  case "يوليو":
  case "أغسطس":
    console.log("الصيف");
    break;
  default:
    console.log("الربيع أو الخريف");
}
```

```output
الشتاء
```

## switch أم if؟

| استخدم switch عندما | استخدم if عندما |
|---|---|
| تقارن متغيراً واحداً بقيم ثابتة محددة | تحتاج نطاقات مثل `score > 90` |
| الحالات كثيرة ومتشابهة | الشروط مختلفة أو مركبة بـ `&&` و `\|\|` |

## ملخص الدرس

- `switch` تقارن قيمة واحدة بعدة حالات باستخدام `===`.
- `break` ضرورية للخروج بعد كل حالة، وإلا يحدث السقوط.
- `default` للحالة التي لا تطابق أي `case`.
- يمكن جمع عدة حالات لتشترك في نفس الكود.

## لماذا نحتاج الحلقات؟

اطبع الأرقام من 1 إلى 5... سهل، خمسة أسطر. لكن ماذا عن 1 إلى 1000؟ **الحلقات (Loops)** تكرر كوداً عدداً من المرات دون أن نكتبه مراراً.

## حلقة for

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

```output
1
2
3
4
5
```

الحلقة لها ثلاثة أجزاء داخل الأقواس، مفصولة بفاصلة منقوطة:

| الجزء | الكود | معناه |
|---|---|---|
| البداية | `let i = 1` | يُنفَّذ مرة واحدة قبل أن تبدأ الحلقة |
| الشرط | `i <= 5` | يُفحص قبل كل دورة، وتتوقف الحلقة عندما يصبح خاطئاً |
| التحديث | `i++` | يُنفَّذ بعد كل دورة |

يسمى المتغير `i` **العدّاد**، والاسم `i` عرف متبع (من كلمة index).

## تتبّع الحلقة خطوة بخطوة

من المفيد أن تتخيل ما يحدث:

1. `i = 1`، هل `1 <= 5`؟ نعم، اطبع 1، ثم `i` تصبح 2.
2. هل `2 <= 5`؟ نعم، اطبع 2، ثم `i` تصبح 3.
3. ... وهكذا حتى `i = 6`، هل `6 <= 5`؟ لا، توقف.

## أمثلة متنوعة

العدّ التنازلي:

```js
for (let i = 3; i >= 1; i--) {
  console.log(`${i}...`);
}
console.log("انطلق!");
```

```output
3...
2...
1...
انطلق!
```

القفز بخطوات أكبر، مثلاً الأرقام الزوجية:

```js
for (let i = 0; i <= 10; i += 2) {
  console.log(i);
}
```

```output
0
2
4
6
8
10
```

## التجميع داخل الحلقة

من أشهر استخدامات الحلقات **تجميع** نتيجة. مثلاً مجموع الأرقام من 1 إلى 100:

```js
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;
}
console.log(sum);
```

```output
5050
```

لاحظ أن `sum` عُرّف **خارج** الحلقة، لأننا نريده أن يحتفظ بقيمته بين الدورات.

## الحلقة مع الشروط

```js
for (let i = 1; i <= 6; i++) {
  if (i % 2 === 0) {
    console.log(`${i} زوجي`);
  } else {
    console.log(`${i} فردي`);
  }
}
```

```output
1 فردي
2 زوجي
3 فردي
4 زوجي
5 فردي
6 زوجي
```

## المرور على أحرف نص

```js
const word = "كود";
for (let i = 0; i < word.length; i++) {
  console.log(`الحرف ${i}: ${word[i]}`);
}
```

```output
الحرف 0: ك
الحرف 1: و
الحرف 2: د
```

لاحظ استخدام `<` وليس `<=`، لأن آخر موقع هو `length - 1`.

> ⚠️ احذر **الحلقة اللانهائية**: إذا لم يصبح الشرط خاطئاً أبداً (مثلاً نسيت `i++`) ستعمل الحلقة للأبد ويتجمد البرنامج. محرر CodeWay يوقفها بعد 5 ثوانٍ.

## ملخص الدرس

- `for (بداية; شرط; تحديث) { ... }` تكرر الكود ما دام الشرط صحيحاً.
- يمكن العد تصاعدياً أو تنازلياً أو بخطوات.
- لتجميع نتيجة، عرّف المتغير قبل الحلقة.
- `i < str.length` للمرور على كل أحرف نص.

## حلقة while

تستخدم `for` عندما نعرف **عدد التكرارات** مسبقاً. أما `while` فنستخدمها عندما نريد التكرار **ما دام شرط معين صحيحاً**، دون معرفة عدد المرات.

```js
let balance = 1000;
let months = 0;

while (balance > 0) {
  balance -= 300;
  months++;
}
console.log(`نفد الرصيد بعد ${months} أشهر`);
```

```output
نفد الرصيد بعد 4 أشهر
```

الصيغة: `while (شرط) { كود }`. يُفحص الشرط قبل كل دورة تماماً مثل for.

## مثال: مضاعفة حتى حد معين

```js
let n = 1;
while (n < 100) {
  n *= 2;
}
console.log(n);
```

```output
128
```

لا نعرف مسبقاً كم مرة سنضاعف، لذلك `while` مناسبة هنا.

## for و while وجهان لعملة واحدة

أي حلقة for يمكن كتابتها بـ while:

```js
let i = 1;
while (i <= 3) {
  console.log(i);
  i++;
}
```

```output
1
2
3
```

لكن لاحظ أن البداية والتحديث تفرقا في أماكن مختلفة، ولهذا `for` أوضح عندما نعدّ.

## حلقة do...while

الفرق الوحيد: `do...while` تنفّذ الكود **مرة واحدة على الأقل** قبل فحص الشرط، لأن الشرط في الأسفل:

```js
let attempts = 10;

do {
  console.log(`المحاولة رقم ${attempts}`);
  attempts++;
} while (attempts < 3);
```

```output
المحاولة رقم 10
```

الشرط `10 < 3` خاطئ من البداية، ومع ذلك نُفّذ الكود مرة واحدة. لو استخدمنا `while` العادية لما طُبع شيء.

متى نحتاجها؟ مثلاً عند طلب إدخال من المستخدم: نسأل مرة على الأقل، ثم نكرر السؤال إذا كانت الإجابة غير صالحة.

## مقارنة سريعة

| الحلقة | متى تستخدمها |
|---|---|
| `for` | عدد التكرارات معروف (عدّ، أو المرور على نص أو قائمة) |
| `while` | التكرار حتى يتغير شرط ما، وعدد المرات غير معروف |
| `do...while` | مثل while لكن يجب التنفيذ مرة واحدة على الأقل |

> ⚠️ في `while` تأكد أن شيئاً داخل الحلقة **يغيّر الشرط** في النهاية، وإلا ستحصل على حلقة لا نهائية.

## ملخص الدرس

- `while` تكرر ما دام الشرط صحيحاً، وتناسب الحالات التي لا نعرف فيها عدد التكرارات.
- `do...while` تنفّذ مرة واحدة على الأقل لأن الشرط يُفحص بعد التنفيذ.
- تأكد دائماً من أن الشرط سيصبح خاطئاً يوماً ما.

--- exercise
لديك رقم `n`. استخدم حلقة `while` لحساب **عدد أرقامه**: اقسم الرقم على 10 باستخدام `Math.floor(n / 10)` في كل دورة، وعدّ الدورات حتى يصبح 0.

~~~

~~~

=== lesson
## التحكم في سير الحلقة

أحياناً نحتاج أن نتوقف عن الحلقة قبل نهايتها، أو نتخطى دورة معينة. هنا تأتي `break` و `continue`.

## break: الخروج من الحلقة فوراً

```js
const numbers = "3 8 12 7 15 4";
const list = numbers.split(" ");

for (let i = 0; i < list.length; i++) {
  const n = Number(list[i]);
  if (n > 10) {
    console.log(`أول رقم أكبر من 10 هو ${n}`);
    break;
  }
}
```

```output
أول رقم أكبر من 10 هو 12
```

بمجرد أن وجدنا ما نبحث عنه لا داعي لإكمال البحث، فـ `break` توقف الحلقة كلياً. بدونها لكانت طبعت 15 أيضاً.

## continue: تخطي الدورة الحالية

`continue` لا توقف الحلقة، بل تقفز إلى **الدورة التالية** مباشرة متجاهلة باقي الكود في الدورة الحالية:

```js
for (let i = 1; i <= 7; i++) {
  if (i % 3 === 0) {
    continue;
  }
  console.log(i);
}
```

```output
1
2
4
5
7
```

تخطينا 3 و 6 لأنهما يقبلان القسمة على 3.

## الفرق بالصورة

| الأمر | ماذا يحدث |
|---|---|
| `break` | يخرج من الحلقة نهائياً ويكمل الكود الذي بعدها |
| `continue` | يترك الدورة الحالية وينتقل للدورة التالية |

## مثال واقعي: البحث مع break

لنتحقق هل الرقم أولي (لا يقبل القسمة إلا على 1 ونفسه):

```js
const n = 29;
let isPrime = n > 1;

for (let d = 2; d < n; d++) {
  if (n % d === 0) {
    isPrime = false;
    break;
  }
}
console.log(isPrime ? `${n} عدد أولي` : `${n} ليس أولياً`);
```

```output
29 عدد أولي
```

إذا وجدنا قاسماً واحداً نعرف الجواب فوراً، فلا داعي لفحص باقي الأرقام.

## الحلقات المتداخلة

يمكن وضع حلقة داخل حلقة. مثلاً جدول ضرب صغير:

```js
for (let row = 1; row <= 3; row++) {
  let line = "";
  for (let col = 1; col <= 3; col++) {
    line += `${row * col}\t`;
  }
  console.log(line);
}
```

```output
1	2	3
2	4	6
3	6	9
```

الرمز `\t` يضيف مسافة جدولة (Tab). لاحظ أن الحلقة الداخلية تكتمل بالكامل في كل دورة من الحلقة الخارجية.

> 💡 `break` و `continue` تؤثران على **أقرب حلقة** فقط. إذا استخدمت `break` داخل الحلقة الداخلية، تخرج منها فقط وتستمر الخارجية.

## ملخص الدرس

- `break` توقف الحلقة كلياً، وهي مفيدة عند إيجاد ما نبحث عنه.
- `continue` تتخطى بقية الدورة الحالية وتنتقل للتالية.
- يمكن تداخل الحلقات، و `break` و `continue` تؤثران على أقرب حلقة فقط.

--- exercise
لديك نص يحتوي أرقاماً مفصولة بمسافات. مرّ عليها بحلقة `for` و:

- **تخطَّ** الأرقام السالبة باستخدام `continue`.
- **توقف** تماماً عند الوصول إلى الرقم `0` باستخدام `break`.
- اجمع باقي الأرقام.

في النهاية اطبع: `المجموع: 18`

~~~starter
const data = "5 -2 7 -9 6 0 10 3".split(" ");
let sum = 0;

for (let i = 0; i < data.length; i++) {
  const n = Number(data[i]);
  // أكمل هنا
}

~~~
~~~expected
المجموع: 18
~~~
~~~solution
const data = "5 -2 7 -9 6 0 10 3".split(" ");
let sum = 0;

for (let i = 0; i < data.length; i++) {
  const n = Number(data[i]);
  if (n === 0) {
    break;
  }
  if (n < 0) {
    continue;
  }
  sum += n;
}
console.log(`المجموع: ${sum}`);
~~~
