=== lesson
## الجسر بين JavaScript والصفحة

كل ما تعلمناه حتى الآن كان يعمل في المخرجات فقط. الآن سنجعل JavaScript تتحكم في **صفحة الويب نفسها**: تغيّر النصوص، وتخفي العناصر، وتستجيب للضغطات.

عندما يقرأ المتصفح ملف HTML، يحوّله إلى **شجرة من الكائنات** في الذاكرة تسمى **DOM** (اختصار Document Object Model). كل وسم في الصفحة يصبح كائناً يمكن لـ JavaScript قراءته وتعديله.

## الصفحة كشجرة

خذ هذا الـ HTML:

```html
<body>
  <h1>متجري</h1>
  <ul>
    <li>قميص</li>
    <li>حذاء</li>
  </ul>
</body>
```

يراه المتصفح كشجرة:

```text
document
 └─ body
     ├─ h1  ← "متجري"
     └─ ul
         ├─ li ← "قميص"
         └─ li ← "حذاء"
```

- **العقدة (Node):** كل عنصر أو نص في الشجرة.
- **الأب (parent):** العنصر الذي يحتوي غيره، مثل `ul` بالنسبة لـ `li`.
- **الأبناء (children):** العناصر داخل عنصر آخر.
- **الإخوة (siblings):** العناصر التي تشترك في نفس الأب.

## الكائن document

نقطة الدخول إلى كل شيء هي الكائن `document`، وهو يمثل الصفحة كاملة:

```html
<h1>مرحباً</h1>
<p>هذه فقرة</p>
```

```js
console.log(document.title === "");
console.log(document.body.children.length);
console.log(document.body.children[0].textContent);
```

```output
true
2
مرحباً
```

- `document.body` عنصر `<body>`.
- `children` أبناء العنصر (عناصر HTML فقط).
- `textContent` النص الموجود داخل العنصر.

## كيف تربط JavaScript بصفحتك؟

في المشاريع الحقيقية تكتب الكود في ملف منفصل وتربطه في نهاية HTML:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <title>موقعي</title>
</head>
<body>
  <h1 id="title">مرحباً</h1>

  <script src="app.js"></script>
</body>
</html>
```

> 💡 نضع وسم `<script>` في **نهاية** `body` حتى تكون كل العناصر قد أُنشئت قبل أن يحاول الكود الوصول إليها. وبديله الحديث: وضعه في `head` مع الخاصية `defer`.

## ماذا نستطيع أن نفعل بـ DOM؟

| الإمكانية | مثال |
|---|---|
| تحديد العناصر | الوصول لزر أو حقل إدخال |
| تغيير المحتوى | تحديث عدد المنتجات في السلة |
| تغيير الأنماط | تفعيل الوضع الليلي |
| إنشاء وحذف العناصر | إضافة تعليق جديد |
| الاستجابة للأحداث | تنفيذ كود عند الضغط على زر |

وهذا ما سنتعلمه في بقية هذه الوحدة. في تمارين هذه الوحدة سترى **معاينة الصفحة** فوق المخرجات، وتتغير مباشرة حسب كودك.

## ملخص الدرس

- DOM شجرة كائنات يبنيها المتصفح من HTML.
- كل وسم عقدة لها أب وأبناء وإخوة.
- `document` نقطة الدخول للصفحة كاملة.
- نربط ملف JavaScript في نهاية `body` أو بـ `defer`.

## الوصول إلى العنصر الذي تريده

قبل أن تغيّر أي شيء في الصفحة، يجب أن **تحدد** العنصر. الطريقة الحديثة والأقوى هي استخدام **محددات CSS** نفسها التي تعرفها.

## querySelector: أول عنصر مطابق

```html
<h1 id="main-title">المتجر</h1>
<p class="note">ملاحظة أولى</p>
<p class="note">ملاحظة ثانية</p>
<button>اشترِ الآن</button>
```

```js
const title = document.querySelector("#main-title");
const firstNote = document.querySelector(".note");
const button = document.querySelector("button");

console.log(title.textContent);
console.log(firstNote.textContent);
console.log(button.textContent);
```

```output
المتجر
ملاحظة أولى
اشترِ الآن
```

| المحدد | يختار |
|---|---|
| `"#id"` | العنصر الذي له هذا المعرّف |
| `".class"` | العناصر التي لها هذا الصنف |
| `"tag"` | العناصر من هذا الوسم |
| `"ul li"` | كل `li` داخل `ul` |
| `"input[type=email]"` | حسب خاصية معينة |

## querySelectorAll: كل العناصر المطابقة

```html
<ul>
  <li class="item">خبز</li>
  <li class="item">حليب</li>
  <li class="item">بيض</li>
</ul>
```

```js
const items = document.querySelectorAll(".item");
console.log(items.length);

items.forEach(item => console.log(item.textContent));

const names = [...items].map(li => li.textContent);
console.log(names);
```

```output
3
خبز
حليب
بيض
["خبز","حليب","بيض"]
```

`querySelectorAll` تُرجع **NodeList**: تشبه المصفوفة وتدعم `forEach` و `length`، لكنها لا تدعم `map` و `filter`. لذلك نحولها لمصفوفة حقيقية بـ `[...items]`.

## الطرق الأقدم

ستراها في أكواد كثيرة:

| الطريقة | تعادل |
|---|---|
| `getElementById("x")` | `querySelector("#x")` |
| `getElementsByClassName("x")` | `querySelectorAll(".x")` تقريباً |
| `getElementsByTagName("p")` | `querySelectorAll("p")` تقريباً |

`getElementById` أسرع قليلاً، لكن `querySelector` أكثر مرونة وتكفيك في كل الحالات.

## إذا لم يُعثر على العنصر

```html
<p>فقرة</p>
```

```js
const missing = document.querySelector("#not-here");
console.log(missing);
console.log(document.querySelectorAll(".nothing").length);
```

```output
null
0
```

> ⚠️ أشهر خطأ للمبتدئين: `Cannot read properties of null`. يعني أن `querySelector` لم تجد العنصر (اسم خاطئ، أو الكود نُفّذ قبل إنشاء العنصر)، ثم حاولت استخدام النتيجة `null`.

## التنقل في الشجرة

بعد تحديد عنصر، يمكنك الانتقال إلى أقاربه:

```html
<div class="card">
  <h3>العنوان</h3>
  <p>الوصف</p>
</div>
```

```js
const heading = document.querySelector(".card h3");
console.log(heading.parentElement.className);
console.log(heading.nextElementSibling.textContent);
console.log(heading.closest(".card") !== null);
```

```output
card
الوصف
true
```

`closest(selector)` تبحث صعوداً عن أقرب أب يطابق المحدد، وهي مفيدة جداً مع الأحداث.

## ملخص الدرس

- `querySelector` تُرجع أول عنصر مطابق أو `null`.
- `querySelectorAll` تُرجع كل العناصر كـ NodeList.
- المحددات نفسها التي في CSS: `#id` و `.class` و `tag`.
- `parentElement` و `children` و `nextElementSibling` و `closest` للتنقل.

## تغيير ما يراه المستخدم

بعد تحديد العنصر، يمكننا تعديل نصه ومحتواه وأنماطه وخصائصه. هنا تبدأ الصفحة بالحياة.

## تغيير النص

```html
<p id="msg">جاري التحميل...</p>
```

```js
const msg = document.querySelector("#msg");
msg.textContent = "تم التحميل بنجاح ✓";
console.log(msg.textContent);
```

```output
تم التحميل بنجاح ✓
```

## textContent أم innerHTML؟

```html
<div id="box"></div>
```

```js
const box = document.querySelector("#box");

box.textContent = "<b>نص عريض؟</b>";
console.log(box.children.length);

box.innerHTML = "<b>نص عريض!</b>";
console.log(box.children.length);
```

```output
0
1
```

- `textContent` يضع النص **كما هو**، حتى لو احتوى وسوماً.
- `innerHTML` يفسّر النص كـ HTML وينشئ عناصر.

> ⚠️ لا تضع أبداً نصاً أدخله المستخدم في `innerHTML`! قد يكتب كوداً خبيثاً يُنفَّذ في صفحتك، وهذه ثغرة أمنية مشهورة اسمها **XSS**. استخدم `textContent` لأي نص من المستخدم.

## تغيير الأنماط

الطريقة المباشرة عبر `style`:

```html
<p id="note">ملاحظة مهمة</p>
```

```js
const note = document.querySelector("#note");
note.style.color = "crimson";
note.style.fontSize = "20px";
note.style.backgroundColor = "#fff3cd";
console.log(note.style.fontSize);
```

```output
20px
```

لاحظ أن خصائص CSS ذات الشرطة مثل `font-size` تُكتب بأسلوب camelCase: `fontSize`.

## الطريقة الأفضل: classList

بدلاً من كتابة الأنماط في JavaScript، نعرّفها في CSS كصنف، ثم نضيف الصنف أو نزيله:

```html
<button id="btn">زر</button>
```

```js
const btn = document.querySelector("#btn");

btn.classList.add("active");
btn.classList.add("big");
btn.classList.remove("big");
console.log(btn.className);

btn.classList.toggle("active");
console.log(btn.classList.contains("active"));
```

```output
active
false
```

| الدالة | وظيفتها |
|---|---|
| `add("x")` | إضافة صنف |
| `remove("x")` | إزالة صنف |
| `toggle("x")` | إضافة إن لم يكن موجوداً، وإزالة إن كان موجوداً |
| `contains("x")` | هل الصنف موجود؟ |

> 💡 `toggle` مثالية للأشياء التي تُفتح وتُغلق: القوائم، والوضع الليلي، وزر الإعجاب.

## الخصائص (Attributes)

```html
<img id="photo" src="cat.jpg" alt="قطة">
<input id="email" type="email">
```

```js
const photo = document.querySelector("#photo");
console.log(photo.getAttribute("alt"));
photo.setAttribute("alt", "قطة لطيفة");
console.log(photo.alt);

const email = document.querySelector("#email");
email.value = "user@mail.com";
email.disabled = true;
console.log(email.value, email.disabled);
```

```output
قطة
قطة لطيفة
user@mail.com true
```

## إنشاء العناصر وحذفها

```html
<ul id="list"><li>أول</li></ul>
```

```js
const list = document.querySelector("#list");

const li = document.createElement("li");
li.textContent = "عنصر جديد";
list.append(li);

console.log(list.children.length);

list.children[0].remove();
console.log(list.children[0].textContent);
```

```output
2
عنصر جديد
```

الخطوات دائماً: **أنشئ** العنصر بـ `createElement`، ثم **املأه** بالنص والأصناف، ثم **أضفه** للصفحة بـ `append` (في النهاية) أو `prepend` (في البداية).

## ملخص الدرس

- `textContent` للنص الآمن، و `innerHTML` للـ HTML (لا تستخدمه مع مدخلات المستخدم).
- `style.prop` لتعديل نمط مباشرة، و `classList` هي الطريقة المفضلة.
- `getAttribute` و `setAttribute` والخصائص المباشرة مثل `value`.
- `createElement` ثم `append` لإضافة عنصر، و `remove()` لحذفه.

## الصفحة تستجيب

**الحدث (Event)** هو شيء يحدث في الصفحة: ضغطة زر، كتابة في حقل، تحريك الفأرة، إرسال نموذج. ونحن نكتب كوداً **يستمع** للحدث وينفّذ دالة عندما يقع.

## addEventListener

```html
<button id="like">أعجبني 👍</button>
<p id="count">0</p>
```

```js
const button = document.querySelector("#like");
const countEl = document.querySelector("#count");
let likes = 0;

button.addEventListener("click", () => {
  likes++;
  countEl.textContent = likes;
});

// محاكاة ثلاث ضغطات للتجربة
button.click();
button.click();
button.click();
console.log(countEl.textContent);
```

```output
3
```

الصيغة: `element.addEventListener("نوع الحدث", دالة)`. الدالة لا تُنفَّذ الآن، بل **كلما** وقع الحدث، ولهذا تسمى **معالج الحدث (event handler)**.

> 💡 في الصفحات الحقيقية المستخدم هو من يضغط. استخدمنا `button.click()` هنا فقط لمحاكاة الضغط في التمرين. جرّب أيضاً الضغط بنفسك على الزر في المعاينة!

## أشهر الأحداث

| الحدث | يقع عندما |
|---|---|
| `click` | الضغط على العنصر |
| `input` | تتغير قيمة حقل الإدخال (مع كل حرف) |
| `change` | تتغير القيمة ويغادر المستخدم الحقل |
| `submit` | إرسال نموذج |
| `keydown` | الضغط على مفتاح في لوحة المفاتيح |
| `mouseenter` و `mouseleave` | دخول الفأرة للعنصر وخروجها |

## كائن الحدث (event)

دالة المعالج تستقبل كائناً فيه تفاصيل ما حدث:

```html
<input id="search" placeholder="ابحث...">
<p id="preview"></p>
```

```js
const search = document.querySelector("#search");
const preview = document.querySelector("#preview");

search.addEventListener("input", event => {
  preview.textContent = `تبحث عن: ${event.target.value}`;
});

search.value = "لابتوب";
search.dispatchEvent(new Event("input"));
console.log(preview.textContent);
```

```output
تبحث عن: لابتوب
```

- `event.target` العنصر الذي وقع عليه الحدث.
- `event.target.value` قيمة الحقل.
- `event.key` المفتاح المضغوط في أحداث لوحة المفاتيح.

## منع السلوك الافتراضي

بعض العناصر لها سلوك تلقائي: النموذج يعيد تحميل الصفحة عند إرساله، والرابط ينقلك لصفحة أخرى. `preventDefault()` توقف ذلك:

```html
<form id="login">
  <input name="user" value="ali">
  <button>دخول</button>
</form>
```

```js
const form = document.querySelector("#login");

form.addEventListener("submit", event => {
  event.preventDefault();
  const user = form.elements.user.value;
  console.log(`محاولة دخول: ${user}`);
});

form.requestSubmit();
```

```output
محاولة دخول: ali
```

بدون `preventDefault()` كانت الصفحة ستُعاد تحميلها وتضيع البيانات. هذا السطر موجود في كل نموذج تتعامل معه JavaScript تقريباً.

## إزالة المستمع

```html
<button id="once">اضغط مرة واحدة</button>
```

```js
const btn = document.querySelector("#once");
let clicks = 0;

function handleClick() {
  clicks++;
  btn.removeEventListener("click", handleClick);
}
btn.addEventListener("click", handleClick);

btn.click();
btn.click();
console.log(clicks);
```

```output
1
```

لإزالة مستمع يجب أن تمرر **نفس الدالة**، لذلك عرّفناها باسم بدلاً من دالة سهمية مجهولة. وهناك اختصار: `addEventListener("click", fn, { once: true })`.

## ملخص الدرس

- `addEventListener(type, handler)` ينفّذ الدالة عند وقوع الحدث.
- أشهر الأحداث: `click` و `input` و `submit` و `keydown`.
- `event.target` العنصر الذي وقع عليه الحدث.
- `event.preventDefault()` يمنع السلوك التلقائي مثل إعادة تحميل الصفحة عند الإرسال.

## مشكلة: مئات المستمعين

تخيّل قائمة فيها 500 منتج، ولكل منتج زر حذف. هل نضيف 500 مستمع؟ وماذا عن المنتجات التي تُضاف لاحقاً، ولم تكن موجودة عندما أضفنا المستمعين؟

الحل الذكي اسمه **تفويض الأحداث (Event Delegation)**، وهو يعتمد على ظاهرة تسمى **الفقاعة (Bubbling)**.

## فقاعة الأحداث (Bubbling)

عندما تضغط على عنصر، لا يقع الحدث عليه وحده. بل **يصعد** الحدث كالفقاعة إلى أبيه، ثم أب أبيه، وهكذا حتى `document`:

```html
<div id="outer">
  <button id="inner">اضغطني</button>
</div>
```

```js
document.querySelector("#outer").addEventListener("click", () => {
  console.log("وصل الحدث إلى div");
});
document.querySelector("#inner").addEventListener("click", () => {
  console.log("ضُغط الزر");
});

document.querySelector("#inner").click();
```

```output
ضُغط الزر
وصل الحدث إلى div
```

ضغطنا الزر فقط، لكن مستمع الـ `div` نُفّذ أيضاً لأن الحدث صعد إليه.

## الفكرة: مستمع واحد على الأب

بدلاً من مستمع لكل عنصر، نضع **مستمعاً واحداً على الأب**، ونعرف من `event.target` أي ابن ضُغط بالضبط:

```html
<ul id="menu">
  <li>الرئيسية</li>
  <li>المنتجات</li>
  <li>تواصل معنا</li>
</ul>
```

```js
const menu = document.querySelector("#menu");

menu.addEventListener("click", event => {
  if (event.target.tagName === "LI") {
    console.log(`اخترت: ${event.target.textContent}`);
  }
});

menu.children[1].click();
menu.children[2].click();
```

```output
اخترت: المنتجات
اخترت: تواصل معنا
```

## الميزة الكبرى: العناصر الجديدة تعمل تلقائياً

```html
<ul id="list"><li>عنصر 1</li></ul>
```

```js
const list = document.querySelector("#list");
list.addEventListener("click", e => {
  if (e.target.tagName === "LI") console.log(`ضغطت ${e.target.textContent}`);
});

const li = document.createElement("li");
li.textContent = "عنصر جديد";
list.append(li);

li.click();
```

```output
ضغطت عنصر جديد
```

العنصر الجديد لم يكن موجوداً عند إضافة المستمع، ومع ذلك يعمل، لأن المستمع على الأب.

## closest و data-attributes: الأسلوب الاحترافي

في الواقع، العنصر المضغوط قد يكون أيقونة داخل الزر وليس الزر نفسه. لذلك نستخدم `closest`، ونخزّن بيانات العنصر في خصائص `data-*`:

```html
<div id="products">
  <div class="card" data-id="7">
    <span>سماعة</span>
    <button class="delete" data-id="7"><b>✕</b> حذف</button>
  </div>
</div>
```

```js
document.querySelector("#products").addEventListener("click", event => {
  const btn = event.target.closest(".delete");
  if (!btn) return;
  console.log(`حذف المنتج رقم ${btn.dataset.id}`);
  btn.closest(".card").remove();
});

document.querySelector(".delete b").click();
console.log(document.querySelectorAll(".card").length);
```

```output
حذف المنتج رقم 7
0
```

- `closest(".delete")` تجد الزر حتى لو ضُغط على `<b>` داخله.
- `data-id="7"` في HTML تُقرأ في JavaScript عبر `element.dataset.id`.
- `if (!btn) return;` تتجاهل الضغطات على أي مكان آخر داخل الأب.

## إيقاف الفقاعة

في حالات نادرة تريد منع الحدث من الصعود: `event.stopPropagation()`. لكن استخدمها بحذر، لأنها قد تعطّل مستمعين آخرين يعتمدون على الفقاعة.

## ملخص الدرس

- الأحداث تصعد من العنصر إلى آبائه (Bubbling).
- التفويض: مستمع واحد على الأب بدلاً من مستمع لكل ابن.
- يعمل تلقائياً مع العناصر المضافة لاحقاً.
- `event.target.closest(selector)` و `dataset` هما الأسلوب الاحترافي.
