## ما هو Angular؟

**Angular** إطار عمل من Google لبناء تطبيقات الويب الكبيرة. على عكس Vue و React اللذين يركزان على الواجهة، Angular **منصة متكاملة**: فيه التوجيه والنماذج والاتصال بالخادم والاختبار وحقن الاعتماديات، كلها رسمية ومتناسقة. لذلك تختاره الشركات والبنوك والجهات الحكومية لتطبيقات يعمل عليها فرق كبيرة لسنوات.

يُكتب بـ **TypeScript** دائماً (راجع دورة TypeScript إن احتجت).

## Angular CLI

كل شيء في Angular يبدأ من أداة سطر الأوامر الرسمية:

```bash
npm install -g @angular/cli
ng new my-app
cd my-app
ng serve
```

افتح `http://localhost:4200`. أهم الأوامر:

| الأمر | الوظيفة |
|---|---|
| `ng new name` | إنشاء مشروع |
| `ng serve` | خادم التطوير مع التحديث الفوري |
| `ng generate component user-card` | إنشاء مكون (اختصاره `ng g c`) |
| `ng generate service cart` | إنشاء خدمة (`ng g s`) |
| `ng build` | البناء للإنتاج في `dist/` |
| `ng test` | تشغيل الاختبارات |

## بنية المشروع

| الملف | الدور |
|---|---|
| `src/main.ts` | نقطة البداية: يشغّل المكون الجذري |
| `src/app/app.ts` | المكون الجذري `App` |
| `src/app/app.html` | قالبه |
| `src/app/app.css` | تنسيقه |
| `src/app/app.config.ts` | إعدادات التطبيق: التوجيه و HttpClient وغيرها |
| `src/index.html` | الصفحة وفيها `<app-root>` |

و `src/main.ts`:

```ts
import { bootstrapApplication } from "@angular/platform-browser";
import { appConfig } from "./app/app.config";
import { App } from "./app/app";

bootstrapApplication(App, appConfig).catch((err) => console.error(err));
```

## أول مكون

```angular
// file: src/app/app.ts
import { Component } from "@angular/core";

@Component({
  selector: "app-root",

  styleUrl: "./app.css",

// test

print(text("p"));
```

```output
مرحباً بك في CodeWay
تعلّم Angular في 2025
```

كل كتلة **Angular** في هذه الدورة تعمل فعلاً بـ Angular الحقيقي (أحدث إصدار)، يُترجم في متصفحك، وتحتها معاينة حية.

- `@Component` **مزخرف (Decorator)** يحوّل الصنف العادي إلى مكون، ويصف قالبه وتنسيقه.
- `selector: "app-root"` اسم الوسم الذي يمثّل المكون في HTML.
- خصائص الصنف (`title` و `year`) متاحة في القالب بـ `{{ }}`.

> 💡 في Angular الحديث (17 فأحدث) كل المكونات **مستقلة (Standalone)**: لا حاجة لملفات `NgModule` القديمة التي ستراها في الشروحات القديمة.

## ملخص الدرس

- Angular منصة متكاملة من Google، تُكتب بـ TypeScript.
- `ng new` و `ng serve` و `ng generate` أساس العمل اليومي.
- المكون صنف عليه `@Component` بـ `selector` وقالب وتنسيق.
- `main.ts` يشغّل المكون الجذري بـ `bootstrapApplication`.

## المدخلات: input()

لتمرير بيانات للمكون، عرّف **مدخلات** بالدالة `input()`. القيمة **إشارة (Signal)** تقرؤها باستدعائها: `name()`:

```angular
// file: src/app/user-card.ts
import { Component, input } from "@angular/core";

@Component({
  selector: "app-user-card",
  template: `
    <div class="card">
      <strong>{{ name() }}</strong> - {{ role() }}
      @if (isAdmin()) { <span>⭐</span> }
    </div>
  `,
})
export class UserCard {
  name = input.required<string>();
  role = input("عضو");
  isAdmin = input(false);
}
// file: src/app/app.ts
import { Component } from "@angular/core";
import { UserCard } from "./user-card";

@Component({
  selector: "app-root",
  imports: [UserCard],
  template: `
    <app-user-card name="ليان" role="مسؤولة" [isAdmin]="true" />
    <app-user-card [name]="newMember" />
  `,
})
export class App {
  newMember = "عمر";
}
// test
texts(".card").forEach(t => print(t));
```

```output
ليان - مسؤولة ⭐
عمر - عضو
```

- `input.required<string>()` مدخل إلزامي، و `input("عضو")` له قيمة افتراضية.
- `name="ليان"` يمرر نصاً ثابتاً، و `[name]="newMember"` بالأقواس المربعة يمرر **تعبيراً** (متغير أو رقم أو قيمة منطقية).

## المخرجات: output()

المكون الابن يبلغ أباه بحدث عبر `output()`، والأب يستمع بالأقواس الهلالية `( )`:

```angular
// file: src/app/counter.ts
import { Component, output } from "@angular/core";

@Component({
  selector: "app-counter",
  template: `<button (click)="add()">+1</button>`,
})
export class Counter {
  added = output<number>();
  add() {
    this.added.emit(1);
  }
}
// file: src/app/app.ts
import { Component } from "@angular/core";
import { Counter } from "./counter";

@Component({
  selector: "app-root",
  imports: [Counter],
  template: `
    <app-counter (added)="total = total + $event" />
    <p>المجموع: {{ total }}</p>
  `,
})
export class App {
  total = 0;
}
// test
await click("button"); await click("button"); await click("button");
print(text("p"));
```

```output
المجموع: 3
```

`$event` هي القيمة التي أُرسلت مع `emit`.

> 💡 قد تجد في المشاريع القائمة الصيغة الأقدم `@Input() name!: string;` و `@Output() added = new EventEmitter<number>();`. الصيغة الحديثة `input()` و `output()` هي الموصى بها الآن.

## ملخص الدرس

- لاستخدام مكون داخل آخر: أضفه إلى `imports` واكتب وسمه.

## أنواع ربط البيانات

ربط البيانات يصل الصنف (TypeScript) بالقالب (HTML). أربعة أشكال:

| الشكل | الاتجاه | مثال |
|---|---|---|
| `{{ }}` الاستيفاء | من الصنف إلى الشاشة | `{{ user.name }}` |
| `[ ]` ربط الخاصية | من الصنف إلى الشاشة | `[src]="avatar"` |
| `( )` ربط الحدث | من الشاشة إلى الصنف | `(click)="save()"` |
| `[( )]` الربط الثنائي | في الاتجاهين | `[(ngModel)]="name"` |

## الإشارات (Signals)

الطريقة الحديثة لحفظ الحالة في Angular هي **الإشارات**: قيمة تعلم من يستخدمها، فتحدّث الشاشة عند تغيرها بدقة:

```angular
// file: src/app/app.ts
import { Component, signal, computed } from "@angular/core";

@Component({
  selector: "app-root",
  template: `
    <h2>{{ count() }}</h2>
    <p>الضعف: {{ double() }}</p>
    <button (click)="increment()" [disabled]="count() >= 3">زيادة</button>
    <button (click)="count.set(0)">تصفير</button>
  `,
})
export class App {
  count = signal(0);
  double = computed(() => this.count() * 2);

  increment() {
    this.count.update((c) => c + 1);
  }
}
// test
for (let i = 0; i < 4; i++) await click("button");
print(text("h2"), "|", text("p"), "| معطل:", $("button").disabled);
```

```output
3 | الضعف: 6 | معطل: true
```

- `signal(0)` ينشئ إشارة، و `count()` يقرؤها.
- `set(قيمة)` يضبطها، و `update(fn)` يحسبها من القيمة السابقة.
- `computed` إشارة مشتقة تتحدث تلقائياً.
- `[disabled]="..."` ربط خاصية: الزر يتعطل عند 3 (لذلك توقف العداد رغم 4 نقرات).

## الربط الثنائي: ngModel

لحقول الإدخال، `[(ngModel)]` يربط الحقل بخاصية في الاتجاهين. يحتاج `FormsModule` في `imports`:

```angular
// file: src/app/app.ts
import { Component } from "@angular/core";
import { FormsModule } from "@angular/forms";

@Component({
  selector: "app-root",
  imports: [FormsModule],
  template: `
    <input [(ngModel)]="name" placeholder="اسمك" />
    <select [(ngModel)]="lang">
      <option value="ar">العربية</option>
      <option value="en">English</option>
    </select>
    <p>{{ lang === "ar" ? "مرحباً" : "Hello" }} {{ name }}</p>
  `,
})
export class App {
  name = "";
  lang = "ar";
}
// test
await type("input", "نورة");
print(text("p"));
await select("select", "en");
print(text("p"));
```

```output

Hello نورة
```

## التحكم في القالب: @if و @for و @switch

```angular
// file: src/app/app.ts
import { Component, signal } from "@angular/core";

@Component({
  selector: "app-root",
  template: `
    @if (tasks().length === 0) {
      <p>لا توجد مهام</p>
    } @else {
      <ul>
        @for (task of tasks(); track task.id; let i = $index) {
          <li>{{ i + 1 }}. {{ task.title }}</li>
        }
      </ul>
    }

    @switch (status()) {
      @case ("online") { <span>🟢 متصل</span> }
      @case ("away") { <span>🟡 غائب</span> }
      @default { <span>⚪ غير متصل</span> }
    }
  `,
})
export class App {
  tasks = signal([
    { id: 1, title: "قراءة" },
    { id: 2, title: "برمجة" },
  ]);
  status = signal("away");
}
// test
print(texts("li").join(" | "), "|", text("span"));
```

```output
1. قراءة | 2. برمجة | 🟡 غائب
```

- `track task.id` إلزامي في `@for`: يساعد Angular على تحديث القائمة بكفاءة.
- داخل `@for` متغيرات جاهزة: `$index` و `$first` و `$last` و `$count`.
- `@for` يقبل أيضاً `@empty { }` لعرض شيء عند خلو القائمة.

> 💡 في المشاريع القديمة ستجد `*ngIf` و `*ngFor`. صيغة `@if` و `@for` الحديثة أوضح وأسرع، وهي الموصى بها.

## ملخص الدرس

- `{{ }}` و `[خاصية]` من الصنف للشاشة، و `(حدث)` من الشاشة للصنف، و `[(ngModel)]` في الاتجاهين.
- `signal` و `computed` للحالة، و `set` و `update` للتعديل.
- `[class.x]` و `[style.prop]` للأصناف والأنماط الديناميكية.
- `@if` و `@else` و `@for` مع `track` و `@switch` للتحكم في القالب.

~~~solution
// file: src/app/app.ts
import { Component, signal, computed } from "@angular/core";
import { FormsModule } from "@angular/forms";

interface Task {
  id: number;
  title: string;
  done: boolean;
}

@Component({
  selector: "app-root",
  imports: [FormsModule],
  template: `
    <input [(ngModel)]="newTitle" placeholder="مهمة جديدة" />
    <button class="add" (click)="add()">أضف</button>
    <ul>
      @for (task of tasks(); track task.id) {
        <li [class.done]="task.done" (click)="toggle(task.id)">{{ task.title }}</li>
      }
    </ul>
    @if (tasks().length === 0) {
      <p>لا توجد مهام</p>
    } @else {
      <p>المنجز: {{ doneCount() }} من {{ tasks().length }}</p>
    }
  `,
})
export class App {
  tasks = signal<Task[]>([]);
  newTitle = "";
  doneCount = computed(() => this.tasks().filter((t) => t.done).length);

  add() {
    const title = this.newTitle.trim();
    if (!title) return;
    this.tasks.update((list) => [...list, { id: list.length + 1, title, done: false }]);
    this.newTitle = "";
  }

  toggle(id: number) {
    this.tasks.update((list) => list.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
  }
}
~~~
