## التوجيه (Routing)

تطبيق Angular **صفحة واحدة (SPA)**: الصفحة لا تُعاد من الخادم عند التنقل، بل يبدّل **الموجّه (Router)** المكون المعروض حسب الرابط.

ثلاث خطوات:

1. **تعريف المسارات** في `app.routes.ts`: كل مسار يربط رابطاً بمكون.
2. **تفعيل الموجّه** بـ `provideRouter(routes)` في `app.config.ts`.
3. **مكان العرض** `<router-outlet />` في قالب `App`، و **روابط** بـ `routerLink`.

```angular
// file: src/app/home.ts
import { Component } from "@angular/core";

@Component({ selector: "app-home", template: `<h2>الرئيسية</h2>` })
export class Home {}
// file: src/app/about.ts
import { Component } from "@angular/core";

@Component({ selector: "app-about", template: `<h2>من نحن</h2>` })
export class About {}
// file: src/app/not-found.ts
import { Component } from "@angular/core";

@Component({ selector: "app-not-found", template: `<h2>الصفحة غير موجودة 404</h2>` })
export class NotFound {}
// file: src/app/app.routes.ts
import { Routes } from "@angular/router";
import { Home } from "./home";
import { About } from "./about";
import { NotFound } from "./not-found";

export const routes: Routes = [
  { path: "", component: Home, title: "الرئيسية" },
  { path: "about", component: About, title: "من نحن" },
  { path: "home", redirectTo: "" },
  { path: "**", component: NotFound },
];
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideRouter } from "@angular/router";
import { routes } from "./app.routes";

export const appConfig: ApplicationConfig = {
  providers: [provideRouter(routes)],
};
// file: src/app/app.ts
import { Component } from "@angular/core";
import { RouterOutlet, RouterLink, RouterLinkActive } from "@angular/router";

@Component({
  selector: "app-root",
  imports: [RouterOutlet, RouterLink, RouterLinkActive],
  template: `
    <nav>
      <a routerLink="/" routerLinkActive="active" [routerLinkActiveOptions]="{ exact: true }">الرئيسية</a> |
      <a routerLink="/about" routerLinkActive="active">من نحن</a>
    </nav>
    <router-outlet />
  `,
  styles: `.active { font-weight: bold; color: #dd0031; }`,
})
export class App {}
// test
print(path(), "→", text("h2"));
await click("text=من نحن");
print(path(), "→", text("h2"), "| النشط:", text("a.active"), "| العنوان:", document.title);
await navigate("/home");
print(path(), "→", text("h2"));
await navigate("/xyz");
print(path(), "→", text("h2"));
```

```output
/ → الرئيسية
/about → من نحن | النشط: من نحن | العنوان: من نحن
/ → الرئيسية
/xyz → الصفحة غير موجودة 404
```

- `path: ""` الصفحة الرئيسية، و `path: "**"` يلتقط أي رابط غير معروف (ضعه **آخراً** لأن المسارات تُفحص بالترتيب).
- `redirectTo` يحوّل من رابط إلى آخر.
- `title` يغيّر عنوان تبويب المتصفح تلقائياً.
- `routerLink` بدلاً من `href`: يتنقل **دون إعادة تحميل** الصفحة.
- `routerLinkActive="active"` يضيف الصنف للرابط النشط، و `exact: true` يمنع تفعيل `/` مع كل الروابط.

> 💡 عند إنشاء المشروع بـ `ng new` يُجهَّز هذا كله تلقائياً: `app.routes.ts` و `provideRouter` و `<router-outlet />`.

## التنقل من الكود

بعد حفظ نموذج مثلاً، تنقّل برمجياً بخدمة `Router`:

```angular
// file: src/app/home.ts
import { Component, inject } from "@angular/core";
import { Router } from "@angular/router";

@Component({
  selector: "app-home",
  template: `<button (click)="finish()">إنهاء التسجيل</button>`,
})
export class Home {
  private router = inject(Router);

  finish() {
    this.router.navigate(["/welcome"], { queryParams: { name: "ريم" } });
  }
}
// file: src/app/welcome.ts
import { Component, inject } from "@angular/core";
import { ActivatedRoute } from "@angular/router";

@Component({
  selector: "app-welcome",
  template: `<h2>أهلاً {{ name }}</h2>`,
})
export class Welcome {
  name = inject(ActivatedRoute).snapshot.queryParamMap.get("name");
}
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideRouter } from "@angular/router";
import { Home } from "./home";
import { Welcome } from "./welcome";

export const appConfig: ApplicationConfig = {
  providers: [provideRouter([
    { path: "", component: Home },
    { path: "welcome", component: Welcome },
  ])],
};
// file: src/app/app.ts
import { Component } from "@angular/core";
import { RouterOutlet } from "@angular/router";

@Component({
  selector: "app-root",
  imports: [RouterOutlet],
  template: `<router-outlet />`,
})
export class App {}
// test
await click("button");
print(decodeURIComponent(path()), "→", text("h2"));
```

```output
/welcome?name=ريم → أهلاً ريم
```

`?name=ريم` يسمى **معامل استعلام (Query Param)**: اختياري ومناسب للبحث والفلترة والترتيب.

## ملخص الدرس

- المسارات مصفوفة `Routes` من `{ path, component }`، وتُفعَّل بـ `provideRouter(routes)`.
- `<router-outlet />` مكان عرض الصفحة، و `routerLink` للروابط، و `routerLinkActive` للرابط النشط.
- `redirectTo` للتحويل، و `**` لصفحة 404 في آخر القائمة.
- `inject(Router).navigate([...])` للتنقل من الكود.

## معاملات المسار

صفحة تفاصيل المنتج تحتاج رقمه في الرابط: `/products/3`. نعرّف المعامل بنقطتين `:id`:

```ts
{ path: "products/:id", component: ProductDetail }
```

ولقراءته، أسهل طريقة في Angular الحديث: فعّل `withComponentInputBinding()` فيصبح المعامل **مدخلاً** عادياً في المكون:

```angular
// file: src/app/data.ts
export const products = [
  { id: 1, name: "حاسوب محمول", price: 3200 },
  { id: 2, name: "سماعات", price: 250 },
  { id: 3, name: "شاشة", price: 900 },
];
// file: src/app/product-list.ts
import { Component } from "@angular/core";
import { RouterLink } from "@angular/router";
import { products } from "./data";

@Component({
  selector: "app-product-list",
  imports: [RouterLink],
  template: `
    <ul>
      @for (p of products; track p.id) {
        <li><a [routerLink]="['/products', p.id]">{{ p.name }}</a></li>
      }
    </ul>
  `,
})
export class ProductList {
  products = products;
}
// file: src/app/product-detail.ts
import { Component, input, computed } from "@angular/core";
import { RouterLink } from "@angular/router";
import { products } from "./data";

@Component({
  selector: "app-product-detail",
  imports: [RouterLink],
  template: `
    @if (product(); as p) {
      <h2>{{ p.name }}</h2>
      <p>السعر: {{ p.price }} ر.س</p>
    } @else {
      <h2>المنتج غير موجود</h2>
    }
    <a routerLink="/">← رجوع</a>
  `,
})
export class ProductDetail {
  id = input.required<string>();
  product = computed(() => products.find((p) => p.id === Number(this.id())));
}
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideRouter, withComponentInputBinding } from "@angular/router";
import { ProductList } from "./product-list";
import { ProductDetail } from "./product-detail";

export const appConfig: ApplicationConfig = {
  providers: [provideRouter([
    { path: "", component: ProductList },
    { path: "products/:id", component: ProductDetail },
  ], withComponentInputBinding())],
};
// file: src/app/app.ts
import { Component } from "@angular/core";
import { RouterOutlet } from "@angular/router";

@Component({ selector: "app-root", imports: [RouterOutlet], template: `<router-outlet />` })
export class App {}
// test
await click("text=سماعات");
print(path(), "→", text("h2"), "|", text("p"));
await navigate("/products/99");
print(path(), "→", text("h2"));
await click("text=← رجوع");
print(path(), "→", count("li"), "منتجات");
```

```output
/products/2 → سماعات | السعر: 250 ر.س
/products/99 → المنتج غير موجود
/ → 3 منتجات
```

- `[routerLink]="['/products', p.id]"` يبني الرابط من أجزاء.
- معاملات الرابط **نصوص** دائماً، لذلك `Number(this.id())`.
- `@if (product(); as p)` يحفظ النتيجة في متغير `p` داخل الكتلة.
- عند الانتقال من `/products/1` إلى `/products/2` يُعاد استخدام المكون نفسه، والمدخل إشارة فيتحدث `computed` تلقائياً.

> 💡 الطريقة الأقدم: `inject(ActivatedRoute).paramMap.subscribe(...)` أو `snapshot.paramMap.get("id")`. ستراها كثيراً في المشاريع القائمة.

## المسارات المتداخلة (Children)

صفحة لوحة تحكم لها قائمة جانبية ثابتة وأقسام تتبدل داخلها: المسار الأب له `<router-outlet />` خاص به:

```angular
// file: src/app/dashboard.ts
import { Component } from "@angular/core";
import { RouterOutlet, RouterLink } from "@angular/router";

@Component({
  selector: "app-dashboard",
  imports: [RouterOutlet, RouterLink],
  template: `
    <h2>لوحة التحكم</h2>
    <a routerLink="stats">الإحصائيات</a> | <a routerLink="settings">الإعدادات</a>
    <section><router-outlet /></section>
  `,
})
export class Dashboard {}

@Component({ selector: "app-stats", template: `<p>120 طالباً هذا الشهر</p>` })
export class Stats {}

@Component({ selector: "app-settings", template: `<p>إعدادات الحساب</p>` })
export class Settings {}
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideRouter } from "@angular/router";
import { Dashboard, Stats, Settings } from "./dashboard";

export const appConfig: ApplicationConfig = {
  providers: [provideRouter([
    { path: "", redirectTo: "dashboard", pathMatch: "full" },
    {
      path: "dashboard",
      component: Dashboard,
      children: [
        { path: "", redirectTo: "stats", pathMatch: "full" },
        { path: "stats", component: Stats },
        { path: "settings", component: Settings },
      ],
    },
  ])],
};
// file: src/app/app.ts
import { Component } from "@angular/core";
import { RouterOutlet } from "@angular/router";

@Component({ selector: "app-root", imports: [RouterOutlet], template: `<router-outlet />` })
export class App {}
// test
print(path(), "→", text("h2"), "/", text("section"));
await click("text=الإعدادات");
print(path(), "→", text("h2"), "/", text("section"));
```

```output
/dashboard/stats → لوحة التحكم / 120 طالباً هذا الشهر
/dashboard/settings → لوحة التحكم / إعدادات الحساب
```

- `routerLink="stats"` بلا `/` رابط **نسبي** للمسار الحالي.
- `pathMatch: "full"` مع المسار الفارغ: يحوّل فقط عندما يكون الرابط فارغاً تماماً.

## ملخص الدرس

- `products/:id` يعرّف معاملاً، و `withComponentInputBinding()` يجعله مدخلاً `id = input()`.
- معاملات الرابط نصوص، حوّلها بـ `Number()` عند الحاجة.
- `children` لمسارات متداخلة، والأب يحتاج `<router-outlet />` خاصاً به.
- الروابط بلا `/` نسبية للمسار الحالي.

## حماية المسارات (Guards)

بعض الصفحات للمستخدمين المسجلين فقط. **الحارس (Guard)** دالة تُستدعى قبل دخول المسار: تُرجع `true` للسماح، أو رابطاً للتحويل:

```bash
ng generate guard auth
```

```angular
// file: src/app/auth.ts
import { Injectable, signal } from "@angular/core";

@Injectable({ providedIn: "root" })
export class Auth {
  loggedIn = signal(false);
}
// file: src/app/auth.guard.ts
import { inject } from "@angular/core";
import { CanActivateFn, Router } from "@angular/router";
import { Auth } from "./auth";

export const authGuard: CanActivateFn = (route, state) => {
  const auth = inject(Auth);
  const router = inject(Router);
  if (auth.loggedIn()) return true;
  return router.createUrlTree(["/login"], { queryParams: { returnUrl: state.url } });
};
// file: src/app/pages.ts
import { Component, inject } from "@angular/core";
import { Router, ActivatedRoute } from "@angular/router";
import { Auth } from "./auth";

@Component({ selector: "app-profile", template: `<h2>ملفي الشخصي 🔒</h2>` })
export class Profile {}

@Component({
  selector: "app-login",
  template: `<h2>تسجيل الدخول</h2><button (click)="login()">دخول</button>`,
})
export class Login {
  private auth = inject(Auth);
  private router = inject(Router);
  private route = inject(ActivatedRoute);

  login() {
    this.auth.loggedIn.set(true);
    const back = this.route.snapshot.queryParamMap.get("returnUrl") || "/";
    this.router.navigateByUrl(back);
  }
}
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideRouter } from "@angular/router";
import { Profile, Login } from "./pages";
import { authGuard } from "./auth.guard";

export const appConfig: ApplicationConfig = {
  providers: [provideRouter([
    { path: "login", component: Login },
    { path: "profile", component: Profile, canActivate: [authGuard] },
  ])],
};
// file: src/app/app.ts
import { Component } from "@angular/core";
import { RouterOutlet } from "@angular/router";

@Component({ selector: "app-root", imports: [RouterOutlet], template: `<router-outlet />` })
export class App {}
// test
await navigate("/profile");
print(decodeURIComponent(path()), "→", text("h2"));
await click("button");
print(path(), "→", text("h2"));
```

```output
/login?returnUrl=/profile → تسجيل الدخول
/profile → ملفي الشخصي 🔒
```

- `CanActivateFn` حارس **دالي**: داخلها تستطيع استخدام `inject()`.
- إرجاع `UrlTree` من `createUrlTree` **يحوّل** المستخدم، وأضفنا `returnUrl` ليعود بعد الدخول إلى حيث كان.
- `canActivate: [authGuard]` يربط الحارس بالمسار، ويمكن وضع أكثر من حارس.

أنواع أخرى: `canActivateChild` لحماية المسارات الأبناء، و `canDeactivate` لمنع الخروج من صفحة فيها تعديلات غير محفوظة، و `canMatch`.

> ⚠️ الحارس يحسّن تجربة المستخدم فقط، **وليس حماية أمنية**: كود الواجهة يمكن تعديله في المتصفح. الحماية الحقيقية للبيانات تكون في الخادم.

## التحميل الكسول (Lazy Loading)

في التطبيق الكبير لا داعي لتحميل كود صفحة الإدارة لكل الزوار. `loadComponent` يحمّل المكون **عند أول زيارة** للمسار، في ملف JavaScript مستقل:

```angular
// file: src/app/admin.ts
import { Component } from "@angular/core";

console.log("تم تحميل ملف لوحة الإدارة الآن");

@Component({ selector: "app-admin", template: `<h2>لوحة الإدارة</h2>` })
export class Admin {}
// file: src/app/app.config.ts
import { ApplicationConfig, Component } from "@angular/core";
import { provideRouter } from "@angular/router";

@Component({ selector: "app-home", template: `<h2>الرئيسية</h2>` })
class Home {}

export const appConfig: ApplicationConfig = {
  providers: [provideRouter([
    { path: "", component: Home },
    { path: "admin", loadComponent: () => import("./admin").then((m) => m.Admin) },
  ])],
};
// file: src/app/app.ts
import { Component } from "@angular/core";
import { RouterOutlet, RouterLink } from "@angular/router";

@Component({
  selector: "app-root",
  imports: [RouterOutlet, RouterLink],
  template: `<a routerLink="/admin">الإدارة</a><router-outlet />`,
})
export class App {}
// test
print(text("h2"));
await click("a");
print(path(), "→", text("h2"));
```

```output
الرئيسية
/admin → لوحة الإدارة
```

- `import("./admin")` **استيراد ديناميكي**: أداة البناء تضع الملف في جزء (chunk) مستقل.
- لمجموعة مسارات كاملة: `loadChildren: () => import("./admin/admin.routes").then(m => m.ADMIN_ROUTES)`.
- عند تشغيل `ng build` سترى في المخرجات قسم **Lazy chunk files** بأسماء هذه الملفات.

## ملخص الدرس

- الحارس `CanActivateFn` يُرجع `true` أو `UrlTree` للتحويل، ويُربط بـ `canActivate`.
- `inject()` متاحة داخل الحراس.
- الحراس لتجربة المستخدم، والحماية الأمنية في الخادم.
- `loadComponent` و `loadChildren` يحمّلان الكود عند الحاجة فيصغر التحميل الأول.

import { inject } from "@angular/core";
import { CanActivateFn, Router } from "@angular/router";

export const adminGuard: CanActivateFn = () => {
  if (inject(Role).role() === "admin") return true;
  return inject(Router).createUrlTree(["/denied"]);

// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
