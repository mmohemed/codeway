## HttpClient: الاتصال بالخادم

Angular فيه عميل HTTP رسمي: **HttpClient**. فعّله مرة واحدة في `app.config.ts`:

```ts
import { provideHttpClient, withFetch } from "@angular/common/http";

export const appConfig: ApplicationConfig = {
  providers: [provideHttpClient(withFetch())],
};
```

ثم احقنه في **خدمة**، فالمكونات لا تتعامل مع الروابط مباشرة:

```angular
// file: src/app/product.service.ts
import { Injectable, inject } from "@angular/core";

import { Observable } from "rxjs";

export interface Product {
  id: number;

  stock: number;

@Injectable({ providedIn: "root" })

  private http = inject(HttpClient);

  getAll(): Observable<Product[]> {
    return this.http.get<Product[]>(this.url);
```

(الخادم `api.codeway.dev` في هذه الدورة وهمي يعمل داخل متصفحك، ويستجيب للطلبات كخادم REST حقيقي.)

- `http.get<Product[]>(url)` يُرجع **Observable**: وصفاً لطلب لم يُرسل بعد.
- الطلب **لا يُرسل** إلا عند `subscribe()`. بدونها لا يحدث شيء!
- `<Product[]>` يخبر TypeScript بشكل الرد، فتحصل على الإكمال التلقائي والتحقق.
- `HttpClient` يحوّل JSON تلقائياً، لا حاجة لـ `res.json()` كما في `fetch`.

## الإضافة والتعديل والحذف

```angular
// file: src/app/todo.service.ts
import { Injectable, inject } from "@angular/core";
import { HttpClient } from "@angular/common/http";

export interface Todo {
  id: number;
  title: string;
  done: boolean;
}

@Injectable({ providedIn: "root" })
export class TodoService {
  private http = inject(HttpClient);
  private url = "https://api.codeway.dev/todos";

  getAll() { return this.http.get<Todo[]>(this.url); }
  create(title: string) { return this.http.post<Todo>(this.url, { title, done: false }); }
  toggle(t: Todo) { return this.http.patch<Todo>(`${this.url}/${t.id}`, { done: !t.done }); }
  remove(id: number) { return this.http.delete<void>(`${this.url}/${id}`); }
}
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideHttpClient, withFetch } from "@angular/common/http";

export const appConfig: ApplicationConfig = { providers: [provideHttpClient(withFetch())] };
// file: src/app/app.ts
import { Component, inject, signal } from "@angular/core";
import { TodoService, Todo } from "./todo.service";

@Component({
  selector: "app-root",
  template: `
    <button class="add" (click)="add()">أضف "مراجعة RxJS"</button>
    @for (t of todos(); track t.id) {
      <p>
        <span (click)="toggle(t)">{{ t.done ? "✅" : "⬜" }} {{ t.title }}</span>
        <button (click)="remove(t.id)">حذف</button>
      </p>
    }
  `,
})
export class App {
  private service = inject(TodoService);
  todos = signal<Todo[]>([]);

  constructor() {
    this.service.getAll().subscribe((list) => this.todos.set(list));
  }

  add() {
    this.service.create("مراجعة RxJS").subscribe((t) => this.todos.update((l) => [...l, t]));
  }

  toggle(t: Todo) {
    this.service.toggle(t).subscribe((u) => this.todos.update((l) => l.map((x) => (x.id === u.id ? u : x))));
  }

  remove(id: number) {
    this.service.remove(id).subscribe(() => this.todos.update((l) => l.filter((x) => x.id !== id)));
  }
}
// test
await click(".add");
await click("p:nth-of-type(2) span");
await click("p:nth-of-type(1) button");
texts("p span").forEach(t => print(t));
print("الطلبات:", api.log.join(" ← "));
```

```output
✅ تعلّم Angular
⬜ مراجعة RxJS
الطلبات: GET /todos ← POST /todos ← PATCH /todos/2 ← DELETE /todos/1
```

| الدالة | الطريقة | الاستخدام |
|---|---|---|
| `http.get<T>(url)` | GET | جلب |
| `http.post<T>(url, body)` | POST | إنشاء |
| `http.put<T>(url, body)` | PUT | استبدال كامل |
| `http.patch<T>(url, body)` | PATCH | تعديل جزئي |
| `http.delete(url)` | DELETE | حذف |

ولإرسال معاملات استعلام: `http.get(url, { params: { category: "شاشات" } })`.

## ملخص الدرس

- `provideHttpClient()` في الإعدادات، ثم `inject(HttpClient)` داخل خدمة.
- كل دوال HttpClient تُرجع Observable، والطلب يُرسل عند `subscribe()`.
- `get<T>` يحدد نوع الرد، و JSON يُحوَّل تلقائياً.
- `post` و `put` و `patch` و `delete` لبقية العمليات.

## RxJS و Observable

**Observable** تيار من القيم عبر الزمن: قد يُصدر قيمة واحدة (رد HTTP) أو قيماً كثيرة (نقرات، كتابة، مؤقت). مكتبة **RxJS** تمنحك **مشغّلات (Operators)** لتحويل هذه التيارات، وهي جزء أساسي من Angular.

```angular
// file: src/app/app.ts
import { Component, signal } from "@angular/core";
import { of, from, interval } from "rxjs";
import { map, filter, take, reduce } from "rxjs/operators";

@Component({ selector: "app-root", template: `@for (l of lines(); track $index) { <p>{{ l }}</p> }` })
export class App {
  lines = signal<string[]>([]);
  log = (s: string) => this.lines.update((l) => [...l, s]);

  constructor() {
    of(1, 2, 3, 4, 5, 6)
      .pipe(
        filter((n) => n % 2 === 0),
        map((n) => n * 10),
      )
      .subscribe((v) => this.log("قيمة: " + v));

    from(["أ", "ب", "ج"]).pipe(reduce((acc, x) => acc + x, "")).subscribe((s) => this.log("مجموع: " + s));

    interval(30)
      .pipe(take(3))
      .subscribe({
        next: (i) => this.log("نبضة " + i),
        complete: () => this.log("انتهى المؤقت"),
      });
  }
}
// test
await wait(200);
texts("p").forEach(t => print(t));
```

```output
قيمة: 20
قيمة: 40
قيمة: 60
مجموع: أبج
نبضة 0
نبضة 1
نبضة 2
انتهى المؤقت
```

- `of(...)` و `from([...])` ينشئان Observable من قيم، و `interval(ms)` يُصدر رقماً كل فترة.
- `pipe(...)` يمرر التيار عبر المشغّلات بالترتيب، مثل خط إنتاج.
- `subscribe` يقبل كائناً بـ `next` و `error` و `complete`.

| المشغّل | الوظيفة |
|---|---|
| `map` | تحويل كل قيمة |
| `filter` | تمرير القيم المطابقة فقط |
| `take(n)` | أول n قيم ثم إنهاء |
| `tap` | تنفيذ شيء دون تغيير القيمة (للتصحيح) |
| `debounceTime(ms)` | الانتظار حتى يتوقف التيار مدة ms |
| `distinctUntilChanged` | تجاهل القيمة المكررة المتتالية |
| `switchMap` | تحويل كل قيمة إلى Observable جديد وإلغاء السابق |
| `catchError` | معالجة الخطأ |

## مثال واقعي: البحث أثناء الكتابة

المستخدم يكتب، ولا نريد طلباً للخادم مع **كل حرف**. هذا هو المثال الكلاسيكي لقوة RxJS:

```angular
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideHttpClient, withFetch } from "@angular/common/http";

export const appConfig: ApplicationConfig = { providers: [provideHttpClient(withFetch())] };
// file: src/app/app.ts
import { Component, inject, signal } from "@angular/core";
import { HttpClient } from "@angular/common/http";
import { Subject } from "rxjs";
import { debounceTime, distinctUntilChanged, switchMap, map } from "rxjs/operators";

interface Product { id: number; name: string; }

@Component({
  selector: "app-root",
  template: `
    <input (input)="search$.next($any($event.target).value)" placeholder="ابحث عن منتج" />
    <ul>
      @for (p of results(); track p.id) { <li>{{ p.name }}</li> }
    </ul>
  `,
})
export class App {
  private http = inject(HttpClient);
  search$ = new Subject<string>();
  results = signal<Product[]>([]);

  constructor() {
    this.search$
      .pipe(
        map((q) => q.trim()),
        debounceTime(300),
        distinctUntilChanged(),
        switchMap((q) => this.http.get<Product[]>("https://api.codeway.dev/products", { params: { q } })),
      )
      .subscribe((list) => this.results.set(list));
  }
}
// test
for (const q of ["ش", "شا", "شاش", "شاشة"]) { await type("input", q); await wait(50); }
await wait(400);
print(texts("li").join(" | "), "| طلبات:", api.calls);
await type("input", "شاشة "); await wait(400);
print("بعد إضافة مسافة فقط، طلبات:", api.calls);
```

```output
شاشة 27 بوصة | طلبات: 1
بعد إضافة مسافة فقط، طلبات: 1
```

كتب المستخدم 4 حروف بسرعة، لكن أُرسل **طلب واحد** فقط:

1. `Subject` تيار نُصدر فيه القيم يدوياً بـ `next()` (هنا: مع كل حرف).
2. `debounceTime(300)` ينتظر توقف الكتابة 300 جزء من الثانية.
3. `distinctUntilChanged()` يتجاهل البحث إن لم يتغير النص (بعد `trim` أصبحت `"شاشة "` مثل `"شاشة"`).
4. `switchMap` يحوّل النص إلى طلب HTTP، **ويلغي** الطلب السابق إن وصل بحث أحدث، فلا تظهر نتائج قديمة.

> 💡 علامة `$` في نهاية الاسم (`search$`) عرف شائع في Angular يعني "هذا Observable".

## ملخص الدرس

- Observable تيار قيم عبر الزمن، و `pipe` يمرره عبر المشغّلات.
- `map` و `filter` و `take` و `tap` للتحويلات الأساسية.
- `Subject` تيار تتحكم فيه بـ `next()`.
- البحث الذكي: `debounceTime` + `distinctUntilChanged` + `switchMap`.

? ما فائدة `debounceTime(300)` في البحث؟
+ انتظار توقف المستخدم عن الكتابة 300ms قبل تمرير القيمة، فتقل الطلبات
- تأخير عرض النتائج دائماً
- تكرار الطلب كل 300ms
> طلب واحد بدلاً من طلب لكل حرف.

? لماذا `switchMap` وليس `map` لتحويل النص إلى طلب HTTP؟

- لا فرق
> map كان سيُنتج Observable داخل Observable دون إرساله.

? ما هو `Subject`؟
+ Observable يمكنك إصدار القيم فيه يدوياً بـ next()
- نوع من المكونات
- خدمة HTTP
> مناسب لتحويل أحداث الواجهة إلى تيار.

## معالجة الأخطاء

الخادم قد يتعطل والشبكة قد تنقطع. التطبيق الاحترافي يعرض رسالة مفهومة بدلاً من صفحة فارغة. الدالة الثانية في `subscribe` (أو `error:`) تلتقط الخطأ:

```angular
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideHttpClient, withFetch } from "@angular/common/http";

export const appConfig: ApplicationConfig = { providers: [provideHttpClient(withFetch())] };
// file: src/app/app.ts
import { Component, inject, signal } from "@angular/core";
import { HttpClient, HttpErrorResponse } from "@angular/common/http";

@Component({
  selector: "app-root",
  template: `
    <button (click)="load()">تحميل</button>
    @if (error()) { <p class="error">{{ error() }}</p> }
    @for (u of users(); track u.id) { <li>{{ u.name }}</li> }
  `,
})
export class App {
  private http = inject(HttpClient);
  users = signal<{ id: number; name: string }[]>([]);
  error = signal("");

  load() {
    this.error.set("");
    this.http.get<{ id: number; name: string }[]>("https://api.codeway.dev/users").subscribe({
      next: (list) => this.users.set(list),
      error: (err: HttpErrorResponse) => this.error.set(`تعذّر التحميل (رمز ${err.status})، حاول مجدداً`),
    });
  }
}
// test
api.failNext = true;
await click("button");
print(text(".error"), "|", count("li"), "مستخدمين");
await click("button");
print("المحاولة الثانية:", exists(".error"), "|", count("li"), "مستخدمين");
```

```output
تعذّر التحميل (رمز 500)، حاول مجدداً | 0 مستخدمين
المحاولة الثانية: false | 3 مستخدمين
```

(`api.failNext` في الفحص يجعل الخادم الوهمي يُرجع خطأ 500 في الطلب التالي.)

### catchError و retry

داخل `pipe` يمكنك معالجة الخطأ وإرجاع قيمة بديلة، أو **إعادة المحاولة** تلقائياً:

```ts
this.http.get<User[]>(url).pipe(
  retry(2),                                // أعد المحاولة مرتين قبل الاستسلام
  catchError(() => of([])),                // ثم أرجع قائمة فارغة بدلاً من الخطأ
);
```

## toSignal: من Observable إلى إشارة

بدلاً من `subscribe` يدوياً وحفظ النتيجة في إشارة، `toSignal` يفعل ذلك ويلغي الاشتراك تلقائياً عند إزالة المكون:

```angular
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideHttpClient, withFetch } from "@angular/common/http";

export const appConfig: ApplicationConfig = { providers: [provideHttpClient(withFetch())] };
// file: src/app/app.ts
import { Component, inject, computed } from "@angular/core";
import { toSignal } from "@angular/core/rxjs-interop";
import { HttpClient } from "@angular/common/http";

interface Product { id: number; name: string; price: number; stock: number; }

@Component({
  selector: "app-root",
  template: `
    @if (products(); as list) {
      <p>المتوفر: {{ inStock().length }} من {{ list.length }}</p>
    } @else {
      <p>جارٍ التحميل...</p>
    }
  `,
})
export class App {
  private http = inject(HttpClient);
  products = toSignal(this.http.get<Product[]>("https://api.codeway.dev/products"));
  inStock = computed(() => (this.products() ?? []).filter((p) => p.stock > 0));
}
// test
print(text("p"));
```

```output
المتوفر: 3 من 4
```

- قيمة `toSignal` تكون `undefined` حتى يصل الرد، لذلك `@if (products(); as list)`.
- بعدها تعمل كأي إشارة: تُستخدم مع `computed`.
- `toObservable(signal)` يفعل العكس.

> 💡 ستجد أيضاً في المشاريع أنبوب `async`: `@if (products$ | async; as list)`. يشترك في القالب ويلغي الاشتراك تلقائياً، وهو البديل الأقدم لـ `toSignal`.

## المعترضات (Interceptors)

كل طلب لخادم محمي يحتاج رمز الدخول في ترويسة `Authorization`. بدلاً من إضافته في كل خدمة، **المعترض** دالة يمر بها **كل** طلب:

```angular
// file: src/app/auth.interceptor.ts
import { HttpInterceptorFn } from "@angular/common/http";

export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = "abc123";
  const authReq = req.clone({ setHeaders: { Authorization: `Bearer ${token}` } });
  return next(authReq);
};
// file: src/app/app.config.ts
import { ApplicationConfig } from "@angular/core";
import { provideHttpClient, withFetch, withInterceptors } from "@angular/common/http";
import { authInterceptor } from "./auth.interceptor";

export const appConfig: ApplicationConfig = {
  providers: [provideHttpClient(withFetch(), withInterceptors([authInterceptor]))],
};
// file: src/app/app.ts
import { Component, inject } from "@angular/core";
import { HttpClient } from "@angular/common/http";

@Component({ selector: "app-root", template: `<button (click)="load()">طلب</button>` })
export class App {
  private http = inject(HttpClient);
  load() {
    this.http.get("https://api.codeway.dev/todos").subscribe();
  }
}
// test
await click("button");
print(api.log[0], "| الترويسة:", api.lastHeaders.authorization);
```

```output
GET /todos | الترويسة: Bearer abc123
```

- الطلب في Angular **غير قابل للتعديل**، لذلك `req.clone({...})` ننشئ نسخة معدلة.
- `next(req)` يمرر الطلب للمعترض التالي ثم للخادم، ويمكن إضافة `pipe` على الرد (مثلاً لتحويل كل خطأ 401 إلى صفحة الدخول).
- استخدامات شائعة: رمز الدخول، مؤشر التحميل العام، تسجيل الأخطاء.

## ملخص الدرس

- عالج الأخطاء في `subscribe({ next, error })` أو بـ `catchError` داخل `pipe`، و `retry(n)` لإعادة المحاولة.
- `toSignal(observable$)` يحوّل الرد إلى إشارة ويدير الاشتراك تلقائياً.
- `HttpInterceptorFn` يعدّل كل الطلبات من مكان واحد، ويُسجَّل بـ `withInterceptors`.
