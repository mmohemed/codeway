## الخدمات (Services)

المكون مسؤول عن **العرض** فقط. أما المنطق المشترك (بيانات السلة، المستخدم الحالي، الاتصال بالخادم) فمكانه **الخدمة**: صنف عادي عليه `@Injectable`.

```bash
ng generate service cart
```

ينشئ `src/app/cart.ts`:

```angular
// file: src/app/cart.ts
import { Injectable, signal, computed } from "@angular/core";

export interface CartItem {
  name: string;
  price: number;
}

@Injectable({ providedIn: "root" })
export class Cart {
  private items = signal<CartItem[]>([]);

  readonly list = this.items.asReadonly();
  readonly total = computed(() => this.items().reduce((s, i) => s + i.price, 0));

  add(item: CartItem) {
    this.items.update((list) => [...list, item]);
  }
}
// file: src/app/product-list.ts
import { Component, inject } from "@angular/core";
import { Cart } from "./cart";

@Component({
  selector: "app-product-list",
  template: `
    <button (click)="cart.add({ name: 'كتاب', price: 40 })">أضف كتاباً</button>
    <button (click)="cart.add({ name: 'قلم', price: 5 })">أضف قلماً</button>
  `,
})
export class ProductList {
  cart = inject(Cart);
}
// file: src/app/cart-badge.ts
import { Component, inject } from "@angular/core";
import { Cart } from "./cart";

@Component({
  selector: "app-cart-badge",
  template: `<p>🛒 {{ cart.list().length }} عناصر - {{ cart.total() }} ر.س</p>`,
})
export class CartBadge {
  cart = inject(Cart);
}
// file: src/app/app.ts
import { Component } from "@angular/core";
import { ProductList } from "./product-list";
import { CartBadge } from "./cart-badge";

@Component({
  selector: "app-root",
  imports: [ProductList, CartBadge],
  template: `<app-cart-badge /><app-product-list />`,
```

## حقن الاعتماديات (Dependency Injection)

لم نكتب `new Cart()` أبداً. بل **طلبنا** الخدمة بـ `inject(Cart)` وAngular هو من ينشئها ويسلّمها. هذا هو **حقن الاعتماديات**، من أهم أفكار Angular:

- `providedIn: "root"` تعني: نسخة واحدة للتطبيق كله (Singleton)، تُنشأ عند أول طلب.
- كل من يطلب `Cart` يحصل على النسخة نفسها، لذلك تصلح الخدمة لمشاركة الحالة.
- في الاختبارات يمكن استبدال الخدمة الحقيقية بنسخة وهمية بسهولة.

> 💡 قد ترى الصيغة الأقدم بالمُنشئ: `constructor(private cart: Cart) {}`. تعمل أيضاً، لكن `inject()` هي الأحدث والأكثر مرونة.

## مزوّدون على مستوى المكون

إذا أردت نسخة **خاصة** بكل مكون بدلاً من نسخة مشتركة، أضف الخدمة في `providers` المكون:

```angular
// file: src/app/counter-store.ts
import { Injectable, signal } from "@angular/core";

@Injectable()
export class CounterStore {
  value = signal(0);
}
// file: src/app/counter.ts
import { Component, inject } from "@angular/core";
import { CounterStore } from "./counter-store";

@Component({
  selector: "app-counter",
  providers: [CounterStore],
  template: `<button (click)="store.value.update(v => v + 1)">{{ store.value() }}</button>`,
})
export class Counter {
  store = inject(CounterStore);
}
// file: src/app/app.ts
import { Component } from "@angular/core";
import { Counter } from "./counter";

@Component({
  selector: "app-root",
  imports: [Counter],
  template: `<app-counter /><app-counter />`,
})
export class App {}
// test
await click("app-counter:nth-of-type(1) button"); await click("app-counter:nth-of-type(1) button");
print(texts("button").join(" | "));
```

## رموز الحقن: InjectionToken

لحقن قيم ليست أصنافاً (مثل إعدادات أو رابط API) استخدم `InjectionToken`، وزوّد قيمته في `app.config.ts`:

```angular
// file: src/app/tokens.ts
import { InjectionToken } from "@angular/core";
```

## ملخص الدرس

- الخدمة صنف عليه `@Injectable` يحمل المنطق والحالة المشتركة.
- `inject(Service)` يطلب الخدمة، وAngular ينشئها (حقن الاعتماديات).
- `providedIn: "root"`: نسخة واحدة للتطبيق، و `providers: []` في المكون: نسخة لكل مكون.
- `InjectionToken` لحقن القيم، و `app.config.ts` مكان المزوّدين العامّين.

## دورة حياة المكون

يمر كل مكون بمراحل: يُنشأ، تصله المدخلات، يُعرض، ثم يُزال. Angular يتيح لك التدخل في كل مرحلة بدوال **الخطافات (Lifecycle Hooks)**:

| الخطاف | متى يُستدعى |
|---|---|
| `constructor` | عند إنشاء الصنف (لا تضع فيه منطقاً ثقيلاً) |
| `ngOnInit` | مرة واحدة بعد وصول المدخلات الأولى: مكان التحميل والتهيئة |
| `ngOnChanges` | عند تغير مدخل بـ `@Input` القديمة |
| `ngAfterViewInit` | بعد عرض القالب (العناصر موجودة في DOM) |
| `ngOnDestroy` | قبل إزالة المكون: مكان التنظيف |

```angular
// file: src/app/timer.ts
import { Component, OnInit, OnDestroy, signal } from "@angular/core";

@Component({
  selector: "app-timer",
  template: `<p class="timer">العدّاد: {{ seconds() }}</p>`,
})
export class Timer implements OnInit, OnDestroy {
  seconds = signal(0);
  private id?: ReturnType<typeof setInterval>;

  ngOnInit() {
    console.log("بدأ المؤقت");
    this.id = setInterval(() => this.seconds.update((s) => s + 1), 100);
  }

  ngOnDestroy() {
    clearInterval(this.id);
    console.log("أُوقف المؤقت");
  }
}
// file: src/app/app.ts
import { Component, signal } from "@angular/core";
import { Timer } from "./timer";

@Component({
  selector: "app-root",
  imports: [Timer],
  template: `
    <button (click)="show.set(!show())">إظهار/إخفاء</button>
    @if (show()) { <app-timer /> }
  `,
})
export class App {
  show = signal(true);
}
// test
await wait(350);
print(text(".timer"));
await click("button");
print("موجود:", exists(".timer"));
```

```output
العدّاد: 4
موجود: false
```

> ⚠️ لو نسيت `clearInterval` في `ngOnDestroy` لظل المؤقت يعمل في الخلفية بعد إخفاء المكون: **تسرّب ذاكرة**. نظّف دائماً ما بدأته.

(المؤقت هنا كل 100 جزء من الثانية بدلاً من ثانية كاملة، ليكون المثال سريعاً.)

## effect: الاستجابة لتغير الإشارات

`effect` تنفّذ دالة كلما تغيرت إشارة تقرؤها. مناسبة للآثار الجانبية: تغيير عنوان الصفحة، الحفظ في `localStorage`، المزامنة مع مكتبة خارجية:

```angular
// file: src/app/app.ts
import { Component, signal, effect } from "@angular/core";

@Component({
  selector: "app-root",
  template: `
    <button (click)="dark.set(!dark())">تبديل الوضع</button>
    <p>الوضع: {{ dark() ? "داكن" : "فاتح" }}</p>
  `,
})
export class App {
  dark = signal(false);

  constructor() {
    effect(() => {
      document.title = this.dark() ? "CodeWay 🌙" : "CodeWay ☀️";
    });
  }
}
// test
await click("button");
print(text("p"), "| عنوان الصفحة:", document.title);
await click("button");
print(text("p"), "| عنوان الصفحة:", document.title);
```

```output
الوضع: داكن | عنوان الصفحة: CodeWay 🌙
الوضع: فاتح | عنوان الصفحة: CodeWay ☀️
```

- `effect` تُنشأ داخل `constructor` (أو عند تعريف الخاصية) لأنها تحتاج سياق الحقن.
- تتتبع تلقائياً الإشارات التي تقرؤها، وتُنظَّف وحدها عند إزالة المكون.

> 💡 لا تستخدم `effect` لحساب قيمة من أخرى: هذا عمل `computed`. القاعدة: **computed للقيم، effect للآثار الجانبية.**

## الوصول إلى عناصر القالب: viewChild

أحياناً تحتاج عنصر DOM مباشرة (مثل وضع المؤشر في حقل). علّم العنصر بـ `#اسم` واقرأه بـ `viewChild`:

```angular
// file: src/app/app.ts
import { Component, viewChild, ElementRef, AfterViewInit } from "@angular/core";

@Component({
  selector: "app-root",
  template: `<input #search placeholder="ابحث..." /><p>{{ info }}</p>`,
})
export class App implements AfterViewInit {
  search = viewChild.required<ElementRef<HTMLInputElement>>("search");
  info = "";

  ngAfterViewInit() {
    this.search().nativeElement.focus();
  }
}
// test
print("المؤشر في الحقل:", document.activeElement === $("input"));
```

```output
المؤشر في الحقل: true
```

`#search` يسمى **متغير القالب**، ويمكن استخدامه في القالب نفسه أيضاً: `(click)="search.focus()"`.

## ملخص الدرس

- `ngOnInit` للتهيئة والتحميل، و `ngOnDestroy` للتنظيف (المؤقتات، الاشتراكات).
- `ngAfterViewInit` حين تحتاج عناصر القالب.
- `effect` للآثار الجانبية عند تغير الإشارات، و `computed` للقيم المشتقة.
- `#ref` مع `viewChild` للوصول إلى عنصر في القالب.

~~~solution
// file: src/app/stopwatch.ts
import { Component, OnDestroy, signal } from "@angular/core";

@Component({
  selector: "app-stopwatch",
  template: `
    <p class="ticks">{{ ticks() }}</p>
    <button class="start" (click)="start()">ابدأ</button>
    <button class="stop" (click)="stop()">أوقف</button>
  `,
})
export class Stopwatch implements OnDestroy {
  ticks = signal(0);
  private id: ReturnType<typeof setInterval> | null = null;

  start() {
    if (this.id) return;
    this.id = setInterval(() => this.ticks.update((t) => t + 1), 50);
  }

  stop() {
    if (this.id) clearInterval(this.id);
    this.id = null;
  }

  ngOnDestroy() {
    this.stop();
  }
}
// file: src/app/app.ts
import { Component, signal } from "@angular/core";
import { Stopwatch } from "./stopwatch";

@Component({
  selector: "app-root",
  imports: [Stopwatch],
  template: `
    <button class="toggle" (click)="visible.set(!visible())">إظهار/إخفاء</button>
    @if (visible()) { <app-stopwatch /> }
  `,
})
export class App {
  visible = signal(true);
}
~~~

## الأنابيب (Pipes)

**الأنبوب** يحوّل القيمة عند عرضها في القالب دون تغيير البيانات الأصلية. يُكتب بالرمز `|`:

```angular
// file: src/app/app.ts
import { Component } from "@angular/core";
import { UpperCasePipe, DecimalPipe, CurrencyPipe, PercentPipe, DatePipe, JsonPipe, SlicePipe } from "@angular/common";

@Component({
  selector: "app-root",
  imports: [UpperCasePipe, DecimalPipe, CurrencyPipe, PercentPipe, DatePipe, JsonPipe, SlicePipe],
  template: `
    <p>{{ name | uppercase }}</p>
    <p>{{ pi | number: "1.2-2" }}</p>
    <p>{{ price | currency: "SAR" }}</p>
    <p>{{ ratio | percent }}</p>
    <p>{{ date | date: "yyyy/MM/dd" }}</p>
    <p>{{ tags | slice: 0 : 2 | json }}</p>
  `,
})
export class App {
  name = "angular";
  pi = 3.14159;
  price = 1499.5;
  ratio = 0.85;
  date = new Date(2025, 2, 15);
  tags = ["ts", "rxjs", "signals"];
}
// test
texts("p").forEach(t => print(t));
```

```output
ANGULAR
3.14
SAR1,499.50
85%
2025/03/15
[ "ts", "rxjs" ]
```

| الأنبوب | المثال | الوظيفة |
|---|---|---|
| `uppercase` / `lowercase` / `titlecase` | `name \| uppercase` | حالة الأحرف |
| `number` | `x \| number: "1.2-2"` | أرقام صحيحة دنيا.أعشار دنيا-عليا |
| `currency` | `p \| currency: "SAR"` | عملة |
| `percent` | `r \| percent` | نسبة مئوية |
| `date` | `d \| date: "yyyy/MM/dd"` | تاريخ بصيغة |
| `slice` | `list \| slice: 0 : 2` | جزء من نص أو مصفوفة |
| `json` | `obj \| json` | للتصحيح: عرض كائن |

- الأنابيب تُستورد في `imports` المكون مثل المكونات.
- يمكن **تسلسل** الأنابيب: `tags | slice: 0 : 2 | json`.
- المعاملات بعد `:`.

```angular
import { Pipe, PipeTransform } from "@angular/core";

@Pipe({ name: "truncate" })

}
```

> 💡 الأنابيب **نقية** افتراضياً: Angular لا يعيد استدعاء `transform` إلا إذا تغيرت المدخلات، فهي سريعة جداً. لذلك تُفضَّل على استدعاء دوال في القالب مثل `{{ format(text) }}` التي تُنفَّذ مع كل تحديث.

## ملخص الدرس

- `{{ value | pipe: arg }}` يحوّل القيمة عند العرض فقط.
- أهم الأنابيب الجاهزة: `uppercase` و `number` و `currency` و `percent` و `date` و `slice` و `json`.
- استورد الأنبوب في `imports` المكون.
- أنبوبك الخاص: صنف بـ `@Pipe({ name })` ودالة `transform(value, ...args)`.

--- exercise
1. أنشئ في `src/app/file-size.pipe.ts` أنبوباً `FileSizePipe` باسم `fileSize` يحوّل عدد البايتات إلى نص:
   - أقل من 1024: `X B`
   - أقل من 1024 × 1024: `X KB` بخانة عشرية واحدة
   - غير ذلك: `X MB` بخانة عشرية واحدة
   (استخدم `toFixed(1)`)
2. في `App` اعرض كل ملف من `files` في `li` بالصيغة: `الاسم بأحرف كبيرة (الحجم)` باستخدام `uppercase` و `fileSize`.

~~~starter

// file: src/app/app.ts

@Component({
  selector: "app-root",
  imports: [UpperCasePipe],

})
~~~

~~~solution
// file: src/app/file-size.pipe.ts
import { Pipe, PipeTransform } from "@angular/core";

@Pipe({ name: "fileSize" })
export class FileSizePipe implements PipeTransform {
  transform(bytes: number): string {
    if (bytes < 1024) return `${bytes} B`;
    if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`;
    return `${(bytes / (1024 * 1024)).toFixed(1)} MB`;
  }
}
// file: src/app/app.ts
import { Component } from "@angular/core";
import { UpperCasePipe } from "@angular/common";
import { FileSizePipe } from "./file-size.pipe";

@Component({
  selector: "app-root",
  imports: [UpperCasePipe, FileSizePipe],
  template: `
    <ul>
      @for (f of files; track f.name) {
        <li>{{ f.name | uppercase }} ({{ f.size | fileSize }})</li>
      }
    </ul>
  `,
})
export class App {
  files = [
    { name: "notes.txt", size: 512 },
    { name: "photo.png", size: 2560 },
    { name: "video.mp4", size: 5452595 },
  ];
}
~~~
