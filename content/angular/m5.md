## النماذج في Angular

Angular يقدم طريقتين لبناء النماذج:

| | نماذج القوالب (Template-driven) | النماذج التفاعلية (Reactive) |
|---|---|---|
| الوحدة | `FormsModule` | `ReactiveFormsModule` |
| أين المنطق | في القالب بـ `ngModel` | في الصنف بـ `FormGroup` |
| مناسبة لـ | النماذج البسيطة | النماذج الكبيرة والمعقدة والقابلة للاختبار |

نبدأ بنماذج القوالب.

## نموذج بالقالب

```angular
// file: src/app/app.ts
import { Component } from "@angular/core";
import { FormsModule, NgForm } from "@angular/forms";

@Component({
  selector: "app-root",
  imports: [FormsModule],
  template: `
    <form #f="ngForm" (ngSubmit)="save(f)">
      <input name="name" [(ngModel)]="user.name" required minlength="3" #name="ngModel" placeholder="الاسم" />
      @if (name.invalid && name.touched) {
        @if (name.errors?.["required"]) { <small>الاسم مطلوب</small> }
        @if (name.errors?.["minlength"]) { <small>3 أحرف على الأقل</small> }
      }

      <input name="email" type="email" [(ngModel)]="user.email" required email placeholder="البريد" />

      <button [disabled]="f.invalid">إرسال</button>
    </form>
    <p>{{ message }}</p>
  `,
})
export class App {
  user = { name: "", email: "" };
  message = "";

  save(form: NgForm) {
    this.message = `تم تسجيل ${form.value.name} (${form.value.email})`;
    form.resetForm();
  }
}
// test
print("الزر معطل:", $("button").disabled);
await type("input[name=name]", "عل"); $("input[name=name]").dispatchEvent(new Event("blur")); await settle();
print(texts("small").join(" | "));
await type("input[name=name]", "علي");
await type("input[name=email]", "ali@codeway.dev");
print("الزر معطل:", $("button").disabled, "| أخطاء:", count("small"));
await submit();
print(text("p"), "| الحقل بعد الإرسال:", JSON.stringify(value("input[name=name]")));
```

```output
الزر معطل: true
3 أحرف على الأقل
الزر معطل: false | أخطاء: 0
تم تسجيل علي (ali@codeway.dev) | الحقل بعد الإرسال: ""
```

- كل حقل مع `ngModel` يحتاج **`name`**: به يُسجَّل في النموذج.
- `#f="ngForm"` متغير قالب يمثّل النموذج كله: `f.valid` و `f.invalid` و `f.value`.
- `#name="ngModel"` يمثّل حقلاً واحداً: `invalid` و `touched` (لمسه المستخدم ثم غادره) و `dirty` (غيّر قيمته) و `errors`.
- خصائص HTML مثل `required` و `minlength` و `email` تصبح **مدققات** Angular.
- `(ngSubmit)` بدلاً من `(submit)`: يمنع إعادة تحميل الصفحة تلقائياً.

## أصناف الحالة التلقائية

Angular يضيف أصنافاً CSS لكل حقل حسب حالته: `ng-valid` / `ng-invalid` و `ng-touched` / `ng-untouched` و `ng-dirty` / `ng-pristine`. فيمكنك تنسيق الأخطاء دون كود:

```css
input.ng-invalid.ng-touched {
  border: 2px solid crimson;
}
```

## ملخص الدرس

- نماذج القوالب: `FormsModule` و `[(ngModel)]` مع `name` لكل حقل.
- `#f="ngForm"` للنموذج و `#x="ngModel"` للحقل، مع `valid` و `touched` و `errors`.
- المدققات: `required` و `minlength` و `maxlength` و `email` و `pattern`.
- `(ngSubmit)` للإرسال، و `resetForm()` للتفريغ.

## النماذج التفاعلية (Reactive Forms)

في النماذج التفاعلية تعرّف النموذج كاملاً **في الصنف**: الحقول وقيمها الأولية ومدققاتها، والقالب يربط العناصر فقط. هذا يجعل النموذج سهل الاختبار والتوسيع، وهو الأكثر استخداماً في التطبيقات الكبيرة.

```angular
// file: src/app/app.ts
import { Component, inject, signal } from "@angular/core";
import { ReactiveFormsModule, FormBuilder, Validators } from "@angular/forms";

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form" (ngSubmit)="save()">
      <input formControlName="title" placeholder="عنوان الدورة" />
      @if (form.controls.title.hasError("required") && form.controls.title.touched) {
        <small>العنوان مطلوب</small>
      }

      <input formControlName="price" type="number" />
      @if (form.controls.price.hasError("min")) { <small>السعر لا يقل عن 0</small> }

      <select formControlName="level">
        <option value="beginner">مبتدئ</option>
        <option value="advanced">متقدم</option>
      </select>

      <button [disabled]="form.invalid">حفظ</button>
    </form>
    <p>{{ saved() }}</p>
  `,
})
export class App {
  private fb = inject(FormBuilder);
  saved = signal("");

  form = this.fb.nonNullable.group({
    title: ["", Validators.required],
    price: [0, [Validators.required, Validators.min(0)]],
    level: ["beginner"],
  });

  save() {
    const { title, price, level } = this.form.getRawValue();
    this.saved.set(`حُفظت: ${title} بسعر ${price} (${level})`);
    this.form.reset();
  }
}
// test
await type("input[type=number]", "-5");
print("معطل:", $("button").disabled, "|", texts("small").join(" | "));
await type("input[formcontrolname=title]", "Angular من الصفر");
await type("input[type=number]", "199");
await select("select", "advanced");
print("معطل:", $("button").disabled);
await submit();
print(text("p"));
print("بعد reset:", JSON.stringify(inject(use("@angular/core").ApplicationRef).components[0].instance.form.getRawValue()));
```

```output
معطل: true | السعر لا يقل عن 0
معطل: false
حُفظت: Angular من الصفر بسعر 199 (advanced)
بعد reset: {"title":"","price":0,"level":"beginner"}
```

- `FormBuilder` يختصر الإنشاء: كل حقل `[قيمة أولية, مدققات]`.
- `nonNullable` يجعل `reset()` يعيد القيم **الأولية** بدلاً من `null`، والأنواع أدق.
- `[formGroup]` يربط النموذج، و `formControlName` يربط كل حقل باسمه.
- `form.controls.title.hasError("required")` للتحقق من خطأ معين.
- `getRawValue()` قيم كل الحقول (حتى المعطلة)، مع أنواعها في TypeScript.

### المدققات الجاهزة

| المدقق | الشرط |
|---|---|
| `Validators.required` | ليس فارغاً |
| `Validators.minLength(n)` / `maxLength(n)` | طول النص |
| `Validators.min(n)` / `max(n)` | قيمة الرقم |
| `Validators.email` | صيغة بريد |
| `Validators.pattern(/^05\d{8}$/)` | تعبير نمطي |

## الاستماع للتغييرات: valueChanges

كل حقل وكل نموذج له `valueChanges`: **Observable** يُصدر القيمة عند كل تغيير. فتستخدم معه كل ما تعلمته من RxJS:

```angular
// file: src/app/app.ts
import { Component, signal } from "@angular/core";
import { ReactiveFormsModule, FormControl } from "@angular/forms";
import { toSignal } from "@angular/core/rxjs-interop";
import { map } from "rxjs/operators";

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <input [formControl]="password" type="password" placeholder="كلمة المرور" />
    <p>القوة: {{ strength() }}</p>
  `,
})
export class App {
  password = new FormControl("", { nonNullable: true });

  strength = toSignal(
    this.password.valueChanges.pipe(
      map((v) => {
        const score = [/.{8,}/, /[A-Z]/, /\d/, /[^A-Za-z0-9]/].filter((r) => r.test(v)).length;
        return ["ضعيفة جداً", "ضعيفة", "متوسطة", "جيدة", "قوية"][score];
      }),
    ),
    { initialValue: "—" },
  );
}
// test
for (const v of ["abc", "abcdefgh", "Abcdefgh1", "Abcdefgh1!"]) { await type("input", v); print(v, "→", text("p")); }
```

```output
abc → القوة: ضعيفة جداً
abcdefgh → القوة: ضعيفة
Abcdefgh1 → القوة: جيدة
Abcdefgh1! → القوة: قوية
```

`FormControl` منفرد يُربط بـ `[formControl]` دون `FormGroup`، مناسب لحقل بحث أو حقل وحيد.

## ملخص الدرس

- `ReactiveFormsModule` و `FormBuilder.nonNullable.group({...})` لتعريف النموذج في الصنف.
- `[formGroup]` و `formControlName` و `[formControl]` للربط في القالب.
- `Validators` للمدققات، و `hasError` و `touched` لعرض الأخطاء.
- `valueChanges` يحوّل التغييرات إلى Observable.

~~~solution
// file: src/app/app.ts
import { Component, inject, signal } from "@angular/core";
import { ReactiveFormsModule, FormBuilder, Validators } from "@angular/forms";

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form" (ngSubmit)="register()">
      <input formControlName="username" />
      <input formControlName="email" />
      @if (form.controls.email.hasError("email")) {
        <small class="email-error">صيغة البريد غير صحيحة</small>
      }
      <input formControlName="age" type="number" />
      <button [disabled]="form.invalid">تسجيل</button>
    </form>
    @if (result()) { <p class="result">{{ result() }}</p> }
  `,
})
export class App {
  private fb = inject(FormBuilder);
  result = signal("");

  form = this.fb.nonNullable.group({
    username: ["", [Validators.required, Validators.minLength(3)]],
    email: ["", [Validators.required, Validators.email]],
    age: [18, Validators.min(13)],
  });

  register() {
    const { username, age } = this.form.getRawValue();
    this.result.set(`مرحباً ${username}، عمرك ${age}`);
    this.form.reset();
  }
}
~~~

## مدققات مخصصة

المدققات الجاهزة لا تغطي كل شيء. **المدقق** مجرد دالة تأخذ الحقل وتُرجع `null` إذا كان صالحاً، أو كائن خطأ إذا لم يكن:

```angular
// file: src/app/validators.ts
import { AbstractControl, ValidationErrors, ValidatorFn } from "@angular/forms";

export function saudiPhone(control: AbstractControl): ValidationErrors | null {
  const ok = /^05\d{8}$/.test(control.value || "");
  return ok ? null : { saudiPhone: true };
}

export function forbiddenWord(word: string): ValidatorFn {
  return (control) =>
    String(control.value || "").includes(word) ? { forbiddenWord: { word } } : null;
}
// file: src/app/app.ts
import { Component, inject } from "@angular/core";
import { ReactiveFormsModule, FormBuilder, Validators } from "@angular/forms";
import { saudiPhone, forbiddenWord } from "./validators";

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form">
      <input formControlName="phone" placeholder="05xxxxxxxx" />
      @if (form.controls.phone.hasError("saudiPhone")) { <small>رقم جوال سعودي غير صحيح</small> }
      <input formControlName="nickname" />
      @if (form.controls.nickname.getError("forbiddenWord"); as e) { <small>كلمة "{{ e.word }}" غير مسموحة</small> }
    </form>
  `,
})
export class App {
  form = inject(FormBuilder).nonNullable.group({
    phone: ["", [Validators.required, saudiPhone]],
    nickname: ["", forbiddenWord("admin")],
  });
}
// test
await type("[formcontrolname=phone]", "0612345678");
await type("[formcontrolname=nickname]", "super_admin");
texts("small").forEach(t => print(t));
await type("[formcontrolname=phone]", "0551234567");
await type("[formcontrolname=nickname]", "layan");
print("أخطاء:", count("small"));
```

```output
رقم جوال سعودي غير صحيح
كلمة "admin" غير مسموحة
أخطاء: 0
```

- `saudiPhone` مدقق مباشر يُمرَّر كما هو.
- `forbiddenWord("admin")` **مصنع مدققات**: دالة تأخذ إعداداً وتُرجع مدققاً، مثل `Validators.minLength(3)`.
- كائن الخطأ يمكن أن يحمل تفاصيل (`{ word }`) تقرؤها بـ `getError`.

## مدقق على مستوى المجموعة

بعض الشروط تخص **حقلين معاً**، مثل تطابق كلمتي المرور. نضع المدقق على `FormGroup` نفسها:

```angular
// file: src/app/app.ts
import { Component, inject } from "@angular/core";
import { ReactiveFormsModule, FormBuilder, Validators, ValidatorFn } from "@angular/forms";

const passwordsMatch: ValidatorFn = (group) => {
  const { password, confirm } = group.value;
  return password === confirm ? null : { mismatch: true };
};

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form">
      <input type="password" formControlName="password" />
      <input type="password" formControlName="confirm" />
      @if (form.hasError("mismatch")) { <small>كلمتا المرور غير متطابقتين</small> }
      <button [disabled]="form.invalid">إنشاء</button>
    </form>
  `,
})
export class App {
  form = inject(FormBuilder).nonNullable.group(
    {
      password: ["", [Validators.required, Validators.minLength(6)]],
      confirm: [""],
    },
    { validators: passwordsMatch },
  );
}
// test
await type("[formcontrolname=password]", "secret123");
await type("[formcontrolname=confirm]", "secret12");
print(text("small"), "| معطل:", $("button").disabled);
await type("[formcontrolname=confirm]", "secret123");
print("خطأ:", exists("small"), "| معطل:", $("button").disabled);
```

```output
كلمتا المرور غير متطابقتين | معطل: true
خطأ: false | معطل: false
```

## قوائم ديناميكية: FormArray

عندما يضيف المستخدم عدداً غير معروف من الحقول (مهارات، أرقام هواتف، عناصر فاتورة) استخدم `FormArray`:

```angular
// file: src/app/app.ts
import { Component, inject } from "@angular/core";
import { ReactiveFormsModule, FormBuilder, Validators } from "@angular/forms";

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form">
      <div formArrayName="skills">
        @for (c of skills.controls; track c; let i = $index) {
          <p><input [formControlName]="i" /> <button type="button" (click)="skills.removeAt(i)">✕</button></p>
        }
      </div>
      <button type="button" class="add" (click)="add()">+ مهارة</button>
    </form>
    <pre>{{ skills.length }} مهارات: {{ skills.value.join("، ") }}</pre>
  `,
})
```

## ملخص الدرس

- المدقق دالة تُرجع `null` أو كائن خطأ، و مصنع المدققات دالة تُرجع مدققاً.
- مدقق المجموعة `{ validators: fn }` للشروط بين أكثر من حقل.
- `FormArray` مع `formArrayName` و `[formControlName]="i"` للحقول الديناميكية، و `push` و `removeAt` للتعديل.

~~~solution
// file: src/app/validators.ts
import { AbstractControl, ValidationErrors } from "@angular/forms";

export function positive(control: AbstractControl): ValidationErrors | null {
  return Number(control.value) > 0 ? null : { positive: true };
}
// file: src/app/app.ts
import { Component, inject } from "@angular/core";
import { ReactiveFormsModule, FormBuilder } from "@angular/forms";
import { positive } from "./validators";

@Component({
  selector: "app-root",
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form">
      <div formArrayName="items">
        @for (c of items.controls; track c; let i = $index) {
          <input type="number" [formControlName]="i" />
        }
      </div>
    </form>
    <button class="add" (click)="add()">+ بند</button>
    <p class="total">المجموع: {{ total() }}</p>
    <p class="status">{{ invalidCount() === 0 ? "الفاتورة صالحة" : "يوجد " + invalidCount() + " بنود غير صالحة" }}</p>
  `,
})
export class App {
  private fb = inject(FormBuilder);
  form = this.fb.nonNullable.group({
    items: this.fb.nonNullable.array([this.fb.nonNullable.control(100, positive)]),
  });

  get items() {
    return this.form.controls.items;
  }

  add() {
    this.items.push(this.fb.nonNullable.control(0, positive));
  }

  total() {
    return this.items.value.reduce((s, v) => s + Number(v), 0);
  }

  invalidCount() {
    return this.items.controls.filter((c) => c.hasError("positive")).length;
  }
}
~~~

? ماذا يُرجع المدقق المخصص عندما تكون القيمة صالحة؟
+ `null`
- `true`
- `{ valid: true }`
> أي كائن يُعتبر خطأ، و null يعني لا أخطاء.

? كيف تتحقق من تطابق كلمتي المرور؟
+ بمدقق على مستوى FormGroup يقارن الحقلين
- بمدقق required على الحقلين
- بـ Validators.pattern
> مدقق الحقل الواحد لا يرى الحقول الأخرى بسهولة.

? متى تستخدم `FormArray`؟
+ عندما يكون عدد الحقول ديناميكياً يضيفه المستخدم ويحذفه
- لكل نموذج فيه أكثر من حقل
- للقوائم المنسدلة
> مثل المهارات أو بنود الفاتورة.
