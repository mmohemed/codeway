=== lesson
## العمليات التي تأخذ وقتاً

تطبيقات Flutter تجلب البيانات من الإنترنت، وتقرأ الملفات، وتنتظر استجابة قواعد البيانات. لو انتظر التطبيق كل عملية وهو متجمد، لتوقفت الواجهة. لذلك تستخدم Dart **البرمجة غير المتزامنة**، وأساسها `Future`.

## ما هو Future؟

`Future<T>` يمثل **قيمة من نوع T ستتوفر في المستقبل**، مثل إيصال طلب في مطعم: ليس الوجبة، لكنه وعد بها.

```dart
Future<String> fetchUsername() {
  return Future.delayed(Duration(milliseconds: 300), () => 'غادة');
}

void main() {
  print('1. أرسلت الطلب');
  fetchUsername().then((name) => print('3. وصل الاسم: $name'));
  print('2. التطبيق مستمر ولا ينتظر');
}
```

```output
1. أرسلت الطلب
2. التطبيق مستمر ولا ينتظر
3. وصل الاسم: غادة
```

- `Future.delayed` تحاكي عملية تأخذ وقتاً، كطلب شبكة.
- `then` تسجّل دالة تُنفَّذ عندما يكتمل الـ Future.
- لاحظ الترتيب: السطر 2 طُبع قبل 3، لأن البرنامج لم ينتظر.

## حالات Future

| الحالة | المعنى |
|---|---|
| غير مكتمل | العملية ما زالت تعمل |
| مكتمل بقيمة | نجحت، والقيمة متاحة |
| مكتمل بخطأ | فشلت |

## معالجة الأخطاء

```dart
Future<double> getPrice(String item) {
  return Future.delayed(Duration(milliseconds: 100), () {
    if (item == 'ذهب') return 250.5;
    throw Exception('المنتج غير موجود');
  });
}

void main() {
  getPrice('ذهب')
      .then((p) => print('السعر: $p'))
      .catchError((e) => print('خطأ: $e'));

  getPrice('ألماس')
      .then((p) => print('السعر: $p'))
      .catchError((e) => print('خطأ: $e'))
      .whenComplete(() => print('انتهى البحث'));
}
```

```output
السعر: 250.5
خطأ: Exception: المنتج غير موجود
انتهى البحث
```

- `throw Exception(...)` داخل الـ Future يجعله يكتمل بخطأ.
- `catchError` تلتقط الخطأ، و `whenComplete` تُنفَّذ دائماً.

## تشغيل عدة Futures معاً

```dart
Future<String> load(String name, int ms) =>
    Future.delayed(Duration(milliseconds: ms), () => name);

void main() {
  Future.wait([
    load('الملف الشخصي', 300),
    load('الإشعارات', 100),
    load('الرسائل', 200),
  ]).then((results) => print(results));
}
```

```output
[الملف الشخصي, الإشعارات, الرسائل]
```

`Future.wait` تنتظر **كلها** معاً بالتوازي، وتُرجع النتائج بنفس الترتيب، فاستغرقت 300 ملي ثانية بدلاً من 600.

## ملخص الدرس

- `Future<T>` قيمة ستتوفر لاحقاً، والبرنامج لا يتوقف لانتظارها.
- `then` للنتيجة، و `catchError` للخطأ، و `whenComplete` تُنفَّذ دائماً.
- `Future.delayed` لمحاكاة التأخير، و `Future.wait` لتشغيل عدة عمليات بالتوازي.

اكتب دالة `checkStock(String item)` تُرجع `Future<int>`:

- بعد 100 ملي ثانية، تُرجع الكمية من الخريطة `stock` إذا كان المنتج موجوداً.

}

      .then((qty) => print('قلم: $qty'))
      .whenComplete(() {

const stock = {'قلم': 12, 'دفتر': 3};

Future<int> checkStock(String item) {
  return Future.delayed(Duration(milliseconds: 100), () {
    final qty = stock[item];
    if (qty == null) throw Exception('$item غير متوفر');
    return qty;
  });
}

void main() {
  checkStock('قلم')
      .then((qty) => print('قلم: $qty'))
      .whenComplete(() {
    checkStock('حقيبة')
        .then((qty) => print('حقيبة: $qty'))
        .catchError((e) => print('خطأ: $e'));
  });
}
~~~

## كتابة الكود غير المتزامن بشكل طبيعي

سلاسل `then` تصبح معقدة مع كثرة الخطوات. `async` و `await` تجعل الكود **يُقرأ من الأعلى للأسفل** كأنه متزامن، وهي الطريقة المستخدمة في كل تطبيقات Flutter الحديثة.

```dart
Future<String> getUser() => Future.delayed(Duration(milliseconds: 100), () => 'ماجد');
Future<int> getOrders(String user) => Future.delayed(Duration(milliseconds: 100), () => 4);

Future<void> showProfile() async {
  print('جاري التحميل...');
  final user = await getUser();
  final orders = await getOrders(user);
  print('$user لديه $orders طلبات');
}

void main() async {
  await showProfile();
  print('تم');
}
```

```output
جاري التحميل...
ماجد لديه 4 طلبات
تم
```

## القواعد

1. `async` بعد أقواس الدالة تجعلها غير متزامنة، **وتُرجع Future دائماً**.
2. `await` تنتظر الـ Future وتعطيك قيمته مباشرة.
3. `await` لا تُستخدم إلا داخل دالة `async`.
4. الدالة التي لا تُرجع قيمة نوعها `Future<void>`.

## الأخطاء بـ try و catch

```dart
Future<String> login(String password) async {
  await Future.delayed(Duration(milliseconds: 100));
  if (password != '1234') {
    throw Exception('كلمة المرور خاطئة');
  }
  return 'مرحباً بك';
}

Future<void> attempt(String pass) async {
  try {
    final msg = await login(pass);
    print(msg);
  } on Exception catch (e) {
    print('فشل: $e');
  } finally {
    print('--');
  }
}

void main() async {
  await attempt('0000');
  await attempt('1234');
}
```

```output
فشل: Exception: كلمة المرور خاطئة
--
مرحباً بك
--
```

- `on Exception catch (e)` يلتقط نوعاً محدداً من الأخطاء.
- `finally` تُنفَّذ دائماً، وهي مكان إخفاء مؤشر التحميل.

## التوازي مع async

```dart
Future<int> task(int ms) => Future.delayed(Duration(milliseconds: ms), () => ms);

void main() async {
  final watch = Stopwatch()..start();
  final results = await Future.wait([task(200), task(200), task(200)]);
  final fast = watch.elapsedMilliseconds < 500;
  print('$results ${fast ? 'بالتوازي' : 'بالتتابع'}');
}
```

```output
[200, 200, 200] بالتوازي
```

> 💡 لا تكتب `await` متتالية لعمليات **مستقلة** عن بعضها. استخدم `Future.wait` لتعمل معاً.

## ملخص الدرس

- `async` تجعل الدالة تُرجع Future، و `await` تنتظر القيمة.
- `try` و `catch` و `finally` لمعالجة الأخطاء بأسلوب مألوف.

- `Future.wait` مع `await` للعمليات المستقلة.

## تدفق من القيم

`Future` يعطيك **قيمة واحدة** في المستقبل. لكن ماذا عن بيانات تصل **باستمرار**: رسائل الدردشة، وموقع GPS، ونتائج البحث أثناء الكتابة، وتحديثات الأسعار؟ هنا نستخدم **Stream**: تدفق من القيم عبر الزمن.

| | Future | Stream |
|---|---|---|
| عدد القيم | واحدة | عدة قيم متتالية |
| مثال | جلب ملف المستخدم | رسائل دردشة واردة |
| الاستماع | `await` أو `then` | `await for` أو `listen` |

## إنشاء Stream والاستماع له

```dart
Stream<int> countdown(int from) async* {
  for (var i = from; i >= 1; i--) {
    await Future.delayed(Duration(milliseconds: 100));
    yield i;
  }
}

void main() async {
  await for (final n in countdown(3)) {
    print('$n...');
  }
  print('انطلق! 🚀');
}
```

```output
3...
2...
1...
انطلق! 🚀
```

- `async*` تجعل الدالة **مولّدة لتدفق**.
- `yield` ترسل قيمة إلى التدفق دون إنهاء الدالة.
- `await for` تستمع لكل قيمة عند وصولها، حتى ينتهي التدفق.

## listen

طريقة أخرى للاستماع، دون إيقاف الدالة الحالية:

```dart
void main() {
  final stream = Stream.fromIterable(['أهلاً', 'كيف حالك؟', 'إلى اللقاء']);
  stream.listen(
    (msg) => print('رسالة: $msg'),
    onDone: () => print('انتهت المحادثة'),
  );
  print('أستمع للرسائل...');
}
```

```output
أستمع للرسائل...
رسالة: أهلاً
رسالة: كيف حالك؟
رسالة: إلى اللقاء
انتهت المحادثة
```

## تحويل التدفقات

التدفقات تدعم نفس دوال المجموعات تقريباً:

```dart
Stream<int> numbers() async* {
  for (var i = 1; i <= 6; i++) {
    yield i;
  }
}

void main() async {
  final evens = numbers().where((n) => n.isEven).map((n) => n * 10);
  await for (final v in evens) {
    print(v);
  }

  final total = await numbers().reduce((a, b) => a + b);
  print('المجموع: $total');
}
```

```output
20
40
60
المجموع: 21
```

## StreamController: تدفق تتحكم به

في التطبيقات كثيراً ما تصنع تدفقاً وتضيف له القيم يدوياً عند وقوع أحداث:

```dart
import 'dart:async';

void main() async {
  final controller = StreamController<String>();

  controller.stream.listen((event) => print('حدث: $event'));

  controller.add('تسجيل دخول');
  controller.add('إضافة للسلة');
  controller.add('دفع');
  await controller.close();
}
```

```output
حدث: تسجيل دخول
حدث: إضافة للسلة
حدث: دفع
```

> 💡 في Flutter يعرض `StreamBuilder` آخر قيمة من تدفق ويعيد بناء الواجهة مع كل قيمة جديدة، وهو أساس تطبيقات الدردشة مع Firebase.

## خاتمة الدورة

أكملت دورة Dart! أصبحت تعرف:

- الأساسيات والأنواع والأمان من null.
- الدوال بمعاملاتها المسماة والدوال المجهولة.
- البرمجة الكائنية: الأصناف والوراثة والـ mixins والأصناف المجردة والمختومة.
- المجموعات ودوالها.
- البرمجة غير المتزامنة: Future و async/await و Stream.

هذا بالضبط ما تحتاجه لتبدأ **Flutter** بثقة.

## ملخص الدرس

- `Stream` تدفق من عدة قيم عبر الزمن.
- `async*` و `yield` لإنشاء تدفق، و `await for` أو `listen` للاستماع.
- التدفقات تدعم `where` و `map` و `reduce`.
- `StreamController` لإنشاء تدفق تضيف إليه القيم يدوياً.
