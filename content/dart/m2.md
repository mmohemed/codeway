=== lesson
## تعريف الدوال

في Dart نحدد **نوع ما تُرجعه الدالة** قبل اسمها، و**نوع كل معامل**:

```dart
int add(int a, int b) {
  return a + b;
}

String greet(String name) {
  return 'أهلاً يا $name';
}

void printLine() {
  print('----------');
}

void main() {
  print(add(3, 4));
  print(greet('هيا'));
  printLine();
}
```

```output
7
أهلاً يا هيا
----------
```

- `int add(...)` الدالة تُرجع `int`.
- `void` الدالة لا تُرجع شيئاً.
- كتابة الأنواع تجعل المترجم يكتشف الأخطاء: لو استدعيت `add('3', 4)` لظهر خطأ قبل التشغيل.

## الصيغة المختصرة =>

للدوال المكوّنة من تعبير واحد:

```dart
int square(int n) => n * n;
bool isEven(int n) => n % 2 == 0;
String fullName(String first, String last) => '$first $last';

void main() {
  print(square(9));
  print(isEven(7));
  print(fullName('محمد', 'العلي'));
}
```

```output
81
false
محمد العلي
```

`=> تعبير` تعني `{ return تعبير; }`، وستراها في كل مكان في Flutter.

## المعاملات المسماة: أسلوب Flutter

عندما تكثر المعاملات، يصعب تذكر ترتيبها. **المعاملات المسماة** توضع بين `{ }` وتُمرر باسمها:

```dart
void createUser({required String name, int age = 18, String? city}) {
  print('$name، $age سنة، ${city ?? 'مدينة غير محددة'}');
}

void main() {
  createUser(name: 'فيصل', age: 30, city: 'أبها');
  createUser(city: 'جدة', name: 'منيرة');
  createUser(name: 'زياد');
}
```

```output
فيصل، 30 سنة، أبها
منيرة، 18 سنة، جدة
زياد، 18 سنة، مدينة غير محددة
```

- الترتيب لا يهم عند الاستدعاء، وكل قيمة واضحة المعنى.
- `required` تجعل المعامل إلزامياً.
- `age = 18` قيمة افتراضية.
- `String? city` اختياري قد يكون null.

> 💡 هذا هو الأسلوب المستخدم في كل Widgets في Flutter: `Text('مرحبا', style: ..., textAlign: ...)` و `Container(width: 100, color: ...)`.

## المعاملات الموضعية الاختيارية

بين `[ ]`، وتُمرر بالترتيب لكنها اختيارية:

```dart
String introduce(String name, [String? title, int years = 0]) {
  var text = name;
  if (title != null) text = '$title $text';
  if (years > 0) text += ' (خبرة $years سنوات)';
  return text;
}

void main() {
  print(introduce('سعاد'));
  print(introduce('سعاد', 'د.'));
  print(introduce('سعاد', 'د.', 12));
}
```

```output
سعاد
د. سعاد
د. سعاد (خبرة 12 سنوات)
```

| النوع | الصيغة | الاستدعاء |
|---|---|---|
| موضعية إلزامية | `f(int a)` | `f(5)` |
| موضعية اختيارية | `f([int a = 0])` | `f()` أو `f(5)` |
| مسماة | `f({int a = 0})` | `f(a: 5)` |
| مسماة إلزامية | `f({required int a})` | `f(a: 5)` |

## ملخص الدرس

- نوع الإرجاع قبل اسم الدالة، ونوع كل معامل قبل اسمه.
- `=>` اختصار لدالة من تعبير واحد.
- المعاملات المسماة `{ }` تُمرر بالاسم، وتدعم `required` والقيم الافتراضية.
- المعاملات الموضعية الاختيارية بين `[ ]`.

--- exercise
اكتب دالة `calculatePrice` تُرجع `double` وتستقبل **معاملات مسماة**:

- `price` من نوع `double` **إلزامي**
- `discount` نسبة الخصم بالمئة، `int`، افتراضيها `0`
- `tax` نسبة الضريبة بالمئة، `int`، افتراضيها `15`

النتيجة: السعر بعد الخصم، ثم تُضاف الضريبة على الناتج. الاستدعاءات جاهزة.

~~~starter
// اكتب الدالة هنا

void main() {
  print(calculatePrice(price: 100));
  print(calculatePrice(price: 200, discount: 50));
  print(calculatePrice(tax: 0, price: 80, discount: 25));
}
~~~
~~~expected
115
115
60
~~~
~~~solution
double calculatePrice({required double price, int discount = 0, int tax = 15}) {
  final afterDiscount = price * (100 - discount) / 100;
  return afterDiscount * (100 + tax) / 100;
}

void main() {
  print(calculatePrice(price: 100));
  print(calculatePrice(price: 200, discount: 50));
  print(calculatePrice(tax: 0, price: 80, discount: 25));
}
~~~

> void تعني لا يوجد نوع إرجاع.

? كيف تجعل معاملاً مسمى إلزامياً؟

## الدوال قيم

في Dart الدالة **كائن** يمكن تخزينه في متغير وتمريره لدالة أخرى. والدالة بلا اسم تسمى **دالة مجهولة (Anonymous Function)** أو **Lambda**:

```dart
void main() {
  var multiply = (int a, int b) => a * b;
  print(multiply(6, 7));

  var shout = (String text) {
    final upper = text.toUpperCase();
    return '$upper!';
  };
  print(shout('flutter'));
}
```

```output
42
FLUTTER!
```

## تمرير دالة لدالة أخرى

الدالة التي تستقبل دالة أو تُرجعها تسمى **دالة من رتبة عليا (Higher-Order Function)**:

```dart
int applyTwice(int Function(int) fn, int value) {
  return fn(fn(value));
}

void main() {
  print(applyTwice((n) => n + 10, 1));
  print(applyTwice((n) => n * 3, 2));
}
```

```output
21
18
```

`int Function(int)` هو **نوع الدالة**: "دالة تستقبل int وتُرجع int".

## الاستخدام الأشهر: مع القوائم

```dart
void main() {
  var prices = [120, 45, 300, 80];

  prices.forEach((p) => print('السعر: $p'));

  var cheap = prices.where((p) => p < 100).toList();
  print(cheap);
}
```

```output
السعر: 120
السعر: 45
السعر: 300
السعر: 80
[45, 80]
```

سنتعمق في دوال القوائم في الوحدة الرابعة.

## الدوال في Flutter: الأحداث

هكذا تبدو الدوال المجهولة في تطبيق حقيقي، كمعالج للضغط على زر:

```dart-error
ElevatedButton(
  onPressed: () {
    setState(() => counter++);
  },
  child: Text('اضغط'),
)
```

`onPressed` معامل مسمى يستقبل دالة، و `() { ... }` دالة مجهولة تُنفَّذ عند الضغط.

## الإغلاق (Closures)

الدالة تتذكر المتغيرات المحيطة بها لحظة إنشائها:

```dart
Function makeCounter() {
  var count = 0;
  return () {
    count++;
    return count;
  };
}

void main() {
  var counterA = makeCounter();
  var counterB = makeCounter();
  counterA();
  counterA();
  print(counterA());
  print(counterB());
}
```

```output
3
1
```

كل عدّاد يحتفظ بمتغير `count` خاص به، حتى بعد انتهاء `makeCounter`.

## typedef: اسم لنوع الدالة

عندما يتكرر نوع دالة طويل، نعطيه اسماً:

```dart
typedef Validator = String? Function(String value);

String? notEmpty(String value) => value.isEmpty ? 'الحقل مطلوب' : null;
String? minLength(String value) => value.length < 6 ? 'قصير جداً' : null;

void main() {
  List<Validator> rules = [notEmpty, minLength];
  for (final rule in rules) {
    print(rule('abc') ?? 'صالح');
  }
}
```

```output
صالح
قصير جداً
```

هذا نفس نمط التحقق من الحقول في نماذج Flutter (`validator:`).

## ملخص الدرس

- الدوال قيم: تُخزن في متغيرات وتُمرر لدوال أخرى.
- الدالة المجهولة `(params) => expr` أو `(params) { ... }`.
- `int Function(int)` نوع دالة، و `typedef` يعطيه اسماً.
- الإغلاق: الدالة تتذكر متغيرات محيطها.

--- exercise
1. اكتب دالة `transform` تستقبل قائمة أرقام `List<int> numbers` ودالة `int Function(int) fn`، وتُرجع قائمة جديدة بعد تطبيق `fn` على كل عنصر (استخدم حلقة `for-in` و `add`).
2. استدعها في `main` مرتين بدالتين مجهولتين: مرة لمضاعفة الأرقام، ومرة لتربيعها.

~~~starter
List<int> transform(List<int> numbers, int Function(int) fn) {
  // أكمل هنا
}

void main() {
  var nums = [1, 2, 3, 4];
  // اطبع النتيجتين
}
~~~
~~~expected
[2, 4, 6, 8]
[1, 4, 9, 16]
~~~
~~~solution
List<int> transform(List<int> numbers, int Function(int) fn) {
  final result = <int>[];
  for (final n in numbers) {
    result.add(fn(n));
  }
  return result;
}

void main() {
  var nums = [1, 2, 3, 4];
  print(transform(nums, (n) => n * 2));
  print(transform(nums, (n) => n * n));
}
~~~
