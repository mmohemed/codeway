## ثلاث مجموعات أساسية

| المجموعة | الوصف | مثال |
|---|---|---|
| `List` | قائمة مرتبة، تسمح بالتكرار | `[1, 2, 2, 3]` |
| `Set` | مجموعة بلا تكرار | `{1, 2, 3}` |
| `Map` | أزواج مفتاح وقيمة | `{'name': 'علي'}` |

وكلها **محددة النوع**: `List<String>` قائمة نصوص فقط، و `Map<String, int>` مفاتيح نصية وقيم رقمية.

## List

```dart
void main() {
  List<String> tasks = ['الدراسة', 'الرياضة'];
  tasks.add('القراءة');
  tasks.insert(0, 'الاستيقاظ');
  tasks.remove('الرياضة');

  print(tasks);
  print(tasks.length);
  print(tasks.first);
  print(tasks.last);
  print(tasks[1]);
  print(tasks.contains('القراءة'));
  print(tasks.indexOf('القراءة'));
}
```

```output
[الاستيقاظ, الدراسة, القراءة]
3
الاستيقاظ
القراءة
الدراسة
true
2
```

| الطريقة | الوظيفة |
|---|---|
| `add(x)` و `addAll(list)` | إضافة في النهاية |
| `insert(i, x)` | إضافة في موقع محدد |
| `remove(x)` و `removeAt(i)` | حذف |
| `contains(x)` و `indexOf(x)` | بحث |
| `isEmpty` و `isNotEmpty` | هل القائمة فارغة؟ |
| `sort()` و `reversed` | ترتيب وعكس |

## Map

```dart
void main() {
  Map<String, int> stock = {
    'قلم': 40,
    'دفتر': 15,
  };

  stock['مسطرة'] = 8;
  stock['قلم'] = stock['قلم']! - 5;

  print(stock);
  print(stock['دفتر']);
  print(stock['ممحاة']);
  print(stock.containsKey('مسطرة'));
  print(stock.keys.toList());

  stock.forEach((item, qty) => print('$item: $qty'));
}
```

```output
{قلم: 35, دفتر: 15, مسطرة: 8}
15
null
true
[قلم, دفتر, مسطرة]
قلم: 35
دفتر: 15
مسطرة: 8
```

> ⚠️ `stock['قلم']` نوعها `int?` وليس `int`، لأن المفتاح قد لا يكون موجوداً فتُرجع `null`. لذلك استخدمنا `!` هنا لأننا متأكدون من وجوده. والأسلم: `stock['قلم'] ?? 0`.

## Set

```dart
void main() {
  final tags = <String>{'dart', 'flutter'};
  tags.add('dart');
  tags.add('mobile');
  print(tags);
  print(tags.length);

  final a = {1, 2, 3, 4};
  final b = {3, 4, 5};
  print(a.union(b));
  print(a.intersection(b));
  print(a.difference(b));

  final unique = [1, 1, 2, 3, 3].toSet().toList();
  print(unique);
}
```

```output
{dart, flutter, mobile}
3
{1, 2, 3, 4, 5}
{3, 4}
{1, 2}
[1, 2, 3]
```

## ميزات خاصة بـ Dart

### المجموعات الشرطية والحلقية

يمكن كتابة `if` و `for` **داخل** القائمة نفسها، وهذا شائع جداً في Flutter لبناء قوائم Widgets:

```dart
void main() {
  final isLoggedIn = true;
  final items = ['الرئيسية', 'المنتجات', if (isLoggedIn) 'حسابي' else 'دخول'];
  print(items);

  final squares = [for (var i = 1; i <= 4; i++) i * i];
  print(squares);
}
```

```output
[الرئيسية, المنتجات, حسابي]
[1, 4, 9, 16]
```

### عامل الانتشار ...

```dart
void main() {
  final basic = ['أ', 'ب'];
  final extra = ['ج'];
  List<String>? optional;

  final all = [...basic, ...extra, ...?optional];
  print(all);
}
```

```output
[أ, ب, ج]
```

`...?` تنشر القائمة فقط إذا لم تكن null.

## ملخص الدرس

- `List<T>` مرتبة، و `Set<T>` بلا تكرار، و `Map<K, V>` أزواج مفتاح وقيمة.
- قراءة Map تُرجع نوعاً قابلاً لـ null، فاستخدم `??`.
- `if` و `for` داخل القوائم مباشرة، و `...` لنشر قائمة داخل أخرى.

--- exercise
لديك قائمة أسماء طلاب حضروا دروساً مختلفة (مع تكرار). المطلوب:

1. اطبع عدد الطلاب **المختلفين** باستخدام `toSet()`.
2. أنشئ `Map<String, int>` اسمها `attendance` تعدّ مرات حضور كل طالب، واطبعها.
3. اطبع اسم من حضر **أكثر** بالشكل: `الأكثر حضوراً: X`.

~~~starter
void main() {
  final visits = ['رغد', 'تركي', 'رغد', 'سما', 'تركي', 'رغد'];

  // أكمل هنا
}
~~~
~~~expected
3
{رغد: 3, تركي: 2, سما: 1}
الأكثر حضوراً: رغد
~~~
~~~solution
void main() {
  final visits = ['رغد', 'تركي', 'رغد', 'سما', 'تركي', 'رغد'];

  print(visits.toSet().length);

  final attendance = <String, int>{};
  for (final name in visits) {
    attendance[name] = (attendance[name] ?? 0) + 1;
  }
  print(attendance);

  var top = attendance.keys.first;
  attendance.forEach((name, count) {
    if (count > attendance[top]!) top = name;
  });
  print('الأكثر حضوراً: $top');
}
~~~

## دوال المجموعات: الأسلوب الوظيفي

بدلاً من الحلقات اليدوية، توفر Dart دوالاً قوية لمعالجة المجموعات. ستستخدمها يومياً، خاصة لتحويل البيانات إلى Widgets في Flutter.

## map: تحويل كل عنصر

```dart
void main() {
  final prices = [100, 250, 80];
  final withTax = prices.map((p) => p * 1.15).toList();
  print(withTax);

  final names = ['dart', 'flutter'];
  print(names.map((n) => n.toUpperCase()).toList());
}
```

```output
[114.99999999999999, 287.5, 92]
[DART, FLUTTER]
```

> ⚠️ `map` و `where` تُرجعان `Iterable` كسولة (Lazy) لا تُحسب إلا عند الحاجة. أضف `.toList()` في النهاية عندما تحتاج قائمة حقيقية.

لاحظ أن `100 * 1.15` طُبعت `114.99999999999999`: هذه طبيعة الأرقام العشرية في كل لغات البرمجة. لعرض الأسعار استخدم `toStringAsFixed(2)`.

## where: التصفية

```dart
void main() {
  final ages = [12, 25, 17, 30, 15];
  print(ages.where((a) => a >= 18).toList());

  final words = ['قلم', 'حاسوب', 'كتاب'];
  print(words.where((w) => w.length > 3).toList());
}
```

```output
[25, 30]
[حاسوب, كتاب]
```

## reduce و fold: التجميع

```dart
void main() {
  final cart = [30, 45, 25];

  final total = cart.reduce((sum, p) => sum + p);
  print(total);

  final totalWithShipping = cart.fold(15, (sum, p) => sum + p);
  print(totalWithShipping);

  final longest = ['أ', 'أبجد', 'أب'].reduce((a, b) => a.length >= b.length ? a : b);
  print(longest);
}
```

```output
100
115
أبجد
```

- `reduce` تبدأ من أول عنصر، ولا تعمل مع قائمة فارغة.
- `fold` تبدأ من قيمة ابتدائية تحددها، فهي أكثر أماناً.

## دوال البحث والتحقق

```dart
void main() {
  final temps = [22, 35, 28, 41];

  print(temps.any((t) => t > 40));
  print(temps.every((t) => t > 20));
  print(temps.firstWhere((t) => t > 30));
  print(temps.firstWhere((t) => t > 50, orElse: () => -1));
  print(temps.skip(1).take(2).toList());

  final sorted = [...temps]..sort((a, b) => b.compareTo(a));
  print(sorted);
}
```

```output
true
true
35
-1
[35, 28]
[41, 35, 28, 22]
```

- `any` و `every` للتحقق.
- `firstWhere` أول عنصر يحقق الشرط، و `orElse` بديل إن لم يوجد.
- `skip` و `take` للتخطي والأخذ.
- `..` **عامل التتابع (Cascade)**: ينفّذ `sort` على القائمة ثم يُرجع القائمة نفسها.

## السلسلة مع الكائنات

النمط الحقيقي في التطبيقات:

```dart
class Product {
  final String name;
  final double price;
  final bool inStock;
  Product(this.name, this.price, this.inStock);
}

void main() {
  final products = [
    Product('ساعة', 900, true),
    Product('حقيبة', 180, false),
    Product('نظارة', 350, true),
    Product('سماعة', 250, true),
  ];

  final available = products
      .where((p) => p.inStock)
      .map((p) => '${p.name} (${p.price.toInt()})')
      .toList();
  print(available);

  final total = products
      .where((p) => p.inStock)
      .fold<double>(0, (sum, p) => sum + p.price);
  print('الإجمالي: ${total.toInt()}');
}
```

```output
[ساعة (900), نظارة (350), سماعة (250)]
الإجمالي: 1500
```

وفي Flutter يصبح نفس النمط: `products.map((p) => ProductCard(product: p)).toList()` لعرض قائمة بطاقات.

## ملخص الدرس

- `map` للتحويل، و `where` للتصفية، و `fold` و `reduce` للتجميع.
- `map` و `where` كسولتان، فأضف `.toList()`.
- `any` و `every` و `firstWhere` للبحث، و `skip` و `take` للتقطيع.
- `..` يسلسل العمليات على نفس الكائن.

void main() {
  final orders = [
    {'customer': 'رنا', 'amount': 450, 'done': true},
    {'customer': 'وليد', 'amount': 1200, 'done': false},
    {'customer': 'أسيل', 'amount': 300, 'done': true},
  ];

  final done = orders.where((o) => o['done'] == true);
