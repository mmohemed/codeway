## لماذا Dart؟

**Dart** لغة برمجة طورتها Google، وهي اللغة التي يُكتب بها **Flutter**: الإطار الذي يبني تطبيقات Android و iOS والويب وسطح المكتب **من كود واحد**. تطبيقات مثل Google Pay و BMW وغيرها مبنية به.

مزايا Dart:

- **سهلة التعلم:** صيغتها مألوفة لمن يعرف JavaScript أو Java أو C#.
- **آمنة:** نظام أنواع قوي وحماية من أخطاء `null`.
- **سريعة:** تُترجم إلى كود أصلي للجوال، وإلى JavaScript للويب.
- **إعادة تحميل فورية (Hot Reload):** ترى تعديلك في التطبيق خلال لحظة.

## أول برنامج

كل برنامج Dart يبدأ من الدالة `main`:

```dart
void main() {
  print('مرحباً بالعالم!');
}
```

```output
مرحباً بالعالم!
```

- `void main()` نقطة البداية التي ينفّذها البرنامج أولاً. `void` تعني أنها لا تُرجع قيمة.
- `print(...)` تطبع في المخرجات.
- النصوص بين علامتي تنصيص مفردة `'...'` (أو مزدوجة `"..."`).
- **الفاصلة المنقوطة `;` إلزامية** في نهاية كل أمر. نسيانها خطأ شائع في البداية.

## أكثر من أمر

```dart
void main() {
  print('أتعلم Dart');
  print(2026);
  print(7 + 3);
}
```

```output
أتعلم Dart
2026
10
```

## المتغيرات

في Dart يمكنك تعريف المتغير بنوعه صراحة، أو تترك اللغة تستنتجه بـ `var`:

```dart
void main() {
  String name = 'ريم';
  int age = 24;
  double height = 1.65;
  bool isStudent = true;

  var city = 'جدة';

  print(name);
  print(age);
  print(height);
  print(isStudent);
  print(city);
}
```

```output
ريم
24
1.65
true
جدة
```

مع `var` تستنتج Dart أن `city` من نوع `String`، **ويبقى نوعه ثابتاً**: لا يمكنك لاحقاً وضع رقم فيه.

```dart-error
void main() {
  var count = 5;
  count = 'خمسة'; // خطأ: A value of type 'String' can't be assigned to a variable of type 'int'
}
```

هذا هو **نظام الأنواع القوي**: الأخطاء تُكتشف قبل التشغيل، وليس عند المستخدم.

## الأنواع الأساسية

| النوع | يخزّن | مثال |
|---|---|---|
| `int` | أرقام صحيحة | `42` |
| `double` | أرقام عشرية | `3.14` |
| `num` | أي رقم (int أو double) | `7` أو `7.5` |
| `String` | نصوص | `'مرحبا'` |
| `bool` | صح أو خطأ | `true` |
| `dynamic` | أي نوع ويمكن تغييره (تجنّبه) | |

## final و const: قيم لا تتغير

```dart
void main() {
  final today = 'الأحد';
  const pi = 3.14159;
  const maxUsers = 100;

  print('$today $pi $maxUsers');
}
```

```output
الأحد 3.14159 100
```

| الكلمة | متى تُحدد القيمة | مثال |
|---|---|---|
| `final` | مرة واحدة، **أثناء التشغيل** | الوقت الحالي، بيانات من الخادم |
| `const` | **عند الترجمة** وقبل التشغيل | ثوابت معروفة مسبقاً كـ pi |

> 💡 في Flutter ستستخدم `final` و `const` كثيراً جداً. القاعدة: استخدم `final` افتراضياً، و `const` للقيم المعروفة مسبقاً، و `var` فقط لما سيتغير.

## النصوص وإدراج المتغيرات

ندرج المتغيرات في النص بالعلامة `$`، والتعبيرات بـ `${}`:

```dart
void main() {
  var product = 'لابتوب';
  var price = 3500;
  var qty = 2;

  print('المنتج: $product');
  print('الإجمالي: ${price * qty} ريال');
  print('عدد الأحرف: ${product.length}');
  print('أحرف كبيرة: ${'dart'.toUpperCase()}');
}
```

```output
المنتج: لابتوب
الإجمالي: 7000 ريال
عدد الأحرف: 6
أحرف كبيرة: DART
```


## العمليات والتحويل بين الأنواع

```dart
void main() {
  print(17 ~/ 5);
  print(17 % 5);
  print(17 / 4);

  var input = '42';
  var number = int.parse(input);
  print(number + 8);

  print(double.parse('2.5') * 2);
  print(99.toString() + '!');
}
```

```output
3
2
4.25
50
5
99!
```

- `~/` قسمة صحيحة (تحذف الكسور)، و `/` قسمة عادية تُرجع `double`.
- `int.parse()` و `double.parse()` تحويل النص إلى رقم.
- `toString()` تحويل أي قيمة إلى نص.
- لاحظ أن `double.parse('2.5') * 2` طُبعت `5` لأن التمرين يعمل على الويب، أما على الجوال فتظهر `5.0`. القيمة نفسها من نوع `double` في الحالتين.

## ملخص الدرس

- نعرّف المتغير بنوعه (`int` و `String` ...) أو بـ `var` فتستنتج Dart النوع.
- النوع ثابت بعد التعريف: Dart لغة أنواع قوية.
- `final` لقيمة تُحدد مرة أثناء التشغيل، و `const` لقيمة معروفة عند الترجمة.
- `$name` و `${expr}` لإدراج القيم في النصوص.

## خطأ المليار دولار

مخترع مفهوم `null` نفسه، توني هور، وصفه بأنه "خطأ المليار دولار"، لكثرة ما سببه من انهيارات في البرامج: تحاول استخدام قيمة فتكتشف أنها غير موجودة. Dart تحل هذه المشكلة جذرياً بنظام **الأمان من null (Null Safety)**.

## المتغيرات لا تقبل null افتراضياً

```dart-error
void main() {
  String name = null; // خطأ: لا يمكن وضع null في String
}
```

في Dart، `String` تعني "نص موجود دائماً". هذا يضمن أنك عندما تستخدم `name.length` لن ينهار البرنامج أبداً.

## الأنواع القابلة لـ null: ?

إذا كانت القيمة قد تكون غير موجودة فعلاً، أضف `?` بعد النوع:

```dart
void main() {
  String? nickname;
  print(nickname);

  nickname = 'أبو فهد';
  print(nickname);
}
```

```output
null
أبو فهد
```

`String?` تعني "نص أو null". والمتغير القابل لـ null قيمته الابتدائية `null` تلقائياً.

## Dart تمنعك من الخطأ قبل وقوعه

```dart-error
void main() {
  String? email;
  print(email.length); // خطأ ترجمة: email قد يكون null
}
```

يجب أن تتعامل مع احتمال null أولاً. ولديك أدوات لذلك:

## 1. الفحص بـ if

```dart
void main() {
  String? email = 'reem@mail.com';

  if (email != null) {
    print(email.length);
  }
}
```

```output
13
```

بعد `if (email != null)` تعرف Dart أن `email` ليس null داخل الكتلة، فتسمح باستخدامه. هذا يسمى **الترقية التلقائية للنوع (Type Promotion)**.

## 2. عامل الوصول الآمن ?.

```dart
void main() {
  String? city;
  print(city?.length);

  city = 'الرياض';
  print(city?.length);
}
```

```output
null
6
```

`city?.length` تعني: إذا كان `city` موجوداً أعطني طوله، وإلا أعطني `null` بدلاً من الانهيار.

## 3. القيمة البديلة ??

```dart
void main() {
  String? username;
  var display = username ?? 'زائر';
  print('مرحباً $display');

  int? savedScore;
  savedScore ??= 0;
  print(savedScore);
}
```

```output
مرحباً زائر
0
```

- `a ?? b` تُرجع `a` إن لم يكن null، وإلا `b`.
- `a ??= b` تضع `b` في `a` فقط إذا كان `a` يساوي null.

## 4. عامل التأكيد ! (بحذر)

```dart
void main() {
  String? token = 'abc123';
  String sure = token!;
  print(sure.length);
}
```

```output
6
```

`!` تقول للمترجم: "أنا متأكد أن القيمة ليست null". لكن إذا كنت مخطئاً، **ينهار البرنامج** وقت التشغيل.

> ⚠️ استخدم `!` نادراً جداً، وفقط عندما تكون متأكداً 100%. الأدوات `?.` و `??` و `if` أكثر أماناً دائماً.

## late: تهيئة متأخرة

```dart
late String config;

void main() {
  config = 'إعدادات جاهزة';
  print(config);
}
```

```output
إعدادات جاهزة
```

`late` تعني: "هذا المتغير ليس null، لكني سأعطيه قيمته لاحقاً قبل استخدامه". شائعة في Flutter مع المتغيرات التي تُهيأ في `initState`.

## ملخص الدرس

- المتغيرات في Dart لا تقبل null إلا إذا أضفت `?` للنوع.
- المترجم يمنعك من استخدام قيمة قد تكون null دون فحص.
- `?.` وصول آمن، و `??` قيمة بديلة، و `??=` تعيين عند null.
- `!` تأكيد خطير، و `late` لتهيئة متأخرة.

## الشروط

صيغة `if` في Dart مألوفة، **والشرط يجب أن يكون `bool` حقيقياً**: لا توجد قيم "صادقة" و"كاذبة" كما في JavaScript، فلا يمكنك كتابة `if (0)` أو `if (name)`.

```dart
void main() {
  var temperature = 34;

  if (temperature > 40) {
    print('حار جداً');
  } else if (temperature > 30) {
    print('حار');
  } else {
    print('معتدل');
  }

  var isMember = true;
  var price = isMember ? 80 : 100;
  print('السعر: $price');
}
```

```output
حار
السعر: 80
```

## switch الحديثة

منذ Dart 3 أصبحت `switch` أقوى بكثير، ويمكن استخدامها **كتعبير يُرجع قيمة**:

```dart
void main() {
  var day = 5;

  var name = switch (day) {
    1 => 'الأحد',
    2 => 'الاثنين',
    5 => 'الخميس',
    6 || 7 => 'عطلة نهاية الأسبوع',
    _ => 'يوم آخر',
  };
  print(name);

  var score = 82;
  var grade = switch (score) {
    >= 90 => 'ممتاز',
    >= 80 => 'جيد جداً',
    >= 60 => 'جيد',
    _ => 'راسب',
  };
  print(grade);
}
```

```output
الخميس
جيد جداً
```

- `=>` تعني "النتيجة هي".
- `_` الحالة الافتراضية (أي شيء آخر).
- `6 || 7` أكثر من قيمة لنفس النتيجة.
- `>= 90` أنماط مقارنة مباشرة!

## حلقة for

```dart
void main() {
  for (var i = 1; i <= 3; i++) {
    print('الدورة $i');
  }

  var fruits = ['تفاح', 'موز', 'عنب'];
  for (var fruit in fruits) {
    print(fruit);
  }
}
```

```output
الدورة 1
الدورة 2
الدورة 3
تفاح
موز
عنب
```

- `for` التقليدية بعدّاد.
- `for (var x in list)` للمرور على عناصر قائمة مباشرة، وهي الأكثر استخداماً.

## while و do-while

```dart
void main() {
  var balance = 100;
  var months = 0;
  while (balance > 0) {
    balance -= 30;
    months++;
  }
  print('نفد الرصيد بعد $months أشهر');

  var tries = 5;
  do {
    print('محاولة $tries');
    tries++;
  } while (tries < 3);
}
```

```output
نفد الرصيد بعد 4 أشهر
محاولة 5
```

## break و continue

```dart
void main() {
  for (var i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;
    if (i > 7) break;
    print(i);
  }
}
```

```output
1
3
5
7
```

- `continue` تتخطى بقية الدورة الحالية.
- `break` تخرج من الحلقة كلياً.
- لاحظ أن المقارنة في Dart بـ `==` (علامتين)، فلا يوجد `===` كما في JavaScript.

## ملخص الدرس

- شروط `if` يجب أن تكون `bool` حقيقية.
- `switch` الحديثة تعبير يُرجع قيمة، وتدعم الأنماط مثل `>= 90` و `_`.
- `for` بعدّاد، و `for-in` للقوائم، و `while` و `do-while`.
- `break` و `continue` للتحكم في الحلقات، والمقارنة بـ `==`.

~~~solution
    print(result);
  }
}
~~~
