## واجهة برمجية داخل مشروعك

**Route Handlers** ملفات `route.ts` تنشئ نقاط API تستجيب لطلبات HTTP: تطبيق جوال يطلب بياناتك، أو خدمة دفع ترسل إشعاراً (Webhook)، أو أي برنامج آخر. تعمل مثل Express لكن داخل مجلد `app`:

| الملف | الرابط |
|---|---|
| `app/api/products/route.ts` | `/api/products` |
| `app/api/products/[id]/route.ts` | `/api/products/42` |

تصدّر دالة باسم كل طريقة HTTP تدعمها: `GET` و `POST` و `PUT` و `PATCH` و `DELETE`.

## أول Route Handler

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/api/hello/route.ts
export async function GET() {
  return Response.json({ message: "مرحباً من الواجهة البرمجية", time: "10:00" });
}
// test
const res = await request("GET", "/api/hello");
print(res.status, res.headers["content-type"]);
print(res.text);
const post = await request("POST", "/api/hello");
print("POST:", post.status);
```

```output
200 application/json
{"message":"مرحباً من الواجهة البرمجية","time":"10:00"}
POST: 405
```

- `Response.json(data)` يُرجع JSON بالحالة 200 والترويسة الصحيحة. ويمكن استخدام `NextResponse.json` من `next/server` وهو نفسه مع إضافات.
- طلب `POST` أعاد **405** (Method Not Allowed) لأننا لم نصدّر دالة `POST`.

## قراءة الطلب

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/api/products/route.ts
import { NextRequest } from "next/server";

const products = [
  { id: 1, name: "قلم", price: 5 },
  { id: 2, name: "دفتر", price: 15 },
  { id: 3, name: "حقيبة", price: 120 },
];

// GET /api/products?max=20
export async function GET(request: NextRequest) {
  const max = Number(request.nextUrl.searchParams.get("max") ?? Infinity);
  return Response.json(products.filter((p) => p.price <= max));
}

// POST /api/products  { "name": "...", "price": 10 }
export async function POST(request: Request) {
  const body = await request.json();
  if (!body.name || typeof body.price !== "number") {
    return Response.json({ error: "الاسم والسعر مطلوبان" }, { status: 400 });
  }
  const product = { id: products.length + 1, name: body.name, price: body.price };
  products.push(product);
  return Response.json(product, { status: 201 });
}
// test
print((await request("GET", "/api/products?max=20")).text);
const bad = await request("POST", "/api/products", { json: { name: "مسطرة" } });
print(bad.status, bad.text);
const ok = await request("POST", "/api/products", { json: { name: "مسطرة", price: 7 } });
print(ok.status, ok.text);
```

```output
[{"id":1,"name":"قلم","price":5},{"id":2,"name":"دفتر","price":15}]
400 {"error":"الاسم والسعر مطلوبان"}
201 {"id":4,"name":"مسطرة","price":7}
```

| تحتاج | تقرأه من |
|---|---|
| معاملات الرابط `?max=20` | `request.nextUrl.searchParams` |
| جسم JSON | `await request.json()` |
| بيانات نموذج | `await request.formData()` |
| الترويسات | `request.headers.get("authorization")` |
| الكوكيز | `request.cookies.get("token")` |

## Route Handler أم Server Action؟

| الحالة | الأنسب |
|---|---|
| نموذج أو زر في واجهتك يعدّل بيانات | Server Action |
| تطبيق جوال أو جهة خارجية تستدعي الواجهة | Route Handler |
| Webhook من خدمة دفع مثل Stripe | Route Handler |
| ملف للتحميل أو استجابة غير HTML | Route Handler |

> 💡 لا تستدعِ Route Handler من مكون خادم في نفس المشروع: استدعِ الدالة أو قاعدة البيانات مباشرة، فهي على نفس الخادم أصلاً.

## ملخص الدرس

- `route.ts` يصدّر دوالاً بأسماء طرق HTTP، ويُرجع `Response`.
- `Response.json(data, { status })` لإرجاع JSON بحالة مناسبة: 200 و 201 و 400 و 404.
- اقرأ المعاملات من `request.nextUrl.searchParams`، والجسم من `request.json()`، والمقاطع من `params`.
- Route Handlers للجهات الخارجية، و Server Actions لنماذج واجهتك.

~~~solution
// file: app/api/tasks/route.ts
import { NextRequest } from "next/server";

const tasks = [
  { id: 1, title: "تعلم Next.js", done: true },
  { id: 2, title: "بناء مشروع", done: false },
];

export async function GET(request: NextRequest) {
  const done = request.nextUrl.searchParams.get("done");
  if (done === null) return Response.json(tasks);
  return Response.json(tasks.filter((t) => String(t.done) === done));
}

export async function POST(request: Request) {
  const body = await request.json();
  if (!body.title || !String(body.title).trim()) {
    return Response.json({ error: "العنوان مطلوب" }, { status: 400 });
  }
  const task = { id: tasks.length + 1, title: body.title, done: false };
  tasks.push(task);
  return Response.json(task, { status: 201 });
}
~~~

## المصادقة والتفويض

- **المصادقة (Authentication)**: من أنت؟ تسجيل الدخول بالبريد وكلمة المرور، أو بحساب Google.
- **التفويض (Authorization)**: ماذا يحق لك؟ مستخدم عادي أم مسؤول؟

بعد تسجيل الدخول يحفظ الخادم **جلسة (Session)**، ويرسل للمتصفح **كوكي** يعرّفه في كل طلب لاحق.

## مكتبات جاهزة أم بناء بنفسك؟

في المشاريع الحقيقية استخدم مكتبة موثوقة، فالمصادقة مليئة بالتفاصيل الأمنية:

| المكتبة | تتميز بـ |
|---|---|
| **Auth.js** (NextAuth) | مفتوحة المصدر، تدعم Google و GitHub وعشرات المزودين |
| **Better Auth** | حديثة وشاملة، تعمل مع قاعدة بياناتك |
| **Clerk** | خدمة جاهزة بواجهات تسجيل مصممة |

لكن فهم الآلية ضروري لاستخدامها بثقة، فلنبنِ نسخة مبسطة.

## تسجيل الدخول: Server Action تضع كوكي

```tsx
// app/login/actions.ts
"use server";
import { cookies } from "next/headers";
import { redirect } from "next/navigation";

export async function login(formData: FormData) {
  const email = String(formData.get("email"));
  const password = String(formData.get("password"));
  const user = await prisma.user.findUnique({ where: { email } });
  if (!user || !(await bcrypt.compare(password, user.password))) {
    return { error: "بيانات الدخول غير صحيحة" };
  }
  const cookieStore = await cookies();
  cookieStore.set("session", createSessionToken(user.id), {
    httpOnly: true,                    // لا تصل إليه JavaScript في المتصفح
    secure: true,                      // عبر HTTPS فقط
    sameSite: "lax",                   // حماية من طلبات المواقع الأخرى
    maxAge: 60 * 60 * 24 * 7,          // أسبوع
  });
  redirect("/dashboard");
}
```

> ⚠️ لا تحفظ كلمات المرور كما هي أبداً: خزّن **بصمتها (hash)** بمكتبة مثل bcrypt، وقارن البصمات عند الدخول. و `httpOnly` تمنع سرقة الجلسة بثغرات XSS.

`cookies()` من `next/headers` تقرأ كوكيز الطلب، وهي **وعد** منذ Next.js 15 (`await cookies()`). استخدامها يجعل الصفحة ديناميكية تلقائياً.

## حماية الصفحات: proxy.ts

بدل فحص الجلسة في كل صفحة، ضع ملف **`proxy.ts`** في جذر المشروع: يعمل **قبل** كل طلب، ويستطيع تحويل الزائر غير المسجل إلى صفحة الدخول:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: proxy.ts
import { NextResponse, type NextRequest } from "next/server";

export function proxy(request: NextRequest) {
  const session = request.cookies.get("session");
  if (!session) {
    return NextResponse.redirect(new URL("/login", request.url));
  }
  return NextResponse.next();
}

export const config = {
  matcher: ["/dashboard/:path*"],
};
// file: app/login/page.tsx
export default function Login() {
  return <h1>تسجيل الدخول</h1>;
}
// file: app/dashboard/page.tsx
export default function Dashboard() {
  return <h1>لوحة التحكم</h1>;
}
// test
let r = await visit("/dashboard");
print("بلا جلسة:", r.status, "→", r.location);
r = await visit("/dashboard", { cookies: { session: "abc" } });
print("مع جلسة:", r.status, r.text);
r = await visit("/login");
print("صفحة الدخول:", r.status, r.text);
```

```output
بلا جلسة: 307 → /login
مع جلسة: 200 لوحة التحكم
صفحة الدخول: 200 تسجيل الدخول
```

- `matcher` يحدد الروابط التي يعمل عليها: `/dashboard/:path*` تعني `/dashboard` وكل ما تحته.
- `NextResponse.redirect` يحوّل بالحالة 307، و `NextResponse.next()` يكمل الطلب كالمعتاد.

> 💡 في Next.js 15 وما قبله كان اسم الملف `middleware.ts` والدالة `middleware`. في Next.js 16 أصبح `proxy.ts` والدالة `proxy`، والفكرة نفسها.

> ⚠️ proxy خط الدفاع الأول فقط. تحقق من الجلسة والصلاحية أيضاً **قرب البيانات**: داخل Server Actions و Route Handlers ودوال قراءة البيانات، فلا تعتمد على طبقة واحدة.

## ملخص الدرس

- المصادقة: من أنت، والتفويض: ماذا يحق لك.
- الجلسة تُحفظ في كوكي `httpOnly` و `secure`، وكلمات المرور تُخزَّن كبصمات.
- `await cookies()` يقرأ الكوكيز ويكتبها داخل Server Actions و Route Handlers.
- `proxy.ts` يعمل قبل الطلبات ويحمي مجموعة روابط بـ `matcher`.
- في المشاريع الحقيقية استخدم Auth.js أو Better Auth أو Clerk.

## قاعدة البيانات مع Prisma

مكونات الخادم و Server Actions تعمل على الخادم، فتستطيع الاتصال بقاعدة البيانات **مباشرة** دون واجهة وسيطة. الأداة الأشهر لذلك في عالم TypeScript هي **Prisma**: تصف جداولك في ملف، فتولّد لك عميلاً بأنواع كاملة.

> 💡 بدائل معروفة: **Drizzle ORM** (أخف وأقرب لـ SQL)، أو عميل قاعدة البيانات مباشرة. والقواعد الشائعة مع Next.js: PostgreSQL (عبر Neon أو Supabase) و MySQL و SQLite.

## الإعداد

## نسخة واحدة من العميل

في التطوير يعيد Next.js تحميل الملفات كثيراً، وكل نسخة جديدة من `PrismaClient` تفتح اتصالات جديدة. لذلك نصدّر نسخة واحدة من ملف مستقل:

```ts
// lib/prisma.ts
import { PrismaClient } from "@prisma/client";

const globalForPrisma = globalThis as unknown as { prisma?: PrismaClient };
export const prisma = globalForPrisma.prisma ?? new PrismaClient();
if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;
```

## القراءة في مكون الخادم

في تمارين الدورة قاعدة بيانات تجريبية بواجهة Prisma نفسها، فيها جدول المنتجات:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: lib/prisma.ts
import { PrismaClient } from "@prisma/client";
export const prisma = new PrismaClient();
// file: app/page.tsx
import { prisma } from "@/lib/prisma";

export default async function Page() {
  const products = await prisma.product.findMany({
    where: { price: { lt: 1000 } },
    orderBy: { price: "desc" },
  });
  const total = await prisma.product.count();
  return (
    <main>
      <h1>أقل من 1000 ر.س ({products.length} من {total})</h1>
      <ul>{products.map((p) => <li key={p.id}>{p.name}: {p.price}</li>)}</ul>
    </main>
  );
}
// test
print((await visit("/")).text);
```

```output
أقل من 1000 ر.س (2 من 3)
لوحة مفاتيح ميكانيكية: 250
فأرة لاسلكية: 120
```

| الدالة | الاستخدام |
|---|---|
| `findMany({ where, orderBy, take, skip })` | قائمة بشروط وترتيب وترقيم صفحات |
| `findUnique({ where: { id } })` | عنصر واحد بمفتاح فريد |
| `count({ where })` | العدد |
| `create({ data })` | إضافة |
| `update({ where, data })` | تعديل |
| `delete({ where })` | حذف |

وفي `where`: القيمة مباشرة للمساواة، أو `{ gt, gte, lt, lte }` للمقارنة، أو `{ contains }` للبحث في النص.

## الكتابة في Server Action

```next

"use server";
import { revalidatePath } from "next/cache";
import { prisma } from "@/lib/prisma";

export async function restock(formData: FormData) {
  const id = Number(formData.get("id"));
  const product = await prisma.product.findUnique({ where: { id } });
  if (!product) return;
  await prisma.product.update({ where: { id }, data: { stock: product.stock + 10 } });
  revalidatePath("/");
}
```

## ملخص الدرس

- مكونات الخادم و Server Actions تتصل بقاعدة البيانات مباشرة.
- Prisma: الجداول في `schema.prisma`، و `prisma migrate dev` ينشئها، والعميل بأنواع كاملة.
- صدّر نسخة واحدة من `PrismaClient` من `lib/prisma.ts`.
- `findMany` و `findUnique` و `count` للقراءة، و `create` و `update` و `delete` للكتابة.
- رابط القاعدة في `.env`، والوصول للبيانات على الخادم فقط.

~~~solution
// file: app/page.tsx
import { prisma } from "@/lib/prisma";

export default async function InventoryPage() {
  const inStock = { stock: { gt: 0 } };
  const [count, products] = await Promise.all([
    prisma.product.count({ where: inStock }),
    prisma.product.findMany({ where: inStock, orderBy: { price: "asc" } }),
  ]);
  return (
    <main>
      <h1>المتوفر: {count} منتجات</h1>
      <ul>{products.map((p) => <li key={p.id}>{p.name} - {p.price} ر.س</li>)}</ul>
    </main>
  );
}
~~~

--- quiz
? لماذا نصدّر نسخة واحدة من PrismaClient من ملف مستقل؟
+ لتجنب فتح اتصالات جديدة مع كل إعادة تحميل للملفات أثناء التطوير
- لأن Prisma لا يعمل إلا مرة واحدة
- لأسباب جمالية فقط
> كثرة الاتصالات قد تستنفد حدود قاعدة البيانات.

? أين يجب أن يتم الوصول لقاعدة البيانات في Next.js؟
+ على الخادم فقط: مكونات الخادم و Server Actions و Route Handlers
- في مكونات العميل
- في المتصفح عبر fetch مباشرة للقاعدة
> كود العميل مكشوف للجميع.

? كيف تجلب المنتجات التي سعرها أقل من 100؟
+ `prisma.product.findMany({ where: { price: { lt: 100 } } })`
- `prisma.product.findMany({ price < 100 })`
- `prisma.product.where("price < 100")`
> lt تعني less than.
