=== lesson
## React وحده لا يكفي لموقع حقيقي

React مكتبة لبناء الواجهات. لكن الموقع الاحترافي يحتاج أكثر من الواجهة: صفحات متعددة بروابط، وظهوراً جيداً في محركات البحث، وسرعة تحميل، وجلب بيانات من قاعدة بيانات، وواجهة برمجية خلفية. مع React وحده تبني كل هذا بنفسك من مكتبات متفرقة.

في تطبيق React التقليدي (Client-Side Rendering) يصل للمتصفح ملف HTML شبه فارغ:

```html
<body>
  <div id="root"></div>
  <script src="/bundle.js"></script>
</body>
```

ثم يحمّل المتصفح JavaScript كاملاً وينفّذه قبل أن يرى المستخدم أي شيء. النتيجة: انتظار أطول، ومحركات بحث قد ترى صفحة فارغة.

## ما هو Next.js؟

**Next.js** إطار عمل مبني على React من شركة Vercel، يضيف كل ما يحتاجه الموقع الحقيقي:

| الميزة | ماذا تعني |
|---|---|
| التوجيه بالملفات | كل مجلد في `app` يصبح رابطاً تلقائياً |
| العرض على الخادم | الصفحة تصل HTML جاهزاً بمحتواها، سريعة ومفهومة لمحركات البحث |
| مكونات الخادم | مكونات تعمل على الخادم فقط، تقرأ قاعدة البيانات مباشرة ولا ترسل JavaScript للمتصفح |
| جلب البيانات والتخزين المؤقت | `fetch` مع تحكم كامل في مدة حفظ النتائج |
| Server Actions و Route Handlers | واجهة خلفية داخل نفس المشروع |
| تحسين الصور والخطوط | تلقائياً، دون إعداد |

تستخدمه شركات مثل Netflix و TikTok و Notion و OpenAI، وتوصي به وثائق React الرسمية لبدء المشاريع الجديدة.

## مثالك الأول

في Next.js، الصفحة مكون React: دالة تُرجع JSX. هذا ملف `app/page.tsx`:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ar" dir="rtl">
      <body>{children}</body>
    </html>
  );
}
// file: app/page.tsx
export default function HomePage() {
  const year = 2025;
  return (
    <main>
      <h1>مرحباً من Next.js</h1>
      <p>هذه الصفحة عُرضت على الخادم عام {year}.</p>
    </main>
  );
}
// test
const res = await visit("/");
print(res.status);
print(res.body);
```

```output
200
<main><h1>مرحباً من Next.js</h1><p>هذه الصفحة عُرضت على الخادم عام 2025.</p></main>
```

لاحظ أن الخادم أرسل HTML **فيه المحتوى فعلاً**، وليس `<div>` فارغاً. هذا ما تراه محركات البحث، وما يظهر للمستخدم فوراً.

> 💡 إذا لم تدرس React بعد: المكون دالة يبدأ اسمها بحرف كبير، وتُرجع **JSX**: صيغة تشبه HTML داخل JavaScript، والأقواس `{ }` تضع فيها أي تعبير JavaScript. و `className` بدل `class`.

## كيف تعمل التمارين في هذه الدورة؟

تكتب ملفات المشروع في محرر واحد، وكل ملف يبدأ بسطر `// file: المسار`. عند التشغيل يُبنى التطبيق فعلاً بقواعد Next.js، ثم **يزور الفحص صفحاتك** ويطبع ما يراه: حالة الاستجابة، والعنوان، والنص، وحتى نتيجة النقر على الأزرار.

## ملخص الدرس

- React مكتبة واجهات، و Next.js إطار عمل كامل مبني عليها.
- Next.js يعرض الصفحات على الخادم فتصل بمحتواها: أسرع وأفضل لمحركات البحث.
- يضيف التوجيه بالملفات، ومكونات الخادم، وجلب البيانات، وواجهة خلفية، وتحسين الصور والخطوط.
- الصفحة ملف `page.tsx` يصدّر مكون React افتراضياً.

## إنشاء مشروع Next.js

الأداة الرسمية `create-next-app` تنشئ مشروعاً جاهزاً بكل الإعدادات:

```bash
npx create-next-app@latest my-blog
```

ستسألك عن تفضيلاتك، والإجابات الموصى بها:

```text
✔ Would you like to use TypeScript? … Yes
✔ Which linter would you like to use? … ESLint
✔ Would you like to use Tailwind CSS? … Yes
✔ Would you like your code inside a `src/` directory? … No
✔ Would you like to use App Router? (recommended) … Yes
✔ Would you like to customize the import alias (`@/*` by default)? … No
```

ثم:

```bash
cd my-blog
npm run dev
```

وافتح `http://localhost:3000`. أي تعديل تحفظه يظهر فوراً.

> 💡 تحتاج Node.js إصدار 20.9 أو أحدث. راجع دورة «Vite و npm» إن احتجت تذكيراً بـ npm والسكربتات.

## بنية المشروع

| المسار | الدور |
|---|---|
| `app/` | قلب التطبيق: الصفحات والتخطيطات (App Router) |
| `app/layout.tsx` | **التخطيط الجذري**: يحيط بكل الصفحات، وفيه `<html>` و `<body>` |
| `app/page.tsx` | الصفحة الرئيسية `/` |
| `app/globals.css` | الأنماط العامة (وفيها `@import "tailwindcss";`) |
| `public/` | ملفات ثابتة: صور وأيقونات، تُطلب بمسار مثل `/logo.png` |
| `next.config.ts` | إعدادات Next.js |
| `package.json` | السكربتات: `dev` و `build` و `start` و `lint` |

## التخطيط الجذري

`app/layout.tsx` إلزامي، ويجب أن يحتوي وسمي `<html>` و `<body>`، و `children` هي الصفحة الحالية:

```tsx
import type { Metadata } from "next";
import "./globals.css";

export const metadata: Metadata = {
  title: "مدونتي",
  description: "مدونة تقنية بالعربية",
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ar" dir="rtl">
      <body>{children}</body>
    </html>
  );
}
```

- `lang="ar" dir="rtl"` ضروريان لموقع عربي: الاتجاه الصحيح، وقراءة صحيحة من قارئات الشاشة ومحركات البحث.
- `metadata` يحدد عنوان الصفحة ووصفها، وسنتوسع فيه في درس SEO.

إذا نسيت `<html>` و `<body>` يرفض Next.js العرض:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <div>{children}</div>;
}
// file: app/page.tsx
export default function Home() {
  return <h1>مرحباً</h1>;
}
// test
await visit("/");
```

```output
ERR: Missing <html> and <body> tags in the root layout.
Read more at https://nextjs.org/docs/messages/missing-root-layout-tags
```

## التوجيه بالملفات

في App Router، **المجلدات داخل `app` هي الروابط**، والملف `page.tsx` يجعل المجلد صفحة يمكن زيارتها:

| الملف | الرابط |
|---|---|
| `app/page.tsx` | `/` |
| `app/about/page.tsx` | `/about` |
| `app/blog/page.tsx` | `/blog` |
| `app/blog/archive/page.tsx` | `/blog/archive` |

لا إعدادات توجيه ولا ملف مركزي: أنشئ مجلداً وفيه `page.tsx` وانتهى.

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/page.tsx
export default function Home() {
  return <h1>الرئيسية</h1>;
}
// file: app/about/page.tsx
export default function About() {
  return <h1>من نحن</h1>;
}
// file: app/about/team/page.tsx
export default function Team() {
  return <h1>فريق العمل</h1>;
}
// test
for (const url of ["/", "/about", "/about/team", "/contact"]) {
  const res = await visit(url);
  print(url, "→", res.status, res.text.split("\n")[0]);
}
```

```output
/ → 200 الرئيسية
/about → 200 من نحن
/about/team → 200 فريق العمل
/contact → 404 404
```

`/contact` أعاد **404** لأنه لا يوجد `app/contact/page.tsx`.

## الروابط: Link

للتنقل بين الصفحات استخدم مكون `Link` بدل `<a>` العادي:

```tsx
import Link from "next/link";

<Link href="/about">من نحن</Link>
```

`Link` ينتج `<a>` عادياً (جيد لمحركات البحث)، لكنه يتنقل **دون إعادة تحميل الصفحة**، ويحمّل الصفحات مسبقاً عند ظهور الرابط، فيكون التنقل فورياً.

## المسارات الديناميكية: [slug]

لصفحة مقال، لا تنشئ مجلداً لكل مقال. اكتب اسم المجلد بين أقواس مربعة، فيطابق أي قيمة:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/blog/[slug]/page.tsx
export default async function PostPage({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  return <h1>مقال: {slug}</h1>;
}
// test
print((await visit("/blog/hello-nextjs")).text);
print((await visit("/blog/server-components")).text);
```

```output
مقال: hello-nextjs
مقال: server-components
```

- قيمة الجزء المتغير تصل في `params`.
- منذ Next.js 15، `params` **وعد (Promise)**، فنكتب `await params` داخل مكون `async`.

## أنماط أخرى

| المجلد | يطابق | `params` |
|---|---|---|
| `[id]` | `/shop/42` | `{ id: "42" }` |
| `[...slug]` | `/docs/a/b/c` | `{ slug: ["a", "b", "c"] }` |
| `[[...slug]]` | `/docs` أيضاً | `{ slug: undefined }` |
| `(marketing)` | لا يظهر في الرابط | مجموعة لتنظيم الملفات فقط |
| `_components` | ليس رابطاً | مجلد خاص لملفاتك |

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/(marketing)/pricing/page.tsx
export default function Pricing() {
  return <h1>الأسعار</h1>;
}
// file: app/docs/[...slug]/page.tsx
export default async function Docs({ params }: { params: Promise<{ slug: string[] }> }) {
  const { slug } = await params;
  return <p>المسار: {slug.join(" ← ")}</p>;
}
// test
print((await visit("/pricing")).text);
print((await visit("/docs/getting-started/install")).text);
```

```output
الأسعار
المسار: getting-started ← install
```

## ملخص الدرس

- كل مجلد في `app` فيه `page.tsx` يصبح رابطاً، والمجلدات المتداخلة روابط متداخلة.
- `Link` من `next/link` للتنقل السريع بين الصفحات.
- `[slug]` جزء ديناميكي تصل قيمته في `params`، ويُقرأ بـ `await params`.
- `[...slug]` يطابق عدة أجزاء، و `(group)` لا يظهر في الرابط، و `_folder` ليس رابطاً.
