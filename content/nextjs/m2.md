## مكونات الخادم: الافتراضي في Next.js

في App Router، **كل مكون هو مكون خادم (Server Component) ما لم تقل غير ذلك**. مكون الخادم:

- يعمل على الخادم فقط، أثناء تجهيز الصفحة.
- يمكن أن يكون `async` فيجلب البيانات مباشرة بـ `await`.
- يصل للمتصفح **HTML فقط**: كوده لا يُرسل للمتصفح، فالصفحة أخف وأسرع.
- يمكنه استخدام الأسرار (مفاتيح API وكلمات مرور قاعدة البيانات) بأمان، لأنها لا تغادر الخادم.

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/page.tsx
type Product = { id: number; name: string; price: number };

export default async function ProductsPage() {
  const res = await fetch("https://api.codeway.dev/products");
  const products: Product[] = await res.json();

  return (
    <main>
      <h1>المنتجات ({products.length})</h1>
      <ul>
        {products.map((p) => (
          <li key={p.id}>{p.name}: {p.price} ر.س</li>
        ))}
      </ul>
    </main>
  );
}
// test
const res = await visit("/");
print(res.text);
```

```output
المنتجات (4)
لوحة مفاتيح ميكانيكية: 250 ر.س
فأرة لاسلكية: 120 ر.س
شاشة 27 بوصة: 1100 ر.س
سماعة رأس: 340 ر.س
```

لا `useEffect`، ولا حالة تحميل، ولا مكتبات لجلب البيانات: المكون `async`، ينتظر البيانات، ثم يُرجع الواجهة. و `https://api.codeway.dev` واجهة تجريبية تعمل داخل تمارين الدورة.

> 💡 `key` في القوائم يساعد React على تمييز كل عنصر. استخدم معرفاً فريداً مثل `id`.

## ما الذي لا يستطيعه مكون الخادم؟

لأنه لا يعمل في المتصفح، لا يمكنه التفاعل مع المستخدم:

- لا أحداث مثل `onClick` و `onChange`.
- لا حالة `useState` ولا `useEffect`.
- لا واجهات المتصفح مثل `window` و `localStorage`.

جرّب إضافة `onClick` في مكون خادم:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/page.tsx
export default function Page() {
  return <button onClick={() => console.log("نقر")}>اضغط</button>;
}
// test
const res = await visit("/");
print(res.status);
print(res.error);
```

```output
500
Event handlers cannot be passed to Client Component props.
  <button onClick={function onClick} children=...>
If you need interactivity, consider converting part of this to a Client Component.
```

ومثله مع `useState`:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/page.tsx
import { useState } from "react";

export default function Page() {
  const [count, setCount] = useState(0);
  return <p>{count}</p>;
}
// test
print((await visit("/")).error);
```

```output
You're importing a component that needs `useState`. This React Hook only works in a Client Component. To fix, mark the file (or its parent) with the `"use client"` directive.
```

الحل في الدرس القادم: **مكونات العميل** للأجزاء التفاعلية فقط.

## تركيب المكونات

مكون الخادم يمكنه استخدام مكونات أخرى، و `async` في أي مستوى:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/page.tsx
async function LatestPosts() {
  const res = await fetch("https://api.codeway.dev/posts");
  const posts: { slug: string; title: string; author: string }[] = await res.json();
  return (
    <ul>
      {posts.slice(0, 2).map((p) => (
        <li key={p.slug}>{p.title} - {p.author}</li>
      ))}
    </ul>
  );
}

export default function Home() {
  return (
    <main>
      <h1>أحدث المقالات</h1>
      <LatestPosts />
    </main>
  );
}
// test
print((await visit("/")).text);
```

```output
أحدث المقالات
مرحباً Next.js - سارة
مكونات الخادم - خالد
```

## ملخص الدرس

- كل مكون في App Router مكون خادم افتراضياً.
- مكون الخادم يمكن أن يكون `async` ويجلب البيانات مباشرة، وكوده لا يصل للمتصفح.
- لا يستطيع استخدام الأحداث ولا `useState` و `useEffect` ولا واجهات المتصفح.
- الأسرار ومفاتيح API آمنة فيه.

## مكونات العميل

عندما تحتاج تفاعلاً (نقرات، كتابة في حقل، حالة تتغير)، اكتب في **أول سطر** من الملف التوجيه `"use client"`:

```tsx
"use client";

import { useState } from "react";

export default function LikeButton() {
  const [likes, setLikes] = useState(0);
  return <button onClick={() => setLikes(likes + 1)}>👍 {likes}</button>;
}
```

مكون العميل:

- يُعرض أولاً على الخادم كـ HTML (فيظهر فوراً)، ثم يُرسل كوده للمتصفح ليصبح تفاعلياً (Hydration).
- يستطيع استخدام `useState` و `useEffect` والأحداث وواجهات المتصفح.
- كوده يزيد حجم JavaScript في الصفحة، لذلك نستخدمه **للأجزاء التفاعلية فقط**.

## الحدود بين الخادم والعميل

النمط الاحترافي: الصفحة مكون خادم يجلب البيانات، وتضع داخلها «جزراً» تفاعلية صغيرة:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: components/AddToCart.tsx
"use client";
import { useState } from "react";

export default function AddToCart({ name }: { name: string }) {
  const [qty, setQty] = useState(0);
  return (
    <div>
      <button onClick={() => setQty(qty + 1)}>أضف {name}</button>
      <span>في السلة: {qty}</span>
    </div>
  );
}
// file: app/page.tsx
import AddToCart from "@/components/AddToCart";

export default async function Page() {
  const res = await fetch("https://api.codeway.dev/products/1");
  const product: { name: string; price: number } = await res.json();
  return (
    <main>
      <h1>{product.name}</h1>
      <p>السعر: {product.price} ر.س</p>
      <AddToCart name={product.name} />
    </main>
  );
}
// test
const page = await mount("/");
print(page.text);
await page.click("button");
await page.click("button");
print("بعد نقرتين:", page.find("span").text);
```

```output
لوحة مفاتيح ميكانيكية
السعر: 250 ر.س
أضف لوحة مفاتيح ميكانيكية
في السلة: 0
بعد نقرتين: في السلة: 2
```

- الصفحة (خادم) جلبت المنتج، ومررت اسمه لمكون العميل عبر **props**.
- `@/components/...` اختصار لمسار من جذر المشروع.
- `mount` في الفحص يفتح الصفحة كمتصفح حقيقي، فيمكن النقر والكتابة.

## ما الذي يمكن تمريره من الخادم للعميل؟

البيانات التي تمر عبر الحدود يجب أن تكون قابلة للتحويل إلى JSON: نصوص وأرقام ومصفوفات وكائنات. **الدوال العادية لا تمر**:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: components/Button.tsx
"use client";
export default function Button({ onPress }: { onPress: () => void }) {
  return <button onClick={onPress}>اضغط</button>;
}
// file: app/page.tsx
import Button from "@/components/Button";
export default function Page() {
  return <Button onPress={() => console.log("hi")} />;
}
// test
print((await visit("/")).error);
```

```output
Functions cannot be passed directly to Client Components unless you explicitly expose it by marking it with "use server". Or maybe you meant to call this function rather than return it.
  <Button onPress={function onPress} ...>
```

الاستثناء الوحيد: **Server Actions** (دوال عليها `"use server"`)، وسنتعلمها في وحدة البيانات.

## نمط children

مكون العميل يمكنه أن يحيط بمكونات خادم عبر `children`، فتبقى هي على الخادم:

```tsx
"use client";
import { useState } from "react";

export default function Collapsible({ title, children }: { title: string; children: React.ReactNode }) {
  const [open, setOpen] = useState(false);
  return (
    <section>
      <button onClick={() => setOpen(!open)}>{title}</button>
      {open && children}
    </section>
  );
}
```

```tsx
// داخل صفحة (مكون خادم)
<Collapsible title="التعليقات">
  <Comments />  {/* مكون خادم async يجلب التعليقات */}
</Collapsible>
```

> ⚠️ ضع `"use client"` في أدنى مستوى ممكن من الشجرة. لو وضعته في الصفحة كلها، أصبح كل ما تستورده كوداً يُرسل للمتصفح.

## ملخص الدرس

- `"use client"` في أول الملف يجعله مكون عميل يدعم الحالة والأحداث.
- مكونات العميل تُعرض على الخادم أولاً ثم تصبح تفاعلية في المتصفح.
- مرّر البيانات من الخادم للعميل عبر props، والدوال العادية لا تمر.
- اجعل مكونات العميل صغيرة و«أوراقاً» في الشجرة، ومرّر مكونات الخادم كـ `children`.

## التخطيطات (Layouts)

`layout.tsx` في أي مجلد يحيط بكل صفحات ذلك المجلد ومجلداته الفرعية. مثالي للأجزاء المشتركة: قائمة جانبية، شريط تنقل، تذييل:

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ar" dir="rtl">
      <body>
        <header>CodeWay</header>
        {children}
      </body>
    </html>
  );
}
// file: app/dashboard/layout.tsx
import Link from "next/link";

export default function DashboardLayout({ children }: { children: React.ReactNode }) {
  return (
    <div>
      <nav>
        <Link href="/dashboard">الملخص</Link> | <Link href="/dashboard/settings">الإعدادات</Link>
      </nav>
      <section>{children}</section>
    </div>
  );
}
// file: app/dashboard/page.tsx
export default function Dashboard() {
  return <h1>ملخص الحساب</h1>;
}
// file: app/dashboard/settings/page.tsx
export default function Settings() {
  return <h1>الإعدادات</h1>;
}
// file: app/page.tsx
export default function Home() {
  return <h1>الرئيسية</h1>;
}
// test
print("--- /dashboard/settings");
print((await visit("/dashboard/settings")).text);
print("--- /");
print((await visit("/")).text);
```

```output
--- /dashboard/settings
CodeWay
الملخص | الإعدادات
الإعدادات
--- /
CodeWay
الرئيسية
```

التخطيطات **تتداخل**: التخطيط الجذري يحيط بتخطيط لوحة التحكم، الذي يحيط بالصفحة. والصفحة الرئيسية لا ترى قائمة لوحة التحكم.

## التخطيط يحتفظ بحالته

عند التنقل بين صفحات تشترك في تخطيط، **لا يُعاد بناء التخطيط**: تتغير الصفحة فقط، وتبقى حالة التخطيط (مثل مؤقت أو قائمة مفتوحة):

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: components/Timer.tsx

import { useState } from "react";
export default function Timer() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + 1)}>عداد التخطيط: {n}</button>;
}
// file: app/shop/layout.tsx
import Link from "next/link";
import Timer from "@/components/Timer";
export default function ShopLayout({ children }: { children: React.ReactNode }) {
  return <div><Timer /><Link href="/shop/a">أ</Link><Link href="/shop/b">ب</Link>{children}</div>;

// file: app/shop/b/page.tsx

// test
```

## شاشة التحميل: loading.tsx

إذا كانت الصفحة تنتظر بيانات بطيئة، يرى المستخدم صفحة بيضاء. ضع `loading.tsx` بجانب الصفحة، فيعرضه Next.js **فوراً** ثم يستبدله بالصفحة عند جهوزها (Streaming):

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body><header>CodeWay</header>{children}</body></html>;
}
// file: app/reports/loading.tsx
export default function Loading() {
  return <p>جاري تحميل التقارير...</p>;
}
// file: app/reports/page.tsx
export default async function Reports() {
  const res = await fetch("https://api.codeway.dev/stats");
  const stats: { visits: number } = await res.json();
  return <h1>الزيارات: {stats.visits}</h1>;
}
// test
const res = await visit("/reports", { stream: true });
print("ما يظهر أولاً:");
print(res.initialText);
print("بعد اكتمال البيانات:");
print(res.text);
```

```output

CodeWay
جاري تحميل التقارير...
بعد اكتمال البيانات:
CodeWay
الزيارات: 1
```

لاحظ أن التخطيط (`CodeWay`) يظهر فوراً مع شاشة التحميل، فيشعر المستخدم أن الموقع سريع.

> 💡 للتحكم الأدق، استخدم `<Suspense fallback={...}>` من React حول جزء بطيء واحد من الصفحة، فيظهر الباقي فوراً.

## الأخطاء: error.tsx و not-found.tsx

- `error.tsx` يلتقط أي خطأ في الصفحة ويعرض واجهة بديلة بدل انهيار الموقع. يجب أن يكون **مكون عميل**، ويستلم `error` و `reset`.
- `not-found.tsx` يُعرض عند استدعاء `notFound()` أو زيارة رابط غير موجود.

```next
// file: app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="ar" dir="rtl"><body>{children}</body></html>;
}
// file: app/products/[id]/page.tsx
import { notFound } from "next/navigation";
export default async function Product({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  if (id === "0") throw new Error("قاعدة البيانات لا تستجيب");
  const res = await fetch(`https://api.codeway.dev/products/${id}`);
  if (!res.ok) notFound();
  const p: { name: string } = await res.json();
  return <h1>{p.name}</h1>;
}
// file: app/products/[id]/error.tsx
"use client";
```

> ⚠️ في نسخة الإنتاج، يُخفي Next.js نص أخطاء الخادم عن المستخدم ويعرض رسالة عامة حماية للتفاصيل الحساسة، فلا تعتمد على عرض `error.message` للزوار.

## ملخص الدرس

- `layout.tsx` يحيط بصفحات مجلده، والتخطيطات تتداخل وتحتفظ بحالتها عند التنقل.
- `loading.tsx` يُعرض فوراً أثناء انتظار الصفحة (Streaming).
- `error.tsx` مكون عميل يلتقط الأخطاء، و `not-found.tsx` لصفحات 404.
