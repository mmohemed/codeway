=== lesson
## ما هو Vue؟

**Vue.js** إطار JavaScript لبناء واجهات المستخدم التفاعلية، أنشأه Evan You عام 2014. يتميز بأنه **تقدمي**: تستطيع إضافته لصفحة واحدة في موقع قائم، أو بناء تطبيق كامل به مع التوجيه وإدارة الحالة. وهو من أسهل الأطر تعلماً، وتستخدمه شركات مثل Alibaba و GitLab و Nintendo.

الفكرة الأساسية: تصف **كيف تبدو الواجهة** بناءً على البيانات، و Vue يحدّث الصفحة تلقائياً كلما تغيرت البيانات. لا `document.querySelector` ولا تعديل يدوي للعناصر.

## إنشاء مشروع

الطريقة الرسمية (تستخدم Vite الذي تعلمته في دورة Vite و npm):

```bash
npm create vue@latest my-app
```

ستسألك الأداة عن إضافات اختيارية: TypeScript و Vue Router و Pinia و Vitest و ESLint. ثم:

```bash
cd my-app
npm install
npm run dev
```

## بنية المشروع

| الملف | الدور |
|---|---|
| `index.html` | الصفحة وفيها `<div id="app">` |
| `src/main.js` | نقطة البداية: ينشئ التطبيق ويركّبه في الصفحة |
| `src/App.vue` | المكون الجذري |
| `src/components/` | مكوناتك |

و `src/main.js` بسيط جداً:

```js
import { createApp } from "vue";
import App from "./App.vue";

createApp(App).mount("#app");
```

## مكون الملف الواحد (SFC)

كل مكون في Vue ملف `.vue` واحد يجمع ثلاثة أجزاء: المنطق والقالب والتنسيق:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const name = ref("CodeWay");
const count = ref(0);
</script>

<template>
  <h1>مرحباً بك في {{ name }}</h1>
  <button @click="count++">نقرت {{ count }} مرة</button>
</template>

<style scoped>
h1 {
  color: #42b883;
}
</style>
// test
print(text("h1"));
await click("button");
await click("button");
print(text("button"));
```

```output
مرحباً بك في CodeWay
نقرت 2 مرة
```

كل كتلة **Vue** في هذه الدورة تعمل فعلاً بـ Vue الحقيقي، وتحتها معاينة حية: جرّب النقر على الزر.

- `<script setup>`: المنطق. كل ما تعرّفه هنا متاح في القالب مباشرة.
- `ref(0)` ينشئ قيمة **تفاعلية**: عندما تتغير، يتحدث كل ما يعتمد عليها في الصفحة.
- `<template>`: شكل الواجهة، و `{{ }}` تعرض قيمة.
- `<style scoped>`: تنسيق يخص هذا المكون فقط، ولا يؤثر على غيره.

> 💡 ثبّت إضافة **Vue - Official** في VS Code لدعم ملفات `.vue`، وإضافة **Vue DevTools** في المتصفح لرؤية المكونات وحالتها.

## ملخص الدرس

- Vue إطار تقدمي يحدّث الواجهة تلقائياً عند تغير البيانات.
- `npm create vue@latest` ينشئ مشروعاً بـ Vite.
- `createApp(App).mount("#app")` يشغّل التطبيق.
- ملف `.vue` يجمع `<script setup>` و `<template>` و `<style scoped>`.

## الاستيفاء: {{ }}

داخل القالب، `{{ }}` تعرض أي **تعبير** JavaScript، وتتحدث تلقائياً:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const product = ref({ name: "سماعة", price: 340, discount: 0.1 });
const tags = ref(["صوتيات", "لاسلكي"]);
</script>

<template>
  <h2>{{ product.name.toUpperCase() }}</h2>
  <p>السعر بعد الخصم: {{ product.price * (1 - product.discount) }} ر.س</p>
  <p>{{ product.price > 300 ? "منتج مميز" : "منتج اقتصادي" }}</p>
  <p>الوسوم: {{ tags.join(" ، ") }}</p>
</template>
// test
texts("h2, p").forEach(t => print(t));
```

```output
سماعة
السعر بعد الخصم: 306 ر.س
منتج مميز
الوسوم: صوتيات ، لاسلكي
```

> 💡 في القالب لا تكتب `.value`: Vue يفك القيم التفاعلية تلقائياً. أما في `<script>` فتكتب `product.value`.

## ربط الخصائص: v-bind أو :

`{{ }}` للنصوص فقط. لربط **خاصية** عنصر بقيمة، استخدم `v-bind:` أو اختصاره `:`:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const user = ref({ name: "ليان", avatar: "/avatars/layan.png", profile: "/u/layan" });
const isLoading = ref(true);
</script>

<template>
  <a :href="user.profile">
    <img :src="user.avatar" :alt="`صورة ${user.name}`" width="40" height="40" />
    {{ user.name }}
  </a>
  <button :disabled="isLoading">حفظ</button>
</template>
// test
print(attr("a", "href"), attr("img", "alt"));
print("الزر معطل:", $("button").disabled);
```

```output
/u/layan صورة ليان
الزر معطل: true
```

- `:href="user.profile"` القيمة داخل علامات التنصيص **تعبير JavaScript** وليست نصاً.
- القيم المنطقية مثل `:disabled` تضيف الخاصية أو تزيلها.

## الأصناف والأنماط الديناميكية

`:class` و `:style` يقبلان كائنات ومصفوفات، فتضيف الصنف حسب شرط:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const done = ref(true);
const urgent = ref(false);
const size = ref(18);
</script>

<template>
  <p class="task" :class="{ done: done, urgent: urgent }">مراجعة الدرس</p>
  <p :style="{ fontSize: size + 'px', color: urgent ? 'red' : 'green' }">نص بحجم {{ size }}</p>
</template>

<style>
.done { text-decoration: line-through; }
</style>
// test
print(attr(".task", "class"));
print(attr("p:last-child", "style"));
```

```output
task done
font-size: 18px; color: green;
```

`{ done: done }` تعني: أضف الصنف `done` إذا كانت القيمة `true`. ويُدمج مع `class` العادي.

## HTML من متغير: v-html

`{{ }}` يعرض النص كما هو حتى لو احتوى وسوماً، وهذا آمن. لعرض HTML فعلي استخدم `v-html`:

```html
<div v-html="article.body"></div>
```

> ⚠️ لا تستخدم `v-html` مع محتوى يكتبه المستخدمون أبداً: يفتح ثغرة XSS تتيح تنفيذ سكربتات خبيثة. استخدمه فقط مع محتوى تثق فيه.

## ملخص الدرس

- `{{ تعبير }}` يعرض أي تعبير JavaScript ويتحدث تلقائياً، دون `.value` في القالب.
- `:خاصية="تعبير"` يربط خصائص العناصر بالبيانات (`v-bind` كاملة).
- `:class` بكائن لإضافة أصناف بشروط، و `:style` بكائن للأنماط.
- `v-html` لعرض HTML، وفقط مع محتوى موثوق.

## التوجيهات (Directives)

التوجيهات خصائص خاصة تبدأ بـ `v-`، تضيف سلوكاً للعناصر. رأينا `v-bind` و `v-html`، وهذه أهمها.

## العرض الشرطي: v-if و v-show

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const score = ref(85);
const showTips = ref(false);
</script>

<template>
  <p v-if="score >= 90">ممتاز 🏆</p>
  <p v-else-if="score >= 60">ناجح ✅</p>
  <p v-else>حاول مجدداً</p>

  <button @click="showTips = !showTips">النصائح</button>
  <div v-show="showTips" class="tips">راجع الدروس يومياً</div>
</template>
// test
print(texts("p").join(" | "));
print("النصائح ظاهرة:", getComputedStyle($(".tips")).display !== "none");
await click("button");
print("النصائح ظاهرة:", getComputedStyle($(".tips")).display !== "none");
```

```output
ناجح ✅
النصائح ظاهرة: false
النصائح ظاهرة: true
```

| | `v-if` | `v-show` |
|---|---|---|
| الإخفاء | يحذف العنصر من الصفحة | يخفيه بـ `display: none` |
| التكلفة | أعلى عند التبديل المتكرر | أعلى عند البداية |
| الأنسب | شروط نادرة التغير | تبديل متكرر مثل القوائم المنسدلة |

## القوائم: v-for

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const courses = ref([
  { id: 1, title: "JavaScript", lessons: 40 },
  { id: 2, title: "SQL", lessons: 29 },
  { id: 3, title: "Git", lessons: 14 },
]);
</script>

<template>
  <ul>
    <li v-for="(course, index) in courses" :key="course.id">
      {{ index + 1 }}. {{ course.title }} ({{ course.lessons }} درساً)
    </li>
  </ul>
  <p v-if="courses.length === 0">لا توجد دورات</p>
</template>
// test
texts("li").forEach(t => print(t));
```

```output
1. JavaScript (40 درساً)
2. SQL (29 درساً)
3. Git (14 درساً)
```

> ⚠️ `:key` إلزامي عملياً مع `v-for`: قيمة فريدة لكل عنصر (مثل `id`) تساعد Vue على تحديث القائمة بكفاءة ودقة. لا تستخدم `index` مفتاحاً إذا كانت القائمة قد تُرتب أو تُحذف منها عناصر.

## الأحداث: v-on أو @

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const messages = ref([]);
const draft = ref("");

function send() {
  if (!draft.value.trim()) return;
  messages.value.push(draft.value.trim());
  draft.value = "";
}
</script>

<template>
  <form @submit.prevent="send">
    <input v-model="draft" placeholder="اكتب رسالة" @keyup.esc="draft = ''" />
    <button>إرسال</button>
  </form>
  <p v-for="(m, i) in messages" :key="i">💬 {{ m }}</p>
</template>
// test
await type("input", "مرحباً");
await submit();
await type("input", "كيف حالك؟");
await click("button");
print(texts("p").join(" | "), "| الحقل:", JSON.stringify(value("input")));
```

```output
💬 مرحباً | 💬 كيف حالك؟ | الحقل: ""
```

- `@click="دالة"` أو تعبير مباشر مثل `@click="count++"`.
- **المعدِّلات (Modifiers)**: `.prevent` يمنع إعادة تحميل الصفحة عند إرسال النموذج، و `@keyup.esc` يعمل عند ضغط Esc فقط.
- في `<script>` نكتب `draft.value` لأنه `ref`.

## الربط ثنائي الاتجاه: v-model

`v-model` يربط حقل الإدخال بمتغير في الاتجاهين: الكتابة تغيّر المتغير، وتغيير المتغير يغيّر الحقل:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const name = ref("");
const age = ref(18);
const agree = ref(false);
const city = ref("جدة");
</script>

<template>
  <input v-model.trim="name" placeholder="الاسم" />
  <input v-model.number="age" type="number" />
  <label><input v-model="agree" type="checkbox" /> أوافق على الشروط</label>
  <select v-model="city">
    <option>الرياض</option>
    <option>جدة</option>
    <option>الدمام</option>
  </select>
  <p>{{ name }} - {{ age + 1 }} - {{ agree ? "موافق" : "غير موافق" }} - {{ city }}</p>
</template>
// test
await type("input", "  سارة  ");
await type("input[type=number]", "25");
await click("input[type=checkbox]");
await select("select", "الدمام");
print(text("p"));
```

```output
سارة - 26 - موافق - الدمام
```

`.trim` يحذف المسافات الزائدة، و `.number` يحوّل النص إلى رقم (لاحظ أن 25 + 1 = 26 وليس 251).

## ملخص الدرس

- `v-if` و `v-else-if` و `v-else` للعرض الشرطي، و `v-show` للتبديل المتكرر.
- `v-for="item in list"` مع `:key` فريد لعرض القوائم.
- `@حدث` لمعالجة الأحداث، مع معدِّلات مثل `.prevent` و `.esc`.
- `v-model` ربط ثنائي الاتجاه، مع `.trim` و `.number`.

<script setup>
import { ref } from "vue";

const tasks = ref([]);
const newTask = ref("");

function addTask() {
  const title = newTask.value.trim();
  if (!title) return;
  tasks.value.push({ id: Date.now() + tasks.value.length, title });
  newTask.value = "";
}
</script>

<template>
  <form @submit.prevent="addTask">
    <input v-model="newTask" placeholder="مهمة جديدة" />
    <button>أضف</button>
  </form>
  <ul>
    <li v-for="task in tasks" :key="task.id">{{ task.title }}</li>
  </ul>
  <p v-if="tasks.length === 0" class="empty">لا توجد مهام</p>
  <p v-else class="count">عدد المهام: {{ tasks.length }}</p>
</template>
~~~
