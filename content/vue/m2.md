## لماذا المكونات؟

الواجهة الحقيقية تتكون من أجزاء متكررة: بطاقة منتج تتكرر عشرين مرة، وزر بتصميم موحد، ونافذة منبثقة. **المكون** قطعة واجهة مستقلة لها قالبها ومنطقها وتنسيقها، تعيد استخدامها في أي مكان.

## إنشاء مكون واستخدامه

كل مكون ملف `.vue`. لاستخدامه، استورده في `<script setup>` واكتبه كوسم:

```vue
<!-- file: src/components/WelcomeCard.vue -->
<template>
  <div class="card">
    <h3>مرحباً بك 👋</h3>
    <p>ابدأ رحلتك في تعلم البرمجة.</p>
  </div>
</template>

<style scoped>
.card { border: 1px solid #ddd; border-radius: 12px; padding: 8px 16px; margin-bottom: 8px; }
</style>
<!-- file: src/App.vue -->
<script setup>
import WelcomeCard from "./components/WelcomeCard.vue";
</script>

<template>
  <WelcomeCard />
  <WelcomeCard />
</template>
// test
print(count(".card"), "بطاقة");
```

```output
2 بطاقة
```

> 💡 أسماء المكونات بصيغة **PascalCase** (كل كلمة تبدأ بحرف كبير) وتتكون من كلمتين على الأقل، مثل `WelcomeCard` و `ProductList`، حتى لا تتعارض مع وسوم HTML.

## Props: تمرير البيانات للمكون

المكون الذي يعرض نفس المحتوى دائماً محدود الفائدة. **Props** هي مدخلات المكون، يعرّفها بـ `defineProps` ويمررها الأب كخصائص:

```vue
<!-- file: src/components/ProductCard.vue -->
<script setup>
const props = defineProps({
  name: { type: String, required: true },
  price: { type: Number, required: true },
  currency: { type: String, default: "ر.س" },
  inStock: { type: Boolean, default: true },
});
</script>

<template>
  <article class="product">
    <h3>{{ name }}</h3>
    <p>{{ price }} {{ currency }}</p>
    <small v-if="!inStock">نفدت الكمية</small>
  </article>
</template>
<!-- file: src/App.vue -->
<script setup>
import ProductCard from "./components/ProductCard.vue";

const products = [
  { id: 1, name: "كتاب Vue", price: 80, inStock: true },
  { id: 2, name: "كوب CodeWay", price: 35, inStock: false },
];
</script>

<template>
  <ProductCard v-for="p in products" :key="p.id" :name="p.name" :price="p.price" :in-stock="p.inStock" />
  <ProductCard name="ملصقات" :price="10" currency="$" />
</template>
// test
texts(".product").forEach(t => print(t));
```

```output
كتاب Vue 80 ر.س
كوب CodeWay 35 ر.س نفدت الكمية
ملصقات 10 $
```

- `:price="80"` بالنقطتين لتمرير **رقم**، و `currency="$"` بدونهما لتمرير نص.
- في القالب تكتب `in-stock` (kebab-case) ويقابلها `inStock` في `defineProps`.
- `default` قيمة عند عدم التمرير، و `required` يحذّرك إن نسيتها.

## Props مع TypeScript

مع `<script setup lang="ts">` يمكن وصف Props بالأنواع مباشرة، وهي الطريقة الأكثر شيوعاً في المشاريع الحديثة:

```vue
<!-- file: src/components/UserBadge.vue -->
<script setup lang="ts">
const { name, role = "عضو" } = defineProps<{
  name: string;
  role?: "مسؤول" | "عضو";
}>();
</script>

<template>
  <span class="badge">{{ name }} ({{ role }})</span>
</template>
<!-- file: src/App.vue -->
<script setup>
import UserBadge from "./components/UserBadge.vue";
</script>

<template>
  <UserBadge name="ليان" role="مسؤول" />
  <UserBadge name="عمر" />
</template>
// test
print(texts(".badge").join(" | "));
```

```output
ليان (مسؤول) | عمر (عضو)
```

> 💡 منذ Vue 3.5 يمكن تفكيك Props مباشرة مع قيم افتراضية كما في المثال، وتبقى تفاعلية.

## تدفق البيانات باتجاه واحد

Props تنزل **من الأب إلى الابن فقط**، وللقراءة فقط: لا تعدّلها داخل الابن. إذا احتاج الابن تغيير شيء، يُبلغ الأب بحدث (الدرس القادم)، والأب يعدّل بياناته فتنزل القيمة الجديدة. هذا يجعل مصدر كل بيان واضحاً.

## ملخص الدرس

- المكون ملف `.vue` تستورده وتستخدمه كوسم، باسم PascalCase من كلمتين.
- `defineProps` يعرّف المدخلات بأنواعها وقيمها الافتراضية.
- `:prop="تعبير"` لتمرير قيم غير نصية، و kebab-case في القالب.
- Props للقراءة فقط وتتدفق من الأب للابن.

## من الابن إلى الأب: الأحداث

Props تنزل من الأب للابن. والعكس؟ الابن **يطلق حدثاً** (emit)، والأب **يستمع** له بـ `@`، تماماً كما تستمع لـ `@click` على زر:

```vue
<!-- file: src/components/LikeButton.vue -->
<script setup>
const props = defineProps({ liked: Boolean });
const emit = defineEmits(["toggle"]);
</script>

<template>
  <button @click="emit('toggle')">{{ props.liked ? "❤️ أعجبني" : "🤍 إعجاب" }}</button>
</template>
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";
import LikeButton from "./components/LikeButton.vue";

const liked = ref(false);
const total = ref(41);
function onToggle() {
  liked.value = !liked.value;
  total.value += liked.value ? 1 : -1;
}
</script>

<template>
  <LikeButton :liked="liked" @toggle="onToggle" />
  <p>{{ total }} إعجاباً</p>
</template>
// test
print(text("button"), "|", text("p"));
await click("button");
print(text("button"), "|", text("p"));
```

```output
🤍 إعجاب | 41 إعجاباً
❤️ أعجبني | 42 إعجاباً
```

لاحظ النمط: الابن لا يعدّل `liked` بنفسه، بل يقول «حدث تبديل»، والأب صاحب البيانات يقرر ماذا يفعل.

## أحداث بقيم (Payload)

يمكن إرسال بيانات مع الحدث، ويستلمها الأب كمعامل:

```vue
<!-- file: src/components/RatingStars.vue -->
<script setup lang="ts">
const emit = defineEmits<{
  rate: [stars: number];
}>();
</script>

<template>
  <button v-for="n in 5" :key="n" class="star" @click="emit('rate', n)">{{ n }}⭐</button>
</template>
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";
import RatingStars from "./components/RatingStars.vue";

const rating = ref(0);
</script>

<template>
  <RatingStars @rate="(stars) => (rating = stars)" />
  <p>تقييمك: {{ rating }} من 5</p>
</template>
// test
await click(".star:nth-child(4)");
print(text("p"));
```

```output
تقييمك: 4 من 5
```

- `defineEmits` يعلن الأحداث، ومع TypeScript يصف نوع كل قيمة.
- `v-for="n in 5"` يكرر من 1 إلى 5.

## v-model على المكونات: defineModel

الحالة الأشهر: مكون حقل إدخال مخصص يريد ربطاً ثنائياً مثل `v-model`. **`defineModel`** يختصر ذلك كله:

```vue
<!-- file: src/components/QuantityInput.vue -->
<script setup>
const quantity = defineModel({ type: Number, default: 1 });
</script>

<template>
  <div class="qty">
    <button class="minus" @click="quantity > 1 && quantity--">−</button>
    <span>{{ quantity }}</span>
    <button class="plus" @click="quantity++">+</button>
  </div>
</template>
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";
import QuantityInput from "./components/QuantityInput.vue";

const qty = ref(2);
</script>

<template>
  <QuantityInput v-model="qty" />
  <p>الإجمالي: {{ qty * 25 }} ر.س</p>
</template>
// test
await click(".plus");
await click(".plus");
await click(".minus");
print(text(".qty span"), "|", text("p"));
```

```output
3 | الإجمالي: 75 ر.س
```

`defineModel` يعطيك `ref` مربوطاً بقيمة الأب: تعديله داخل الابن يُطلق تلقائياً حدث `update:modelValue`، والأب يتحدث.

## ملخص الدرس

- الابن يطلق حدثاً بـ `emit("اسم", قيمة)` بعد إعلانه بـ `defineEmits`.
- الأب يستمع بـ `@اسم="دالة"` ويستلم القيمة كمعامل.
- البيانات تنزل كـ props، والطلبات تصعد كأحداث.
- `defineModel` يجعل المكون يدعم `v-model` بسطر واحد.

## Slots: تمرير محتوى للمكون

Props تمرر **بيانات**. لكن أحياناً تريد تمرير **محتوى كامل**: مكون «بطاقة» تضع داخلها ما تشاء، أو «نافذة» تختلف محتوياتها. هذا ما تفعله **Slots**:

```vue
<!-- file: src/components/BaseCard.vue -->
<template>
  <div class="card">
    <slot>محتوى افتراضي</slot>
  </div>
</template>

<style scoped>
.card { border: 1px solid #ddd; border-radius: 12px; padding: 12px; margin: 6px 0; }
</style>
<!-- file: src/App.vue -->
<script setup>
import BaseCard from "./components/BaseCard.vue";
</script>

<template>
  <BaseCard>
    <h3>عرض اليوم</h3>
    <p>خصم 30% على كل الدورات</p>
  </BaseCard>
  <BaseCard><button>زر داخل البطاقة</button></BaseCard>
  <BaseCard />
</template>
// test
texts(".card").forEach(t => print(t));
```

```output
عرض اليوم خصم 30% على كل الدورات
زر داخل البطاقة
محتوى افتراضي
```

`<slot>` مكان يُوضع فيه ما كتبه الأب بين وسمي المكون، وما بداخل `<slot>` يظهر إن لم يمرر الأب شيئاً.

## Slots مسماة

لمكون فيه عدة أماكن للمحتوى (رأس وجسم وتذييل)، سمِّ كل slot، ومرر لكل منها بـ `<template #الاسم>`:

```vue
<!-- file: src/components/AppModal.vue -->
<template>
  <div class="modal">
    <header><slot name="header" /></header>
    <main><slot /></main>
    <footer><slot name="footer"><button>إغلاق</button></slot></footer>
  </div>
</template>
<!-- file: src/App.vue -->
<script setup>
import AppModal from "./components/AppModal.vue";
</script>

<template>
  <AppModal>
    <template #header><h3>حذف الحساب</h3></template>
    <p>هل أنت متأكد؟ لا يمكن التراجع.</p>
    <template #footer>
      <button>إلغاء</button>
      <button class="danger">احذف</button>
    </template>
  </AppModal>
</template>
// test
print("header:", text("header"));
print("main:", text("main"));
print("footer:", texts("footer button").join(" و "));
```

```output
header: حذف الحساب
main: هل أنت متأكد؟ لا يمكن التراجع.
footer: إلغاء و احذف
```

`#header` اختصار `v-slot:header`، والمحتوى غير الموجود في `<template>` يذهب للـ slot الافتراضي.

## Scoped Slots: الابن يعطي بيانات للمحتوى

قد يملك المكون بيانات، ويريد أن يقرر الأب **كيف تُعرض**. الابن يمرر بياناته للـ slot كخصائص، والأب يستلمها:

```vue
<!-- file: src/components/DataList.vue -->
<script setup>
defineProps({ items: Array });
</script>

<template>
  <ul>
    <li v-for="(item, i) in items" :key="i">
      <slot :item="item" :index="i">{{ item }}</slot>
    </li>
  </ul>
</template>
<!-- file: src/App.vue -->
<script setup>
import DataList from "./components/DataList.vue";

const users = [{ name: "ليان", role: "مسؤول" }, { name: "عمر", role: "عضو" }];
</script>

<template>
  <DataList :items="users">
    <template #default="{ item, index }">
      <b>{{ index + 1 }}.</b> {{ item.name }} <small>({{ item.role }})</small>
    </template>
  </DataList>
</template>
// test
texts("li").forEach(t => print(t));
```

```output
1. ليان (مسؤول)
2. عمر (عضو)
```

`DataList` يتولى منطق القائمة، والأب يتحكم في شكل كل عنصر. هذا نمط شائع في مكتبات الجداول والقوائم.

## ملخص الدرس

- `<slot />` مكان لمحتوى يمرره الأب بين وسمي المكون، مع محتوى افتراضي اختياري.
- Slots مسماة بـ `<slot name="x">`، والأب يملؤها بـ `<template #x>`.
- Scoped slots: الابن يمرر بيانات `<slot :item="item">`، والأب يستلمها `#default="{ item }"`.
