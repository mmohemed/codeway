=== lesson
## تطبيق الصفحة الواحدة (SPA)

في تطبيق Vue، الصفحة لا تُعاد تحميلها عند التنقل: **Vue Router** يغيّر الرابط في شريط العنوان ويعرض المكون المناسب فوراً. النتيجة تنقل سريع جداً كتطبيقات الجوال.

```bash
npm install vue-router
```

## الإعداد

ثلاث خطوات: تعريف المسارات، وإنشاء الموجّه، وتسجيله في التطبيق:

```vue
<!-- file: src/views/HomeView.vue -->
<template><h2>الرئيسية</h2></template>
<!-- file: src/views/AboutView.vue -->
<template><h2>من نحن</h2></template>
<!-- file: src/router/index.js -->
import { createRouter, createWebHistory } from "vue-router";
import HomeView from "../views/HomeView.vue";
import AboutView from "../views/AboutView.vue";

export default createRouter({
  history: createWebHistory(),
  routes: [
    { path: "/", name: "home", component: HomeView },
    { path: "/about", name: "about", component: AboutView },
  ],
});
<!-- file: src/main.js -->
import { createApp } from "vue";
import App from "./App.vue";
import router from "./router";

createApp(App).use(router).mount("#app");
<!-- file: src/App.vue -->
<template>
  <nav>
    <RouterLink to="/">الرئيسية</RouterLink> |
    <RouterLink to="/about">من نحن</RouterLink>
  </nav>
  <RouterView />
</template>
// test
print(path(), "→", text("h2"));
await click("text=من نحن");
print(path(), "→", text("h2"));
print("الرابط النشط:", text(".router-link-active"));
```

```output
/ → الرئيسية
/about → من نحن
الرابط النشط: من نحن
```

- `RouterLink` ينتج رابطاً `<a>` يتنقل دون إعادة تحميل، ويأخذ الصنف `router-link-active` عندما يكون رابط الصفحة الحالية.
- `RouterView` المكان الذي يُعرض فيه مكون المسار الحالي.
- `createWebHistory` روابط نظيفة مثل `/about`. (في معاينات الدورة يُحفظ التنقل في الذاكرة لأن المعاينة بلا شريط عنوان.)

## المسارات الديناميكية

```vue
<!-- file: src/views/ProductView.vue -->
<script setup>
import { ref, watch } from "vue";
import { useRoute, useRouter } from "vue-router";

const route = useRoute();
const router = useRouter();
const product = ref(null);

watch(
  () => route.params.id,
  async (id) => {
    const res = await fetch(`https://api.codeway.dev/products/${id}`);
    if (!res.ok) return router.replace("/not-found");
    product.value = await res.json();
  },
  { immediate: true }
);
</script>

<template>
  <h2 v-if="product">{{ product.name }}: {{ product.price }} ر.س</h2>
  <button @click="router.push(`/products/${Number(route.params.id) + 1}`)">التالي</button>
</template>
<!-- file: src/main.js -->
import { createApp } from "vue";
import { createRouter, createWebHistory } from "vue-router";
import App from "./App.vue";
import ProductView from "./views/ProductView.vue";

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: "/", redirect: "/products/1" },
    { path: "/products/:id", component: ProductView },
    { path: "/:pathMatch(.*)*", component: { template: "<h2>الصفحة غير موجودة</h2>" } },
  ],
});
createApp(App).use(router).mount("#app");
<!-- file: src/App.vue -->
<template><RouterView /></template>
// test
print(path(), text("h2"));
await click("button");
print(path(), text("h2"));
await navigate("/products/99");
print(path(), text("h2"));
```

```output
/products/1 لوحة مفاتيح: 250 ر.س
/products/2 فأرة لاسلكية: 120 ر.س
/not-found الصفحة غير موجودة
```

| الأداة | الاستخدام |
|---|---|
| `:id` في المسار | جزء متغير يُقرأ من `route.params.id` |
| `useRoute()` | معلومات المسار الحالي: `params` و `query` و `path` |
| `useRouter()` | التنقل بالكود: `push` و `replace` و `back` |
| `redirect` | تحويل مسار لآخر |
| `/:pathMatch(.*)*` | يطابق أي رابط غير معروف (صفحة 404) |

> ⚠️ عند الانتقال من `/products/1` إلى `/products/2` يُعاد استخدام **نفس المكون**، فلا يعمل `onMounted` مرة أخرى. لذلك نراقب `route.params.id` بـ `watch` كما في المثال.

## التحميل الكسول وحماية المسارات

لتصغير حجم التحميل الأول، حمّل الصفحات عند الحاجة بدالة `import()`:

```js
{ path: "/admin", component: () => import("../views/AdminView.vue"), meta: { requiresAuth: true } }
```

و **حارس عام** يعمل قبل كل تنقل، مثلاً لمنع غير المسجلين:

```js
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !isLoggedIn()) return { path: "/login", query: { redirect: to.fullPath } };
});
```

## ملخص الدرس

- Vue Router: `createRouter` بمسارات ثم `app.use(router)`، و `RouterLink` للروابط و `RouterView` لعرض الصفحة.
- `:param` للمسارات الديناميكية، و `useRoute` للقراءة، و `useRouter` للتنقل بالكود.
- راقب `route.params` بـ `watch` لأن المكون يُعاد استخدامه.
- `() => import(...)` للتحميل الكسول، و `beforeEach` لحماية المسارات.

## مشكلة الحالة المشتركة

السلة في متجر: زر «أضف» في صفحة المنتج، والعدد في شريط التنقل، والقائمة في صفحة السلة. ثلاثة مكونات متباعدة تحتاج **نفس البيانات**. تمريرها بـ props وأحداث عبر كل المستويات متعب ومربك.

**Pinia** مكتبة إدارة الحالة الرسمية لـ Vue: **مخزن (Store)** واحد تستخدمه أي مكون مباشرة.

```bash
npm install pinia
```

```js
// src/main.js
import { createPinia } from "pinia";
createApp(App).use(createPinia()).mount("#app");
```

## تعريف مخزن

الطريقة الحديثة (Setup Store) تكتب المخزن كأنه composable: `ref` للحالة، و `computed` للقيم المشتقة، ودوال للأفعال:

```vue
<!-- file: src/stores/cart.js -->
import { defineStore } from "pinia";
import { ref, computed } from "vue";

export const useCartStore = defineStore("cart", () => {
  const items = ref([]);

  const count = computed(() => items.value.reduce((n, i) => n + i.qty, 0));
  const total = computed(() => items.value.reduce((s, i) => s + i.price * i.qty, 0));

  function add(product) {
    const existing = items.value.find((i) => i.id === product.id);
    if (existing) existing.qty++;
    else items.value.push({ ...product, qty: 1 });
  }

  return { items, count, total, add };
});
<!-- file: src/components/CartBadge.vue -->
<script setup>
import { useCartStore } from "@/stores/cart";
const cart = useCartStore();
</script>
<template><span class="badge">🛒 {{ cart.count }}</span></template>
<!-- file: src/components/ProductList.vue -->
<script setup>

```

ثلاثة مكونات تقرأ وتعدّل نفس المخزن دون أي props أو أحداث بينها.

| داخل Setup Store | يقابله |
|---|---|
| `ref()` | الحالة **state** |
| `computed()` | القيم المشتقة **getters** |
| `function` | الأفعال **actions** |

## التفكيك من المخزن: storeToRefs

المخزن كائن `reactive`، فالتفكيك المباشر يفقد التفاعلية (نفس فخ `reactive`). استخدم `storeToRefs` للحالة والقيم المشتقة، أما الدوال فتفكَّك مباشرة:

```js
import { storeToRefs } from "pinia";

const cart = useCartStore();
const { items, total } = storeToRefs(cart); // تفاعلية ✓
const { add } = cart;                        // الدوال لا تحتاج storeToRefs
```

## صيغة Options Store

ستجد في مشاريع كثيرة الصيغة الأخرى، بنفس المعنى:

```js
export const useCounterStore = defineStore("counter", {
  state: () => ({ count: 0 }),
  getters: { double: (state) => state.count * 2 },
  actions: { increment() { this.count++; } },
});
```

> 💡 لا تضع كل شيء في Pinia: الحالة المحلية لمكون واحد (مثل نص حقل أو نافذة مفتوحة) مكانها `ref` داخل المكون. Pinia للحالة المشتركة بين مكونات كثيرة: المستخدم المسجل، والسلة، والإعدادات.

## ملخص الدرس

- Pinia يحل مشكلة الحالة المشتركة بين مكونات متباعدة.
- `defineStore("id", () => { ... return {...} })`: `ref` للحالة، و `computed` للمشتقات، والدوال للأفعال.
- أي مكون يستدعي `useXStore()` ويقرأ ويعدّل مباشرة.
- `storeToRefs` للتفكيك الآمن، و Pinia للحالة المشتركة فقط.

<!-- file: src/stores/user.js -->
import { defineStore } from "pinia";
import { ref, computed } from "vue";

export const useUserStore = defineStore("user", () => {
  const name = ref(null);
  const favorites = ref([]);

  const isLoggedIn = computed(() => name.value !== null);

  function login(n) {
    name.value = n;
  }

  function logout() {
    name.value = null;
    favorites.value = [];
  }

  function toggleFavorite(course) {
    const i = favorites.value.indexOf(course);
    if (i >= 0) favorites.value.splice(i, 1);
    else favorites.value.push(course);
  }

  return { name, favorites, isLoggedIn, login, logout, toggleFavorite };
});
