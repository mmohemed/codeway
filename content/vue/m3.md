## نظام التفاعلية

قلب Vue هو **التفاعلية (Reactivity)**: Vue يتتبع البيانات التي يستخدمها القالب، وعندما تتغير يعيد رسم الأجزاء المتأثرة فقط. لكي يعمل هذا، يجب إنشاء البيانات بدوال خاصة: `ref` و `reactive`.

## ref

`ref` يغلّف أي قيمة (رقم، نص، كائن، مصفوفة) في كائن له خاصية `.value`:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref } from "vue";

const count = ref(0);
const user = ref({ name: "ليان", points: 10 });

function reward() {
  count.value++;            // في JavaScript نكتب .value
  user.value.points += 5;   // الكائنات داخل ref تفاعلية بعمق
}
</script>

<template>
  <!-- في القالب بلا .value -->
  <p>{{ user.name }}: {{ user.points }} نقطة (مكافآت: {{ count }})</p>
  <button @click="reward">كافئ</button>
</template>
// test
await click("button");
await click("button");
print(text("p"));
```

```output
ليان: 20 نقطة (مكافآت: 2)
```

## reactive

`reactive` يجعل **كائناً** تفاعلياً مباشرة، بلا `.value`:

```vue
<!-- file: src/App.vue -->
<script setup>
import { reactive } from "vue";

const form = reactive({
  email: "",
  remember: false,
  errors: [],
});

function validate() {
  form.errors = [];
  if (!form.email.includes("@")) form.errors.push("البريد غير صحيح");
}
</script>

<template>
  <input v-model="form.email" />
  <button @click="validate">تحقق</button>
  <p v-for="e in form.errors" :key="e" class="error">{{ e }}</p>
</template>
// test
await type("input", "layan");
await click("button");
print(texts(".error").join(" | ") || "لا أخطاء");
await type("input", "layan@codeway.dev");
await click("button");
print(texts(".error").join(" | ") || "لا أخطاء");
```

```output
البريد غير صحيح
لا أخطاء
```

## أيهما أستخدم؟

| | `ref` | `reactive` |
|---|---|---|
| يقبل | أي قيمة | الكائنات والمصفوفات فقط |
| الوصول في JavaScript | `x.value` | `x.prop` مباشرة |
| استبدال القيمة كاملة | `x.value = جديد` ✓ | لا يمكن دون فقدان التفاعلية |
| التفكيك `const { a } = x` | - | يفقد التفاعلية ⚠️ |

> 💡 توصية وثائق Vue الرسمية: استخدم `ref` كخيار أساسي في كل مكان. هو يعمل مع كل الأنواع، وسلوكه أوضح.

## فخ التفكيك

```vue
<!-- file: src/App.vue -->
<script setup>
import { reactive, toRefs } from "vue";

const state = reactive({ likes: 3 });
const { likes } = state;                 // ⚠️ رقم عادي، انقطع عن state
const { likes: likesRef } = toRefs(state); // ✓ ref مرتبط بـ state

function like() { state.likes++; }
</script>

<template>
  <button @click="like">إعجاب</button>
  <p class="state">state.likes = {{ state.likes }}</p>
  <p class="plain">likes المفكك = {{ likes }}</p>
  <p class="ref">toRefs = {{ likesRef }}</p>
</template>
// test
await click("button");
await click("button");
print(texts("p").join(" | "));
```

```output
state.likes = 5 | likes المفكك = 3 | toRefs = 5
```

`toRefs` يحوّل كل خاصية في كائن `reactive` إلى `ref` مرتبط، فيصبح التفكيك آمناً.

## ملخص الدرس

- `ref(قيمة)` لأي نوع، ويُقرأ ويُعدّل بـ `.value` في JavaScript، وبدونها في القالب.
- `reactive(كائن)` للكائنات بلا `.value`، لكن لا يمكن استبداله كاملاً ولا تفكيكه مباشرة.
- `toRefs` يجعل تفكيك `reactive` آمناً.
- التوصية: `ref` كخيار افتراضي.

## computed: قيم محسوبة

كثيراً ما تحتاج قيمة **مشتقة** من بيانات أخرى: إجمالي السلة، أو القائمة بعد التصفية. `computed` يحسبها ويحفظ النتيجة، ولا يعيد الحساب إلا إذا تغيرت البيانات التي تعتمد عليها:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref, computed } from "vue";

const products = ref([
  { name: "لوحة مفاتيح", price: 250, category: "إكسسوارات" },
  { name: "شاشة", price: 1100, category: "شاشات" },
  { name: "فأرة", price: 120, category: "إكسسوارات" },
]);
const search = ref("");
const maxPrice = ref(2000);

const filtered = computed(() =>
  products.value.filter((p) => p.name.includes(search.value) && p.price <= maxPrice.value)
);
const total = computed(() => filtered.value.reduce((s, p) => s + p.price, 0));
</script>

<template>
  <input v-model="search" placeholder="ابحث" />
  <input v-model.number="maxPrice" type="number" />
  <ul><li v-for="p in filtered" :key="p.name">{{ p.name }}</li></ul>
  <p>{{ filtered.length }} منتجات بإجمالي {{ total }} ر.س</p>
</template>
// test
print(text("p"));
await type("input[type=number]", "300");
print(texts("li").join(" | "), "|", text("p"));
await type("input", "فأرة");
print(texts("li").join(" | "), "|", text("p"));
```

```output
3 منتجات بإجمالي 1470 ر.س
لوحة مفاتيح | فأرة | 2 منتجات بإجمالي 370 ر.س
فأرة | 1 منتجات بإجمالي 120 ر.س
```

> 💡 الفرق عن الدالة العادية `total()`: الدالة تُنفَّذ مع كل إعادة رسم، و `computed` يُنفَّذ فقط عند تغير اعتمادياته. ولا تضع آثاراً جانبية (طلبات شبكة، تعديل بيانات) داخل `computed`: وظيفته الحساب فقط.

## watch: رد فعل على التغيير

عندما تريد **فعل شيء** (وليس حساب قيمة) عند تغير بيان: حفظ في `localStorage`، أو جلب بيانات جديدة، استخدم `watch`:

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref, watch } from "vue";

const userId = ref(1);
const user = ref(null);
const log = ref([]);

watch(
  userId,
  async (newId, oldId) => {
    log.value.push(`تغير من ${oldId} إلى ${newId}`);
    const res = await fetch(`https://api.codeway.dev/users/${newId}`);
    user.value = await res.json();
  },
  { immediate: true }
);
</script>

<template>
  <button v-for="id in 3" :key="id" :class="'u' + id" @click="userId = id">مستخدم {{ id }}</button>
  <h3 v-if="user">{{ user.name }} - {{ user.email }}</h3>
  <p v-for="l in log" :key="l">{{ l }}</p>
</template>
// test
print(text("h3"));
await click(".u3");
print(text("h3"));
print(texts("p").join(" | "));
```

```output
ليان - layan@codeway.dev
هدى - huda@codeway.dev
تغير من undefined إلى 1 | تغير من 1 إلى 3
```

- `watch(مصدر, (جديد, قديم) => {})` يعمل عند كل تغير للمصدر.
- `{ immediate: true }` يشغّله مرة فوراً عند البداية أيضاً (لاحظ «من undefined إلى 1»).
- `{ deep: true }` لمراقبة التغييرات داخل كائن.

> 💡 `watchEffect(() => {...})` بديل أقصر: يعمل فوراً، ويعيد العمل تلقائياً عند تغير أي بيان تفاعلي استخدمه داخله.

## دورة حياة المكون

للتنفيذ في لحظات معيّنة من حياة المكون:

| الدالة | تعمل |
|---|---|
| `onMounted` | بعد ظهور المكون في الصفحة (مكان شائع لجلب البيانات) |
| `onUpdated` | بعد كل تحديث للعرض |
| `onUnmounted` | عند إزالته (لإيقاف المؤقتات والمستمعين) |

```vue
<!-- file: src/App.vue -->
<script setup>
import { ref, onMounted } from "vue";

const products = ref([]);
const loading = ref(true);

onMounted(async () => {
  const res = await fetch("https://api.codeway.dev/products?category=إكسسوارات");
  products.value = await res.json();
  loading.value = false;
});
</script>

<template>
  <p v-if="loading">جاري التحميل...</p>
  <ul v-else><li v-for="p in products" :key="p.id">{{ p.name }}</li></ul>
</template>
// test
print(texts("li").join(" | "));
```

```output
لوحة مفاتيح | فأرة لاسلكية
```

## ملخص الدرس

- `computed` لقيمة مشتقة تُحفظ ولا تُحسب إلا عند تغير اعتمادياتها، ودون آثار جانبية.
- `watch` لتنفيذ عمل عند تغير بيان، مع `immediate` و `deep`، و `watchEffect` بديل تلقائي.
- `onMounted` لجلب البيانات بعد ظهور المكون، و `onUnmounted` للتنظيف.

  { name: "سارة", score: 92 },
  { name: "خالد", score: 55 },
  { name: "نورة", score: 78 },

## Composables: إعادة استخدام المنطق

المكونات تعيد استخدام **الواجهة**. لكن ماذا عن **المنطق**؟ مثلاً: جلب البيانات مع حالة التحميل والخطأ، تحتاجه في عشرات المكونات. **Composable** دالة تستخدم Composition API (ref و computed و watch...) وتُرجع حالة تفاعلية، فتعيد استخدامها في أي مكون.

> 💡 العرف: اسم الـ composable يبدأ بـ `use`، مثل `useFetch` و `useCounter`، ويوضع في مجلد `src/composables`.

## أول composable

```vue
<!-- file: src/composables/useCounter.js -->
import { ref, computed } from "vue";

export function useCounter(initial = 0, step = 1) {
  const count = ref(initial);
  const isEven = computed(() => count.value % 2 === 0);
  const increment = () => (count.value += step);
  const reset = () => (count.value = initial);
  return { count, isEven, increment, reset };
}
<!-- file: src/App.vue -->
<script setup>
import { useCounter } from "./composables/useCounter";

const likes = useCounter();
const { count: score, increment: addPoints } = useCounter(100, 10);
</script>

<template>
  <button class="like" @click="likes.increment">إعجابات: {{ likes.count }}</button>
  <button class="score" @click="addPoints">النقاط: {{ score }}</button>
</template>
// test
await click(".like"); await click(".like"); await click(".like");
await click(".score");
print(text(".like"), "|", text(".score"));
```

```output
إعجابات: 3 | النقاط: 110
```

كل استدعاء لـ `useCounter` ينشئ **حالة مستقلة**: `likes` و `score` لا يؤثر أحدهما على الآخر. ولاحظ أن التفكيك آمن هنا، لأن الدالة تُرجع كائناً عادياً قيمه `ref`.

## useFetch: النمط الأشهر

```vue
<!-- file: src/composables/useFetch.js -->
import { ref, watchEffect, toValue } from "vue";

export function useFetch(url) {
  const data = ref(null);
  const error = ref(null);
  const loading = ref(false);

  watchEffect(async () => {
    loading.value = true;
    error.value = null;
    try {
      const res = await fetch(toValue(url));
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      data.value = await res.json();
    } catch (e) {
      error.value = e.message;
    } finally {
      loading.value = false;
    }
  });

  return { data, error, loading };
}
<!-- file: src/App.vue -->
<script setup>
import { ref, computed } from "vue";
import { useFetch } from "./composables/useFetch";

const id = ref(1);
const { data: product, error, loading } = useFetch(
  computed(() => `https://api.codeway.dev/products/${id.value}`)
);
</script>

<template>
  <button class="next" @click="id++">التالي</button>
  <button class="bad" @click="id = 99">غير موجود</button>
  <p v-if="loading">جاري التحميل...</p>
  <p v-else-if="error" class="err">خطأ: {{ error }}</p>
  <h3 v-else-if="product">{{ product.name }} - {{ product.price }} ر.س</h3>
</template>
// test
print(text("h3"));
await click(".next");
print(text("h3"));
await click(".bad");
print(text(".err"));
```

```output
لوحة مفاتيح - 250 ر.س
فأرة لاسلكية - 120 ر.س
خطأ: HTTP 404
```

- `toValue(url)` يقرأ القيمة سواء كانت نصاً عادياً أو `ref` أو `computed`.
- لأن `watchEffect` قرأ `url`، فهو يعيد الجلب تلقائياً عند تغير `id`.

> 💡 لا تبنِ كل شيء بنفسك: مكتبة **VueUse** فيها أكثر من 200 composable جاهز ومختبر: `useLocalStorage` و `useDark` و `useMouse` و `useDebounceFn` وغيرها.

## ملخص الدرس

- Composable دالة تبدأ بـ `use` تستخدم Composition API وتُرجع حالة تفاعلية ودوالاً.
- كل استدعاء ينشئ حالة مستقلة.
- `useFetch` يجمع البيانات والتحميل والخطأ في مكان واحد ويُعاد استخدامه.
- `toValue` يقبل قيماً عادية أو تفاعلية، ومكتبة VueUse فيها مئات الـ composables.

<!-- file: src/composables/useToggle.js -->
import { ref } from "vue";

export function useToggle(initial = false) {
  const state = ref(initial);
  const toggle = () => (state.value = !state.value);
  const setTrue = () => (state.value = true);
  const setFalse = () => (state.value = false);
  return { state, toggle, setTrue, setFalse };
}
<!-- file: src/App.vue -->
<script setup>
import { useToggle } from "./composables/useToggle";

const menu = useToggle();
const dark = useToggle(true);
</script>

<template>
  <button class="menu-btn" @click="menu.toggle">القائمة</button>
  <nav v-if="menu.state.value">الدورات | المسارات</nav>
  <button class="dark-btn" @click="dark.toggle">{{ dark.state.value ? "ليلي" : "نهاري" }}</button>
  <button class="light-btn" @click="dark.setFalse">نهاري الآن</button>
</template>
