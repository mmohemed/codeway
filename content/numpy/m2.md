## العمليات على المصفوفات (Vectorization)

في NumPy لا تكتب حلقات. العمليات الحسابية تنطبق **عنصراً بعنصر** على المصفوفة كلها، وهذا يسمى **التوجيه (Vectorization)**:

```python
import numpy as np

price = np.array([100, 250, 80, 40])
qty = np.array([3, 1, 5, 10])

print(price * qty)             # إجمالي كل بند
print((price * qty).sum())     # إجمالي الفاتورة
print(price * 1.15)            # مع ضريبة 15%
print(price - price.mean())    # الفرق عن المتوسط
print(qty ** 2, qty % 2 == 0)
```

```output
[300 250 400 400]
1350
[115.  287.5  92.   46. ]
[-17.5 132.5 -37.5 -77.5]
[  9   1  25 100] [False False False  True]
```

## الدوال الشاملة (ufuncs)

دوال رياضية تعمل على كل عنصر:

```python
import numpy as np

x = np.array([1, 4, 9, 16])
print(np.sqrt(x))
print(np.log10([10, 100, 1000]))
print(np.round(np.array([2.456, 3.789]), 1))
print(np.abs([-3, 5, -7]))
print(np.maximum([1, 8, 3], [4, 2, 6]))   # الأكبر عنصراً بعنصر
print(np.clip([5, 120, -3, 60], 0, 100))  # حصر القيم بين 0 و 100
```

```output
[1. 2. 3. 4.]
[1. 2. 3.]
[2.5 3.8]
[3 5 7]
[4 8 6]
[  5 100   0  60]
```

## لماذا هي أسرع؟

نقيس الفرق بين حلقة Python وعملية NumPy على مليون رقم:

```python
import numpy as np
import time

data = list(range(1_000_000))
arr = np.arange(1_000_000, dtype=np.int64)

t = time.perf_counter()
squares = [x * x for x in data]
loop = time.perf_counter() - t

t = time.perf_counter()
squares_np = arr * arr
vec = time.perf_counter() - t

print("النتيجة متطابقة:", squares[-1] == squares_np[-1])
print("NumPy أسرع؟", vec < loop)
```

```output
النتيجة متطابقة: True
NumPy أسرع؟ True
```

(الأوقات الفعلية تختلف من جهاز لآخر، لكن NumPy أسرع عادةً بعشرات المرات، لأن الحلقة تُنفَّذ بلغة C داخلياً.)

> ⚠️ لماذا `dtype=np.int64`؟ مصفوفات NumPy أرقامها بحجم ثابت، فإن تجاوز الناتج أكبر رقم يتسع له النوع **يفيض (overflow) بصمت** وتظهر أرقام خاطئة. مربع 999999 لا يتسع في `int32` (الافتراضي في المتصفح هنا)، بينما قائمة Python لا حد لأرقامها.

## القيم الخاصة: nan و inf

```python
import numpy as np

a = np.array([10.0, 0.0, -5.0])
with np.errstate(divide="ignore", invalid="ignore"):
    r = a / 0
print(r)
print(np.isnan(r), np.isinf(r))

scores = np.array([80, np.nan, 95, 70])
print(scores.mean(), np.nanmean(scores))
```

```output
[ inf  nan -inf]
[False  True False] [ True False  True]
nan 81.66666666666667
```

- القسمة على صفر لا توقف البرنامج كما في Python العادية، بل تعطي `inf` أو `nan` (ليس رقماً).
- أي عملية مع `nan` تعطي `nan`، لذلك توجد نسخ تتجاهلها: `nanmean` و `nansum` و `nanmax`.

## ملخص الدرس

- العمليات `+ - * / ** %` والمقارنات تعمل عنصراً بعنصر دون حلقات.
- الدوال الشاملة: `sqrt` و `log` و `exp` و `abs` و `round` و `maximum` و `clip`.
- التوجيه أسرع بكثير من الحلقات لأنه يُنفَّذ بلغة C.
- `nan` و `inf` قيم خاصة، و `nanmean` وأخواتها تتجاهل `nan`.

## البث (Broadcasting)

ماذا يحدث عند جمع مصفوفتين **بشكلين مختلفين**؟ NumPy "يمدّ" الأصغر تلقائياً لتطابق الأكبر، دون نسخها فعلاً في الذاكرة. هذا هو **البث**.

أبسط حالة رأيتها: رقم مع مصفوفة. الرقم يُبث على كل العناصر:

```python
import numpy as np

print(np.array([1, 2, 3]) * 10)
```

```output
[10 20 30]
```

## صف مع جدول

```python
import numpy as np

# درجات 3 طلاب في 3 مواد
scores = np.array([
    [70, 80, 90],
    [60, 75, 85],
    [90, 95, 100],
])
bonus = np.array([5, 0, 10])      # درجة إضافية لكل مادة

print(scores + bonus)              # bonus يُضاف لكل صف
```

```output
[[ 75  80 100]
 [ 65  75  95]
 [ 95  95 110]]
```

الشكل (3, 3) مع (3,): الصف `bonus` يُكرر على الصفوف الثلاثة.

## عمود مع جدول

لإضافة قيمة مختلفة **لكل صف**، اجعلها عموداً بشكل (3, 1):

```python
import numpy as np

scores = np.array([
    [70, 80, 90],
    [60, 75, 85],
    [90, 95, 100],
])
per_student = np.array([[2], [10], [0]])   # الشكل (3, 1)
print(scores + per_student)
```

```output
[[ 72  82  92]
 [ 70  85  95]
 [ 90  95 100]]
```

## قواعد البث

NumPy يقارن الأشكال **من اليمين**، وكل بُعدين متقابلين يجب أن يكونا:

1. **متساويين**، أو
2. **أحدهما 1** (فيُمدّ).

| الشكل أ | الشكل ب | النتيجة |
|---|---|---|
| (3, 4) | (4,) | (3, 4) ✓ |
| (3, 4) | (3, 1) | (3, 4) ✓ |
| (3, 1) | (1, 4) | (3, 4) ✓ |
| (3, 4) | (3,) | ✗ خطأ: 4 و 3 |

```python
import numpy as np

a = np.ones((3, 4))
try:
    a + np.array([1, 2, 3])
except ValueError as e:
    print("خطأ:", e)

# جدول الضرب: عمود (9, 1) × صف (9,) = جدول (9, 9)
n = np.arange(1, 10)
table = n.reshape(-1, 1) * n
print(table[:3])
```

```output
خطأ: operands could not be broadcast together with shapes (3,4) (3,) 
[[ 1  2  3  4  5  6  7  8  9]
 [ 2  4  6  8 10 12 14 16 18]
 [ 3  6  9 12 15 18 21 24 27]]
```

## مثال عملي: التوحيد القياسي (Standardization)

قبل تعلم الآلة، تُحوّل كل عمود إلى متوسط 0 وانحراف معياري 1، لتتساوى الأعمدة ذات المقاييس المختلفة (العمر بالسنوات والراتب بالآلاف). بالبث سطر واحد:

```python
import numpy as np

# العمر، الراتب، سنوات الخبرة
X = np.array([
    [25, 8000, 2],
    [35, 15000, 10],
    [45, 22000, 20],
    [30, 11000, 5],
])
Z = (X - X.mean(axis=0)) / X.std(axis=0)
print(Z.round(2))
print("المتوسطات:", Z.mean(axis=0).round(2))
```

```output
[[-1.18 -1.14 -1.06]
 [ 0.17  0.19  0.11]
 [ 1.52  1.53  1.57]
 [-0.51 -0.57 -0.62]]
المتوسطات: [0. 0. 0.]
```

`X.mean(axis=0)` شكله (3,): متوسط لكل عمود، يُبث على الصفوف الأربعة.

## ملخص الدرس

- البث يسمح بالعمليات بين مصفوفات مختلفة الشكل دون حلقات ولا نسخ.
- الأشكال تُقارن من اليمين: كل بُعدين متساويين أو أحدهما 1.
- صف (n,) يُبث على صفوف الجدول، وعمود (m, 1) يُبث على أعمدته.
- تطبيق شائع: `(X - X.mean(axis=0)) / X.std(axis=0)`.

## الإحصاء الوصفي

NumPy فيها كل الدوال الإحصائية الأساسية، وكلها تقبل `axis`:

```python
import numpy as np

salaries = np.array([7500, 9200, 8800, 12000, 6900, 45000, 10100])

print("المتوسط:", salaries.mean().round(1))
print("الوسيط:", np.median(salaries))
print("الانحراف المعياري:", salaries.std().round(1))
print("أقل وأعلى:", salaries.min(), salaries.max())
print("المدى:", np.ptp(salaries))
print("الربيعيات:", np.percentile(salaries, [25, 50, 75]))
```

```output
المتوسط: 14214.3
الوسيط: 9200.0
الانحراف المعياري: 12663.9
أقل وأعلى: 6900 45000
المدى: 38100
الربيعيات: [ 8150.  9200. 11050.]
```

لاحظ: راتب واحد مرتفع جداً (45000) رفع المتوسط كثيراً، بينما بقي **الوسيط** معبّراً عن الراتب المعتاد. لهذا يُفضَّل الوسيط مع البيانات التي فيها قيم شاذة (مثل الرواتب وأسعار العقارات).

> 💡 `std()` يحسب الانحراف المعياري **للمجتمع** افتراضياً. للعينة استخدم `std(ddof=1)` (وهو الافتراضي في Pandas).

## الجبر الخطي

أساس تعلم الآلة كله: ضرب المصفوفات وحل المعادلات.

```python
import numpy as np

# أسعار 3 منتجات، وكميات طلبات 2 عميلين
prices = np.array([10, 25, 4])
orders = np.array([
    [2, 1, 5],
    [0, 3, 10],
])
print(orders @ prices)          # ضرب مصفوفة في متجه: إجمالي كل طلب
print(np.dot([1, 2, 3], [4, 5, 6]))

A = np.array([[2, 1], [1, 3]])
print(A @ A)
print(np.linalg.det(A).round(2))
print(np.linalg.inv(A).round(2))
```

```output
[ 65 115]
32
[[ 5  5]
 [ 5 10]]
5.0
[[ 0.6 -0.2]
 [-0.2  0.4]]
```

- `@` هو ضرب المصفوفات (وليس `*` الذي يضرب عنصراً بعنصر).
- في `orders @ prices`: كل صف من الطلبات يُضرب في الأسعار ويُجمع.

### حل نظام معادلات

اشترى أحمد 2 قهوة و 1 كعكة بـ 31 ريالاً، واشترت سارة 1 قهوة و 3 كعكات بـ 38 ريالاً. ما سعر كل منهما؟

```python
import numpy as np

A = np.array([[2, 1],
              [1, 3]])
b = np.array([31, 38])
coffee, cake = np.linalg.solve(A, b)

```


## ملخص الدرس

- `mean` و `median` و `std` و `percentile` و `ptp` للإحصاء الوصفي، والوسيط أقوى أمام القيم الشاذة.
- `cumsum` و `sort` و `argsort` و `unique` للتراكم والترتيب والعدّ.
- `np.corrcoef` لمعامل الارتباط.
- `@` لضرب المصفوفات، و `np.linalg` للمحدد والمعكوس وحل المعادلات.

~~~starter
import numpy as np

    [95, 85, 88],
    [60, 75, 70],
    [88, 92, 95],
    [72, 68, 80],
~~~

~~~solution
median_final = np.median(final)
~~~
