## البيانات في كل مكان

كل تطبيق تستخدمه يخزّن بيانات: حسابات المستخدمين في تويتر، والمنتجات في أمازون، والرسائل في واتساب، والحجوزات في تطبيقات الطيران. أين تُحفظ كل هذه البيانات؟ في **قاعدة بيانات (Database)**.

قاعدة البيانات نظام منظّم لتخزين البيانات، يتيح لك **إضافتها، والبحث فيها، وتعديلها، وحذفها** بسرعة وأمان، حتى لو كانت ملايين السجلات.

## لماذا لا نستخدم ملف Excel؟

| ملف Excel | قاعدة البيانات |
|---|---|
| يبطئ مع عشرات الآلاف من الصفوف | تتعامل مع الملايين بسرعة |
| شخص واحد يعدّل في نفس الوقت غالباً | آلاف المستخدمين معاً |
| لا شيء يمنع إدخال بيانات خاطئة | قيود تمنع الأخطاء (مثل بريد مكرر) |
| البيانات المترابطة تتكرر في أوراق متعددة | جداول مترابطة دون تكرار |

## قاعدة البيانات العلائقية

أشهر نوع هو **قاعدة البيانات العلائقية (Relational Database)**، وفيها تُنظّم البيانات في **جداول** ترتبط ببعضها. مثلاً في متجر إلكتروني:

- جدول **العملاء**: من اشترى؟
- جدول **المنتجات**: ماذا نبيع؟
- جدول **الطلبات**: من طلب ماذا ومتى؟

جدول الطلبات لا يكرر اسم العميل وعنوانه في كل طلب، بل يحفظ **رقم العميل** فقط، وهذا الرقم يربطه بجدول العملاء. هذه "العلاقة" هي سبب التسمية.

أشهر أنظمة إدارة قواعد البيانات العلائقية:

| النظام | يُستخدم في |
|---|---|
| PostgreSQL | الشركات الناشئة والكبرى، قوي ومجاني |
| MySQL | مواقع الويب و WordPress |
| SQLite | التطبيقات والجوال، قاعدة بيانات في ملف واحد |
| SQL Server | أنظمة شركات Microsoft |
| Oracle | البنوك والمؤسسات الضخمة |

## ما هي SQL؟

**SQL** (تُنطق "إس كيو إل" أو "سيكول") هي اختصار Structured Query Language، أي **لغة الاستعلام المنظّمة**. هي اللغة التي نتحدث بها مع كل هذه الأنظمة. والجميل أن أساسياتها **واحدة تقريباً** في كلها، فما تتعلمه هنا ستستخدمه في أي نظام.

SQL لغة **تصريحية**: أنت تصف **ماذا تريد**، وقاعدة البيانات تقرر **كيف** تجلبه:

```sql
SELECT name, price
FROM products
WHERE price < 100;
```

```output
name | price
شاحن | 80
رواية | 45
كتاب طبخ | 70
```

اقرأها كجملة إنجليزية: "اختر الاسم والسعر من المنتجات حيث السعر أقل من 100". لم نكتب حلقات ولا شروطاً معقدة.

## من يستخدم SQL؟

- **مطورو الواجهات الخلفية:** لبناء التطبيقات.
- **محللو البيانات:** لاستخراج التقارير والإحصاءات.
- **علماء البيانات:** لتجهيز البيانات قبل التحليل.
- **مديرو المنتجات والتسويق:** للإجابة عن أسئلة العمل بأنفسهم.

ولهذا تُعد SQL من أكثر المهارات طلباً في سوق العمل التقني.

## ملخص الدرس

- قاعدة البيانات نظام لتخزين البيانات وإدارتها بسرعة وأمان.
- القاعدة العلائقية تنظّم البيانات في جداول مترابطة.
- SQL لغة التعامل مع قواعد البيانات العلائقية، وأساسياتها واحدة في كل الأنظمة.
- SQL تصريحية: تصف ماذا تريد، لا كيف تجلبه.

## تشريح الجدول

الجدول في قاعدة البيانات يشبه جدول Excel، لكن بقواعد أصرم. لنأخذ جدول المنتجات في متجرنا:

```sql
SELECT * FROM products LIMIT 4;
```

```output
id | name | category | price | stock
1 | لابتوب | إلكترونيات | 3500 | 12
2 | سماعة | إلكترونيات | 250 | 40
3 | شاحن | إلكترونيات | 80 | 0
4 | قميص | ملابس | 120 | 25
```

| المصطلح | المعنى | في المثال |
|---|---|---|
| **الجدول (Table)** | مجموعة بيانات عن نوع واحد من الأشياء | `products` |
| **العمود (Column)** | خاصية واحدة لكل عنصر، وله **نوع** محدد | `name` و `price` |
| **الصف (Row)** أو **السجل (Record)** | عنصر واحد كامل | لابتوب بكل بياناته |
| **الخلية (Cell)** | قيمة واحدة: تقاطع صف وعمود | `3500` سعر اللابتوب |

## كل عمود له نوع

على عكس Excel، لا يمكنك وضع نص في عمود أرقام (في معظم الأنظمة). أشهر الأنواع:

| النوع | يخزّن | مثال |
|---|---|---|
| `INTEGER` أو `INT` | أرقام صحيحة | 42 |
| `REAL` أو `DECIMAL` | أرقام عشرية | 19.99 |
| `TEXT` أو `VARCHAR(n)` | نصوص | 'أحمد' |
| `DATE` و `TIMESTAMP` | تواريخ وأوقات | '2025-01-05' |
| `BOOLEAN` | صح أو خطأ | TRUE |

> 💡 في SQL تُكتب النصوص بين علامتي تنصيص **مفردة** `'أحمد'`. العلامة المزدوجة `"..."` مخصصة لأسماء الأعمدة والجداول في المعيار.

## المفتاح الأساسي (Primary Key)

لاحظ عمود `id` في كل جدول. هو **المفتاح الأساسي**: رقم فريد لكل صف لا يتكرر أبداً ولا يكون فارغاً. حتى لو وُجد عميلان باسم "أحمد"، فلكل منهما رقم مختلف يميّزه.

## القيمة الفارغة NULL

`NULL` تعني "لا توجد قيمة" أو "غير معروف". وهي **ليست صفراً ولا نصاً فارغاً**:

```sql
SELECT name, email FROM customers WHERE id IN (4, 5);
```

```output
name | email
نورة | noura@mail.com
فهد | NULL
```

العميل فهد ليس له بريد مسجّل، فقيمته `NULL`. سنرى لاحقاً أن التعامل مع NULL يحتاج انتباهاً خاصاً.

## قاعدة بيانات متجرنا

في كل دروس هذه الدورة سنعمل على قاعدة بيانات متجر إلكتروني فيها خمسة جداول:

| الجدول | يحتوي |
|---|---|
| `customers` | العملاء: الاسم والمدينة والبريد وتاريخ التسجيل |
| `products` | المنتجات: الاسم والتصنيف والسعر والكمية في المخزون |
| `orders` | الطلبات: رقم العميل والتاريخ والحالة |
| `order_items` | تفاصيل كل طلب: أي منتج، وكم قطعة، وبأي سعر |
| `employees` | موظفو المتجر: القسم والراتب والمدير المباشر |

ستجد في كل تمرين زر **«📋 جداول قاعدة البيانات»** يعرض أعمدة كل جدول.

## ملخص الدرس

- الجدول = أعمدة (خصائص لها أنواع) + صفوف (سجلات).
- المفتاح الأساسي يميّز كل صف ولا يتكرر.
- النصوص بين علامتي تنصيص مفردة `'...'`.
- `NULL` تعني غياب القيمة، وليست صفراً.

## أين ستكتب SQL؟

**في هذه الدورة:** لا تحتاج تثبيت أي شيء. كل تمرين فيه محرر SQL حقيقي يعمل داخل متصفحك بمحرك **SQLite** كامل، ومعه قاعدة بيانات المتجر جاهزة. وكل مرة تضغط «تشغيل» تبدأ قاعدة البيانات من جديد، فلا تخشَ تجربة أي شيء، حتى الحذف!

أما في العمل الحقيقي فلديك خيارات:

| الأداة | مناسبة لـ |
|---|---|
| **DB Browser for SQLite** | برنامج مجاني بسيط لملفات SQLite |
| **pgAdmin** | واجهة رسمية لـ PostgreSQL |
| **MySQL Workbench** | واجهة رسمية لـ MySQL |
| **DBeaver** | أداة واحدة تتصل بكل الأنظمة |
| **سطر الأوامر** | `psql` و `mysql` و `sqlite3` |

## قواعد كتابة SQL

```sql
-- هذا تعليق من سطر واحد
/* وهذا تعليق
   من عدة أسطر */

SELECT name, city
FROM customers
WHERE city = 'جدة';
```

```output
name | city
سارة | جدة
فهد | جدة
```

1. **الفاصلة المنقوطة `;`** تنهي العبارة. ضرورية عند كتابة أكثر من عبارة.
2. **الكلمات المحجوزة** مثل `SELECT` و `FROM` لا تتأثر بحالة الأحرف، فـ `select` تعمل أيضاً. لكن العرف كتابتها بأحرف كبيرة لتمييزها.
3. **المسافات والأسطر الجديدة** لا تهم، فاكتب كل جزء في سطر لتسهيل القراءة.
4. **التعليقات** تبدأ بـ `--` لسطر واحد، أو بين `/* */`.

## أكثر من استعلام في مرة واحدة

يمكنك كتابة عدة عبارات، وكل `SELECT` تظهر نتيجته كجدول مستقل:

```sql
SELECT COUNT(*) AS customers_count FROM customers;
SELECT COUNT(*) AS products_count FROM products;
```

```output
customers_count
8

products_count
10
```

## أنواع عبارات SQL

| المجموعة | العبارات | الوظيفة | الوحدة |
|---|---|---|---|
| الاستعلام (DQL) | `SELECT` | قراءة البيانات | 2 إلى 5 |
| التعديل (DML) | `INSERT` و `UPDATE` و `DELETE` | إضافة وتعديل وحذف الصفوف | 6 |
| التعريف (DDL) | `CREATE` و `ALTER` و `DROP` | إنشاء الجداول وتعديل بنيتها | 7 |
| التحكم (TCL) | `BEGIN` و `COMMIT` و `ROLLBACK` | المعاملات | 8 |

> 💡 معظم عمل محللي البيانات هو `SELECT`، أما المطورون فيستخدمون كل الأنواع.

## قراءة رسائل الخطأ

عندما تخطئ، يخبرك المحرك بالسبب. جرّب في التمرين كتابة اسم جدول خاطئ، وستظهر رسالة مثل `no such table: product`. اقرأ الرسالة دائماً، فهي تدلك على المشكلة بالضبط.

## ملخص الدرس

- محرر CodeWay فيه SQLite حقيقي، وقاعدة البيانات تبدأ من جديد في كل تشغيل.
- الكلمات المحجوزة بأحرف كبيرة عرفاً، والفاصلة المنقوطة تفصل العبارات.
- التعليقات `--` و `/* */`.
- عبارات SQL أربع مجموعات: استعلام وتعديل وتعريف وتحكم.
