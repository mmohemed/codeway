## قيمة من عدة أنواع ممكنة

**نوع الاتحاد (Union)** يعني أن القيمة واحدة من عدة أنواع. يُكتب بالعلامة `|`:

```ts
function printId(id: number | string) {
  console.log(`المعرّف: ${id}`);
}

printId(101);
printId("USR-7");
printId(true);
```

```output
ERR: سطر 7: Argument of type 'boolean' is not assignable to parameter of type 'string | number'.
```

## لا يمكن استخدام ما لا يشترك فيه الجميع

```ts
function format(value: number | string) {
  return value.toUpperCase();
}
```

```output
ERR: سطر 2: Property 'toUpperCase' does not exist on type 'string | number'.   Property 'toUpperCase' does not exist on type 'number'.
```

`toUpperCase` موجودة في `string` فقط، والقيمة قد تكون رقماً. لاستخدامها يجب أن **نضيّق** النوع أولاً، وهو موضوع الدرس الثالث. أما الخصائص المشتركة فمسموحة مباشرة:

```ts
function size(value: string | string[]) {
  return value.length;
}

console.log(size("مرحبا"));
console.log(size(["أ", "ب", "ج"]));
```

```output
5
3
```

## الاتحاد مع null: البيانات التي قد تغيب

```ts
interface User { name: string }

function findUser(id: number): User | null {
  return id === 1 ? { name: "عزيز" } : null;
}

const u1 = findUser(1);
const u2 = findUser(9);
console.log(u1?.name ?? "غير موجود");
console.log(u2?.name ?? "غير موجود");
```

```output
عزيز
غير موجود
```

النوع `User | null` يجبر من يستدعي الدالة على التعامل مع احتمال عدم الوجود. هذا من أهم ما يمنع انهيار التطبيقات.

## مصفوفات الاتحاد

انتبه للفرق في مكان الأقواس:

```ts
const mixed: (number | string)[] = [1, "اثنان", 3];
const onlyOne: number[] | string[] = ["أ", "ب"];

console.log(mixed.length, onlyOne.length);
```

```output
3 2
```

- `(number | string)[]`: مصفوفة واحدة فيها أرقام ونصوص مختلطة.
- `number[] | string[]`: إما مصفوفة أرقام كلها، أو مصفوفة نصوص كلها.

## ملخص الدرس

- `A | B` القيمة من النوع A أو B.
- يمكن استخدام ما هو مشترك بين كل الأنواع فقط، حتى نضيّق النوع.
- `Type | null` لقيم قد تغيب، ويجبر المستدعي على التحقق.
- `(A | B)[]` يختلف عن `A[] | B[]`.

## الجمع بدل الاختيار

الاتحاد `|` يعني "هذا **أو** ذاك". أما **التقاطع (Intersection)** بالعلامة `&` فيعني "هذا **و** ذاك معاً": القيمة يجب أن تحقق كل الأنواع.

```ts
type Named = { name: string };
type Aged = { age: number };
type Person = Named & Aged;

const p: Person = { name: "بشاير", age: 26 };
console.log(`${p.name} - ${p.age}`);

const incomplete: Person = { name: "بلا عمر" };
```

```output
ERR: سطر 8: Type '{ name: string; }' is not assignable to type 'Person'.   Property 'age' is missing in type '{ name: string; }' but required in type 'Aged'.
```

## بناء الأنواع من قطع صغيرة

النمط الأشهر: أنواع صغيرة قابلة لإعادة الاستخدام، ثم تجميعها:

```ts
type WithId = { id: number };
type WithTimestamps = { createdAt: string };
type WithAuthor = { author: string };

type Comment = WithId & WithTimestamps & WithAuthor & { text: string };
type Article = WithId & WithTimestamps & WithAuthor & { title: string; tags: string[] };

const comment: Comment = { id: 1, createdAt: "2025-05-01", author: "ريان", text: "مقال مفيد" };
const article: Article = { id: 9, createdAt: "2025-04-28", author: "منى", title: "تعلم TS", tags: ["ts"] };

function byline(item: WithAuthor & WithTimestamps): string {
  return `${item.author} في ${item.createdAt}`;
}

console.log(byline(comment));
console.log(byline(article));
```

```output
ريان في 2025-05-01
منى في 2025-04-28
```

الدالة `byline` تقبل أي شيء له مؤلف وتاريخ: تعليقاً أو مقالاً أو أي نوع مستقبلي.

## دمج كائنات وقت التشغيل

التقاطع يصف بدقة ناتج دمج كائنين:

```ts
function merge<A extends object, B extends object>(a: A, b: B): A & B {
  return { ...a, ...b };
}

const result = merge({ name: "منتج" }, { price: 99 });
console.log(result.name, result.price);
```

```output
منتج 99
```

(استخدمنا هنا Generics، وسنشرحها في الوحدة القادمة.)

## التعارض ينتج never

إذا تعارضت الأنواع في التقاطع، يصبح النوع مستحيلاً:

```ts
type A = { value: string };
type B = { value: number };
type C = A & B;

const c: C = { value: "نص" };
```

```output
ERR: سطر 5: Type 'string' is not assignable to type 'never'.
```

لا توجد قيمة هي نص ورقم في نفس الوقت، فنوع `value` أصبح `never`.

## ملخص الدرس

- `A & B` تقاطع: القيمة تحتوي كل خصائص A وكل خصائص B.
- مفيد لبناء أنواع كبيرة من قطع صغيرة قابلة لإعادة الاستخدام.
- يصف بدقة ناتج دمج الكائنات.
- تعارض الخصائص ينتج `never`.

## من الواسع إلى الدقيق

**التضييق (Narrowing)** هو أن تفحص قيمة نوعها واسع (مثل `string | number`)، فتعرف TypeScript نوعها الدقيق داخل الكتلة التي بعد الفحص. هذه أهم مهارة عملية في TypeScript.

## typeof

```ts
function double(value: string | number) {
  if (typeof value === "string") {
    return value.repeat(2);
  }
  return value * 2;
}

console.log(double("ها"));
console.log(double(21));
```

```output
هاها
42
```

داخل الـ if تعرف TypeScript أن `value` نص. وبعدها، لأن الـ if أرجعت، تعرف أنه لم يتبقَّ إلا `number`.

## الصدق و null

```ts
function greet(name: string | null | undefined) {
  if (!name) {
    return "مرحباً يا ضيف";
  }
  return `مرحباً يا ${name.trim()}`;
}

console.log(greet(null));
console.log(greet("  دانة  "));
```

```output
مرحباً يا ضيف
مرحباً يا دانة
```

## in: هل الخاصية موجودة؟

```ts
type Cat = { meow: () => string };
type Dog = { bark: () => string };

function speak(pet: Cat | Dog): string {
  if ("meow" in pet) {
    return pet.meow();
  }
  return pet.bark();
}

console.log(speak({ meow: () => "مياو" }));
console.log(speak({ bark: () => "هاو" }));
```

```output
مياو
هاو
```

## instanceof: للأصناف

```ts
function describeDate(input: Date | string): string {
  if (input instanceof Date) {
    return `سنة ${input.getFullYear()}`;
  }
  return `نص: ${input}`;
}

console.log(describeDate(new Date(2030, 0, 1)));
console.log(describeDate("غداً"));
```

```output
سنة 2030
نص: غداً
```

## الاتحاد المميَّز: النمط الأقوى

أضف لكل نوع في الاتحاد خاصية مشتركة بقيمة حرفية مختلفة (غالباً اسمها `kind` أو `type`)، ثم ميّز بها:

```ts
type Circle = { kind: "circle"; radius: number };
type Rect = { kind: "rect"; width: number; height: number };
type Shape = Circle | Rect;

function area(s: Shape): number {
  switch (s.kind) {
    case "circle":
      return 3 * s.radius ** 2;
    case "rect":
      return s.width * s.height;
  }
}

console.log(area({ kind: "circle", radius: 2 }));
console.log(area({ kind: "rect", width: 3, height: 5 }));
```

```output
12
15
```

داخل `case "circle"` تعرف TypeScript أن `s` من نوع `Circle` بالضبط. هذا النمط يُستخدم في كل مكان: حالات الطلبات الشبكية، وأحداث Redux، ورسائل النظام.

## دوال الفحص المخصصة (Type Guards)

```ts
interface Admin { name: string; permissions: string[] }
interface Guest { name: string }

function isAdmin(u: Admin | Guest): u is Admin {
  return "permissions" in u;
}

const people: (Admin | Guest)[] = [
  { name: "بندر", permissions: ["حذف"] },
  { name: "زائر" }
];

for (const p of people) {
  console.log(isAdmin(p) ? `${p.name}: ${p.permissions.length} صلاحية` : `${p.name}: زائر`);
}
```

```output
بندر: 1 صلاحية
زائر: زائر
```

`u is Admin` في نوع الإرجاع تخبر TypeScript: "إذا أرجعت الدالة true، فـ u من نوع Admin".

## ملخص الدرس

- التضييق: فحص يجعل TypeScript تعرف النوع الدقيق داخل الكتلة.
- الأدوات: `typeof` و `!value` و `in` و `instanceof`.
- الاتحاد المميَّز بخاصية `kind` مع `switch` هو النمط الأقوى.
- `x is Type` لكتابة دوال فحص مخصصة.

## القيمة نفسها نوع

**النوع الحرفي (Literal Type)** نوع لا يقبل إلا قيمة واحدة بعينها:

```ts
let direction: "left" = "left";
direction = "right";
```

```output
ERR: سطر 2: Type '"right"' is not assignable to type '"left"'.
```

وحده لا يبدو مفيداً، لكن قوته الحقيقية في **الاتحاد**: مجموعة محددة من القيم المسموحة.

## اتحاد الحروفيات: البديل الأنظف للنصوص الحرة

```ts
type Size = "S" | "M" | "L" | "XL";
type HttpMethod = "GET" | "POST" | "PUT" | "DELETE";

function order(item: string, size: Size) {
  console.log(`طلب ${item} مقاس ${size}`);
}

order("قميص", "M");
order("قميص", "XXL");
```

```output
ERR: سطر 9: Argument of type '"XXL"' is not assignable to parameter of type 'Size'.
```

مع `string` عادية كان الخطأ `"XXL"` سيمر، ويُكتشف لاحقاً في قاعدة البيانات أو عند العميل. والمحرر أيضاً يقترح القيم الأربع المسموحة أثناء الكتابة.

## الحروفيات الرقمية والمنطقية

```ts
type Dice = 1 | 2 | 3 | 4 | 5 | 6;
type Answer = true;

function roll(): Dice {
  return 4;
}

const r: Dice = roll();
console.log(`النرد: ${r}`);
```

```output
النرد: 4
```

## Template Literal Types: أنواع من قوالب النصوص

ميزة قوية: بناء أنواع حرفية من أنواع أخرى:

```ts
type Color = "red" | "blue";
type Shade = "light" | "dark";
type Theme = `${Shade}-${Color}`;

const t1: Theme = "dark-blue";
const t2: Theme = "light-red";
console.log(t1, t2);

type EventName = `on${"Click" | "Hover"}`;
const e: EventName = "onClick";
console.log(e);

const bad: Theme = "dark-green";
```

```output
ERR: سطر 13: Type '"dark-green"' is not assignable to type '"light-red" | "light-blue" | "dark-red" | "dark-blue"'. Did you mean '"dark-red"'?
```

`Theme` يقبل بالضبط 4 قيم: كل تركيبة من الظل واللون. هكذا تُبنى أنواع مكتبات CSS وأسماء الأحداث.

## الحروفيات مع as const

```ts
const ROLES = ["admin", "editor", "viewer"] as const;
type Role = typeof ROLES[number];

function check(role: Role) {
  return ROLES.includes(role) ? `دور صالح: ${role}` : "غير صالح";
}

console.log(check("editor"));
```

```output
دور صالح: editor
```

نمط شائع جداً: مصفوفة ثابتة تُستخدم في الكود وقت التشغيل، ومنها **نستخرج** النوع بـ `typeof ROLES[number]`، فيبقى مصدر الحقيقة واحداً.

## ملخص الدرس

- النوع الحرفي يقبل قيمة واحدة بعينها، وقوته في الاتحاد: `"S" | "M" | "L"`.
- يمنع القيم الخاطئة ويعطي إكمالاً تلقائياً.
- Template Literal Types تبني أنواعاً من القوالب: `` `${A}-${B}` ``.
- `typeof ARR[number]` مع `as const` تستخرج النوع من مصفوفة.
