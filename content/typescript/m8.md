## TypeScript و React: ثنائي مثالي

معظم مشاريع React الحديثة تُكتب بـ TypeScript. تنشئ مشروعاً جاهزاً هكذا:


## أنواع خصائص المكوّن (Props)

```ts-error
interface ButtonProps {
  label: string;
```

## الـ Reducer: المكان الذي تتألق فيه الأنواع

`useReducer` مع **اتحاد مميَّز** للأفعال هو أقوى استخدام لـ TypeScript في React. والجميل أن الـ reducer دالة عادية يمكن تجربتها هنا:

```ts
interface CartState {
  items: { id: number; qty: number }[];
}

type CartAction =
  | { type: "add"; id: number }
  | { type: "remove"; id: number }
  | { type: "clear" };

function cartReducer(state: CartState, action: CartAction): CartState {
  switch (action.type) {
    case "add": {
      const exists = state.items.find(i => i.id === action.id);
      return {
        items: exists
          ? state.items.map(i => (i.id === action.id ? { ...i, qty: i.qty + 1 } : i))
          : [...state.items, { id: action.id, qty: 1 }]
      };
    }
    case "remove":
      return { items: state.items.filter(i => i.id !== action.id) };
    case "clear":
      return { items: [] };
  }
}

let state: CartState = { items: [] };
state = cartReducer(state, { type: "add", id: 7 });
state = cartReducer(state, { type: "add", id: 7 });
state = cartReducer(state, { type: "add", id: 3 });
state = cartReducer(state, { type: "remove", id: 3 });
console.log(state.items);
```

```output
[{"id":7,"qty":2}]
```

داخل `case "add"` تعرف TypeScript أن `action.id` موجود. وإذا أرسلت فعلاً بنوع غير معرّف، أو نسيت `id`، يُرفض الكود.

## ملخص الدرس

- مشروع React بـ TypeScript: `npm create vite@latest -- --template react-ts`.
- `interface Props` لخصائص المكونات، و `useState<T>` عندما لا يكفي الاستنتاج.
- أنواع الأحداث مثل `React.ChangeEvent<HTMLInputElement>`.
- الـ reducer مع اتحاد مميَّز للأفعال يمنع أخطاء إدارة الحالة.

اكتب `todoReducer` لقائمة مهام بالأفعال التالية (اتحاد مميَّز):

- `{ type: "add"; title: string }`: يضيف مهمة جديدة `{ id, title, done: false }` حيث `id` = عدد المهام الحالي + 1.
- `{ type: "toggle"; id: number }`: يعكس `done` للمهمة.

~~~expected
✓ شراء الخبز | ○ دفع الفاتورة
1
~~~
~~~solution
interface Todo { id: number; title: string; done: boolean }

type TodoAction =
  | { type: "add"; title: string }
  | { type: "toggle"; id: number }
  | { type: "clearDone" };

function todoReducer(state: Todo[], action: TodoAction): Todo[] {
  switch (action.type) {
    case "add":
      return [...state, { id: state.length + 1, title: action.title, done: false }];
    case "toggle":
      return state.map(t => (t.id === action.id ? { ...t, done: !t.done } : t));
    case "clearDone":
      return state.filter(t => !t.done);
  }
}

let todos: Todo[] = [];
todos = todoReducer(todos, { type: "add", title: "شراء الخبز" });
todos = todoReducer(todos, { type: "add", title: "دفع الفاتورة" });
todos = todoReducer(todos, { type: "toggle", id: 1 });
console.log(todos.map(t => `${t.done ? "✓" : "○"} ${t.title}`).join(" | "));
todos = todoReducer(todos, { type: "clearDone" });
console.log(todos.length);
~~~

## TypeScript على الخادم

Node.js و TypeScript يعملان معاً بسلاسة. إعداد مشروع خلفي:

```text
npm init -y
npm install express
npm install -D typescript tsx @types/node @types/express
npx tsc --init
```

- `@types/node` أنواع Node.js المدمجة: `process` و `fs` و `path`.
- `tsx` يشغّل ملفات `.ts` مباشرة أثناء التطوير: `npx tsx watch src/server.ts`.
- للإنتاج: `npx tsc` ثم `node dist/server.js`.

## خادم Express بأنواع

```ts-error
import express, { Request, Response } from "express";

interface Product { id: number; name: string; price: number }
const products: Product[] = [{ id: 1, name: "ساعة", price: 450 }];

const app = express();
app.use(express.json());

app.get("/products/:id", (req: Request<{ id: string }>, res: Response<Product | { error: string }>) => {
  const product = products.find(p => p.id === Number(req.params.id));
  if (!product) return res.status(404).json({ error: "غير موجود" });
  res.json(product);
});

app.listen(3000);
```

لاحظ أن `req.params.id` **نص دائماً**، حتى لو كان الرابط `/products/1`. الأنواع تذكّرك بتحويله.

## الحقيقة المرّة: البيانات الخارجية

TypeScript تفحص كودك **وقت الترجمة**. لكن البيانات القادمة من الخارج (طلبات المستخدمين، و APIs، والملفات) تصل **وقت التشغيل**، ولا تضمن الأنواع شكلها:

```ts
interface Order { product: string; qty: number }

const body: string = '{"product": "قلم", "qty": "ثلاثة"}';
const order = JSON.parse(body) as Order;

console.log(order.qty * 2);
```

```output
NaN
```

`as Order` **كذبة** صدّقتها TypeScript: لا يوجد أي فحص فعلي، فوصل نص بدل رقم.

## الحل: التحقق وقت التشغيل

اكتب دالة تتحقق فعلاً من الشكل:

```ts
interface Order { product: string; qty: number }

function parseOrder(data: unknown): Order {
  if (
    typeof data === "object" && data !== null &&
    "product" in data && typeof data.product === "string" &&
    "qty" in data && typeof data.qty === "number" && data.qty > 0
  ) {
    return { product: data.product, qty: data.qty };
  }
  throw new Error("بيانات الطلب غير صالحة");
}

for (const body of ['{"product":"قلم","qty":3}', '{"product":"قلم","qty":"ثلاثة"}']) {
  try {
    const order = parseOrder(JSON.parse(body));
    console.log(`طلب: ${order.qty} × ${order.product}`);
  } catch (e) {
    console.log((e as Error).message);
  }
}
```

```output
طلب: 3 × قلم
بيانات الطلب غير صالحة
```

في المشاريع الحقيقية تُستخدم مكتبات مثل **Zod** تجعل هذا أقصر بكثير، وتستنتج النوع من قواعد التحقق نفسها:

```ts-error
import { z } from "zod";

const OrderSchema = z.object({
  product: z.string(),
  qty: z.number().int().positive()
});
type Order = z.infer<typeof OrderSchema>;

const order = OrderSchema.parse(req.body); // يرمي خطأ واضحاً إذا كان الشكل خاطئاً
```

## من الكتابة إلى الاحتراف

أنهيت أدوات TypeScript الأساسية. في هذا الدرس الأخير نجمع **الممارسات التي تميّز الكود الاحترافي**، مع أمثلة على كل منها.

## 1. فعّل strict دائماً

لا تبدأ مشروعاً دون `"strict": true`، وأضف أيضاً `noUncheckedIndexedAccess` لتجعل الوصول للمصفوفات آمناً.

## 2. لا any، واستخدم unknown

```ts
function safeLength(x: unknown): number {
  if (typeof x === "string" || Array.isArray(x)) return x.length;
  return 0;
}
console.log(safeLength("TypeScript"), safeLength(42));
```

```output
10 0
```

## 3. دع الاستنتاج يعمل

```ts-error
// ❌ تكرار بلا فائدة
const total: number = 10;
const names: string[] = ["a"].map((x: string): string => x.toUpperCase());

// ✅ أنظف، والأنواع نفسها
const total = 10;
const names = ["a"].map(x => x.toUpperCase());
```

اكتب الأنواع على **حدود** الكود: معاملات الدوال، وأنواع إرجاع الدوال العامة، والبيانات المشتركة بين الوحدات.

## 4. اجعل الحالات المستحيلة غير ممكنة التمثيل

```ts-error
// ❌ يسمح بحالات متناقضة: isLoading و error معاً؟ data مع error؟
interface State { isLoading: boolean; error?: string; data?: User[] }

// ✅ كل حالة واضحة ولا تتناقض
type State =
  | { status: "loading" }
  | { status: "error"; error: string }
  | { status: "success"; data: User[] };
```

هذه من أهم أفكار التصميم بالأنواع.

## 5. مصدر واحد للحقيقة

```ts
const SIZES = ["S", "M", "L"] as const;
type Size = typeof SIZES[number];

interface Shirt { name: string; size: Size; price: number }
type ShirtUpdate = Partial<Omit<Shirt, "name">>;

const update: ShirtUpdate = { price: 99 };
console.log(SIZES.length, update.price);
```

```output
3 99
```

نوع `Size` مشتق من المصفوفة، و `ShirtUpdate` مشتق من `Shirt`. أي تعديل في المصدر ينتشر تلقائياً.

## 6. تجنّب as و !

`value as Type` و `value!` يلغيان فحص المترجم. كل استخدام لهما يحتاج سبباً مقنعاً، والأفضل دائماً **التضييق** بفحص حقيقي.

## 7. الاتحاد المميَّز مع never للتغطية الكاملة

```ts
type Payment = { method: "card"; last4: string } | { method: "cash" } | { method: "wallet"; app: string };

function describe(p: Payment): string {
  switch (p.method) {
    case "card": return `بطاقة تنتهي بـ ${p.last4}`;
    case "cash": return "نقداً";
    case "wallet": return `محفظة ${p.app}`;
    default: {
      const unreachable: never = p;
      return unreachable;
    }
  }
}

console.log(describe({ method: "wallet", app: "STC Pay" }));
```

```output
محفظة STC Pay
```

~~~solution
type FetchState =
  | { status: "idle" }
  | { status: "loading" }
  | { status: "error"; message: string }
  | { status: "success"; items: string[] };

function render(s: FetchState): string {
  switch (s.status) {
    case "idle":
      return "اضغط للتحميل";
    case "loading":
      return "جاري التحميل...";
    case "error":
      return `خطأ: ${s.message}`;
    case "success":
      return `تم تحميل ${s.items.length} عناصر`;
    default: {
      const unreachable: never = s;
      return unreachable;
    }
  }
}

const states: FetchState[] = [
  { status: "idle" },
  { status: "loading" },
  { status: "error", message: "انقطع الاتصال" },
  { status: "success", items: ["أ", "ب", "ج"] }
];
states.forEach(s => console.log(render(s)));
~~~
