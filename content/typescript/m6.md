## أنواع جاهزة لتحويل الأنواع

توفر TypeScript **أدوات أنواع (Utility Types)** تصنع أنواعاً جديدة من أنواع موجودة، دون تكرار التعريف. لنأخذ هذا النوع:

```ts-error
interface User {
  id: number;
  name: string;
  email: string;
  age?: number;
}
```

## Partial: كل الخصائص اختيارية

مثالي لدوال **التحديث**، حيث يرسل المستخدم بعض الحقول فقط:

```ts
interface User { id: number; name: string; email: string }

function updateUser(user: User, changes: Partial<User>): User {
  return { ...user, ...changes };
}

const u: User = { id: 1, name: "وجدان", email: "w@mail.com" };
console.log(updateUser(u, { email: "new@mail.com" }));
```

```output
{"id":1,"name":"وجدان","email":"new@mail.com"}
```

## Required: كل الخصائص إلزامية

```ts
interface Config { host?: string; port?: number }

function start(config: Required<Config>) {
  console.log(`يعمل على ${config.host}:${config.port}`);
}

start({ host: "localhost", port: 3000 });
start({ host: "localhost" });
```

```output
ERR: سطر 8: Argument of type '{ host: string; }' is not assignable to parameter of type 'Required<Config>'.   Property 'port' is missing in type '{ host: string; }' but required in type 'Required<Config>'.
```

## Pick: اختيار بعض الخصائص

```ts
interface User { id: number; name: string; email: string; password: string }

type PublicUser = Pick<User, "id" | "name">;

const card: PublicUser = { id: 3, name: "ثامر" };
console.log(card);
```

```output
{"id":3,"name":"ثامر"}
```

## Omit: كل الخصائص ما عدا بعضها

```ts
interface User { id: number; name: string; email: string; password: string }

type NewUser = Omit<User, "id">;
type SafeUser = Omit<User, "password">;

const signup: NewUser = { name: "رزان", email: "r@mail.com", password: "secret" };
const shown: SafeUser = { id: 9, name: "رزان", email: "r@mail.com", password: "x" };
```

```output
ERR: سطر 7: Object literal may only specify known properties, and 'password' does not exist in type 'SafeUser'.
```

`NewUser` لنموذج التسجيل (المعرّف يولّده الخادم)، و `SafeUser` لما نرسله للواجهة دون كلمة المرور. ولاحظ الخطأ: `SafeUser` لا تقبل `password` أصلاً.

## الجدول

| الأداة | الناتج |
|---|---|
| `Partial<T>` | كل الخصائص اختيارية |
| `Required<T>` | كل الخصائص إلزامية |
| `Readonly<T>` | كل الخصائص للقراءة فقط |
| `Pick<T, K>` | الخصائص K فقط |
| `Omit<T, K>` | كل الخصائص ما عدا K |
| `ReturnType<F>` | نوع ما تُرجعه الدالة F |
| `Parameters<F>` | أنواع معاملات الدالة F كـ Tuple |
| `NonNullable<T>` | T بعد حذف null و undefined |

```ts
function createOrder(item: string, qty: number) {
  return { item, qty, createdAt: "2025-07-01" };
}

type Order = ReturnType<typeof createOrder>;
type Args = Parameters<typeof createOrder>;

const o: Order = createOrder("قلم", 3);
const args: Args = ["دفتر", 2];
console.log(o.item, args[1]);
```

```output
قلم 2
```

`ReturnType` مفيدة جداً عندما تُرجع دالة كائناً ولا تريد كتابة نوعه يدوياً مرتين.

## ملخص الدرس

- `Partial` للتحديثات الجزئية، و `Required` لفرض كل الحقول.
- `Pick` و `Omit` لاشتقاق أنواع أصغر من نوع كبير.
- `ReturnType` و `Parameters` لاستخراج الأنواع من الدوال.
- مصدر واحد للحقيقة: عدّل `User` فتتحدث كل الأنواع المشتقة منه.

## قاموس بمفاتيح وقيم محددة

`Record<K, V>` نوع كائن مفاتيحه من النوع `K` وقيمه من النوع `V`. مثالي للقواميس وجداول البحث:

```ts
const stock: Record<string, number> = {
  "قلم": 40,
  "دفتر": 12
};

stock["ممحاة"] = 5;
console.log(Object.keys(stock).length, stock["قلم"]);
```

```output
3 40
```

## القوة الحقيقية: مفاتيح من اتحاد

عندما تكون المفاتيح اتحاد حروفيات، تتأكد TypeScript من وجود **كل** المفاتيح:

```ts
type Status = "pending" | "shipped" | "delivered";

const labels: Record<Status, string> = {
  pending: "قيد الانتظار",
  shipped: "تم الشحن",
  delivered: "تم التسليم"
};

const colors: Record<Status, string> = {
  pending: "orange",
  shipped: "blue"
};

console.log(labels.shipped);
```

```output
ERR: سطر 9: Property 'delivered' is missing in type '{ pending: string; shipped: string; }' but required in type 'Record<Status, string>'.
```

نسيت حالة `delivered` في `colors`؟ خطأ ترجمة! وعند إضافة حالة جديدة للنوع `Status`، تدلك TypeScript على كل قاموس يجب تحديثه.

## قيم معقدة

```ts
type Role = "admin" | "editor";

interface Permissions {
  canDelete: boolean;
  canPublish: boolean;
}

const permissions: Record<Role, Permissions> = {
  admin: { canDelete: true, canPublish: true },
  editor: { canDelete: false, canPublish: true }
};

function can(role: Role, action: keyof Permissions): boolean {
  return permissions[role][action];
}

console.log(can("editor", "canDelete"));
console.log(can("admin", "canDelete"));
```

```output
false
true
```

## Record مقابل Map

| `Record<K, V>` | `Map<K, V>` |
|---|---|
| كائن عادي `{}` | صنف مدمج |
| مفاتيح نصية أو رقمية | مفاتيح من أي نوع |
| ممتاز لقواميس ثابتة معروفة المفاتيح | ممتاز لإضافة وحذف متكرر |
| يتحول لـ JSON مباشرة | يحتاج تحويلاً |

## ملخص الدرس

- `Record<K, V>` كائن مفاتيحه K وقيمه V.
- مع اتحاد حروفيات كمفاتيح، تفرض TypeScript وجود كل المفاتيح.
- مثالي لجداول الترجمة والإعدادات والصلاحيات.

## مجموعة ثوابت باسم

**التعداد (enum)** يعطي أسماء واضحة لمجموعة قيم ثابتة مرتبطة:

```ts
enum Direction {
  Up,
  Down,
  Left,
  Right
}

const move: Direction = Direction.Left;
console.log(move);
console.log(Direction[move]);
```

```output
2
Left
```

التعداد الرقمي يبدأ من `0` افتراضياً، ويمكنك أيضاً قراءة الاسم من الرقم `Direction[2]`.

## التعداد النصي (الأوضح)

```ts
enum OrderStatus {
  Pending = "PENDING",
  Paid = "PAID",
  Shipped = "SHIPPED"
}

function describe(s: OrderStatus): string {
  switch (s) {
    case OrderStatus.Pending: return "بانتظار الدفع";
    case OrderStatus.Paid: return "مدفوع";
    case OrderStatus.Shipped: return "في الطريق";
  }
}

const status = OrderStatus.Paid;
console.log(status, describe(status));
```

```output
PAID مدفوع
```

القيم النصية أسهل في التتبع: في قاعدة البيانات وسجلات الأخطاء ترى `"PAID"` بدل الرقم `1` الغامض.

## enum ليس نوعاً فقط

على عكس بقية ما تعلمناه، الـ enum **يبقى في JavaScript** بعد الترجمة ككائن حقيقي:

```js
var OrderStatus;
(function (OrderStatus) {
  OrderStatus["Pending"] = "PENDING";
  OrderStatus["Paid"] = "PAID";
})(OrderStatus || (OrderStatus = {}));
console.log(Object.values(OrderStatus));
```

```output
["PENDING","PAID"]
```

## البديل الحديث: اتحاد الحروفيات

كثير من الفرق تفضّل اليوم اتحاد الحروفيات مع `as const` بدل enum:

```ts
const STATUS = {
  Pending: "PENDING",
  Paid: "PAID",
  Shipped: "SHIPPED"
} as const;

type Status = typeof STATUS[keyof typeof STATUS];

function isFinal(s: Status): boolean {
  return s === STATUS.Shipped;
}

console.log(isFinal("SHIPPED"), isFinal(STATUS.Pending));
```

```output
true false
```

| enum | اتحاد حروفيات / as const |
|---|---|
| صيغة خاصة بـ TypeScript | JavaScript عادية + أنواع |
| يولّد كوداً عند الترجمة | لا يولّد شيئاً إضافياً |
| يجب استخدام `Status.Paid` | يقبل النص `"PAID"` مباشرة |

> 💡 كلاهما صحيح ومنتشر. ستجد enum كثيراً في Angular والمشاريع القديمة، والاتحادات أكثر في مشاريع React الحديثة.

## ملخص الدرس

- `enum` يسمّي مجموعة ثوابت مرتبطة، والنصي أوضح من الرقمي.
- الـ enum يبقى في JavaScript ككائن بعد الترجمة.
- البديل الشائع: كائن `as const` واتحاد حروفيات مستخرج منه.

--- exercise
1. عرّف `enum Priority` نصياً بالقيم: `Low = "low"` و `Medium = "medium"` و `High = "high"`.
2. اكتب دالة `badge(p: Priority): string` تُرجع `🟢 منخفضة` أو `🟡 متوسطة` أو `🔴 عالية`.
3. اكتب دالة `sortByPriority` ترتب مصفوفة مهام تنازلياً حسب الأولوية (عالية أولاً).

~~~starter

  { title: "تحديث الموقع", priority: Priority.Low },
  { title: "إصلاح خطأ الدفع", priority: Priority.High },
  { title: "كتابة التقرير", priority: Priority.Medium }
];

  console.log(`${badge(t.priority)} ${t.title}`);

~~~
~~~expected
🔴 عالية إصلاح خطأ الدفع
🟡 متوسطة كتابة التقرير
🟢 منخفضة تحديث الموقع
~~~
~~~solution
enum Priority {
  Low = "low",
  Medium = "medium",
  High = "high"
}

function badge(p: Priority): string {
  switch (p) {
    case Priority.Low: return "🟢 منخفضة";
    case Priority.Medium: return "🟡 متوسطة";
    case Priority.High: return "🔴 عالية";
  }
}

const weight: Record<Priority, number> = { low: 1, medium: 2, high: 3 };

function sortByPriority<T extends { priority: Priority }>(items: T[]): T[] {
  return [...items].sort((a, b) => weight[b.priority] - weight[a.priority]);
}

const tasks = [
  { title: "تحديث الموقع", priority: Priority.Low },
  { title: "إصلاح خطأ الدفع", priority: Priority.High },
  { title: "كتابة التقرير", priority: Priority.Medium }
];

for (const t of sortByPriority(tasks)) {
  console.log(`${badge(t.priority)} ${t.title}`);
}
~~~

## الأنواع من الأنواع

في هذا الدرس نجمع أداتين تحوّلان الأنواع: `keyof` لأسماء الخصائص، و `typeof` لاستخراج نوع من قيمة موجودة.

## keyof: أسماء الخصائص كنوع

```ts
interface Settings {
  theme: string;
  fontSize: number;
  notifications: boolean;
}

type SettingKey = keyof Settings;

function describeKey(key: SettingKey): string {
  return `الإعداد: ${key}`;
}

console.log(describeKey("fontSize"));
console.log(describeKey("language"));
```

```output
ERR: سطر 14: Argument of type '"language"' is not assignable to parameter of type 'keyof Settings'.
```

`keyof Settings` يساوي `"theme" | "fontSize" | "notifications"`، وعند إضافة خاصية للواجهة يتحدث تلقائياً.

## typeof: نوع من قيمة

`typeof` في سياق الأنواع تستخرج نوع متغير موجود:

```ts
const defaultUser = {
  name: "ضيف",
  language: "ar",
  points: 0
};

type User = typeof defaultUser;

const u: User = { name: "عهود", language: "en", points: 120 };
console.log(u.points);

const bad: User = { name: "ناقص" };
```

```output
ERR: سطر 12: Type '{ name: string; }' is missing the following properties from type '{ name: string; language: string; points: number; }': language, points
```

مفيدة عندما يكون لديك كائن إعدادات أو بيانات افتراضية، وتريد نوعه دون كتابته مرتين.

## الدمج: keyof typeof

النمط الأشهر: مفاتيح كائن موجود كنوع:

```ts
const translations = {
  hello: "مرحباً",
  bye: "مع السلامة",
  thanks: "شكراً"
};

type TranslationKey = keyof typeof translations;

function t(key: TranslationKey): string {
  return translations[key];
}

console.log(t("thanks"));
console.log(t("welcome"));
```

```output
ERR: سطر 14: Argument of type '"welcome"' is not assignable to parameter of type '"hello" | "bye" | "thanks"'.
```

دالة الترجمة `t` لا تقبل إلا مفاتيح موجودة فعلاً، والمحرر يقترحها عليك. هكذا تعمل مكتبات الترجمة الاحترافية.

## الأنواع المعيّنة (Mapped Types)

`keyof` تفتح باباً متقدماً: إنشاء نوع بالمرور على خصائص نوع آخر. هكذا بُنيت `Partial` نفسها:

```ts
type MyPartial<T> = { [K in keyof T]?: T[K] };
type Flags<T> = { [K in keyof T]: boolean };

interface Form { name: string; email: string }

const draft: MyPartial<Form> = { name: "رامي" };
const touched: Flags<Form> = { name: true, email: false };
console.log(draft.name, touched.email);
```

```output
رامي false
```

`[K in keyof T]` يعني: لكل خاصية K في T. و `Flags<Form>` نوع يحدد لكل حقل في النموذج هل لمسه المستخدم، وهو نمط حقيقي في مكتبات النماذج.

## ملخص الدرس

- `keyof T` اتحاد أسماء خصائص T.
- `typeof value` (في سياق الأنواع) تستخرج نوع قيمة موجودة.
- `keyof typeof obj` مفاتيح كائن حقيقي كنوع.
- `{ [K in keyof T]: ... }` لإنشاء أنواع معيّنة جديدة.
