## الأصناف بأنواع

الأصناف في TypeScript هي أصناف JavaScript نفسها، مع إضافة **أنواع للخصائص** و**محددات الوصول**:

```ts
class Account {
  owner: string;
  private balance: number;

  constructor(owner: string, initial: number) {
    this.owner = owner;
    this.balance = initial;
  }

  deposit(amount: number): void {
    if (amount <= 0) throw new Error("مبلغ غير صالح");
    this.balance += amount;
  }

  getBalance(): number {
    return this.balance;
  }
}

const acc = new Account("ليان", 100);
acc.deposit(50);
console.log(`${acc.owner}: ${acc.getBalance()}`);
console.log(acc.balance);
```

```output
ERR: سطر 23: Property 'balance' is private and only accessible within class 'Account'.
```

## محددات الوصول

| المحدد | يمكن الوصول إليه من |
|---|---|
| `public` (الافتراضي) | أي مكان |
| `private` | داخل الصنف فقط |
| `protected` | داخل الصنف والأصناف التي ترثه |
| `readonly` | قراءة فقط بعد الإنشاء |

> 💡 `private` في TypeScript فحص وقت الترجمة فقط. للخصوصية الحقيقية وقت التشغيل أيضاً استخدم `#balance` الخاصة بـ JavaScript.

## اختصار المُنشئ (Parameter Properties)

تكرار `this.x = x` متعب. ضع المحدد قبل المعامل مباشرة:

```ts
class Product {
  constructor(
    public readonly id: number,
    public name: string,
    private cost: number
  ) {}

  priceWithMargin(margin: number): number {
    return Math.round(this.cost * (1 + margin));
  }
}

const p = new Product(1, "طاولة", 300);
console.log(p.name, p.priceWithMargin(0.25));
p.id = 2;
```

```output
ERR: سطر 15: Cannot assign to 'id' because it is a read-only property.
```

`public readonly id: number` في المُنشئ يعلن الخاصية ويهيئها في خطوة واحدة.

## الوراثة و protected

```ts
class Employee {
  constructor(public name: string, protected salary: number) {}

  info(): string {
    return `${this.name}`;
  }
}

class Manager extends Employee {
  constructor(name: string, salary: number, private bonus: number) {
    super(name, salary);
  }

  totalPay(): number {
    return this.salary + this.bonus;
  }
}

const m = new Manager("فهد", 15000, 3000);
console.log(m.info(), m.totalPay());
console.log(m.salary);
```

```output
ERR: سطر 21: Property 'salary' is protected and only accessible within class 'Employee' and its subclasses.
```

الصنف الابن يصل إلى `salary` لأنها `protected`، أما الكود الخارجي فلا.

## implements: الصنف يلتزم بواجهة

```ts
interface Shape {
  area(): number;
  name: string;
}

class Square implements Shape {
  name = "مربع";
  constructor(private side: number) {}
  area() { return this.side ** 2; }
}

class Circle implements Shape {
  name = "دائرة";
  constructor(private r: number) {}
  area() { return Math.round(Math.PI * this.r ** 2); }
}

const shapes: Shape[] = [new Square(4), new Circle(3)];
shapes.forEach(s => console.log(`${s.name}: ${s.area()}`));
```

```output
مربع: 16
دائرة: 28
```

إذا نسي صنف تنفيذ `area()` يرفضه المترجم.

## ملخص الدرس

- الأصناف بأنواع للخصائص والمعاملات وقيم الإرجاع.
- `public` و `private` و `protected` و `readonly` للتحكم بالوصول.
- `constructor(public name: string)` يعلن الخاصية ويهيئها معاً.
- `implements Interface` يُلزم الصنف بشكل محدد.

--- exercise
أنشئ صنف `Counter`:

- خاصية `private count` تبدأ من `0`.
- خاصية `readonly name` نصية تُمرر في المُنشئ (استخدم الاختصار).
- طريقة `increment(by: number = 1): this` تزيد العدّاد وتُرجع `this` لتسمح بالسلسلة.
- طريقة `value(): number`.

~~~starter
// الصنف هنا

~~~
~~~expected
الزيارات: 7
~~~
~~~solution
class Counter {
  private count = 0;

  constructor(public readonly name: string) {}

  increment(by: number = 1): this {
    this.count += by;
    return this;
  }

  value(): number {
    return this.count;
  }
}

const visits = new Counter("الزيارات");
visits.increment().increment(5).increment();
console.log(`${visits.name}: ${visits.value()}`);
~~~

## صنف لا يُنشأ منه مباشرة

**الصنف المجرد (abstract)** قالب ناقص عمداً: يحدد ما يجب على الأبناء تنفيذه، ويوفر كوداً مشتركاً، لكن لا يمكن إنشاء كائن منه مباشرة.

```ts
abstract class Notification {
  constructor(protected recipient: string) {}

  abstract channel(): string;
  abstract format(message: string): string;

  send(message: string): void {
    console.log(`[${this.channel()}] إلى ${this.recipient}: ${this.format(message)}`);
  }
}

class EmailNotification extends Notification {
  channel() { return "بريد"; }
  format(message: string) { return `<p>${message}</p>`; }
}

class SmsNotification extends Notification {
  channel() { return "SMS"; }
  format(message: string) { return message.slice(0, 20); }
}

const list: Notification[] = [
  new EmailNotification("a@mail.com"),
  new SmsNotification("0500000000")
];
list.forEach(n => n.send("تم تأكيد طلبك رقم 1234 بنجاح"));
```

```output
[بريد] إلى a@mail.com: <p>تم تأكيد طلبك رقم 1234 بنجاح</p>
[SMS] إلى 0500000000: تم تأكيد طلبك رقم 12
```

- `abstract channel(): string;` طريقة بلا جسم، **يجب** على كل ابن تنفيذها.
- `send` كود مشترك يستخدم الطرق المجردة دون أن يعرف تفاصيلها.

## لا يمكن إنشاؤه مباشرة

```ts
abstract class Base {
  abstract run(): void;
}

const b = new Base();
```

```output
ERR: سطر 5: Cannot create an instance of an abstract class.
```

## والابن يجب أن ينفّذ كل شيء

```ts
abstract class Base {
  abstract run(): void;
  abstract stop(): void;
}

class Task extends Base {
  run() { console.log("يعمل"); }
}
```

```output
ERR: سطر 6: Non-abstract class 'Task' does not implement inherited abstract member stop from class 'Base'.
```

## abstract class أم interface؟

| abstract class | interface |
|---|---|
| يمكن أن تحتوي كوداً مشتركاً | شكل فقط بلا كود |
| وراثة واحدة `extends` | تنفيذ عدة واجهات `implements` |
| موجودة وقت التشغيل | تختفي عند الترجمة |
| مناسبة لـ "نوع من" بسلوك مشترك | مناسبة لـ "قادر على" |

> 💡 هذا النمط يسمى **Template Method**: الأب يحدد خطوات العملية، والأبناء يملؤون التفاصيل. ستراه في أطر العمل مثل NestJS و Angular.

## ملخص الدرس

- `abstract class` قالب لا يُنشأ منه مباشرة.
- `abstract method()` طريقة يجب على كل ابن تنفيذها.
- الأب يوفر كوداً مشتركاً يستخدم الطرق المجردة.
- استخدم الواجهة للشكل فقط، والصنف المجرد عند وجود سلوك مشترك.

--- exercise
1. أنشئ صنفاً مجرداً `Report` فيه: طريقة مجردة `title(): string`، وطريقة مجردة `rows(): string[]`، وطريقة عادية `render(): string` تُرجع العنوان ثم كل صف في سطر جديد مسبوقاً بـ `- `.
2. أنشئ `SalesReport` ترث منه: العنوان `تقرير المبيعات`، والصفوف `["يناير: 1200", "فبراير: 950"]`.

~~~starter
// الأصناف هنا

const report: Report = new SalesReport();
console.log(report.render());
~~~
~~~expected
تقرير المبيعات
- يناير: 1200
- فبراير: 950
~~~
~~~solution
abstract class Report {
  abstract title(): string;
  abstract rows(): string[];

  render(): string {
    return [this.title(), ...this.rows().map(r => `- ${r}`)].join("\n");
  }
}

class SalesReport extends Report {
  title() {
    return "تقرير المبيعات";
  }
  rows() {
    return ["يناير: 1200", "فبراير: 950"];
  }
}

const report: Report = new SalesReport();
console.log(report.render());
~~~

## تقسيم المشروع إلى وحدات

مثل JavaScript الحديثة، كل ملف TypeScript **وحدة (Module)** تُصدّر وتستورد. والإضافة الجديدة: تصدير **الأنواع** واستيرادها أيضاً.

```ts-error
// ملف models/user.ts
export interface User {
  id: number;
  name: string;
}

export type Role = "admin" | "member";

export function createUser(name: string): User {
  return { id: Date.now(), name };
}
```

```ts-error
// ملف app.ts
import { createUser } from "./models/user";
import type { User, Role } from "./models/user";

const u: User = createUser("نجلاء");
const role: Role = "admin";
```

`import type` يوضح أن المستورد **نوع فقط**، فيُحذف تماماً عند الترجمة. هذا أوضح للقارئ، ويمنع تحميل ملفات بلا داعٍ.

## ملفات التعريف .d.ts

ماذا لو استخدمت مكتبة مكتوبة بـ JavaScript؟ لا توجد أنواع! الحل: **ملف تعريف (Declaration File)** امتداده `.d.ts`، يصف الأنواع فقط دون أي كود تنفيذي:

```ts-error
// ملف price-utils.d.ts
export declare function formatPrice(value: number, currency?: string): string;
export declare const VERSION: string;
```

## مكتبات npm و DefinitelyTyped

- مكتبات حديثة كثيرة **تتضمن** ملفات `.d.ts` بداخلها، مثل axios و zod.
- لغيرها، يوجد مستودع مجتمعي ضخم اسمه **DefinitelyTyped**، وتثبت منه الأنواع هكذا:

```text
npm install --save-dev @types/node
npm install --save-dev @types/express
npm install --save-dev @types/lodash
```

> 💡 إذا ظهر لك الخطأ `Could not find a declaration file for module 'x'`، جرّب أولاً `npm i -D @types/x`.

## declare: وصف ما هو موجود أصلاً

الكلمة `declare` تخبر TypeScript: "هذا الشيء موجود وقت التشغيل، ثق بي ولا تولّد له كوداً". مثلاً متغير عام يضيفه سكربت خارجي في الصفحة:

```ts
(globalThis as any).APP_CONFIG = { version: "2.1.0", debug: false };

declare const APP_CONFIG: { version: string; debug: boolean };

console.log(`الإصدار ${APP_CONFIG.version}`);
console.log(APP_CONFIG.debug ? "وضع التطوير" : "وضع الإنتاج");
```

```output
الإصدار 2.1.0
وضع الإنتاج
```

بدون سطر `declare` لكانت TypeScript لا تعرف `APP_CONFIG` فترفض الكود.

## توسيع الأنواع الموجودة

```ts
interface Array<T> {
  last(): T | undefined;
}

Array.prototype.last = function () {
  return this[this.length - 1];
};

console.log([3, 7, 9].last());
```

```output
9
```

بفضل **دمج الواجهات** أضفنا طريقة لنوع `Array` المدمج. (للتوضيح فقط: تعديل النماذج المدمجة ليس ممارسة جيدة في مشاريعك.)

## ملخص الدرس

- `export` و `import` للأنواع كما للقيم، و `import type` للأنواع فقط.
- ملفات `.d.ts` تصف أنواع كود JavaScript دون تنفيذ.
- `@types/اسم-المكتبة` من DefinitelyTyped لأنواع المكتبات القديمة.
- `declare` لوصف ما هو موجود وقت التشغيل.
