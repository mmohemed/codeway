=== lesson
## دالة واحدة لكل الأنواع

اكتب دالة تُرجع أول عنصر في مصفوفة. بدون Generics لديك خياران سيئان:

```ts
function firstAny(arr: any[]): any {
  return arr[0];
}

const n = firstAny([10, 20]);
console.log(n.toUpperCase());
```

```output
ERR: TypeError: n.toUpperCase is not a function
```

مع `any` ضاعت معلومة النوع، فمرّ خطأ واضح وانهار البرنامج. والخيار الآخر كتابة دالة لكل نوع: `firstNumber` و `firstString`... وهذا تكرار.

## الحل: Generics

**المعامل النوعي (Type Parameter)** `<T>` متغير يمثل **نوعاً** يُحدد عند الاستدعاء:

```ts
function first<T>(arr: T[]): T | undefined {
  return arr[0];
}

const n = first([10, 20]);
const s = first(["أ", "ب"]);

console.log(n?.toFixed(1));
console.log(s?.toUpperCase());
```

```output
10.0
أ
```

- `<T>` بعد اسم الدالة يعلن معاملاً نوعياً.
- عند `first([10, 20])` استنتجت TypeScript أن `T = number`، فالنتيجة `number | undefined`.
- والاسم `T` عرف متبع (من Type)، ويمكن استخدام أي اسم.

## الخطأ يُكتشف الآن

```ts
function first<T>(arr: T[]): T | undefined {
  return arr[0];
}

const n = first([10, 20]);
console.log(n?.toUpperCase());
```

```output
ERR: سطر 6: Property 'toUpperCase' does not exist on type 'number'.
```

## أكثر من معامل نوعي

```ts
function pair<K, V>(key: K, value: V): [K, V] {
  return [key, value];
}

function mapArray<T, R>(items: T[], fn: (item: T) => R): R[] {
  const result: R[] = [];
  for (const item of items) result.push(fn(item));
  return result;
}

const p = pair("العمر", 30);
const lengths = mapArray(["قلم", "حاسوب"], w => w.length);
console.log(p, lengths);
```

```output
["العمر",30] [3,5]
```

`mapArray` هي بالضبط كيف تُعرَّف `Array.prototype.map` في TypeScript: من مصفوفة `T` ودالة من `T` إلى `R` تنتج مصفوفة `R`.

## تحديد النوع صراحة

عادة تستنتج TypeScript الأنواع، لكن يمكنك تحديدها:

```ts
function emptyList<T>(): T[] {
  return [];
}

const names = emptyList<string>();
names.push("نوال");
console.log(names);
```

```output
["نوال"]
```

هنا لا يوجد وسيط تستنتج منه TypeScript، فحددنا `<string>` بأنفسنا.

## ملخص الدرس

- Generics تكتب كوداً واحداً يعمل مع أنواع مختلفة دون فقدان معلومة النوع.
- `function f<T>(x: T): T` والنوع يُستنتج عند الاستدعاء غالباً.
- يمكن استخدام عدة معاملات نوعية `<K, V>`.
- `f<string>()` لتحديد النوع صراحة عند الحاجة.

--- exercise
اكتب دالة عامة `last<T>` تستقبل مصفوفة من `T` وتُرجع آخر عنصر (أو `undefined` إذا كانت فارغة)، ودالة عامة `groupBy<T>` تستقبل مصفوفة ودالة تُرجع مفتاحاً نصياً لكل عنصر، وتُرجع `Record<string, T[]>` تجمع العناصر حسب المفتاح.

~~~starter
function last(arr) {
}

function groupBy(items, keyFn) {
}

console.log(last([1, 2, 3]));
console.log(last<string>([]));
const words = ["تفاح", "توت", "موز", "مانجو"];
console.log(groupBy(words, w => w[0]));
~~~
~~~expected
3
undefined
{"ت":["تفاح","توت"],"م":["موز","مانجو"]}
~~~
~~~solution
function last<T>(arr: T[]): T | undefined {
  return arr[arr.length - 1];
}

function groupBy<T>(items: T[], keyFn: (item: T) => string): Record<string, T[]> {
  const groups: Record<string, T[]> = {};
  for (const item of items) {
    const key = keyFn(item);
    (groups[key] ??= []).push(item);
  }
  return groups;
}

console.log(last([1, 2, 3]));
console.log(last<string>([]));
const words = ["تفاح", "توت", "موز", "مانجو"];
console.log(groupBy(words, w => w[0]));
~~~

## أنواع تحمل أنواعاً أخرى

كما تكون الدوال عامة، يمكن للواجهات والأنواع أن تكون عامة: **قوالب** تُملأ بنوع عند الاستخدام. وأنت تستخدمها بالفعل: `Array<T>` و `Promise<T>` و `Map<K, V>`.

## استجابة API عامة

كل الاستجابات من الخادم لها نفس الغلاف، لكن البيانات بداخلها تختلف:

```ts
interface ApiResponse<T> {
  success: boolean;
  data: T;
  error?: string;
}

interface User { id: number; name: string }
interface Product { title: string; price: number }

const userRes: ApiResponse<User> = {
  success: true,
  data: { id: 1, name: "رهف" }
};

const listRes: ApiResponse<Product[]> = {
  success: true,
  data: [{ title: "مصباح", price: 90 }]
};

console.log(userRes.data.name);
console.log(listRes.data[0].price);
```

```output
رهف
90
```

واجهة واحدة `ApiResponse<T>` تخدم كل أنواع البيانات، والمحرر يعرف أن `userRes.data` من نوع `User` بالضبط.

## صنف عام: مخزن بيانات

```ts
class Store<T> {
  private items: T[] = [];

  add(item: T): void {
    this.items.push(item);
  }

  find(predicate: (item: T) => boolean): T | undefined {
    return this.items.find(predicate);
  }

  get count(): number {
    return this.items.length;
  }
}

interface Task { title: string; done: boolean }

const tasks = new Store<Task>();
tasks.add({ title: "مراجعة الدرس", done: false });
tasks.add({ title: "حل التمرين", done: true });

console.log(tasks.count);
console.log(tasks.find(t => t.done)?.title);
```

```output
2
حل التمرين
```

## القيم الافتراضية للمعاملات النوعية

```ts
interface Paginated<T, Meta = { page: number; total: number }> {
  items: T[];

const page: Paginated<string> = {
```


## نوع النتيجة: نجاح أو فشل

نمط احترافي يجمع Generics مع الاتحاد المميَّز:

```ts
type Result<T, E = string> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function parseAge(input: string): Result<number> {
  const n = Number(input);
  if (Number.isNaN(n) || n < 0) return { ok: false, error: `قيمة غير صالحة: ${input}` };
  return { ok: true, value: n };
}

for (const input of ["30", "abc"]) {
  const r = parseAge(input);
  console.log(r.ok ? `العمر ${r.value}` : r.error);
}
```

```output
العمر 30
قيمة غير صالحة: abc
```

بدلاً من رمي الأخطاء، تُرجع الدالة نتيجة تُجبر المستدعي على التحقق من `ok` قبل الوصول إلى `value`.

## ملخص الدرس

- الواجهات والأنواع والأصناف يمكن أن تكون عامة: `interface Box<T>`.
- `ApiResponse<T>` نمط شائع لتوحيد شكل الاستجابات.
- المعامل النوعي يمكن أن يكون له افتراضي: `<T, M = Default>`.
- `Result<T>` يجمع Generics مع الاتحاد المميَّز.

~~~solution
interface Cache<T> {
  get(key: string): T | undefined;
  set(key: string, value: T): void;
  size: number;
}

class MemoryCache<T> implements Cache<T> {
  private data = new Map<string, T>();

  get(key: string): T | undefined {
    return this.data.get(key);
  }

  set(key: string, value: T): void {
    this.data.set(key, value);
  }

  get size(): number {
    return this.data.size;
  }
}

const prices = new MemoryCache<number>();
prices.set("قهوة", 12);
prices.set("شاي", 8);
console.log(prices.get("قهوة"));
console.log(prices.get("عصير"));
console.log(prices.size);
~~~

## ليس أي نوع

أحياناً تحتاج الدالة العامة أن يكون للنوع خصائص معينة. هذه الدالة تريد خاصية `length`:

```ts
function longest<T>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}
```

```output
ERR: سطر 2: Property 'length' does not exist on type 'T'. | سطر 2: Property 'length' does not exist on type 'T'.
```

`T` قد يكون أي شيء، حتى رقماً ليس له `length`. الحل: **القيد (Constraint)** بالكلمة `extends`:

```ts
function longest<T extends { length: number }>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}

console.log(longest("قصير", "أطول بكثير"));
console.log(longest([1, 2], [1, 2, 3]));
console.log(longest(10, 20));
```

```output
ERR: سطر 7: Argument of type 'number' is not assignable to parameter of type '{ length: number; }'.
```

- `T extends { length: number }` تعني: T أي نوع بشرط أن يملك `length` رقمية.
- النصوص والمصفوفات تُقبل، والأرقام تُرفض.

## keyof مع القيود: الوصول الآمن للخصائص

```ts
function getProp<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const book = { title: "رحلة", pages: 220, available: true };

const t = getProp(book, "title");
const p = getProp(book, "pages");
console.log(t.toUpperCase(), p + 1);

getProp(book, "price");
```

```output
ERR: سطر 11: Argument of type '"price"' is not assignable to parameter of type '"title" | "pages" | "available"'.
```

- `keyof T` اتحاد أسماء خصائص T: `"title" | "pages" | "available"`.
- `K extends keyof T` تعني: K يجب أن يكون اسم خاصية موجودة فعلاً.
- `T[K]` نوع تلك الخاصية بالضبط: `title` تُرجع `string` و `pages` تُرجع `number`.

## القيد بواجهة

```ts
interface HasId {
  id: number;
}

function findById<T extends HasId>(items: T[], id: number): T | undefined {
  return items.find(item => item.id === id);
}

const users = [{ id: 1, name: "حسن" }, { id: 2, name: "أروى" }];
const orders = [{ id: 7, total: 300 }];

console.log(findById(users, 2)?.name);
console.log(findById(orders, 7)?.total);
```

```output
أروى
300
```

دالة واحدة تعمل مع أي نوع له `id`، وتُرجع النوع الكامل: `findById(users, 2)` تُرجع كائناً فيه `name`.

## ملخص الدرس

- `T extends Shape` يقيّد المعامل النوعي بأنواع تملك شكلاً معيناً.
- `keyof T` اتحاد أسماء خصائص T.
- `K extends keyof T` و `T[K]` للوصول الآمن والدقيق لأي خاصية.
- القيود تجعل الدوال العامة مرنة وآمنة معاً.
