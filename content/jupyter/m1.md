## ما هو Jupyter؟

**Jupyter Notebook** (الدفتر) بيئة تجمع في ملف واحد: **الكود** و **نتائجه** (جداول ورسوم) و **الشرح** المكتوب. لهذا أصبح الأداة اليومية لمحللي البيانات وعلماء البيانات والباحثين: تكتب خطوة، تنفذها، ترى النتيجة فوراً، ثم تكمل.

الاسم من ثلاث لغات: **Ju**lia و **Pyt**hon و **R**. والملف بامتداد `.ipynb` (IPython Notebook).

| | سكربت `.py` | دفتر `.ipynb` |
|---|---|---|
| التنفيذ | كله مرة واحدة من البداية | خلية خلية، وبأي ترتيب |
| النتائج | في الطرفية ثم تختفي | محفوظة تحت كل خلية |
| الشرح | تعليقات فقط | نصوص منسقة وعناوين وصور |
| مناسب لـ | البرامج والتطبيقات | الاستكشاف والتحليل والتقارير |

## التثبيت والتشغيل

```bash
pip install jupyterlab
jupyter lab
```

يفتح المتصفح على `http://localhost:8888` بواجهة **JupyterLab**:

- **الشريط الأيسر**: مستعرض الملفات، والنوى العاملة، وجدول المحتويات.
- **منطقة العمل**: الدفاتر والملفات في تبويبات، يمكن وضعها جنباً إلى جنب.
- **المشغّل (Launcher)**: إنشاء دفتر جديد، أو طرفية، أو ملف نصي.

> 💡 **JupyterLab** هي الواجهة الحديثة الموصى بها. الواجهة الكلاسيكية تُشغَّل بـ `jupyter notebook`. وبدائل شائعة: **VS Code** (يفتح ملفات `.ipynb` مباشرة)، و **Google Colab** في المتصفح دون تثبيت (درس قادم)، أو تثبيت **Anaconda** الذي يتضمن Jupyter ومكتبات البيانات معاً.

## النواة (Kernel)

الدفتر مجرد واجهة. التنفيذ الفعلي تقوم به **النواة**: عملية Python تعمل في الخلفية وتحتفظ **بكل المتغيرات** في ذاكرتها بين الخلايا.

- **Restart Kernel**: يمسح كل المتغيرات ويبدأ من جديد.
- **Interrupt**: يوقف خلية عالقة (حلقة لا تنتهي).
- **Restart & Run All**: إعادة التشغيل ثم تنفيذ كل الخلايا بالترتيب. **افعلها قبل مشاركة أي دفتر**.

## الخلايا والتنفيذ

في هذه الدورة تكتب الدفتر كنص، وكل خلية تبدأ بسطر `# %%`. هذه صيغة حقيقية (Percent format) يفهمها **VS Code** و **Jupytext** وتتحول إلى `.ipynb`. وتعمل الخلايا هنا بـ **IPython الحقيقي**، المحرك نفسه الذي تحت Jupyter:

```python
# %%
price = 120
qty = 3
# %%
total = price * qty
total
# %%
round(total * 1.15, 2)
```

```output
In [1]:
In [2]:
Out[2]: 360
In [3]:
Out[3]: 414.0
```

- `In [n]`: رقم التنفيذ. يزداد مع **كل** تنفيذ لأي خلية، وليس رقم الخلية في الصفحة.
- `Out[n]`: قيمة **آخر سطر** في الخلية تُعرض تلقائياً، دون `print`.
- كل الخلايا تتشارك نفس المتغيرات (`total` من الخلية الثانية متاح في الثالثة).

## خطر الحالة المخفية

لأنك تستطيع تنفيذ الخلايا بأي ترتيب، قد يصل الدفتر لحالة **لا تطابق ما تراه**: حذفت خلية لكن متغيرها ما زال في الذاكرة، أو عدّلت خلية سابقة ولم تُعد تنفيذ ما بعدها.

```python
# %%
discount = 0.10
# %%
price = 200
final = price * (1 - discount)
final
# %%
discount = 0.50
# %%
final
```

```output
In [1]:
In [2]:
Out[2]: 180.0
In [3]:
In [4]:
Out[4]: 180.0
```

`final` ما زال 180 رغم أننا غيّرنا الخصم إلى 50%، لأن الخلية التي تحسبه لم تُنفَّذ من جديد. في Jupyter الحقيقي قد ترى أرقام `In [n]` غير متسلسلة (مثل 7 ثم 3 ثم 12)، وهذا إنذار: **أعد تشغيل النواة ونفّذ الكل**.

## خلايا Markdown

الدفتر الجيد ليس كوداً فقط: هو **تقرير** يشرح السؤال والطريقة والاستنتاج. خلايا **Markdown** تكتب فيها نصاً منسقاً. في صيغة النص تبدأ بـ `# %% [markdown]` وكل سطر فيها يبدأ بـ `# `:

```python
# %% [markdown]
# # Monthly sales report
# Source: **orders.csv**, first half of 2024.
#
# ## Questions
# 1. Which city brings the most revenue?
# 2. Which product sells the most units?
# %%
import pandas as pd
orders = pd.read_csv("orders.csv")
orders["total"] = orders["qty"] * orders["unit_price"]
orders.groupby("city")["total"].sum().idxmax()
```

```output
# Monthly sales report
Source: **orders.csv**, first half of 2024.

## Questions
1. Which city brings the most revenue?
2. Which product sells the most units?
In [1]:
Out[1]: 'Jeddah'
```

اضغط **«شغّل المثال»** لترى خلية Markdown منسقة كما في Jupyter.

### صيغة Markdown

| تكتب | تظهر |
|---|---|
| `# عنوان` / `## فرعي` | عناوين بأحجام |
| `**غامق**` / `*مائل*` | **غامق** / *مائل* |
| `- عنصر` أو `1. عنصر` | قوائم |
| `` `code` `` | كود داخل السطر |
| `[نص](https://...)` | رابط |
| `![وصف](image.png)` | صورة |
| `$x^2 + y^2$` | معادلة رياضية (LaTeX) |
| `> اقتباس` | اقتباس |

## الأوامر السحرية (Magics)

أوامر خاصة بـ IPython/Jupyter تبدأ بـ `%` (للسطر) أو `%%` (للخلية كاملة). ليست Python، لكنها تختصر مهام شائعة:

```python
# %%
items = list(range(100_000))
fast = %timeit -o -q -n 20 sum(items)
slow = %timeit -o -q -n 20 [x for x in items if x > -1]
print("sum() أسرع؟", fast.best < slow.best)
# %%
name = "CodeWay"
year = 2025
%who
# %%
%%writefile notes.txt
Jupyter magics are handy.
Second line.
# %%
print(open("notes.txt").read().splitlines())
```

```output
In [1]:
sum() أسرع؟ True
In [2]:
fast	 items	 name	 slow	 year	 
In [3]:
Writing notes.txt
In [4]:
['Jupyter magics are handy.', 'Second line.']
```

| الأمر | الوظيفة |
|---|---|
| `%timeit` | قياس سرعة سطر بتكرار ذكي (و `-o` لحفظ النتيجة) |
| `%%time` | زمن تنفيذ الخلية كاملة مرة واحدة |
| `%who` / `%whos` | المتغيرات الموجودة في الذاكرة |
| `%%writefile name` | حفظ محتوى الخلية في ملف |
| `%run script.py` | تشغيل سكربت داخل الدفتر |
| `%load_ext autoreload` | إعادة تحميل وحداتك تلقائياً عند تعديلها |
| `%lsmagic` | قائمة كل الأوامر السحرية |
| `!pip install pandas` | تنفيذ أمر طرفية (علامة التعجب) |

(`!` لأوامر الطرفية تعمل في Jupyter و Colab، لكنها لا تعمل في متصفح هذه المنصة لعدم وجود نظام تشغيل حقيقي.)

## Out و _ و display

```python
# %%
10 * 5
# %%
"hello".upper()
# %%
print(Out[1] + 1, "|", _)
# %%
import pandas as pd
df = pd.DataFrame({"a": [1, 2], "b": [3, 4]})
display(df)
display(df.sum())
```

```output
In [1]:
Out[1]: 50
In [2]:
Out[2]: 'HELLO'
In [3]:
51 | HELLO
In [4]:
   a  b
0  1  3
1  2  4
a    3
b    7
dtype: int64
```

- `Out[n]` قاموس بكل النتائج السابقة، و `_` آخر نتيجة، و `__` التي قبلها.
- `display(x)` يعرض كائناً بشكل غني **في وسط الخلية** (لعرض أكثر من جدول في خلية واحدة).
- سطر ينتهي بـ `;` لا تُعرض قيمته (مفيد لإخفاء نصوص الرسوم مثل `[<matplotlib...>]`).

## ملخص الدرس

- خلايا Markdown للعناوين والشرح والاستنتاجات: الدفتر تقرير لا مجرد كود.
- `%` للسطر و `%%` للخلية: `%timeit` و `%%time` و `%who` و `%%writefile` و `%run`.
- `!` لأوامر الطرفية مثل `!pip install`.
- `Out[n]` و `_` للنتائج السابقة، و `display()` لعرض عدة كائنات.
