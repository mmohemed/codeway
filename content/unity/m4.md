## واجهة المستخدم (UI)

واجهة Unity (نظام **uGUI**) تُبنى داخل كائن **Canvas**: تنشئه من GameObject ← UI، وكل عناصر الواجهة أبناؤه:

| العنصر | استخدامه |
|---|---|
| `Text - TextMeshPro` | النصوص: النقاط، الوقت، الرسائل |
| `Image` | صور وأشرطة (الصحة) بخاصية `fillAmount` |
| `Button` | زر بحدث `onClick` |
| `Slider` و `Toggle` و `InputField` | أدوات الإعدادات والإدخال |

عناصر الواجهة تُرسم فوق اللعبة بإحداثيات **الشاشة** (RectTransform) لا العالم. في هذه الدورة نكتب موضعها بالبكسل `ui=(x, y)` من الزاوية العلوية اليسرى، ونختصر Canvas.

> في المشاريع الحديثة يُستخدم **TextMeshPro** (`TMP_Text`) بدل `Text` القديم: نفس الفكرة بجودة أعلى، ويحتاج `using TMPro;`.

## تحديث النص

```unity
[scene]
Main Camera: Camera pos=(0,0)
ScoreText: Text ui=(10,10) text="Score: 0"
TimerText: Text ui=(380,10) text=""
Game: GameObject
  + ScoreBoard scoreText=@ScoreText timerText=@TimerText

// file: ScoreBoard.cs
using UnityEngine;
using TMPro;

public class ScoreBoard : MonoBehaviour
{
    public TMP_Text scoreText;
    public TMP_Text timerText;
    public float timeLeft = 30f;
    int score;

    public void AddScore(int points)
    {
        score += points;
        scoreText.text = "Score: " + score;
    }

    void Update()
    {
        timeLeft = Mathf.Max(0, timeLeft - Time.deltaTime);
        timerText.text = Mathf.CeilToInt(timeLeft).ToString();
    }
}
// test
call("Game", "AddScore", 10);
call("Game", "AddScore", 5);
step(90);
print(get("ScoreText", "GetComponent<TMP_Text>().text"), "|", get("TimerText", "GetComponent<TMP_Text>().text"));
```

```output
Score: 15 | 29
```

لاحظ: النص يتحدث **فقط عندما تتغير النقاط**، لا كل إطار. تحديث النصوص كل إطار هدر للأداء.

## شريط الصحة بـ Image.fillAmount

```unity
[scene]
Main Camera: Camera pos=(0,0)
HealthBar: Image ui=(10,40) size=(200,18) color=#4caf50
Player: GameObject pos=(0,0) sprite=player
  + PlayerHealth bar=@HealthBar

// file: PlayerHealth.cs
using UnityEngine;
using UnityEngine.UI;

public class PlayerHealth : MonoBehaviour
{
    public Image bar;
    public int maxHealth = 100;
    int health;

    void Start() { health = maxHealth; }

    public void Damage(int amount)
    {
        health = Mathf.Clamp(health - amount, 0, maxHealth);
        float ratio = (float)health / maxHealth;
        bar.fillAmount = ratio;
        bar.color = ratio < 0.3f ? Color.red : Color.green;
        Debug.Log($"health {health} -> fill {bar.fillAmount:F2}, color {bar.color}");
    }
}
// test
step(1);
call("Player", "Damage", 35);
call("Player", "Damage", 45);
```

```output
health 65 -> fill 0.65, color RGBA(0.000, 1.000, 0.000, 1.000)
health 20 -> fill 0.20, color RGBA(1.000, 0.000, 0.000, 1.000)
```

`Image.fillAmount` من 0 إلى 1، ونوع الصورة في Inspector يجب أن يكون **Filled**.

## الأزرار و onClick

الزر يرسل حدث `onClick`. تربطه بدالة `public` في Inspector (قسم On Click ()، تسحب الكائن وتختار الدالة)، أو بالكود بـ `AddListener`. هنا الزر الأول مربوط من "Inspector" بـ `onClick=@Menu.StartGame`، والثاني بالكود:

```unity
[scene]
Main Camera: Camera pos=(0,0)
PlayButton: Button ui=(170,120) size=(140,36) text="Play" onClick=@Menu.StartGame
QuitButton: Button ui=(170,170) size=(140,36) text="Quit"
Menu: GameObject
  + Menu quitButton=@QuitButton

// file: Menu.cs
using UnityEngine;
using UnityEngine.UI;

public class Menu : MonoBehaviour
{
    public Button quitButton;

    void Start()
    {
        quitButton.onClick.AddListener(QuitGame);
    }

    public void StartGame()
    {
        Debug.Log("Start game!");
    }

    void QuitGame()
    {
        Debug.Log("Quit pressed");
        quitButton.interactable = false;
    }
}
// test
step(1);
click(240, 138);
click(240, 188);
click(240, 188);
click(20, 300);
```

```output
Start game!
Quit pressed
```

- النقرة الثانية على Quit لم تفعل شيئاً لأننا جعلنا `interactable = false`.
- النقر خارج الأزرار لا يرسل شيئاً.
- **انقر على الأزرار في المعاينة** لتجربتها.

## الصوت: AudioSource و AudioClip

الصوت في Unity ثلاثة أشياء:

- **AudioClip**: ملف الصوت (wav أو mp3 أو ogg) في مجلد Project.
- **AudioSource**: مكوّن يشغّل الصوت على الكائن، وفيه `clip` و `volume` و `loop` و `playOnAwake`.
- **AudioListener**: الأذن، موجود على الكاميرا تلقائياً.

> المحاكي لا يُصدر صوتاً فعلياً، لكنه يسجّل كل تشغيل ويعرضه في السجل 🔊 لتتأكد أن الكود يشغّل الصوت الصحيح في الوقت الصحيح.

```unity
[scene]
Main Camera: Camera pos=(0,0)
Music: GameObject
  + AudioSource clip=theme loop=true playOnAwake=true
Player: GameObject pos=(0,0) sprite=player
  + AudioSource
  + PlayerSounds jumpSound=clip:jump coinSound=clip:coin

// file: PlayerSounds.cs
using UnityEngine;

public class PlayerSounds : MonoBehaviour
{
    public AudioClip jumpSound;
    public AudioClip coinSound;
    private AudioSource source;

    void Awake() { source = GetComponent<AudioSource>(); }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
            source.PlayOneShot(jumpSound);
        if (Input.GetKeyDown(KeyCode.C))
        {
            source.clip = coinSound;
            source.volume = 0.5f;
            source.Play();
            Debug.Log("playing: " + source.isPlaying + " clip=" + source.clip.name);
        }
    }
}
// test
press("space"); press("space"); press("c");
print(sounds().join(", "));
```

```output
playing: True clip=coin
theme, jump, jump, coin
```

| الدالة | الاستخدام |
|---|---|
| `Play()` | تشغّل `clip` المضبوط (وتوقف ما قبله على نفس المصدر) |
| `PlayOneShot(clip)` | مؤثر قصير يمكن أن يتداخل مع غيره (قفز، طلقة) |
| `Stop()` | إيقاف |
| `AudioSource.PlayClipAtPoint(clip, pos)` | صوت في مكان، ويبقى حتى لو حُذف الكائن |

## صوت عند تدمير كائن

مشكلة شائعة: عملة تشغّل صوتها ثم تُحذف فوراً، فينقطع الصوت مع حذف الـ AudioSource. الحل `PlayClipAtPoint`:

```unity

  + Rigidbody2D gravityScale=0
  + BoxCollider2D

// file: Walk.cs

public class Walk : MonoBehaviour
{
    void FixedUpdate() { GetComponent<Rigidbody2D>().linearVelocity = Vector2.right * 4; }

// file: Coin.cs
using UnityEngine;

public class Coin : MonoBehaviour
{
    public AudioClip pickup;

    void OnTriggerEnter2D(Collider2D other)
    {
        if (!other.CompareTag("Player")) return;
        AudioSource.PlayClipAtPoint(pickup, transform.position);
        Destroy(gameObject);
        Debug.Log("coin collected");
    }
}
// test

print(sounds(), exists("Coin"));
```

```output
["coin"] false
```

## الرسوم المتحركة: Animation و Animator

نظام الحركة في Unity (**Mecanim**) طبقتان:

1. **Animation Clip**: مقطع حركة واحد (`Idle` و `Run` و `Jump`): إطارات صور أو تغيّر خصائص عبر الزمن. تنشئه من نافذة **Animation**.
2. **Animator Controller**: **آلة حالات** (State Machine) فيها الحالات (كل حالة مقطع) والانتقالات بينها بشروط على **Parameters**. تراه في نافذة **Animator**.

والكود لا يشغّل المقاطع مباشرة: **يضبط الـ Parameters فقط**، والـ Animator ينتقل حسب الشروط:

| النوع | الكود |
|---|---|
| Float | `animator.SetFloat("Speed", 3.5f)` |
| Bool | `animator.SetBool("Grounded", true)` |
| Int | `animator.SetInteger("Weapon", 2)` |
| Trigger | `animator.SetTrigger("Attack")` (يُستهلك عند الانتقال) |

في هذه الدورة نكتب الـ Animator Controller بعد `[animator اسم]`: كل سطر انتقال `من -> إلى: شرط`، و`Any` تعني **Any State** (من أي حالة)، والحالة الأولى هي الافتراضية:

```unity
[animator PlayerAnim]
Idle -> Run: Speed > 0.1
Run -> Idle: Speed < 0.1
Any -> Jump: Jump
Jump -> Idle: Grounded

[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform tag=Ground
  + BoxCollider2D
Player: GameObject pos=(0,-3.25) sprite=player
  + Rigidbody2D gravityScale=3
  + BoxCollider2D
  + Animator controller=PlayerAnim
  + PlayerAnimation

// file: PlayerAnimation.cs
using UnityEngine;

public class PlayerAnimation : MonoBehaviour
{
    Animator anim;
    Rigidbody2D rb;
    SpriteRenderer sr;
    bool grounded;

    void Awake()
    {
        anim = GetComponent<Animator>();
        rb = GetComponent<Rigidbody2D>();
        sr = GetComponent<SpriteRenderer>();
    }

    void Update()
    {
        float x = Input.GetAxisRaw("Horizontal");
        rb.linearVelocity = new Vector2(x * 5, rb.linearVelocity.y);
        if (x != 0) sr.flipX = x < 0;

        if (Input.GetKeyDown(KeyCode.Space) && grounded)
        {
            rb.AddForce(Vector2.up * 12, ForceMode2D.Impulse);
            anim.SetTrigger("Jump");
            grounded = false;   // تركنا الأرض الآن، لا ننتظر رسالة الفيزياء
        }
        anim.SetFloat("Speed", Mathf.Abs(rb.linearVelocity.x));
        anim.SetBool("Grounded", grounded);
    }

    void OnCollisionEnter2D(Collision2D c) { if (c.gameObject.CompareTag("Ground")) grounded = true; }
    void OnCollisionExit2D(Collision2D c) { if (c.gameObject.CompareTag("Ground")) grounded = false; }
}
// test
step(10); print(state("Player"));
keyDown("left"); step(10); print(state("Player"), get("Player", "sr.flipX"));
keyUp("left"); step(3); print(state("Player"));
press("space"); step(5); print(state("Player"));
step(60); print(state("Player"));
```

```output
Idle
Run True
Idle
Jump
Idle
```

- السكربت لا يعرف شيئاً عن المقاطع: يخبر الـ Animator **بالحالة الفيزيائية** فقط (السرعة، على الأرض؟)، وهذا يفصل المنطق عن الرسوم.
- `flipX` يقلب الصورة للنظر يساراً بدل رسم مقاطع جديدة.
- في المحرر الحقيقي ألغِ **Has Exit Time** في الانتقالات التي يجب أن تحدث فوراً (مثل القفز)، واجعل **Transition Duration** صفراً للرسوم البكسلية. المحاكي يجعل الانتقالات كلها فورية.

## Animator.Play والتحقق من الحالة

```unity
[animator DoorAnim]
Closed -> Open: IsOpen
Open -> Closed: !IsOpen

[scene]
Main Camera: Camera pos=(0,0)
Door: GameObject pos=(0,0) color=#8b5a2b size=(1,2)
  + Animator controller=DoorAnim
  + Door

// file: Door.cs
using UnityEngine;

public class Door : MonoBehaviour
{
    Animator anim;

    void Awake() { anim = GetComponent<Animator>(); }

    public void Toggle()
    {
        anim.SetBool("IsOpen", !anim.GetBool("IsOpen"));
    }

    public string Current()
    {
        return anim.GetCurrentAnimatorStateInfo(0).IsName("Open") ? "open" : "closed";
    }
}
// test
step(1); print(call("Door", "Current"));
call("Door", "Toggle"); step(1); print(call("Door", "Current"));
call("Door", "Toggle"); step(1); print(call("Door", "Current"));
```

```output
closed
open
closed
```

`GetCurrentAnimatorStateInfo(0)` يخبرك بالحالة الحالية في الطبقة 0، مفيد مثلاً لمنع الحركة أثناء حالة الهجوم.

~~~starter
using UnityEngine;

public class EnemyBrain : MonoBehaviour

}
~~~

--- quiz
? ما دور الكود مع Animator Controller؟
+ يضبط الـ Parameters، والـ Animator ينتقل بين الحالات حسب الشروط
- يشغّل كل إطار من الصور يدوياً
- لا علاقة للكود بالحركة
> هكذا يبقى منطق اللعبة منفصلاً عن الرسوم.

? ما نوع الـ Parameter المناسب للهجوم الذي يحدث مرة عند الضغط؟
+ Trigger
- Float
- Bool يبقى true
> الـ Trigger يُستهلك تلقائياً عند الانتقال.

? ما فائدة Any State؟
+ انتقال يمكن أن يحدث من أي حالة (مثل التعرض للضرر)
- حالة لا تفعل شيئاً
- تشغيل كل الحالات معاً
> بدونها تحتاج سهماً من كل حالة.
