## من المحرر إلى الهاتف

البناء يحوّل مشروعك إلى تطبيق مستقل. خطوات Android:

1. **تثبيت الوحدة**: Unity Hub ← Installs ← المحرر ← Add Modules ← **Android Build Support** (ومعها OpenJDK و Android SDK & NDK).
2. **اختيار المنصة**: File ← **Build Profiles** (في الإصدارات الأقدم Build Settings) ← Android ← **Switch Platform**.
3. **المشاهد**: أضف مشاهد اللعبة لقائمة Scene List بالترتيب.
4. **Player Settings**:
   - Company Name و Product Name و Version.
   - **Package Name** فريد مثل `com.mystudio.mygame`.
   - **Default Orientation**: عمودي أو أفقي.
   - **Scripting Backend: IL2CPP** و **Target Architectures: ARM64** (مطلوب في Google Play).
   - Minimum API Level والأيقونة.
5. **التوقيع**: Publishing Settings ← **Keystore** جديد (احفظه وكلمة سره جيداً، بدونه لا يمكنك تحديث لعبتك على المتجر أبداً).
6. **البناء**: **Build** يُخرج ملف `.apk` للتجربة على هاتفك، أو فعّل **Build App Bundle** لملف `.aab` الذي يطلبه Google Play. و **Build And Run** يثبّتها على هاتف موصول (مع تفعيل USB Debugging).

وفي iOS: نفس الفكرة، لكن Unity يُخرج **مشروع Xcode** تبنيه على جهاز Mac بحساب Apple Developer.

## كود حسب المنصة

نفس الكود يعمل على كل المنصات، لكن أحياناً تحتاج سلوكاً مختلفاً. طريقتان:

- **وقت الترجمة**: `#if UNITY_ANDROID ... #endif` الكود غير المطابق لا يدخل البناء أصلاً.
- **وقت التشغيل**: `Application.platform` و `Application.isMobilePlatform`.

في هذه الدورة تختار المنصة بـ `[platform Android]` (والافتراضي تشغيل داخل المحرر):

```unity
[platform Android]
[scene]
Main Camera: Camera pos=(0,0)
Boot: GameObject
  + PlatformInfo

// file: PlatformInfo.cs
using UnityEngine;

public class PlatformInfo : MonoBehaviour
{
    void Start()
    {
        Debug.Log("platform: " + Application.platform);
        Debug.Log("mobile: " + Application.isMobilePlatform);
#if UNITY_ANDROID
        Debug.Log("Android build: show Google Play login");
#elif UNITY_IOS
        Debug.Log("iOS build: show Game Center login");
#else
        Debug.Log("Desktop build");
#endif
#if UNITY_EDITOR
        Debug.Log("running inside the Editor");
#endif
        Application.targetFrameRate = 60;
        Screen.orientation = ScreenOrientation.LandscapeLeft;
        Screen.sleepTimeout = SleepTimeout.NeverSleep;
    }
}
```

```output
platform: Android
mobile: True
Android build: show Google Play login
```

- على الجوال معدل الإطارات الافتراضي **30**، فاضبط `Application.targetFrameRate = 60` إن احتجت حركة أنعم (على حساب البطارية).
- `SleepTimeout.NeverSleep` يمنع الشاشة من الانطفاء أثناء اللعب.

## اللمس

لا لوحة مفاتيح على الهاتف: المدخلات **لمسات**. كل لمسة `Touch` فيها `position` (بكسل من الزاوية السفلية اليسرى) و `phase`:

| المرحلة | معناها |
|---|---|
| `Began` | بداية اللمس |
| `Moved` | الإصبع يتحرك |
| `Stationary` | ثابت على الشاشة |
| `Ended` | رُفع الإصبع |

```unity
[platform Android]
[scene]
Main Camera: Camera pos=(0,0)
Pad: GameObject
  + TouchPad

// file: TouchPad.cs
using UnityEngine;

public class TouchPad : MonoBehaviour
{
    void Update()
    {
        if (Input.touchCount == 0) return;
        Touch t = Input.GetTouch(0);
        string side = t.position.x < Screen.width / 2 ? "left" : "right";
        if (t.phase == TouchPhase.Began)
            Debug.Log($"touch {side} at {t.position}");
        else if (t.phase == TouchPhase.Ended)
            Debug.Log("released");
    }
}
// test
touch(100, 200);
touch(400, 50);
print("screen:", get("Pad", "Screen.width"), "x", get("Pad", "Screen.height"));
```

```output
touch left at (100.00, 120.00)
released
touch right at (400.00, 270.00)
released
screen: 480 x 320
```

في المعاينة النقر بالفأرة يُحاكي اللمس عندما تكون المنصة Android (كما في **Device Simulator** في المحرر). وتذكّر أن `Screen.width` على الهاتف الحقيقي بدقة شاشته (مثل 2400×1080)، لذلك احسب بالنسب لا بأرقام ثابتة.

## الاهتزاز وفتح الروابط

```csharp
Handheld.Vibrate();                                   // اهتزاز قصير (Android و iOS)
```

اكتب `TouchMove.cs`:

2. في `Update`: إذا كانت هناك لمسة (`Input.touchCount > 0`) خذ الأولى:
   - إذا كانت في **النصف الأيسر** للشاشة (`position.x < Screen.width / 2f`) تحرك يساراً `speed * Time.deltaTime`، وإلا يميناً.

~~~setup

[scene]

Player: GameObject pos=(0,0) sprite=player
  + TouchMove
~~~
~~~starter
using UnityEngine;

public class TouchMove : MonoBehaviour
{
    public float speed = 4f;

    void Update()
    {
    }
}
~~~
~~~solution
using UnityEngine;

public class TouchMove : MonoBehaviour
{
    public float speed = 4f;

    void Update()
    {
        if (Input.touchCount > 0)
        {
            Touch t = Input.GetTouch(0);
            float dir = t.position.x < Screen.width / 2f ? -1f : 1f;
            transform.position += Vector3.right * dir * speed * Time.deltaTime;
            if (t.phase == TouchPhase.Began)
                Debug.Log("tap");
        }
    }
}
~~~
~~~test
touch(400, 160, 29);
print(pos("Player"));
step(30);
print(pos("Player"));
touch(50, 160, 59);
print(pos("Player"));
~~~
~~~expected

[2,0]
[2,0]
tap
[-2,0]
~~~

## البناء للكمبيوتر (Windows و Mac و Linux)

1. Unity Hub ← Add Modules ← **Windows Build Support** (أو Mac/Linux).
2. Build Profiles ← **Windows** (أو macOS أو Linux) ← Switch Platform.
3. **Player Settings ← Resolution and Presentation**:
   - **Fullscreen Mode**: Fullscreen Window أو Windowed.
   - الدقة الافتراضية ودعم تغيير حجم النافذة.
4. **Build**: اختر مجلداً فارغاً. الناتج على Windows ملف `MyGame.exe` **ومعه** مجلد `MyGame_Data` و `UnityPlayer.dll` ومجلدات أخرى: **وزّع المجلد كاملاً** (مضغوطاً zip)، فالملف التنفيذي وحده لا يعمل.
5. **Development Build**: يفعّل الـ **Profiler** ورسائل Console في النسخة المبنية لكشف مشاكل الأداء. لا تنشر به النسخة النهائية.

ولتوزيع لعبتك: **Steam** (عبر Steamworks) أو **itch.io** (رفع ملف zip مباشرة، وممتاز للبداية).

## الخروج والدقة والجودة

على الكمبيوتر يتوقع اللاعب زر خروج وقائمة إعدادات:

```unity
[platform Windows]
[scene]
Main Camera: Camera pos=(0,0)
Settings: GameObject
  + Settings

// file: Settings.cs
using UnityEngine;

public class Settings : MonoBehaviour
{
    void Start()
    {
        string[] levels = QualitySettings.names;
        Debug.Log("quality levels: " + levels.Length + ", current: " + levels[QualitySettings.GetQualityLevel()]);
        QualitySettings.SetQualityLevel(1);
        Screen.SetResolution(1280, 720, false);
        Debug.Log($"resolution {Screen.width}x{Screen.height} fullscreen={Screen.fullScreen}");
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.F))
        {
            Screen.fullScreen = !Screen.fullScreen;
            Debug.Log("fullscreen: " + Screen.fullScreen);
        }
        if (Input.GetKeyDown(KeyCode.Escape))
            QuitGame();
    }

    public void QuitGame()
    {
        Debug.Log("Quitting...");
#if UNITY_EDITOR
        UnityEditor.EditorApplication.isPlaying = false;
#else
        Application.Quit();
#endif
    }
}
// test
press("f");
press("escape");
print(record().join(" | "));
```

```output
quality levels: 6, current: High
resolution 1280x720 fullscreen=False
fullscreen: True
Quitting...
Quality 1 | SetResolution 1280x720 false | fullScreen true | Quit
```

- `Application.Quit()` **لا يفعل شيئاً داخل المحرر**، لذلك يستخدم المطورون `#if UNITY_EDITOR` لإيقاف وضع التشغيل بدلاً منه.
- هذا المثال مبني لـ Windows (`[platform Windows]`) فلم يدخل كود المحرر في البناء.

## حفظ البيانات: PlayerPrefs

`PlayerPrefs` تحفظ قيماً صغيرة (أعلى نتيجة، الإعدادات، المستوى المفتوح) وتبقى بعد إغلاق اللعبة. على Windows تُحفظ في الـ Registry، وعلى Android في ملف التطبيق. في هذه الدورة `[prefs]` تمثّل ما حُفظ في جلسة سابقة:

```unity
[prefs]
highScore = 120
playerName = "Sara"

[scene]
Main Camera: Camera pos=(0,0)
Save: GameObject
  + SaveDemo

// file: SaveDemo.cs
using UnityEngine;

public class SaveDemo : MonoBehaviour
{
    void Start()
    {
        int best = PlayerPrefs.GetInt("highScore", 0);
        string name = PlayerPrefs.GetString("playerName", "Guest");
        float volume = PlayerPrefs.GetFloat("volume", 0.8f);
        Debug.Log($"{name} best={best} volume={volume}");
        Debug.Log("has level key: " + PlayerPrefs.HasKey("level"));

        PlayerPrefs.SetInt("level", 3);
        PlayerPrefs.SetFloat("volume", 0.5f);
        PlayerPrefs.Save();
        Debug.Log("saved level " + PlayerPrefs.GetInt("level"));
    }
}
```

```output
Sara best=120 volume=0.8
has level key: False
saved level 3
```

- القيمة الثانية في `GetInt("key", 0)` افتراضية إن لم يكن المفتاح محفوظاً.
- `PlayerPrefs` للبيانات الصغيرة فقط. لحفظ تقدّم كامل (مخزون، عالم) استخدم ملف JSON في `Application.persistentDataPath` مع `JsonUtility`.

## الإيقاف المؤقت بـ Time.timeScale

`Time.timeScale = 0` يوقف الزمن: `Time.deltaTime` يصبح صفراً، والفيزياء و `FixedUpdate` و `WaitForSeconds` تتوقف. و `Update` يستمر (حتى تستطيع قراءة زر الاستئناف):

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ball: GameObject pos=(-5,0) sprite=coin
  + Roll
Pause: GameObject
  + PauseMenu

// file: Roll.cs
using UnityEngine;

public class Roll : MonoBehaviour
{
    void Update() { transform.position += Vector3.right * 2 * Time.deltaTime; }
}

// file: PauseMenu.cs
using UnityEngine;

public class PauseMenu : MonoBehaviour
{
    bool paused;

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.P))
        {
            paused = !paused;
            Time.timeScale = paused ? 0f : 1f;
            Debug.Log(paused ? "PAUSED" : "RESUMED");
        }
    }
}
// test
step(60); print(pos("Ball"));
press("p"); step(60); print(pos("Ball"));
press("p"); step(30); print(pos("Ball"));
```

```output
[-3,0]
PAUSED
[-2.97,0]
RESUMED
[-1.93,0]
```

--- exercise
اكتب `HighScore.cs` يحفظ أعلى نتيجة. في `[prefs]` نتيجة سابقة `highScore = 50`:

1. دالة `public int Best()` ترجع `PlayerPrefs.GetInt("highScore", 0)`.
2. دالة `public bool Submit(int score)`:
   - إذا كانت `score` أكبر من `Best()`: احفظها بـ `SetInt` ثم `Save()`، واطبع `"New record: "` ثم النتيجة، وارجع `true`.
   - وإلا اطبع `"Best is still "` ثم `Best()` وارجع `false`.
3. دالة `public void ResetScores()`: تحذف المفتاح بـ `DeleteKey` وتطبع `"reset"`.

~~~setup
[prefs]
highScore = 50

[scene]
Main Camera: Camera pos=(0,0)
Game: GameObject
  + HighScore
~~~
~~~starter
using UnityEngine;

public class HighScore : MonoBehaviour
{
    public int Best()
    {
        return 0;
    }

    public bool Submit(int score)
    {
        return false;
    }

    public void ResetScores()
    {
    }
}
~~~
~~~solution
using UnityEngine;

public class HighScore : MonoBehaviour
{
    public int Best()
    {
        return PlayerPrefs.GetInt("highScore", 0);
    }

    public bool Submit(int score)
    {
        if (score > Best())
        {
            PlayerPrefs.SetInt("highScore", score);
            PlayerPrefs.Save();
            Debug.Log("New record: " + score);
            return true;
        }
        Debug.Log("Best is still " + Best());
        return false;
    }

    public void ResetScores()
    {
        PlayerPrefs.DeleteKey("highScore");
        Debug.Log("reset");
    }
}
~~~
~~~test
step(1);
print(call("Game", "Best"));
print(call("Game", "Submit", 30));
print(call("Game", "Submit", 75));
print(prefs("highScore"));
call("Game", "ResetScores");
print(call("Game", "Best"), prefs("highScore"));
~~~

~~~expected
50
Best is still 50
False
New record: 75
True
75
reset
0 null
~~~
