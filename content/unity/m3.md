## Rigidbody2D: الجسم الفيزيائي

إضافة **Rigidbody2D** لكائن تسلّمه لمحرك الفيزياء: يسقط بالجاذبية، ويتحرك بسرعته، ويصطدم بغيره (إن كان له Collider). وفي 3D المكوّن اسمه `Rigidbody` بنفس الفكرة.

| الخاصية | معناها |
|---|---|
| `bodyType` | Dynamic (فيزياء كاملة) أو Kinematic (يتحرك بالكود فقط) أو Static |
| `gravityScale` | مضاعف الجاذبية (0 = بلا جاذبية) |
| `mass` | الكتلة |
| `linearVelocity` | السرعة الحالية (في الإصدارات قبل Unity 6 اسمها `velocity`) |

والجاذبية الافتراضية -9.81 م/ث² على y.

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform
  + BoxCollider2D
Rock: GameObject pos=(-3,4) sprite=bomb
  + Rigidbody2D gravityScale=1
  + CircleCollider2D
Balloon: GameObject pos=(3,0) sprite=coin
  + Rigidbody2D gravityScale=-0.2
  + CircleCollider2D
Probe: GameObject
  + Probe rock=@Rock

// file: Probe.cs
using UnityEngine;

public class Probe : MonoBehaviour
{
    public Rigidbody2D rock;

    void FixedUpdate()
    {
        if (Time.fixedTime == 0.5f)
            Debug.Log("rock speed after 0.5s: " + rock.linearVelocity.y.ToString("F2"));
    }
}
// test
step(120);
print(pos("Rock"), pos("Balloon"));
```

```output
rock speed after 0.5s: -4.91
[-3,-3.78] [3,3.96]
```

- بعد نصف ثانية سرعة الحجر قرابة -4.9 (= -9.81 × 0.5)، ثم استقر على الأرض.
- البالون `gravityScale` سالب فيصعد ببطء.
- لم نكتب سطر حركة واحداً: الفيزياء تكفي.

## تحريك جسم فيزيائي بالكود

**لا تحرّك جسماً ديناميكياً بـ `transform.position`**: هكذا تتجاوز الفيزياء فيخترق الجدران. بدلاً من ذلك:

| الطريقة | الاستخدام |
|---|---|
| `rb.linearVelocity = ...` | تحكم مباشر بالسرعة (حركة اللاعب) |
| `rb.AddForce(f, ForceMode2D.Impulse)` | دفعة فورية (القفز، الانفجار) |
| `rb.AddForce(f)` | قوة مستمرة كل FixedUpdate (محرك، رياح) |
| `rb.MovePosition(p)` | للأجسام Kinematic (منصات متحركة) |

وقاعدة مهمة: **اقرأ المدخلات في `Update`، وطبّق الفيزياء في `FixedUpdate`**:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform
  + BoxCollider2D
Wall: GameObject pos=(3,-2.5) color=#8b5a2b size=(1,3)
  + BoxCollider2D
Player: GameObject pos=(-4,-3) sprite=player
  + Rigidbody2D gravityScale=3
  + BoxCollider2D
  + PlayerMove speed=6 jumpForce=14

// file: PlayerMove.cs
using UnityEngine;

public class PlayerMove : MonoBehaviour
{
    public float speed = 5f;
    public float jumpForce = 12f;
    private Rigidbody2D rb;
    private float moveX;
    private bool jumpPressed;

    void Awake() { rb = GetComponent<Rigidbody2D>(); }

    void Update()
    {
        moveX = Input.GetAxisRaw("Horizontal");
        if (Input.GetKeyDown(KeyCode.Space)) jumpPressed = true;
    }

    void FixedUpdate()
    {
        rb.linearVelocity = new Vector2(moveX * speed, rb.linearVelocity.y);
        if (jumpPressed)
        {
            rb.AddForce(Vector2.up * jumpForce, ForceMode2D.Impulse);
            jumpPressed = false;
        }
    }
}
// test
step(30);
keyDown("right"); step(90); keyUp("right");
print("at wall:", pos("Player"));
press("space"); step(12);
print("jumping:", pos("Player")[1] > -2);
```

```output
at wall: [2,-3.25]
jumping: true
```

- السرعة الأفقية من المدخلات، مع **الاحتفاظ** بالسرعة الرأسية `rb.linearVelocity.y` حتى لا نلغي الجاذبية والقفز.
- الجدار أوقف اللاعب: الفيزياء تمنع التداخل.
- `jumpPressed` يحفظ الضغطة من `Update` حتى يطبقها `FixedUpdate` (قد تمر إطارات بلا FixedUpdate فتضيع الضغطة).

## Kinematic: منصة متحركة

الجسم **Kinematic** لا تؤثر فيه الجاذبية ولا الاصطدامات، بل يتحرك كما تأمره فقط، ويدفع الأجسام الديناميكية:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Platform: GameObject pos=(-3,-1) color=#3a7d44 size=(3,0.5)
  + Rigidbody2D bodyType=Kinematic
  + BoxCollider2D
  + Mover

// file: Mover.cs
using UnityEngine;

public class Mover : MonoBehaviour
{
    private Rigidbody2D rb;
    private Vector2 start;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        start = rb.position;
    }

    void FixedUpdate()
    {
        float x = Mathf.PingPong(Time.fixedTime * 2f, 6f);
        rb.MovePosition(start + new Vector2(x, 0));
    }
}
// test
step(60); print(pos("Platform"));
step(120); print(pos("Platform"));
```

```output
[-1.04,-1]
[2.96,-1]
```

`Mathf.PingPong(t, 6)` يصعد من 0 إلى 6 ثم ينزل إلى 0 ويكرر.

## Colliders: شكل التصادم

**Collider** يحدد حدود الجسم: `BoxCollider2D` و `CircleCollider2D` و `CapsuleCollider2D` و `PolygonCollider2D`. وعندما يلتقي جسمان لهما Collider، وأحدهما على الأقل فيه Rigidbody2D، يرسل Unity رسائل لسكربتاتهما:

| الرسالة | متى |
|---|---|
| `OnCollisionEnter2D(Collision2D c)` | بداية اصطدام صلب |
| `OnCollisionExit2D(Collision2D c)` | انتهاء التلامس |
| `OnTriggerEnter2D(Collider2D other)` | دخول منطقة **Trigger** |
| `OnTriggerExit2D(Collider2D other)` | الخروج منها |

(في 3D: `OnCollisionEnter(Collision)` و `OnTriggerEnter(Collider)` بلا 2D.)

## الاصطدام الصلب ومعرفة الطرف الآخر

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform tag=Ground
  + BoxCollider2D
Box: GameObject pos=(0,-3.5) color=#8b5a2b size=(1,1) tag=Box
  + BoxCollider2D
Ball: GameObject pos=(0,3) sprite=bomb
  + Rigidbody2D
  + CircleCollider2D bounciness=0.5
  + Ball

// file: Ball.cs
using UnityEngine;

public class Ball : MonoBehaviour
{
    int hits;

    void OnCollisionEnter2D(Collision2D collision)
    {
        hits++;
        GameObject other = collision.gameObject;
        Vector2 normal = collision.GetContact(0).normal;
        Debug.Log($"hit {hits}: {other.name} tag={other.tag} normal={normal}");
        if (other.CompareTag("Box") && hits >= 3)
            Destroy(other);
    }
}
// test
step(300);
print("box exists:", exists("Box"));
```

```output
hit 1: Box tag=Box normal=(0.00, 1.00)
hit 2: Box tag=Box normal=(0.00, 1.00)
hit 3: Box tag=Box normal=(0.00, 1.00)
hit 4: Ground tag=Ground normal=(0.00, 1.00)
hit 5: Ground tag=Ground normal=(0.00, 1.00)
hit 6: Ground tag=Ground normal=(0.00, 1.00)
box exists: false
```

- `collision.gameObject` الكائن الآخر، و`GetContact(0).normal` اتجاه الدفع: (0, 1) يعني ضُربنا من **الأسفل** (هبطنا فوقه).
- `bounciness` في Physics Material يجعل الكرة ترتد (هنا تختصر كتابته في سطر الـ Collider).
- بعد حذف الصندوق سقطت الكرة على الأرض.

## Triggers: مناطق تكتشف ولا تصطدم

فعّل **Is Trigger** في الـ Collider فيصبح منطقة: الأجسام تمر خلالها، ويصلك `OnTriggerEnter2D`. للعملات والفخاخ ونقاط الحفظ ونهاية المستوى:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform
  + BoxCollider2D
Player: GameObject pos=(-5,-3) sprite=player tag=Player
  + Rigidbody2D gravityScale=2
  + BoxCollider2D
  + AutoRun
Coin: GameObject pos=(-2,-3.5) sprite=coin tag=Coin
  + CircleCollider2D isTrigger=true
Water: GameObject pos=(2,-3.5) color=#3a6fd8 size=(2,1)
  + BoxCollider2D isTrigger=true
  + Zone

// file: AutoRun.cs
using UnityEngine;

public class AutoRun : MonoBehaviour
{
    public int coins;
    Rigidbody2D rb;

    void Awake() { rb = GetComponent<Rigidbody2D>(); }
    void FixedUpdate() { rb.linearVelocity = new Vector2(4, rb.linearVelocity.y); }

    void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Coin"))
        {
            coins++;
            Destroy(other.gameObject);
            Debug.Log("coins: " + coins);
        }
    }
}

// file: Zone.cs
using UnityEngine;

public class Zone : MonoBehaviour
{
    void OnTriggerEnter2D(Collider2D other) { Debug.Log(other.name + " entered water"); }
    void OnTriggerExit2D(Collider2D other) { Debug.Log(other.name + " left water"); }
}
// test
step(180);
```

```output
coins: 1
Player entered water
Player left water
```

لاحظ أن كلا الطرفين يستقبل الرسالة: اللاعب عرف أنه لمس العملة، والماء عرف أن اللاعب دخله.

## التحقق من الأرض للقفز

لا تسمح بالقفز في الهواء: احفظ `isGrounded` من رسائل الاصطدام بالأرض:

```csharp
void OnCollisionEnter2D(Collision2D c) { if (c.gameObject.CompareTag("Ground")) isGrounded = true; }
void OnCollisionExit2D(Collision2D c)  { if (c.gameObject.CompareTag("Ground")) isGrounded = false; }
```

وطريقة أدق تراها في الدرس القادم: **Raycast** نحو الأسفل.

## Raycasting: شعاع يكتشف ما أمامه

**Raycast** شعاع تطلقه من نقطة في اتجاه لمسافة، فيخبرك بأول Collider يصيبه: هل اللاعب على الأرض؟ هل يرى العدو اللاعب؟ ماذا تحت مؤشر الفأرة؟

```csharp
RaycastHit2D hit = Physics2D.Raycast(origin, direction, distance, layerMask);
if (hit)   // أو hit.collider != null
{
    hit.collider   // ما أصابه
    hit.point      // نقطة الإصابة
    hit.distance   // المسافة
    hit.normal     // اتجاه السطح
}
```

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform
  + BoxCollider2D
Wall: GameObject pos=(4,-2) color=#8b5a2b size=(1,4)
  + BoxCollider2D
Eye: GameObject pos=(-4,-2)
  + Eye

// file: Eye.cs
using UnityEngine;

public class Eye : MonoBehaviour
{
    void Start()
    {
        RaycastHit2D right = Physics2D.Raycast(transform.position, Vector2.right, 20f);
        if (right)
            Debug.Log($"right: {right.collider.name} at {right.distance:F2}, point {right.point}, normal {right.normal}");

        RaycastHit2D down = Physics2D.Raycast(transform.position, Vector2.down, 10f);
        Debug.Log("down: " + down.collider.name + " " + down.distance.ToString("F2"));

        RaycastHit2D up = Physics2D.Raycast(transform.position, Vector2.up, 10f);
        Debug.Log("up hit? " + (up.collider != null));
    }
}
```

```output
right: Wall at 7.50, point (3.50, -2.00), normal (-1.00, 0.00)
down: Ground 2.00
up hit? False
```

## طبقات (Layers) وأقنعة (LayerMask)

مشكلة شائعة: الشعاع يبدأ من **داخل** collider اللاعب نفسه فيصيب اللاعب! (Unity يفعل ذلك افتراضياً: Queries Start In Colliders). الحل: ضع الأرض في طبقة `Ground` (أعلى Inspector ← Layer)، واجعل الشعاع لا يرى غيرها بـ **LayerMask**:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ground: GameObject pos=(0,-4.5) sprite=platform layer=Ground
  + BoxCollider2D
Player: GameObject pos=(0,-3.25) sprite=player
  + Rigidbody2D gravityScale=3
  + BoxCollider2D
  + GroundCheck groundLayer=Ground

// file: GroundCheck.cs
using UnityEngine;

public class GroundCheck : MonoBehaviour
{
    public LayerMask groundLayer;

    void Start()
    {
        RaycastHit2D noMask = Physics2D.Raycast(transform.position, Vector2.down, 1f);
        Debug.Log("without mask: " + noMask.collider.name + " at " + noMask.distance);

        RaycastHit2D withMask = Physics2D.Raycast(transform.position, Vector2.down, 1f, groundLayer);
        Debug.Log("with mask: " + withMask.collider.name + " at " + withMask.distance.ToString("F2"));
        Debug.Log("mask value: " + groundLayer.value + " = " + LayerMask.GetMask("Ground"));
    }

    public bool IsGrounded()
    {
        return Physics2D.Raycast(transform.position, Vector2.down, 0.8f, groundLayer);
    }
}
// test
step(5);
print("grounded:", call("Player", "IsGrounded"));
```

```output
without mask: Player at 0
with mask: Ground at 0.75
mask value: 64 = 64
grounded: True
```

- حقل `LayerMask` يظهر في Inspector قائمة تختار منها الطبقات.
- نصف ارتفاع اللاعب 0.75، فشعاع طوله 0.8 يصل للأرض فقط وهو واقف عليها.
- `Physics2D.OverlapCircle(groundCheck.position, 0.2f, groundLayer)` طريقة أخرى شائعة: دائرة صغيرة عند القدمين.

## عدو يرى اللاعب

```unity
[scene]
Main Camera: Camera pos=(0,0)
Guard: GameObject pos=(-4,0) sprite=enemy
  + Guard sightRange=6
Crate: GameObject pos=(0,0) color=#8b5a2b size=(1,1)
  + BoxCollider2D
Player: GameObject pos=(4,0) sprite=player tag=Player
  + BoxCollider2D
  + Rigidbody2D gravityScale=0

// file: Guard.cs
using UnityEngine;

public class Guard : MonoBehaviour
{
    public float sightRange = 5f;

    public string Look()
    {
        Vector2 eye = (Vector2)transform.position + Vector2.right * 0.6f;
        RaycastHit2D hit = Physics2D.Raycast(eye, Vector2.right, sightRange);
        if (!hit) return "nothing";
        return hit.collider.CompareTag("Player") ? "I see you!" : "blocked by " + hit.collider.name;
    }
}
// test
print(call("Guard", "Look"));
```

```output
blocked by Crate
```

بدأنا الشعاع أمام العدو بقليل (`+ 0.6`) حتى لا يبدأ داخل جسمه، والصندوق حجب الرؤية.

~~~solution
using UnityEngine;

public class Sensor : MonoBehaviour
{
    public float speed = 3f;
    public float stopDistance = 1f;
    public LayerMask wallLayer;

    public float DistanceAhead()
    {
        RaycastHit2D hit = Physics2D.Raycast(transform.position, Vector2.right, 10f, wallLayer);
        if (hit) return hit.distance;
        return 10f;
    }

    void Update()
    {
        if (DistanceAhead() > stopDistance)
            transform.position += Vector3.right * speed * Time.deltaTime;
    }
}
~~~

--- quiz
? ماذا يرجع Physics2D.Raycast إذا لم يصب شيئاً؟
+ نتيجة collider فيها null، و if (hit) تكون false
- خطأ NullReferenceException
- آخر شيء أصابه سابقاً
> افحص دائماً قبل استخدام hit.collider.

? لماذا قد يصيب شعاعٌ اللاعبَ نفسه؟
+ لأنه يبدأ من داخل collider اللاعب، فنستخدم LayerMask أو نبدأه خارج الجسم
- لأن الأشعة ترتد
- لأن اللاعب في طبقة UI
> Queries Start In Colliders مفعلة افتراضياً.

? ما فائدة LayerMask في Raycast؟
+ يحدد الطبقات التي يراها الشعاع ويتجاهل غيرها
- يلوّن الشعاع
- يجعل الشعاع أطول
> مثلاً: الأرض فقط للتحقق من الوقوف.
