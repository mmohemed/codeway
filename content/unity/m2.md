## C# في Unity

سكربتات Unity بلغة **C#**: لغة قوية الأنواع (لكل متغير نوع ثابت) من Microsoft. كل سكربت صنف يرث `MonoBehaviour` حتى يُضاف لكائن، ويمكنك أيضاً كتابة أصناف C# عادية للبيانات والمنطق.

## المتغيرات والأنواع

```unity
// file: Basics.cs
using UnityEngine;

public class Basics : MonoBehaviour
{
    int lives = 3;
    float speed = 4.5f;
    double precise = 4.5;
    bool isAlive = true;
    string playerName = "Sara";

    void Start()
    {
        Debug.Log(playerName + " lives=" + lives + " speed=" + speed + " alive=" + isAlive);
        Debug.Log(7 / 2);
        Debug.Log(7 / 2f);
        Debug.Log((int)9.8f);
        Debug.Log(Mathf.RoundToInt(2.5f) + " " + Mathf.RoundToInt(3.5f));
        Debug.Log($"Hi {playerName}, speed {speed:F2}");
        var total = lives * 10;
        Debug.Log(total / 4);
    }
}
```

```output
Sara lives=3 speed=4.5 alive=True
3
3.5
9
2 4
Hi Sara, speed 4.50
7
```

- `float` يحتاج اللاحقة **f**: `4.5f`. بدونها `4.5` من نوع `double`، و Unity كله يستخدم `float`.
- قسمة عددين صحيحين صحيحة: `7 / 2 = 3`.
- `(int)9.8f` تحويل صريح يحذف الكسر (9)، و`Mathf.RoundToInt` تقرّب **للزوجي** عند النصف (2.5 ← 2 و 3.5 ← 4).
- `$"... {x:F2}"` نص محرف بتنسيق.
- `var` يستنتج النوع، لكنه يبقى ثابتاً بعدها.

ماذا لو نسيت `f`؟ C# يرفض الترجمة، و Unity لا يشغّل اللعبة حتى تصلح الخطأ:

```unity
// file: Oops.cs
using UnityEngine;

public class Oops : MonoBehaviour
{
    void Start()
    {
        float speed = 5.5;
        Debug.Log(speed);
    }
}
```

```output
ERR: error CS0664: Literal of type double cannot be implicitly converted to type 'float'; use an 'F' suffix to create a literal of this type (السطر 9)
```

## الدوال والشروط والحلقات

```unity
// file: Logic.cs
using UnityEngine;
using System.Collections.Generic;

public class Logic : MonoBehaviour
{
    enum Weapon { Sword, Bow, Magic }

    int Damage(Weapon w, int level)
    {
        switch (w)
        {
            case Weapon.Sword: return 10 + level * 2;
            case Weapon.Bow: return 8 + level * 3;
            default: return 15;
        }
    }

    void Start()
    {
        Debug.Log(Damage(Weapon.Sword, 3) + " " + Damage(Weapon.Bow, 3) + " " + Damage(Weapon.Magic, 1));

        int[] scores = { 40, 95, 70 };
        int best = 0;
        foreach (int s in scores)
            if (s > best) best = s;
        Debug.Log("best: " + best + " of " + scores.Length);

        List<string> items = new List<string>();
        items.Add("key");
        items.Add("potion");
        items.Remove("key");
        Debug.Log(items.Count + " " + items[0] + " " + items.Contains("key"));

        Dictionary<string, int> stock = new Dictionary<string, int>();
        stock["arrow"] = 20;
        stock["arrow"] -= 5;
        Debug.Log("arrows: " + stock["arrow"]);

        for (int i = 3; i > 0; i--)
            Debug.Log(i);
        Debug.Log(Weapon.Bow);
    }
}
```

```output
16 17 15
best: 95 of 3
1 potion False
arrows: 15
3
2
1
Bow
```

- **المصفوفة** `int[]` حجمها ثابت (`Length`)، و **List** تكبر وتصغر (`Count` و `Add` و `Remove`)، و **Dictionary** أزواج مفتاح ← قيمة.
- `enum` قائمة قيم مسماة، أوضح من الأرقام والنصوص.
- `using System.Collections.Generic;` ضروري لـ List و Dictionary.

## أصناف C# العادية والخصائص

ليس كل صنف MonoBehaviour. بيانات اللاعب أو العنصر صنف عادي تنشئه بـ `new`:

```unity
// file: Item.cs
public class Item
{
    public string Name { get; private set; }
    public int Price { get; set; }
    public bool IsExpensive => Price > 100;

    public Item(string name, int price)
    {
        Name = name;
        Price = price;
    }

    public override string ToString() => $"{Name} ({Price} gold)";
}

// file: Shop.cs
using UnityEngine;

public class Shop : MonoBehaviour
{
    private int gold = 150;

    void Start()
    {
        Item sword = new Item("Sword", 120);
        Debug.Log(sword + " expensive=" + sword.IsExpensive);
        if (TryBuy(sword)) Debug.Log("bought, gold left: " + gold);
        if (!TryBuy(sword)) Debug.Log("not enough gold");
    }

    bool TryBuy(Item item)
    {
        if (gold < item.Price) return false;
        gold -= item.Price;
        return true;
    }
}
```

```output
Sword (120 gold) expensive=True
bought, gold left: 30
not enough gold
```

- **الخاصية** `{ get; private set; }` تُقرأ من أي مكان لكن لا تُغيَّر إلا من داخل الصنف: تحمي بياناتك.
- `=>` اختصار لدالة أو خاصية من سطر واحد.
- `private` (الافتراضي) لا يُرى خارج الصنف، و`public` يُرى من كل مكان (ويظهر في Inspector إن كان حقلاً في MonoBehaviour).

--- exercise
اكتب سكربت `Health.cs` (على كائن `Player`):

1. حقل `public int maxHealth = 100;` وخاصية `public int Current { get; private set; }`.
2. في `Awake`: اجعل `Current = maxHealth`.
3. خاصية `public bool IsDead => Current <= 0;`
4. دالة `public void TakeDamage(int amount)`: تُنقص `Current` ولا تجعله أقل من 0 (استخدم `Mathf.Max`).
5. دالة `public void Heal(int amount)`: تزيد `Current` ولا تتجاوز `maxHealth` (استخدم `Mathf.Min`).
6. دالة `public float Percent()`: ترجع النسبة كـ float من 0 إلى 1 (انتبه للقسمة الصحيحة!).

المشهد يضبط `maxHealth=80`.

~~~setup
[scene]
Main Camera: Camera pos=(0,0)
Player: GameObject pos=(0,0) sprite=player
  + Health maxHealth=80
~~~
~~~starter
using UnityEngine;

public class Health : MonoBehaviour
{
    public int maxHealth = 100;

    void Awake()
    {
    }
}
~~~
~~~solution
using UnityEngine;

public class Health : MonoBehaviour
{
    public int maxHealth = 100;
    public int Current { get; private set; }
    public bool IsDead => Current <= 0;

    void Awake()
    {
        Current = maxHealth;
    }

    public void TakeDamage(int amount)
    {
        Current = Mathf.Max(Current - amount, 0);
    }

    public void Heal(int amount)
    {
        Current = Mathf.Min(Current + amount, maxHealth);
    }

    public float Percent()
    {
        return (float)Current / maxHealth;
    }
}
~~~

~~~test
print(get("Player", "Current"), call("Player", "Percent"));
call("Player", "Heal", 100);
print(get("Player", "Current"));
call("Player", "TakeDamage", 500);
print(get("Player", "Current"), get("Player", "IsDead"));
~~~

~~~expected
80 1
50 0.625
80
0 True
~~~

## الحركة كل إطار و Time.deltaTime

`Update()` تُستدعى **كل إطار**، وعدد الإطارات في الثانية يختلف بين الأجهزة (30 أو 60 أو 144). لذلك نضرب السرعة في `Time.deltaTime` (زمن الإطار بالثواني) لتصبح "وحدة في الثانية":

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ship: GameObject pos=(-5,0) sprite=ship
  + Fly speed=3

// file: Fly.cs
using UnityEngine;

public class Fly : MonoBehaviour
{
    public float speed = 2f;

    void Update()
    {
        transform.Translate(Vector3.right * speed * Time.deltaTime);
    }
}
// test
step(60);
print(get("Ship", "transform.position"));
```

```output
(-2.00, 0.00, 0.00)
```

بعد ثانية (60 إطاراً) تحرك 3 وحدات بالضبط، وكذلك لو كانت 30 إطاراً أو 144.

## Input: لوحة المفاتيح

| الدالة | ترجع |
|---|---|
| `Input.GetKey(KeyCode.Space)` | true طالما المفتاح مضغوط |
| `Input.GetKeyDown(KeyCode.Space)` | true في إطار الضغط فقط |
| `Input.GetKeyUp(KeyCode.Space)` | true في إطار الرفع فقط |
| `Input.GetAxis("Horizontal")` | من -1 إلى 1 **بتدرج ناعم** (الأسهم و A/D) |
| `Input.GetAxisRaw("Horizontal")` | -1 أو 0 أو 1 فوراً |
| `Input.GetButtonDown("Jump")` | زر مسمى في Input Manager (Jump = المسافة) |

الفرق بين `GetAxis` و `GetAxisRaw` مهم: الأول يتسارع تدريجياً (حساسية 3 في الثانية) فتبدو الحركة ناعمة، والثاني فوري فيناسب ألعاب الدقة:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Probe: GameObject
  + AxisProbe

// file: AxisProbe.cs
using UnityEngine;

public class AxisProbe : MonoBehaviour
{
    public float smooth;
    public float raw;
    public int jumps;

    void Update()
    {
        smooth = Input.GetAxis("Horizontal");
        raw = Input.GetAxisRaw("Horizontal");
        if (Input.GetKeyDown(KeyCode.Space)) jumps++;
    }
}
// test
keyDown("right"); step(6);
print(get("Probe", "smooth.ToString(\"F2\")"), get("Probe", "raw"));
step(20);
print(get("Probe", "smooth"), get("Probe", "raw"));
keyUp("right"); step(1);
print(get("Probe", "smooth.ToString(\"F2\")"), get("Probe", "raw"));

print("jumps:", get("Probe", "jumps"));
```

```output
0.30 1
1 1
0.95 0
jumps: 1
```

ضغطنا المسافة 30 إطاراً، لكن `GetKeyDown` كانت true في إطار واحد فقط.

## الفأرة واللمس

```unity
[scene]
Main Camera: Camera pos=(0,0)
Clicker: GameObject
  + Clicker marker=@Marker
Marker: GameObject pos=(0,0) sprite=star

// file: Clicker.cs
using UnityEngine;

public class Clicker : MonoBehaviour
{
    public Transform marker;

    void Update()
    {
        if (Input.GetMouseButtonDown(0))
        {
            Vector3 screen = Input.mousePosition;
            Vector3 world = Camera.main.ScreenToWorldPoint(screen);
            world.z = 0;
            marker.position = world;
            Debug.Log("screen " + screen + " -> world " + world);
        }
    }
}
// test
click(360, 80);
```

```output
screen (360.00, 240.00, 0.00) -> world (3.75, 2.50, 0.00)
```

- `Input.mousePosition` بالبكسل على **الشاشة**، و(0, 0) في الزاوية **السفلية** اليسرى.
- `Camera.main.ScreenToWorldPoint` يحوّلها لإحداثيات **العالم** (الوحدات).
- `world.z = 0` مسموح لأن `world` متغير محلي. أما `transform.position.z = 0` فخطأ ترجمة، كما سترى في التمرين.

> **نظام الإدخال الجديد:** Unity 6 يأتي بحزمة **Input System** الحديثة (`InputAction` و `PlayerInput`) وهي الأنسب للمشاريع الكبيرة وأذرع التحكم. نستخدم هنا `Input` الكلاسيكي لأنه أبسط للتعلم، ويعمل بتفعيل **Active Input Handling = Both** في Player Settings.

## دورة حياة MonoBehaviour

Unity يستدعي دوال سكربتك تلقائياً بترتيب ثابت، حسب اسمها:

| الدالة | متى |
|---|---|
| `Awake()` | مرة عند إنشاء الكائن، قبل أي Start (حتى لو كان السكربت معطلاً) |
| `OnEnable()` | كلما تفعّل الكائن أو السكربت |
| `Start()` | مرة قبل أول Update، وبعد Awake **كل** الكائنات |
| `FixedUpdate()` | بمعدل ثابت (كل 0.02 ثانية = 50 مرة في الثانية): للفيزياء |
| `Update()` | كل إطار: المدخلات والمنطق |
| `LateUpdate()` | كل إطار بعد كل Update: تتبع الكاميرا |
| `OnDisable()` | عند التعطيل |
| `OnDestroy()` | عند الحذف |

```unity
[scene]
Main Camera: Camera pos=(0,0)
A: GameObject
  + Life label="A"

// file: Life.cs
using UnityEngine;

public class Life : MonoBehaviour
{
    public string label;
    public int updates, fixedUpdates;

    void Awake() { Debug.Log(label + " Awake"); }
    void OnEnable() { Debug.Log(label + " OnEnable"); }
    void Start() { Debug.Log(label + " Start"); }
    void FixedUpdate() { fixedUpdates++; }
    void Update() { updates++; }
    void LateUpdate() { if (updates == 1) Debug.Log(label + " first LateUpdate"); }
    void OnDisable() { Debug.Log(label + " OnDisable"); }
    void OnDestroy() { Debug.Log(label + " OnDestroy"); }
}
// test
step(60);
print("in 1s: Update", get("A", "updates"), "FixedUpdate", get("A", "fixedUpdates"));
```

```output
A Awake
A OnEnable
A Start
A first LateUpdate
in 1s: Update 60 FixedUpdate 50
```

في ثانية: 60 استدعاءً لـ `Update` (60 إطاراً) و 50 لـ `FixedUpdate` (كل 0.02 ثانية). لذلك:

- الفيزياء (`Rigidbody2D`) في `FixedUpdate`، والمدخلات في `Update` (لأن `GetKeyDown` قد تُفوَّت في FixedUpdate).
- `Awake` لتجهيز الكائن نفسه (`GetComponent`)، و`Start` لما يعتمد على كائنات أخرى (لأنها كلها مرت بـ Awake).

## Coroutines: الانتظار دون تجميد

تريد فعل شيء بعد ثانيتين، أو تكراراً بفاصل زمني؟ **Coroutine** دالة ترجع `IEnumerator` وتتوقف عند `yield return` ثم تكمل لاحقاً، واللعبة تعمل أثناء الانتظار:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Bomb: GameObject pos=(0,0) sprite=bomb
  + Bomb

// file: Bomb.cs
using UnityEngine;
using System.Collections;

public class Bomb : MonoBehaviour
{
    void Start()
    {
        StartCoroutine(Countdown(3));
        Debug.Log("Start finished at " + Time.time);
    }

    IEnumerator Countdown(int seconds)
    {
        for (int i = seconds; i > 0; i--)
        {
            Debug.Log(i + " at " + Time.time.ToString("F1"));
            yield return new WaitForSeconds(1f);
        }
        Debug.Log("BOOM at " + Time.time.ToString("F1"));
        Destroy(gameObject);
    }
}
// test
step(200);
print("exists:", exists("Bomb"));
```

```output
3 at 0.0
Start finished at 0
2 at 1.0
1 at 2.0
BOOM at 3.0
exists: false
```

- `StartCoroutine(Countdown(3))`: لاحظ الأقواس: نستدعي الدالة ونمرر الناتج.
- `yield return new WaitForSeconds(1f)` انتظار ثانية، و`yield return null` انتظار إطار واحد.
- الـ Coroutine يتوقف تلقائياً إذا حُذف الكائن أو تعطّل.

## Invoke و InvokeRepeating

لاستدعاء دالة بعد مدة أو بتكرار، دون كتابة Coroutine:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Spawner: GameObject pos=(0,3)
  + Spawner enemy=@Enemy

[prefab Enemy]
Enemy: GameObject sprite=enemy tag=Enemy

// file: Spawner.cs
using UnityEngine;

public class Spawner : MonoBehaviour
{
    public GameObject enemy;
    int spawned;

    void Start()
    {
        InvokeRepeating("Spawn", 0.5f, 1f);
        Invoke("Announce", 2f);
    }

    void Spawn()
    {
        spawned++;
        Instantiate(enemy, new Vector3(spawned * 2 - 5, 0, 0), Quaternion.identity);
        if (spawned == 4) CancelInvoke("Spawn");
    }

    void Announce()
    {
        Debug.Log("2 seconds: " + spawned + " enemies");
    }
}
// test
step(360);
print("enemies:", count("Enemy"));
```

```output
2 seconds: 2 enemies
enemies: 4
```

## LateUpdate: كاميرا تتبع اللاعب

الكاميرا يجب أن تتحرك **بعد** أن يتحرك اللاعب في الإطار نفسه، وإلا تهتز. لذلك تتبعه في `LateUpdate`:

```unity
[scene]
Main Camera: Camera pos=(0,0)
  + CameraFollow target=@Player offset=(2,1)
Ground: GameObject pos=(0,-2) sprite=platform
Player: GameObject pos=(0,0) sprite=player
  + Runner

// file: Runner.cs
using UnityEngine;

public class Runner : MonoBehaviour
{
    void Update()
    {
        transform.position += Vector3.right * 4 * Time.deltaTime;
    }
}

// file: CameraFollow.cs
using UnityEngine;

public class CameraFollow : MonoBehaviour
{
    public Transform target;
    public Vector2 offset;

    void LateUpdate()
    {
        Vector3 p = target.position + (Vector3)offset;
        p.z = transform.position.z;
        transform.position = p;
    }
}
// test
step(60);
print(get("Player", "transform.position"), get("Main Camera", "transform.position"));
```

```output
(4.00, 0.00, 0.00) (6.00, 1.00, 0.00)
```

~~~solution
using UnityEngine;
using System.Collections;

public class Blinker : MonoBehaviour
{
    public int times = 3;
    public float interval = 0.25f;

    void Start()
    {
        StartCoroutine(Blink());
    }

    IEnumerator Blink()
    {
        SpriteRenderer sr = GetComponent<SpriteRenderer>();
        for (int i = 0; i < times; i++)
        {
            sr.enabled = false;
            yield return new WaitForSeconds(interval);
            sr.enabled = true;
            yield return new WaitForSeconds(interval);
        }
        Debug.Log("done at " + Time.time.ToString("F1"));
    }
}
~~~

--- quiz
? أي دالة يستدعيها Unity قبل الأخرى دائماً؟
+ Awake قبل Start
- Start قبل Awake
- Update قبل Start
> Awake لكل الكائنات أولاً، ثم Start.

? أين تضع كود الفيزياء (Rigidbody)؟
+ FixedUpdate
- LateUpdate
- OnDestroy
> FixedUpdate بمعدل ثابت يتزامن مع محرك الفيزياء.

? ما الخطأ في `StartCoroutine(Countdown);`؟
+ يجب استدعاء الدالة: StartCoroutine(Countdown())
- يجب كتابة Invoke بدلاً منها
- لا خطأ
> نمرر IEnumerator الذي ترجعه الدالة.

? لماذا تُحرّك الكاميرا في LateUpdate؟
+ لأنها تُستدعى بعد كل Update فيكون اللاعب قد تحرك
- لأنها أسرع
- لأن الكاميرا لا تعمل في Update
> هكذا لا تتأخر الكاميرا إطاراً عن اللاعب.
