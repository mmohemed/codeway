## ما هو Unity؟

**Unity** أشهر محرك ألعاب في العالم: تُصنع به نسبة كبيرة من ألعاب الجوال، وألعاب كثيرة على الكمبيوتر والمنصات، وتطبيقات الواقع الافتراضي والمعزز. لغته **C#**، وتصدّر به اللعبة نفسها إلى Android و iOS و Windows و Mac و الويب وغيرها.

تثبّته عبر **Unity Hub** من unity.com: تنزّل Hub، ثم تختار إصدار المحرر (يفضّل إصدار LTS طويل الدعم)، ثم تنشئ مشروعاً بقالب **2D** أو **3D**. والترخيص المجاني (Unity Personal) يكفي للتعلم وللمشاريع الصغيرة.

> **عن أمثلة هذه الدورة:** محرر Unity برنامج ضخم على جهازك، لذلك نستخدم هنا **محاكياً تعليمياً** في المتصفح: يفسّر مجموعة كبيرة من C# ويشغّل دورة حياة السكربتات وفيزياء ثنائية الأبعاد مبسطة (صناديق تصادم بلا دوران). الكود الذي تكتبه هنا هو كود Unity نفسه، لكن المحرك الحقيقي فيه أكثر بكثير، ونتائجه الفيزيائية الدقيقة قد تختلف قليلاً.

## نوافذ المحرر

| النافذة | ما فيها |
|---|---|
| **Scene** | مساحة العمل: تضع الكائنات وتحركها بالفأرة |
| **Game** | ما تراه الكاميرا، أي ما يراه اللاعب |
| **Hierarchy** | قائمة كل الكائنات في المشهد الحالي على شكل شجرة |
| **Inspector** | خصائص الكائن المحدد ومكوّناته، وتعديل قيمها |
| **Project** | ملفات المشروع: السكربتات والصور والأصوات والمشاهد (مجلد Assets) |
| **Console** | رسائل `Debug.Log` والتحذيرات والأخطاء |

وفي الأعلى زر **Play ▶**: يشغّل اللعبة داخل المحرر. انتبه: **كل تغيير في Inspector أثناء التشغيل يضيع عند الإيقاف** (خطأ شائع جداً للمبتدئين).

أدوات التحريك في نافذة Scene: **W** للتحريك و **E** للتدوير و **R** للتحجيم، و **F** لتقريب الكاميرا من الكائن المحدد.

## الـ Hierarchy والـ Inspector في هذه الدورة

نكتب الـ Hierarchy نصاً بعد `[scene]`: كل سطر `الاسم: النوع` ثم خصائص، والمسافة البادئة تعني "ابن لما فوقه". والسطر الذي يبدأ بـ `+` **مكوّن** (Component) على الكائن الذي فوقه، وبعده قيم حقوله كما تضبطها في Inspector. والسكربتات تأتي بعد `// file: اسم.cs`:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Player: GameObject pos=(-3,0) sprite=player
  + Greeter message="Hello Unity" times=2
Enemy: GameObject pos=(3,0) sprite=enemy

// file: Greeter.cs
using UnityEngine;

public class Greeter : MonoBehaviour
{
    public string message = "Hi";
    public int times = 1;

    void Start()
    {
        for (int i = 0; i < times; i++)
            Debug.Log(message);
        Debug.Log("I am " + gameObject.name + " at " + transform.position);
    }
}
```

```output
Hello Unity
Hello Unity
I am Player at (-3.00, 0.00, 0.00)
```

- السكربت **صنف** يرث `MonoBehaviour`، واسم الصنف يجب أن يطابق اسم الملف (`Greeter.cs`).
- الحقول `public` تظهر في Inspector، وقيمة Inspector (`"Hello Unity"`) **تتغلب** على القيمة في الكود (`"Hi"`).
- `Start()` يستدعيها Unity مرة قبل أول إطار.
- `Debug.Log` تكتب في نافذة Console.
- `transform.position` موقع الكائن، ويُطبع بخانتين عشريتين.

## الإحداثيات والوحدات

في Unity الوحدة **متر**، و **y يزيد للأعلى** (عكس Godot و Phaser)، والنقطة (0, 0) في **منتصف** الشاشة إذا كانت الكاميرا عندها. وكاميرا 2D الافتراضية (Orthographic Size = 5) ترى 10 وحدات طولاً.

```unity
[scene]
Main Camera: Camera pos=(0,0)
Box: GameObject pos=(0,0) color=#ffd84d size=(1,1)
  + Mover

// file: Mover.cs
using UnityEngine;

public class Mover : MonoBehaviour
{
    void Start()
    {
        transform.position = new Vector3(2, 3, 0);
        Debug.Log(transform.position);
        transform.position += Vector3.right * 2;
        Debug.Log(transform.position.x);
        transform.localScale = new Vector3(2, 1, 1);
        transform.Rotate(0, 0, 45);
        Debug.Log(transform.eulerAngles.z);
    }
}
```

```output
(2.00, 3.00, 0.00)
4
45
```

كل كائن فيه **Transform** دائماً: الموقع `position` والدوران `rotation` والحجم `localScale`. وهو المكوّن الوحيد الذي لا يمكن حذفه.

## الكائن (GameObject) والمكوّنات (Components)

فكرة Unity الأساسية: **الكائن وعاء فارغ، والمكوّنات تعطيه قدراته**. الكائن وحده لا يفعل شيئاً، ثم تضيف له:

| المكوّن | يعطي الكائن |
|---|---|
| `Transform` | موقع ودوران وحجم (موجود دائماً) |
| `SpriteRenderer` | صورة ثنائية الأبعاد |
| `Rigidbody2D` | جاذبية وسرعة وفيزياء |
| `BoxCollider2D` / `CircleCollider2D` | شكل تصادم |
| `AudioSource` | تشغيل صوت |
| `Animator` | رسوم متحركة |
| سكربتك (`PlayerController`) | سلوكك الخاص |

وفي المحرر: Inspector ← **Add Component**. وفي الكود: `AddComponent<T>()`.

## GetComponent: الوصول للمكوّنات

السكربت يصل إلى مكوّن آخر على نفس الكائن بـ `GetComponent<النوع>()`. والأسلوب الصحيح أن تجلبه **مرة واحدة** في `Awake` أو `Start` وتحفظه في متغير، لا في كل إطار:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Ball: GameObject pos=(0,2) sprite=coin
  + Rigidbody2D gravityScale=1
  + CircleCollider2D
  + BallInfo

// file: BallInfo.cs
using UnityEngine;

public class BallInfo : MonoBehaviour
{
    private Rigidbody2D rb;
    private SpriteRenderer sr;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        sr = GetComponent<SpriteRenderer>();
    }

    void Start()
    {
        Debug.Log("gravity: " + rb.gravityScale);
        rb.gravityScale = 0;
        sr.flipX = true;
        Debug.Log("has collider: " + (GetComponent<Collider2D>() != null));
        Debug.Log("has audio: " + (GetComponent<AudioSource>() != null));
        AudioSource audio = gameObject.AddComponent<AudioSource>();
        Debug.Log("added: " + audio);
    }
}
```

```output
gravity: 1
has collider: True
has audio: False
added: Ball (UnityEngine.AudioSource)
```

- `GetComponent<Collider2D>()` يجد `CircleCollider2D` لأنه نوع من `Collider2D`.
- إذا لم يكن المكوّن موجوداً ترجع `null`، فافحص قبل الاستخدام.
- `gameObject` الكائن الذي عليه السكربت، و`transform` اختصار لـ `gameObject.transform`.

## الوسوم (Tags) والبحث والتفعيل

```unity
[scene]
Main Camera: Camera pos=(0,0)
Manager: GameObject
  + Finder
Enemy1: GameObject pos=(-3,0) sprite=enemy tag=Enemy
Enemy2: GameObject pos=(3,0) sprite=enemy tag=Enemy
Door: GameObject pos=(0,-2) color=#8b5a2b size=(1,2)

// file: Finder.cs
using UnityEngine;

public class Finder : MonoBehaviour
{
    void Start()
    {
        GameObject[] enemies = GameObject.FindGameObjectsWithTag("Enemy");
        Debug.Log("enemies: " + enemies.Length);
        foreach (GameObject e in enemies)
            Debug.Log(e.name + " tag=" + e.tag + " compare=" + e.CompareTag("Enemy"));

        GameObject door = GameObject.Find("Door");
        door.SetActive(false);
        Debug.Log("door active: " + door.activeSelf);
        Debug.Log("find inactive: " + (GameObject.Find("Door") == null));
    }
}
```

```output
enemies: 2
Enemy1 tag=Enemy compare=True
Enemy2 tag=Enemy compare=True
door active: False
find inactive: True
```

- **Tag** تصنيف للكائن (Player و Enemy و Coin...) تختاره في أعلى Inspector، و`CompareTag` أسرع وأضمن من مقارنة النصوص.
- `SetActive(false)` يعطّل الكائن كله: يختفي ويتوقف سكربته. و`GameObject.Find` **لا يجد الكائنات المعطلة**.
- `GameObject.Find` بطيء نسبياً لأنه يبحث في كل المشهد، فلا تستدعه في `Update`. والأفضل غالباً حقل `public` تسحب إليه الكائن في Inspector.

## المراجع عبر Inspector

بدل البحث بالاسم، اجعل الحقل `public` من نوع `GameObject` أو `Transform` أو أي مكوّن، واسحب الكائن إليه في Inspector. في هذه الدورة: `target=@Player`:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Player: GameObject pos=(2,1) sprite=player
  + Rigidbody2D gravityScale=0
Turret: GameObject pos=(-3,0) sprite=ship
  + Turret target=@Player body=@Player

// file: Turret.cs
using UnityEngine;

public class Turret : MonoBehaviour
{
    public Transform target;
    public Rigidbody2D body;
    public GameObject missing;

    void Start()
    {
        float d = Vector3.Distance(transform.position, target.position);
        Debug.Log("distance: " + d.ToString("F2"));
        Debug.Log("target body: " + body.gravityScale);
        Debug.Log(missing == null);
        Debug.Log(missing.name);
    }
}
```

```output
distance: 5.10
target body: 0
True
ERR: UnassignedReferenceException: The variable missing of Turret has not been assigned.
ERR: You probably need to assign the missing variable of the Turret script in the inspector. (Turret.Start، السطر 17)
```

حقل لم تضبطه في Inspector ثم استخدمته: يظهر في Console خطأ `UnassignedReferenceException` يخبرك باسم الحقل والسكربت. وهذا من أكثر الأخطاء شيوعاً في Unity، ونصّه يدلّك على الحل مباشرة.

## المشاهد (Scenes)

**المشهد** ملف `.unity` فيه مجموعة كائنات: قائمة البداية مشهد، وكل مستوى مشهد، وشاشة الخسارة مشهد. واللعبة تنتقل بينها بـ `SceneManager`:

```csharp
using UnityEngine.SceneManagement;

SceneManager.LoadScene("Level2");                                     // بالاسم
SceneManager.LoadScene(1);                                            // برقمها في Build Settings
SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);     // إعادة المستوى الحالي
```

**مهم:** لا يُحمّل مشهد إلا إذا أضفته إلى **File ← Build Profiles (أو Build Settings) ← Scene List**، وترتيبه هناك هو رقمه. في هذه الدورة كل `[scene اسم]` مشهد مضاف بالترتيب، والأول يبدأ تلقائياً:

```unity
[scene Menu]
Main Camera: Camera pos=(0,0)
Menu: GameObject
  + MainMenu
Title: Text ui=(150,140) text="MY GAME - press Enter"

[scene Level1]
Main Camera: Camera pos=(0,0)
Player: GameObject pos=(0,0) sprite=player
  + LevelInfo

// file: MainMenu.cs
using UnityEngine;
using UnityEngine.SceneManagement;

public class MainMenu : MonoBehaviour
{
    void Start()
    {
        Debug.Log("Scene: " + SceneManager.GetActiveScene().name);
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Return))
            SceneManager.LoadScene("Level1");
    }
}

// file: LevelInfo.cs
using UnityEngine;
using UnityEngine.SceneManagement;

public class LevelInfo : MonoBehaviour
{
    void Start()
    {
        Scene s = SceneManager.GetActiveScene();
        Debug.Log("Now in " + s.name + " (index " + s.buildIndex + ")");
        Debug.Log("Menu still here? " + (GameObject.Find("Menu") != null));
    }
}
// test
step(5);
press("enter");
step(2);
```

```output
Scene: Menu
Now in Level1 (index 1)
Menu still here? False
```

عند تحميل مشهد جديد **تُحذف كل كائنات المشهد القديم** (وتُستدعى `OnDestroy` فيها)، ثم تُنشأ كائنات المشهد الجديد.

## DontDestroyOnLoad: كائن يبقى بين المشاهد

مدير اللعبة أو مشغّل الموسيقى يجب أن يبقى عند الانتقال. `DontDestroyOnLoad(gameObject)` يحميه من الحذف. ومع **Singleton** نضمن نسخة واحدة فقط:

```unity
[scene Level1]
Main Camera: Camera pos=(0,0)
GameManager: GameObject
  + GameManager

[scene Level2]
Main Camera: Camera pos=(0,0)
GameManager: GameObject
  + GameManager

// file: GameManager.cs
using UnityEngine;
using UnityEngine.SceneManagement;

public class GameManager : MonoBehaviour
{
    public static GameManager Instance;
    public int score;

    void Awake()
    {
        if (Instance != null)
        {
            Debug.Log("duplicate destroyed");
            Destroy(gameObject);
            return;
        }
        Instance = this;
        DontDestroyOnLoad(gameObject);
    }

    void Start()
    {
        score += 10;
        Debug.Log("score: " + score);
        if (SceneManager.GetActiveScene().name == "Level1")
            SceneManager.LoadScene("Level2");
    }
}
// test
step(5);
print("managers:", named("GameManager"), get("GameManager", "GameManager.Instance.score"));
```

```output
score: 10
duplicate destroyed
managers: 1 10
```

- `static` يجعل `Instance` مشتركاً للصنف كله، فأي سكربت يكتب `GameManager.Instance.score`.
- في المشهد الثاني أُنشئت نسخة جديدة فوجدت `Instance` موجوداً فحذفت نفسها، وبقيت الأصلية بنقاطها.

## الـ Prefabs: قوالب الكائنات

**Prefab** كائن جاهز محفوظ في مجلد Project (تسحب الكائن من Hierarchy إلى Project). ثم تنشئ منه نسخاً بالكود بـ `Instantiate`، وأي تعديل على الـ Prefab يظهر في كل نسخه. في هذه الدورة يُعرَّف بـ `[prefab اسم]`:

```unity
[scene]
Main Camera: Camera pos=(0,0)
Spawner: GameObject pos=(0,3)
  + Spawner coinPrefab=@Coin count=4

[prefab Coin]
Coin: GameObject sprite=coin tag=Coin
  + CircleCollider2D isTrigger=true

// file: Spawner.cs
using UnityEngine;

public class Spawner : MonoBehaviour
{
    public GameObject coinPrefab;
    public int count = 3;

    void Start()
    {
        for (int i = 0; i < count; i++)
        {
            Vector3 pos = new Vector3(-3 + i * 2, 0, 0);
            GameObject c = Instantiate(coinPrefab, pos, Quaternion.identity);
            c.name = "Coin " + i;
        }
        Debug.Log("coins: " + GameObject.FindGameObjectsWithTag("Coin").Length);
        Destroy(GameObject.Find("Coin 0"));
        Destroy(GameObject.Find("Coin 1"), 0.5f);
    }
}
// test
step(1);
print(count("Coin"));
step(40);
print(count("Coin"));
```

```output
coins: 4
3
2
```

- `Instantiate(prefab, موقع, دوران)` ترجع النسخة الجديدة، واسمها الافتراضي `Coin(Clone)`.
- `Quaternion.identity` يعني "بلا دوران".
- `Destroy(obj)` يحذف في نهاية الإطار، و`Destroy(obj, 0.5f)` بعد نصف ثانية.

لعبة فيها مشهدان: `Level` و `GameOver`. في `Level` كائن `Player` عليه سكربتك `Lives.cs`، وفيه حقل `public int lives = 3;` (المشهد يضبطه 2).

اكتب `Lives.cs`:

1. دالة `public void Hit()`: تُنقص `lives` بواحد وتطبع `"Lives: "` ثم العدد.
2. إذا وصلت `lives` إلى 0: اطبع `"Game Over"` ثم حمّل المشهد `"GameOver"`.
3. لا تنسَ `using UnityEngine.SceneManagement;`.

الفحص يستدعي `Hit()` مرتين ثم يتأكد من المشهد الحالي.

~~~setup
[scene Level]
Main Camera: Camera pos=(0,0)
Player: GameObject pos=(0,0) sprite=player
  + Lives lives=2

[scene GameOver]
Main Camera: Camera pos=(0,0)
Message: Text ui=(180,150) text="GAME OVER"
~~~
~~~starter
using UnityEngine;

public class Lives : MonoBehaviour
{
    public int lives = 3;

    public void Hit()
    {
    }
}
~~~
~~~solution
using UnityEngine;
using UnityEngine.SceneManagement;

public class Lives : MonoBehaviour
{
    public int lives = 3;

    public void Hit()
    {
        lives--;
        Debug.Log("Lives: " + lives);
        if (lives == 0)
        {
            Debug.Log("Game Over");
            SceneManager.LoadScene("GameOver");
        }
    }
}
~~~

step(1);
call("Player", "Hit");
step(1);
print(scene());
call("Player", "Hit");
step(1);
print(scene(), exists("Player"), exists("Message"));
~~~

Lives: 0
Game Over
GameOver false true
~~~
