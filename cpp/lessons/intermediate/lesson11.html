المراجع (References) في ++C

أسماء مستعارة للذاكرة – كفاءة وتحكم

اسم مستعار

المرجع هو اسم آخر (alias) لمتغير موجود. لا يستهلك ذاكرة إضافية، بل يشير إلى نفس العنوان.

تمرير بكفاءة

تمرير المتغيرات للدوال بالمرجع يتجنب نسخ البيانات، مما يحسن الأداء للأنواع الكبيرة.

تعديل مباشر

أي تغيير على المرجع ينعكس على المتغير الأصلي، لأنها تشير إلى نفس الموقع.

1. تعريف المرجع (Reference)

يتم تعريف المرجع باستخدام & بعد النوع. يجب أن تتم تهيئته عند التعريف (لا يمكن أن يكون فارغاً).

int original = 50;
int &ref = original;  // ref أصبح مرجعاً للمتغير original

cout << original;    // 50
cout << ref;         // 50 أيضاً

ref = 100;            // تعديل قيمة ref يعدل original
cout << original;     // 100

// ملاحظة: لا يمكن إعادة ربط المرجع بمتغير آخر بعد تعريفه.
تنبيه أساسي: يجب تهيئة المرجع عند تعريفه. لا يمكنك كتابة int &ref; دون إعطائه متغيراً يرتبط به. (الاستثناء: معاملات الدوال، أعضاء class، وفي بعض السياقات المحددة).

2. المرجع (&) vs المؤشر (*)

وجه المقارنةالمرجع (Reference)المؤشر (Pointer)
التهيئةيجب أن يُهيأ عند التعريف (يرتبط بمتغير)يمكن تركه غير مهيأ (قيمة عشوائية)
إعادة الربطلا يمكن جعله يشير إلى متغير آخر بعد الربطيمكن تغيير عنوان المؤشر في أي وقت
القيمة NULL/nullptrلا يمكن أن يكون NULL، دائماً مرتبط بمتغيريمكن أن يساوي nullptr (لا يشير لشيء)
الوصول للقيمةتلقائي (لا حاجة لاستخدام *)يحتاج إلى * للإشارة للقيمة (dereference)
الاستخدام الأكثر شيوعاًمعاملات الدوال، التحميل الزائد، for-eachإدارة الذاكرة الديناميكية، هياكل البيانات

3. تمرير الدوال بالمرجع

المراجع تسمح للدالة بتعديل المتغير الأصلي، وتجنب نسخ البيانات الضخمة.

// تمرير بالقيمة (يتم النسخ)
void incrementByValue(int x) {
    x++;  // يعدل النسخة فقط، الأصل لا يتغير
}

// تمرير بالمرجع (يتعامل مع الأصل)
void incrementByReference(int &x) {
    x++;  // يعدل المتغير الأصلي
}

int main() {
    int a = 10, b = 20;
    incrementByValue(a);
    cout << a;  // 10 (لم يتغير)
    
    incrementByReference(b);
    cout << b;  // 21 (تغير)
    return 0;
}

المرجع إلى ثابت (const reference): يستخدم لقراءة البيانات دون تعديلها، مع تجنب النسخ. مثالي للكائنات الكبيرة. void display(const string &text);

4. إرجاع مرجع من دالة

يمكن للدالة إرجاع مرجع، مما يسمح باستخدامها في الطرف الأيسر من معادلة التخصيص.

int arr[] = {10, 20, 30};

// دالة ترجع مرجعاً للعنصر في المصفوفة
int &getElement(int index) {
    return arr[index];  // إرجاع مرجع
}

int main() {
    getElement(1) = 99;  // الآن arr[1] = 99
    cout << arr[1];      // 99
    return 0;
}
تحذير: لا تُرجع مرجعاً إلى متغير محلي (local variable) لأنه سيتم تدميره عند انتهاء الدالة.

5. مراجع rvalue (&&) – نقل الموارد

ظهرت في C++11 لدعم دلالات النقل (move semantics) وتجنب النسخ غير الضروري.

void processValue(int &x) {   // مرجع lvalue
    cout << "lvalue reference";
}

void processValue(int &&x) {  // مرجع rvalue
    cout << "rvalue reference";
}

int main() {
    int a = 5;
    processValue(a);           // lvalue reference
    processValue(10);          // rvalue reference (10 مؤقت)
    processValue(std::move(a));// rvalue reference بعد تحويل a
    return 0;
}

6. استخدام المراجع مع حلقات for

لتعديل عناصر المجموعة أو تجنب نسخها، نستخدم المرجع.

vector<int> vec = {1, 2, 3, 4};

// بدون مرجع (نسخ) – لا يمكن تعديل العناصر
for (auto x : vec) {
    x = 0;  // يؤثر على النسخة فقط
}

// باستخدام مرجع – تعديل حقيقي
for (auto &x : vec) {
    x *= 2;  // يضاعف كل عنصر
}

// مرجع ثابت للقراءة فقط
for (const auto &x : vec) {
    cout << x;  // نقرأ ولا نعدل
}

7. قواعد طي المراجع (Reference collapsing)

في قوالب C++، قد تظهر مراجع لمراجع، لكن القواعد تطويها إلى مرجع واحد. مثال:

template<typename T>
void func(T &x) { // إذا أُرسل int&، تصبح T = int& ، فيصبح النوع int& &
    // قواعد الطي: & + & → & , && + & → & , & + && → & , && + && → &&
}

تطبيقات عملية مع المراجع

المبادلة (Swap) بالمرجع

void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

البحث وإرجاع مرجع

int &findLargest(int arr[], int size) {
    int maxIdx = 0;
    for(int i=1; i arr[maxIdx]) maxIdx = i;
    return arr[maxIdx];
}

تمرين: اكتب دالة تستخدم مرجعاً لتقرأ قيمة من المستخدم وتخزنها في متغير

عرض الحل 
#include <iostream>
using namespace std;

void readInput(int &value) {
    cout << "أدخل رقماً: ";
    cin >> value;
}

int main() {
    int number;
    readInput(number);  // يتم تعبئة number مباشرة
    cout << "لقد أدخلت: " << number;
    return 0;
}

أفضل الممارسات

  • استخدم المراجع للتمرير لتجنب النسخ.
  • استخدم const reference للقراءة فقط.
  • لا تُرجع مرجعاً لمتغير محلي.
  • استخدم المراجع في حلقات for للتعديل.
  • تعلم rvalue references للنقل (move).
  • المراجع أكثر أماناً من المؤشرات غالباً.
