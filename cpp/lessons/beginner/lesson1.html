📚 نظرة عامة

لغة C++ هي لغة برمجة قوية ومتعددة الاستخدامات، تم تطويرها في عام 1979 بواسطة بيارن ستروستروب في مختبرات بيل. تعتبر C++ امتداداً للغة C مع إضافة مفهوم البرمجة كائنية التوجه.

معلومة مهمة: C++ هي اللغة المستخدمة في تطوير أنظمة التشغيل، الألعاب، التطبيقات عالية الأداء، وحتى متصفحات الإنترنت!

🎯 لماذا تتعلم C++؟

  • أداء عالي وسرعة فائقة
  • تحكم كامل في إدارة الذاكرة
  • مجال واسع للاستخدامات
  • أساس قوي لتعلم لغات أخرى

💻 أول برنامج في C++

لنبدأ بأشهر برنامج في عالم البرمجة - برنامج "Hello, World!"

// أول برنامج في C++
#include <iostream>

using namespace std;

int main() {
    cout << "مرحباً بالعالم!" << endl;
    return 0;
}
شرح الكود:
  • #include <iostream> - استدعاء مكتبة الإدخال والإخراج
  • using namespace std; - استخدام المساحة القياسية
  • int main() - الدالة الرئيسية التي يبدأ منها البرنامج
  • cout - أمر الطباعة على الشاشة
