إعداد بيئة التطوير (IDE)

تقدمك في الدرس: 50% (تمت مشاهدة 3 من 6 أقسام)

📚 ماذا نحتاج لنكتب برامج C++؟

قبل أن تكتب أي برنامج، تحتاج إلى أداتين أساسيتين:

  • محرر نصوص تكتب فيه الكود وتحفظه في ملف امتداده .cpp.
  • مُترجِم (Compiler) يحوّل الكود الذي كتبته إلى برنامج تنفيذي يفهمه الحاسوب، مثل g++ أو مترجم Microsoft.

وبيئة التطوير المتكاملة (IDE) برنامج واحد يجمع المحرر والمترجم وأداة تتبّع الأخطاء (Debugger)، فتكتب وتشغّل بضغطة زر.

كيف يعمل البرنامج؟ تكتب الكود في main.cpp ← يترجمه المترجم ← ينتج ملفًا تنفيذيًا (main.exe في Windows، أو main في Linux و macOS) ← تشغّله. على عكس Python، لا يعمل كود C++ قبل ترجمته.

🧰 أي بيئة أختار؟

  • Visual Studio Community (Windows، مجاني): بيئة متكاملة جاهزة فيها المترجم. الأسهل للمبتدئ على Windows.
  • VS Code مع المترجم g++ (كل الأنظمة، مجاني): محرر خفيف ومنتشر، تضيف له إضافة C/C++ من Microsoft ومترجمًا منفصلًا.
  • Code::Blocks (كل الأنظمة، مجاني): بيئة بسيطة، ولها نسخة تثبيت لـ Windows تحتوي المترجم MinGW.
  • مترجم على الإنترنت مثل OnlineGDB أو Compiler Explorer: لتجربة سريعة بلا تثبيت، لكنه لا يغني عن بيئة على جهازك للمشاريع.

🪟 التثبيت على Windows: Visual Studio

  1. نزّل Visual Studio Community من موقع Microsoft الرسمي وشغّل المثبّت.
  2. في شاشة اختيار المكوّنات (Workloads) اختر Desktop development with C++ ثم اضغط Install.
  3. بعد التثبيت افتح Visual Studio واختر Create a new project ثم Console App (بلغة C++).
  4. اكتب الكود في الملف المفتوح، ثم اضغط Ctrl + F5 للتشغيل دون Debugger، فتظهر نافذة الناتج.
إذا فضّلت VS Code على Windows، فثبّت المترجم MinGW-w64 (مثلًا عبر MSYS2) وأضف مجلد bin الخاص به إلى متغير PATH، ثم تأكد بالأمر g++ --version في موجه الأوامر.

🐧 التثبيت على Linux و macOS

على Ubuntu و Debian ثبّت أدوات البناء بأمر واحد في الطرفية:

sudo apt update
sudo apt install build-essential

وعلى macOS ثبّت أدوات المطوّر من Apple (تحتوي المترجم clang، ويمكن استدعاؤه بالأمر g++):

xcode-select --install

ثم تأكد أن المترجم يعمل:

g++ --version

💻 ترجمة البرنامج وتشغيله من الطرفية

احفظ الكود التالي في ملف اسمه hello.cpp:

#include <iostream>

int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}

ثم افتح الطرفية في مجلد الملف، وترجمه وشغّله:

g++ hello.cpp -o hello      # الترجمة: ينتج برنامجًا اسمه hello
./hello                     # التشغيل في Linux و macOS
hello.exe                   # التشغيل في Windows

الناتج: Hello, C++!

خيارات مفيدة للمترجم:
  • -o اسم يحدد اسم البرنامج الناتج (بدونه يكون a.out أو a.exe).
  • -Wall يعرض التحذيرات التي تكشف أخطاء شائعة مبكرًا.
  • -std=c++17 يحدد إصدار اللغة المستخدم.

⚠️ أخطاء شائعة عند البداية

  • 'g++' is not recognized: المترجم غير مثبت أو مجلده غير مضاف إلى PATH. أغلق الطرفية وافتحها من جديد بعد إضافته.
  • expected ';' before ...: نسيت الفاصلة المنقوطة في نهاية سطر. اقرأ رقم السطر في رسالة الخطأ.
  • التعديل لا يظهر: نسيت حفظ الملف، أو شغّلت البرنامج القديم دون إعادة الترجمة.
  • النافذة تُغلق فورًا عند تشغيل البرنامج بالنقر المزدوج: شغّله من الطرفية، أو بـ Ctrl + F5 في Visual Studio.

📝 ملخص الدرس

  • كود C++ يُكتب في ملف .cpp ثم يُترجم إلى برنامج تنفيذي قبل تشغيله.
  • على Windows: Visual Studio Community مع «Desktop development with C++» هو الأسهل للبداية.
  • على Linux: build-essential، وعلى macOS: xcode-select --install.
  • الترجمة بـ g++ ملف.cpp -o اسم ثم تشغيل البرنامج الناتج.
  • اقرأ رسالة الخطأ ورقم السطر: هي دليلك الأول لإصلاح المشكلة.
